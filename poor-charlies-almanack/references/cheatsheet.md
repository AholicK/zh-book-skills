# 决策规则速查 — 《穷查理宝典：芒格智慧箴言与私人书单》（珍藏本 1+2 册）

| 能力 | 一句话规则 |
|---|---|
| 人类误判心理学：25 倾向检查清单（总纲、对策与倾向库） | 决定前把 25 种心理倾向逐条对照一遍——最大的错误来源在聪明人自己的脑子里。 |
| 多元思维模型格栅（普世智慧） | 从各重要学科取 95% 的大道理，组成随时可调用的思维模型格栅。 |
| 逆向思维与证否 | 想成功先研究怎样失败——把失败原因排列成检查清单，再逐项避开。 |
| 集中投资决策法（定错价格、考勤卡、重注与坐等） | 把出手次数压到一生 20 次，只在赔率明显错误时狠狠下注，然后安坐。 |
| 能力圈（三档过滤器与边界） | 只在自己能持续做出更准判断的领域里出手——问「在不在圈内」，这个问题本身就是答案。 |
| 激励机制设计与审计 | 设计或审计任何制度时，先问：这套机制实际上在奖励什么行为？ |
| 诉诸利益的说服与讲清理由 | 想说服别人，先把他能得到的利益讲清楚——理由要讲，但要讲进对方的利益里。 |
| 坏消息制度与认错坦白 | 有坏消息立刻汇报，只有好消息可以等待——把「欢迎坏消息」变成制度而不是美德。 |
| 学习机器与技能操练 | 每天睡前比早晨聪明一点点——把学习变成机制、把技能编成检查清单对抗遗忘。 |
| 心态修炼：不自怜、不妒忌、抗打击 | 不幸来临时有两条路——自怜是标准反应但不是唯一反应；把每次不幸当作学东西的机会。 |
| 规模优势与竞争分析 | 分析行业先盘两条清单：规模优势从哪里来、规模劣势什么时候反噬。 |
| 技术第二步分析与冲浪/竞争性毁灭 | 新技术出台先做第二步分析——省下的钱最后落在谁手里，再判断公司是冲浪还是被浪吞。 |
| 会计红旗识别 | 看到 EBITDA 就换成「狗屁利润」，看到脱离现实的假设就想会计丑闻。 |
| 反面教材教育法 | 教孩子的有效方式不是讲道理——用德育故事打底，用反面教材划边界。 |
| 个人财务守则 | 先把信用卡和透支堵住，再把物质需求降下来——节俭是责任的仆人。 |
| 晚年与人生阶段 | 晚年最好的铠甲是此前被悉心度过的生活——不贪财、不抱怨、不提前退场，把建设性的工作做到底。 |
| 专家与顾问审计 | 面对专家先问三句话：这条建议对他自己是否特别有利、他有没有「司机知识」、他的过往业绩如何。 |
| 从众与独立判断 | 「大家都这样」不是理由——识别从众压力，提前建好反从众的机制。 |
| 双轨分析 | 重要决定做两轨检查：理性地看利益结构，再单独看大脑可能自动犯哪些错。 |
| 投资错误规避（负面清单） | 投资先别急着赢——不做空、不碰 IPO、别买避税结构、别听预测，先把高失败率动作排掉。 |
| 为人处世：品格、勤勉与职业选择 | 想得到好东西，先让自己配得上——选对上司、把工作一次做好、和可靠的人长期合作。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
