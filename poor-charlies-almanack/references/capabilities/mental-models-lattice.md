# 多元思维模型格栅（普世智慧）

## R — 原文 (Reading)

> 如果你们只是记得一些孤立的事物，试图把它们硬凑起来，那么你们无法真正地理解任何东西。如果这些事物不在一个理论框架中相互联系，你们就无法把它们派上用场。你们必须在头脑中拥有一些思维模型。……
> 你必须拥有多元思维模型——因为如果你只能使用一两个，研究人性的心理学表明，你将会扭曲现实，直到它符合你的思维模型，或者至少到你认为它符合你的模型为止。……
> 这些模型必须来自各个不同的学科——因为你们不可能在一个小小的院系里面发现人世间全部的智慧。正是由于这个原因，诗歌教授大体上不具备广义上的智慧。他们的头脑里没有足够的思维模型。所以你必须拥有横跨许多学科的模型。……
>
> — 第一讲 · 基本的、普世的智慧是什么？（L3136-3148）

> 那就像谚语所说的：“在手里拿着铁锤的人看来，每个问题都像钉子。”……
> “铁锤人倾向”并没有放过布兰夏德和斯金纳这么聪明的人。如果你们不注意的话，它也不会放过你们。
>
> — 第一讲 · 基本的、普世的智慧是什么？（L3142）；第三讲 · 一、奖励和惩罚超级反应倾向（L3922）

## I — 方法论骨架 (Interpretation)

格栅的第一条规则：孤立的知识既无法理解、也无法派上用场——经验必须悬挂在一个由许多思维模型组成的框架上。三条要求把「格栅」与「知识面」区分开：

1. **多元**。如果你只能使用一两个模型，研究人性的心理学表明，你会扭曲现实，「直到它符合你的思维模型」；这就是「铁锤人倾向」——在手里拿着铁锤的人看来，每个问题都像钉子。作者称它是灾难性的思考方式，也是灾难性的处世方式。
2. **跨学科**。模型必须来自各个不同的学科；作者称真正重要的大道理占每个学科的 95%（第二讲 L3694），所以不必精通全部，只需吸取各科最要紧的部分。
3. **用上并操练**。重要学科的重要理论「要全部都用上，而不是只用几种」（第四章 L875）；并要「认真学习这些模型，让它们变成你随时能够使用的本领」（第四章 L883）——像钢琴家必须持续练习，而不是收藏知识点。

自检信号：技能种类减少 → 可用的模型减少 → 陷入铁锤人倾向引起的错误（第三讲 L4392）。中招者名单提醒我们它不放过聪明人：斯金纳（只信激励）、布兰夏德、格雷厄姆的信徒。

## A1 — 书中的应用 (Past Application)

### 案例 1: 蒙眼下棋的象棋大师：基本知识的力量
- **类型**: 书中转述（第四章）
- **问题**: 芒格要说明「常（非常）识」——非常基础的知识——是一种威力巨大的工具
- **方法论的使用**: 他举了一位象棋大师的例子：此人在伯克希尔·哈撒韦开年会那个周末赶到奥马哈展示棋技，蒙上眼睛同时跟好几个人对弈；之所以能做到，是因为他拥有关于棋盘的扎实知识
- **结论**: 你拥有的基本知识越多，需要吸取的新知识就越少
- **结果**: 未说明

### 案例 2: 芒格的数学与物理学教育：硬科学思维打底
- **类型**: 作者亲历（第一章）
- **问题**: 如何获得日后跨学科普世智慧的地基
- **方法论的使用**: 芒格 1941 年进入密歇根大学时选择数学作为专业（被数学逻辑和推理所吸引），上了一门理科必修基础课程后又喜欢上了物理学；此后他被派往新墨西哥大学、加州理工，专攻热力学和气象学
- **结论**: 他后来热衷用物理学方式解决问题，常说任何人要成功都应学习物理学
- **结果**: 未说明（书中记载其终身受益于物理学方法）

### 案例 3: 用硬科学方法学软科学：一场教育实验
- **类型**: 作者亲历（下篇·私人书单 第二辑 人类）
- **问题**: 一个掌握自己专业的人，能否把硬科学的治学精神与方法迁移到广阔的学术领域
- **方法论的使用**: 芒格很早就学过基本物理学和数学，花了很多精力掌握硬科学的基本治学精神与方法，再用这种方法去学习各种软科学，增加跨学科普世智慧
- **结论**: 他把自己的生活称为一场教育实验——一个掌握自己专业的人在非常广阔的学术领域试验这种方法
- **结果**: 未说明（作者称实验有效）

### 案例 4: 只用一两个模型：扭曲现实与「铁锤人」
- **类型**: 书中警告的失败模式（第一讲）
- **问题**: 只带一两种工具去看世界
- **方法论的使用**: （失败模式）把一切问题裁剪成自己熟悉的形状——扭曲现实而不自知，看似专业的判断系统性失真；缺模型的学科（如文学）则连基本框架都没有
- **结论**: 这正是格栅要防的第一种病；单一模型提供「确定性」与便捷解释，大脑还会主动筛选符合模型的证据
- **结果**: 未说明（警告性归纳，无单一事件）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 做完重要判断后发现翻来覆去只有一两个角度，心里没底
2. 想建立自己的思维工具箱/模型库，不知道包含什么、怎么组织
3. 遇到陌生领域的问题，不知道该从哪些学科取工具
4. 学了很多、读了很多，一到真实决策却调用不出来
5. 担心自己正在成为「手里只有锤子的人」

### 语言信号

- 「我是不是只用一个视角在看这件事？」
- 「除了我的老本行，这个问题还能从哪些学科看？」
- 「学的东西在真做决定的时候想不起来」
- 「这超出了我的专业，我是不是在硬套？」
- 英文: "everything looks like a nail", "what mental models apply here", "I only have one framework"

### 与相邻 skill 的区分

- 与 `inversion` 的区别: p145 并列的两种思维习惯——本 skill 管「无视学科界线、把各科模型收进工具箱」；`inversion` 管「反过来想、从失败入手」的提问方向
- 与 `misjudgment-checklist` 的区别: 心理学是格栅中的一个学科分支，那条清单是这条分支上最著名的成品；本 skill 负责建整个工具箱与「我现在用的是哪把锤子」的自检
- 与 `learning-machine` 的区别: 格栅靠持续学习建成；本 skill 管调用（遇到不同问题取不同模型），后者管建造与更新（每天进步＋操练）

## E — 可执行步骤 (Execution)

1. **写清问题，标出它涉及哪些层面**
   - 完成标准: 一句话写清要判断的事，并列出它涉及哪些层面（商业／心理／数学／工程／生物…）
   - 输入契约: 一个真实待决问题；不许跳过本步直接套用最顺手的模型

2. **逐学科取工具**
   - 完成标准: 至少从 3 个不同学科各取 1 条可能适用的模型，逐条写明「用它能看见什么」（书中示例：复利与排列组合、机会成本、激励、后备系统、断裂点、临界质量、质量控制）
   - 判停条件: 发现只有本专业的模型在起作用时停下，补别的学科再继续；完整模型清单原书未给（G3），以使用者自己的知识库与本 Bundle 其他卡片为准

3. **换模型复检**
   - 完成标准: 检查结论是否由单一模型主导；若所有问题都由同一模型解释，按铁锤人倾向处理——去找它不适用之处，并用第二个学科的模型重做一遍

4. **把用过的模型编进操练清单**
   - 完成标准: 记录本次用到的模型与场景；下次同类问题能不看记录直接调用（像钢琴家持续练习）
   - 输出契约: 给出①问题陈述 ②各学科模型与各自看见的要点 ③换模型复检记录 ④结论与仍存分歧之处

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用「你就是铁锤人」去指责他人的场合：铁锤人倾向是自我诊断工具——自检「我现在手里拿的是哪把锤子」，不是给别人贴的标签
- 需要单一学科深度资质的场合（医疗、法律、精算等专业处置）：格栅提供跨学科检查视角，不替代专业资质
- 想以「读得多、懂得广」自我标榜的场合：格栅不等于泛泛的知识面——判据是「遇到不同问题能否取不同模型并随手调用」，不是读书量
- 把「我懂了格栅」当成一次性成就的场合：模型重在操练不在收藏——「全部都用上」并变成随时可调用的本领（p42）才算数

### 作者在书中警告的失败模式

- 只使用一两个模型会扭曲现实，直到现实符合模型（ce58）：看似专业的判断系统性失真
- 铁锤人倾向连聪明人也不放过：斯金纳过度强调激励机制的超级威力、以为靠它就能创建人间乌托邦，声望因此江河日下（ce107）；布兰夏德、格雷厄姆的信徒同样中招
- 死记硬背应付考试（ce57/ce19）：知识无法形成相互联系的框架——「他们在学校中是失败者，在生活中也是失败者」
- 不把基本概率方法变成生活的一部分（ce59）：像「踢屁股比赛中的独腿人」，把巨大优势拱手送人

### 作者的盲点 / 时代局限

- 「80–90 个模型」只是数量级说法，且原书明言其中「非常重要的只有几个」——完整清单与课程表原书未给（G3），不得用百科知识补全成作者未提供的模型表
- 跨学科呼吁主要落在个人自修：作者承认「这个世界并不是按照跨学科的方法组织起来的」（p87），但未给组织层面的解法
- 举例带 1990s 语境（斯金纳、布兰夏德、格雷厄姆信徒、日本衰退等），示例的当代适用性需自行判断

### 容易混淆的邻近方法论

- `misjudgment-checklist`: 那条是清单本体（重要决定前逐条对照 25 倾向），本 skill 是工具箱的建立与「哪把锤子」自检——心理学是格栅的学科分支之一
- `inversion`: p145 并列的两种思维习惯——逆向负责提问方向，格栅负责工具来源，可互为前后步骤
- `learning-machine`: 格栅靠持续学习建成与更新；本 skill 只管在问题现场取用
