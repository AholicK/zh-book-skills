# 投资错误规避（负面清单）

## R — 原文 (Reading)

> 实际上，无论什么时候，只要有人拿着一份200页的计划书并收一大笔佣金要卖给你什么，别买下它。……如果采用这个“芒格的规矩”，你偶尔会犯错误。然而从长远来看，你将会远远领先于其他人——你将会避开许多可能会让你仇视你的同类的不愉快经验。……
>
> 第一，做空的利润上限只有100%，但损失空间几乎是无穷的，这正好是同做多相反的。……第二，做空要通过借债完成，所以即使做空的决定完全正确，但如果时机不对，操作者也会面临损失，甚至破产。……第三，最好的做空投资机会一般是各种各样的舞弊情况，但舞弊作假往往被掩盖得很好，需要很长时间才会败露。
>
> — 第一讲 · 选股的艺术（L3600-3606）
> — 序言 · 书中自有黄金屋（李录）（L85）

## I — 方法论骨架 (Interpretation)

投资错误规避的核心不是「找到好机会」，而是先把「愚蠢动作」列成负面清单、逐条避开。错误分两类：

1. **做错的事**：为高佣金与复杂结构买单（200 页计划书 + 大笔佣金）、为省税买不该买的东西、依赖外部预测、为管理波动而不断交易、做空与高杠杆机构——共性是卖方激励与买方结果脱节，或赔率结构天然不利。
2. **没做的事**：看懂了、却因小气或不必要地讨价还价而不买（或只买一点）真正的好机会——不产生账面成本、不触发警报，伯克希尔把它列为自己历史上最严重的错误。

三条判据：

- **先问谁在挣佣金**：激励结构指向卖方时，产品越复杂越要拒绝（「芒格的规矩」按形式特征一票筛查）。
- **算赔率结构**：做空三重缺陷（李录在序言总结）——收益上限 100%、损失无上限、依赖借债与时点；高杠杆机构一次判断失误就翻船。
- **过滤噪音**：不依赖外部预测做决策；「波动即风险」「市场总是对的」这类口径会把真实风险（买贵、看不懂、无优势）替换成可度量的替身。

使用顺序：本清单先行，正面决策随后（见 `concentrated-investing`）；避免愚蠢不等于什么都不做——坐失良机同样在清单上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 不钻油井与「芒格的规矩」
- **类型**: 作者亲历（第一讲）
- **问题**: 市面上以避税为卖点的服务与高佣金复杂推销层出不穷，要不要碰？
- **方法论的使用**: 芒格说他和沃伦个人从不钻油井（一种大规模避税的方法），依法纳税；并给出「芒格的规矩」——有人拿 200 页计划书、收一大笔佣金向你推销时，别买下它。
- **结论**: 这类交易的激励结构指向卖方；按形式特征一票否决，是低成本的启发式筛查。
- **结果**: 未说明（作者自述「做得非常好」；同时承认按此规矩「偶尔会犯错误」）。

### 案例 2: 长期资本管理公司：诺奖得主与高杠杆
- **类型**: 书中转述（下篇 第四辑 · 芒格演讲转述）
- **问题**: 一家创办人是声誉极佳的债券交易员和两位诺贝尔经济学奖得主、用复杂数学模型做债券套利的对冲基金。
- **方法论的使用**: 1998 年，在所罗门兄弟不再从事债券套利与外国金融恐慌的共同影响下，它连续两个月出现亏损；因负债水平极高（当年年度负债 1 250 亿美元）很快陷入困境。
- **结论**: 高杠杆把一次判断失误放大到破产级别——模型的精密不能替代对杠杆的警觉。
- **结果**: 基金损失惨重，美联储被迫提供紧急援助，以免流动性发生连锁反应。

### 案例 3: 李录：做空与短仓时期的教训
- **类型**: 书中转述（序言 · 李录自述）
- **问题**: 为留住并吸引投资者，李录有两三年不得不通过做长短仓对冲，去管理旗下基金的波动性。
- **方法论的使用**: 他总结做空难以用于长期投资的三点——利润上限 100% 而损失无穷、借债操作怕时机不对、舞弊作假往往被掩盖很久。
- **结论**: 做空自带借债与时间压力，赔率结构天然不利；为管理波动性而不断交易，会错过最好的长期机会。
- **结果**: 未说明（李录自述这段回报平淡）；他称职业生涯最大的失败不是错误决定造成的损失，而是没能大量买进最喜欢的几只最优秀股票。

### 案例 4: 坐失良机的错误（伯克希尔最严重的错误）
- **类型**: 书中警告的失败模式（第四章 · 错误）
- **问题**: 看懂了、却因为小气或不必要地讨价还价而不买（或只买一点）真正的好机会。
- **方法论的使用**: 伯克希尔把它列为自己历史上最严重的错误；包括因沃尔玛的股价上涨了一点点而没有买进、少赚 100 亿美元的例子。
- **结论**: 机会成本不进财务报表、不触发任何警报，绝大多数人不会注意到它；「买得不够多」把本可改变命运的机会缩成普通收益。
- **结果**: 书中称此类错误让伯克希尔损失了几十亿美元，且自己「还在不断地犯这样的错误」。

### 案例 5: 过度追求避税是企业大错之一
- **类型**: 书中警告的失败模式（第一讲 · 税收的效应）
- **问题**: 为省税而做决策：因为税负而买入不该买的东西、进入不该进入的结构，被兜售避税方案的中间人牵着走。
- **方法论的使用**: 芒格称过度追求减少纳税额是企业犯下大错的常见原因之一，他见过许多人因为太想避税而犯下可怕错误。
- **结论**: 税收是确定的小额节省，避税方案带来的是不确定的大额风险与费用；推销者有佣金激励，方案越复杂越难被审查。
- **结果**: 未说明（原书未给个案结局）。

### 案例 6: 伦勃朗化：因为涨所以买
- **类型**: 书中警告的失败模式（第四章 · 股票、伦勃朗和泡沫）
- **问题**: 把股票当伦勃朗的画作买——购买理由是价格一直都在上涨，再加上股票涨跌产生的巨大「财富效应」。
- **方法论的使用**: 上涨制造财富效应，财富效应制造更多买盘，买盘制造更多上涨；链条中缺少企业盈利这一支撑。
- **结论**: 芒格用「悲惨繁荣」描绘它——崩溃只是时间问题。
- **结果**: 未说明（书中称它产生的后果是悲惨的）。

### 案例 7: 高市盈率与过高预期
- **类型**: 书中警告的失败模式（第四章 · 未来的市场回报率）
- **问题**: 在极高估值上继续期待高回报：把特殊时期的收益率当作常态。
- **方法论的使用**: 芒格以当年日本股市市盈率高达 50～60 倍、导致长达十年经济衰退为例，说美国投资者应该调低预期。
- **结论**: 回报的合法来源是企业资本回报率与买入价格；以畸高价格买入等于提前透支未来收益，市场情绪反转时估值与盈利双双收缩。
- **结果**: 未说明（原书语境为预警，未给结局）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 有人拿着复杂计划书、收着高额佣金或服务费，来推销投资、理财、保险或避税产品
2. 正在考虑做空、使用杠杆，或投资大量举债、把「风险管理很好」挂在嘴边的金融机构
3. 想依据宏观预测、「专家点位」或行业轮动决定买卖
4. 复盘时想弄清「哪些动作不能碰」，理解为什么少犯错与更聪明同样重要
5. 看到某样东西价格一直涨，想用「它还会涨」作为买入理由

### 语言信号

- 「机会难得，别人都在买」「高佣金说明产品更专业」
- 「这个方案能省不少税」
- 「专家预测明年……」「据说这是下一个风口」
- 「它一直涨，不会跌的」「做空它，这明显是舞弊」
- 英文: "can't miss", "everyone is buying", "it only goes up"

### 与相邻 skill 的区分

- 与 `concentrated-investing` 的区别: 那条是正面的投资决策法（在哪里重注、如何坐等）；本卡是负面清单（哪些动作不能碰）——两者互为镜像、成套使用
- 与 `inversion` 的区别: 逆向法是产出负面清单的方法学（问「怎样会失败」）；本卡是它在投资域已产出的一张成品清单，用卡时不必重新演练方法学

## E — 可执行步骤 (Execution)

1. **激励与形式特征筛查（一票否决）**
   - 完成标准: 对每个机会写明「谁在挣佣金/费用、收多少、结构多复杂」；命中「200 页计划书 + 大笔佣金」或「以避税为主要卖点」的形式特征即停手
   - 判停条件: 卖方激励与买方结果脱节、说不清净结果 → 放弃，不进入下一步

2. **杠杆与做空结构检查**
   - 完成标准: 若方案含做空、借债或高杠杆机构：写明收益上限与损失空间、时点依赖、负债规模；核对「是否需要不断交易或盯盘才能控制风险」
   - 输出契约: 一页结构说明（收益上限 / 损失空间 / 时点风险 / 负债来源）

3. **预测与学院口径过滤**
   - 完成标准: 把决策依据中的宏观预测、「市场总是对的」「波动即风险」类口径单独标出；决策依据回到赔率与企业价值（原书口径），不依赖外部预测
   - 注意: 本步只做噪音标注，不产出对当下市场的判断

4. **机会成本侧对照（清单双向化）**
   - 完成标准: 同时在清单上登记「没做的错误」——看懂却因小气或讨价还价而放弃、或只买一点的机会
   - 判停条件: 若整份清单只有「别买」没有「该下多重注」→ 转 `concentrated-investing` 做正面决策

5. **成套使用与复盘**
   - 完成标准: 与集中投资决策链成套执行（负面清单先行、正面决策随后）；复盘时同时登记账面亏损与机会成本两类错误

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **不构成对具体操作的禁止或建议**：本卡是错误模式与风险警觉的清单，不是买卖指令、目标价或收益承诺；具体决策须结合使用者自己的处境与合规要求
- 不要把「芒格的规矩」当作绝对禁令：它是按形式特征的启发式筛查，**原书承认按它「偶尔会犯错误」**（错过某些好交易）——保留该限定
- 不要单独使用：本卡与 `concentrated-investing` 配成一套；单用时「避免愚蠢」容易被读成「什么都不做」——坐失良机（ce24）同样在本清单上
- 条目源自芒格 1990s 语境与赔率结构分析（含基金费率、机构风险、市场估值判断），按原样引用；原书未给估值公式与阈值，需使用者自定

### 作者在书中警告的失败模式

- 因为涨所以买（伦勃朗化）：购买理由是价格上涨本身与财富效应，最终以悲惨后果收场（ce30）
- 在极高估值上期待高回报：把特殊时期的收益率当常态（ce31，日本 50～60 倍市盈率的教训）
- 为省税而做决策：损失远大于省下的税，被兜售避税方案的中间人牵着走（ce79）
- 坐失良机：不产生账面成本、绝大多数人不会注意到，却造成以十亿计的机会损失（ce24）
- 做空与杠杆的结构性缺陷：收益上限 100%、损失无上限、借债怕时机错；高杠杆金融机构容易阴沟里翻船（ce01、ce25、ce35）
- 依赖预测、为波动而交易、把资金交给高费用中介：净收益被费率与噪音吞掉（ce28、ce52、ce53）

### 作者的盲点 / 时代局限

- 「别听预测」以及对经济学家、极端有效市场理论信徒（ce75 里「神经病」一词）的贬评，是**作者的立场性表述**，按原文保留、注明立场——不作事实定论
- 费率口径（开放式基金每年 2% + 转来转去多付 3%～4%）与 17% 抽水等为原书语境数字，随时代与产品变化，不得直接套用到当下产品
- 本卡覆盖的是原书收案范围内的错误模式，不是「一切亏钱方式」的完备清单——未列入者不等于安全

### 容易混淆的邻近方法论

- `concentrated-investing`：正面的投资决策法（能力圈内重注、坐等）；本卡是它的镜像负面清单。两卡互为条件：只用正面卡会漏掉「哪些动作不能碰」，只用本卡会漏掉「该下多重注」
- `inversion`：逆向思维方法学（研究怎样会失败、把失败案例排成清单）；本卡是它在投资域的一张成品清单——清单本身可直接对照使用
