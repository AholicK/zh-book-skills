# 专家与顾问审计

## R — 原文 (Reading)

> 我认为这个世界的知识可以分为两种：一种是普朗克知识，它属于那种真正懂的人。他们付出了努力，他们拥有那种能力。另外一种是司机知识。……
> 他们掌握了鹦鹉学舌的技巧；他们可能有漂亮的头发；他们的声音通常很动听；他们给人留下深刻的印象。但其实他们拥有的是伪装成真实知识的司机知识。……
>
> — 第二讲 如何获得精彩人生？（L3732-3734）
>
> （1）如果顾问提出的专业建议对他本身特别有利，你就应该特别害怕这些建议；（2）在和顾问打交道时，学习和使用你的顾问所在行业的基本知识；（3）复核、质疑或者更换你得到的建议，除非经过客观考虑之后这些建议看起来是合适的。
>
> — 第三讲 人类误判心理学 · 一、奖励和惩罚超级反应倾向（L3928）

## I — 方法论骨架 (Interpretation)

专家与顾问的产出有两个独立的风险面，审计要分别过一遍：

**一、知识的真伪。** 知识分两种：普朗克知识属于真正懂的人——他们付出了努力、拥有那种能力；司机知识是伪装成真实知识的表演——鹦鹉学舌、漂亮头发、动听声音、给人深刻印象（f59/g19）。识别动作不是看头衔与表达，而是**用难题当场验证**：普朗克的司机把演讲背得滚瓜烂熟，被物理学教授提问时也只能说「这么简单的问题，我想请我的司机来回答」。追问一个能落到事实与因果的问题，真懂与背稿立刻分开。

**二、利益的方向。** 激励机制引起的偏见非常普遍：平素正派的人在机制驱动下做出不道德行为，还会为它寻找借口（f65）。因此面对专业顾问的三条对策（p149/f65）：① 建议对顾问本人特别有利时，特别害怕这些建议；② 学习和使用顾问所在行业的基本知识——不学就无法复核；③ 复核、质疑或更换建议，除非经过客观考虑之后这些建议看起来是合适的。芒格的观察是：管理顾问的报告结尾几乎总写着「这个问题需要更多的管理顾问服务」；「我从来没有见过一个哪怕稍稍客观的经纪人」（c111/ce102）。

**自我侧的对偶：** 被问到不懂的问题时，不要表演——照搬韦尔奇的答案「我没有足够的能力来回答这个问题」，因为没有人期望你什么都懂（f28/p89）；选人时看轻面试印象、看重以往业绩（p165）。

本卡是自我防护工具，不是怀疑一切的工具；原书未给资质核验程序——给的是上面这组问题与判据。

## A1 — 书中的应用 (Past Application)

### 案例 1: 普朗克与司机
- **类型**: 书中转述（第二讲 · 如何获得精彩人生）
- **问题**: 如何区分真懂的人与鹦鹉学舌的表演者
- **方法论的使用**: 芒格讲普朗克的笑话：普朗克到处演讲量子物理，司机记住了内容，提议到慕尼黑由司机讲、普朗克戴司机帽坐前排；司机照做后被物理学教授提问，只好说「这么简单的问题，我想请我的司机来回答」（c101）
- **结论**: 普朗克知识属于真正懂、付出努力的人；司机知识是伪装成真实知识的表演——芒格说美国所有政客都拥有司机知识
- **结果**: 未说明（笑话用于说明两种知识）

### 案例 2: 管理顾问的报告结尾
- **类型**: 作者亲历（第三讲 · 一、奖励和惩罚超级反应倾向）
- **问题**: 咨询建议的可靠性
- **方法论的使用**: 作者的观察：一生中遇到的管理顾问，没有不在报告结尾写上同一个建议的——「这个问题需要更多的管理顾问服务」（c111）；同一时期他还说「我从来没有见过一个哪怕稍稍客观的经纪人」
- **结论**: 激励机制引起的偏见非常普遍，必须怀疑或有保留地接受专业顾问的建议；越是有利可图的方向，越难保持客观
- **结果**: 未说明（以观察支持三条对策）

### 案例 3: 照搬韦尔奇答案：「我没有足够的能力来回答这个问题」
- **类型**: 书中转述（下篇 · 第六辑 处世；芒格演讲，转引韦尔奇）
- **问题**: 有提问者问芒格「你认为苹果犯了哪些错误」
- **方法论的使用**: 芒格照搬通用电气 CEO 杰克·韦尔奇的答案：我没有足够的能力来回答这个问题（c61）
- **结论**: 当你不了解、也没有相关才能时，不要害怕说出来；反面是自信地回答其实并不了解的问题——「像乱跳舞的蜜蜂，会把整个蜂窝搞得乱哄哄」
- **结果**: 未说明

### 案例 4: 招聘委员会主席：取消面试，只看书面材料
- **类型**: 作者亲历（第三讲 · 十二、自视过高的倾向）
- **问题**: 学术招聘的决定依据
- **方法论的使用**: 说服其他委员取消面试，直接聘用书面申请材料比其他求职者优秀很多的人；被指责不尊重「学术界的正常程序」时回应：研究表明面试印象的预测价值很低，我正在应用这个成果（c130）
- **结论**: 看轻面试印象、看重以往业绩（p165）；「学术研究表明……预测价值很低」为书中转述、无出处
- **结果**: 未说明

### 案例 5: 惠普面试口齿伶俐的菲奥里纳
- **类型**: 书中转述（第三讲 · 十二、自视过高的倾向）
- **问题**: 现代企业招聘高层管理人员时，若求职者能说会道，就可能遭遇很大的危险
- **方法论的使用**: 芒格的判断：惠普面试口齿伶俐的卡莉·菲奥里纳（1999年至2005年期间担任惠普公司CEO）、想任命她为新总裁时，就面临着这样的危险（c131）
- **结论**: （1）惠普选择菲奥里纳女士是一个糟糕的决定；（2）如果惠普懂更多心理学并采取预防措施，就不会作出这个决定
- **结果**: 芒格判断这是糟糕的决定（书中未展开后续）

### 案例 6: 司机知识：鹦鹉学舌式的伪装知识
- **类型**: 书中警告的失败模式（第二讲 · 如何成为普朗克知识的人）
- **问题**: 以「司机知识」闯世界：能复述、能表演、能取悦听众，却没有真正的理解与能力
- **方法论的使用**: 表演型知识无需付出真实努力即可获得外部认可，在激励上占优；一旦被问到实质问题就露馅（ce92）
- **结论**: 它无法应对新问题，且让人误把「说得出来」当成「做得出来」
- **结果**: 被实质问题一问即露馅（普朗克司机的笑话即其原型）

### 案例 7: 经纪人与管理顾问的自利建议
- **类型**: 书中警告的失败模式（第三讲 · 一、奖励和惩罚超级反应倾向）
- **问题**: 照单接受经纪人、顾问、工程师等专业人士的建议
- **方法论的使用**: 对方看不见自己的偏见，且收入直接取决于建议内容——建议几乎必然偏向其自身利益（ce102）
- **结论**: 专业知识的权威外观让委托人放弃怀疑；三条对策（特别害怕／学习行业知识／复核质疑更换）就是为这种情形设的
- **结果**: 自利建议被照单接受（书中作为普遍机制描述）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 收到顾问、中介、理财师、医生的专业方案，准备照做之前
2. 一位专家讲得头头是道，想验证是真懂还是擅长表演
3. 招聘或选人只能依赖面试印象与口才，想换一套证据标准
4. 被问到你不懂的问题，想学会体面地承认
5. 别人的建议结尾总多出「需要更多此类服务」式的自我推荐

### 语言信号

- 「专家都这么说了，应该没问题吧」
- 「他讲得特别好，但我说不清哪里不对」
- 「为什么每个方案最后都多要一次他的服务」
- 「面试表现特别亮眼」
- 英文: "the consultant says", "he sounded really convincing", "trust me, I'm an expert"

### 与相邻 skill 的区分

- 与 `incentive-design` 的区别: 顾问审计第一步＝利益审计（f65）；`incentive-design` 审计的是制度在奖励什么行为，本卡审计的是「建议与建议者」——他得到什么、他是真懂吗
- 与 `circle-of-competence` 的区别: 共用证否标尺——能力圈问「我在不在圈内」（对自己），本卡问「对方在不在圈内、他为什么想让我信」（对他人）；「不懂就承认」是两卡共用的对外表达
- 与 `learning-machine` 的区别: 普朗克知识靠学习取得（付出努力、操练、模拟器）；本卡只做真伪识别——识别出真知之后要取得它，走那条卡

## E — 可执行步骤 (Execution)

1. **利益审计**
   - 完成标准: 列出建议者的收益来源（佣金、雇佣、续约、后续业务），判断「这个建议对他本身是否特别有利」；越有利越要害怕（f65 第一条）

2. **补课（取得复核资格）**
   - 完成标准: 学习并使用建议者所在行业的基本知识；能用自己的话复述建议的行业逻辑，并提出至少一个实质追问（f65 第二条）
   - 判停条件: 不具备该行业基本知识时，原书未给替代程序——唯一路径是先补课，否则复核没有意义

3. **用难题当场验证**
   - 完成标准: 提一个能落到事实与因果的问题（为什么这样做、边界条件是什么、反例如何解释）；能接住追问的是普朗克知识，只能重复稿子的是司机知识
   - 注意: 目的是验证与学习，不是审讯——不得用于无证据地质疑他人（见 B 段）

4. **复核、质疑或更换**
   - 完成标准: 对建议给出「接受／修改／更换」的结论，并写明「经过客观考虑之后看起来合适」的核对点；写不出核对点就不接受（f65 第三条）

5. **自我对偶：不懂就承认＋业绩证据**
   - 完成标准: 被问到自己不懂的问题时，以「我没有足够的能力来回答这个问题」收口，不表演；选人场合以以往业绩替代当面印象（f28/p165）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 「司机知识」判断是自我防护工具，不得用于无证据地质疑他人——不能因为对方表达流畅、头衔陌生就影射其为司机
- 不要用本卡拒绝专业帮助：三步法第二步明确要求学习和使用顾问所在行业的基本知识；审计不等于不请顾问
- 招聘「只看书面材料」（c130）是特定个案做法（学术招聘委员会、当时当地），不是普适规范——其他岗位的选人证据标准需自行设计

### 作者在书中警告的失败模式

- 司机知识：能复述、能表演、能取悦听众，被实质问题一问就露馅（ce92）
- 自利建议：经纪人、管理顾问（报告结尾都写「这个问题需要更多的管理顾问服务」）、工程师——建议几乎必然偏向其自身利益（ce102）
- 头衔≠真知：心理学博士当上总裁后发狂般挥霍资金、从折旧准备金账户提款，下属却因权威—错误影响倾向难以反对（ce163）

### 作者的盲点 / 时代局限

- 无资质核验程序（原书未给）——只给问题清单（利益披露／基本知识／复核质疑／复述检验：能复述不等于能回答追问）；没有可机械执行的资质审查流程
- 追问验证依赖审计者自己的知识水位；「审计者自己也是司机」的情形原书未讨论
- 「学术研究表明面试印象的预测价值很低」为书中转述、无出处
- 案例语境为 1990s（惠普任命菲奥里纳为 1999 年），引用按原样

### 容易混淆的邻近方法论

- `incentive-design`: 利益审计是它的第一步视角；本卡是「建议与专家」的上层流程，两者常连用
- `circle-of-competence`: 共用「能否承认不懂、能否证否自己」的标尺——一个对外（他懂吗），一个对内（我懂吗）
- `learning-machine`: 普朗克知识靠学习取得；识别出司机知识之后，成长动作走那条卡
