# 技术第二步分析

## R — 原文 (Reading)

> 微观经济学的伟大意义在于让人能够辨别什么时候技术将会帮助你，什么时候它将会摧毁你。大多数人并没有想通这个问题。但像巴菲特这样的家伙就想通了。……这个道理很浅显——有好些各色新发明虽然很棒，但只会让你们花冤枉钱，你们的企业就算采用了它们也改变不了江河日下的命运。因为钱不会落到你手里。改善生产带来的所有好处都流向消费者了。……然而，他们并没有进行第二步分析——也就是弄清楚有多少钱会落在你手里，多少钱会流向消费者。……
>
> 在现代文明社会，科学技术突飞猛进，所以出现了一种我称之为竞争性毁灭的现象。假设你拥有一家最好的马鞭厂，突然之间，社会上出现了不用马的汽车。……过不了几年，你的马鞭生意就完蛋了。你要么去做另外一种不同的生意，要么从此关门大吉——你被摧毁了。这种事情总是反复地发生。……当新的行业出现时，先行者会获得巨大的优势。如果你是先行者，你会遇到一种我称之为“冲浪”的模型——当冲浪者顺利冲上浪尖，并停留在那里，他能够冲很长很长一段时间。但如果他没冲上去，就会被海浪吞没。
>
> — 第一讲 · 微观经济学的思维模型（L3374-3392）
> — 第一讲 · 微观经济学的思维模型（L3394-3400）

## I — 方法论骨架 (Interpretation)

技术变革对企业的利弊，要用「两步」来判：

1. **第一步（人人都会）**：新技术提高效率、节省成本——推销机器的人和企业内部催促买设备的员工都这么说。
2. **第二步（关键、常被跳过）**：算清楚省下来的钱有多少落在你手里、多少流向消费者。判据看竞争结构——无特性商品（纺织业）：好处全部流向消费者，买新机器只是白花钱；有护城河（如唯一报纸）：节约的成本回到自己手里，新技术值得采用。原书给的算术样本：不断购买「三年内可以收回成本」的新玩意，这么做 20 年，年均回报率只有不到 4%。

配套两个模型：

- **竞争性毁灭**（作者术语，g15）：技术变革把整个品类消灭——不是同一品类里输给对手，而是品类本身被替换（最好的马鞭厂遇上汽车）。识别信号是需求整体消失，运营优化无法补偿；出路只有换生意或关门。
- **冲浪模型**：新行业出现时，先行者若站稳在浪潮前沿（最好的销售系统、最多的专利、狂热的持续改进——NCR、微软、英特尔），能冲很久；冲不上去就被海浪吞没。它判断的是「位置是否可持续」，不是「是否最早出现」。

顺序与收口：先判「技术帮你还是毁你」→ 再判「企业在浪尖还是浪底」→「是否参与」还要过能力圈（原书：伯克希尔自认很难理解软件、电脑芯片等科技行业，尽量避开）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 新纺织机：巴菲特希望它没这么厉害
- **类型**: 作者亲历（第一讲）
- **问题**: 伯克希尔早年做纺织品生意——非常糟糕的无特性商品行业；有人告诉巴菲特，新纺织机的效率是旧纺织机的两倍。
- **方法论的使用**: 巴菲特说：「天哪，我希望这种新机器没这么厉害——因为如果它确实这么厉害的话，我就要把工厂关掉了。」他知道更好的机器能极大地提高生产力，但最终受益的是购买纺织品的消费者。
- **结论**: 在无特性商品行业，钱不会落到采用新技术的厂家手里——先做第二步分析，才不会为「效率翻倍」欢呼。
- **结果**: 未说明（书中说明纺织业者得不到好处）。

### 案例 2: 马鞭厂与汽车：竞争性毁灭
- **类型**: 书中演练（第一讲）
- **问题**: 假设你拥有一家最好的马鞭厂，突然之间，社会上出现了不用马的汽车。
- **方法论的使用**: 过不了几年，马鞭生意就完蛋了——你要么去做另外一种不同的生意，要么从此关门大吉；这种事情总是反复地发生。
- **结论**: 竞争性毁灭不针对企业的效率，而针对需求本身：在被打掉的品类里做到最好也无济于事。
- **结果**: 未说明（书中为模式演示）。

### 案例 3: 帕特森：从一台收款机到国民收款机公司
- **类型**: 书中转述（第一讲）
- **问题**: 帕特森原是小零售商，没赚到什么钱；一台早期收款机放到收银台后，他的店立刻扭亏为盈——职员想偷钱就难多了。
- **方法论的使用**: 他没有想「这对我的零售店有帮助」，而是想「我要做收款机的生意」——创办了国民收款机公司（NCR），冲上了浪尖：最好的销售系统、最多的专利，一切也都是最好的。
- **结论**: 新行业出现时的先行者优势属于站稳浪潮前沿的人；聪明的做法是把新工具看成新生意，而不是只改善旧生意。
- **结果**: 未说明（书中称帕特森后来把大量财产捐作善款）。

### 案例 4: IBM：冲浪 60 年后被颠下浪尖
- **类型**: 书中转述（第一讲 · 选股的艺术）
- **问题**: 一家长期占据行业之巅的科技企业（管理人员非常出色、训练有素），会怎样被技术变化击落？
- **方法论的使用**: 世界上主流科技发生变化，加上它自身的市场地位下降，IBM 决定削减员工的规模；看它资产负债表上失去了什么就知道——现代制度下企业的大量资产属于职员，企业走下坡路时这些资产就消失了。
- **结论**: 科技行业的优势来自特定技术周期；60 年的成功不提供保护，这也是伯克希尔不很喜欢科技行业的原因之一。
- **结果**: IBM 成功「冲浪」60 年之后被颠下了浪尖——书中称在摧毁股东财富方面它算得上是模范。

### 案例 5: 冲浪失败：被海浪吞没
- **类型**: 书中警告的失败模式（第一讲）
- **问题**: 新行业出现时没能站到浪尖。
- **方法论的使用**: 冲浪者顺利冲上浪尖并停留在那里，能冲很久；没冲上去，就会被海浪吞没——先行者优势一旦被对手夺走，后来者只能在激烈竞争中被清洗出局。
- **结论**: 新行业的早期阶段有赢家通吃式的卡位效应（专利、销售系统、规模），位置一旦被占据就很难逆转。
- **结果**: 未说明（书中为模型警告）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估一项新技术/新设备投资：「三年内可以收回成本」的推销或内部催促来了
2. 所在行业出现替代性技术，想判断自己是受益者还是被毁灭者
3. 看到新兴行业爆发，纠结是否参与、以什么位置参与
4. 持有的企业处于技术周期变化中：优势依赖单一技术路线、市场地位开始下滑
5. 复盘「效率提升」类投资为何没带来收益

### 语言信号

- 「新技术能把成本降下来」「三年内收回投资」
- 「这是行业趋势，不跟上就被淘汰」「我们要不要冲一下这个新赛道」
- 「先行者优势」「站上风口」
- 英文: "game changer", "first mover", "we'll be left behind"

### 与相邻 skill 的区分

- 与 `scale-advantages` 的区别: 本卡只处理技术冲击（受益面/毁灭面/位置）；竞争结构（规模优势与劣势）由那条卡负责——做行业分析时两卡连用
- 与 `mental-models-lattice` 的区别: 本卡是微观经济学模型在「技术变革」这一处的落地用法（格栅中的一个样本），不是模型总纲

## E — 可执行步骤 (Execution)

1. **第一步噪音消毒**
   - 完成标准: 把「新技术节省成本」的承诺单独列出，标明来源（谁在推销、谁在催促、他们从中得到什么）；与「钱落到谁手里」的问题分开

2. **第二步分析（成本归宿）**
   - 完成标准: 先判行业竞争结构——是否有品牌、转换成本、护城河（与 `scale-advantages` 连用）；再给归属初判：「好处回到自己手里（帮）」或「好处流向消费者（毁）」
   - 判停条件: 无护城河 + 无特性商品 → 直接判「好处流向消费者」，不为「三年收回成本」的算术买单

3. **毁灭面检查（竞争性毁灭）**
   - 完成标准: 问「替代品会不会把整个品类抽走」——需求消失而非竞争加剧；若是，给转型或退出选项，不给「优化运营」类建议

4. **位置判断（冲浪）**
   - 完成标准: 若新行业出现——判断「是否站稳在浪潮前沿」（最好的销售系统、最多的专利、狂热的持续改进），而不是「是否最早出现」；冲不上去的结局是被吞没

5. **能力圈收口**
   - 完成标准: 输出结构与位置判断，但「是否参与」由能力圈决定（原书伯克希尔自认不懂高科技而主动避开）；本卡不产出投资建议
   - 输出契约: 一页：第一步承诺清单 / 第二步归属判断 / 毁灭面 / 位置判断 / 能力圈标注

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **原书语境为 1990s**——不得把本卡套用为对当下具体行业的判断；对当下的评估需要使用者自己补行业知识与数据
- 不构成投资建议：不做标的推荐、不给目标价或收益承诺
- 不把冲浪模型当作追热点的许可：它是**机会识别**（站稳浪潮前沿 + 前沿地位可持续），不是「早入场就行」；本卡也不提供入场时机建议
- 本卡不含第二步分析的定量程序：原书只给判据（钱落到谁手里），未给计算公式——原书未给，需使用者自定

### 作者在书中警告的失败模式

- 只做第一步分析（成本节约）而跳过第二步：纺织业不断买新设备，20 年年均回报率只有不到 4%（ce71）
- 在被技术替代的行业里做到最好也无济于事：需求被抽走，只有转型或关门两条路（ce72）
- 冲浪失败被吞没：未能站到浪尖的后来者被清洗出局（ce73）
- 长胜企业的护城河随技术周期失效：IBM 冲浪 60 年后被颠下浪尖，报表资产随裁员与业务萎缩一起消失（ce78）

### 作者的盲点 / 时代局限

- 案例与技术均为 1990s 语境（纺织、报纸、NCR、IBM、微软/英特尔），引用按原文、不作当代复刻承诺
- 第二步分析需要行业竞争结构的知识：原书只给判据不给流程；单用本卡容易把「技术=坏」误读成通则——对有护城河的企业（如唯一报纸），新技术是好事（f41）
- 「伯克希尔避开科技行业」是作者的能力圈自述，不是对科技行业的普遍判断，不得援引为「科技股不能碰」的权威依据

### 容易混淆的邻近方法论

- `scale-advantages`：竞争结构分析（规模优势/劣势）。本卡判技术受益面、毁灭面与位置；单边结论常来自两卡分离使用——行业分析双件套连用
- `mental-models-lattice`：本卡是微观经济学模型的一处落地；格栅讲多模型取用的总习惯，二者不是同一层级
