# 激励机制设计与审计

## R — 原文 (Reading)

> 我最先讨论这个倾向，是因为每个人都以为自己完全明白激励机制和惩罚机制在改变认知和行为方面有多么重要。但其实往往不是这样子的。……
> 也许最重要的管理原则就是：“制定正确的激励机制。”……
> 激励机制引起的偏见的另外一个常见后果是，人们倾向于钻各种制度的空子，他们往往在损人利己方面表现得极有创意。因此，几乎所有制度设计都必须具备防止钻空子的重要属性。制度设计还需要遵守如下的原则：尽量避免奖励容易作假的事情。
>
> — 第三讲 人类误判心理学 · 一、奖励和惩罚超级反应倾向（L3906-3958）

## I — 方法论骨架 (Interpretation)

激励机制是作者在误判心理学里第一个讨论的倾向，也是最容易被低估的一个：每个人都以为自己懂它——包括作者本人，他自认比 95% 的同龄人更理解激励的威力，却「总是低估那种威力」（p147，作者自述）。它最危险的后果叫**激励机制引起的偏见**：不是坏人做坏事，而是平素正派的人被机制推着做出不道德行为，还会为自己的糟糕行为寻找正当理由（g22）。

判读只有一条铁律：**看这套机制实际在奖励什么行为，而不是它宣称要什么**——决定行为的是决策者的激励机制（p111）。由此推出两组动作：① 对齐奖励口径，要成果就按成果付酬（联邦快递要的是快速、无差错完成，却按小时付薪在奖励「耗时间」）；② 防钻空子，因为人们钻空子时极有创意——制度几乎都必须具备防止钻空子的属性，并尽量避免奖励容易作假的事情（f66/p153）。

配套三件工具：机械化控制（收款机让不诚实难以得逞，是「伟大的道德工具」）；合理的会计口径（西屋电器的反例）；顺序与即时奖励——祖母的规矩：先吃完胡萝卜才准吃甜点，奖励要放在必要任务之后且要即时（书中转述斯金纳：即时的奖励最有效），奖励品甚至可以是你已经拥有的东西（f67）。

制度设计的收口形态是信任之网：一群可靠的人之间有正确的信任，而不是复杂的官僚程序（f62/c105）。但它以「可靠的人」为前提——人不可靠时，程序、控制与复核才是补救手段，两手不是互相取消。

审计他人时的第一步是利益审计：这个建议对提出者是否特别有利（完整三步法见 `expert-audit`）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 联邦快递：改按班次计薪，问题一夜解决
- **类型**: 书中转述（第一讲 · 选股的艺术）
- **问题**: 夜班工人总是不能按时完成分拣；劝说、威胁都用过，没有一种生效（ce98）
- **方法论的使用**: 不再按小时计薪，而是按班次计薪——职员只要工作做完就可以回家
- **结论**: 公司要的不是工作时间长，而是快速、无差错地完成；按小时付薪与目标相反——问题不在工人而在机制
- **结果**: 问题一夜之间就全都解决了；作者借这个案例说「制定正确的激励机制是非常、非常重要的教训」

### 案例 2: 施乐：提成表把销售员推向劣质旧机器
- **类型**: 书中转述（第三讲 · 一、奖励和惩罚超级反应倾向）
- **问题**: 施乐创始人乔·威尔逊不解：为什么新机器总是卖不过性能低下的旧机器
- **方法论的使用**: 回公司后发现，按公司与销售员签署的提成协议，把旧机器卖给客户，销售员能得到很高的提成
- **结论**: 在这种变态激励机制的推动下，劣等旧机器当然卖得更好——问题不在销售员的品德，而在提成表（同一事件在反例侧记为 ce99）
- **结果**: 找到症结（书中未展开后续修正细节）

### 案例 3: 收款机：把不诚实挡在流程之外
- **类型**: 书中转述（第三讲 · 一、奖励和惩罚超级反应倾向）
- **问题**: 帕特森开小店时员工常偷钱；而得到奖励的坏行为特别容易形成习惯
- **方法论的使用**: 装上收款机，让不诚实的行为难以得逞——用机械化控制代替对人道德的信赖
- **结论**: 作者称收款机是「伟大的道德工具」：让不当行为无从下手，比依赖人的道德更可靠
- **结果**: 商店开始盈利；帕特森后来创办国民收款机公司，生前把大量财产捐作善款

### 案例 4: 祖母的规矩：先吃完胡萝卜才准吃甜点
- **类型**: 书中演练（第一讲 · 导言）
- **问题**: 如何让不喜欢然而必要的任务先被执行（演讲次序、日常难任务）
- **方法论的使用**: 先说完胡萝卜（普世智慧的广泛课题）再说甜点（选股）；应用到商界就是管理人员每天先完成必要任务，再奖励自己处理喜欢的任务
- **结论**: 这是奖励机制在自我管理上的应用（顺序机制）——奖励必须放在必要任务之后，且即时奖励最有效
- **结果**: 未说明（作为方法论工具）

### 案例 5: 胆囊医生：真心相信自己在做好事
- **类型**: 作者亲历（第三讲 · 一、奖励和惩罚超级反应倾向）
- **问题**: 内布拉斯加州林肯市一名外科医生，年复一年把大量正常胆囊送到病理学实验室
- **方法论的使用**: 他并非图利——负责开除他的医生说，他真心认为胆囊是一切疾病的祸根，真爱护病人就该尽快切除；手术收入被信念包装（ce101）
- **结论**: 激励机制引起的偏见能把自身利益读成专业信念；每个专业人士和普通人身上都或多或少有这种倾向
- **结果**: 该医生多年后才被革除职务

### 案例 6: 苏联体制：「他们假装给薪水，我们假装在工作」
- **类型**: 书中警告的失败模式（第三讲 · 一、奖励和惩罚超级反应倾向）
- **问题**: 一个对激励机制完全无知的体制：薪酬与真实贡献脱钩
- **方法论的使用**: 作者把它作为反面教材，反衬「制定正确的激励机制」的管理原则
- **结论**: 劳资双方理性地进入互相表演的均衡，生产与报酬双双失真
- **结果**: 整个系统在无人真的做事中耗尽

### 案例 7: 为糟糕行为寻找借口
- **类型**: 书中警告的失败模式（第三讲 · 一、奖励和惩罚超级反应倾向）
- **问题**: 受过教育、平素正派的人在激励机制驱动下做出不道德行为
- **方法论的使用**: 作者指出：他们会有意或无意地用不道德行为换取想要的东西，还会为自己的糟糕行为寻找借口
- **结论**: 当事人不认为自己在作恶，因而无法自我纠正；教育与修养不能替代激励结构
- **结果**: 错误被「正当化」并持续（书中作为普遍机制描述）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要设计或修改考核、薪酬、提成方案，担心上线后行为走样
2. 团队出现怪行为（老产品比新产品好卖、工时很长产出很少、报喜不报忧），想找制度层面的原因
3. 收到销售、中介、顾问的建议，想先看清对方与建议之间的利益关系
4. 想给团队或自己定规矩之前，先检查「这套机制实际会奖励什么」
5. 自己拖延、明知该做的事不做，想用奖励机制管理自己的行为（祖母的规矩式安排）

### 语言信号

- 「制度定了，但总有人钻空子」
- 「我要求的是快速完成，他们却在耗时间」
- 「考核怎么设计，团队才会真往目标上使劲」
- 「他为什么总推荐那个更贵的方案」
- 英文: "how should I structure the incentives", "they game the system", "what's in it for them"

### 与相邻 skill 的区分

- 与 `persuasion-by-interest` 的区别: 那条是沟通方法（说服时把对方的利害讲清楚）；本卡是制度方法（设计或审计机制的奖惩结构）——同一个激励视角，一个对人说话，一个对制度开刀
- 与 `bad-news-discipline` 的区别: 那条管信息流条款（坏消息立刻上报、好消息可以等待）；本卡管奖惩条款（机制在奖励什么行为）——坏消息制度是组织制度设计的一部分
- 与 `expert-audit` 的区别: 那条审计建议与建议者（是否真懂、是否利益相关），其第一步＝利益审计；本卡审计机制本身在奖励什么
- 与 `misjudgment-checklist` 的区别: 倾向一是误判清单中的第一条；本卡是该倾向的机构化对策（把「别低估激励」落成可执行的设计步骤）
- 与 `character-and-career` 的区别: 信任之网要求个人可靠；那条讲个人的可靠从哪里来，本卡讲组织层面的机制取舍

## E — 可执行步骤 (Execution)

1. **描述现状机制（看行为，不看宣称）**
   - 完成标准: 写出「行为 → 获得什么」的对照表（谁在什么条件下被奖励/惩罚）；找不到奖励依据的行为标为待查
   - 输入契约: 一套现行制度（考核/薪酬/流程）＋观察到的实际行为

2. **检查奖励与目标是否一致**
   - 完成标准: 对每条奖励项写出「它实际鼓励的行为」与「业务真正需要的行为」；不一致处按联邦快递式口径替换（按成果而非工时）

3. **防钻空子压力测试**
   - 完成标准: 对每条奖励项连问三问——能不能被伪造？有没有人能用它损人利己？违规收益是否大于代价？（原则：几乎所有制度都必须防止钻空子；尽量避免奖励容易作假的事情）
   - 判停条件: 若某项奖励容易作假又无法用机械化控制兜住，先改奖励项，再谈执行

4. **加机械化控制与会计口径纪律**
   - 完成标准: 为高风险环节装「收款机式」控制（让不当行为难以得逞）；会计口径按保守原则复核（西屋反例）

5. **布置顺序与即时奖励**
   - 完成标准: 用祖母的规矩排任务——必要任务在前、喜欢的任务在后；奖励要即时（书中转述斯金纳实验：即时的奖励最有效），奖励品可以是你已经拥有的东西

6. **信任之网检查（制度形态）**
   - 完成标准: 核对机制能否用「可靠的人＋正确的信任」替代层层设防；若防备条款长到「47 页婚姻协议」的程度，先解决人，不是再加程序
   - 判停条件: 若「可靠的人」这一前提不成立，退回程序、控制与复核，不要硬套信任之网

7. **对制度涉及的建议做利益审计**
   - 完成标准: 对顾问、中介、销售的建议先问「这个建议对他本身是否特别有利」；越有利越要害怕（深入流程见 `expert-audit`）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 不提供具体行业指标模板：原书只给原则与案例，考核权重、提成比例等参数原书未给，需使用者自定
- 不要滑向犬儒主义：本卡用于审计他人时，结论应是「机制在奖励什么」，不是「所有人都在谋私」——书中的诊断恰恰是「正派的人被机制扭曲」
- 不要用机制设计替代底线约束：道德说教不能代替机制设计，机制也不替代底线约束——采购人员不从供应商收任何好处（哪怕一个热狗）是纪律，不是可谈判项（p160/c120）
- 制度化的信任之网以「一群可靠的人」为前提；人不可靠时先改人选与结构，不要用条款硬撑

### 作者在书中警告的失败模式

- 按小时计薪奖励「耗时间」而不是快速完工：动员与威胁都无效（ce98）
- 提成表把销售员推向劣质旧机器：公司被自己的薪酬制度反向牵引（ce99）
- 正派的人在激励驱动下做出不道德行为，并为其寻找借口（ce100）
- 成本保利合同奖励浪费与串通，催生贪污受贿（ce103）
- 苏联体制的互相表演：「他们假装给薪水，我们假装在工作」（ce106）
- 设计制度时假设人们照章办事，不设防、还奖励容易作假的事，必然被钻空子（ce108）

### 作者的盲点 / 时代局限

- 案例为 1990s 语境（联邦快递、施乐等），引用按原样，不作当代复刻承诺
- 「防钻空子」只给原则，没有量化压力测试程序；知识型岗位产出难以测量时如何设计激励，原书未给
- 信任之网给的是形态与判据（47 页条款），如何成批获得「可靠的人」原书未给程序
- 对股票期权的否定（如「给六十几岁的创始人 CEO 大量期权是精神错乱」p72）是作者的立场性主张，按原样保留

### 容易混淆的邻近方法论

- `persuasion-by-interest`: 同一激励视角用在沟通场景——那条教你怎么说，本卡教你改机制
- `misjudgment-checklist`: 倾向一是清单中的一条，本卡是它的机构化对策
- `bad-news-discipline`: 坏消息制度是组织制度设计的一部分；本卡管奖惩结构，那条管信息流
- `expert-audit`: 顾问审计的第一步＝利益审计（f65），与本卡共用激励视角
- `character-and-career`: 信任之网的编织材料是个人的可靠与正直，个人品格与组织制度互为条件
- 祖母的规矩是奖励机制的自我应用（顺序机制），不要读成时间管理上的「先难后易」心得（g23）
