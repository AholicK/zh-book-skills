# 会计红旗识别

## R — 原文 (Reading)

> 我认为，你每次看到“EBITDA”（即未计利息、税项、折旧及摊销前的利润）这个词，你都应该用“狗屁利润”来代替它。……
> 激进会计法吓坏了，所以尽量采用保守的会计法。……
> IBM刚刚将它对养老基金回报率的预期调高到10%。绝大多数公司（在2000年）的回报率是9%。我们认为6%更为现实一些。……
> 要测试任何（有显著衍生品风险的）大型机构的管理人员的智力和道德水准，最好的方法是问他们：“你真的能理解你的衍生品账目吗？”……如果有人说“是”，那这个人要么疯掉了，要么是在说谎。
>
> — 第四章 芒格主义 · 会计业的堕落遗患无穷（L1273-1325）／衍生品（L1221-1243）

## I — 方法论骨架 (Interpretation)

会计是商业活动的语言，但它只是粗略的估算——漂亮的数字不等于对实际情况的真正了解。本卡不教记账，也不做比率分析，练的是三组「先降级信任」的定性动作：

1. **口径替换**：看到 EBITDA，就在心里把它替换成「狗屁利润」。被剔除的利息、税项、折旧、摊销都是真实成本，成本不会因为不被计量而消失；凡公司只宣传非标准口径的，先按此降级信任。
2. **假设核查**：利润里最软的数字藏在对未来的假设里。养老基金回报率假设是典型——假设越高，当期费用越低、利润越好看（2000 年前后行业是 9%~10%，作者认为 6% 更现实）；用「以最近的事情推断未来」支撑的假设，要按利润的调节旋钮来审。
3. **取向选择**：宁可保守。伯克希尔的方针是被激进会计法吓坏后尽量采用保守会计法——保守口径既有助于生意决策，也是自我保护的一环。
4. **理解度测试**：对有显著衍生品风险的机构，问「你真的能理解你的衍生品账目吗？」；回答「是」的人要么疯了要么在说谎——账面利润由模型假设捏造，想动用那笔钱时它并不存在。

组织层面还有一条判据：宽松的会计标准本身就是行为的邀请函（携带钞票经过贫民窟的类比），坏行为会传染；而审计的独立性受付费关系支配——「谁给我面包吃，我就给谁唱歌」。报表数字在进入任何决策链之前，先用红旗视角过一遍。

## A1 — 书中的应用 (Past Application)

### 案例 1: 通用再保险的衍生品账本：卖不掉，只能大幅削价清算
- **类型**: 作者亲历（第四章 · 衍生品破灭的可能性）
- **问题**: 伯克希尔面对通用再保险持有的衍生品业务与账本
- **方法论的使用**: 先试图卖掉衍生品业务，未能成功，只好开始清算——用「能不能按账本价格变现」来检验账面价值
- **结论**: 清算不得不大幅削价；据此预测美国主要银行无法按账本价格清算其持有的衍生品，并说伯克希尔是美国唯一甩掉衍生品账本的大型公司
- **结果**: 伯克希尔完成清算；对银行业风险的预测书中未给后续

### 案例 2: 好市多期权：模型把 60 美元的期权算得更值钱
- **类型**: 作者亲历（第四章 · 期权估值和布莱克—舒尔斯模型）
- **问题**: 好市多发行执行价分别为 30 美元和 60 美元的股票期权
- **方法论的使用**: 用模型适用边界核验估值——该模型是一套「一无所知」的系统，只对约 90 天的短期期权有效
- **结论**: 模型认为 60 美元的期权价值更高——「这简直是疯了」；较长期的期权再使用这个模型是「有点神经」的做法
- **结果**: 未说明

### 案例 3: 西屋电器：把高风险贷款记成漂亮账
- **类型**: 书中转述（第三讲 · 倾向一：合理会计系统）
- **问题**: 西屋电器旗下信贷公司放出大量与主业无关的对外贷款（含占建设费用 95% 的贷款与酒店建筑贷款）
- **方法论的使用**: 按书中同案给出的口径，这类贷款本应在财务报表中记为零利润甚至记为损失，直到许多年后收回；西屋却按从前给子公司贷款的经验计提坏账
- **结论**: 账做得漂亮、放贷管理人员显得优秀，连外部会计师也认可了这种糟糕做法；最该受指责的是创造这种会计系统的会计与高层
- **结果**: 西屋电器损失数十亿美元

### 案例 4: 诺曼底美国公司：伪造的招股材料
- **类型**: 作者亲历（第四章 · 诺曼底美国的个案研究）
- **问题**: 所罗门与一家不良企业有交易，其招股材料全是伪造的（2002 年年会上查理点名是诺曼底美国公司）
- **方法论的使用**: 所罗门发现招股材料伪造；查理与沃伦（董事兼最大股东）说「别跟这个家伙做生意」
- **结论**: 承销委员会已批准该项目——但最终诺曼底在纳斯达克挂牌一天后取消发行、宣布所有交易无效
- **结果**: 发行被取消，当事人坐牢

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读财报、招股书或投资备忘录时反复看到 EBITDA、调整后利润之类非标准口径
2. 评估养老金假设、坏账计提、期权成本等「依赖假设」的数字，怀疑利润被假设抬高
3. 手里有含衍生品或复杂金融头寸的账目，不确定自己是否真的看得懂
4. 需要为自己（或合作方）的会计取向定调：偏保守还是偏激进

### 语言信号

- 「这个利润口径是怎么算的？」
- 「他们只给调整后的数字，不给标准口径」
- 「这些假设现实吗？」
- 英文: "adjusted EBITDA", "non-GAAP measures", "pension assumptions"

### 与相邻 skill 的区分

- 与 `concentrated-investing` 的区别: 那条处理「要不要重注、何时出手」的决策；本卡是出手前的财报核验——先让报表数字过一道红旗视角，再谈下注

## E — 可执行步骤 (Execution)

1. **口径替换练习**
   - 完成标准: 通读利润表与业绩说明，凡出现 EBITDA 或非标准口径，替换为「狗屁利润」并恢复全部被剔除的成本再看盈利能力；列出被剔除项目的规模
2. **关键假设核查**
   - 完成标准: 列出养老金回报率、坏账计提口径、期权是否计成本等关键假设，逐条与实际基准比对；原书未给基准的写「原书未给，需使用者自定」
   - 判读: 假设越高（如脱离现实的回报率），当期利润越被高估
3. **理解度测试**
   - 完成标准: 对每一类复杂头寸问「我真的能理解这份账目吗？」并试着回答「现在按账本价格清算能拿回多少」；答不出就归入「太难」，不再据此判断
4. **取向定性**
   - 完成标准: 给出「保守／激进」的定性判断与对应动作；发现宽松标准即视为对不当行为的邀请
   - 判停条件: 无法获得原始报表或关键假设披露时，写明「数据不足，红旗核查无法完成」，不得用二手转述代替

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要财务比率、勾稽验算或估值公式的场合——原书未给任何勾稽公式，本卡是定性红旗与口径替换，不做数字验算
- 想把「替换 EBITDA」当作记账或调账动作的场合——它是阅读姿态训练（对可疑口径先降级信任），不是会计规则
- 作为投资建议使用——本卡只审查报表表述与假设，不给出买卖判断、目标价或收益承诺
- 直接套用到当代准则的场合——相关警示为 1990s–2000s 语境（安然时代），此后准则已有变化，需另行判断

### 作者在书中警告的失败模式

- EBITDA 误用（ce42）：把利息、折旧等真实成本从视野里抹掉，把现金流不佳、重资产、高负债的公司看成赚钱机器
- 养老基金脱离现实的回报率假设（ce44）：当期利润被人为抬高，缺口被推迟到未来，提出问题的人反而遭到敌意对待
- 安达信（ce43）：合伙制事务所既缺少内控、选择客户又不谨慎，一个客户带来的灾难把整个事务所拖垮

### 作者的盲点 / 时代局限

- 相关演讲与案例集中在 1990s–2000s（安然、安达信时代），当时的一些准则漏洞（如期权是否计成本之争）此后多有修订——对当下做红旗判断需核对现行准则
- 「狗屁利润」为原文用词、带强烈情绪色彩；引用时按原样并注明语境，正式文书可改用中性表述
- 作者对衍生品与期权估值持极强立场（「任何反对这种看法的人都是神经病」一类措辞）——按作者观点的原样保留，不作普遍结论

### 容易混淆的邻近方法论

- `concentrated-investing`：那是一条投资决策链（定错价格、狠狠下注、按兵不动）；本卡只是决策链前端的报表核验步骤，本身不产生买卖决定
