# 逆向思维与证否（反过来想）

## R — 原文 (Reading)

> 比如说，查理思考问题总是从逆向开始。如果要明白人生如何得到幸福，查理首先是研究人生如何才能变得痛苦；要研究企业如何做强做大，查理首先研究企业是如何衰败的；大部分人更关心如何在股市投资上成功，查理最关心的是为什么在股市投资上大部分人都失败了。……
> 我只想知道将来我会死在什么地方，这样我就不去那儿了。……
> 查理在他漫长的一生中，持续不断地研究收集关于各种各样的人物、各行各业的企业，以及政府管理、学术研究等各领域中的人类失败之著名案例，并把那些失败的原因排列成正确决策的检查清单，使他在人生、事业的决策上几乎从不犯重大错误。……
>
> — 序言 书中自有黄金屋 · 二（李录叙述，L103-105）

> 如果你们想要帮助印度，应该考虑的问题不是“我要怎样才能帮助印度？”与之相反，你们应该问：“我要怎样才能损害印度？”……
>
> — 第二讲 如何获得精彩人生？ · 逆向思考（L3706-3708）

> 我觉得我没资格拥有一种观点，除非我能比我的对手更好地反驳我的立场。
>
> — 下篇·私人书单 第一辑 自然《物种起源》（L1571-1577）

## I — 方法论骨架 (Interpretation)

面对目标时不直接问「怎么达成」，先问「什么会让我失败」——把问题倒过来想：

1. **换问法**。想帮助印度，就问「怎样才能损害印度」，找出能造成最大损害的事然后避免去做；对复杂的适应系统与人类的大脑，逆向思考往往让问题更容易解决（第二讲 L3706）；数学类比：问题很难解决时，利用反向证明往往迎刃而解。
2. **攒素材**。收集各领域人类的著名失败案例——不是灵感，而是可积累的样本；作者的热衷点正是「先收集各种错误判断的例子，再考虑怎样避免这些下场」（第三讲 L3816）。
3. **列清单**。把失败原因排列成正确决策的检查清单，决策时逐项核对——收集→分析→排列→核对，这就是 f02 的完整链条；逆向提供方向，清单提供可执行的核对面。
4. **转正面**。负面清单要转成决策前的正面核对项才落地（清单即成品形态）。

配套的两条原则：

- **避免愚蠢优先于追求聪明**：作者说「我们赚钱，靠的是记住浅显的，而不是掌握深奥的」，「持续地试图别变成蠢货，久而久之，我们这种人便能获得非常大的优势」（第四章 L763）；生活和生意上的大多数成功来自你知道应该避免哪些事情（L791）。
- **证否精神（对知识的诚实）**：不能比最强反驳者更好地反驳自己，就不配拥有该观点（p79）；达尔文式证伪——越觉得自己的假说出色，越要去找可能推翻它的证据（第三讲 L4042）；并随时收集可证否的证据、修正判断（序言 L111，李录记述）。

代数学家雅各比的格言「反过来想，总是反过来想」（第三讲 L3816）是这一整套程序的口号。

## A1 — 书中的应用 (Past Application)

### 案例 1: 如何损害印度：逆向提问的示范
- **类型**: 书中演练（第二讲）
- **问题**: 想帮助印度，正面提问「我要怎样才能帮助印度」无从下手
- **方法论的使用**: 芒格示范把问题倒过来：先问「我要怎样才能损害印度」，找出能对印度造成最大损害的事情，然后避免去做
- **结论**: 从逻辑上看两种方法一样，但精通代数的人知道：问题很难解决时，利用反向证明往往就能迎刃而解
- **结果**: 未说明（方法论演示）

### 案例 2: 把人类失败案例排列成决策检查清单（伯克希尔的长期实践）
- **类型**: 书中转述（序言 · 李录叙述）
- **问题**: 如何在人生与事业决策上几乎不犯重大错误
- **方法论的使用**: 芒格一生持续收集各种人物、各行各业企业、政府管理、学术研究等领域的著名失败案例，并把失败原因排列成正确决策的检查清单；清单素材来自失败样本，而非成功故事
- **结论**: 李录评价：这点对巴菲特及伯克希尔 50 年业绩的重要性「再强调也不为过」
- **结果**: 未说明（李录叙述的评价，非单一事件结果）

### 案例 3: 只从自己的糟糕经验中吸取教训
- **类型**: 书中警告的失败模式（第四章）
- **问题**: 把学习来源限定在自身经历
- **方法论的使用**: （失败模式）只靠亲身失败来学习：学费昂贵、样本稀少、重大错误可能直接终结事业，学习速度远低于从他人案例中学习的人
- **结论**: 作者说「你吸取教训的来源越广泛，而不是仅仅从你自己的糟糕经验中吸取教训，你就能变得越好」——别人的失败案例是无成本的高质量样本
- **结果**: 未说明（警告性条目）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 计划/项目/产品上线前，想把「可能怎么失败」系统排一遍
2. 总在问「怎么才能成功」却理不清头绪，需要换切入点
3. 观点或方案要经过最挑剔的质询，想先自证否一遍
4. 复盘只总结正面经验，失败教训没人收集，团队反复踩同一类坑
5. 想建立自己「不做什么」的负面清单（投资、事业、生活）

### 语言信号

- 「帮我看看这件事会怎么搞砸」
- 「先别说怎么做成，先说怎么做不成」
- 「失败案例要怎么变成检查清单？」
- 「我是不是只从自己的教训里学东西？」
- 英文: "let's invert the problem", "how could this fail", "avoid stupidity", "what would make this fail"

### 与相邻 skill 的区分

- 与 `misjudgment-checklist` 的区别: 决策前自检的两条路径——查失败（本 skill：从失败案例反推清单）与查心理（那条：25 倾向逐条对照）
- 与 `mental-models-lattice` 的区别: p145 并列的两种思维习惯——本 skill 是雅各比式逆向（提问方向），后者是无视学科界线取模型（工具来源）
- 与 `anti-example-education` 的区别: 共同机制是从错误与失败中学习——本 skill 用在决策现场，后者落在教育现场（反面教材展示行为的连锁后果）
- 与 `investment-pitfalls` 的区别: 负面清单是逆向法在投资域的成品；本 skill 负责造清单的方法

## E — 可执行步骤 (Execution)

1. **写下正向目标**
   - 完成标准: 一句话写清「想要达成什么」，以及为什么现在要处理它

2. **换问法，列失败场景**
   - 完成标准: 把目标倒转成「什么会必然导致失败/痛苦」的问句，列出不少于 5 条具体失败场景
   - 判停条件: 列不出具体场景时，先去收集同类事情的失败案例（别人的、行业的）——不得凭空编造失败原因，样本优先于想象

3. **从失败场景提取避免清单**
   - 完成标准: 每条失败场景转成一条「不要做什么」，并标注它来自哪个案例

4. **转成正面检查清单**
   - 完成标准: 把避免清单逐条改写为决策时的核对项（在什么节点、核对什么信号），形成可逐项打勾的清单——这是落地成品（f02 链条的终点）
   - 输出契约: 给出①正向目标 ②失败场景表（含来源） ③避免清单 ④正面检查清单

5. **发布前过证否关**
   - 完成标准: 替反方写出最有力的反驳；如果自己不能比对手更好地反驳自己的立场，标记「不配拥有该观点」并暂缓；随手记录新出现的可证否证据，准备修正
   - 判停条件: 观点过不了证否关时回到第 2 步重做，而不是把话说得更大声

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把「反过来想」当辩论技巧、用来赢过别人时——证否铁律（p79）是自检标准，不是攻击工具
- 只停在负面清单、不落地的用法：逆向法产出负面清单后要转成正面检查清单（f02 的完整链条），否则清单无法在决策时逐项核对
- 只想证明自己正确、不打算修改方案时：证否精神含「对知识的诚实」——随时准备修正自己的判断（序言 L111，李录记述）
- 需要在紧迫窗口内即时处置的场合：逆向法会扩大核查面，先处置、事后按本卡复盘（两者之间的优先级原书未给，需使用者自定）

### 作者在书中警告的失败模式

- 只从自己的糟糕经验中吸取教训（ce84）：学费昂贵、样本稀少，重大错误可能直接终结事业
- 懒惰和言而无信会让我们在生活中失败——「如果你们言而无信，就算有再多的优点，也无法避免悲惨的下场」（第二讲 L3708）
- 「让人生痛苦」的忠告反用：尽可能只从自身经验获得知识、别从古人或今人成败中吸取教训——反用才是原则（下篇 L1457）
- 决策前不听反方：法院要求法官和陪审团先聆听辩方的长篇大论，以防判决时犯「第一结论偏见」；反方缺席的评审程序与此相反（第三讲 L4034）

### 作者的盲点 / 时代局限

- 序言出处为李录叙述（NR-02）：本卡 R 段第一块（研究痛苦/衰败、死在哪、失败清单）出自李录回忆，引用时应保留「李录回忆」归属；核心机制另有第二讲 L3706-3708、第三讲 L3816 两处芒格原文佐证
- 失败样本的搜集与更新方式（收集什么、多少、多久更新）原书未给，不同领域如何本地化亦未给程序——需使用者自定
- 「逆向思考对复杂系统更容易解决问题」是作者的经验性论断（书中转述、无出处），不是实验结论

### 容易混淆的邻近方法论

- `misjudgment-checklist`: 同为决策前自检，但素材不同——失败案例 vs 心理倾向；误判清单本身正是由失败案例反推而来，两卡是同一源头的两条支流
- `mental-models-lattice`: p145 两种思维习惯并列——本卡管「反过来想」的提问方向，后者管「无视学科界线」的模型来源
- `anti-example-education` / `investment-pitfalls`: 前者是失败学习在教育现场的应用，后者是负面清单在投资域的成品；本卡是其共同的方法学源头
