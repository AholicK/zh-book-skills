# 人生商业模式：能力 × 效率 × 杠杆（先查内核，后上杠杆）

## R — 原文 (Reading)

> 人生，就是一种商业模式。我们可以将其总结为一个公式：人生商业模式=能力×效率×杠杆。……记住，所有的杠杆，不论是团队、产品、资本，还是影响力，它们的作用都是复制放大。……杠杆能帮你获得巨大的成功，但是使用杠杆也是有前提的：你必须先拥有强大的能力内核。……复制放大，不是必然导致成功。如果你的能力内核很强大，使用杠杆会使你更快地获得成功。但是，如果你的能力内核很虚弱，使用杠杆只会加速你的失败。
>
> — 第3章 个体进化的底层逻辑 · 人生商业模式=能力×效率×杠杆（L2049-2278）

## I — 方法论骨架 (Interpretation)

把「成长」当成一门生意来盘：**成果 = 能力 × 效率 × 杠杆**。乘法结构意味着任何一项趋近于零，整体就趋近于零——三要素不是并列加分，而是互为瓶颈。

三项各自的检查口径：

1. **能力**——不是现有技能清单，而是元能力「获得能力的能力」（原文：一个人最重要的能力，是获得能力的能力）。获得路径是三级递进：勤奋 → 可怕的勤奋 → 高效而可怕的勤奋；最后一跳的关键装置是**反馈机制**，即用「哪些有效、哪些无效」的反馈不断训练稍微困难的任务（刻意练习），而不是把同一动作重复更久。
2. **效率**——三件事：选择（先判断一件事值不值得做，17 分钟省出 17 个小时）、方法（更高效的做法）、工具（把思维从「结构化 / 有边界 / 不能错」中解放出来的白板类工具）。
3. **杠杆**——四种放大方式：团队、产品、资本、影响力。它们本身不产生方向，只做复制放大。

最关键的前置判据是**内核检查**：杠杆的支点是可复制的能力内核（书中样本是麦肯锡的「知识库+方法论」）。先有内核、再上杠杆；内核虚弱时放大倍数越大失败越快——所以本卡的动作顺序固定为：三要素审计 → 内核检查 → 杠杆匹配。

## A1 — 书中的应用 (Past Application)

### 案例 1: 微软的「可怕的勤奋」——抢床位与睡袋
- **类型**: 作者亲历（第3章）
- **问题**: 「获得能力的能力」要用什么强度换？作者以自己在微软的工程师岁月作答
- **方法论的使用**: 办公室每层有两个房间各放两张小床，同事早上第一件事是把员工卡扔在床上占位；没抢到床的人去茶水间拿睡袋睡地上，作者常睡在会议室地上，第二天被搞清洁的阿姨踢到就知道天亮了；同期还有每天免费晚餐、晚 9 点后下班可报销打车费的制度安排
- **结论**: 作者把这类状态归入「可怕的勤奋」，并说明自己十几年几乎天天 996
- **结果**: 书中未说明结果；作者据此说明勤奋是他找到的答案，并在同节另立前提条款（见 B 段）

### 案例 2: 麦肯锡——把「知识库+方法论」做成团队杠杆
- **类型**: 书中转述（第3章·杠杆）
- **问题**: 咨询业少有公司能做大，麦肯锡为什么能不断复制自己
- **方法论的使用**: 先把能力内核固定下来——所有服务过的客户案例进知识库，并沉淀 MECE 法则、七步分析法等方法论；再用团队杠杆：每年从顶尖大学招大批商学院毕业生，用这套方法论与知识库给比自己年长 20～50 岁的企业家做战略咨询
- **结论**: 「知识库+方法论」这个可复制的支点，是团队杠杆能转起来的前提
- **结果**: 书中交代的结果是麦肯锡在全球不断复制自己，年收入规模约 100 亿美元（书中转述）

### 案例 3: 反例——内核虚弱时，杠杆只会加速失败
- **类型**: 书中反例（第3章·杠杆，ce201）
- **问题**: 什么情况下加杠杆是危险动作
- **方法论的使用**: 作者列出的警示信号包括：先招人 / 先融资、再想「核心竞争力是什么」；用团队或资本掩盖内功不足；复制放大之后问题按比例放大
- **结论**: 杠杆是放大器而不是加速器，它不改变方向；成果 ≈ 内核 × 杠杆，内核趋零时乘数越大越快放大失败
- **结果**: 书中未给具体企业案例（该条为规则性反例）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 收入或成长遇到天花板，想弄清到底卡在能力、效率还是杠杆哪一项
2. 手上有一个可复制的东西（方法、课程、产品原型），在犹豫要不要招人、融资、铺规模
3. 已经在带团队或做产品，增长却全靠堆人力，想判断有没有放大结构
4. 想上杠杆但心里没底：不知道自己有没有「可复制的能力内核」
5. 听到「赛道」「复利」「放大器」一类说法，想把它落到自己身上做一次体检

### 语言信号

- 「我这么努力，为什么还是原地踏步」
- 「这件事到底值不值得我投时间」
- 「我要不要招人 / 融资 / 做加盟把它做大」
- 「我们什么都能做一点，但好像没有一样拿得出手」
- 英文: "how do I scale this beyond my own hours", "should I raise money before the core is proven", "what's my real moat"

### 与相邻 skill 的区分

- 与 `transaction-structure` 的区别: 两个「商业模式」含义不同——`transaction-structure` 看利益相关者的交易结构（与谁交易、怎么分利），本卡看个人/小主体的能力×效率×杠杆
- 与 `time-management` 的区别: `time-management` 处理「时间怎么切分」，本卡处理「这件事值不值得做 + 怎么放大」；效率三项里的「选择」动作两卡共享，颗粒度与三层计划归 `time-management`
- 与 `distribution-choice` 的区别: 本卡回答「要不要上杠杆、上哪种」，`distribution-choice` 回答「这条路所在的分布值不值得进」——先判边际交付时间是否为零，再定杠杆形态
- 与 `knowledge-skill-attitude` 的区别: 那条解决「能力怎么练」，本卡只判「能力项是否成立、要不要升级元能力」；练法细节转 `knowledge-skill-attitude`

## E — 可执行步骤 (Execution)

1. **三要素审计**
   - 完成标准: 分别写下当前的能力项、效率项、杠杆项，每项至少落一个具体事实或动作（不接受「我很努力」这类形容词）
   - 判停条件: 三项都写不出时，先盘点一周时间去向再回来

2. **内核检查（硬闸门）**
   - 完成标准: 用一句话写出你的能力内核——它必须是可复制、可交付、别人拿得走的东西（对照样本：麦肯锡的「知识库+方法论」）；再回答：如果明天团队 / 资金 / 流量全部归零，它还在吗
   - 判停条件: 答不上来、或答案是「不在」，停止加杠杆，回到能力项（练法转 `knowledge-skill-attitude`）；答「在」才进入第 3 步

3. **杠杆匹配**
   - 完成标准: 在团队 / 产品 / 资本 / 影响力四种杠杆中选定 1～2 种，写出选它的理由与放弃另外几种的理由
   - 输出契约: 给出①三要素现状 ②能力内核一句话 ③选定杠杆及理由 ④接下来 30 天的第一件事

4. **边界回读**
   - 完成标准: 重读原文免责条款——所有勤奋必须在身体和家庭的承受范围之内；若方案里出现具体倍数或收益数字，一律标注为示意或由使用者自定，不当作承诺

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单次、短周期的任务决策（没有放大结构可谈，直接做即可）
- 还没有任何可复制物的时候讨论「杠杆」——此时正确的动作是练能力，不是配杠杆
- 把公式当励志口号使用：本卡是审计工具，不产出情绪价值

### 作者在书中警告的失败模式

- 内核虚弱时上杠杆：使用杠杆的前提是先拥有强大的能力内核（g08）；四种杠杆都是放大器，放大不改变方向，只会加速失败（ce201）
- 把「复制放大」误当「必然成功」：原文明说「复制放大，不是必然导致成功」
- 用勤奋替代反馈：没有反馈机制的重复训练只是消耗，不是刻意练习（p89）
- **过劳风险（重要限制）**：作者以自身 711 / 睡会议室的亲历为「可怕的勤奋」背书，全书未讨论过劳、健康与家庭代价；引用本卡时必须同时保留原文免责——「确保所有的勤奋，都在你的身体和家庭的承受范围之内」（p88）

### 作者的盲点 / 时代局限

- **幸存者样本**：本书批判幸存者偏见，但它的案例（麦肯锡、贝恩、马斯克、三位跨领域全才）同样是幸存者样本；失败侧只有规则性反例（ce201），没有对等密度的失败案例
- **商业顾问视角**：案例几乎全部来自企业与创业者；对不掌握资源的人，「获得能力的能力」「把自己当 CEO」更接近一种期望而非可执行路径，书中未讨论资源匮乏下的优先级
- **「用 2 年获得别人 5 年的能力」近似线性兑换**：隐含假设是加班时长可以直接兑换能力增速，未讨论平台期、健康损耗与家庭成本
- **时代锚点**：成书 2021，案例集中 2016–2020 移动互联网红利（996、免费晚餐、报销打车费等制度语境已变），引用时须标注时间

### 容易混淆的邻近方法论

- `transaction-structure`: 同一个「商业模式」词的另一种用法（交易结构 vs 个人三要素），混用会让审计对象错位
- `three-levels-of-wisdom`: 那条处理「选什么、靠什么定力」，与本卡共享长期主义内核；出现「选择与坚持」的问题应先分流
- 书外的「复利 / 放大器」成功学话术: 它把放大器说成好消息；本卡的处理是先把放大器接在内核检查之后
