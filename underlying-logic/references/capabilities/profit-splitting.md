# 分钱模型：优先/劣后与四阶段分钱法

## R — 原文 (Reading)

> 一切的分钱方式，无外乎优先和劣后；一切的分配方式，都是固定、剩余、分成的万千组合。……
>
> 在第一个阶段（辛苦赚钱阶段）：人力优先，资本劣后；在第二个阶段（资本收益阶段）：资本优先，人力劣后；在第三个阶段（均衡阶段）：人力、资本均衡分配；在第四个阶段（超出预期阶段）：资本优先，人力劣后。……
>
> 一切的商业模式，都必须有全局性增量。如果没有全局性增量，那所谓的商业模式，就是把你口袋里的钱换到我的口袋里。
>
> — 第5章 社会协作的底层逻辑 · 一切的分钱方式，无外乎优先和劣后（L4579-4605）
> — 第5章 社会协作的底层逻辑 · 如何在一个不确定的项目中“优先劣后”（L4607-4669）
> — 第5章 社会协作的底层逻辑 · 企业之间要通过分成，创造全局性增量（L4723-4725）

## I — 方法论骨架 (Interpretation)

任何「钱怎么分」的问题，先拆成坐标系，再谈比例。

**两轴**：优先利=固定，旱涝保收（员工完成目标就该得利益，与公司盈亏无关）；劣后利=剩余，拿走优先后剩下的部分，可能爆赚也可能巨亏。**三式**：固定、剩余、分成——一切分配方式都是这三式的组合（p230）。基本配置是员工拿优先利、老板拿劣后利；要激励员工时改用劣后利（分成），优秀员工通过不断分成逐渐成为合伙人（p231/p232）。

**四阶段（出资方与出力方的合作）**：按利润区间配置——①辛苦赚钱阶段（0～5 万示例档）人力优先、资本劣后，她拿 100%、你拿 0（先覆盖出力方的全部时间与机会成本）；②资本收益阶段（5 万～25 万）资本优先、人力劣后，80%/20%；③均衡阶段（25 万～100 万）60%/40%；④超出预期阶段（100 万以上）资本优先、人力劣后，80%/20%（远超预期的回报与努力关系不大，主要靠资本）（p233-p237）。第五种情况是亏钱——无钱可分，不用讨论。

**竞争优劣势与交易成本**：双方都有竞争优势→用分成；一方优势大→大的一方拿剩余、小的一方拿固定（直播带货者拿剩余、打包发货者拿固定）；交易成本高时（异地协作、不能天天盯着），优势大的一方拿低固定+高分成，小的一方拿高固定+低分成（p238/p239）。

**最后一道检验**：一切商业模式都必须有全局性增量；没有增量的分成只是搬钱（p240）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 萌力星球的 IP 授权——用分成创造全局性增量
- **类型**: 书中转述（第5章·企业之间要通过分成，创造全局性增量）
- **问题**: 手握 IP（萌二、乖巧宝宝、发射小人）的萌力星球，与合作伙伴怎么合作更赚钱
- **方法论的使用**: 两种授权方式对比——品牌商授权收固定授权费（萌力星球拿固定、伙伴拿剩余）vs 衍生品授权收低固定+提成；后者更赚钱，因为分成让双方都有动力：伙伴拿大头、卖得越多赚得越多，萌力星球投入更多精力优化设计。增量来源被作者指认为转化率——IP 表情带来的熟悉感增加信任，转化率若提高 30%，商家乐意拿出 7% 或 10% 分成
- **结论**: 把「一方拿固定、一方拿剩余」改为增加分成，创造性地增加了全局性增量
- **结果**: 书中结论为品牌商赚得多了、萌力星球也赚得多了，达成双赢

### 案例 2: 虚构合作案例——不确定项目四阶段如何分钱
- **类型**: 书中演练（第5章·如何在一个不确定项目中「优先劣后」）
- **问题**: 你出资本、她来运营的合作项目，收益不确定，钱怎么分
- **方法论的使用**: 按利润区间走四阶段——①辛苦赚钱阶段（赚不到 5 万元）：人力优先、资本劣后，她拿 100%、你拿 0；②资本收益阶段（5 万～25 万元）：资本优先、人力劣后，你 80%、她 20%；③均衡阶段（25 万～100 万元）：你 60%、她 40%；④超出预期阶段（超过 100 万元）：你 80%、她 20%
- **结论**: 四阶段依次为人力优先、资本优先、均衡分配、资本优先
- **结果**: 演练结论如上；档位数字为书中的示意性设定，双方须协商上限与触发条件

### 案例 3: 直播卖货者与打包发货伙伴——谁拿固定、谁拿剩余
- **类型**: 书中演练（第5章·合作中，竞争有优劣势时如何分钱）
- **问题**: 你做直播带货、有了粉丝和销量，找伙伴负责打包发货，两个人谁拿固定、谁拿剩余
- **方法论的使用**: 基本配置是你拿剩余、他拿固定（打包发货没有核心竞争力，可谈好每月固定给多少钱）；岗位越有核心竞争力越应拿劣后；若交易成本高（你在杭州直播、他在广州发货，不能天天盯着），就要用分成给他加一点劣后——优势大的一方拿低固定+高分成，优势小的一方拿高固定+低分成
- **结论**: 优势大的一方拿剩余、小的一方拿固定；交易成本高时改为「低固定+高分成」与「高固定+低分成」
- **结果**: 演练结论如上（虚构情境的对照题）

### 案例 4: 失败侧——没有全局性增量的商业模式只是搬钱
- **类型**: 书中反例（第5章）
- **问题**: 合作模式没有创造新价值，只是重新分配既有的钱
- **方法论的使用**: 作者把它定义为「把你口袋里的钱换到我的口袋里」——不产生增量，不长久；对照萌力星球：靠分成把转化率提高 30%，提高的部分才拿来分
- **结论**: 没有全局性增量，所谓的商业模式不成立
- **结果**: 反例结论如上；预警信号为收益只能从对方利润里抠、说不清新增价值从哪来

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 两人合伙（一人出钱、一人出力），怎么定分配
2. 想给核心员工分成或股权，不知道给多少、什么时候给
3. 企业间合作、授权、分销：该收固定费用还是收提成
4. 合作中途发现「钱怎么分」没谈清，想补一份规则
5. 有人提了一个「看起来很赚」的合作模式，想知道它成不成立

### 语言信号

- 「我们俩一人出钱一人出力，钱怎么分」
- 「该给他多少股份、多少分成」
- 「授权是收固定费用还是收提成」
- 「这个合作模式靠谱吗」
- 英文: "how should we split the profit", "fixed fee or revenue share", "equity split with my co-founder"

### 与相邻 skill 的区分

- 与 `partnership-pay` 的区别: 那条是四种分配形式（工资/奖金/股权/价值观）的个人版入口；本卡是分钱规则集——优先/劣后与四阶段配置
- 与 `community-tiers` 的区别: 先判关系层级（利益/事业/命运），再定分钱方案；共同体判定决定谁优先谁劣后
- 与 `wealth-and-scarcity` 的区别: 稀缺决定分配权（那条），分配权落到操作就是优先/劣后的配置（本卡）——判定在前，配置在后
- 与 `fairness-justice-openness` 的区别: 本卡管「怎么配」，那条管「公不公」——分钱方案能不能被接受，取决于是否用同一把尺子

## E — 可执行步骤 (Execution)

1. **先定结构**
   - 完成标准: 把分钱对象拆成两轴三式——谁优先（固定）、谁劣后（剩余）、是否引入分成；员工—老板场景默认员工优先（固定）、老板劣后（剩余）
   - 判停条件: 若双方都想拿固定，先回到第 2 步重新评估竞争优劣势

2. **判合作形态**
   - 完成标准: 判断双方的竞争优势大小与交易成本高低——双方都强→用分成（可用四阶段）；一大一小→大者拿剩余、小者拿固定；一大一小且交易成本高→大者低固定+高分成、小者高固定+低分成

3. **四阶段配置（含触发条件）**
   - 完成标准: 出资/出力型项目按四阶段给出比例与每阶段的触发阈值——①辛苦赚钱阶段：人力优先、资本劣后（她拿 100%、你拿 0）；②资本收益阶段：资本优先、人力劣后（80%/20%）；③均衡阶段（60%/40%）；④超出预期阶段：资本优先、人力劣后（80%/20%）；**每段必须写明触发条件（利润区间、流水阈值由双方协商确定，书中 5 万/25 万/100 万为示意档位）**
   - 判停条件: 写不出触发条件就暂不签署——方案未完成

4. **复核全局性增量**
   - 完成标准: 回答「这份合作创造了什么新增价值」；答不出来即判定为零和搬钱（ce407），回到商业模式本身重新设计
   - 输出契约: 给出①优先/劣后结构 ②分阶段比例与触发条件 ③全局性增量说明

5. **边界回读**
   - 完成标准: 复读三条限制——表 5-2～5-5 缺失（NR-01），四阶段数字以正文为准（100%/0→80%/20%→60%/40%→80%/20%）；无全局性增量的分成只是搬钱；本卡不替代法律/税务意见

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **表 5-2～5-5 缺失（NR-01）**：源文分钱配置表在 OCR 底本中缺失、仅存正文比例——四阶段数字以正文为准（100%/0→80%/20%→60%/40%→80%/20%），不得自行补表或推演缺失单元格
- 需要法律或税务意见的场合：股权、分成条款的合规与税务处理须由专业人士完成，本卡只给结构
- 单方定价场景（你说了算、对方议价权极低）：本卡假设双方可协商、可达成共识
- 还没确认有全局性增量时：先回答「新增价值从哪来」，再谈比例

### 作者在书中警告的失败模式

- 没有全局性增量的商业模式只是搬钱（ce407）：把你口袋里的钱换到我的口袋里——不产生增量、不长久
- 配置与关系错位：员工该拿优先利（固定）、老板该拿劣后利（剩余）；想激励员工时却只给固定、不给劣后分成，优秀员工就无法成长为合伙人（p231/p232）
- 阶段方案缺触发条件：四阶段是按利润区间配置的，区间本身就是触发条件；不写清楚，方案会在赚到钱的那天开始吵（本卡规则，源自 f407/p233 的区间口径）
- 照搬别人的固定比例：优先/劣后配置取决于双方竞争优势与交易成本，书中强调这是「最基本的配置」、随条件变化（f408/p239）

### 作者的盲点 / 时代局限

- **表 5-2～5-5 缺失与示意档位**：分钱配置表在源文 OCR 中缺失（NR-01）；5 万/25 万/100 万是讨论用的示意档位，不是普适阈值——引用时必须一并说明
- **分成比例没有推导过程**：80/20、60/40 等比例以结论形态给出，书中未展示推导或验证（批判节：黑板上的经济学式断言）
- **立场盲点（商业顾问视角）**：四种配置的谈判前提是双方地位大致对等；对议价权悬殊的场合（个人 vs 大公司），作者未讨论如何争取「劣后」——那部分更像期望而非可操作路径（批判节）
- **时代锚点**：案例（直播带货、IP 表情包授权）集中在 2016–2020 移动互联网红利期，收益结构与当年平台生态绑定

### 容易混淆的邻近方法论

- `partnership-pay`: 都谈分配形式；那条从个人视角讲工资/奖金/股权/价值观的优先级，本卡讲结构设计与阶段规则
- `fairness-justice-openness`: 都决定方案能否被接受；那条管「公不公」（同一把尺子），本卡管「怎么配」
- `trust-as-asset`: 都约束合作；信用决定合作能否开始，分钱机制决定能否持续
