# 战略势能：找不属于自己的能量，求之于势不责于人

## I — 方法论骨架 (Interpretation)

竞争先算能量账：**你赢靠什么能量、对手靠什么能量、场上有没有可以借用的、不属于自己的能量。**

- **能量谱系**（书中演练）：拳头（化学能瞬间变动能）→ 刀剑（线上的切割）→ 弓箭（增加时间维度：势能转动能、点伤害）→ 投石车（配重势能，可把 100 公斤石弹抛约 250 米）→ 子弹（火药能量）。掌握能量的水平决定战争形态——「战争的本质，是对能量的控制」。
- **水攻 = 借势原型**：围城墙建坝三年（工程难），一旦放水即冲垮全城——水攻城池的本质是借助一个自身并不具备的势能来作战；「易守难攻」同理：山头积攒了势能，从下仰攻者在消耗能量。
- **企业映射**：销售团队=把化学能转化为动能、在平地推石头的冷兵器军队（高级销售=力气大的巨人）；优秀商业模式=站在山顶推石头（对手在仰攻）；科技/专利=工具势能（研发投入=筑坝）。判据：**借助外在势能，而不是借助员工每天吃下去的化学能，企业才有更大的机会获得成功。**

方法论口号：**求之于势，不责于人**——上半句：寻找战略势能，追求技术的领先、商业模式的优越以及效率的优势；下半句：把正确的人放在正确的位置上进行赋能（在匹配责权利制度的前提下，调动每个人全部的能量）。业绩不好先找势能问题，不要先责怪团队；「不责于人」不是不让团队出力，而是先给一个好的位置。

前提公式（作者原话）：**「你陪客户喝的酒，是做产品时没有流的汗」**——靠销售硬拼补不回来的，是产品与势能的欠账。

## A1 — 书中的应用 (Past Application)

### 案例 1: 熊逸讲「水攻」——建坝三年，引水破城
- **类型**: 书中转述（第5章，转述自得到课程《熊逸讲透〈资治通鉴〉》）
- **问题**: 过去打仗多用火攻（《孙子兵法》有《火攻篇》无《水攻篇》），水通常被用作防守（护城河）；要用水攻城，该怎么办？
- **方法论的使用**: 转述的答案是建坝——围绕城墙，向后建水坝；这位将军用了整整三年，才把大坝一直建到上游水源；之后只要把水一放，上游的水哗哗地冲过去，整个城市就被冲开了
- **结论**: 水攻的本质是借助一个自身并不具备的势能来作战；胜负不取决于己方士兵每天吃的饭（化学能），而取决于能否把时间与投入累积成一个更大的、本不属于自己的势能
- **结果**: 书中结论：城市被冲开；作者由此引申「易守难攻」也是同一道理

### 案例 2: 从拳头到子弹——战争工具的能量谱
- **类型**: 书中演练（第5章）
- **问题**: 战争形态由什么决定？
- **方法论的使用**: 作者排列能量演算谱：拳头是化学能瞬间变动能；刀剑是线上的切割；弓箭增加了时间的维度——弓弦拉得越紧，弹回来的势能越大，势能传递给箭后转化为动能，以尖锐箭头作唯一接触点造成「点」伤害；投石车用绞盘把化学能转为配重势能，可把 100 公斤石弹抛射约 250 米；子弹靠枪膛内爆炸能量
- **结论**: 战争工具史=掌握能量水平的跃迁史；「自从掌握了火药和枪支，人类掌握能量的水平就大幅度提高」
- **结果**: 未说明（能量谱推演），推演即结论；弹射距离等数字为书中口径、无出处

### 案例 3: 华为的研发投入——2019 年 1317 亿元、占收入 15.3%
- **类型**: 书中转述（第5章）
- **问题**: 「科技也是势能」在企业里长什么样？
- **方法论的使用**: 作者转述（并回扣自己写过的文章《华为：这不是技术战争，这是财富分配权的战争》）：华为特别重视研发，每年研发投入都超过全年销售收入的 10%；以 2019 年为例，华为研发费用达到 1317 亿元，占全年销售收入的 15.3%
- **结论**: 重研发=筑坝蓄势；作者用电攻/水攻类比解释——华为建了 10 年 5G 的「水路」，才最终借助水的势能，冲掉了许多「城池」
- **结果**: 书中未给经营结果数字；数字为书中转述、无出处（2019 年口径）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 业绩下滑，团队被要求「更拼」，你在想除了加人加激励还有没有别的杠杆
2. 同质化竞争里只能靠降价和加班，想找不与对手硬拼的打法
3. 在纠结要不要投研发、投品牌、投供应链——投入大、见效慢
4. 面对更强大的对手，判断「这场仗还要不要打、怎么打」
5. 作为管理者，被追着要增长数字，需要区分「团队问题」还是「势能问题」

### 语言信号

- 「只能靠兄弟们拼了」
- 「业绩不行就是团队执行不行」
- 「要不要投研发/建渠道？」
- 「对手太强，我们怎么打」
- 英文: "how do we compete with a bigger player", "should we invest in R&D", "unfair advantage"

### 与相邻 skill 的区分

- 与 `product-value-layers` 的区别: 那条换一层价值（功能→体验→个性化）避开价格战；本 skill 换一个能量层（借商业模式的势、科技的势）——两者都是「不与对手在同一层硬拼」，产品层换价值、战略层换势能
- 与 `profit-types` 的区别: 那条解释利润类型（社会工资 vs 创新利润）与「谁掌握稀缺资源谁有分配权」；本 skill 解释势能从哪里借——没有势能就只剩社会工资，势能是创新利润的来源，两条常连用

## E — 可执行步骤 (Execution)

1. **盘点势能选项**
   - 完成标准: 列出至少 3 类「本不属于自己的能量」候选，并注明来源——技术/研发（专利、工艺）、商业模式（结构设计带来的位置优势）、渠道/供应链/生态、效率优势；每项写一句「它替我们省了什么、加了什么」
   - 输入契约: 一条具体业务线，含竞争位置与资源现状

2. **筛可积累性**
   - 完成标准: 对每个候选核对「可积累性」——投入能不能逐年沉淀成墙（研发成果、专利、品牌、数据），还是当年投入当年花掉（加人、加激励、陪客应酬）；只把可积累项列为势能候选
   - 判停条件: 候选全部不可积累时，直接说明「当前打法只能是化学能竞争」，并给出最省力的执行方案，不要包装成势能故事

3. **选一项，定先后**
   - 完成标准: 从可积累候选中选出一项作为主攻方向，写出：①要筑的「坝」是什么（具体交付物）②需要多久（如实给量级）③什么样的水位才算借到势（验收口径，原书未给，需使用者自定）
   - 输出契约: ①势能选项清单 ②可积累性判断 ③主攻方向与验收口径

4. **再谈执行强度（求之于势，不责于人）**
   - 完成标准: 在势能方向确定后，才讨论人的安排——把正确的人放在正确的位置上赋能（职责权利匹配），而不是先喊「更拼」；输出一句对团队的诚实结论：哪些问题是势能欠账、哪些才是执行问题

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **不要用它否定团队与管理**：「求之于势，不责于人」的下半句是把正确的人放在正确的位置上赋能，不是「团队不重要、可以不管人」（brief 必写①）；截取「不责于人」当挡箭牌是误用
- 没有可积累性前提的行业/阶段：如果投入无法沉淀（项目制接单、纯人力外包），本框架给不出杠杆，硬讲势能是自我安慰（brief 必写②）
- 短期现金流告急时：先处理生存问题；「筑坝三年」不适合等米下锅的场景

### 作者在书中警告的失败模式

- 只靠员工化学能、不借助势能：把增长押在销售团队上——靠高级销售「巨人」多推一点、陪酒拼单，而不去建商业模式与科技的势能，本质上是在仰攻（ce308）；警告信号：增长只靠加人、加激励、陪客应酬；研发/模式投入被当成「锦上添花」；竞争被描述为「兄弟们更拼」
- 平地推石头：销售团队再强，也只是把化学能转化为动能，与站在山顶推石头的一方不是同一能量等级——「你陪客户喝的酒，是做产品时没有流的汗」

### 作者的盲点 / 时代局限

- **证据强度有限（brief 必写③）**：本单元 12 条候选、证据中等，结论强度低于高证据单元；华为等案例是转述、无独立出处，不宜作为唯一决策依据
- **军事隐喻的直接映射**：战争是零和的，企业竞争多数不是；书中未区分二者，把「能量对抗」框带来，可能诱导对同行的攻击性叙事（BOOK_OVERVIEW 自反性提示：本书自身也是成功者经验总结）
- **「建坝三年」的可执行性**：借助外在势能依赖资本、时间窗口与容错空间；对没有研发预算与喘息空间的小微企业，这条路径往往不可选（BOOK_OVERVIEW 立场盲点：商业顾问视角）
- **势能不可度量**：书中的能量是比喻，未给「势能」的度量与验收口径（原书未给，需使用者自定）；不同业务之间无法比较「谁势能更大」
- 数据带时代锚点：华为 2019 年数字（1317 亿元、15.3%）为书中转述、无出处，后续经营环境已变（BOOK_OVERVIEW 时代局限）

### 容易混淆的邻近方法论

- 「借势营销」/蹭热点：那是短期声量与流量，不沉淀可积累的势能；本 skill 指的是投入能积成墙的研发、模式与效率优势
- 单纯加大投入（烧钱换规模）：投入本身不是势能，只有转化为可积累的位置优势（技术、结构、效率）才算；否则只是把化学能花得更快
- 「不责于人」被读成「绩效豁免」：书中下半句仍是赋能与责权利匹配，不是取消要求
