# 表述四分法：事实、观点、立场与信仰

## R — 原文 (Reading)

> 我们常说，一个人的表述大概可以分为两种：事实和观点。事实有真假，观点无对错。……但是细究起来，还可以再细分，至少可以分为四种：事实（Fact）、观点（Opinion）、立场（Stand）和信仰（Belief）（见图2-1）。……这就是立场——“我们不争对错，只争输赢”。所以，不要和有立场的人争对错。这也是我们常说的“小孩子才谈对错，成年人只谈利益”。为什么？因为小孩子没有位置和利益。
>
> — 第2章 · 事实、观点、立场和信仰（L569-621）

## I — 方法论骨架 (Interpretation)

面对一段表述，先分类、再回应。四类的定义与判据（g23）：

- **事实**：独立于人的判断的客观存在（「今天 30 摄氏度」）——看真假；
- **观点**：对同一个事实的不同看法（「今天很热」）——无对错，因人而异；
- **立场**：被位置和利益影响的观点（物业员工冒汗也说不热）——不争对错，只争输赢；
- **信仰**：一套完全自洽的逻辑体系（信科学也是信仰）——信仰之间互相矛盾，无法互相证伪，只能选择。

判定链：能否独立于人的判断 →（否）是否只是对某个事实的看法 →（否）是否被位置与利益左右 →（否）是否属于自洽体系。

按类别选应对：

- **事实** → 核验来源；承认「对事实的了解还不够全面」；
- **观点** → 容纳与讨论；不必分输赢；
- **立场** → 不辩对错——可以说「It's good for you」（这对你有益）；除非位置利益相同，否则不可能达成共识；
- **信仰** → 不攻击——你不可能获胜，还会失去这个朋友。

自检方向：这套判定链同时对准自己——「我说的话、我的表述，是事实，是观点，是立场，还是信仰？」

谦逊提醒：现实世界有时复杂到无法判断事实（圆柱体从上往下看是圆形、从侧面看是长方形或正方形；「横看成岭侧成峰」；鱼在鱼缸里看到球面的世界）——所以对事实的判断也要留有余地。

## A1 — 书中的应用 (Past Application)

### 案例 1: 「今天很热」与「今天 30 摄氏度」
- **类型**: 书中演练（第2章）
- **问题**: 「今天很热」是不是事实？
- **方法论的使用**: 不是——「今天 30 摄氏度」才是事实，「热」是你的观点；作者又以圆柱体的观察角度、「横看成岭侧成峰」、鱼在鱼缸里看到的球面世界说明：现实世界有时复杂到无法判断事实
- **结论**: 事实是最不容易产生争议的客观存在；我们只能说对事实的了解还不够全面
- **结果**: 未说明（判定示例）

### 案例 2: 物业公司职员一边冒汗一边说「我不热」
- **类型**: 书中演练（第2章）
- **问题**: 有人问你热不热，你觉得挺热的；但如果在物业公司工作，一旦承认热，别人就会要求你给大厦开空调
- **方法论的使用**: 于是你一边冒着汗，一边说「我不热，我就是不热」——这就是立场：被位置和利益影响的观点
- **结论**: 除非能和对方有相同的位置和利益，否则你们不可能达成共识——不要和有立场的人争对错，「我们不争对错，只争输赢」
- **结果**: 未说明（示例）

### 案例 3: 辩论场上说「交换立场」之后
- **类型**: 书中演练（第2章）
- **问题**: 辩论赛进行到一半，主持人突然说「交换立场」
- **方法论的使用**: 双方都会愣一下，但几秒钟后，持有反方观点的辩手还是能面红耳赤地去说服对方，甚至说得好像自己转而相信这个持方观点了——立场即「持方」
- **结论**: 立场由位置而非信念决定；辩论的底层逻辑是「不争对错，只争输赢」
- **结果**: 未说明（示例）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 家庭群、评论区为一条消息吵得不可开交，想弄清该不该参与、怎么参与
2. 对方明明在事实层面说不通，却始终不松口，你不确定还要不要继续说服
3. 有人劝你信一套你无法验证的体系（价值观/世界观），你想体面地不伤和气
4. 自己准备发言，想先检查这句话会引起多大争议、属于哪一类
5. 复盘一场没吵出结果的争论，想知道问题出在哪一步

### 语言信号

- 「你怎么就不明白呢？」
- 「道理我都说了，他就是不听」
- 「这事关乎原则/三观」
- 「你站哪边？」
- 英文: "how can you not see this?", "I'm just stating a fact", "don't be so irrational"

### 与相邻 skill 的区分

- 与 `mind-injection` 的区别: 本卡识别「这句话是什么」（四分类）；`mind-injection` 识别「这个问题藏了什么」（「为什么+观点」句式）——同一防御链的两环
- 与 `debate-craft` 的区别: 本卡是辩论前的分类准备（先弄清对方说的到底是事实、观点、立场还是信仰）；`debate-craft` 是辩论的原理与技术本身
- 与 `logic-literacy` 的区别: 本卡管「别人的表述属于哪一类、如何应对」；`logic-literacy` 的四句话用于自检自己的发言与论证——构成「识别—自检」双件套

## E — 可执行步骤 (Execution)

1. **取表述**
   - 完成标准: 拿到待处理的原句（自己将说的/对方说的），逐字写下；不只转述大意
   - 判停条件: 若只有情绪没有原句，先请对方或自己还原原话；无法还原时按最接近的版本处理并标注

2. **四分类判定**
   - 完成标准: 按判定链归类——看真假（事实）→ 看是否只是对事实的看法（观点）→ 看是否被位置利益影响（立场）→ 看是否属自洽体系（信仰）；一句话多属性时全部标出（如观点 + 立场）
   - 输出契约: ①原句 ②类别及判定依据

3. **按类别选应对**
   - 完成标准: 事实→核验来源；观点→容纳；立场→不辩对错（可说 It's good for you），不指望共识；信仰→不攻击
   - 判停条件: 若对方同时含立场与信仰属性，按更高约束处理（不辩 + 不攻）

4. **自检**
   - 完成标准: 把同一判定链对准自己要发表的表述，写出它属于哪一类；若是「立场/信仰」冒充「事实/观点」，先改写再发出
   - 输出契约: ①自己的表述 ②类别 ③改写（如需）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 分类的用途是选应对方式，不是给对话对方贴标签羞辱（「你就是立场」「你就是信仰」）——标签贴到人身上就变了性质
- 正式辩论/谈判场合的立场对抗是规则使然：本卡不评判「有立场」这件事本身，识别不等于贬低
- 「信仰是自洽的逻辑体系」≠「信仰错误」：尊重与识别并重——识别是为了选择应对方式，不是判定对方错
- 无法判断事实的复杂情形不要强行分类：先补事实再分类，或如实标注「暂不可判」

### 作者在书中警告的失败模式

- 和有立场的人争对错：跟「屁股决定脑袋」的人讲对错，除非位置利益相同，否则不可能达成共识，白耗成本（ce11）；警告信号：对方说「我们这行就是这样」、同一个人换个位置立刻换说法、讨论总回到「你站哪边」
- 攻击别人的信仰：第一，你不可能获胜；第二，你会失去这个朋友（ce12）

### 作者的盲点 / 时代局限

- 四分类的边界有重叠情形：同一句话可以同时是「观点 + 立场」（例如转发一条消息，转发者既表达看法、又可能受带货利益影响），原书未给复合情形的裁定规则
- 案例（物业职员、辩论场）为作者构造的示意场景，非真实事件；现实中的立场往往比示例更隐蔽，识别难度更高
- 两条禁令给出的都是「不要做」，没讨论冲突场景下「识别到了、但必须应对」的正面策略（如谈判中对方确实有立场且必须谈成）
- 「It's good for you」为英文句子，直译进中文对话的语气与接受度书未讨论（原书未给，需使用者自定措辞）
- OCR 底本限制：图 2-1（表述四分法图）图内内容缺失，仅存图题，本卡以正文文字口径重建（NR-01）

### 容易混淆的邻近方法论

- 与 `mind-injection` 的先后: 先分类（本卡），再看句式有没有藏观点（注射式洗脑）——分类错了，会把「为什么 + 立场」当成普通疑问接下去
- 与 `debate-craft` 的场合差: 辩论场上恰恰要用「重新定义概念」等对抗技术；本卡的不辩/不攻是日常沟通礼仪，两者场合不同、不可互串
- 与逻辑素养类工具的配合: 本卡先分类、再回应；`logic-literacy` 的四句话用于检验论证本身——识别与自检分工
