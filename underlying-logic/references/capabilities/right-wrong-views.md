# 对错判断：三种对错观 × 人性、道德和法律

## R — 原文 (Reading)

> 如果你是评论家，可以选择法学家的立场；如果你是政策制定者，可以选择经济学家的立场；如果将要失足摔死的就是你自己，我建议你选择商人的立场——“我的错，都是我的错”，因为“我的损失最大”。……总之，谁的损失大，就是谁的错。……一件事情出现不好的结果时，责怪、埋怨、后悔都是无用的，它们改变不了结果。……如果自己有所损失，只能怪自己，也只有自己才能改变事情最终的结果——靠自己，自强者万强。
>
> — 第1章 · 一个人心中，应该有三种“对错观”（L133-199）

## I — 方法论骨架 (Interpretation)

损失或冲突发生后，第一问不是「谁对谁错」，而是「**我是谁**」——位置决定判据：

- **评论家**（旁观者）→ 法学家的对错观：看证据与法规，谁违法谁错；
- **政策制定者**（定规则的人）→ 经济学家的对错观：看社会总成本，怎样判能让此类事件整体减少（如惩罚没锁门的工地，倒逼所有工地都上锁）；
- **当事人**（损失落在自己头上）→ 商人的对错观：谁的损失大，就是谁的错——先自救。

三种观**同时并存、按身份选用**，不是从三种里挑出唯一正确的一种，更不是道德相对主义——法学家观以证据与法规为据、经济学家观以社会总成本为据，各有硬标准。

当事人视角的推论链：损失已发生 → 责怪、埋怨、后悔都改变不了结果 → 能改变最终结果的只有自己（自强者万强）。这就是把「谁的损失大」翻译成行动的口诀，书中以「课题分离」作心理学解释（转述自阿德勒）。

配套结构（第 1 章「人性、道德和法律」节）：批评先定层——人性层（自私基因、生存繁衍，无善无恶；母亲杀婴称「没有人性」）、道德层（为群体繁荣达成、常反人性的社会契约；插队称「不道德」）、法律层（道德的子集与底线；口角杀人称「触犯法律」）。用词不可跨层混用，否则归因混乱；维护手段也不同：引导靠宣传、舆论（长效但见效慢），约束靠惩罚、驱逐（剧烈但立竿见影）。法律的位置被概括为「法律更像人性的低保，是一种强制性的修养」（转引自刘晗课程对电影《烈日灼心》台词的引用）。

使用纪律：商人观只用于当事人决定自己的行动，不用来评判他人。

## A1 — 书中的应用 (Past Application)

### 案例 1: 首富被绑架后说「这次是我错了」
- **类型**: 书中转述（第1章）
- **问题**: 悍匪周密计划绑架首富之子，首富以数亿元赎回（书中转述）；绑匪问首富为何如此冷静
- **方法论的使用**: 首富答「因为这次是我错了。我们在当地知名度这么高，但是一点儿防备都没有……我要仔细检讨一下」——法律上绑匪错，但从首富角度，这类事本可通过安保避免；作者评：他真觉得自己错了，不是客气
- **结论**: 损失已发生且无法挽回时，从「自己还能改变的部分」看问题——书中以心理学概念「课题分离」解释：绑架索赎金是绑匪的课题，遭受损失是首富的课题（转述自阿德勒）
- **结果**: 首富最终以数亿元赎回儿子，破财消灾；书中未说明后续

### 案例 2: 地铁里被踩一脚，是谁的错
- **类型**: 书中演练（第1章）
- **问题**: 作者设定的日常情境（无具体人名、时间）：在地铁里被人踩了一脚，谁的错？
- **方法论的使用**: 判定为「我的错」——要求道歉、与耍无赖的对方吵架都要花时间，而我的时间比对方值钱，浪费同样的时间，我的损失大
- **结论**: 商人的对错观落到日常：止损比争理便宜
- **结果**: 书中给出的处理动作是：说「我的错，我的错」，然后心平气和地走到旁边

### 案例 3: 坏人 A、好人 B 与没锁门的工地 C
- **类型**: 书中演练（第1章）
- **问题**: A 诱骗 B 进入 C 没有锁门的工地，B 失足摔死——这是谁的错？
- **方法论的使用**: 三种对错观分别给出判定——法学家：A 错（蓄意谋杀）；经济学家：C 错（锁门成本远低于全社会的防范成本，惩罚 C 能让所有工地锁门）；商人：B 错（不管谁担责，B 已经死了，只能怪自己）
- **结论**: 同一事件三种答案并存，取决于站在谁的位置
- **结果**: 例题结论如上，书中未说明现实结果

### 案例 4: 人行横道上不肯让路的行人（反例）
- **类型**: 书中反例（第1章）
- **问题**: 卡车冲向走在人行横道上的行人，所有人喊他让开，他却淡定地说「他不能撞我。他撞我是违反交通法规的，他负全责。我就不让」
- **方法论的使用**: 作者用这个反例展示「用对错代替自救」的代价——卡车司机的错固然成立，但这样的判断救不回行人的命；行人当时该想「不让，就是我错，因为不让开我就会死」
- **结论**: 损失即将落到自己头上时，坚持抽象对错、不肯避让，是拿自己的代价去证明对方错
- **结果**: 行人被卡车撞死（例题给定结局）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 遭遇损失后反复追问「这到底是谁的责任」，情绪内耗停不下来
2. 朋友遭遇诈骗、事故向你倾诉，你想知道该劝他追责还是先止损
3. 看到社会新闻或身边纠纷，想评论对错，不确定该用谁的尺子
4. 自己即将踩坑（合同、投资、冲突现场），想知道此刻该按什么标准行动
5. 批评别人之前，想弄清自己说的是「没有人性」「不道德」还是「违法」

### 语言信号

- 「这事到底怪谁？」
- 「明明是他违法，凭什么要我退让？」
- 「我咽不下这口气」
- 「就算我认栽，这理也得说清楚」
- 英文: "whose fault is this?", "it's not fair, why should I back down?", "should I just let it go?"

### 与相邻 skill 的区分

- 与 `logic-plus-context` 的区别: 那是全书的生成公式（方法论从哪里来）；本卡是它在「对错判断」场景的首个落地，管「损失发生后按身份选判据」
- 与 `three-levels-of-wisdom` 的区别: 本卡解决「谁的错、怎么办」；`three-levels-of-wisdom` 处理人生层级的取舍（选择 > 定力 > 博弈），同一决策里常先后使用——先判断，再取舍
- 与 `boundaries` 的区别: 「谁的损失大就是谁的错」的前提是分清所有权与课题（什么是我的、什么是我能改变的）；`boundaries` 提供这层判据
- 与 `world-three-laws` 的区别: 本卡先判对错、定应对；`world-three-laws` 决定接下来用哪条法则与世界打交道（自然/族群/普遍）

## E — 可执行步骤 (Execution)

1. **身份定位**
   - 完成标准: 判定提问者/决策者是谁——评论家（旁观）、政策制定者（定规则）、当事人（损失落在自己头上）；一人多身份时分别列出
   - 判停条件: 分不清身份时先问一句「谁的损失最大」

2. **选判据**
   - 完成标准: 按身份匹配——评论家→证据与法规；政策制定者→社会总成本（怎样判能让此类事减少）；当事人→谁的损失大就是谁的错
   - 输入契约: 一段损失/冲突的事实描述

3. **自救优先（当事人场景）**
   - 完成标准: 损失已发生时，行动清单先于追责讨论——止损、保全、复盘；「责怪、埋怨、后悔」不进入行动清单
   - 判停条件: 若涉及犯罪/侵权，自救与依法维权并行，不得以「我的错」放弃追责

4. **定层用语（涉及批评时）**
   - 完成标准: 批评用词先定层——「没有人性」（人性层）、「不道德」（道德层）、「违法」（法律层）各归其位，不跨层混用
   - 输出契约: ①身份 ②选用判据 ③下一步行动 ④（如涉及）批评用语所属层级

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **权力不对等场景**：不能把「谁的损失大就是谁的错」变成对受害者的二次责怪——它只用于当事人自己决定行动，不用于评判他人（BOOK_OVERVIEW 批判节、verified 边界提示）
- 需要法律追责与公共救济的场景：「你的错，靠自己」与依法维权不互斥，不能本末倒置、放弃追责
- 三种观并存不代表怎么判都行：它们各有硬标准，不能拿「角度不同」给明显的侵害行为开脱

### 作者在书中警告的失败模式

- 用「对错」代替自救：坚持「他违反法规、他负全责，我就不让」的行人被卡车撞死——拿自己的代价去证明对方错（ce02）；警告信号：强调「他违反规定，他负全责」、把「我就不让」当骨气、认为让开等于认输
- 责怪、埋怨、后悔改变不了结果：坏结果出现后，情绪性追责不产生任何改变，行动才有用（p04）

### 作者的盲点 / 时代局限

- 商人观在权力、资源严重不对等的场景（受害者 vs 加害者）可能滑向受害者有罪论——「被绑架是你防备不够」式的判断，对没有资源配备安保的普通人并不成立（BOOK_OVERVIEW 最强反对意见、verified note 点名）
- 案例（首富绑架）是单一叙事，其「本可避免」的判断带事后视角；商业顾问视角的案例池对不掌握资源的读者近于期望（BOOK_OVERVIEW 立场盲点）
- 「谁的损失大」如何比较、比较到什么颗粒度（时间、金钱、机会），原书未给量化口径，需使用者自定；与法律救济并行的场合书未展开
- OCR 底本限制：图 1-1（三种对错观关系图）图内内容缺失，本卡以正文文字口径重建（NR-01）；首富等人物的细节为书中转述，非独立事实核查（NR-04 口径）

### 容易混淆的邻近方法论

- 与 `fairness-justice-openness` 的差别: 「谁的错」是个体层面的判断与行动；「公平/公正/公开」是分配层面的判断——同一句话的两个层次，不要把商人观升格为公共裁判标准
- 与人性/道德/法律三层结构的搭配: 批评用语先定层，避免「没有人性」「不道德」「违法」跨层混用；两层配合——先定对错观（本卡），再定用语层级
