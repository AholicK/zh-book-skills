# 概率思维·千百十个（对冲运气的位阶）

## R — 原文 (Reading)

> 概率思维是你要心平气和地承认，就算你做对了所有事情，你成功的概率也不高，比如在今天的互联网行业，成功的概率可能只有约 5%；在认识到这一点之后，再思考应该用什么方式提高成功的概率。……
>
> 时代是对冲运气的第一要素，我把它排在“千位”。……
>
> 我们经常说“结构不对，什么都不对”。举个例子，如果两个人合伙创业，各持50%的股份，那么他们的公司大概率很难获得发展。

## I — 方法论骨架 (Interpretation)

第一步是承认概率：创业与重大决策是不完全信息决策，「就算尽了一切努力，做对了所有事情，依然有 95% 是要靠运气」（作者自述观点）。先把「运气」还原为中性词——概率，再问「用什么方式提高成功概率」。

第二步是对冲概率，两套算法：

1. **期望值算法**（对冲确定效应）：红按钮=确定拿 100 万美元；蓝按钮=50% 拿 1 亿美元、50% 拿 0。多数人受「确定效应」（二鸟在林，不如一鸟在手）支配选红，但期望值 = 50%×1亿 + 50%×0 = 5000 万美元 > 100 万，蓝才是理性选择。既想理性又想要确定性：把项目以低于期望值的价格卖给投资人（如 2000 万美元），落袋为安。
2. **千百十个位阶**（对冲运气）：
   - **千位=时代**——对冲运气的第一要素；看到「无线成交占比 90%」级信号就要意识到时代变了，必须顺应。
   - **百位=战略**——要有自己独立的战略与模型，坚定执行；网络效应领域里「快鱼战略」最重要。
   - **十位=治理**——股权与组织结构：「结构不对，什么都不对」（50%:50% 与 98%:1%:1% 都大概率失败）。
   - **个位=管理**——找人、激励、流程、文化。

位阶不是重要性排序，而是杠杆差：百位（战略）上进一步，抵得上个位（管理）上进百步；反过来，用个位对抗千位如同螳臂当车。书中的提升口径（把握时代 +12%、战略 +5%、治理 +2%、管理 +1%，基础 5%→25%）**是示意数字，不得当真实概率**。失败仍然会发生——「不接受失败，再来一次」：连续四次、每次 25%，有一次成功就是大概率事件。

## A1 — 书中的应用 (Past Application)

### 案例 1: 红蓝按钮的期望值演算
- **类型**: 书中演练（第2章）
- **问题**: 红色按钮确定拿 100 万美元；蓝色按钮 50% 拿 1 亿美元、50% 什么都拿不到
- **方法论的使用**: 算期望值（50%×1亿+50%×0=5000 万美元）并与确定效应对照；给出第三方案——把项目卖给投资人
- **结论**: 蓝色按钮期望值更大、是最理性的选择；偏好确定性者可以把项目以 2000 万美元转卖、落袋为安
- **结果**: 演算结果（示意）：转卖者确定获得 2000 万美元，投资人获得 3000 万美元期望利润

### 案例 2: 微软 GTEC 二十周年聚会上的访谈
- **类型**: 作者亲历（第2章）
- **问题**: 创业成功最重要的因素是什么？
- **方法论的使用**: 作者在微软 GTEC（全球技术支持中心）二十周年聚会上访谈原子创投创始人冯一名（他成功投资了途虎养车网等众多独角兽）
- **结论**: 冯一名说——「创业成功非常重要的因素之一就是运气」；作者引此把运气还原为中性的概率
- **结果**: 书中未说明访谈后续

### 案例 3: 2018「双11」与域名生意
- **类型**: 书中转述（第2章）
- **问题**: 时代（千位）信号长什么样？
- **方法论的使用**: 作者转述 2018 年「双11」阿里体系总交易额 1682 亿元、无线成交占比 90%——意味着必须在 5 英寸屏上讲清产品；域名是 PC 时代的入口（美图董事长蔡文胜靠投资域名起家）
- **结论**: 时代变了就要顺应；靠囤卖域名发家的概率下降
- **结果**: 未说明（书中转述、无出处）

### 案例 4: 股权结构例题（50%:50% 与 98%:1%:1%）
- **类型**: 书中演练（第2章）
- **问题**: 治理（十位）如何决定成败？
- **方法论的使用**: 两个例题——两人合伙各持 50%（股份相同意味着谁也不会听谁的）；一人 98%、另两人各 1%（创始人说他人「只值 1%」，投资人回「你也不值 98%」）
- **结论**: 两种结构都不对、大概率失败；「在千位、百位、十位上踏错半步，后面的努力就显得微不足道了」
- **结果**: 例题结论（未说明后续）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 复盘一次失败：不知道败在运气、时代、战略还是执行
2. 创业、换赛道或职业选择前，想判断「这件事值不值得下注」
3. 团队反复出现「很努力但没结果」，怀疑是努力的位阶出了问题
4. 面对合伙股权与组织结构（如 50%:50%），需要判断结构风险
5. 一次失败之后，纠结要不要再来一次

### 语言信号

- 「我什么都做对了，为什么还是输」
- 「是不是我不够努力」
- 「再坚持一下就好了」
- 「这行业现在不做就没机会了」
- 英文: "we did everything right", "it's a probability game", "just need to work harder"

### 与相邻 skill 的区分

- 与 `compound-interest-myths` 的区别: 同组量化决策——本 skill 看努力的位阶（时代/战略/治理/管理），那条看收益数字的真伪；先核查数字，再决定下注位置
- 与 `math-mindsets` 的区别: 本 skill 是位阶诊断（当前努力在哪一位、杠杆差几级）；`math-mindsets` 是五种思维的动作集合——「重复对冲」回答「要重复几次」，本卡回答「把重复投在哪一位」

## E — 可执行步骤 (Execution)

1. **承认概率**
   - 完成标准: 用「就算做对所有事，成功概率也不高」重述当前决策的处境；书中互联网基准约 5%（示意）
   - 输入契约: 一个正在做或刚失败的具体决策

2. **自上而下诊断四个位阶**
   - 完成标准: 逐位回答——千位：时代是顺是逆（有无「无线成交占比 90%」级信号）？百位：有无独立战略/模型，还是人云亦云？十位：股权与组织结构是否有人在关键处拍板？个位：管理（找人、激励、流程）做了什么？
   - 输出契约: 四位阶逐条结论，标出「当前努力主要落在哪一位」

3. **找出位阶错位**
   - 完成标准: 判断是否存在「用个位对抗千位」的错位（如行业结构变化时只抓内部效率）；若有，给出至少要上移到的位阶
   - 判停条件: 若四个位阶都无杠杆可用、事情完全不可控，停止本流程（纯运气场景不适用）

4. **调整下注位置**
   - 完成标准: 给出调整动作——换到更大概率成功的事、修正战略或结构，或明确「不接受失败，再来一次」的重复计划
   - 输出契约: 动作清单，每条注明落点与预期改变的位阶；涉及百分比处一律标注「示意」

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 完全不可控的纯运气场景（抽奖、彩票）——千百十个要求落到可行动作，无动作可落时本卡无用
- 损失刚发生、情绪未平的现场——先处理情绪与补救，再做位阶复盘
- 用「时代不好」替自己开脱的场合——位阶诊断是为了找动作，不是找借口（最常见的误用）

### 作者在书中警告的失败模式

- 确定效应——为「落袋为安」放弃期望值更高的选项；决策语言是「至少能拿到手」、从不算期望值（ce112）
- 用「个位」的管理对抗「千位」的时代——「如同螳臂当车」；行业成本/需求结构变化时只抓内部效率（ce116）
- 结构不对还继续加码——50%:50% 与 98%:1%:1% 都不对，踏错半步，后面的努力微不足道

### 作者的盲点 / 时代局限

- 把握时代 +12%、战略 +5%、治理 +2%、管理 +1%、基础 5%→25% 全是作者示意数字（NR-03 登记），无数据来源；本卡出现的任何百分比都必须带「示意」标识
- 案例集中在 2016–2020 移动互联网（双11、团购、打车、域名），成书 2021：时代判断带幸存者与事后归因色彩——成功者复盘能点出「时代」，事前识别时代却没有给出可操作信号
- 「股权结构大概率失败」是工作例题加商业直觉的断言，无数据支撑，不能当治理设计的正式依据
- 「95% 靠运气」是作者自述观点（他自承「我过去也分享过这个观点」），无出处

### 容易混淆的邻近方法论

- `compound-interest-myths`: 两卡都在给话术做减法——本卡减位阶错位，那条减数字幻觉
- `math-mindsets`: 「重复」在两卡中各占一半——本卡给位置，那条给次数与期望值算法
