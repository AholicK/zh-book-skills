# 逻辑素养四句话与逻辑闭环自检

## R — 原文 (Reading)

> 那么，如何才能挖掘自己的逻辑思维呢？有四句话可以帮助大家建立基本的逻辑素养：证有不证无，以偏不概全，证有靠举例，概全靠推理（见图2-12）。……
>
> 一件事情的真相，有千万种可能。看到一个事实，就会排除一批假象。很多人往往只看到3～5个事实，就迫不及待地找一个最符合自己价值观的当作真相。……离事实越远，离阴谋论就越近。
>
> — 第2章 思考问题的底层逻辑 · 四句话建立基本的逻辑素养（L1371-1416）
> — 第2章 思考问题的底层逻辑 · 小提示（逻辑闭环）（L1471-1473）

## I — 方法论骨架 (Interpretation)

逻辑素养不是逻辑学知识，而是四句可以逐条打钩的自检句——既检查自己发出的论证，也扫描别人递过来的结论：

1. **证有不证无**——证明「有」，一个例子就够；证明「无」或「所有」，举一万个例子也不行，只能靠推理。「我从来没见过」不是证据，只是你的经验边界。
2. **以偏不概全**——几个个案推不出全称结论；正确姿势是把大概率成功的事情重复做，而不是跟着「某某没读书也发财」式的偏例走。
3. **证有靠举例**——说「有」就要举得出例子；举不出，就只是假说。假说可以保留，但不能拿它强加于人。
4. **概全靠推理**——一般性结论只能靠推理证明；「大家都这么说」「这难道不是共识吗」都不是证明。

另配两把尺度：

- **逻辑闭环五层次**（无逻辑无闭环 → 有逻辑无闭环 → 低层次闭环 → 高层次闭环但排斥新事物 → 高层次闭环且持续打碎自己）。最危险的是第三层：一切都能在自己的框架里得到解释，于是无需更新、永远「正确」，却无法前进。
- **刨根问底**：对「习以为常」的说法不满足于表面解释，一层一层往下追溯，每一层都去验证（做实验、查资料、看原始出处），直到根本原因。

四句话管「论证成不成立」，五层次管「人在哪一层认知里说话」，刨根问底管「结论的根在哪」。

## A1 — 书中的应用 (Past Application)

### 案例 1: 赤道水流的刨根问底
- **类型**: 作者亲历（第2章）
- **问题**: 微信群友转发赤道旅行视频——脸盆里的水在赤道北面逆时针、南面顺时针旋转，导游解释为地转偏向力，群友纷纷感慨世界神奇
- **方法论的使用**: 作者去过两次赤道看表演、两次南北极做实验，知道小尺度水流远不足以产生这种差别；2014 年专程去厄瓜多尔首都基多看当地人做实验、拍视频查资料，一路下钻
- **结论**: 地转偏向力确实存在，但只能影响大尺度物体，小尺度水流方向随机、主要受环境影响；实验的真相是当地人拉完塞子会轻推一下水；景点画的「赤道线」因地板移动早已不是真正的赤道
- **结果**: 得出上述三条结论，视频里流传的解释被推翻

### 案例 2: 进化岛社群的「凭良心能不能赚钱」
- **类型**: 作者亲历（第2章）
- **问题**: 进化岛社群学员问「真正凭良心做生意到底能不能赚到钱？」
- **方法论的使用**: 作者用「以偏不概全 / 证有不证无」纠偏——「好人没赚到钱」的个别例子推不出全称结论
- **结论**: 也许是错误归因：凭良心做生意没赚到钱，问题通常不是因为有良善的「心」，而是因为没有商业的「脑」；不能把脑的问题归于心
- **结果**: 书中未说明学员后续反应

### 案例 3: 「米」「尺」「斤」的单位溯源
- **类型**: 书中转述（第2章）
- **问题**: 1 米为什么恰好等于 3 尺？赤道周长为什么是约 40076 千米这样的「整」数？
- **方法论的使用**: 刨根问底的连续下钻：先量出赤道到北极的地表距离、取其千万分之一定义为「米」；1930 年国民政府为与国际接轨，把 1 尺定义为 1 米的 1/3（此前尺长不定）
- **结论**: 不是先有「米」再去量地球，逻辑恰好相反；两套单位中必有一个迎合另一个；「半斤八两」来自 16 进制的司马斤
- **结果**: 未说明（溯源结论本身即结果）

### 案例 4: 三句「撒谎」回应模板
- **类型**: 书中演练（第2章）
- **问题**: 面对「读书有什么用」「你还不如什么都不做」式的以偏概全反驳
- **方法论的使用**: 作者给出三组对话模板——「他的财富撒了谎」（终身学习才能大概率成功，他的运气不一定降临在我身上）／「你的成功撒了谎」（以终为始才能大概率成功，你的成功不能复制到别的公司）／「我的不幸撒了谎」（正确的事情重复做才能大概率成功）
- **结论**: 用「大概率成功的事重复做」替换个案叙事
- **结果**: 未说明（对话模板，无现实结果）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到一条让自己信服或愤慨的结论，想先判断它站不站得住
2. 自己准备发言、写文章、做汇报，希望论证不被抓漏洞
3. 正被「读书无用」「某某也这样」式的个案说服，或想用个案去说服别人
4. 与人争论半天没有交集，想弄清双方各自在哪一层「闭环」里说话
5. 只掌握三五个事实就被某个「真相」吸引，需要检查自己是否在向阴谋论滑

### 语言信号

- 「我从来没见过，不可能有这种东西」
- 「大家都这么认为」「这难道不是共识吗」
- 「我认识好几个人都是这样，所以……」
- 「我相信就有」
- 英文: "I've never seen it, so it can't exist", "everyone knows that", "I know several people who…"

### 与相邻 skill 的区分

- 与 `axiomless-learning` 的区别: 那条解决「学什么、怎么学」（无公理体系学科的学习法）；本 skill 只做论证层检验。二者可接力：先检验结论，再决定学什么
- 与 `fact-opinion-stance-faith` 的区别: 那条解决「这句话是什么」（事实/观点/立场/信仰）；本 skill 解决「这句话成不成立」。识别出立场者后应停止争对错，只对事实/观点主张做四句检验
- 与 `mind-injection` 的区别: 那条拦「为什么+观点」的句式注入（防御入口）；本 skill 是拿到任何论证后的逐句检验清单（展开层）

## E — 可执行步骤 (Execution)

1. **逐句拆解**
   - 完成标准: 把待检验内容拆成「主张 + 例子/理由」的最小句，逐句标注它落在「有/无、全/偏、举例、推理」中的哪一类
   - 输入契约: 一段发言原文（自己的或他人的）；没有原文无法检验

2. **四句打钩**
   - 完成标准: 对每条主张给出结论——是否用举例证「无」（违例 1）／是否以偏概全（违例 2）／说「有」是否举出了例子（举不出即假说）／全称结论是否有推理链（只有共识即违例 4）
   - 输出契约: 每条主张一行「违例类型 + 依据句（原话摘录）」

3. **指出违例并补证**
   - 完成标准: 对每个违例给出具体补证动作——把「无」改回「我没见过」、把全称改偏称、为「有」补例子、为全称补推理链
   - 判停条件: 若对方说的是立场或信仰而非事实主张，停止举证辩论并转入 `fact-opinion-stance-faith` 的口径

4. **闭环自检（可选）**
   - 完成标准: 若是长期争论，判断双方各处于逻辑闭环五层次的哪一层，识别是否存在「什么都能解释」的低层次闭环
   - 判停条件: 结论只用于自检与选择沟通方式，不用于给他人贴层次标签

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 日常寒暄、情绪安抚、已达成共识的场合——对每句话做举证检验会毁掉对话
- 对方谈的是立场或信仰而非事实主张——立场无法用举证驳倒，应转 `fact-opinion-stance-faith` 处理
- 需要对他人做人格或能力评判时——四句话是自检工具，不是给人打分的尺子

### 作者在书中警告的失败模式

- 「我从来没见过，不可能有这种东西」——用个人经验边界当世界的边界，关掉可能性也关掉机会（ce104）
- 「我相信就有」「这难道不是共识吗」——用信念和共识替代举证与推理；举不出例子的「有」只是假说，不能强加于人（ce105）
- 低层次逻辑闭环——所有问题在闭环内都能解释，于是无法前进；第四层次者排斥新事物，结构一变就用旧认知补漏洞，「沿着旧地图，是找不到新大陆的」（ce106）
- 只看到 3～5 个事实就迫不及待地选定最合口味的「真相」——事实越少越容易滑向阴谋论（ce107）

### 作者的盲点 / 时代局限

- 四句话管形式不管判停：事实收集到多少算「够了」、举证何时应当停止，书中只给出「3～5 个事实」这种警告式表述，没有可操作标准
- 逻辑闭环五层次没有可操作的判定判据，实际使用容易变成给人贴「层次」标签的武器，作者未给出防误用规则
- 案例集中在 2016–2020 移动互联网语境（成书 2021）；「允许更多的可能性，你才能得到更多的机会」带有创业红利期的时代色彩
- 批判节提示的自反性：本书教读者警惕「成功经验不可信」，自身却是一部成功者经验总结集——用四句话检验本书自己的断言，也会发现不少未给反例的结论

### 容易混淆的邻近方法论

- `fact-opinion-stance-faith`: 先分清「是什么」，再检验「成不成立」；四句话对立场无效，边界由前者划定
- `mind-injection`: 句式层拦截与论证层检验常被混为一谈——一个在入口，一个在展开，可先后使用但不能互相替代
