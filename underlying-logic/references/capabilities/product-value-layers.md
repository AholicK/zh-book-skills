# 产品三层价值：功能、体验、个性化与定价

## R — 原文 (Reading)

> 从商业洞察的角度来说，产品价格是由消费者能感知到的价值决定的。……消费者能感知到什么价值？——功能价值、体验价值、个性化价值（见图5-3）。……比功能更稀缺的，是体验；比体验更稀缺的，是个性化。所以，产品的定价，取决于你能提供给消费者什么价值。
>
> — 第5章 社会协作的底层逻辑 · 产品价格到底应该由什么决定（L3863-3879）
> — 第5章 社会协作的底层逻辑 · 小提示（L3965-3979）

## I — 方法论骨架 (Interpretation)

定价的第一性原理：**价格不是由成本决定的，也不是由「定位中高端」决定的，而是由消费者能感知到的价值决定的。**可感知的价值分三层，稀缺度递增：

1. **功能价值**——满足基本需要（西瓜甜、馒头饱）。竞争靠性价比：性价比=性能/价格（品质相同则越便宜越高；价格相同则品质越好越高）。两种购物需求永远存在：物美价廉（在价廉里找物美）与价廉物美（在物美里找价廉）。做出高性价比的两种方法：规模效应（规模越大价格越低）与技术优势（比效率）——但比到最后容易演变成价格战，把利润空间压榨得越来越小。
2. **体验价值**——差异化带来的稀缺性（同一只西瓜，切半并送一个勺子）。**核心方法论：从产品视角切换为用户视角**——把「我怎么做产品」换成「用户想怎么得到便利/感受」。作者的判断：大多数公司都不应该在同一个产品上比价格，而是要给消费者提供更稀缺的价值——体验价值。
3. **个性化价值**——私人定制，是这个时代最高级、最昂贵的需求；个性化产品是能让用户感知到最稀缺价值感的产品（七夕的「心形」西瓜；红领西服的在线定制）。

定价收束：**价值越稀缺，价格就越高**——先定位自己能提供哪一层价值，再定价；升级方向是沿着功能 → 体验 → 个性化迁移，而不是在同一层里比价格。

## A1 — 书中的应用 (Past Application)

### 案例 1: 创业者说「定位就是中高端、卖给中产阶级」
- **类型**: 作者亲历（第5章）
- **问题**: 作者做商业咨询时的经历：看了创业者的产品后说「产品很好，但是感觉有点贵」；创业者回答：「我们的产品定位就是中高端，是要卖给中产阶级人群的」
- **方法论的使用**: 作者指出：产品价格由消费者能感知到的价值决定（功能、体验、个性化三层），而不是由一句「定位中高端」决定；心里吐槽「中产阶级得罪谁了」
- **结论**: 定价问题要回到「消费者能感知到哪一层价值」，不是回到定位口号
- **结果**: 书中未说明该产品后续定价

### 案例 2: 卖西瓜的三代卖法
- **类型**: 书中演练（第5章）
- **问题**: 街头小贩怎样把同一个西瓜卖出三档价格？
- **方法论的使用**: 第一代：卖整个西瓜，广告「甜得舍不得卖」（功能价值）；销量不好后推出新卖法——卖半个西瓜、送一个勺子（体验价值：提供便利与差异化）；到了七夕情人节，再推「心形」西瓜——在半个西瓜上切一刀、再拼一下（个性化价值）
- **结论**: 比功能更稀缺的是体验，比体验更稀缺的是个性化；价值越稀缺，价格越高
- **结果**: 未说明实际销量结果；作者结论如上

### 案例 3: 七浦路与港汇广场——价廉物美与物美价廉
- **类型**: 书中转述（第5章）
- **问题**: 消费者的「性价比」需求有几种形态？
- **方法论的使用**: 作者以上海两处商圈说明：七浦路（翻译成英文是「Cheap Road」，东西很便宜）——周末空闲去逛，在「价廉」里找「物美」；徐家汇的高端购物中心港汇广场——要参加高端酒店婚礼却没有礼服时去，在「物美」里找「价廉」
- **结论**: 这两种需求永远不会消失，背后都是性价比；做功能型产品时，高性价比或许可以成为竞争优势
- **结果**: 书中未说明结果

### 案例 4: 红领西服的互联网个性化定制
- **类型**: 书中转述（第5章）
- **问题**: 个性化定制能不能规模化？
- **方法论的使用**: 转述红领西服（一家在互联网上做个性化衣物定制的公司）的流程：客户对自己的身材进行测量后，把尺寸数据发给他们；他们找专业设计师为客户设计十几件衣服，做好之后邮寄给你，同时给出十几种搭配方法——喜欢就留下、不喜欢可邮寄退回
- **结论**: 个性化是产品销售中最高级的卖法，利用邮购方式可在互联网上满足每个人的个性化价值
- **结果**: 书中未说明经营结果

### 案例 5: 「Made in Germany」标签的由来
- **类型**: 书中转述（第5章）
- **问题**: 模仿与山寨能走多远？
- **方法论的使用**: 转述：18 世纪英国谢菲尔德公司的剪刀刀具质量好、受欢迎，德国索林根城制造商「山寨」了该产品，品质接近但价格很低，导致德国制造声名狼藉；1887 年英国国会通过侮辱性的《商品法》，要求所有来自德国的产品都必须贴上「Made in Germany」的标签，以此将价廉质劣的德国货与优质的英国产品区分开来
- **结论**: 德国人后来把所有努力和创新凝聚在这个标签上，产品越做越好、摆脱了「低级货」烙印；比起一味模仿，更重要的是建立差异化、提供更稀缺的体验价值
- **结果**: 书中结论：德国产品最终摆脱「低级货」烙印；作者补充：美国、日本也曾是山寨大国

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要给自己或公司的新产品定价，纠结「定高了没人买、定低了没利润」
2. 产品同质化严重，只能跟着对手降价，利润越做越薄
3. 想升级做高端，但不确定该往哪个方向投入
4. 客户说「有点贵」，你想知道贵在哪里、该补什么价值
5. 看到别人做定制/礼盒卖高价，想知道自己能不能复制

### 语言信号

- 「我们的定位是中高端」
- 「竞品降价了，我们要不要跟？」
- 「产品很好，但是有点贵」
- 「怎么做出差异化？」
- 英文: "how should I price this", "price war", "differentiation"

### 与相邻 skill 的区分

- 与 `distribution-choice` 的区别: 那条判分布与交付形态（产品还是服务、边际交付时间）；本 skill 判同一产品里卖哪一层价值——先判分布，再定价值层与定价
- 与 `strategic-potential` 的区别: 那条换一个能量层（借商业模式与科技的势能）；本 skill 换一层价值（功能→体验→个性化）——都是「不与对手在同一层硬拼」，一个在战略层、一个在产品层
- 与 `profit-types` 的区别: 那条给利润类型的判据（社会工资 vs 创新利润）；本 skill 给价值层级的定位——功能层必被拉平，体验/个性化层才有超额，价值层级决定利润类型

## E — 可执行步骤 (Execution)

1. **定位当前价值层级**
   - 完成标准: 对自家产品逐层核对并给出证据——功能层：消费者能说出哪些性能？体验层：用户使用时有什么被照顾到的感受/便利？个性化层：有没有让具体某个人感到「这是给我的」？判定结论必须落到一层为主，不许写「我们三层都有」
   - 输入契约: 一个具体产品与它的目标消费者，外加至少 2 条真实的用户反馈或评价

2. **核对可感知性**
   - 完成标准: 对主张的价值逐条回答「消费者能不能感知到、怎么感知到」——说不出感知路径的（如抽象的「品质感」）暂不计入定价依据（brief 必写①：价格=感知价值，不等于任意定价）
   - 判停条件: 感知证据不足时，先做用户访谈/评价分析，再谈定价

3. **选择升级方向**
   - 完成标准: 在三条路里选定并写明动作——留在功能层（用规模效应或技术优势降本，接受价格战风险）；升体验层（按「从产品视角切换为用户视角」列 3 条具体改造）；升个性化层（设计定制流程与退换规则）
   - 输出契约: ①当前层级 ②可感知性核对结论 ③升级方向与动作清单
   - 判停条件: 升级动作对能力（设计、供应链、交付、售后）要求过高时，先补能力再升级，不要先改价签（brief 必写②：升级路径需能力支撑，否则是虚假高端化）

4. **定价并复检**
   - 完成标准: 依据价值稀缺度给出定价方向：价值越稀缺、价格越高；复检两条——定价与所提供价值层一致；没有把「定位口号」当定价依据

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **不要把它读成「想定多高就定多高」**：价格由消费者能感知到的价值决定，价值必须真实可感知；感知不到的高价只是自嗨（brief 必写①）
- 缺少交付能力时的升级冲动：从「切半送勺」到「互联网定制」，每一层升级都要设计与交付能力接得住；能力不支撑的升级叫虚假高端化（brief 必写②）
- 招标、监管定价、公益与成本加成类场景：这些不完全由消费者感知价值定价，本框架不适用

### 作者在书中警告的失败模式

- 在同一个产品上比价格：规模效应降价 → 比到最后演变成价格战、将利润空间压榨得越来越小；看到别人赚钱就蜂拥模仿（山寨），不做差异化——大多数公司这样打，打不出利润（ce309）；警告信号：竞争动作只有降价和模仿；宣传语全是「更便宜、更划算」；产品与竞品说不出本质差异
- 一味模仿解决不了差异化：德国制造、美日山寨史都证明模仿能起步，但停在模仿就只能被贴上「价廉质劣」（p199、c325）
- 定位口号代替定价依据：「定位就是中高端、卖给中产阶级」——作者当场指出价格由消费者能感知的价值决定（c330）

### 作者的盲点 / 时代局限

- **缺少量化口径**：「价值越稀缺，价格就越高」是方向性判断，书中未给各层价值的溢价幅度与计算方法（原书未给，需使用者自定）；案例均为作者观察/转述，无经营数据支撑
- **升级路径的成本被略过**：体验、个性化升级意味着设计、供应链与交付结构的改造；书中以「切一刀拼个心形」为例，对复杂产品与 B 端业务可复制性存疑（BOOK_OVERVIEW 立场盲点：商业顾问视角）
- **必须澄清（brief 必写③）**：功能层竞争不必然是死路——规模玩家仍在功能层胜出（规模效应本身就是护城河），书中「大多数公司不该比价格」是在缺乏规模与技术的语境下说的，不能读成「功能层等于没前途」
- **样本偏成功侧与时代锚点**：红领西服、Made in Germany 都是成功样本（幸存者样本）；「个性化是这个时代最高级、最昂贵的需求」带 2021 年前后消费升级语境，此后消费分层变化需重新检验（BOOK_OVERVIEW 时代局限）

### 容易混淆的邻近方法论

- 「定位理论」式的品牌口号：那是心智占位语言，本 skill 是价值层级与定价判据——口号不能替代「消费者能感知到什么」
- 单纯涨价做高端（高端化=涨价）：书中口径是价值稀缺度决定价格，顺序是「先给价值、再谈价格」；先改价签再补价值是倒置
- `distribution-choice` 里的产品/服务划分：同一对概念（产品/服务）在两处口径不同，混用会跳过分布判定直接给定价结论

## 相关 skills（阶段 3 定稿）

- composes-with: `distribution-choice`（共同决定做产品还是做服务、卖哪一层价值）、`strategic-potential`（都是「不与对手在同一能量层硬拼」：产品层换价值、战略层换势能）、`profit-types`（价值层级决定利润类型：功能层必被拉平，体验/个性化层才有超额）
- contrasts-with: 无强对比卡；与 `distribution-choice` 的边界在「交付增量」vs「价值层级」
