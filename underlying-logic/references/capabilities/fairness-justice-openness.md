# 公平、公正、公开与效率（含再分配）

## R — 原文 (Reading)

> 公平——用“同一把”尺子丈量万物；公正——选“哪一把”尺子来丈量；公开——把丈量的过程展示给公众，让同意公正者监督公平。……
> 公正的本质不是“你对我错”的问题，而是“谁有权做选择”的问题。……你定义公正，我维护公平。……
> 公平，是指收入分配追求相对平等。……效率，是指以最小的投入获得最大的产出。……初次分配负责效率，再分配负责公平。
>
> — 第5章 · 公平、公正与公开；效率与公平（L4893-5176）

## I — 方法论骨架 (Interpretation)

「公不公平」的争论，先拆成三个不同的词（书中严格切分）：

- **公平 = 用「同一把」尺子丈量万物**：对所有人一视同仁。核心不是用「哪一把」尺子，而是用「同一把」尺子；两把尺子（用「分享」量哥哥、用「独享」量弟弟）就是不公平。
- **公正 = 选「哪一把」尺子来丈量**：这是价值观问题；本质不是「你对我错」，而是「谁有权做选择」——定义权归承担后果的一方（哈佛对录取规则的成败负责，所以校方有权制定标准，包括「捐款优先」），但定义者无权妨碍公平：你定义公正，我维护公平。
- **公开 = 把丈量的过程展示给公众，让同意公正者监督公平**：既想公平又想公正的办法；一旦公开，维护公平的成本会因分摊给所有利益相关者而大大降低。书中示例（美国大选三步）：①同意一人一票＝定义公正；②不准花钱买选票＝维护公平；③当众唱票＝公开。

分配总量的层面另有一对概念：

- **公平**：收入分配追求相对平等；**效率**：以最小的投入获得最大的产出（书中引科斯的话：资源，总会落到用得最好的人手里）。
- 玉石演算（成品价值=玉石品质×匠人手艺）：宝玉给老王（手艺 8）→ 两人总收入 78；为求平等把宝玉给小张（手艺 2）→ 总收入 42：收入接近了，效率跌掉 36。所以共识是**初次分配负责效率，再分配负责公平**（再分配工具：累进个税、失业救济、再就业培训、减免低收入税费、社会服务、现金补助等）。
- 政策钟摆（书中梳理）：80 年代「效率优先」→ 90 年代「效率优先，兼顾公平」→ 十六届六中全会「更加注重公平」→ 十八大「再分配更加注重公平」；作者判断钟摆正摆向「效率与公平的均衡」，触发事件是 2020 年中央经济工作会议第六项任务「强化反垄断和防止资本无序扩张」——公平是下一个时代的红利，但开出罚单不意味着要拆掉高速公路。

使用纪律：三个概念各问各的问题——量得是否同尺（公平）、谁有权选尺（公正）、过程是否公开（公开）；不要在一场争论里混用。

## A1 — 书中的应用 (Past Application)

### 案例 1: 妈妈分东西与老板评奖金：两把尺子
- **类型**: 书中演练（第5章）
- **问题**: 作者用两个对照示例演示「不公平」：妈妈要求哥哥把东西分给弟弟，哥哥反问「弟弟也没有分给我啊」，妈妈说「他不一样，他是弟弟」；老板以「没完成业绩」不给张三奖金，张三反问「李四也没完成啊」，老板说「他不一样，他很努力」
- **方法论的使用**: 逐句核对尺子——妈妈用「分享」丈量哥哥、用「独享」丈量弟弟；老板用「功劳」丈量张三、用「苦劳」丈量李四
- **结论**: 两者都是用了两把尺子，这就是不公平
- **结果**: 书中未说明结果（示例）；作者结论：公平的核心不是用「哪一把」尺子，而是用「同一把」尺子

### 案例 2: 高考是不是用「同一把」尺子
- **类型**: 书中演练（第5章）
- **问题**: 一个典型争议：高考公不公平？
- **方法论的使用**: 先看尺子——高考用「分数」这把唯一的尺子丈量所有学生（高一分上清华北大、低一分明年再来；学生作弊退考、老师作弊坐牢）
- **结论**: 就「同一把尺子」而言，高考是公平的；「为什么不用素质、美德甚至身高做标准」的追问，属于「公正」范畴（选哪把尺子）
- **结果**: 例题结论如上；作者另给出推论：高考是「难以监管的公正对总体公平的妥协」，再谨慎加入一点额外「公正」因子中和粗暴的公平

### 案例 3: 美国私立学校的「套尺」与哈佛的录取标准
- **类型**: 书中转述（第5章）
- **问题**: 美国私立学校自主招生，公众质疑其标准（如「捐款优先」）
- **方法论的使用**: 私立学校可自主决定用「哪一把」尺子，每个学校手里是一把不同的尺子、甚至一组套尺——分数、社会活动、体育特长、背景多元化，还有「家里有钱并愿意捐款」；只要「捐款优先」这个规则是一视同仁的，哈佛的行为就是公平的
- **结论**: 但你可以说它不「公正」——在这件事中，哈佛是公正的定义者：是校方而不是你对哈佛的成功失败负责，所以校方有权制定标准；同时无权妨碍公平（规则定了就不能换尺子）
- **结果**: 书中结论：公正的本质不是「你对我错」，而是「谁有权做选择」

### 案例 4: 老王与小张：玉石匠人的公平与效率演算
- **类型**: 书中演练（第5章）
- **问题**: 两块玉石（碎石品质 3、宝玉品质 9）、两位匠人（小张手艺 2、老王手艺 8），应该让谁雕哪一块？
- **方法论的使用**: 用「成品价值=玉石品质×匠人手艺」算两种方案——方案 A 宝玉给老王：9×8+3×2=78；方案 B 宝玉给小张（更平等）：3×8+9×2=42
- **结论**: 方案 B 里小张收入从 6 涨到 18（+12）、接近老王（24），但两人总收入从 78 跌到 42——断崖式下跌；把资源给用得最好的人，社会财富最大化
- **结果**: 演算结论如上；作者由此把互联网巨头比作「老王」，把线下小卖家、出租车司机、收费员、菜贩、不会用移动支付的老人比作「小张」

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 分钱、评奖、排班、资源分配被质疑「不公平」，需要判定到底哪里出了问题
2. 家庭或团队里出现偏心争议（「他不一样」式理由反复出现）
3. 要设计一套规则（招生、招聘、评审、评奖）并决定选什么标准、要不要公开
4. 自己吃了规则的亏，不知道该骂「不公平」还是该去争「改规则」
5. 讨论一家公司或一项政策该讲效率还是讲公平（收入差距、再分配话题）

### 语言信号

- 「这不公平！」
- 「凭什么他拿的和我不一样？」
- 「他不一样」「情况特殊」出现在解释里
- 「规则是你们定的，我有什么办法」
- 英文: "that's not fair", "who decided this rule?", "let's make it transparent"

### 与相邻 skill 的区分

- 与 `right-wrong-views` 的区别: 对错观解决「谁的损失大、该怎么办」（个体层面的判断与行动）；本卡解决「尺子是不是同一把、谁有权选尺子、过程是否公开」（分配层面的判断）——同一句话的两个层次
- 与 `profit-splitting` 的区别: `profit-splitting` 给出分钱结构（优先/劣后、固定/剩余/分成）；本卡提供验收尺子——分钱方案公不公（同一把尺子/选哪把尺子）决定它能不能被接受

## E — 可执行步骤 (Execution)

1. **拆词定位**
   - 完成标准: 把争议拆成三问并逐项作答——①用的是「同一把」还是「两把」尺子（公平）②这把尺子由谁定、谁承担后果（公正）③丈量过程是否公开（公开）
   - 判停条件: 若当事人争的其实是「结果不如我意」，先回到这一步核对概念——把「不公正」错喊成「不公平」会骂错对象、也找不到改规则的入口（ce410）

2. **验公平（同一把尺子）**
   - 完成标准: 找同类样本做横向核对——同类行为是否同标准、同结果；扫描「他不一样」「情况特殊」式理由，出现即记一条「两把尺子」（ce409）

3. **定公正（谁有权选尺子）**
   - 完成标准: 写清尺子的定义者——**谁对这件事的成败承担后果，谁有权定义公正**；同时确认其无权妨碍公平（规则确定后不得中途换尺子，规则内竞争、禁止破坏规则）
   - 输出契约: ①争议定名（公平/公正/公开 或组合）②定义权归属 ③下一步（维护公平/争取改规则/退出）

4. **能公开就公开**
   - 完成标准: 检查是否能将丈量过程展示给利益相关者（书中设想：把「我为什么招这 300 个学生」写成 3 万字论文并公开发表）；公开后维护公平的成本会因分摊而降低
   - 判停条件: 涉及隐私/机密时不做形式化公开，改为向利益相关者定向说明

5. **效率与公平分层（涉总量分配时）**
   - 完成标准: 把方案拆到两层——初次分配看效率（资源是否给了用得最好的人）、再分配看公平（书中工具箱：累进个税、失业救济、再就业培训、减免低收入税费、社会服务、现金补助）；再分配的目标是「一定程度上的公平」，不是消灭差距
   - 判停条件: 争论若上升为「该不该再分配」，提醒双方：公平与效率是钟摆，钟摆会回摆，但效率不会被抛弃（限速牌≠拆高速公路）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 不给强权的规则背书：「公正定义权归承担后果的一方」的前提是定义者真的承担后果、且无权妨碍公平——不能把这条判据拿去为既得利益辩护（权力滥用边界）
- 再分配 ≠ 均贫富：效率与公平是钟摆，不是单向；「公平是下一个时代的红利」是作者的长期判断，不是短期口号
- 不用于为既得利益辩护：三定义可用于设计制度、定位争议，不可用来把「他吃亏」解释成「他不懂公正」

### 作者在书中警告的失败模式

- 用两把尺子（ce409）：妈妈/老板式双标一旦被察觉，规则立刻失去公信力；信号：「他不一样」「情况特殊」成高频理由、同类行为评价不一、团队开始比较「谁被偏心」
- 把「不公正」错喊成「不公平」（ce410）：骂错对象，也找不到改变规则的正确入口
- 为公平牺牲效率（ce411）：把最好资源错配给能力差的一方，差距缩小了，社会总财富却从 78 跌到 42；信号：只谈差距、不谈总产出，绩效与回报脱钩
- 效率高速公路上超速驾驶（ce412）：垄断与资本无序扩张伤害初次分配中「效率和公平的均衡」，最终引来罚单；信号：增长故事从不提被落下的人、依赖垄断而非效率创新、政策与舆论持续转冷被忽视

### 作者的盲点 / 时代局限

- 时代锚点：案例集中在 2016–2020 移动互联网红利期（阿里被反垄断调查、2020 年中央经济工作会议）——「钟正在报时」式的判断需要剥离时效后再引用（BOOK_OVERVIEW 时代局限）
- 立场与样本：书中给的是站在「老王」一侧的建议（设「促进公平部」帮老人、小贩、农民），对「小张」一侧如何自处着墨不足；案例池同样是幸存者样本（BOOK_OVERVIEW 立场盲点）
- 「谁承担后果谁定义公正」默认「承担后果」是客观可判的，未讨论谁有权界定「后果由谁承担」；在权力不对等场景可能被强者用作护城河（BOOK_OVERVIEW 最强反对意见的同类风险）
- 玉石演算的 24 / 18 / 78 / 42 是示例数字，原书未给一般化核算口径；哪些「公正」因子该被加进公平的尺子里（如名额分配），书中只说「谨慎加入」，未给裁决规则——原书未给，需使用者自定

### 容易混淆的邻近方法论

- 与「平均主义」的混淆：公平=同一把尺子（过程一致），不是结果一样；再分配求的是「一定程度上的公平」（书中口径）
- 与 `right-wrong-views` 的边界: 个体层的对错判断不要升格为公共裁判标准；分配层的公平问题也不要退回成「谁的损失大」
