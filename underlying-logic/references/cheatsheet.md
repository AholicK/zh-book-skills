# 决策规则速查 — 《底层逻辑：看清这个世界的底牌》

| 能力 | 一句话规则 |
|---|---|
| 底层逻辑+环境变量=方法论 | 方法论会随环境失效：先盘点它绑定的环境变量，再提炼不变内核、重建新做法。 |
| 对错判断：三种对错观 × 人性、道德和法律 | 损失发生后先定身份再选判据：当事人用商人观先自救——谁的损失大，就是谁的错。 |
| 人生三层智慧：选择 > 定力 > 博弈 | 人生取舍先分层自检：选择（学会放弃并承担）> 定力（长期主义）> 博弈（重复博弈才启用）。 |
| 无公理学科学习法：兼听、反例与前提 | 学无公理体系的学科三件事：兼听各学派、给每个模型找反例、记住每个理论的前提。 |
| 表述四分法：事实、观点、立场与信仰 | 争论前先分类：事实核验、观点容纳、立场不辩（It's good for you）、信仰不攻。 |
| 注射式洗脑的识别与防御（「为什么+观点」句式） | 听到「为什么+观点」先别答原因——先拆出观点、质疑它，再决定回不回答。 |
| 辩论的原理与技术（说服观众的三要点） | 辩论不是说服对手而是说服观众：改概念、拆论证、赢下 10 秒回合。 |
| 假设—验证—结论—调整（反经验主义四步法） | 遇到突发问题别凭经验——大胆假设、去验证、下结论、做调整。 |
| 系统洞察：五块积木（快速看透本质的分析框架） | 看透本质=打开系统黑盒子：找存量、连因果、成对找回路、标上滞后。 |
| 三级解法：改结果、改原因、改模型（流程·制度·系统） | 解法分三级——改制度改结果、改流程改原因、改系统改模型；先定级再动手。 |
| 逻辑素养四句话与逻辑闭环自检 | 用四句话逐条检验论证：证有不证无、以偏不概全、证有靠举例、概全靠推理 |
| 复利三谬误纠偏与财富自由三路径 | 拆解复利话术的三谬误（期数/效果/收益率），再用三路径回答「怎么滚」 |
| 概率思维·千百十个（对冲运气的位阶） | 按时代/战略/治理/管理四个位阶诊断努力位置，用期望值对冲确定效应 |
| 五种数学思维（重复、动态、公理、向量、博弈） | 五种数学思维各配一句自检问题：重复对冲、动态眼光、公理体系、方向性、共赢 |
| 系统思维：商业模式是利益相关者的交易结构 | 把商业模式还原为利益相关者的交易结构，找结构性断点再给改造点 |
| 人生商业模式：能力 × 效率 × 杠杆（先查内核，后上杠杆） | 先审计能力×效率×杠杆三要素，再检查可复制的能力内核，最后才匹配杠杆 |
| 把工作当成玩：四象限定位与「自污 / 示弱 / 看淡」 | 用乐趣×价值四象限给时间定位，再做两个低风险动作，不评价他人 |
| 时间颗粒度与三层计划：把时间当预算来管 | 先自测时间颗粒度并校准，再按年/天/小时三层做计划；三层缺一不可 |
| 边际交付时间：先判分布，再选路径（正态 / 幂律） | 先用边际交付时间判正态还是幂律分布，再决定避开、剥离还是改做产品 |
| 创造 10 倍价值（不是强 10%）：换赛道、换圈子与攻击应对 | 判断目标在强 10% 还是强 10 倍区间，换新路而非血战；被攻击时先证据后律师再回归价值 |
| 人脉的本质：给予价值、平等交换（10-30-60） | 先问能给出什么价值，按 10-30-60 盘点关系；牵线成人之美分文不取 |
| 知识、技能与态度：用脑、用手、用心 | 先判断要学的是知识、技能还是态度，再匹配学法；两条禁忌专防错配 |
| 员工与企业是合伙关系：优先劣后与四种分配 | 把雇用关系看成优先/劣后结构，再按工资/奖金/股权/价值观对号入座；期权必核条款 |
| 黄金三问：What／Why／How 与知行合一 | 先还原真正想问的 Why、重定义问题，缺 Why 没动力、缺 How 是鸡汤 |
| 打比方三步法与幽默鉴赏（溢出的智慧） | 先洞察陌生事物的本质，再匹配熟悉事物讲出来；幽默是溢出的智慧，只作鉴赏 |
| 边界感：对所有权的认知，越界前先征求同意 | 越界与否先问所有权归属：时间、隐私、权利归谁，过界前先征求同意。 |
| 奖励机制表：多巴胺 / 内啡肽 / 血清素的分工与运用 | 先识别激励点燃的是哪种奖励物质，再改机制——多巴胺管动机，快乐另算。 |
| 世界三大法则：自然法则、族群法则、普遍法则的选择器 | 协作难先看法则：组织内族群、跨组织普遍、遇野蛮人自然法则自保。 |
| 战略势能：找不属于自己的能量，求之于势不责于人 | 增长别只压团队化学能：先找可积累的势能，再谈执行强度。 |
| 产品三层价值：功能、体验、个性化与定价 | 定价看消费者能感知的价值层：功能比价、体验差异、个性化最贵。 |
| 利润三分类：社会工资、趋势红利与创新利润 | 先判你的钱是哪一类利润，再把投入拨向创新利润 |
| 没有 KPI 的管理：只招成年人，用安全感换创造力 | 先核人才密度、现金流、业务性质三前提，再定能否取消 KPI |
| 共同体三级判定：利益、事业与命运 | 用三档测试判定关系层级，再决定谈利益、共事业还是绑命运 |
| 财富的本质与稀缺性：创造靠能力，分配靠稀缺 | 财富公式三问加稀缺性五问，把「多努力」换成「提分配权」 |
| 分钱模型：优先/劣后与四阶段分钱法 | 先拆优先/劣后与固定剩余分成，再按阶段与交易成本配置 |
| 信用：一个人最大的资产 | 把信用当资产经营：被信任降低交易成本，言出必行是储蓄，失信一夜清零。 |
| 公平、公正、公开与效率（含再分配） | 分配争议先拆三问：同一把尺子（公平）、谁有权选尺子（公正）、过程是否公开——再谈效率与再分配。 |
| 服从性测试（劝酒的本质） | 劝酒、拎包、改来改去不是礼仪而是权力测试——识别「理解要执行，不理解也要执行」，再定去留。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
