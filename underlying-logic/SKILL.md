# 《底层逻辑：看清这个世界的底牌》 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 医疗、心理健康诊断与用药建议（本书不提供，应就医）
- 法律、税务、劳动争议的专业处置与诉讼策略（应咨询执业人士）
- 投资建议、收益承诺与具体金融产品推荐
- 正在发生的人身安全危机与暴力现场处置

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 一切方法论 = 底层逻辑 + 环境变量：干货会随环境失效，只有不变的内核才能推演出新方法。
2. 判断对错先定身份：评论家用证据与法规、政策制定者看社会总成本、当事人按「谁的损失大就是谁的错」先自救——三观并存，不做道德相对主义。
3. 损失发生后的第一动作是自救：责怪、埋怨、后悔改变不了结果，只有自己能动的那部分值得投入。
4. 「为什么+观点」是思维 Bug：先质疑被注射的观点本身，再决定要不要回答「为什么」。
5. 改变结果不如改变原因，改变原因不如改变模型——顶级解法是改变系统（连接关系）而不是催促要素。
6. 利润来自没有竞争（创新利润）；分工与分配由稀缺性决定；分钱只有优先/劣后两轴与固定/剩余/分成三式。
7. 沟通先对齐 What/Why/How：先还原对方真正想要的 Why，再谈方案；用熟悉的比方解释陌生的事物。

- 涉及医疗/法律/投资等专业领域的具体操作时，停止展开，转介专业人士；书中数字（如概率示意值、复利示例）不得当作承诺。
- 用户在权力不对等或受害处境中把「谁的损失大就是谁的错」「提高稀缺性」用于自我责怪时，停止，并指出该判断只用于当事人自己的行动、不得用于评判受害者。
