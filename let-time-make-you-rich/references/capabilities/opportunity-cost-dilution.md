# 稀释机会成本：把单一标的换成「一系列标的」的载体

## R — 原文 (Reading)

> 「只投资单个标的的机会成本无限大！……一个简单的办法就是投资一系列优质标的。当你购买指数基金（比如，标准普尔指数基金）或者ETF（比如 BOX）的时候，你的投资对象不再是某一个优秀企业或者项目，而是一系列优秀企业或者项目！」
>
> 「通过购买一系列优质标的，你一方面有效地稀释了机会成本，另外一方面更重要，你的投资标的的属性和质量变了！」
>
> — 第3章 · 究竟有没有只涨不跌的投资标的（L277-289）

## I — 方法论骨架 (Interpretation)

**问题不是「风险集中」，而是「机会成本无限大」。** 本书的口径：钱是排他的——同一笔钱投了 A 就不能投 B，于是 B 的未来涨幅成为 A 的机会成本；只投单一标的时，这个成本被放大到无限（g15）。因此本卡要处理的对象不是「波动」，而是「你放弃了什么」。

**动作是一步：把标的从「一个企业」换成「一系列企业的载体」**——指数基金或 ETF。作者把这称为「一个简单的办法」，因为它不需要你挑选，只需要你换一个持有形式。

**更要紧的是附带收益：标的属性被换掉了。** 赌的不再是某家公司的运气，而是「整体经济发展」——后者才是「长期来看只涨不跌」属性的真正承载体。所以「稀释」的宾语是机会成本，不是风险；日常说的「分散风险」会丢掉属性替换这一层，也会让人误以为「买 5 只个股就算分散」。

落点复核：载体必须是**被动型**（不做主动挑选、不频繁交易）——这一步的判据见 `target-screening` 引用的 g22 分类；若载体自己去做主动管理，就把成功率的乘法又还回去了（ce21）。

## A1 — 书中的应用 (Past Application)

**原书未提供本单元的正例案例（本单元无 case 类候选）。** 以下为按原书规则构造的**合成演练**（明确标记为非书中案例）。

### 合成演练: 全仓单一标的的替换动作
- **类型**: 合成演练（依据 f10/p06/g15/g26 的规则构造，非原书材料）
- **问题**: 「我已经全仓一只白酒股，还想继续加仓。」
- **方法论的使用**: 按本书口径判定「全仓单一标的」违反机会成本原则（B 的涨幅成为 A 的机会成本）；给出载体替换动作——把该标的换成「一系列标的」的载体；再按 g22 复核载体是否为被动型（是否跟随指数、是否由管理人主动挑组合）
- **结论**: 替换动作成立；进一步检查发现该输入还触及属性检验（该白酒股是否满足「长期不断看涨」）→ 已记录为 v04→v05 的单元间交叉
- **结果**: 演练结论，非实测；替换后载体的具体选择需用户自行做出，本卡不推荐产品

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 重仓/全仓单一标的，心里不踏实但说不清哪里不对
2. 自认为「选的就是最好的，所以不需要分散」
3. 想知道「买几只才算分散」「指数基金到底解决什么问题」
4. 正在犹豫要不要把单一持仓换成指数 / ETF，但不确定收益在哪

### 语言信号

- 「我就看好这一只，全仓了」
- 「买 3–5 只股票算分散了吗？」
- 「指数基金不就是懒人基金吗，有什么用？」
- 「ETF 和买个股的区别到底在哪？」
- 英文: "should I diversify", "is an index fund enough", "concentration vs diversification"

### 与相邻 skill 的区分

- 与 `target-spotting` 的区别: 那条产出「一个候选」；本条处理「候选只有一个」这个结构问题——先定位、再稀释，动作不重叠
- 与 `target-screening` 的区别: 本条换的是**载体形式**（一个→一系列）；筛选判的是**属性资格**（长期不断看涨）——两卡处理的问题不同，常连用
- 与「资产配置 / 组合优化」的区分: 本书不讨论比例、相关性、再平衡，本卡也不讨论；不要把它扩写成资产配置教程

## E — 可执行步骤 (Execution)

1. **清点持仓结构**
   - 完成标准: 列出用户当前持仓清单，标注是否属于「单一标的」（一个代码 / 一家公司）
   - 输入契约: 持仓名单或描述；涉及具体金额可脱敏

2. **按本书口径说明问题**
   - 完成标准: 用「B 的未来涨幅成为 A 的机会成本」的机制说明单一持仓的问题，且明确宾语是**机会成本**而非风险（g15/g26 口径）
   - 判停条件: 若用户的问题其实是「这只标的到底行不行」→ 转 `target-screening`

3. **给出替换动作**
   - 完成标准: 动作 = 把标的换成「一系列优质标的」的载体（指数基金 / ETF 类）；载体复核 = 是否被动跟随（不做主动挑选、不频繁交易）→ 不合格则先转 `target-screening` 的 g22 判别
   - 输出契约: 替换动作 + 载体属性复核结果 + 未决项（具体产品由用户自选）

4. **利益关联标注（引用书中产品时强制）**
   - 完成标准: 凡引用书中出现的具体产品（标准普尔指数基金、BOX），必须标注 BOX 为作者自研产品、属产品推荐语境（g24），不得作为中立建议

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只有唯一可达的合规投资渠道（如仅有某一种产品可买）——结构上无法替换，先如实说明
- 用户想要资产配置、比例建议、再平衡方案——超出本书范围
- 单一标的是用户主动承担的风险偏好（如全部身家押注自己的公司）——本卡不做价值评判，只说明本书口径下的代价

### 作者在书中警告的失败模式

- **只投一个标的（ce04）**：机会成本无限大，「我选的就是最好的，所以不需要分散」正是它的征兆
- **载体搭错（ce21）**：换成「主动管理型」载体等于把「一系列标的」的优势又交还出去——「把自己原本100%成功的策略委托给他人之后，换来了5%的成功率」
- **误读为分散风险**：若把本方法理解为「多买几只」，会跳过「属性替换」这一层收益（g26）

### 作者的盲点 / 时代局限

- 指数 / ETF 的费用、跟踪误差、编制规则、单一市场集中度风险，书中一律未提——本卡不得替作者补齐这些内容
- 作者推荐了具体产品（BOX，自研），构成利益关联；且「一系列标的」的载体选择在作者笔下直接指向自家产品，需按 g24 标注
- 「机会成本无限大」是本书的修辞化口径（时间被列为「绝对排他性资产」L323），不是经济学通行的可比口径；下游不得据此给出量化结论

### 容易混淆的邻近方法论

- `target-spotting`: 「最被看好」的候选是输入，不是终点；本卡负责把它从「一个」变成「一系列」
- `target-screening`: 载体属性（主动/被动）判别借用了筛选卡的判据，但两卡的问题不同：一个是「换形式」，一个是「验资格」
