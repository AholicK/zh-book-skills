# 标的定位法：用「所有人都最看好」定位候选（含循环性边界）

## R — 原文 (Reading)

> 「直接选择市场上所有人都最看好的股票。注意这个“最”字。在深交所你就直接买万科，在上交所你就直接买贵州茅台，在纳斯达克你就直接买苹果，在港交所你就直接买腾讯……这就是交易市场的神奇之处——在这里，你可以利用他人的智慧。」
>
> — 第2章 · 证券交易市场是世界第九大奇迹（L245-259）

## I — 方法论骨架 (Interpretation)

**把「选股」这一苦差事外包给市场共识。** 作者的理由：市场上最聪明的人提供的建议「竟然是彻头彻尾免费的」（L253）——你不需要自己研究，只需要取「所有人都最看好」的那一个。注意「最」字：不是「之一」，是公认的第一。

操作上它是一步动作：按市场（交易所）分别取该市场公认的最优标的，然后**立刻交给下游**——因为这条判据有一个必须在出口处标明的性质：

**「最被看好」只能告诉你「过去被最看好」。** 它是对历史共识的观察，不能推出「未来继续涨」；要把它变成可持有的定投标的，必须经过属性检验（`target-screening`）与载体稀释（`opportunity-cost-dilution`）。书中作者举的例子（万科、茅台、苹果、腾讯、中烟国际）全部是事后赢家——这是本方法的循环性所在（BOOK_OVERVIEW §3），不是它的使用说明。

采用率数据说明这一步的实际难度不在技术而在心理：茅台股东 80594 户 vs 约 1.5 亿开户（≈万分之五）——「简单直接粗暴却极其有效」的原则，几乎没有人敢用。

## A1 — 书中的应用 (Past Application)

### 案例 1: 茅台股东数与开户数的对照（万分之五）
- **类型**: 转述统计（reported_case）
- **问题**: 这条「简单到没有门槛」的原则，实际有多少人在用？
- **方法论的使用**: 以贵州茅台股东总数（80594 户，2019-03-31 统计）对比同期中国股市开户数（约 1.5 亿），算出采用率
- **结论**: 约万分之五（含机构投资者），作者据此推断普通人中「也许只有万分之一不到的人敢用」
- **结果**: 复算通过（80594 ÷ 1.5×10⁸ = 万分之 5.37）；它同时是「简单恐惧症」（ce01）的量化证据

### 案例 2: 中烟国际 2019 年港交所上市
- **类型**: 转述案例（reported_case）
- **问题**: 面对一个「全中国最具现金生产能力的公司」上市，该做什么？
- **方法论的使用**: 作者给出的动作是「你直接买就是了」——把市场共识当作免费研究
- **结论**: 该书未给出上市后的表现（书中未说明）
- **结果**: 未说明——本案例只演示动作，不提供验证，引用时须如实标注

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想投资但卡在「买什么」：不懂财报、没时间研究、希望有一个不靠内幕的起点
2. 面对一堆基金/股票代码无从下手，想知道有没有「不研究也能站对位置」的方法
3. 已经听说过「买龙头」，但不确定这条原则的边界在哪
4. 想验证「我选股这么难，是不是方向错了」

### 语言信号

- 「我想投 A 股，但不知道买哪只」
- 「选股太难了，有没有不研究也行的方法？」
- 「别人说买龙头就行了，靠谱吗？」
- 「茅台/苹果这种，直接买可以吗？」
- 英文: "what should I buy", "which stock should I pick", "is buying the market leader enough"

### 与相邻 skill 的区分

- 与 `target-screening` 的区别: 本条只负责**定位候选**（过去被最看好）；「这个标的到底合不合格」的判定归 `target-screening`——两卡是流水线的前后两道工序
- 与 `opportunity-cost-dilution` 的区别: 本条输出「一个标的」，稀释机会成本处理「把它换成一系列标的的载体」；不要在本卡里直接给载体建议
- 与荐股类问题划清界限: 本卡不给买卖建议、不做合规投顾，只转述并限定作者的原则及其边界

## E — 可执行步骤 (Execution)

1. **确认市场与观察口径**
   - 完成标准: 明确用户要投的市场（上交所/深交所/港交所/美股等）；说明「最被看好」的度量口径书中未给（市值、成交额、共识度都是候选），本卡采用什么口径必须显式声明为**实现约定**并与用户确认
   - 输入契约: 市场名 + 用户可接受的口径；缺项先问，不猜值

2. **取候选**
   - 完成标准: 按声明的口径产出候选（通常 1 个），并遵守「最」字约束——不列「之一」
   - 判停条件: 若用户实际想问的是「我已经选了一个，它行不行」→ 转 `target-screening`

3. **强制边界标注（不可省略）**
   - 完成标准: 输出中必须包含这句意思的标注——「该判据只能定位『过去被最看好』，未来需要额外的属性检验；作者本人未讨论『最被看好』与『估值是否合理』的关系」
   - 输出契约: 候选 + 边界标注 + 转交步骤（去 `target-screening` 与 `opportunity-cost-dilution`）

4. **记录采用率事实（可选，用于心态校准）**
   - 完成标准: 给出「约万分之五」这一采用率事实及其出处（c02），帮助用户理解自己即将跳过什么

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要求荐股、择时、买卖点——直接拒绝并说明超出本书能力域
- 用户已持有单一标的且出现经营恶化（ce05 柯达/诺基亚场景）——此时需要的是属性复核，不是继续加仓的「共识」理由
- 把本条与「估值是否合理」混用：书中对估值问题**完全未讨论**，不得替作者补一个估值判据

### 作者在书中警告的失败模式

- **把「最优秀的企业」当作不会衰落的标的（ce05）**：柯达、诺基亚都曾是共识，黑天鹅无法用「它最强」规避；只投单一标的还有机会成本无限大的问题
- **未从长期倒推筛选标准（ce28）**：用着「市场共识」却忘了长期持有把选择错误的代价同步放大
- **简单恐惧症（ce01）**：本条太简单，最容易被跳过——采用率数据就是证据

### 作者的盲点 / 时代局限

- **循环论证（结构性缺口，不可在书内闭合）**：「最被看好」的证据其实是「已经涨了很多」，用它推出「未来继续涨」需要额外假设；这一缺口已写入 BOOK_OVERVIEW §3 最强反对意见第 1 条，下游能力卡必须携带
- 举例全部为事后赢家（万科/茅台/苹果/腾讯/中烟国际），未给失败候选
- 「利用他人的智慧」未讨论共识的形成机制（信息环境、流动性、指数编制）

### 容易混淆的邻近方法论

- `target-screening`: 「最被看好」是入口，「长期不断看涨」是闸门——注意 v03 与 v05 构成的循环关系，两个卡都携带同一根边界（事前判据缺失）
- `opportunity-cost-dilution`: 候选拿到后必须处理单一标的问题，别停在「选好一个」这一步
