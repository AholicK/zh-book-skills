# 资格判定：你的钱有没有使用期限（含「投资有风险」的推理错误）

## R — 原文 (Reading)

> 「你作为一个普通人，有着市场上所有那些所谓专业的基金经理所不可能具备的优势：你的钱虽然不多，但，你的钱没有使用期限。……几乎所有的主动型基金，都有结算期限，比如你常常听说的7+3或者5+2，甚至只有国内才有的2+1。……他们必须做的事是，在一个时间期限里跑出一个好成绩，否则，没有下一次了！」
>
> 「投资的确有风险，这没错。但，这个论断绝对不应该也绝对不能直接推导出一个极端的结论：普通人不要做投资！」
>
> — 第6章 6.9 · 普通人究竟有什么样的极端优势（L1089-1101）；第1章（L123-125）

## I — 方法论骨架 (Interpretation)

**「投资有风险」推不出「普通人不要投资」。** 这是一条逻辑检查：风险存在 ≠ 应该退出；这个不严谨的结论被绝大多数普通人「不仅默默接受了，还深信不疑」（L125）。作者把它拆开重装。

替换后的判据只剩一条，而且是可核验的资金属性问题：**你的钱有没有使用期限？** 借钱投资 = 给钱装上期限 = 亲手消灭自己的结构性优势（「借钱投资是最危险的……在投资之外也应该做到永不借钱」L507）。作者用它解释房贷定投的处境：房奴「不是房子的奴隶，他们是银行的奴隶」（ce02）。

为什么这条判据有分量：专业基金经理的钱有 7+3 / 5+2 / 2+1 的结算期限，被逼着在期限内跑出成绩，**能否扛住周期「完全是概率决定的」（L1101）**；而普通人的钱只要不借、不急，就可以持续投入、长期持有，「至于究竟是多长的长期，全由你自己来决定」（p38）——这是「有资格定投的根本原因」。

所以资格判定不问收入高低（p72：不分种族、国籍、智商、学历），只问资金的两个属性：**是自己的吗？有期限吗？**

## A1 — 书中的应用 (Past Application)

### 案例 1: 房奴与定投茅台的同学——18 年后的两份资产
- **类型**: 算例 / 假设情境（worked_example；作者自承这种比较「很可能并不存在」，L161）
- **问题**: 两个人在 18 年前做不同选择：一个贷款买房（=定投房产），一个定投茅台股票，结局如何？
- **方法论的使用**: 把房贷识别为「借来的、有使用期限的钱在定投」——利息与房产价值相当；把同学的定投识别为「无期限资金 + 合格标的」的组合；并对照流动性（房产趋近于零，股票几乎是 100%）
- **结论**: 房产约 20 倍，因贷款利息折半为 10 倍，再因未付利息打 3/4 折为约 7.5 倍；茅台股票 18 年 180 倍、定投约 40 倍
- **结果**: 结果为作者构造的对照算例，非真实事件；复算通过（见 coverage-audit）

### 案例 2: 作者的个人史（普通人样本）
- **类型**: 作者亲历（firsthand）
- **问题**: 「普通人」到底长什么样、能不能改变处境？
- **方法论的使用**: 作者自述出身（黑龙江海林县）、高考落榜、三本、从销售起步、写长销书、2011 年进入投资领域——全程以「普通人」自居
- **结论**: 「最终，是定投改变了我的命运」（L1613）；但作者同时强调有钱之后「依然是个普通人」——臭毛病没改、情商没提高、仍会做愚蠢决定
- **结果**: 作者自陈（无法独立核验）；用途是说明资格不与出身挂钩

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在「要不要开始投资/定投」的门口犹豫，理由含糊（怕亏、觉得不配、觉得钱少）
2. 用「投资有风险」当退出理由，但说不出风险与「不做」之间的推理
3. 手里有钱但是借来的、杠杆来的、或是有明确用途期限的钱，想知道能不能投入
4. 想借钱/加杠杆进场前的资格自检

### 语言信号

- 「投资有风险，普通人还是别碰了吧？」
- 「我就这点钱，够资格投资吗？」
- 「我打算贷款/借钱来投」
- 「房贷不就是最好的投资吗？」
- 英文: "investing is risky so I shouldn't", "am I qualified to invest", "should I borrow to invest"

### 与相邻 skill 的区分

- 与 `four-elements-plan` 的区别: 本条是门槛题（能不能开始、资金属性合不合规），方案形态题归 `four-elements-plan`；顺序是先本条后那条
- 与 `time-ledger` 的区别: 本条回答「凭什么是你（资金没有期限）」，`time-ledger` 回答「为什么必须是你（努力追不上资本）」——一个讲资格，一个讲必要性
- 与 `long-term-cycle` 的区别: 本条的「可以长期持有」是资格说明；「长期到底多长」的口径归 `long-term-cycle`

## E — 可执行步骤 (Execution)

1. **拆推理**
   - 完成标准: 把用户的「有风险→不要投」还原成完整语句，指出它缺少的步骤（风险存在不等于退出最优）；引用 p01
   - 输入契约: 用户对投资的原话或顾虑；无需其他字段

2. **清点资金属性**
   - 完成标准: 逐项确认——是否借来的（含消费贷、经营贷、杠杆）、是否有明确的用途/兑付期限、是否动用了应急储备
   - 判停条件: 若存在借钱/杠杆 → 停止给出投入建议，先按「借钱投资是最危险的」（p02）处理，并明确这是该资金结构下的结论

3. **对照机构资金期限**
   - 完成标准: 用 7+3 / 5+2 / 2+1 的结算期限说明机构的结构性劣势（期限决定行为，不是能力），确认用户资金是否具备「无使用期限」这一优势

4. **出具资格判定**
   - 完成标准: 输出两段——① 资格结论（具备 / 不具备 / 先处理前置问题）；② 约束清单（哪些动作会立刻摧毁优势：借钱、加杠杆、动用应急金）
   - 输出契约: 结论 + 依据引用 + 下一步（进入 `four-elements-plan` 或先处理负债/现金流）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要求具体产品、个股推荐或买卖时机——本卡不产出这些
- 用户已经负债累累、现金流断裂——先处理债务与生存问题，此时本卡的正确输出是「不进入」
- 把本卡当收入门槛检查：作者明确说「很难有个清楚的定义」（g27），不得补一个收入/资产门槛

### 作者在书中警告的失败模式

- **借钱投资（ce02）**：房奴不是房子的奴隶，是银行的奴隶；经济危机中「因为还不起房贷而跳楼自杀的案例从来都不罕见」（L507）
- **把「有风险」当判决**：不严谨的结论被默默接受、深信不疑——这是全书要拆的第一个推理错误
- **高架杆效应（c30）**：重大决策时人像站在高架杆上，「虽然都极度小心，但也都极度紧张，因此最终根本就无法正确行走」——说明决策质量在重大处反而更低，资格判定的冷静尤其重要

### 作者的盲点 / 时代局限

- **未讨论的张力**：「普通的钱没有使用期限」与「普通人随时可能失业/生病」之间的矛盾，书中仅以「量力而行」一句带过（BOOK_OVERVIEW §3 最强反对意见第 3 条）
- c01 是作者构造的假设情境（worked_example），且作者自承「很可能并不存在」——不得作为现实论据引用
- 「不该借钱投资」的论证带作者产品语境（无管理费的 BOX），属立场相关材料

### 容易混淆的邻近方法论

- `four-elements-plan`: 资格判定通过不是终点而是起点；两卡常连用，但不要把「填四栏」塞进本卡
- ce09「把边界外的决定性因素理解为命」的失败模式与本卡相邻：资格论回答「能不能」，不是「能不能对抗运气」
