# 一招一式、简单恐惧症与被动聪明

## R — 原文 (Reading)

> 「他们要“在该买的时候买”，随后还要“在该卖的时候卖”。……结果是，他们只因为多了一招一式，就把自己的成功概率从100% 降低至了25%！」
>
> 「但，请千万注意，定投的最大威力恰恰就来自它只有一招一式。因为，只有一招一式的结果就是，定投的你完全没有任何其他选择，你只要做就好了。」
>
> — 第5章 · 为什么很少有人使用定投策略（L527-543）

## I — 方法论骨架 (Interpretation)

**用最简单的乘法把「简单」量化。** 一整套动作需要连续做对 n 个独立决策，单次成功率 p，则整套成功率 = p^n：定投把 n 压到 1（该买时买），于是成功率取最高档；「多一招一式」（该卖时卖）就把 100% 降到 25%（就算按更高把握算，八成把握两次也只有 64%，六成把握降至 36%）。说服力来自 **n 的减少**，不是 p 的提高。

**反对「简单恐惧症」（g12）**：绝大多数人不信任简单的原则、方法、道理，「总是以为太过简单的都不可能有效」；成因是「从未有过真正的一技之长」——「磨炼任何技能所需要的长期重复，都是简单的，简单到枯燥的地步」。行李箱要等轮子发明 6000 年后才被装上（c06），就是这一症状的教科书案例；英语朗读、写作多读、健身锻炼三例同理。

**机制层：被动聪明（g11）。** 「一个人可能并不聪明，但因为他选择了一个正确的方式行动，以至于随后的一切决策和行为都自动变得更聪明」（L1251）。定投的三个自动产物：长期买入 → 自动完成「长期持有」（耐心）；定期买入 → 自动获得纪律；定额投入 → 自动获得「量力而行」（f27）。作者把它称为「定投的最大好处」，并据此说「定投是最好的投资教育和投资实践，别无二选」。

**成本最低的自检问题**：这个新动作让我需要做对的独立决策从 n 变成了 n+1 吗？是 → 你在给自己加戏。

## A1 — 书中的应用 (Past Application)

### 案例 1: 行李箱的轮子——简单方案被系统性忽略
- **类型**: 转述案例（reported_case）
- **问题**: 为什么有效的方案会被整体忽视几千年？
- **方法论的使用**: 人类发明轮子约 6000 年，往行李箱上装轮子却始于 1970 年，且头 20 年一直不畅销
- **结论**: 「因为基于种种原因，人们总是忽略简单的解决方案」
- **结果**: 未说明（作者只给出「头 20 年不畅销」这一结果）；它是「简单恐惧症」的跨领域证据

### 合成演练: 给定投加一条规则
- **类型**: 合成演练（依据 f09/p04 的规则构造，非书中案例）
- **问题**: 「定投既然这么简单，我能不能顺便加上『跌 10% 就加倍买』这个规则？」
- **方法论的使用**: 把动作数从 1 增加到 2（「该买时买」+「跌 10% 加倍」），按书中口径整套成功率由 100% 降至 25%；「复杂并不等于高级」判其不构成改进
- **结论**: 建议保持一招一式——只有一招一式时不存在出错的分支
- **结果**: 演练结论；注意 f09 的乘法把「定投 = 100%」当起点，前提是标的已按最高标准筛过（见 B 段）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想给一个已经够简单的计划「加优化」：加点规则、加点判断、加点技巧
2. 反复寻找更复杂的方法，因为「这么简单不可能有效」
3. 想知道为什么「很多人说定投好，却没人用」
4. 需要一个理由拒绝各种「精进技巧」的诱惑

### 语言信号

- 「这么简单？真的有用吗？」
- 「我能不能稍作改良——比如跌得多的时候多买点？」
- 「有没有更高级一点的版本？」
- 「报班/买课学了很多技巧，还是没做出来」
- 英文: "this seems too simple to work", "can I tweak the strategy", "any advanced version?"

### 与相邻 skill 的区分

- 与 `half-baked-check` 的区别: 本条处理**主动加戏**（本来没要求你做，你偏要加）；半吊子卡处理**漏做环节**（要求做的没做全）——一个加法一个减法
- 与 `active-passive` 的区别: 那条讲策略层「少动作」的哲学（被动力量）；本条给出可计算的机制（成功率乘法）与行为产物（三个自动属性）
- 与「效率/技巧类」skill 的区分: 本卡的回答通常是「不要加」，与技巧类 skill 的取向相反——不要用于「如何把 X 做得更精巧」的请求

## E — 可执行步骤 (Execution)

1. **清点动作数**
   - 完成标准: 把用户当前方案拆成「需要连续做对的独立决策」，逐个数出来（n）；每个决策都要能写成一句「在什么条件下做什么」
   - 输入契约: 用户当前的做法描述；缺条件的先请其补全

2. **计算与对照**
   - 完成标准: 对拟新增的每个动作，说明它把 n 提高了多少；按 p^n 给出对照（至少给出 0.5 与 0.8 两档）；结论措辞不得超出「按本书口径」的范围
   - 判停条件: 若新增动作实质上是在做「预测」（择时、猜顶底）→ 按 `active-passive` 的边界处理并终止加戏讨论

3. **判断「简单恐惧症」**
   - 完成标准: 检查用户排斥该方案的理由是否为「太简单 / 显得不高明」；若是，给出成因说明（未有一技之长 → 不信任长期枯燥的重复）与三个跨领域例子（朗读、多读、锻炼）
   - 输出契约: 判定 + 理由 + 是否属简单恐惧症

4. **交付「被动聪明」的三属性说明**
   - 完成标准: 说明计划形状如何自动产出耐心、纪律、量力而行；把结论落到「先装过滤器，再谈理解」（「你不定投，你永远不知道它的好处」）
   - 输出契约: 结论 + 三个自动属性清单 + 本卡的强制前提（见第 5 步）

5. **强制前提（不可省略）**
   - 完成标准: 输出必须包含——「成功率乘法把『定投 = 100%』当作前提，等于把标的选错这一分支设为零；该前提只有在这只标的已按最高标准筛过之后才成立」（否则会产出「定投必胜」的错误表述）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 标的本身未经检验（`target-screening` 未过）时谈「一招一式必胜」——这是本卡最容易产出的失真
- 把「简单恐惧症」当软钉子去嘲讽用户——作者用它做的是自我诊断，不是给人贴标签
- 用户的能力缺陷是信息不足（真的缺少知识），而非方案复杂——本卡不解决这类问题

### 作者在书中警告的失败模式

- **简单恐惧症（ce01）**：第一反应是「就这么简单？」，转而寻找捷径、窍门、秘密
- **把定投肤浅理解为摊薄成本（ce03）**：一旦均价被抬高就失去继续的理由
- **频繁换车道（ce10/ce13）**：「保证每次都能正确地更换车道，这概率本来就没多少，他们还反复换！」
- **报班学标题党（ce32）/ 养生不锻炼（ce33）**：避开唯一有效的基础动作，用外部产品替代行为本身

### 作者的盲点 / 时代局限

- **成功率乘法的前提未讨论**：f09 把标的选择失败的分支设为零；若标的选错，n=1 只保证「一错到底」——本卡必须补上这一前提
- 「多一招失败率就降」的推演中，单次成功率（0.5/0.8/0.6）取自作者断言，无样本
- 「三个自动属性」被描述为自动获得，未讨论计划中断、金额被临时调大的情形
- 「定投是最好的投资教育和实践，别无二选」属作者价值判断

### 容易混淆的邻近方法论

- `half-baked-check`: 「做活不做全套」是缺环节；本卡反对的是加环节——注意方向，两卡连用时要区分
- `active-passive`: 两卡共享「动作少」的主题，但判据不同：本卡算 n，那条判「是否针对趋势」
