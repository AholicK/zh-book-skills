# 半吊子诊断：做活不做全套

## R — 原文 (Reading)

> 「“半吊子”这个词，真的值得认真思考一番——因为所谓的“愚昧”，所谓的“身处镜像世界之中错误的一侧”，其症状就是做什么都是“半吊子”。」
>
> 「这基本上是我们的人生态度：无论什么，要么不做，只要决定做，就要做全套。绝对不能做“半吊子”」
>
> — 第9章 · 镜像世界另外一侧的众生相（L1429-1483）

## I — 方法论骨架 (Interpretation)

**「半吊子」不是骂人话，而是一种行为结构：做活不做全套。** 它是「愚昧」与「身处镜像世界错误一侧」的**可操作症状**——所以它可以被检查、被定位，而不是只能被感慨。

**诊断方法（本卡补上的一层）**：书中给了七个具体形态，却没有统一的「全套」判据。因此流程是两步：① **先定义这件事的完整动作链**（做全套 = 哪些环节必须成对/成套存在）；② 检查自己缺了哪一环——缺了就是半吊子，补齐或干脆不做。

**书中给出的七个形态（原文判据）：**
1. 只做合约不套保——「在不做现货交易的情况下，直接只做期货合约交易……成了百分之百的赌博」（ce20）
2. 定投却把钱交给主动管理者——「把自己原本100%成功的策略委托给他人之后，换来了5%的成功率」（ce21）
3. 抄底不逃顶——「抄底成功，之后还要逃顶成功……这才叫真正的成功」（ce22/p56）
4. 只提价格不提盘口量——「单独提价格，那就是『半吊子』」（ce23/p57）
5. 只提涨幅倍数——「涨多少倍，不是单独算数的东西」（ce24/p58）
6. 拿一半操作吹整个牛——「拿着一半的操作吹整个牛的人，很快就会被另外一半打脸，并且几乎是百分之百的概率」（ce22）
7. **最惨的一种：半途而废**——「明明做了长期的决策，却最终半途而废」（ce25）

**判据的对称性**：短线操作的问题不在方向，而在**所需连续成功的次数**——「越是短线的操作，越需要更多次的成功才有效」（p55）；这与 `one-move-simplicity` 的成功率乘法同源。

## A1 — 书中的应用 (Past Application)

### 案例 1（完整动作链样板）: 期货套保的「全套」做法
- **类型**: 书中给出的示例做法（作者设计的完整动作链，非实测案例）
- **问题**: 一个不得不在长期看涨的标的上卖出的人，怎样做才是「全套」？
- **方法论的使用**: 完整动作链 = 现货市场卖出 N 股 + 合约市场买入适量看涨合约（书中示例为 10 倍杠杆）；后验：涨 → 合约弥补少赚；跌 → 现货卖出算值当
- **结论**: 只做第二步即失去对冲，风险从有限变为无限——「99% 合约交易者都是『半吊子』」
- **结果**: 「适量」的定量口径书中未给；本案例的用途是**定义「全套」的样板**，不是教套保

### 合成演练: 定投交给主动管理者
- **类型**: 合成演练（依据 f15/f28/g22 的规则构造，非书中案例）
- **问题**: 「我定投了一只 ETF，但基金经理在调仓换股，我该不该继续投？」
- **方法论的使用**: 拆出动作链——采用定投（对）+ 把执行交给主动管理者（错）→ 命中 ce21；再从长期倒推筛选强度判定该载体不合格；补齐动作为换成被动跟随指数的载体
- **结论**: 判为半吊子，补齐动作明确；不能只回答「继续/不继续」
- **结果**: 演练结论；载体判别转 `target-screening` 的 g22 口径

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 做了一件事的一部分，隐约觉得哪里不对，说不清缺什么
2. 听到「抄底成功」「赚了 100 倍」类说法，想有一个核验口径
3. 用着定投，但执行交给了别的东西（基金、代投、智能策略）
4. 想给一个「做着做着不想做了」的决定找一个可判定的处理方式

### 语言信号

- 「我定了投，但这个基金还能自己调仓，没问题吧？」
- 「帮我看下这个策略缺什么环节？」
- 「他说自己在最低点抄底了」
- 「我不想继续了，但已经投了这么久……」
- 英文: "am I doing this half-way", "does my plan have missing pieces", "he claims he timed the bottom"

### 与相邻 skill 的区分

- 与 `one-move-simplicity` 的区别: 那条反对**加戏**（多做的环节），本条针对**缺环**（少做的环节）——方向相反，同属行为链审计
- 与 `target-screening` 的区别: 「定投交给主动管理者」在标的面是筛选不合格，在行为面是半吊子——两卡从不同切面处理同一场景，先按本条定位缺环、再按那条重验标的
- 与 `long-term-cycle` 的区别: 半途而废的**判定**（是不是在错误时点离场）依赖周期口径；本条负责识别「缺环」，时点问题转那条

## E — 可执行步骤 (Execution)

1. **定义完整动作链**
   - 完成标准: 对用户这件事，写出「做全套」应包含的环节清单（成对 / 成套出现的动作）；不能套用书中七形态的，按「该动作的正当用途需要哪几步才能成立」定义
   - 输入契约: 用户的做的事 + 目前实际做了哪些步骤；缺步骤描述的先请其回忆

2. **逐环核对**
   - 完成标准: 每个环节标注「已做 / 未做 / 中途放弃」；命中书中七形态的直接引用对应条目（ce20-ce25）
   - 判停条件: 若缺环表现为「在第一个周期中途重新决策」→ 转 `long-term-cycle` 取时点口径后再判

3. **给出补齐或退出的结论**
   - 完成标准: 对每个缺环给出「补齐动作」或「不做」二选一（作者的态度：要么不做，要做做全套）；不得留在「继续观察」这类模糊态
   - 输出契约: 表列 = 环节 | 状态 | 补齐动作 / 退出依据

4. **对「吹牛类」表述做核验（可选）**
   - 完成标准: 对「抄底/逃顶/涨了多少倍」类说法，按 p57/p58 要求补齐量：盘口单量、流通量、交易量——缺量的一律判「半吊子表述」
   - 输出契约: 核验结论 + 缺失字段清单

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把「半吊子」当贬义词用于评判他人——作者用它做自我诊断；用于人际指责会直接触发对抗
- 「全套」被无限扩大时——若把任何可能的优化都列为「缺环」，标准会失守；缺环必须限定为「该动作的正当用途所必需的环节」
- 用户处于半途而废的冲动中且已投入巨大——先走第 3 步的时点口径（`long-term-cycle`）再谈退出，避免情绪化决策

### 作者在书中警告的失败模式

- **七个形态本身**（ce20-ce25）：只做合约不套保 / 定投交给主动管理者 / 抄底不逃顶 / 只提价格 / 只提涨幅 / 半途而废（最惨：代价随坚持时长递增）
- **只提价格不提量（ce23/ce39）**：「在最高点和最低点上，盘口交易量总是很少很少的——因为那不是正常价格，那是很快会被整个市场迅速纠正的『短暂失真价格』」
- **恐惧作为动力（p48）**：作者自陈「一旦你开始决心不做『半吊子』……直至有一天被他们吓倒」——这条属动机策略，不可作为判据

### 作者的盲点 / 时代局限

- **「全套」的统一判据书中未给**：只有七个具体形态；本卡的 E 段以「先定义动作链、再查缺环」做操作性补充，属本流水线的实现约定
- 半吊子的判定依赖「正确动作链」的定义权——谁的链算链？作者未讨论标准之争
- 「要么不做，要做做全套」被抬为人生态度（p47），但书中未讨论「何时应当放弃」的正当性（退出本身不等于半途而废）

### 容易混淆的邻近方法论

- `one-move-simplicity`: 两卡一起使用时，先判断用户是「加戏」还是「缺环」——用错方向会给出相反建议
- `long-term-cycle`: 「半途而废」的时点判定不在本卡；本卡只负责识别「中途离场」这一动作形态
