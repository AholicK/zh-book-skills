# 长期与周期判断（长期 = 至少两个大周期）

## R — 原文 (Reading)

> 「你找最近的历史最高点，把那里当作当前周期的下降阶段的起点，到下一次众所皆知、随后从那里跌落的历史最高点，那就是下降阶段之后、上升阶段已然完成，进入了下一个周期。……只有下降阶段的起点是已知的」
>
> 「什么叫长期？在我看来，对普通人来说，所谓的长期不过是“至少度过两个大周期”——这就是长期了。……请注意，重点在两个大周期，而不是七年。」
>
> — 第6章 6.8 · 对于长期的理解决定你的结果（L1041-1045）

## I — 方法论骨架 (Interpretation)

**「长期」不是一个模糊的形容词，而是一个可判定的状态：至少度过两个大周期。** 配套的判据句是「一个上升，不叫趋势，一个下降，也不叫趋势；一个上升加上一个下降，构成一个周期；判断趋势需要至少两个周期」（L1017-1021）——单个涨跌段不构成任何信息，谈趋势的最小样本量是两个周期。

**周期定位法（本书唯一给出的可操作锚点）：** 取最近的历史最高点 = 当前周期下降阶段的起点；等到下一个「众所皆知、随后从那里跌落」的历史最高点出现，前一个周期即告完成。作者诚实标注了限度——**只有下降阶段的起点是已知的**；终点不可预测，也不需要预测：「你就是没办法不知道已经过去了两个周期」（L1045）。

**必须随卡交付的两条纪律：**
① 「重点在两个大周期，而不是七年」——「七年」只是书中给出的示例换算（一个周期三到五年），且该时长无出处；**不得把七年固化成判据**；
② 判据只用于回答「我是否已熬过完整的来回」与「何时可以重新决策（继续持有 / 部分套现 / 全部套现）」，**不得用于「现在该不该买」**。

**心态侧配套（f19 三段自问）**：对当下的人和事连问三句——它两个大周期后会是什么样？那时的我会是什么样？那时的我该如何面对同样的人和事？作者称其结果是「我很难再因为某个人某件事而生气了」。

## A1 — 书中的应用 (Past Application)

### 案例 1: 康德拉季耶夫长波（康波）
- **类型**: 转述案例（reported_case）
- **问题**: 大周期是否有理论支持？一个周期有多长？
- **方法论的使用**: 作者引用康波——约五六十年为一循环的经济周期现象，分上升与下降两个阶段
- **结论**: 作者自陈该理论「在实际应用中指导意义并不总是明确，很难被学术量化，所以也不太被学术界重视」，「现在康波理论只不过是许多非正统经济学的理论基石」
- **结果**: 该自我限定是本卡「不可把周期当预测工具」的直接依据；引用康波时必须连作者的自谦一起带上

### 案例 2: 三次危机的修复速度对比
- **类型**: 转述案例（reported_case）
- **问题**: 为什么大萧条恢复得那么慢，而亚洲金融危机、次贷危机的修复越来越快？
- **方法论的使用**: 作者用「经济周期的形成，本质上是多方协作时而协调、时而不协调造成的」解释；信息高速流动使全球化协作更容易，所以修复加速——「所谓的『永远』正在缩短」
- **结论**: 支撑「对普通人来说，长期并非永远」的一条理由（另一条是「每一代人赚到的钱都比上一代人更多」）
- **结果**: 三个对比全部是定性描述、无量化数据——不得据此推出具体年限

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 跌了很长一段时间，想知道「还要熬多久」「什么时候算一个周期」
2. 问「长期投资到底多长」「七年是不是就到头了」
3. 想知道「我是不是已经度过了一个周期、可以重新决策了」
4. 被短期的涨跌情绪裹挟，需要一个把当下放大的尺度

### 语言信号

- 「我从 2021 年开始定投，跌了两年，什么时候算度过一个周期？」
- 「长期到底是多久？一辈子吗？」
- 「现在能卖了吗？」
- 「都跌成这样了，还需要耐心吗？」
- 英文: "how long is long-term", "when can I sell", "is the cycle over yet"

### 与相邻 skill 的区分

- 与 `active-passive` 的区别: 那条讲「为什么与趋势有关的事才值得做」；本条给出趋势/周期的**识别口径**——先有尺度，再筛决策
- 与 `four-elements-plan` 的区别: 本卡为「长期」栏提供口径（两个大周期）；方案表的其余栏目归 `four-elements-plan`
- 与 `half-baked-check` 的区别: 「半途而废」（ce25）是在第一个周期中途重新决策——那条判行为链完整性，本条提供「何时才允许重新决策」的时点口径

## E — 可执行步骤 (Execution)

1. **明确问题与标的**
   - 完成标准: 区分用户问的是①「长期是多长」（口径题）还是②「我度过一个周期了吗」（定位题）；对②需拿到具体标的价格历史
   - 输入契约: 标的名称 + 可取得的历史价格数据（用户提供或请其指出数据源）；数据不可得时明确说明无法定位

2. **口径题：给出两个大周期**
   - 完成标准: 说明「长期 = 至少两个大周期」；同时说明「七年」只是示例换算、无出处，不得固化为判据；不得给出任何时间预测
   - 输出契约: 口径说明 + 「不建议把任何单一年数当判据」的限定

3. **定位题：执行周期定位法**
   - 完成标准: 找出最近的历史最高点作为当前周期的下降起点；说明终点不可预测也不需要预测；给出「是否已度过两个大周期」的判定（不确定时明确写「不确定」，不猜）
   - 判停条件: 用户在第一个周期中途、且想重新决策 → 转 `half-baked-check`（半途而废的风险）并建议等待判据成立

4. **心态侧自问（可选）**
   - 完成标准: 若用户处于焦躁状态，给出三段自问（两个大周期之后的人与事）；说明这是情绪工具，不是判断工具

5. **输出契约**
   - 完成标准: 结论 = 口径 or 定位结果 + 可决策时点 + 明确禁止事项（不得含时间预测、不得含「到期必涨」类表述）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要求预测：几年翻倍、何时回本、何时见底——**给出任何时间点预测都属于越界**
- 用户把本卡当「到期就会涨」的依据——判据只对起点有效，终点「没办法也没必要判断」（L1045）
- 用三步自问把所有问题推迟到两个周期之后——作者未讨论哪些问题不能推迟

### 作者在书中警告的失败模式

- **越差越找捷径（ce19）**：「对现状越是不满，摆脱现状的欲望就越是强烈……越差的学生越寄希望于找到捷径」——「马上」与任何长期机制冲突；解药是「你越差，就越需要耐心」
- **把「长期」理解成「永远」而绝望（ce29）**：用巴菲特的尺度（「我希望我的长期是永远」）衡量自己，于是在起点处放弃——普通人的长期并非永远
- **半途而废（ce25）**：在第一个周期中途重新决策，「当初曾经『坚持』得越久，他们半途而废的代价就越高」

### 作者的盲点 / 时代局限

- **「一个周期三到五年」无出处**，而「七年」这个可操作数字正建立其上——引用时必须写明来源不牢
- 「经济周期正在缩短」的论据仅为三次危机的定性对比（c23），无量化口径，却被用来支撑「永远正在缩短」
- p35「每一代人赚到的钱都比上一代人更多」无数据来源
- 康波理论作者自陈「很难被学术量化」（c24）——不得作为判据使用

### 容易混淆的邻近方法论

- `half-baked-check`: 「半途而废」属于半吊子的一种（ce25），但它的时点判定依赖本卡——两卡连用时注意分工
- `four-elements-plan`: 「长期」栏填的是本卡的口径，不是「7 年」——最容易写错的字段
