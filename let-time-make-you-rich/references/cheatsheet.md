# 决策规则速查 — 《让时间陪你慢慢变富》

| 能力 | 一句话规则 |
|---|---|
| 定投方案的四要素设定与启动条件（含第五问「意外」） | 定投方案 = 四栏 + 第五问：标的最重要，「意外」不答不算完成。 |
| 资格判定：你的钱有没有使用期限（含「投资有风险」的推理错误） | 判断能不能开始定投，只看一条——你的钱有没有使用期限。 |
| 标的定位法：用「所有人都最看好」定位候选（含循环性边界） | 不知道买什么时，取市场公认「最被看好」的那一个——但记住它只说明过去。 |
| 稀释机会成本：把单一标的换成「一系列标的」的载体 | 只投单一标的机会成本无限大——把标的换成「一系列标的」的载体（指数 / ETF）。 |
| 标的属性检验与排除清单（「长期不断看涨」是唯一准入属性） | 定投标的只有一条准入属性——「长期不断看涨」；债券、黄金、房产、潮鞋不合格。 |
| 主动的边界诊断（边界内尽力，边界外停手） | 主动只在边界内有效——先问对象是自己、他人还是运气，出界就停手。 |
| 主动地被动：顺应趋势、放弃鸡毛蒜皮 | 一切与趋势无关的都是鸡毛蒜皮——主动只花在「选哪一边」，选完就停手。 |
| 长期与周期判断（长期 = 至少两个大周期） | 长期 = 至少两个大周期；只有下降起点可定位，终点不预测也不需要预测。 |
| 完全不信命：切断「过去必然影响将来」 | 把「命」翻译成「过去必然影响将来」，再检查哪些联系可以切断。 |
| 一招一式、简单恐惧症与被动聪明 | 每多一招一式，整套成功率相乘下降——保持一招一式，别给自己加戏。 |
| 半吊子诊断：做活不做全套 | 做活不做全套就是半吊子——先定义完整动作链，再查缺了哪一环。 |
| 定投者的环境建设、家人沟通与意义赋予 | 家人是最大的阻力——先核对你的事对家人是否同等重要，只对你成立就作罢。 |
| 愚昧归因、践行路径与镜像世界诊断 | 失败多半是愚昧（可教育）而不是愚蠢（不可救药）——但别用它去评判别人。 |
| 努力的天花板与「为什么必须投资」的时间账 | 人只有约 9 年可自由支配时间，钱却 24 小时不休息——这是必须投资的原因。 |
| 定投与一把梭的收益核算（含微笑 / 猥琐曲线） | 定投收益 = 均价 / 市值 / 收益率三栏可复算；同一条曲线，你站在哪边决定你看到什么。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
