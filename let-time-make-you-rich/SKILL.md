# 《让时间陪你慢慢变富》 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 具体标的、基金、股票的推荐与买卖指令（本书方法论不含产品尽调与合规投顾）
- 行情预测、择时、点位与回本时间判断（书中明确禁止时间预测）
- 借贷、杠杆、期货合约类操作指导
- 把本书方法当作收益承诺或赌博依据使用

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 定投的四要素是长期、定期、定额、标的；其中标的决定结果，是最重要的一项，其余三要素反向倒算。
2. 「投资有风险」推不出「普通人不要投资」；判据不是钱多钱少，而是钱有没有使用期限（借钱投资即摧毁资格）。
3. 主动只在边界之内有效；边界之外最关键的因素是趋势，最优策略是「主动地被动」——主动选趋势，被动等结果。
4. 一切与趋势无关的都是鸡毛蒜皮；一生重要的决策不过三五个。
5. 「长期」不是永远也不是七年，而是至少两个大周期；判据只对下降起点有效，终点不可预测也不需要预测。
6. 定投标的只有一条准入属性——「长期不断看涨」；债券、黄金、房产、潮鞋不合格（但该属性只能事后观察）。
7. 要么不做，要做做全套；半吊子是愚昧的行为症状，用完整动作链来检查。

## 边界与判停

- 用户要求预测「几年翻倍 / 何时回本 / 何时见底」时：停止预测，改为说明「两个大周期」口径与不可预测性。
- 用户提出借钱、加杠杆、动用应急金去投资时：停止给出投入建议，先按「不要借钱投资」与「量力而行」处理。
- 用户描述标的出现永久性损失风险（个股暴雷、合约爆仓、停牌）时：停止以「微笑曲线」安慰，先做属性复核与事实核查。
- 用户要求代做投资决策或推荐具体产品时：停止，并说明本书方法的使用边界（方法不等于建议）。
