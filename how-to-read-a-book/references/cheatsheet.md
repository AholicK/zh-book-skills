# 决策规则速查 — 《如何阅读一本书》

| 能力 | 一句话规则 |
|---|---|
| 阅读的活力与艺术：主动阅读与两类阅读目的 | 先分清这次读的是「资讯」还是「理解」——只有后者值得动用后面的全部规则。 |
| 阅读的层次：四层次累积模型 | 阅读是层层累积不是任选菜单——先低后高，低层技能在任何场合都不消失。 |
| 基础阅读：层次一与其成长阶段 | 读不动先分诊：是字词层的锅还是理解层的锅——别对生字问题开分析阅读的方子。 |
| 检视阅读：略读六步与粗浅通读 | 先花一小时决定这本书值不值得读：六步略读＋一次不停顿的通读。 |
| 做一个自我要求的读者：四个基本问题与笔记 | 读任何东西都带四个问题，并让书页留下痕迹——这才是「自我要求」。 |
| 一本书的分类（规则一） | 开读前先归类：论说还是虚构、理论还是实用——分类错了，后面全错。 |
| 透视一本书：规则二三四与大纲 | 用一句话说出全书、用大纲铺开骨架、用问题清单收束主题——说不出口就是没读清。 |
| 与作者找出共通的词义（规则五） | 把让你头痛的字圈出来，用上下文定它在本书里的唯一意义——别去问字典。 |
| 判断作者的主旨：规则六七八 | 换自己的话说出来、举一个书外的例子——说不出、举不出，就是还没读懂。 |
| 分析阅读三阶段规则总表（15 条规则集） | 把 15 条规则当验收单用：哪一条没做，就补哪一个最小动作。 |
| 公正地评断与赞同/反对：规则九至十五 | 先说我了解了，再表态；找不出证据支持任何批评点，就有义务同意作者。 |
| 辅助阅读：相关经验、导读与工具书 | 卡住了才去找外力，且按顺序：相关经验→相关著作→导读→工具书；先读完再求助。 |
| 如何阅读实用型的书 | 读实用书就问两句：他要你做什么、他凭什么说能成——赞同了就得行动，否则你是没懂。 |
| 想象文学、故事、戏剧与诗 | 读文学先关掉论说文的那套检查器：不找共识主旨论述、不拿事实标准批评——先进入，再评论。 |
| 如何阅读历史书 | 历史至少读两种；不只问发生了什么，更问人们为何如此行动；报道先过记者五问。 |
| 如何阅读科学与数学 | 科学书就抓住一件事：作者要解决什么问题、问题背景是什么；数学当语言，从欧几里得入门。 |
| 如何阅读哲学书（含神学与经书） | 哲学书从问题读起：先找他要回答的问题，再自找他的中心原则——别用二手解读替代自己发现。 |
| 如何阅读社会科学 | 社科书先拆要素（科学/哲学/历史各占什么），再接受一件事：这类主题必须多书同读。 |
| 主题阅读：第四层次五步骤 | 主题阅读是「书服务你」：自建中立词汇、让作者回答你的问题、把分歧陈列成议题——全程引原文。 |
| 阅读与心智的成长：选书与重读 | 用金字塔分层你的书：底层的扫描即可、值得的做分析阅读、顶层的反复重读——荒岛十书帮你找到它。 |
| 附录一：建议阅读书目的使用 | 书单是邀请不是考核：从最感兴趣的那本开始，读得好胜于读得广，最后自己拟一份。 |
| 附录二：四层次练习与测验（自测系统） | 用书里的题库练手：材料→答题→对答案→回原文——不许拿去评分别人，也别指望标准答案。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
