# 附录一：建议阅读书目的使用

## R — 原文 (Reading)

> 不论基于什么理由，最聪明的做法都是从你最感兴趣的书开始读。……主要的目标是要读得好，而不是要读得广。……这个书单就像是一个时代的演进表，当然，你用不着依时间先后的顺序来读。……读诗，我们认为从一本好的合选集开始阅读，会比从某一位作者的个人选集开始要好得多。
>
> — 附录一 建议阅读书目（L3073-L3085）

## I — 方法论骨架 (Interpretation)

附录一的建议阅读书目是一份「值得你花时间」的经典清单：入选的书超越大多数读者的水平，「会强迫大部分读者作心智上的成长」。它不是课程表，也不附完成期限。使用原则有五条：

1. **从最感兴趣的书开始**——不论基于什么理由，这是最聪明的做法。
2. **不必按时间顺序读**——书单按作者出生年代排列，只是「一个时代的演进表」；你可以从最近出版的一本书读起，再回溯到荷马及《旧约》。
3. **读得好，而不是读得广**——读不完不必失望；书单上的书没有特定时间要求；「这是一个你可以从容接受的邀请」，任何时候都可以开始。
4. **诗从好的合选集起步**——读抒情诗从合选集开始，胜过从某一位作者的个人选集开始。
5. **终点是自己拟一份书单**——「当然，最后你还是要自己拟出一份书单，然后全力以赴」；现成书单只是一个可以开始的地方。

三处必须随书单一起说明的已知事实：

- **范围自限**：书单只列西方作品（不含中国、日本、印度），作者自陈理由；并提示：先在自己文化里比较容易理解的书上练好阅读技巧，再攻异文化经典。
- **星标利益关联**：凡作者主编的《西方世界的经典名著》（一个星号）与《名著入门》（两个星号）收录的作品会被特别标示——读星标时应当知道这是作者自家主编的丛书。
- **入选标准**：超越多数读者水平、能强迫心智成长——正因此它们适合当练习阅读技巧的目标（p501）。

书单中特别了不起的作品「每次你重读，都会发现许多新的想法」，是「可以一读再读，永不会厌倦的」；作者说这样的伟大作品「任何一个人要去荒岛，都该带着这些书一起去」（c501）——正好与 `choosing-books` 的荒岛十书测验接得上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 抒情诗从合选集开始（帕尔格雷夫与马克·范多伦）
- **类型**: 书中转述（附录一）
- **问题**: 读抒情诗该从哪一种选本入门
- **方法论的使用**: 作者建议从好的合选集开始（胜过某一位作者的个人选集），推荐帕尔格雷夫《英诗金库》及《牛津英诗选》为最好的入门书；现代增补如塞尔登·罗德曼《现代诗一百首》；马克·范多伦《诗歌入门》兼收短论，谈如何阅读许多有名的抒情诗
- **结论**: 书单中抒情诗作者少并非偏见——「读诗，我们认为从一本好的合选集开始阅读，会比从某一位作者的个人选集开始要好得多」
- **结果**: 未说明

### 案例 2: 书单只列西方作品的三个理由
- **类型**: 书中转述（附录一）
- **问题**: 为什么书单不包括中国、日本或印度的作品
- **方法论的使用**: 作者自述三个理由：对西方传统以外的文化并不十分在行，建议不会有什么分量；东方并非单一传统，须通晓所有东方文化才能将书单拟好；「在你想要了解其他世界的文化之前，应该要先了解自己的文化」
- **结论**: 选书范围是作者自限、承认有偏见；并用《易经》《薄伽梵歌》之例说明：应先在自己文化中较易理解的书上练好阅读技巧，再攻异文化经典
- **结果**: 未说明

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到一份「必读经典」长书单，不知从哪本开始
2. 想从书单第一部（荷马）硬啃却读不动，怀疑自己不适合读经典
3. 想按兴趣选起点、甚至从当代作品回溯着读
4. 想读诗，纠结选个人选集还是合选集
5. 想建立属于自己的终身书单

### 语言信号

- 「这份书单该从哪本开始读」
- 「书单太长了，读不完怎么办」
- 「是不是必须按年代顺序读」
- 「有没有公认的好书单可以直接用」
- 「读不动荷马，能不能从更近一点的书开始」
- 英文: "reading list", "where do I start", "classics reading order"

### 与相邻 skill 的区分

- 与 `choosing-books` 的区别: 选书卡管单本书的价值分层（金字塔）与重读判定；本卡管现成书单的使用原则与自拟终点——现成书单只是选书素材之一，自拟才是归宿

## E — 可执行步骤 (Execution)

1. **选起点**
   - 完成标准: 从最感兴趣的书开始，而非从年代第一本开始；允许倒序（可从最近出版的一本回溯到荷马及《旧约》）
   - 输入契约: 一份现成书单（如附录一）或用户自述的兴趣方向
2. **调预期**
   - 完成标准: 明确「读得好胜于读得广」、无完成期限、读不完不失望——把书单当「可以随时开始的邀请」而非挑战
3. **读诗分支**
   - 完成标准: 抒情诗选择好的合选集起步（如《英诗金库》《牛津英诗选》），而不是某位作者的个人选集
4. **解码星标**
   - 完成标准: 识别一个星号 =《西方世界的经典名著》、两个星号 =《名著入门》；一并登记其利益关联（作者主编）
5. **范围自觉**
   - 完成标准: 明示书单只含西方作品；若目标含异文化经典，先在本文化较易理解的书上练技巧
6. **自拟书单**
   - 完成标准: 产出自己的书单，并能为每本书说明选择理由（不只照抄推荐清单）
   - 输出契约: ①起点与阅读顺序 ②个人书单（含理由）③对星标/范围的说明（如用到附录一书单）
   - 判停条件: 不要把「读完书单」当完成标准（书单没有特定时间要求）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把长长的书单当作待办清单与考核指标（ce501：以「读完了多少本」计分，反而违背「读得好而不是读得广」）
- 被年代顺序绑住、从最古的荷马开始硬啃（ce502：读不动就放弃整份书单）
- 只借别人的书单、不自己拟一份、也不建立自己的选书标准（ce503）
- 未练好自己文化里的书就去攻异文化经典（ce504：困难被叠加——书本身难＋阅读技巧未练）

### 作者在书中警告的失败模式

- ce501 必读挑战心态：为难、焦虑、以数量计分；正确心态是「从容接受的邀请」
- ce502 年代顺序误读：书单只是「时代的演进表」，阅读顺序可以随意（甚至倒过来）
- ce503 停留在借用现成书单：不去发现对自己有特殊价值的书
- ce504 一上手就攻《易经》《薄伽梵歌》这类最难的外文化经典：既读不懂也学不到技巧

### 作者的盲点 / 时代局限

- 书单只列西方作品、作者承认存在偏见（L3083：「我们承认自己是有些偏见」）——使用者必须知其所限
- 星标指向作者自己主编的两套丛书，存在利益关联（p504 须一并说明，不得只解码不声明）
- 书目正文（各条书目与版本）未逐条核编（NR-06）——**本卡只蒸馏「使用原则」，书单正文不蒸馏（低价值区）**
- 「值得一生阅读的书单」的说法依赖西方正典语境；对非西方读者，起点与次序判断需自行校准

### 容易混淆的邻近方法论

- `choosing-books`: 那是「读哪些书、每本投多少精力」的分层判据；本卡是「现成书单怎么用、自拟怎么收尾」的接口卡
