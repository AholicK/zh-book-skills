# 判断作者的主旨：规则六七八

## R — 原文 (Reading)

> 第六个规则可以说是：将一本书中最重要的句子圈出来，找出其中的主旨。……
> “用你自己的话来说”，是测验你懂不懂一个句子的主旨的最佳方法。如果要求你针对作者所写的某个句子作解释，而你只会重复他的话，或在前后顺序上作一些小小的改变，你最好怀疑自己是否真的了解了这句话。……
> 你能不能举出一个自己所经历过的主旨所形容的经验，或与主旨有某种相关的经验？
>
> — 第九章 判断作者的主旨 · 句子与主旨（L1241）；找出主旨（L1281、L1293）

## I — 方法论骨架 (Interpretation)

分析阅读第二阶段（诠释一本书的内容）的第 6–8 条规则，处理「句子与论述说了什么」。核心区分：**句子是文法单位，主旨与论述是逻辑单位（思想与知识的单位）**（g16）。

- **规则六：圈出最重要的句子，找出其中的主旨。** 关键句有两条定位线：读者视角——需要花一点努力来诠释的句子（第一眼不能完全理解）；作者视角——阐述其肯定／否定判断及其理由的句子（p143/p144）。欧几里得、阿奎那会把主旨写在明处，读者仍须自己处理（ce136）。
- **两个测验（主旨是否真懂的验收口）：** ①「用你自己的话来说」——用完全不同的用语说出同样的意义；只会重复原句或小改语序，说明拿到的只是「字」而不是「思想」（L1281／ce140）。②举出例子——自己经历过的相关经验，或就特例说明通则；举不出例子，就要怀疑自己并不懂（L1293／ce141）。
- **一个句子可以含有多个主旨**（《君主论》复合句示范）：拆开才能「同意一部分、不同意另一部分」（ce135）；反过来，同一主旨也可由不同句子表达（c123 租约例）。
- **规则七：找出并重新架构论述。** 论述＝一系列先后有序、部分带有例证与理由作用的主旨（g17）；不是段落——段落长短无定则，论述可跨段、也可小于一段（ce145）。先找现成的论述段落；没有表达出来的就自己从相关文句建构（纸上列出或页边编号，p149/p150）；先见结论找理由、先见理由找结论（p151）；区分归纳（特殊事实→共通概念）与演绎（通则→更进一步的共通概念）（p152）；标出前提的三种身份：双方同意的假设、可证实的主张、不需证实的自明之理（p153）。
- **规则八：找出作者的解答。** 回到规则四的问题清单逐问盘点：哪些解决了、哪些没解决、哪些是作者自知未解决的；为解决旧问题又提出了什么新问题（f115/p154）。完成它，才具备与作者辩论的资格。
- **贯穿的失败态：口语主义**——使用文字而没有体会其中的思想传达（g18）；两个测验就是它的检测仪。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《君主论》：一个复合句里的两个主旨
- **类型**: 书中演练（第九章）
- **问题**: 一个文法上的单一句子能不能表达多个主旨（规则六的拆解动作）。
- **方法论的使用**: 作者取马基雅维里《君主论》的复杂句示范：「一个君王就算无法赢得人民的爱戴，也要避免憎恨，以唤起人民的敬畏；因为只要他不剥夺人民的财产与女人，他就不会被憎恨，也就可以长长久久地承受人民的敬畏。」分号与「因为」把它分段，拆解后至少含两个主旨——（1）以敬畏代替爱戴；（2）要避免被人民憎恨，就不要去剥夺人民的财产与女人。
- **结论**: 除非能在一个复杂句中辨认出不同的主旨，否则无法判断作者在谈些什么；拆开后才能分别同意或不同意其中某一点。
- **结果**: 未说明（示范性拆解）。

### 案例 2: 形上学主旨：即席翻译与举例测验
- **类型**: 书中演练（第九章）
- **问题**: 怎样才算真正抓到一个主旨（两个测验的示范）。
- **方法论的使用**: 以形上学基本主旨「除了实际存在的事物，没有任何东西能发生作用」试学生：先要求用不同的句子说出同样的意义（即席翻译），学生多半只能完美地重复原句；再要求举例——能说出「只靠可能会下的雨滴，青草是不会滋长的」或「只靠可能有的储蓄，一个人的存款账目是不会增加的」，才算真的抓到了主旨。
- **结论**: 完美复述只是拿到字句；能翻译、能举例，才表示抓住了思想。
- **结果**: 书中称，学生多半重复原句无法翻译，只有能举例者才算真的抓到主旨；此例成为两个测验的正式示范。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读完一本书却说不清作者到底主张什么，只能用「他说了……」含糊带过
2. 要引用或转述作者观点去写东西，怕只抄字句、没懂思想
3. 读长句、复杂句时理不清里面装了哪些主张
4. 读完不知道作者解决了哪些问题、留了哪些没解决
5. 怀疑自己的「懂了」只是背下来了，想要一个可重述、可举例的检验

### 语言信号

- 「每个字都认识，连起来不知道在说什么」
- 「他到底主张什么？——我得翻原文才能说」
- 「这几句话谁支持谁、结论在哪」
- 「我怎么知道自己是真懂了还是背下来了」
- 「能不能帮我把他这一章的论证理出来」
- 英文: "say it in my own words", "what's the argument", "what did the author actually claim"

### 与相邻 skill 的区分

- 与 `shared-meaning` 的区别: 先定关键字词义（该卡），再抓主旨与论述（本卡）；共识没完成就做本卡，会建立在错位理解上
- 与 `x-ray-the-book` 的区别: 该卡给全书骨架（第一阶段），本卡在骨架里填充主旨、论述与解答（第二阶段）
- 与 `rules-overview` 的区别: 总表收拢规则 5–8 的编号与验收口径；执行细则在本卡
- 与 `practical-books` 的区别: 实用书的规则四／八有变体（问「他要你做什么、凭什么」、赞同即行动），由该卡承接
- 与 `fair-criticism` 的区别: 评论要先说「我了解了」——这个前置条件在本卡完成；本卡不处理同意／不同意
- 与 `imaginative-literature` 的区别: 论说 vs 文学两套读法互斥——读文学时不找共识、主旨与论述（否定三指令），转该卡

## E — 可执行步骤 (Execution)

1. **圈出关键句**
   - 完成标准: 每条关键句注明定位理由——「第一眼读不懂／需要努力诠释」（读者视角）或「承载作者的肯定／否定判断及其理由」（作者视角）；借作者提示（划线、欧几里得式定义定理、阿奎那式提问结构）与已圈关键字引导（f112/p143/p144）
   - 输入契约: 一本已完成规则五（关键字与共识）的论说性作品
   - 判停条件: 说不出哪些句子需要慢读→按 ce137/ce138 自检：全书匀速＝所有内容都同等不重要

2. **抓主旨并过两个测验**
   - 完成标准: ①用自己的话（完全不同的用语）复述该句主旨；②举一个例子／经验（真实的或虚构的均可；科学类主旨可能需实验等特殊经验）；两个测验都过才算抓住（f113/p145/p146）
   - 输出契约: 「关键句 → 自述主旨 → 例证」三列清单
   - 判停条件: 复述只能背原句或小改语序→口语主义警报（ce140/ce142），重读该句，不往下走

3. **拆复合句**
   - 完成标准: 一个句子含多个主旨时逐条拆出，使你能分别同意或不同意（《君主论》示范）；注意分号、「因为」等文法标记给出的分段线索
   - 判停条件: 冒出「全对／全错」的二选一冲动→回看该句是否其实含多个主旨（ce135）

4. **规则七：找出并重新架构论述**
   - 完成标准: 优先找书中现成的论述段落；没有表达出来的，就从相关文句中自建——纸上列出全部主旨，或用页边编号标出应排序而读的句子（p149/p150）；结论与理由双方向找齐，并标注归纳／演绎类型与前提身份（假设／可证实／自明之理，p151-p153）
   - 输出契约: 论述骨架（结论＋理由链＋前提清单＋类型标注）
   - 判停条件: 作者对最可能被质疑的一环含糊带过→标记「未言之语」但不要替作者补全（ce146）；也不要要求每个前提都被证实（ce148）

5. **规则八：解答盘点**
   - 完成标准: 对照规则四的问题清单逐问判定——已解决／未解决／作者自知未解决（并记录为解决旧问题提出的新问题）（f115/p154）
   - 输出契约: 三分类问题解答清单
   - 判停条件: 完成本步才可进入评论类 skill（`fair-criticism`）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只背原句的「口语主义」：复述流利但换不了说法、举不出例子（ce142/ce143）——本卡的两个测验会直接检出这类「假理解」
- 把段落当论述单位：逐段找「这段的论述」，在只有证据细节的段落里会落空（ce145）；论述是逻辑单位，可跨段、可小于段

### 作者在书中警告的失败模式

- ce134：认为语言与思想一对一（字与义的纽扣／纽扣洞比喻被当成真实关系）
- ce135：在复杂句里辨认不出多个主旨；ce136：不注意书中已标明的重点句子；ce137：全书同一速度读；ce138：在错误的地方暂停（为兴趣句而非困扰句停留——读古书的最大障碍）
- ce139：提不出问题，却指望书给新视野
- ce140：只用原文重复来「解释」主旨；ce141：举不出例子／说不出与经验的关联
- ce142：口语主义——玩弄文字、背诵文字；ce143：自满复述却说不清主旨；ce144：看不出不同字句是同一主旨，无法作跨书比较
- ce145：把段落当论述单位；ce146：跟着演说家／宣传家的未言之语走（接受被省略、会被质疑的前提）
- ce148：想证实每一个主旨，于是无从开始——论述必有开端（假设或自明之理）

### 作者的盲点 / 时代局限

- 规则八细则最薄：只有一小段正文、无操作示例；解答盘点的记录格式由使用者自定（原书未给）
- 规则七的前提清点只给三类（假设／可证实／自明之理），没有判别算法——遇到难分的前提按自己的判断标注并说明理由（原书未给，需使用者自定）
- 《君主论》等引文在转档中自带省略（原文如此）——复述与拆解时须回源核对原句

### 容易混淆的邻近方法论

- `fair-criticism`: 理解完成（做出「我了解了」的判断）之后才可以评论；本卡是第三阶段评论的启动条件
- `shared-meaning`: 规则五（关键字共识）是本卡前置——先定字义，再抓主旨与论述
