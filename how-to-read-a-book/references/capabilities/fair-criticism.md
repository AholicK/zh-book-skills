# 公正地评断与赞同/反对（规则九至十五：四批评点与举证义务）

## R — 原文 (Reading)

> 在你说出“我同意”，“我不同意”，或“我暂缓评论”之前，你一定要能肯定地说：“我了解了。”上述三种意见代表了所有的评论立场。
>
> ……
>
> 在读者说出：“我了解，但我不同意。”之后，他可以用以下的概念向作者说明：（1 ）你的知识不足（uninformed）。（2）你的知识有错误（misinformed）。（3）你不合逻辑——你的推论无法令人信服。（4）你的分析不够完整。
>
> ……
>
> 如果你说你读懂了，而你却找不出证据来支持前面任何一个批评点的话，这时你就有义务要同意作者的任何论点。
>
> — 第十章 公正地评断一本书 · 暂缓评论的重要性（L1427）；第十一章 赞同或反对作者 · 偏见与公正（L1553）、判断作者论述的完整性（L1595）

## I — 方法论骨架 (Interpretation)

评断阶段（规则九至十五）只解决一个问题：**什么时候、以什么方式，你才有资格对一本书开口**。次序是硬性的——先听懂，再说「我了解了」，最后才轮到表态；同意、不同意、暂缓评论三种立场并列，都要花心力判断；暂缓评论也是一种评论（「还没有被说服」的立场）。把评论等同挑毛病，是最常见的误解。

- **规则九（暂停键）**：说不出「我了解了」就不要评论。「我懂了」要迟疑着说——大纲与诠释没完成，批评就建在流沙上；「我不懂」也是重要评断，但要在尽过最大努力之后说，且理由在书不在你。
- **规则十（姿态）**：不同意时理性表达，不为赢而辩——「赢」只在于增进知识，不在把对方打败；必须同意作者时不要难过（难过即好辩已深）。
- **规则十一（证据）**：评断前先找出理论基础，区分「有证据支持、可辩护的知识」与「没有理论支持的个人意见」；不把讨论退化成「各持己见」的乒乓球赛。
- **四批评点（许可清单）**：说「我了解，但我不同意」之后，只有四种可说的声明——知识不足 / 知识错误 / 不合逻辑（缺乏连贯或前后矛盾）/ 分析不完整。四点彼此独立、不互相排斥，可单用也可全用。
- **举证义务（硬纪律）**：找不出前三点的证据，你就**有义务同意作者的任何论点**——「前提没错、推论也没问题，但我就是不同意」不成立，那只是「我不喜欢」。第四点不能作为反对全书的根据：只能在同意其余部分时，据此「暂缓评论」。

判停点：凡是想开口评断而起点不是「我了解了」，都先退回去完成理解（见 `propositions-and-arguments`）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 「所有人生而平等」：误解与不同意之辨
- **类型**: 书中演练（第十一章）
- **问题**: 「所有人生而平等」这句话，该同意还是不同意？
- **方法论的使用**: 作者先演示第一种「不同意」：若把话理解为「人生而具有的智慧、力量与其他能力都相同」，双方会据事实观察表示不同意——但这是**误解**；澄清为「政治权利平等」之后，误解式的不同意就毫无意义。等误解被纠正，真正的议题才出现：可以同意，也可以不同意。
- **结论**: 只有双方都了解对方所说的内容时，关于事实或方向的议题才是真实的议题；与作者达成共识之后，才可以决定同意他的论点，或是不同意他的立场。
- **结果**: 书中结论（演示性讨论，无事件后续）

### 案例 2: 知识不足的例子：达尔文缺遗传学、休谟缺区别
- **类型**: 书中转述（第十一章）
- **问题**: 「知识不足」这个批评点，怎么才算成立？
- **方法论的使用**: 作者转述两例——达尔文缺乏基因遗传学的知识（由孟德尔及后继者研究证实），《物种起源》最大的缺点就是他对遗传机能的知识一无所知；18 世纪休谟对人的想象与思想的区别一无所知，而早期的哲学家早已建立起这个概念。两例演示批评点（1）的举证要求。
- **结论**: 说一位作者知识不足，就是说他缺少某些与他想要解决的问题相关的知识——知识必须确实相关、并能说明如何影响结论，否则没有理由作这样的评论。
- **结果**: 未说明

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读完一本书（或一篇报告）想表态，不确定自己的「不同意」站不站得住脚
2. 要写书评、做批判性汇报、参加读书会，需要一个有纪律的评断流程而不是吐槽
3. 看到别人的批评（书评、讨论帖），想判断：这条批评有没有先理解、有没有举证
4. 被「你的前提没错、推论也没问题，但我就是不同意」式的分歧困住，想弄清这到底是什么
5. 想说某本书「不完整」「视野有限」，想确认这个批评能不能成立

### 语言信号

- 「我就是不同意，但说不出哪里不对」
- 「这本书不行 / 写得很烂」（说不出证据的否定）
- 「反正我不喜欢这个结论」
- 「他根本没读懂就开始骂」
- 「说得头头是道，但全是个人意见」
- 英文: "I just don't buy it", "the book is flawed"（无举证）, "agree to disagree"

### 与相邻 skill 的区分

- 与 `propositions-and-arguments` 的区别: 那张卡生产「我了解了」（一句话主旨、论述与两个测验）；本 skill 从「我了解，但不同意」开始——它是本卡的前置，不是替代。
- 与 `rules-overview` 的区别: 总表把第三阶段条目按编号收拢供审计；本卡是第三阶段的可执行版——引用编号之前先回本卡核对举证要求。
- 与 `reading-history` 的区别: 历史读物有自己的批评变体（不够逼真 / 误用资料）；评历史书先用那张卡分诊，不要用通用四批评点直接覆盖。

## E — 可执行步骤 (Execution)

1. **前置自检：确认「我了解了」**
   - 完成标准: 能用一句话说出全书主旨、能用自己的话复述主要论述；两项都说不出 → 转 `propositions-and-arguments` 补课，不得开始评断
   - 输入契约: 一本已读完的书 + 你的立场倾向（同意 / 不同意 / 暂缓）
   - 判停条件: 只读了部分、或本书与作者其他著作互文（《诗学》型）时，先按 `auxiliary-reading` 处置并注明「评论必须更慢举起」

2. **绑定立场，禁止跳步**
   - 完成标准: 立场在三者中明示其一；「暂缓评论」要写出哪些部分尚未被说服；「同意」也要给出理由（分享同样的理论）

3. **不同意时：写出四批评点及证据**
   - 完成标准: 每个使用的批评点都附可复核的证据——（1）知识不足: 阐述所缺的知识、与问题的关联、若有该项知识结论会怎样不同；（2）知识错误: 说明事实，或提出比作者更有可能性的相反立场；（3）不合逻辑: 例举精确证据，指明「缺乏连贯」或「前后矛盾」；（4）分析不完整: 精确指出未解决的问题 / 未善用的资料 / 未看出的含意
   - 输出契约: 立场 + 批评点清单（注明编号）+ 每点的证据；第四点单独标注「仅用于暂缓评论」

4. **刹车检查：无证据 → 义务同意**
   - 完成标准: 若前三批评点都给不出证据，把结论改为「同意作者（至少同意一部分）」；删除「前提、推论都对但我就是不同意」式表述（那是情绪或偏见，不是反对）

5. **姿态校准（推荐）**
   - 完成标准: 评断文本中不含动机揣测与优越感；对照理想辩论三条件（控情绪 / 摊开自己的前提 / 不偏不倚）逐条自检

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无理解的评断（ce205/ce208）：没做完前两个阶段、说不出「我了解了」就表态——「毫无理解便同意只是愚蠢，还不清楚便不同意也是无礼」
- 把评论等同挑毛病（ce206）：评论含同意、不同意、暂缓评论三种立场；只找茬、不表态，都丢了评断的一半
- 无证据的反对（ce227）：找不出前三批评点的证据还想反对——那不是反对，是你「不喜欢」

### 作者在书中警告的失败模式

- 受教与卑躬屈膝混为一谈（ce203）：把「不批评」当礼貌，读者放弃独立判断——受教是极为主动的美德，最能学习的读者也就是最能批评的读者（须合读 g19）
- 不懂就同意（ce205）：同意与不同意一样要花心力判断，不表态不是安全选项
- 评论=挑毛病（ce206）：许多人将评论与不同意混为一谈——连「建设性」的批评也是不同意；同意也需要被表态
- 没读就发难（ce208）：「我不知道你在说什么，但我想你错了」——唯一应对是请对方重述论点，重述不出来即说明他并不了解
- 轻易说「我懂了」（ce210）/ 没尽力就怪书（ce211）：「我懂了」要迟疑着说；「我不懂」要在尽过最大努力之后、理由在书不在你时说——在好书上读不懂，通常是读者的错
- 未读他书就评断（ce212）：《诗学》《国富论》《共产党宣言》这类须合读作者其他著作的书，要「更慢地举起评论的长矛」
- 为反对而反对（ce213）/ 书房里的廉价胜利（ce214）：把谈话当战争、翻几页就判人输——对话没有对手在场阻止胜负，读者才要自己加上「依据事实」的约束
- 都是观点（ce216）：以「各持己见」终结讨论；乒乓球赛式交谈没人是赢家——若沟通是为增进知识，此立场必无收获
- 知识 vs 个人意见不分（ce217）：把书当传记读、评人不评书——不区分两者，就找不出不同意见的理由
- 理解后不能不同意（ce220）：把一切分歧归因于误解——双方都了解之后，关于事实或方向的议题才是真实的议题，此时仍可不同意
- 找不出证据却不同意（ce227）：「前提都没错，推论也没问题，但我就是不同意你的结论」——此时你唯一能说的可能只是「不喜欢」这个结论：情绪或偏见，不是反对
- 万能「不完整」（ce228）：「人是有限的……任何工作也都是有限的」——不精确指认问题点，这个评论毫无意义，也不能作为反对全书的根据

### 作者的盲点 / 时代局限

- 理想辩论三条件（控情绪 / 摊前提 / 去派性）作者自认只能做到近似——「我们发现自己也会攻击一本书，而不是在评论」（f206/ce225）：这是规范性理想，不是可完全执行的操作
- 「如何在真实书里找可举证的批评点」原书未给检索方法（原书未给，需使用者自定）；举证是硬义务，检索路径要自己搭
- 受教的美德须合读 g19 才完整：受训练不等于受教——引用评断纪律时，不要把「谦虚受教」写成「不要质疑作者」

### 容易混淆的邻近方法论

- `propositions-and-arguments`：跳过理解直接套四批评点，就是在犯规则九——两卡的完成标准不可合并
- `reading-history`：历史阅读的批评标准与通用四批评点不是一套，评历史书先分诊
