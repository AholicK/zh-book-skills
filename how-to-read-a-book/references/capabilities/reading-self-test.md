# 附录二：四层次练习与测验（自测系统）

## R — 原文 (Reading)

> 我们建议你花十分钟（速度是这个阶段的基础）有系统地浏览整个目录之后，再回答问题。然后我们要你再粗浅地阅读一次目录——大约要花二十分钟——再回答更多问题。
> ……
> 对这四个问题，我们在答案栏没有附上解答。答案在书的本身。……这不只是因为分析阅读是个工作，而且是个很孤独的工作。读者是一个人在阅读一本书，基本上，除了他自己的思想外，没有其他的帮助资源。
>
> — 附录二 四种层次阅读的练习与测验 · 第二个阅读层次的练习与测验：检视阅读；第三层次阅读的练习与测验：分析阅读（L4071；L4501-L4503）

## I — 方法论骨架 (Interpretation)

附录二是一套自测系统：为四个阅读层次各配练习材料与问题，读者可以自己做，也可以像读书会一样做小组练习。材料与结构：

- **基础阅读**：密尔与牛顿的传记短文（约 1200 字），用舒服的速度读（约六到十分钟）＋圈点笔记＋答题；有些题需要文章之外的背景知识。
- **检视阅读**：《神曲》与《物种起源》的目录当全书读——先花十分钟有系统地浏览（预读/略读）答第一组问题，再花二十分钟粗浅阅读答更多问题，共三十分钟。
- **分析阅读**：材料就是本书本身——用四个基本问题与十五个规则自答；答案栏不附解答，「答案在书的本身」。
- **主题阅读**：《政治学》第一卷与《社会契约论》第一编的节文，主题为「自然与原始的国家」；速度不重要，可做笔记、划线、反复重读，先答各自立场题、再答对照题。

使用纪律（判据）：

- **核对方式**：先自己作答，再看答案栏；对答案有疑问必须回原文找来源（作者明说：试试看能不能从亚里士多德或卢梭中，找到我们提供答案的来源）。
- **答案的宽容度**：答案栏出现「选（c）我们也算你是对的」「选（a）也并非全错」这类口径，反映的是问题本身的模糊度——正确性取决于问题表述的精确度，须回到文本理解，而不是背答案。
- **练习目的**：让读者熟悉阅读技巧，而不是评定能力；作者明令这类测验不得用作评分或雇用依据。
- **情绪管理**：答不出不要恼怒——「最好的答案就在书的本身」，答不出正是对全书作进一步研究的入口；主题阅读部分「要走很多冤枉路」，灰心是过程常态而非失败信号。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《神曲》目录的三十分钟检视
- **类型**: 书中演练（附录二）
- **问题**: 怎样实操检视阅读的两个步骤（预读/浏览 + 粗浅的阅读）
- **方法论的使用**: 把《神曲》全目录当作全书来读——先花十分钟有系统地浏览整个目录后答第一组问题，再花二十分钟粗浅地阅读一次目录、答更多问题，共三十分钟
- **结论**: 作者称这三十分钟虽粗浅（「学者一生花了三十年」），但一个人确实能对这本书有相当多的了解，甚至带引读者对全书做分析阅读
- **结果**: 未说明

### 案例 2: 分析阅读四问自答：答案栏不附解答
- **类型**: 书中演练（附录二）
- **问题**: 用四个基本问题（整本书谈什么／细节如何说明／有没有道理／与我何干）与十五个规则检视本书
- **方法论的使用**: 答案栏对这四问不附解答——「答案在书的本身」；因为分析阅读是一个很孤独的工作，读者除了自己的思想外没有其他帮助资源
- **结论**: 作者借机自曝本书两处不完整（基础阅读谈得少、主题阅读说得不够）；个别阅读问题须读者自己解决
- **结果**: 未说明（书中明确不提供答案：答案在书的本身）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 学完四层次方法后想练手，却没有练习材料
2. 组织读书会/共读，需要现成题库与答案
3. 想检验自己的检视阅读或分析阅读水平
4. 想用「三十分钟检视一本作品」的方式快速认识一本书
5. 遇到有人拿阅读测验分数做评分/招聘决定，需要边界警示

### 语言信号

- 「有没有练习题和答案」
- 「怎么检验自己学到了没有」
- 「读书会需要一套现成的题目」
- 「这份阅读测验可以用来评估学生/员工吗」
- 英文: "reading test", "practice questions", "reading assessment"

### 与相邻 skill 的区分

- 与 `inspectional-reading` 的区别: 检视卡给方法与六步；本卡提供配套练习材料与节奏（《神曲》目录：十分钟浏览＋二十分钟粗读），并附答案核对法
- 与 `syntopical-reading` 的区别: 主题卡是方法本体与五步骤；本卡提供主题练习的现成材料（《政治学》《社会契约论》节文）与「回原文找答案来源」的核对纪律

## E — 可执行步骤 (Execution)

1. **选层与备料**
   - 完成标准: 按要练的层次取材料（基础=密尔/牛顿传记；检视=《神曲》或《物种起源》目录；分析=本书；主题=两篇节文）
   - 输入契约: 想练的阅读层次；缺材料时给出上述对应出处
2. **读与记**
   - 完成标准: 基础按舒服速度＋圈点笔记（约六到十分钟／1200 字）；检视按「十分钟系统浏览 → 答题 → 二十分钟粗读 → 答更多题」；主题不限时、可反复重读并划线笔记
3. **作答**
   - 完成标准: 先自己作答、不翻答案；分析阅读四问必须自答（没有人会替你回答）；多选题「把所有你觉得好像正确的答案都选出来」——含文章明说与隐含的、以及你已有的背景知识
4. **核答与回源**
   - 完成标准: 对照答案栏；凡有疑问或不同意见，回原文（或注明的译本）找到答案来源；遇到「选…也算对」的题，回到文本理解问题表述的精确度
5. **结果处置**
   - 完成标准: 答不出的题转为「对全书作进一步研究」的入口；不得将分数用于评分/雇用；对主题部分答案仍有疑问者，可真正做一次主题阅读
   - 输出契约: ①各层作答记录 ②与答案栏的差异清单及回源核对结果 ③（可选）进一步研究清单
   - 判停条件: 检视练习的三十分钟不等于读完整本作品（ce522）；只读目录不足以回答深层问题（ce512）——答不出即转为分析阅读的入口

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把测验结果用于评分、学生评估或雇用机会（ce505 明令禁止：没有科学标准、有文化歧视性、不能预期学业或事业成功、常包含一个以上的「正确」答案）
- 用零散片段替代整书练习（ce506：一般测验文章为出题拼凑、互相无关；本附录选材刻意不同——「实际上也值得一读」）
- 机械对答案（ce518：答案宽容度反映问题本身的模糊度，应回原文核对而非背诵答案）

### 作者在书中警告的失败模式

- ce507 答不出题就恼怒、认为题目不公平（应借此对全书作进一步研究）
- ce508 指望别人替自己回答四个基本问题（把最核心的练习外包；分析阅读是孤独的工作）
- ce512 只读目录就宣称能回答深入问题（检视阅读有明确的功能边界）
- ce518 只记答案不查原文，把「选对」当作理解了文本
- ce522 把三十分钟检视当作读完整本书（「考虑到一些学者一生花了三十年的时间在《神曲》上……实在是很粗浅的」）
- ce523 把答案栏当权威而不是核对起点（作者要求读者挑战答案并回原著取证）
- ce524 因主题阅读过程漫长、分析模糊而灰心放弃（「要走很多冤枉路」是过程常态）

### 作者的盲点 / 时代局限

- 分析阅读四问不附答案（L4501「答案在书的本身」）——须自答，且没有评分标尺
- 答案栏简短晦涩是故意设计（p511：为刺激回想）；要求回原文核对（p517）
- 部分题目依赖背景知识（p510/p513），对背景不足的读者不公平——作者以「素养越好，读得越好」提示，未给补救路径
- 作者自认主题阅读部分说得不够（p517：「关于主题阅读，我们说的还不够」）；这套测验也不能替代正式标准测验

### 容易混淆的邻近方法论

- `inspectional-reading`: 练习材料就是检视阅读两步骤（预读＋粗浅通读），但练习≠方法本身——方法在该卡
- `syntopical-reading`: 主题练习材料与核对方法是本卡内容；方法本体与五步骤在该卡
