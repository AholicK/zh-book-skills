# 如何阅读实用型的书（两问、行动义务与雄辩觉察）

## R — 原文 (Reading)

> 当你在阅读任何一种实用书时，一定要问你自己两个主要的问题。第一：作者的目的是什么？第二：他建议用什么方法达到这个目的？
>
> ……
>
> 行为规则要谈得上是真理，有两种情况：一是真的有效；二是这样做能带引你到正确的结果，达到你的期望。
>
> ……
>
> 在评断一本实用性的书时，所有的事都与结果及目标有关。
>
> ……
>
> 赞同一本实用性的书，却确实需要你采取行动。
>
> — 第十三章 如何阅读实用型的书 · 两种实用性的书（L1879、L1883）、说服的角色（L1887）、赞同实用书之后（L1915）

## I — 方法论骨架 (Interpretation)

实用书的阅读从一句冷静的话开始：**任何实用性的书都不能解决它关心的实际问题**——实际问题只能靠行动解决，书本只能帮助你。因此读任何实用书先问两句：作者的目的是什么？他建议用什么方法达到这个目的？原理型书（经济 / 政治 / 道德巨著）比规则型书更难回答，但想了解与评论就必须回答。

- **两类实用书**：规则为主（主旨即规则，多为命令句，可与叙述式互改，「及时一针，胜过事后九针」）与原理为主（要读出言外之意——由原理衍生出未明说的规则，再找出它如何实际应用）。判读要点：「无法让一本实用的书被实用地阅读，就是失败的阅读。」
- **四问的变体**：问一基本不变；规则四改为「找出作者想要你做什么」、规则八改为「了解他要你这么做的目的」；问三重点转为能否接受作者的宗旨——他最终的目标，加上他建议的方法；问四全部改变——赞同实用书需要采取行动。
- **评断的靶心是结果与目标**：行为规则要谈得上是真理，一是真的有效，二是能带引你到正确的结果、达到你的期望；若目标是你不关心或不期望的，方法再真实有用也毫无兴趣（马克思 / 柏克例）。判断「主要是与结果达成共识，而非方法」。
- **雄辩是特性，不是恶意**：每本实用书都混杂雄辩或宣传——作者必须激起情绪反应、左右意志来引导你接受结论与方法。读懂的表现之一，就是掌握基本共识 / 主旨 / 论述，从而指出「情绪用字」、对诉求有抵抗力；但不能走到「完全不接受所有诉求」（那就不必读实用书了）。
- **作者性格更重要**：实用书要说服人行动，作者的性格与处境影响其目的与方法——读《政治学》须知希腊奴隶制背景，读《君主论》须知马基雅维里与美第奇家族的关系，读《利维坦》须知英国内战。

判停点：赞同的检验是行动——接受结论与方法却不行动，说明实际上并未真正同意。

## A1 — 书中的应用 (Past Application)

### 案例 1: 「及时一针，胜过事后九针」：规则句的命令式与叙述式
- **类型**: 书中演练（第十三章）
- **问题**: 实用书里的「规则」长什么样、怎么找？
- **方法论的使用**: 作者用谚语演示：规则多用命令句——「及时一针，胜过事后九针」；也可以改写为叙述式的说法——「如果你及时补上一针，就省下后来要补的九针。」两句都在提示争取时间的价值；以规则为主的书，要找寻的主旨就是这些规则。
- **结论**: 认识规则有一个判据——它在建议你某件事是值得做的，而且一定会有收获；命令句与叙述式可以互相改写。
- **结果**: 未说明

### 案例 2: 马克思与柏克：评断实用书要看结果与目标
- **类型**: 书中演练（第十三章）
- **问题**: 一本方法「真实有用」的书，为什么有人接受、有人完全无感？
- **方法论的使用**: 作者用马克思与柏克两种立场演示：若你「不能分享马克思对经济价值的狂热」，他的经济教条与改革措施对你来说就有点虚假或无关痛痒；如柏克般认为维持现状是最好的策略、相信还有比改变资本不平等更重要的事，也不会因方法有效而接受自己不关心的目的。
- **结论**: 评断实用书主要与结果及目标达成共识，而非方法——就算方法非常真实有用，如果所达到的目的是我们不关心或不期望的结果，也不会有半点兴趣。
- **结果**: 未说明

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读一本实用书（经管、理财、育儿、沟通、写作方法论），读完后不清楚自己算不算「读到位」
2. 被一本书说服了却迟迟没行动，纠结这算不算读完 / 到底有没有学懂
3. 读政治、道德、经济类著作，觉得结论可疑，想知道评断这类书的标准是什么
4. 读一本「讲道理」的原理型书，想把它变成可执行的规则
5. 想分辨一本实用书里哪些是道理、哪些是推销 / 宣传话术

### 语言信号

- 「这本书到底想让我做什么」
- 「说得都对，就是做不到」（或：做不到是不是没读好）
- 「读完感觉很热血，但不知道学到了什么」
- 「这种（成功学 / 理财 / 方法论）书可信吗」
- 英文: "self-help book", "how do I put this into practice", "the author is just trying to sell me something", "I agree but I haven't done anything"

### 与相邻 skill 的区分

- 与 `book-classification` 的区别: 那张卡负责判出「这是实用书」（规则一）；本 skill 承接判出之后的读法——两问、行动义务、雄辩觉察。
- 与 `propositions-and-arguments` 的区别: 通用论说阅读的共识 / 主旨 / 论述在那儿；本卡是规则四 / 八的实用书变体，评断标准换成结果与目标。
- 与 `imaginative-literature` 的区别: 完成标准互斥——实用书赞同即须行动，想象文学用不着采取行动；两卡不得混用。

## E — 可执行步骤 (Execution)

1. **判定读物类型（实用 / 理论；规则型 / 原理型）**
   - 完成标准: 能说出判定依据——核心问题是不是「怎样做得更好 / 更糟」；主旨是规则（命令句，可改叙述式）还是原理；拿不准先回 `book-classification` 复核

2. **两问：目的与方法**
   - 完成标准: 写出两句答案——「作者想要（你）做什么」+「他建议用什么方法达到这个目的」；是原理型书时，进一步由原理衍生出未明说的规则
   - 输出契约: 目的-方法对照；原理型书附「原理 → 规则」衍生清单

3. **落地：由规则到自己的特殊状况**
   - 完成标准: 把规则套进自己的具体处境（时间 / 地点 / 资源），产出至少一条自己可执行的行动；「书里没说这种情况怎么办」不作数——须练习特殊判断力、加上自己的想法

4. **辨雄辩：标出「情绪用字」**
   - 完成标准: 找出书中打动情绪、影响意志的段落与用词，能说出「作者在说服我接受什么」；用已掌握的共识 / 主旨 / 论述反照隐藏式雄辩

5. **评断与行动检验：一切与结果及目标有关**
   - 完成标准: 先判断你认不认同作者想要的结果（目标优先于方法）；赞同的检验是行动——接受结论与方法却不行动 = 实际上并未真正同意；按结论适用面处理义务（通用结论人人适用；筛选结论先判断自己是否属于该阶层，不属于则无行动义务）
   - 判停条件: 若完全不接受任何诉求 → 不必读实用书（这是放弃阅读，不是评断的胜利）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把通用读法原样套到所有读物（ce301）：本卡是实用书分支——读小说、诗、数学别硬套两问与行动义务
- 把实用书当药方（ce303）：书只能帮助你，实际问题只能靠行动解决——期待「读完问题就消失」是定位错误
- 拒绝一切诉求（ce308）：对推销全盘抵抗、既不服气也不行动——「那就不必阅读实用性的书了」

### 作者在书中警告的失败模式

- 读完问题没解决（ce303）：笔记做得漂亮却从不实践，问题原封不动
- 找不到针对自己处境的建议（ce304）：实用书作者不能亲身体验读者的特殊状况——规则要配特殊判断力落地，抱怨「书里没说这种情况」就永远用不上
- 失败地读完（ce305）：不把它实用地读——不从原理衍生规则、不落实应用，等于既没了解也不能评论
- 雄辩不自知（ce306）：忽略实用书必然混杂雄辩与说服——「买了一堆货物，却不知道自己买了些什么」
- 隐藏式雄辩（ce307）：未觉察的推销直接打动情绪、不经过头脑——要用共识 / 主旨 / 论述的掌握来反照「情绪用字」
- 不理作者时代（ce309）：用读数学书的方式读政治、道德、经济论著，不查作者的时代与处境
- 赞同却不行动（ce310）：嘴上同意、方法也接受却不行动——实际上并没有同意；「太忙」不是解释

### 作者的盲点 / 时代局限

- 两问无书面模板、雄辩段落无标注格式（原书未给，需使用者自定）
- 「赞同即行动」的义务与想象文学「用不着采取行动」互为对照，不得混用（与 `imaginative-literature` 分诊）
- 示例带 20 世纪中期的性别角色假设（巧克力慕斯例以「男性读者从不进厨房」为前提，c306）——引用时注意语境

### 容易混淆的邻近方法论

- `imaginative-literature`：完成标准互斥——读小说 / 诗时不要把本卡的两问硬套（ce302），那边另有规则
- `propositions-and-arguments`：先走通用规则（共识 / 主旨 / 论述），再做本卡的变体调整——顺序不可颠倒
- `book-classification`：分类判出「实用书」才轮到本卡；原理型书易被误认为理论书，拿不准先回分类复核
