# 透视一本书：规则二三四与大纲

## R — 原文 (Reading)

> 分析阅读的第二个规则是：使用一个单一的句子，或最多几句话（一小段文字）来叙述整本书的内容。……
> 你必须能用几句话，告诉你自己，或别人，这整本书在说的是什么。……
> 除非你遵循规则三——要求你说明组成整体的各个部分——否则就没有办法有效地运用规则二——要求你作全书的重点摘要。
>
> — 第七章 透视一本书（L777、L783）；驾驭复杂的内容：为一本书拟大纲的技巧（L981）

## I — 方法论骨架 (Interpretation)

分析阅读第一阶段（找出一本书在谈什么）的第 2–4 条规则，把「读懂了没有」落成三件可交付物：**一句话主旨、一份分层大纲、一张问题清单**。

- **规则二：一句话说全书。** 用单一句子或最多几句话叙述整本书在谈什么。唯一验收是「说出口」：说得太多说明只看到多样的内容、没看清整体；「我知道但说不出来」连自己也骗不过（ce112）。作者可能在书名、前言或「本书计划」里帮忙，但架构的最后责任在读者，读完才算交卷（p119）。
- **规则三：列出重要部分，说明顺序与关系。** 先拟全书的纲、再拟各部分的纲；通用公式是全书分几部分→每部分分几段→每段分几个重点。用自己拟的纲要读明白，作者章节标题只当指南而非照抄（ce119）。
- **规则三对规则二是绝对必要的检验（L981）。** 没有大纲，一句话摘要只能算「猜对了」；有纲要才能说明摘要「如何」「为什么」得体——像两岁孩子说「二加二等于四」，正确但可能全不知其意（ce120）。
- **规则四：找出作者要问的问题。** 一本书是作者问题（一个或一连串）的答案：先找出主要问题，复杂时列出次要问题并排定先答后答；可套理论性问题与实用性问题的公式清单核对（p122/p123）。只找「作者想表达的问题」，不窥探作者内心——那是意图谬误（ce122）。
- **执行限度：** 规则是理想标准，作出近似草稿就该满足（p116）；只对少数相关的书做精细大纲（p117）；三规则目标同一、合成第一阶段，不得只取一条（p125/p126）；「阶段」是掌握的层次性，不是一遍遍重读的次序（ce124）。

三件交付物齐备并能互相说明，第一阶段的「架构认识」才算完成；说不出口、指不出依据，就回到缺的那一步。

## A1 — 书中的应用 (Past Application)

### 案例 1: 亚里士多德摘要《奥德赛》：情节的真正主干
- **类型**: 书中演练（第七章）
- **问题**: 如何用几句话说出整本书的内容（规则二的示范）。
- **方法论的使用**: 亚里士多德在《诗学》中把《奥德赛》缩成几句话：某个男人离家多年，海神嫉妒他，让他一路尝尽孤独和悲伤；家乡也濒临险境，一些企图染指他妻子的人挥霍他的财富、对付他的儿子；最后他在暴风雨中回来，让少数几个人认出他，摧毁了那些居心不良的人。
- **结论**: 亚里士多德断言这就是情节的真正主干，其他的都是插曲。
- **结果**: 作者称，用这种方式了解故事后，就能把不同情节放进正确的位置。

### 案例 2: 美国联邦宪法：全书最完整的规则三大纲示范
- **类型**: 书中演练（第七章）
- **问题**: 如何为一份组织整齐的文献拟分层大纲（规则三的完整示范）。
- **方法论的使用**: 作者把美国联邦宪法拟为八条主要归纳——前言（声明目的）→立法→行政→司法→联邦与州的关系→宪法修正案→人权宣言→后续修正案；再示范将第一条细分「二之一」至「二之八」各款。
- **结论**: 作者称这只是其中一种方法，鼓励读者用自己的观点区分主要部分并列出大纲。
- **结果**: 书中称，用这样的方法阅读一份文献会看到许多以前没看到的东西；读者可以做得比示范更详细。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读完一本书，被问「这本书讲了什么」时只能罗列细节、挤不出一句主旨
2. 要写读书笔记、书评或汇报材料，需要先讲清书的结构
3. 面对长篇文献（研究报告、法律文本、长论文），抓不住主要部分与顺序
4. 读完感觉「大概知道」，但一问「为什么这么说」就答不上来
5. 想把一本值得的书读「透」，需要一套可交付、可复述的读法

### 语言信号

- 「我知道这本书在讲什么，但是说不出来」
- 「这本书太厚／太乱，理不出头绪」
- 「帮我理一下这本书的大纲」
- 「读完记不住，只剩零碎的点」
- 「怎么检验自己是不是真的读懂了」
- 英文: "I can't put it into words", "outline this book for me", "what the book is really about"

### 与相邻 skill 的区分

- 与 `book-classification` 的区别: 分类（规则一）决定适用分支，是本卡入口步骤；本卡处理「全书说了什么」（规则二三四），不重复分类判断
- 与 `four-questions-and-notes` 的区别: 四问是一切阅读的通用骨架；本卡是问题一／二在具体书上落成产出（一句话主旨、大纲、问题清单）
- 与 `propositions-and-arguments` 的区别: 本卡给骨架（第一阶段），该卡拆内容（第二阶段：共识、主旨、论述、解答）——先骨架后内容
- 与 `rules-overview` 的区别: 总表用于全局复核与定位；本卡执行第一阶段细则

## E — 可执行步骤 (Execution)

1. **确认输入**
   - 输入契约: 一本已按规则一分类（必要时先走 `book-classification`）、并做过检视阅读的书；非精读对象先用 `inspectional-reading` 判断值不值得投入
   - 完成标准: 说明这本书属于哪一类（论说／文学、理论／实用），并确认它值得做本流程
   - 判停条件: 结构确实混乱的低价值读物——按 p158 判「问题出在书」，不为它做精细大纲（ce114／ce118）

2. **规则二：写出一句话摘要**
   - 完成标准: 用单一句子或最多几句话说出整本书在谈什么；能对别人复述；说不出口或用太多话（只看到多样内容）视为未完成（ce112）
   - 输出契约: ①一句话（或一小段）全书大意；②注明是否采用了书名／前言的提示（p119）
   - 判停条件: 摘要越写越长抓不住主线→跳到第 3 步先做大纲，再回来重写

3. **规则三：拟分层大纲**
   - 完成标准: 全书→主要部分→段落→重点逐层列出；各部分写「谈的是什么」并说明顺序与关联；可用通用公式起步；允许不照原书章节，但须能说明取舍（p115／ce119）
   - 程度控制: 草稿近似即可（p116）；不细分到最小结构单位（ce117）；只对值得的书做（p117）
   - 输出契约: 至少两级大纲（口头版或书面版）

4. **互检：用大纲检验摘要（L981）**
   - 完成标准: 能说明一句话摘要对应书中哪些部分、为什么得体（「如何」「为什么」）；换一种说法仍说得通（ce120 为反例）

5. **规则四：列问题清单**
   - 完成标准: 说出作者要解答的主要问题；复杂问题列出次要问题并排定先后顺序（p121）；用理论／实用两张公式清单核对类型（p122/p123）
   - 输出契约: 有序问题清单（主要→次要；先答→后答）
   - 判停条件: 发现自己开始揣测作者心理→停，回到「作品里能指认的问题」（ce122 意图谬误）

6. **收束与分流**
   - 完成标准: 三件交付物（一句话主旨／分层大纲／问题清单）齐备，即可回答基本问题一
   - 判停条件: 产出并入 `rules-overview` 复核，随后进入第二阶段（`propositions-and-arguments`）；非精读书目可在任意一步停下——草图近似即为良好练习（p116）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对低价值读物追求完美纲要：没有一本书完美，也不值得为任何一本书写出完美纲要（ce118）；力气按书的特质分配——最优秀的阅读者也只对少数相关的几本书做近似大纲（p117）
- 只取三规则中的一条单独使用：规则二三四有整体性与同一目标，合起来才提供对一本书架构的认识（p125/p126）；也不要把「阶段」当重读次序（ce124）

### 作者在书中警告的失败模式

- ce112：满足于「感觉上的整体」说不出口——「我知道这本书在谈什么，但是我说不出来」连自己也骗不过
- ce113：只看出「怎样呈现一体」、看不出「怎样呈现多个」（列不出部分与关联）
- ce114：对没有整体性与组织架构的书强求整齐大纲；或反向——把结构混乱当成自己没读懂（多数书并未按规则写作）
- ce116：把书中示范摘要当标准答案背诵；另一面是「反正各自诠释」式的任意解读
- ce117：被完整公式「像要读一辈子」吓退——要么不做、要么全量执行；ce119：忽略章节标题乱拟架构，或完全被动照抄标题体系
- ce120：猜对重点却不知为何（两岁孩子说「二加二等于四」）；ce121：把小说读到一部分就宣称掌握主题
- ce122：意图谬误——试图从作品中看透作者内心

### 作者的盲点 / 时代局限

- 「理想化标准、草稿近似即可」（p116；L1667 作者自限）：一个人可以做一个艺术家，却不必做理想的艺术家——引用 15 条规则时必须一并保留这个自限，不得把公式呈报为硬性达标线
- 示范摘要非唯一答案（ce116／p118）：整体精神可以有各种不同诠释，没有哪一种一定对——但仍须接受客观标准的检验
- 「大纲要多细」只给了两次上限提示（p116/p117），无量化标准——程度由使用者自定

### 容易混淆的邻近方法论

- `propositions-and-arguments`: 本卡完成第一阶段（架构），该卡做第二阶段（内容诠释：共识→主旨→论述→解答）；先骨架后内容，不可跳级
- `book-classification`: 规则一（分类）是本卡三规则的前置入口——分类错了，后续适用分支全错
