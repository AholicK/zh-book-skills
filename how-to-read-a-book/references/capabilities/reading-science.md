# 如何阅读科学与数学

## R — 原文 (Reading)

> 你要做的就是运用阅读论说性作品的规则，而且要很清楚地知道作者想要解决的问题是什么。…你阅读这些书只是为了了解科学的历史与哲学。…科学的客观不在于没有最初的偏见，而在于坦白承认。……数学其实是一种语言，我们可以像学习自己的语言一样学习它。…你可以从欧几里得开始，他的《几何原理》是所有这类作品中最清晰也最优美的作品。
>
> — 第十七章 如何阅读科学与数学 · 了解科学这一门行业（L2419-L2421）；阅读科学经典名著的建议（L2429）；面对数学的问题（L2459-L2467）

## I — 方法论骨架 (Interpretation)

定位（先定责任边界）：门外汉读科学经典不是为了成为专家，而是为了**了解科学的历史与哲学**——把「问题本身及问题的背景」弄清楚，责任就算结束；你的责任不是成为这个主题的专家，而是去了解相关的问题。

主规则只有一条：**运用阅读论说性作品的规则，并把「作者想要解决的问题是什么」放在纲上**。科学作品的主要词汇多是不常见或科技用语，由此找主旨——科学主旨通常是摆脱时间与地点限制的一般性通则。

两个警觉点：①区分作者最初的假设与论证后的结论——科学的客观不在于没有最初的偏见，而在于坦白承认；②科学以归纳法为特质，归纳论点建立在证据上，读者常常只能靠手中这本书——书不能启发你时，唯一办法是亲身体验以获得特殊经验（看实验、操作仪器、去博物馆观察标本与模型）。

数学的转念：**数学是一种语言**——有自己的字汇、文法与句法，可像学自己的语言一样学它，而且只需学一次（它完全是书写的语言）。起步从欧几里得《几何原理》开始；几何命题分两种：作图问题（去做）与定理（去证明）；命题证明的是「若……则」的关系是否为真，别无其他，不必纠缠对象是否真实存在。

读法按「企图」分流：想了解数学本身→从头读到尾、手上拿笔、页边写笔记（比任何其他书都更需要）；只读一本「有数学在内」的科学书→跳着略读更聪明——先看定理说明、再看结论、掌握如何证明，读引理与系理，再读旁注（讨论命题与整个问题的关系），卡住就不看图表、只挑感兴趣处，但**不要错过作者强调的重点**。

判停点：能说清问题本身及背景、并分出假设与结论，即达到原书设定的完成线；逐页读完细节不是达标线。

## A1 — 书中的应用 (Past Application)

### 案例 1: 从《几何原理》第一册前五个命题入门数学
- **类型**: 书中演练（第十七章）
- **问题**: 怕数学的读者如何跨过门槛、领略数学之美
- **方法论的使用**: 以《几何原理》第一册前五个命题示范读法——基本几何命题分两种（作图问题的叙述、几何图形与各相关部分之间的关系的定理）；作图题动手去做，定理加以证明，命题结尾分别有 Q.E.F.（作图完毕）与 Q.E.D.（证明完毕）
- **结论**: 命题层层依赖——等腰三角形两底角相等的证明，必须先作三个图（命题一→二→三→五）
- **结果**: 未说明（作者称几个晚上就能读完、足以领略数学之美）

### 案例 2: 牛顿《自然哲学的数学原理》的跳读示范
- **类型**: 书中演练（第十七章）
- **问题**: 含大量命题的科学经典，是否必须逐个细读
- **方法论的使用**: 先看定理的说明，再看结论，掌握这是如何证明出来的；读引理（lemmas）及系理（corollaries）的说明，再读旁注（scholiums，讨论命题与整个问题的关系）
- **结论**: 用不着每个命题都仔细读（第一次从头看时更是如此）；觉得困难就不看图表、只挑感兴趣的内容，但不要错过牛顿所强调的重点
- **结果**: 未说明；作者指出重点之一是第三卷结尾的「宇宙系统」（牛顿称之为一般的旁注），总结了前人重点并提出后世都会思考的大问题

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想读（或正在读）一本科学经典——牛顿、达尔文、伽利略、拉瓦锡——但不知从哪里下手
2. 看到科学书里的公式、命题、图表就卡住，或自认「我数学不好」而绕开所有带数学的书
3. 读科普书想有真实收获，想分清「读得懂」与「以为自己读得懂」
4. 想弄明白一位科学家到底解决了什么问题、为什么值得读，而不是只摘结论
5. 读一本带数学的科学书，在「逐行硬啃」与「跳着略读」之间拿不定主意

### 语言信号

- 「这本书数学太多，我看不懂」「我从小数学就不好」
- 「这些公式和命题，要不要一个个推？」
- 「科普文章读着挺轻松，但读完什么都记不住」
- 「怎么才算把一本科学经典读明白了？」
- 「《自然哲学的数学原理》这种书，普通人真能读吗？」
- 英文: "I'm not a math person", "the equations lost me", "do I need to read every proof?", "how do I read Newton?"

### 与相邻 skill 的区分

- 与 `reading-philosophy` 的区别: 两者都从「先找作者要解决的问题」入口（task-18 双单元），但**方法互异、必须分诊**——科学的问题可依托证据与（必要时的）特殊经验，哲学的问题除了思考别无方法；用实验/民调回答哲学问题，或用纯文本阅读代替科学证据，都是典型的错配。

## E — 可执行步骤 (Execution)

1. **分诊：先判读物与企图**
   - 完成标准: 判明读物属「科学/数学」方向（原创经典或科普）而不是哲学或文学；记录读者的企图（了解数学本身 / 读懂一本有数学在内的科学书）
   - 输入契约: 一本具体的书 + 阅读企图；只有主题没有书名时先协助选书（按 ce340 边界：不从专业论文起步），不得替用户假设企图

2. **以问题为纲定位**
   - 完成标准: 写下「作者想要解决的问题是什么」及其问题背景；从目录、前言、旁注找线索，直到说得出来
   - 说明: 本步内联论说性作品的阅读规则（分类→共识→主旨→论述→解答）；细则以分析阅读各规则卡为准

3. **假设 / 结论分列**
   - 完成标准: 拉两栏——作者最初的假设（可能带个人偏见，作者会坦白要求你接受）与经过论证之后的结论；能指出哪些结论建立在哪些假设上

4. **数学读法分流**
   - 完成标准: 企图 A（了解数学本身）→给出通读计划：从头读到尾、拿笔、页边笔记；企图 B（读科学内容）→给出跳读路线：定理说明→结论→证明思路→引理系理→旁注，并标出不得错过的重点
   - 判停条件: 卡在细节时核对是否属「用不着读完所有细节才能获得启发」的情形（拉瓦锡《化学原理》例）

5. **证据与特殊经验核对**
   - 完成标准: 列出归纳论述所依赖的证据；判定哪些需要亲眼实验/观察，列为扩展动作并注明非达标线
   - 输出契约: 产出 ①读物与企图分诊 ②作者的问题+背景 ③假设/结论两栏 ④数学读法选择与笔记要求 ⑤证据清单；判停条件：能说清问题本身及背景即停，不以「成为专家」或「读完所有细节」为完成标准

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 从专家论文/专业期刊起步读一门科学（ce340）——现代科学论文是专家写给专家看的；门外汉的正当路径是退一步读科普书，并学会分辨其中的好书与坏书
- 把科学作品的假设当作已被证明的结论，或把作者坦白承认的假设当成缺陷（ce342）
- 用纯文本阅读的产物声称替代实验与特殊经验（ce344）——不了解科学家引以为理论基础的证据，就只能接受结论而无法真正评价它

### 作者在书中警告的失败模式

- ce341: 读科学经典不抓住作者要解决的问题——只摘结论与公式、说不出问题背景，读者的责任就没有结束
- ce343: 以为必须读完所有细节才能获得启发（拉瓦锡《化学原理》例：前言强调科学方法，已深具启发性）
- ce345: 以行业傲慢关闭科学史阅读（「有能力的人，就去做。没有能力的人，就去教」）——把「不是专家」当不读科学书的理由
- ce401: 怕数学——把一时的畏惧当作永久的能力判断；数学是一种语言，可以学
- ce402: 目标与手段错配——想了解数学本身却略读，或只想读科学内容却逐行硬啃
- ce403: 读科普不全神贯注——没有公式的三页文章，分神也读不懂

### 作者的盲点 / 时代局限

- L2501 句义畸变（NR-01 转档缺陷）：此处一句义受损（关于「没有数学有时反而可能更麻烦」的论述），引用须回源核对，勿据此转述
- 「作者的问题算不算读透」无完成判据（原书未给）——注意到问题本身及背景即尽责，但「注意到」如何核验，书中没有给
- 数学两条路以读者的「企图」分流、无客观判据（原书未给，需使用者自定）
- 亲手实验是扩展动作而非达标线：「并不是说你一定要依序完成所有的实验才能开始阅读这本书」（L2437）

### 容易混淆的邻近方法论

- `reading-philosophy`: task-18 双单元、同用「以问题为纲」；但**科学方法与哲学方法互异（须分诊）**——科学可依托证据与特殊经验，哲学除了思考别无方法；用错会双重失效
- `propositions-and-arguments`: f318 明说本方法就是「运用阅读论说性作品的规则」——本卡运行时须内联该前置规则，否则悬空
