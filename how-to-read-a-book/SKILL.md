# 《如何阅读一本书》 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 纯消遣与娱乐阅读的选书、推荐与陪伴式讨论（本方法针对「为求得理解而读」的场景）。
- 代替学科内容本身：它教「怎么读」，不替代数学、哲学、科学与社会科学等学科知识。
- 速读训练承诺：作者明确速度不解决理解力；速读课程只处理基础阅读层次的困难。
- 替读者决定读什么：选书标准作者有意留白（L3049「你该自己去找出对你有特殊价值的书来」），不得代补。

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 目的决定方式：先分清「为获得资讯而读」还是「为求得理解而读」——只有后者值得动用全部阅读规则。
2. 阅读的四个层次（基础→检视→分析→主题）是累积递进的，不是任选菜单；低层技能在任何场合都不消失。
3. 主动阅读 = 提出问题并按顺序回答；四个基本问题适用于一切读物，并让书页留下痕迹（笔记与「写出言外之意」）。
4. 先分诊再精读：检视阅读（六步略读 + 粗浅通读）应成为任何一本书的前置动作。
5. 分析阅读三阶段 15 条规则互锁：架构（规则 1-4）→ 诠释（5-8）→ 评论（9-15）；没有大纲无法有效摘要，没有诠释无法判断真实。
6. 评论是读者的最后义务：先完全读懂（「我了解了」），再按四个批评点逐一举证；找不出证据就有义务同意作者。
7. 阅读的终极目的是心智成长：读超越自己头脑的书；重读时书「与你一起成长」是好书的标志。
