# 《智识分子：做个复杂的现代人》 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 专业领域（法律、医疗、金融、统计建模）的正式咨询与决策——本包提供思维方法，不替代专业建议。
- 需要实时事实核查或最新数据的新闻判断——本包提供方法框架，不提供实时数据。
- 对具体个人/群体的道德评判与政治站队——本书是分析方法，不是立场纲领。

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 常识是我们的敌人：主流看法默认先怀疑，用数据与检验修正——把未来当概率分布，而不是常识判断。
2. 任何判断先问代价与边际：「没有免费的午餐」；用「下一步值不值」的边际分析替代总量思维与感情投入。
3. 人会对激励做出反应，也会互相模仿：改变行为看激励结构与模仿渠道，而不是喊口号、讲道理。
4. 复杂系统（complex）不能凭空扰动：牵一发而动全身；简单系统（complicated）才可预测、可动手改。
5. 专家的可信度看思维方式不看头衔：狐狸（多视角、常修正）远优于刺猬（一个大主意）。
6. 教育的默认功能是分类与打磨器具：主人教育（审美、明辨、调动资源）几乎只能靠家庭与个人。
7. 英雄＝不被大数据预测的人：机器的疆域是可预测，人的位置在创造新知识与表达好恶。
