# 十八般武艺：不绑定单一理论，用多流派套路轮番试

## R — 原文 (Reading)

> 想要解决社会、经济和生活问题，不能追求掌握一个一劳永逸的“正确”理论，而应该追求掌握一系列不同流派的思维方法，十八般武艺，多多益善。……博雅之学的本意是决策之学。……你掌握的套路越多，办事的时候可供选择的思路就越多。……如果你把经济学理论模型当成放诸四海皆准的真理，你什么事儿都不太可能干成。但是如果你把经济学理论当成仅供参考的寓言，你反而可能非常灵活地办成一些事情。
>
> — 自序 · 做个复杂的现代人（L187-L219）；自序 · 十八般武艺（L215）

## I — 方法论骨架 (Interpretation)

这是一张**总纲卡**：面对社会、经济、生活里的复杂问题，不先绑定任何单一理论，而是把手里各路「武艺」当作可轮换的招式，一招不成再换一招。作者给的三条骨干是：

1. **招式要多**：理论只是「寓言故事、名人典故和思维套路」，不当放诸四海皆准的真理；套路越多，办事时可选思路越多（L213-L215）。同一个问题可以当经济学问题，也可以当政治问题，甚至物理问题（L217）。
2. **关键是「度」与数字，不是立场**：解决问题的关键往往不在理念高不高大上，而在于「度」、在于数字——任何东西都有利有弊，用与不用还要看能承受多大代价（p06）。认准一个方向毫不动摇是理念与情怀；知道过犹不及、该左左该右右、时刻为最优值调整，才是理性态度（p05）。
3. **理工科思维的三动作**：取舍（tradeoff）、量化、科学方法（p07）；且出身理工科 ≠ 具备理工科思维，只守本领域的专家未必有（g02）。

理论不好使，不怪老师教错，只怪自己会的招太少（L217）。座右铭是：简单打不过复杂，只有复杂的人才能打败复杂（L219）。

**判停/转出点**：到了「要不要继续投入」这一步，转 `marginal-stop-rule`；到了「这是不是复杂系统、能不能动」这一步，转 `dont-poke-complex-systems`；要判断哪一招的结论算证据，转 `knowledge-reliability`。

## A1 — 书中的应用 (Past Application)

### 案例 1: 上谈话节目谈环保、指责能源公司 CEO「犯了反人类罪」的科学家
- **类型**: 书中转述（自序 · 如何听取理工科专家的意见）
- **问题**: 一位以环境相关研究为专业的著名科学家，受邀上谈话节目谈环保问题
- **方法论的使用**: 反面用法——他只用本专业视角下结论，态度极端，指责能源巨头公司的 CEO 们「犯了反人类罪」；作者指出他知识面太窄、没有 tradeoff 的思维，也不知道社会中其他方面需求的重要性
- **结论**: 只知道自己学科一点点知识的专家，其意见在公共问题上不能作决策依据，应只当决策的参考，并再听别人的论点和数据（p04）
- **结果**: 未说明（作者只评论：这样的专家不会被认真对待）

### 案例 2: 2015 年 9 月 5 日三位名人的微博事故
- **类型**: 书中转述（自序 · 理念与算数）
- **问题**: 只知道一个理念的公共发言者，被自己的理念驱使去为「方向」找证据
- **方法论的使用**: 反面用法——名人 A 把网络小说中虚构的光绪皇帝讲话当成真的转发；名人 B 的《人类起源于中国的猜想》从小处到大处各种尺度全错；名人 C 犯了统计错误。作者评：这已经不仅仅是理念，这是迷信，他们被自己的理念给劫持了
- **结论**: 手里只有一套理念的人，用半生之力铸就一个「锤子」，就把一切东西都视为「钉子」；要找合适的「度」，至少需要掌握两个不同的理念
- **结果**: 未说明（作者未交代事件后续）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一个复杂问题用单一理论/单一学科视角解释不通，或越解释越别扭
2. 选专业、选学校、换工作、做公共议题判断时，想知道「该学哪些本事才够用」
3. 讨论里出现「越 X 越 Y」式的单向论证，用户想把它拉回到「度」与代价上
4. 只有一套解释框架的人来推销结论，用户想看看别的流派会怎么说
5. 想给孩子或自己安排通识/博雅学习，但拿不准标准是什么

### 语言信号

- 「这个问题的本质就是……（某个单一框架）」
- 「学那么多有什么用，把一门学精不就行了」
- 「方向对了就行，剩下的都是执行问题」
- 「遇事不知道用哪套方法，很乱」
- 英文: "what's the best framework for this?", "one theory can't explain everything", "which discipline should I learn?"

### 与相邻 skill 的区分

- 与 `fox-vs-hedgehog` 的区别: 那条是可信度判据（为什么狐狸式的人更该被信）；本 skill 是**生产侧**的方法库建设与轮换用法（怎么让自己变复杂）
- 与 `marginal-stop-rule` 的区别: 那条管「该不该继续投入」的下一步临界效果；本 skill 管「还有哪些招可用、怎么轮着试」
- 与 `dont-poke-complex-systems` 的区别: 那条先判「能动不能动」；本 skill 在动手前提供招式库（先判能动不能动，再挑招式）
- 与 `knowledge-reliability` 的区别: 那条裁定「哪一招的结论算证据」；本 skill 只负责多招轮换与代价核算，不裁定证据等级

## E — 可执行步骤 (Execution)

1. **立问题**
   - 完成标准: 把问题写成一句话，并写明决策目标（要什么）与约束（不能牺牲什么）
   - 输入契约: 一个真实困惑；若用户只给情绪或抱怨，先请他改写成一句可判断的问题

2. **列招式**
   - 完成标准: 至少写出 3 个不同流派/学科的套路，每个附一句「它会把这个问题看成什么」（如经济学看成激励与代价、政治学看成联盟与权力、物理学看成流量与阈值）
   - 判停条件: 招不足 3 个时，明确提示这是「招太少」，转向补充方法库（读书/跨学科学习），而不是硬用一个框架凑答案

3. **轮换试招**
   - 完成标准: 对每个套路写出①它给出的建议 ②它最可能忽略的代价与盲区；允许一次试不成立刻换招，但每换一招都要留下上一步的结论

4. **转「度」与代价**
   - 完成标准: 把「这个东西好不好」改写成「用到什么程度、要付多大代价、代价能否承受」；给出至少两个可量化的候选档位（具体数值口径原书未给，由使用者自定并标明为自定）

5. **收尾与转出**
   - 完成标准: 给出①问题与目标 ②候选套路（≥3）及各自视角 ③每个套路的建议与盲区 ④当前选择与撤回条件
   - 判停条件: 涉及复杂系统干预转 `dont-poke-complex-systems`；只差停止点转 `marginal-stop-rule`；需要裁定证据可靠性转 `knowledge-reliability`

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要一个**明确的「用哪个套路」判定树**时：原书明说「至于遇到什么事应该用哪个套路去解决，这没有任何程序性固定办法，是一种艺术，只能自己选择」（L213）——本卡不提供选择规则，也不得补造
- 单一学科就能干净解决的技术/执行问题（此时轮换套路只是拖延）
- 纯价值与立场之争（缺少数值口径时，「度」无法计算）

### 作者在书中警告的失败模式

- **只懂一门、跨界定案**（ce11）：气象学家「不惜代价」减排、航天人只算回报、生物能源人说核电危险——「他根本没有 tradeoff 的思维，也不知道社会中其他方面需求的重要性」，其结果是失去公共可信度
- **理念劫持**（ce12）：只有一套理念的人把一切问题往一个框架里塞，为「方向」转发未经核实的材料、犯统计错误——「他们用半生之力铸就了一个属于自已的锤子，就把一切东西都视为钉子」（OCR 原貌）
- **理论当真理**（ce28）：把一本书、一个模型当成完备行动指南，「你什么事儿都不太可能干成」；理论不好使就埋怨老师教错了，而不是怪自己会的招太少
- 用传统简单社会的经验（《三国演义》《孙子兵法》《厚黑学》）应对现代问题（ce16）

### 作者的盲点 / 时代局限

- 「把理论当寓言」**不等于理论无用**：作者反对的是把它当放诸四海皆准的真理，不是反对使用理论
- 理性必须另外学：智商与理性几乎是两码事，理性能力（充分认识局面、做好最佳决策）要单独训练（p08）；且作者提醒改变落后思维模式的研究鲜有成功案例（ce17）
- 方法库**没有质量分级**：哪个套路的结论更硬、哪一招算证据，原书未给判据（转 `knowledge-reliability`）
- 作者自我限定：「我还不能保证书中说的理论都是对的」（L225）；理论进展之快常常超过书籍出版的速度——本卡继承这一限定，不把书中的招式当权威清单

### 容易混淆的邻近方法论

- **折中主义 / 和稀泥**：本卡要求的是「多招轮换 + 代价核算」，不是「各打五十大板」；每换一招都要能说出它解释了什么、漏了什么
- **博雅教育＝贵族修养**：作者明确反对把通识当成「显得像上等人」的化妆品，博雅之学的本意是决策之学（L199-L203）
