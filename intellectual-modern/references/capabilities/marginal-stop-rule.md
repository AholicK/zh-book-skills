# 边际分析：只看下一步的停止规则

## R — 原文 (Reading)

> 而经济学家的智慧在于问一句值不值得。……边际分析是指你不用考虑总的效果，你只要考虑做下一步的临界效果就行了。……只要你生产的下一个这个产品的收益大于成本，你就可以继续生产。如果下一个产品的成本正好等于收益，你就应该停止生产。
>
> — PART I · 最简单经济学的五个智慧（2.没有免费的午餐）（L553-L573）

## I — 方法论骨架 (Interpretation)

把「还要不要继续」从总账问题改造成「下一步」问题：

- **不算总账**：已投入多少、历史上总回报多高，都与决策无关（沉没成本不进入决策）；一个领域的平均回报率与「下一笔钱能买到什么」无关。
- **开关式算法**（p31）：只看下一单位的临界效果——下一单位收益 > 成本 → 继续；收益 = 成本 → 停止；收益 < 成本 → 必停。「下一个单位」按同一计量单位计（下一个产品、下一小时、下一元钱、下一次）。
- **默认预期**：边际效应常常递减——投入越多、效果越不明显（p32）。不许按平均效果外推；效果开始衰减时，停止点会更早到来。
- **通用句式**：「经济学家问一句值不值得」——任何「好东西」（安全、环保、生命、方便）先问代价：代价太高就不要；换来的价值更大就付出（p30）。这条同样适用于生命与安全——不存在「不计代价」。
- **接口**：价格/回报是输入（其可信度由 `price-signal-check` 检验）；停止后改做别的，不在本卡范围内。
- **缺损（原书明说）**：未给收益/成本的量化口径与周期，也未给折算方法——数值怎么算由使用者自定，本卡不补公式。

## A1 — 书中的应用 (Past Application)

### 案例 1: 航天「投入 1 元回报 7 到 12 元」——正确与错误用法对照
- **类型**: 书中演练（PART I · 最简单经济学的五个智慧 · 2.没有免费的午餐；正误对照）
- **问题**: 有说法称「航天领域每投入1元钱，将会产生7元至12元的回报」——据此是否就应该拼命往航天领域投钱？
- **方法论的使用**: 错误用法是把总体回报率当作继续加码的理由——那是把过去所有投入平均后的数字；正确用法是用边际分析问：在已经有这么多航天成果的情况下，「我再往航天里多投入1元钱，能产生多少回报」；并记住边际效应常常递减
- **结论**: 决定加不加码的不是历史总账，而是下一元钱的临界效果
- **结果**: 未说明（书中只做正误对照，未给后续数据）

### 案例 2: 「不惜一切代价」与极端环保——生命无价的反面
- **类型**: 书中演练（PART I · 最简单经济学的五个智慧 · 2.没有免费的午餐；反面模式归纳，非独立事件）
- **问题**: 人们常常错误地以为有些东西可以不计代价：生命无价，要不惜一切代价保证安全；有些极端环保主义者要求抹掉一切人类痕迹
- **方法论的使用**: 作者用日常行为反驳：根本没有任何人不惜一切代价保证自己的安全——每次出门上街都冒交通事故的危险，但该过马路就过马路、该坐飞机就坐飞机；要完全避免交通事故就得待在家里哪儿都不去，这个代价太高了。对污染的正解是算账与定价（先算环境能承受多少污染，再把排污份额卖给企业），不是禁止或清零
- **结论**: 安全与环境也要算账；「不惜一切代价」是无法执行的句式，实际能被执行的永远是「用多少代价换多少收益」
- **结果**: 未说明（论证性内容；作者另给出「我不禁止，我要价」的污染管理办法作为对照）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一个项目/习惯/投入做了很久，纠结「要不要继续投」
2. 有人用「已经投了这么多」或「历史回报很高」劝继续加码
3. 面对「不惜一切代价」「一个都不能少」的要求，需要把它翻译成可执行的取舍
4. 追求一个「好东西」（安全、健康、品质）到效果明显下降，不知道停在哪一步
5. 要给一项持续投入定停止点、预算上限或退出规则

### 语言信号

- 「都投入这么多了，不能半途而废」
- 「每投 1 块钱能赚 7 块，当然要继续投」
- 「不惜一切代价也要……」
- 「再坚持一下就好了」
- 「已经花了这么多，现在停不就白费了」
- 英文: "sunk cost", "we've come too far to stop", "whatever it takes"

### 与相邻 skill 的区分

- 与 `price-signal-check` 的区别: 同以价格为轴——那条检验「价格信号本身可不可信」，本卡把价格（或回报）当作边际决策的输入，算「下一步值不值得」
- 与 `dont-poke-complex-systems` 的区别: 那条管「复杂系统里该不该动手」（怕的是意外后果）；本卡管「已经在动的投入，下一步该不该继续」——先判该不该动，再判停不停
- 与 `space-and-big-science` 的区别: 那条是「太贵」视角在大工程上的应用展开；本卡给的是通用的开关规则
- 与 `multi-method-toolkit` 的区别: 本卡是武艺库里最常用那一招的具体算法；那条负责「怎么选武艺」

## E — 可执行步骤 (Execution)

1. **盘投入、划清界限**
   - 完成标准: 列出已投入的总量与历史成绩，同时写明「这些数字不进入决策」——防止沉没成本与平均回报率进场
   - 输入契约: 一个持续投入的活动（生产、投资、加班、健身、工程投入等）；缺具体活动先问用户
   - 判停条件: 若没有可重复的「下一步」（一次性买断/签约定终身），本卡不适用

2. **定义「下一步」单位**
   - 完成标准: 把动作拆到一个可重复的计量单位（下一个产品、下一小时、下一元钱、下一次），并确认使用者能对其收益与成本给出估计

3. **算临界账**
   - 完成标准: 给出下一单位的收益与成本两组数字（或区间与假设）；按开关规则给出结论：> → 继续；= → 停止；< → 必停。数值口径与周期原书未给，由使用者自定并写明假设
   - 输出契约: 单位定义 + 两组数字与假设 + 继续/停止结论

4. **递减校正**
   - 完成标准: 追问「投入越多效果越不明显吗」；若效果持平或上升，注明与「边际效应常常递减」的经验默认不符，需重估假设

5. **输出与复核**
   - 完成标准: 给出①下一单位定义 ②两组数字与假设 ③继续/停止结论；若结论为继续，给出下一个复核触发点（什么时候再算一次）
   - 判停条件: 若用户给不出任何数量级估计，退回定性判断（「换来的东西价值更大吗」），并明确标注「口径为临时估计」

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要精确量化口径的正式决策（投资模型、预算报表、招标测算）：原书只给算法、明说无数值口径与周期——量化标准须使用者自定，不得按本卡补造公式
- 一次性、不可重复的决定（买断、签约）：没有「下一个单位」可算
- 目标本身尚未确定时：本卡算「做到哪一步停」，不算「该不该有这个目标」

### 作者在书中警告的失败模式

- 用总体回报率为追加投入找理由（ce27）：历史平均回报率与下一笔钱的边际效果无关；投入越大、效果越差，直到成本超过收益
- 把目标设为「不计代价」（ce14）：生命无价、极端环保式的绝对要求都不可执行——没有谁真的不计代价，资源总是稀缺
- 鸡汤世界观（ce15）：「只要努力一切皆有可能」「世界上最美好的东西都是免费的」——决策不看条件与预算，碰到硬约束就崩溃

### 作者的盲点 / 时代局限

- 「边际效应常常递减」是经验性默认（p32），不等于必然——遇到边际收益持平或上升的场景，将停止点后移或改写假设，不得当作铁的定律
- 无法定价的物品（情感、生命质量）原书未给折算方法——不得替作者发明；强行折算前先声明口径
- 案例语境：松花江、全球变暖等例子出自 2014 年前后的专栏文章，判据可用、具体数字须重核

### 容易混淆的邻近方法论

- `price-signal-check`: 两者都在市场语境，但分工不同——那条回答「价格信号能不能信」，本卡回答「按这个信号算，下一步还值不值」
- `dont-poke-complex-systems`: 那条警告复杂系统别乱动大招，本卡给继续投入的算账规则；两者可接力（先判该不该动，再判停不停）
- `space-and-big-science`: 「太贵」视角的大工程应用；本卡是其通用算法（边际开停规则），大工程里的数量级问题仍须自定口径
