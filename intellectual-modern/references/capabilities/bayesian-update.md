# 贝叶斯信念更新：把「信不信」改成会随证据变的数字

## R — 原文 (Reading)

> 更进一步，“信或不信”有点生硬，最好我们能把它量化一下，用一个数字来描述，比如说用概率。……一个智识分子应该拥有这种复杂的信念体系，时刻调整自己对各种事物的看法。……
>
> 而贝叶斯定理的精神在于，既然无法得到全面的信息，我们就在证据有限的情况下，尽可能地做一个更好的判断。……所以因为这一次不灵的事件，你应该把你对雍和宫的信念值从22% 调低到10%。……
>
> 如果一个疾病比较罕见，那么你就不应该对阳性诊断太有信心。……这就是冤假错案产生的数学原理，这也是为什么卡尔·萨根说“超乎寻常的论断需要超乎寻常的证据”。……观点随事实改变，有胆有识，这就是贝叶斯定理的伟大原则。
>
> — PART III · 贝叶斯定理的胆识（L3123-L3224）；公式区 L3149-L3153、L3167-L3180 OCR 残缺，未引

## I — 方法论骨架 (Interpretation)

「信或不信」太生硬，操作上把它改写成**概率**：信念值一般落在 0.01%–99.99% 之间且动态变化——真正的深信不疑和彻底不信都很少，甚至可能是虚张声势自欺欺人。信念的意义不在表态，而在**给自己的决策提供依据**。

**五步更新流程**（原书未编号，据 L3167-L3188 雍和宫演算归纳）：

1. **估先验 p(A)**：你事先认为事件 A 有多可能（例：雍和宫「好使」= 15%）。
2. **估两个似然**：若 A 成立证据 B 出现的概率 p(B|A)（好使则升职 = 0.8），若 A 不成立证据仍出现的概率 p(B|¬A)（不好使也能升职 = 0.5）。
3. **算后验**：p(B) = p(B|A)·p(A) + p(B|¬A)·p(¬A)，再按标准式 P(A|B) = P(B|A)·P(A) / P(B) 得后验（15% → 约 22%）。
4. **随新证据迭代**：一年后听说水平相当的某乙祈福后未升职（两个似然变为 0.2 与 0.5），信念从 22% 调低到 10%。
5. **长期收敛**：有时候往上调有时候往下调，听说了很多证据之后形成比较稳定的看法；几次「不灵」的打击之后，很快就不该再信了。

**方向规则**（原书原句 OCR 括号错乱，此处按标准式重写）：只要 p(B|A) ≥ p(B|¬A)，事件 B 就使信念上调，反之则下调。

**基础率效应**：信念值很低时，强有力的证据也难以扭转它。极端例子是 HIV 检测——灵敏度 99.9%、特异度 99.99%、人群携带率 0.01%（万分之一），随机路人测出阳性而真携带的概率只有 50%（一万人中 1 个真阳性 + 1 个被冤枉）。由此：罕见事件下「准确率高达 X%」不足为凭；排查应「冒出来一个抓一个」，绝不搞「人人过关」——这是冤假错案产生的数学原理，也是萨根那句「超乎寻常的论断需要超乎寻常的证据」的算法版本。

**定位：这是纪律，不是计算能力考试**。核心要求是「观点随事实改变」——有新证据就调整信念；反证出现时忽略它、或宣称「这是阴谋，反而证明我更正确」，等于把信念变成不可检验的身份标签（二愣子性格不适合求知）。

两条须携带的缺口：① 先验赋值主观，**原书未给赋值规则**（演练须自定估计并标注「自定」）；② 公式区 L3149-L3153、L3167-L3180 OCR 残缺，引用与使用时按标准式重建并标注「OCR 残缺、按标准式重建」。

## A1 — 书中的应用 (Past Application)

### 案例 1: 雍和宫祈福的贝叶斯演算
- **类型**: 书中演练（PART III · 贝叶斯定理的胆识）
- **问题**: 一个日常信念「雍和宫祈福好使」（先验 15%）遇到一条新证据时该怎么更新
- **方法论的使用**: 先估三个值——p(A)=0.15、p(B|A)=0.8、p(B|¬A)=0.5；听到某甲祈福后升职，按贝叶斯定理算得后验约 22%；一年后听说水平相当的某乙祈福后未升职，似然变为 0.2 与 0.5，再算得 10%
- **结论**: 单条利好只把信念从 15% 抬到 22%——「我这个人听劝」（上调了）而且「我这个人稳重」（没有一听就信）；信念随证据双向移动
- **结果**: 演算结果 0.15→0.22→0.1；作者提示：几次不灵之后很快就不该信了

### 案例 2: HIV 检测的贝叶斯悖论
- **类型**: 书中演练（PART III · 贝叶斯定理的胆识）
- **问题**: 检测灵敏度 99.9%、特异度 99.99%，随便在街头找一个人做检查发现阳性——这个人真的携带 HIV 的可能性多大？
- **方法论的使用**: 代入贝叶斯定理（A=真携带，B=检测阳性，p(A)=0.01%），算得 p(A|B)=50%；并给直观解释：一万人中 1 人真感染被查出、9999 人里还会冤枉约 1 人，共查出 2 人
- **结论**: 疾病罕见时基础率主导结论；马普研究所（转述）拿此题考学生、数学家和医生，95% 的大学生和 40% 的医生答错
- **结果**: p(A|B)=50%；作者引申（转述萨根）「超乎寻常的论断需要超乎寻常的证据」

### 案例 3: 作者对自动驾驶汽车信念的转变
- **类型**: 作者亲历（PART III · 贝叶斯定理的胆识）
- **问题**: 作者对 Google 自动驾驶系统的相信程度需要随证据调整
- **方法论的使用**: 2010 年看到报道时判断记者没听懂专家的介绍或被忽悠（当时的车队只是模仿着往前走，根本谈不上应对复杂的交通路况）；此后陆续看到很多报道、越来越多细节被透露出来，逐步上调信念
- **结论**: 信念值随证据累积而上升，升到可以拿来指导判断的程度
- **结果**: 相信程度约 95%——「这个信念值已经足以让我在写文章的时候假定这个自动驾驶系统真实存在」

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 有个说不清信不信的念头（偏方、祈福、某产品的宣传、某专家的说法），想知道遇到新消息后该怎么调整
2. 看到「准确率 99%」之类的说法，想知道该有多大把握
3. 被人用一条新闻、一个案例说服或打击，想判断这条证据到底该改变多少看法
4. 发现自己对某件事的信念只升不降，反证来了也总能解释过去
5. 想为一次争议做决策，需要把「信不信」变成可比较、可利用的数字

### 语言信号

- 「这件事到底靠不靠谱？我也说不清」
- 「检测说阳性，我是不是就完了」
- 「准确率都 99% 了，还能有错？」
- 「反正我就是不信／我就是信」
- 英文: "how much should I update?", "the test is 99% accurate", "prior vs posterior", "what's the base rate?"

### 与相邻 skill 的区分

- 与 `fox-vs-hedgehog` 的区别: 那条在**事前**给「这位专家／这个说法该不该信」做定性打分（狐狸十条特征）；本 skill 处理**证据到达之后**的信念数值更新——估先验、估似然、算后验、再迭代，是「事前设概率」的具体算法
- 与 `common-sense-skeptic` 的区别: 那条是概率史观的**世界观层面**（把未来当概率分布、把历史当数据库）；本 skill 是个人信念管理的**操作层面**（一次可演算的更新 + 3 句反思）

## E — 可执行步骤 (Execution)

1. **取信念**
   - 完成标准: 把待更新的信念写成一个明确的命题 A（可判真假，如「这个偏方有效」），并写下一句它对你的决策意味着什么
   - 输入契约: 一个日常信念 + 一条具体新证据 B（谁、何时、发生了什么）；缺证据时先请用户提供，不许代拟

2. **估三个值**
   - 完成标准: 写出 ① 先验 p(A) ② p(B|A) ③ p(B|¬A)，每个都给出 0–100% 的数值与一句估计理由；**明确标注这是主观自定估计**（原书未给赋值规则），不许假装精确

3. **算后验**
   - 完成标准: 按 p(B) = p(B|A)·p(A) + p(B|¬A)·p(¬A) 与 P(A|B) = P(B|A)·P(A) / P(B) 算出后验数值（可用计算器/脚本，保留两位有效数字）；公式若需引用，标注「OCR 残缺、按标准式重建」
   - 判停条件: 若 p(B|A) 与 p(B|¬A) 都估不出来（信息完全缺失），停止计算，先补证据

4. **读方向与迭代**
   - 完成标准: 用方向规则（p(B|A) ≥ p(B|¬A) 则上调，反之下调）核对后验与先验的大小关系；写出「下一步什么证据会让我再往哪个方向调」

5. **输出反思**
   - 完成标准: 产出 3 句反思——① 这次更新说明了什么（听劝还是稳重）② 还缺什么证据 ③ 什么新证据会改变我的看法
   - 输出契约: ① 信念与证据陈述 ② 三个估计值及理由（标注自定）③ 后验数值与方向 ④ 3 句反思；全程拒绝在证据未变时重复调参

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要精确概率的正式统计场合——本卡是日常信念管理规范，不是统计课考点，也不是公式崇拜
- 命题本身不可检验、或属于身份认同（无法为 B 估计「A 假时证据出现的概率」时，更新流程无处落脚）
- 信息完全缺失、连粗估都做不了时：先补证据，再谈更新
- 拿它给自己已有立场做「数字化背书」——先验主观，反向操作同样可行，这正违背「观点随事实改变」的纪律

### 作者在书中警告的失败模式

- **ce319 忽视基础率**：只看检测/信号的准确率（99.9% 灵敏度、99.99% 特异度）就相信阳性结论——罕见事件下阳性为真的概率只有 50%；同样数学决定「人人过关」式排查必然制造大量冤假错案。警告信号：论证只有「准确率高达 X%」、不问先验概率/事件稀少程度、「有一个算一个，全都查一遍」
- **ce320 坚持信念不看证据**：反证出现时忽略它、或宣称「这是阴谋，反而证明我更正确」；或走另一极端——信就全信、不信就立刻否定（雍正对年羹尧式）。警告信号：反证被解释成「更证明我对」、信念只升不降、讨论信念时谈忠诚而非证据
- 两种极端都使信念无法被事实修正；正确态度是不断根据新的事实来调整自己的观点

### 作者的盲点 / 时代局限

- 先验赋值**主观、原书未给赋值规则**（L3178 仅给示例估计）——演练必须自定并标注；原书也不讨论更复杂的形式
- 公式区 L3149-L3153、L3167-L3180 OCR 残缺（「P(AIB)」「p(B[A)」式错乱）——引用须按标准式重建并标注
- HIV 例数据来自 The Social Atom（转述 Mark Buchanan），作者自注「此例子中使用的数据未必符合现在真实的病毒检测，这仅仅是一个例子」——不可当现行检测的真实参数
- 「禁止教授贝叶斯」段以「据说」开头（L3222），未给引用出处——引用须保留该限定

### 容易混淆的邻近方法论

- **概率论习题 / 统计推断**：本卡不要求精确计算能力，要求的是「观点随事实改变」的纪律；算不出后验时，方向性判断（证据提升还是降低信念）也有价值
- **决策树 / 期望值计算**：那类工具在已知概率分布下算最优行动；本卡处理的是概率本身未知、只能主观估计时的信念管理
- `fox-vs-hedgehog`（事前评估）与 `common-sense-skeptic`（概率史观）：一个在事前、一个在世界观，本卡在事后更新
