# 流水线教育识读：标准学生、隐含教案与三层次

## I — 方法论骨架 (Interpretation)

把教育当**生产系统**识读的三把尺子（识读工具，不是身份判定）：

**尺一：隐含教案审计**（转述自 Jean Anyon《社会阶层与隐含教案》，1980）。学校在教什么，不看它的宣传，看它的教法/纪律/作业三类证据：工人阶层的学校练「遵守流程」（死记步骤、不问目的）；中产阶层的学校练「把事做对」（课本权威、答案正确即可）；专业人士阶层练创造性与独立性（独立调研、写文章演讲）；主管精英阶层练「制定规则」（决策与选择、学生自治）。**判法**：拿证据逐类对照，判定一所学校在给哪个阶层备课。

**尺二：三层次体检**。流水线教育的默认目标是打磨「器具」而不是培养「人」——器具分两层：工具（找工作）与工艺品（用成绩、才艺、「素质」等指标衡量自己，追求「符合标准」）；第三层是主人翁（审美、明辨、调动资源，以欣赏、选择和改变世界为目的）。**判法**：把家庭/学校的每笔投入逐笔归层，看比例是否畸形。到达路径：第一层靠学校；第二层靠家庭＋精英大学；第三层几乎完全靠家庭与个人。

**尺三：主人 / 奴隶对照**。被动 vs 主动是分界线：主人学习审美（关心怎么评价别人）、奴隶学习比美（关心别人怎么评价自己）；主人学「我想要什么」，奴隶学「我要变成什么」。同一项教育动作，看它在练主人还是练奴隶。

**两条必须并存的背景**：结构约束（素质可遗传、家庭收入与文化水平直接决定孩子能达到的层次）与自由意志（「基因加环境，也不能把人完全定死」，人可以不必如此）是书中并置而未打通的两套叙事——引用时须两条同时保留，不把任何一条单写成宿命或鸡汤。

判停：若问题的落点是「怎么学 / 学什么技巧」而非「这套系统在干什么」，本卡不适用。

## A1 — 书中的应用 (Past Application)

### 案例 1: Jean Anyon 的隐含教案研究
- **类型**: 书中转述（PART II · 说英雄，谁是英雄）
- **问题**: 不同阶层的小学教育在教什么？教育差异是「量」的还是「质」的？
- **方法论的使用**: 教育研究者 Jean Anyon 在 20 世纪 70 年代末全程跟班考察不同阶层的几个小学的四年级和五年级教学，1980 年发表《社会阶层与隐含教案》：哪怕在离起跑线不远的四五年级，各阶层的教学方法与培养目标已完全不同
- **结论**: 工人阶层学校训练遵守流程（教除法只给步骤、不解释目的，学生提出更好办法会被否决）、中产学校要求把事做「对」（课本权威不可质疑）、专业人士学校已要求独立调研与写作演讲、精英学校学生学「怎么制定规则」（老师问的第一个问题是「你的第一个决定是什么」）
- **结果**: 如论文结论（书中逐层展开；作者据此判定各阶层学校在训练什么人）

### 案例 2: 作者的小学与初中数学课
- **类型**: 作者亲历（PART II · 说英雄，谁是英雄）
- **问题**: 自己的数学课为什么这么教——做应用题不先写「解」字对错都扣分，老师纠结「乘」与「乘以」的顺序，解一元一次方程要背五个步骤
- **方法论的使用**: 用隐含教案框架回看自己的经历——哈尔滨市道里区最好的中学、全校最好的数学老师教出来的课，有些题不按步骤做更好，但课上经常要考背诵
- **结论**: 他后来用阶级分析才明白「这分明是在训练工人」——工人必须严格遵守流程步骤，不必关心最终产品
- **结果**: 未说明（作者称当时不理解为啥这么教，后来恍然大悟）

### 案例 3: 工人子弟的「造反精神」
- **类型**: 作者亲历（PART II · 说英雄，谁是英雄）
- **问题**: 工人阶层学校里有没有主动对抗体制的学生
- **方法论的使用**: 用美国这套标准对照，作者自评其小学属于工人阶层（连教学楼里从哪边走、上课怎么举手都有明确规定），但好几个同学根本不在乎这些规定、经常跟学校对着干
- **结论**: 老师「夸」他们有「造反精神」——即使在工人阶层学校，也有主动对抗体制的个性学生（「个性学生从来都不是体制的产物，他们主动对抗体制」）
- **结果**: 未说明（作者反问：这帮工人子弟「做事常常带有统治阶级的风格」）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对一所学校（或一段教育叙事/宣传），想知道它实际上在教什么、培养什么人
2. 做家庭教育的投入决策（报班、择校、选课），想先看清每笔投入指向哪个目标层次（工具/工艺品/主人翁）
3. 看到「素质教育」「个性化培养」「做最好的自己」类说法，想判断它是不是只是把「器具」生产得更精致
4. 反思自己的教育经历或职场行为，怀疑自己一直活在「等别人挑选」的叙事里
5. 讨论「对抗体制/不随大流」的教育动作，想区分真的对抗与加码适应

### 语言信号

- 「这所学校到底在教什么」「这算是素质教育吗」
- 「大家都补，我们也得补」「不能输在起跑线」
- 「做最好的自己」
- 「怎么培养主人翁精神」「为什么总觉得自己在等人挑选」
- 英文: "what is this school really teaching", "assembly line education", "owner mentality vs slave mentality"

### 与相邻 skill 的区分

- 与 `education-sorting-machine` 的区别: 那条看体制层的分类与筛选功能（把人分到哪、门槛与军备竞赛）；本卡看课堂层与家庭层（在教什么、期待什么）——先判结构用那条，再审内容用本卡。
- 与 `elite-school-premium` 的区别: 那条判名校溢价值不值（分类机制的顶端效应）；本卡先做「学校在教什么」的识读，是选校判断的前置步骤。
- 与 `kipp-character-education` 的区别: 那张把纪律训练落到具体制度（挣得式奖励、打分、延长在校时间）；本卡以「主人教育/奴隶教育」标准审查这类训练，指出 KIPP 式模板与主人教育标准的冲突点。
- 与 `road-to-character` 的区别: 那张处理「主人翁」出现之后个人拿什么标准要求自己（谦卑、召唤、成长）；本卡处理主人翁与器具是如何被教育生产出来的。

## E — 可执行步骤 (Execution)

1. **确定识读对象并分层**
   - 完成标准: 对象明确（一所学校 / 一笔教育投入 / 一种教育叙事），并已区分它属于「体制层问题（分类、门槛、竞争）」还是「课堂层问题（教法、期待、培养目标）」；若为体制层，先转 `education-sorting-machine`。
   - 输入契约: 缺对象先问清；不静默代入用户自身或孩子的情形。

2. **隐含教案审计（尺一）**
   - 收集三类证据: 教法（老师问的第一个问题是「怎么算」还是「你的第一个决定是什么」）、纪律（什么行为被鼓励/被禁止）、作业（背步骤还是做项目、能否质疑课本）。
   - 完成标准: 输出「四阶层特征对照表 + 更像在给哪个阶层备课」的判定，并附三条以上具体证据。
   - 判停条件: 证据不足两类时标注「无法判定」，不硬猜（不拿学校宣传当证据）。

3. **三层次体检（尺二）**
   - 列出家庭/学校对教育的每笔投入（时间、金钱、具体动作），逐笔归层: 工具（以找工作为目的）/ 工艺品（提升个人价值、符合指标）/ 主人翁（欣赏、选择和改变世界）。
   - 完成标准: 输出投入清单（投入 → 归层 → 理由）+ 比例结论；指出畸形所在。
   - 注意: 三层次判定细则原书未给——按定义归位即可，不设配额、不造计分表。

4. **主人 / 奴隶对照自检（尺三）**
   - 对当前主要行为逐条过六组对照（审美/比美、明辨是非/迎合、找工具用工具/把自己变成工具、调动资源/变成别人的资源、「我想要什么」/「我要变成什么」）。
   - 完成标准: 标出奴隶侧主导项至少一条，并给出一条向主人侧移动的具体动作。

5. **张力核对与输出**
   - 输出前核对: 结论同时保留结构约束（素质可遗传、家庭决定层次）与自由意志（人可以不必如此）两条；**不得输出「你/这所学校属于 X 阶层」式标签化判定**。
   - 输出契约: 审计报告 = 隐含教案判定＋三层次比例＋主人/奴隶自检＋一条行动建议；报告须携带转述口径（Anyon 1980、美国语境）与限制声明。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把阶层判定当给人/学校贴标签: 四阶层与三层次是识读工具，用于理解系统在做什么，不是身份归类。
- 「怎么学」类操作问题（学习方法、备考技巧、报班方案）——本卡是结构识读，不产出学习方案。
- 拿 1980 年美国单篇论文做普适规律外推: 跨语境（中国、当代）使用必须标注来源与年代，不得作为定论。
- 跨国教育笼统比较（「美式教育好不好」）：先回答「你说的是哪个阶层的教育」（ce213），否则是盲人摸象。

### 作者在书中警告的失败模式

- ce211：指望学校培养个性——大班教学只能按中等偏下的程度授课，学校的目标永远是「标准学生」（照顾多数人）；课堂越是模范，最好的和最差的学生越是在看课外书、玩手机。个性化培养不在体制的职责范围内。
- ce212：把提前学、请家教、加码投入当成「对抗应试体制」——实际上是更主动地适应体制、以更好的成绩取悦老师，只把军备竞赛推得更高（所有家长都这么做，名次分布不变）。
- ce214：被动的自我叙事——按「做个好器具等着被挑选」的思路做教育与职业选择（好生活不是自己创造的，而是「谁看我好，赐予我的」），思维本质上是被动的：外界喜欢什么，我就变成什么。
- ce215：把「做最好的自己」与职场小算计当作自我提升路径——仍是在取悦世界的框架里梳妆打扮等人挑选，缺少主人翁意识。

### 作者的盲点 / 时代局限

- Anyon 四阶层框架基于 1980 年美国单篇论文、以四五年级为样本，书中未给数据收集与判定细则——跨语境使用须标注，不得外推为普适规律。
- p240（素质可遗传、人不易超越父母阶层）与 p241（人根本上是自由的）是书中并置未打通的两套叙事——引用须两条同时保留，单取一条即失真。
- 三层次判定细则原书未给——只给定义与归位原则，不补配额；「主人翁」若写成口号式正能量即偏离原意。
- 「硅谷中印工程师地位差别」为作者自述「我想」的归因（c234），无统计数据；「文化差异论」为作者立场，书中未回应反方证据。

### 容易混淆的邻近方法论

- `education-sorting-machine`: 体制层的分类与门槛（它在把谁分到哪）vs 本卡的课堂层与家庭层（在教什么、期待什么）——两条可先后配合。
- `elite-school-premium`: 名校溢价的顶端效应 vs 本卡的通用「学校在教什么」审计——「要不要冲名校」用那条，「这所学校在干什么」用本卡。
- `kipp-character-education`: 纪律训练的落地 vs 本卡的主人教育审查标准——两卡在「谁在被培养成器具」这一点上是对照关系。
- `road-to-character`: 个人修炼（主人翁出现之后拿什么标准要求自己）vs 本卡（主人翁如何被生产出来）——先有本卡的识读，才有那条卡起点上的自我定位。
