# 道德直觉与六个模块（政治分歧的定位与换位）

## R — 原文 (Reading)

> 所以判断一件事是否道德很容易，而为自己的判断找到理由则需要思考时间。科学家相信人的道德判断是直觉式的、感性的快速判断，并非来自理性计算。人的理性，只不过是为自己的感情服务而已，是先有了答案再去想办法找证据。……他认为人脑中有六个最基本的道德模块，能够对生活中出现的各种事件进行模式识别，来自动做出道德判断。……但是这些道德模块在每个人心中的相对分量的大小是不一样的。……每一种政治意识形态，都对应于这六个道德模块的一种组合。
>
> — PART I · 人的正义思想是从哪里来的？（L1067-L1105）

## I — 方法论骨架 (Interpretation)

本单元是一套**分歧定位框架**（全单元转述自 Haidt《正义之心》，L1045）：道德判断是「直觉先定答案、理性事后补理由」——所以道德/政治争论里讲道理基本改变不了判断，只会改变对方的说辞。

六个道德模块是这套直觉的零件（括号内为作者补充的中西对应，L1089-L1099）：

1. 关爱 / 伤害（仁）
2. 公平 / 作弊（信）
3. 忠诚 / 背叛（义）
4. 权威 / 服从（礼）
5. 圣洁 / 堕落（以「恶心」为感觉、有点宗教味道的模块）
6. 自由 / 压迫（儒家少讲、道家讲）

判据三条：

- **模块俱全、权重不同**：每人都有六个模块，但相对分量不一样；政治意识形态＝模块组合——自由主义者重关爱、自由、公平，保守主义者六模块同等重视，自由论者只重自由＋公平（L1133-L1203）。
- **先定位、不评判**：分析分歧先问「对方哪个模块最强、我被哪个模块驱动」，把分歧表述为**组合差异**而非道德高下。
- **换位而非说服**：不靠列证据去改变对方的直觉判断，改为承认对方模块的合理关切＋给兼容方案（具体动作）。

完成标准：每个当事方都有「模块判定＋原话依据」；产出一句不含高下判断的改述；回应稿先对齐模块、再落到动作。

## A1 — 书中的应用 (Past Application)

### 案例 1: 海特的三道道德测试题（美印调查差异）
- **类型**: 书中演练（PART I · 人的正义思想是从哪里来的？）
- **问题**: 不同文化对「不伤害任何人」的行为会做出相同的道德判断吗
- **方法论的使用**: 用三道测试题（吃自家被撞死的狗；一道涉及违反圣洁感的极端行为——原题用语冒犯，此处按规格改写；把旧国旗撕成条当抹布）调查不同人群，「它们没有正确答案」
- **结论**: 大部分美国人认为这些行为谈不上不道德（没有人受到伤害）；印度调查中大部分印度人认为不道德、应受遣责——道德判断受文化塑造
- **结果**: 如引文；书中还指出神性道德观是现代中国所没有的

### 案例 2: YourMorals.org 十三万人的道德模块测试
- **类型**: 书中转述（PART I · 人的正义思想是从哪里来的？）
- **问题**: 政治意识形态能否用道德模块的组合来刻画
- **方法论的使用**: 2011 年海特等研究者建道德测试网站（YourMorals.org），对超过十三万人做道德模块测试，再把结果与政治意识形态对照
- **结论**: 得到每种意识形态对应的模块组合；书中称另有实验得到一致结果（该段 OCR 残缺，不引具体内容）
- **结果**: 如引文（横轴政治立场、纵轴道德认同程度的组合图）

### 案例 3: 人们为道德判断补找理由的现象
- **类型**: 书中转述（PART I · 人的正义思想是从哪里来的？）
- **问题**: 被追问「为什么认为某事不道德」时，人们怎么回答
- **方法论的使用**: 海特研究中的观察——人们往往不从个人道德观角度解释，而爱找实用主义理由（如「吃狗肉会生病」）
- **结论**: 先有直觉判断、后有理性理由；理由常是事后拼凑
- **结果**: 如引文（理由难找时干脆说「我知道这是错的，我只是还没想到理由」；未给统计数字）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 家庭群/同事群里为道德、社会或政治话题吵起来，双方各执一词
2. 想不通「为什么摆事实讲道理，对方就是听不进去」
3. 自己对某个行为有强烈反应（反感/恶心/义愤），想弄清是哪个直觉被触发
4. 要面对立场不同的受众发言，想知道对方的敏感点在哪

### 语言信号

- 「缺德就是缺德，这有什么好讨论的」
- 「道理讲了一百遍，他就是不听」
- 「我就是觉得恶心，别问我为什么」
- 「他居然觉得这没什么」「三观不合，没法聊」
- 英文: "I just know it's wrong", "you can't reason with these people", "it's a values thing"

### 与相邻 skill 的区分

- 与 `voter-story-thinking` 的区别: 那条处理选民侧的政治沟通（为什么小故事比政策有效）；本卡是它的前置步骤——先给双方做模块定位，再决定怎么表达
- 与 `debate-defense` 的区别: 那条教你被攻击时如何防守反击；本卡在「讲道理改变不了直觉判断」的前提下，管的是这类争论要不要打、怎么换位
- 与 `evolutionary-psychology` 的区别: 那条解释直觉/本能的来源家族（一般框架）；本卡只做六模块的政治直觉定位与换位动作，不展开进化机制

## E — 可执行步骤 (Execution)

1. **还原分歧现场**
   - 完成标准: 拿到双方原话——谁对什么行为/主张提出反对，用了哪些词（「恶心」「不成体统」「欺负人」等）
   - 判停条件: 拿不到对方原话时，降级为对己方做自测（见步骤 2），并在输出中标注

2. **模块定位**
   - 完成标准: 对照六个模块表，为每个当事方写出至少一个「最重的模块」判定＋依据（引用其原话中的关键词与感觉类型）
   - 输入契约: 分歧描述＋各方原话；判定按三题自测的精神类推（原书未给量表，不补造）
   - 输出契约: 判定表（当事方 / 命中模块 / 依据）

3. **改述分歧**
   - 完成标准: 产出一句「模块组合差异」表述，如「你在意的是 X（圣洁/权威），我在意的是 Y（关爱/自由），是我们权重排序不同」——不出现道德高下判断

4. **换位回应**
   - 完成标准: 起草一段不以说服为目标的回应：先承认对方模块的合理关切，再给兼容方案（具体到可执行动作）
   - 判停条件: 若用户的真实目标就是靠证据取胜去改变对方立场，提醒按 ce108 的口径这大概率无效；有对抗攻防需求时转 `debate-defense`

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要解决具体利益/规则冲突的场合（模块定位只产出理解与措辞，不产出分配方案——规则设计另走激励类工具）
- 用户只想要「谁对谁错」的判决（本卡不做道德评判，也不输出谁更高尚）

### 作者在书中警告的失败模式

- 在道德/政治分歧中用「给出理由、讲清楚道理」的方式说服对方（ce108）：判断是瞬间直觉，理由只是事后补的解释——认知负担实验与催眠实验都显示辩论的证据与逻辑根本不进入判断环节；用对方「讲不出好理由」判断他没有认真思考同样是误判
- 把特定人群的研究结论外推为普世人性（ce123）：受试者是 WEIRD（西方、受教育、工业化、富裕、民主）的一群人，即使在西方社会也是特殊的——「研究表明人们都……」而样本全是大学生/美国人时，结论只能限定在样本内

### 作者的盲点 / 时代局限

- 无标准化量表：六模块如何判定权重、判定细则，原书未给（BOOK_OVERVIEW 已标注）——卡片只做定性对照
- 基因证据自相矛盾：作者一处自认「不太了解现在是否有足够证据」（L1181），后文又写「先天因素绝对非常重要」——两条如实并列，不得推基因决定论
- fMRI 段 OCR 残缺（L1119-L1129），不得作为证据引用
- 原始测试题含冒犯性表述（p116 第二题）——卡片已按规格改写为一般表述（「违反圣洁感的极端行为」），不得引用原句
- 全单元转述自 Haidt《正义之心》：模块理论、测试题、十三万人调查皆是海特团队的研究

### 容易混淆的邻近方法论

- `voter-story-thinking`: 同样面对「讲道理没用」，那条的落点是政治说服（小故事）；本卡的落点是分歧定位与换位
- `evolutionary-psychology`: 直觉的进化解释与本卡同源，但本卡不处理「为什么演化成这样」
- `debate-defense`: 本卡说「说服无效」，那条训练「对抗中的防守」——互补，不互相替代
