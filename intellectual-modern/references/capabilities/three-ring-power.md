# 三围权力分析（名义选民 / 实际选民 / 胜利联盟）

## R — 原文 (Reading)

> 名义选民：在名义上有选举权和被选举权的全体公民。……实际选民：那些真正对谁当领导人有影响力的人。……胜利联盟：必须依赖他们，领导人才能维持自己权力的人。……看一个国家是不是真民主，关键并不在于是否举行选举，而在于胜利联盟（以下简称“联盟”）的人数。……联盟和名义选民的相对大小关系，是政治格局的关键。
>
> — PART I · 放诸古今皆准的权力规则（L1221-L1249）

## I — 方法论骨架 (Interpretation)

一套把「民主 / 独裁」二分替换成**三张名单**的权力分析工具（转述自 Bueno de Mesquita《独裁者手册》，L1219-L1225）：

- **名义选民**：名义上有权的人（全体选民）。
- **实际选民**：真正对领导人去留有影响力的人。
- **胜利联盟**：领导人必须依赖、能推翻他的人——领导人取悦的对象从来只有他们，不是全体人民。

**判格局**：看「联盟 / 名义选民」的相对大小——联盟人多 ≈ 民主，联盟人少 ≈ 事实独裁（不论有没有选举）。「民主的本质不是选举，而是联盟人数多。」

**五条权力规则**（拿来给动作对号入座，L1235-L1243）：

1. 联盟越小越好（收买便宜）；2. 名义选民越多越好（方便替换）；3. 控制收入（知道钱在哪并能控制流动）；4. 回报联盟要够但不过多；5. 绝不动联盟的奶酪去讨好人民（伤害联盟利益的改革必败）。

怎么用：① 给分析对象（国家/公司/组织）列三层名单；② 算两个数字之比判格局；③ 把领导人（或对手）的近期动作逐条对照五规则，解释「为什么他这么做 / 为什么改革推不动」。名单判定细则原书未给，须自订标准并标注。

## A1 — 书中的应用 (Past Application)

### 案例 1: 惠普 CEO Fiorina 的权力操作
- **类型**: 书中转述（PART I · 放诸古今皆准的权力规则）
- **问题**: 一个业绩糟糕的 CEO，任内动作不断，如何解释她的行为逻辑
- **方法论的使用**: 按五规则复盘——一上台就在董事会排除异己（规则 1：减少联盟人数）；不顾市场反对坚决收购康柏（规则 2：扩大名义选民、冲淡董事会中对自己的反对势力）；给新董事会加薪（规则 4：收买联盟）
- **结论**: 每个动作都符合权力规则；书中点破关键——企业董事关心股价胜过「喜爱」CEO
- **结果**: 任职六年后 2005 年被迫下台，仍拿到巨额遣散费；书中推测若惠普是一个国家，她或许能一直干下去

### 案例 2: 华盛顿不称帝的「资本论」
- **类型**: 书中转述（PART I · 放诸古今皆准的权力规则）
- **问题**: 华盛顿施行民主而不称帝，是出于个人美德吗
- **方法论的使用**: 用联盟结构检验——美国建国靠的军事力量本身就是各州组成的一个联盟，根本不是谁一家独大的局面
- **结论**: 「华盛顿哪有称帝的资本」；民主的条件是建政之初联盟人数就比较大，而非领袖品德
- **结果**: 未说明（史论性判断）

### 案例 3: 路易十四与朱元璋：替换与削弱联盟
- **类型**: 书中转述（PART I · 放诸古今皆准的权力规则）
- **问题**: 领导人如何对付「不是自己人」的旧联盟
- **方法论的使用**: 观察替换动作——路易十四扩大名义选民、用新贵族替代旧贵族、把旧贵族关进凡尔赛宫使其富贵只能依靠他；朱元璋屠功臣以削弱联盟能力、证明联盟成员可替换
- **结论**: 对付联盟的手法＝收买＋替换；对领导人来说联盟成员的能力并不重要、忠诚最重要；作者推测科举制扩大名义选民是皇帝统治稳定的一大原因
- **结果**: 未说明（作为权力规则的例证）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 分析一家公司/机构的人事地震与派系变动：到底谁说了算
2. 读国际新闻，想判断某国究竟算不算民主、某笔对外援助到底在干什么
3. 想解释「为什么好领导干不长、腐败者却长期在位」
4. 组织里资源/政策突然倾斜，想判断它在回报谁

### 语言信号

- 「到底这是谁的意思」「上面的人听谁的」
- 「那还不都是体制问题」
- 「他这么烂为什么还下不了台」
- 「换汤不换药，下面的人就是摆设」
- 英文: "who really calls the shots", "it's the system", "why is he still in power"

### 与相邻 skill 的区分

- 与 `voter-story-thinking` 的区别: 那条处理选民侧（为什么政治沟通要讲小故事）；本卡处理领导者侧（他必须取悦谁）——两侧合起来才是完整的政治分析
- 与 `strangers-not-family` 的区别: 那条破「国家/组织利益」的拟人化直觉（政策视角）；本卡把「国家利益幻觉」还原成联盟利益结构，并给出动作复盘的器械
- 与 `starfish-vs-spider` 的区别: 那条讲组织形态（集权 vs 去中心化）与抗打击能力；本卡讲权力维系结构（联盟大小与维系手段）——前者问「组织像什么」，后者问「谁在支撑领导人」

## E — 可执行步骤 (Execution)

1. **列三层名单**
   - 完成标准: 为分析对象分别写出名义选民 / 实际选民 / 胜利联盟三层名单，每层附判定依据
   - 输入契约: 待分析对象的基本结构与近期的人事/资源动作；缺失时先收集，不得凭空代列
   - 边界注记: 联盟成员判定细则原书未给，按 p120 的定义自订判定标准并在输出中标注

2. **判格局**
   - 完成标准: 给出「联盟人数 vs 名义选民规模」的比较与格局结论（偏民主 / 偏事实独裁，不论有无选举）
   - 输出契约: 三行——三层名单、两个数字之比、格局判定

3. **五规则对号入座**
   - 完成标准: 把领导人与对手的近期动作逐条核对五规则，至少命中 3 条并写明「动作 → 规则」对应
   - 判停条件: 若手上动作信息不足 3 条，如实输出「证据不足以对号」，不硬凑

4. **输出与边界注记**
   - 完成标准: 产出四件套——① 三层名单（附依据）② 格局判定 ③ 动作-规则对照表 ④ 边界注记（判定细则为自订；作者自认税率模型「相当不可靠」；理论为转述、含强判断）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 内幕与名单无法获取的组织：三张名单全靠猜测时，本卡只能产出「标注可信度的假设」，不能当结论分发
- 价值判断与法律定性问题（「这样做好不好、合不合法」）——本卡解释结构，不做规范评判

### 作者在书中警告的失败模式

- 用「制度」解释一切（ce109）：制度与其说是答案不如说是问题本身——同一统治者、同一时期，比利时越来越民主而刚果越来越独裁，「制度问题」解释不了，联盟结构才能
- 相信「经济发展必然带来民主」（ce112）：反了——经济好时领导人有钱安抚联盟、反而更不会改；民主化更常发生在经济危机、领导人没钱「按不住」联盟的时候
- 把结果归因于个人美德（ce113）：华盛顿不称帝是因为「哪有称帝的资本」，不是道德高尚
- 指望外国推动民主（ce110）、以为援助能帮助当地民众（ce111）：援助常被当地独裁者截留用于回报联盟，反而巩固其统治

### 作者的盲点 / 时代局限

- 联盟成员的判定细则原书未给（BOOK_OVERVIEW 已标注）——操作时必须自订判定标准
- 作者自认税率模型「相当不可靠」（L1295）；批评者认为该理论「大大美化了美国的民主」并高估美国联盟人数（L1281）——两条如实保留
- 理论「难被反驳」的批评（BOOK_OVERVIEW）：解释力强的另一面是可用性须与预言/复盘的验证挂钩
- 全书为 Bueno de Mesquita《独裁者手册》的转述（含「国家利益是幻觉」等强判断），引用须随带转述来源

### 容易混淆的邻近方法论

- `strangers-not-family`: 同破「国家利益幻觉」，那条落在政策视角与陌生人社会；本卡落在联盟结构与权力规则
- `starfish-vs-spider`: 组织形态学 vs 权力结构学——判断「组织能否在打击下存活」用前者，判断「谁在支撑一把手」用后者
- `voter-story-thinking`: 同属政治分析，那条在选民侧、本卡在领导者侧
