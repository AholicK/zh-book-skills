# 狐狸与刺猬：一位专家（或一个说法）到底该不该信

## R — 原文 (Reading)

> 所以我们智识分子的最根本教训，就是要做狐狸，不要做刺猬。……狐狸乐于接受新的信息；……狐狸对自己决策的信心远小于刺猬；……狐狸对很多事情持怀疑态度；……当考虑冲突的时候，狐狸能看到双方可能正确的方面；……狐狸喜欢有多个答案的问题，他们在解决问题的时候常常能发现多个选择……这个准确与否，与专家的专业从业时间，是否能接触到机密资料，他是自由派还是保守派、乐观派还是悲观派，都没关系。唯一有关系的是专家的思维方式。
>
> — 自序 · 做个复杂的现代人（L157-L181）；自序 · 狐狸与刺猬（L137）

## I — 方法论骨架 (Interpretation)

判断一位专家（或一个有具体内容的说法）该不该信，不看头衔看**思维方式**——这是泰特洛克二十年预测研究的结论（**转述自泰特洛克**）：专业、从业时间、能否接触机密资料、自由派还是保守派、乐观还是悲观，都与预测准不准无关；唯一相关的是狐狸式还是刺猬式。

- **刺猬**：非常深入地了解自己的小领域，有一个「大主意」，在简约的名义下寻求和扩大它的解释力；现实不符就忽略现实，预测落空就找理由说「这恰恰说明我当初是对的」。
- **狐狸**：知道很多小事，乐于接受新信息，对自己决策的信心小，做过决定仍换视角再想，总爱修正预测，能看到冲突双方可能正确的方面，喜欢有多个答案的问题。

操作上把狐狸十特征当成一张**定性对照表**：拿对象的言论与行为逐条对照，命中越多越该信；刺猬式断言先降权，不单独作为决策依据。

两个不可省的补充：① 刺猬并非无用——世界任何时候都需要刺猬来提供观点和建议，只是它在科学决策中的真正地位只是个「吹鼓手和工具」（L181）；② 这条判据的第一个检查对象是**自己**——「不要被自己心中的『大主意』劫持」（p01）。

判停点：若能拿到该专家**事前设定概率**的预测记录，优先用「事前概率—事后对账」核实（p18）；拿不到这类记录时，才退回十特征定性对照。

## A1 — 书中的应用 (Past Application)

### 案例 1: 泰特洛克 284 位专家二十年预测研究
- **类型**: 书中转述（PART I · 别用「常识」理解复杂世界）
- **问题**: 专家的预测到底准不准，凭什么判断一位专家的可信度
- **方法论的使用**: 泰特洛克 1984 年起调查 284 位以预测政治经济趋势为职业的政治学家、智囊和外交官（例如「戈尔巴乔夫有没有可能被政变搞下台」），要求他们对多数问题给出三种可能性的概率；研究做了约二十年，等预测全部水落石出后对账
- **结论**: 与准确度有关的不是专业、资历、立场，而是思维方式（狐狸 / 刺猬）
- **结果**: 专家总成绩不如把三种可能均设为 33%（不如抛硬币）；本专业领域的得分反而比专业外更差；书中同时提到专家总体仍比普通人略高一点（L291）

### 案例 2: 用头衔与专业对口判断可信度（反例）
- **类型**: 书中转述（PART I · 别用「常识」理解复杂世界）
- **问题**: 面对专家意见，先看「他是不是专家」「是不是本专业」「有多少机密资料」「从业多少年」，据此做投资、择业或公共决策
- **方法论的使用**: 泰特洛克研究的反面用法——这些指标恰恰与预测准确度都无关；作者据此主张社会科学应像硬科学一样依靠实验和数据（转述自 Watts《什么都是显然的》）
- **结论**: 头衔与专业对口不是可信度证据；专业身份并不校正过度自信；只给立场与断言、拿不出概率式预测的人无法被检验
- **结果**: 未说明（书中以研究结论立论，未交代该用法导致的具体后果）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到一篇专家观点、研报或对未来的断言，想知道这位专家（或这个说法）该不该信
2. 有人拿头衔、机构、从业年限为某个判断背书，用户想核对这个背书管不管用
3. 用户发现自己长期用一个框架解释一切问题，怀疑被「大主意」劫持
4. 需要为一个有争议的公共问题选立场，手边只有单一领域专家的意见
5. 复盘自己过去做过的判断：哪些地方当时像刺猬

### 语言信号

- 「他是 XX 领域的专家，应该不会错吧」
- 「这人说的到底靠不靠谱？」
- 「怎么看都只有这一个解释」
- 「某某教授说的，还能有假？」
- 「我是不是被自己的观点绑架了」
- 英文: "should I trust this expert?", "what's his track record?", "this theory explains everything"

### 与相邻 skill 的区分

- 与 `multi-method-toolkit` 的区别: 那条负责「招要多」（方法库是狐狸式的底气：招多才能修正）；本 skill 负责「信不信」（对人或说法做可信度判定）
- 与 `common-sense-skeptic` 的区别: 同一「先检验、再相信」纪律的两个入口——那条处理「大家都这么觉得」的主流看法，本 skill 处理「某位专家这么说」
- 与 `big-data-prediction` 的区别: 看人能否被信任 vs 看成见能否预测人（前者评估预测者，后者评估预测方法本身）

## E — 可执行步骤 (Execution)

1. **取对象**
   - 完成标准: 拿到待评估的**具体言论或预测原文**（谁、在什么场合、说了什么、什么时间说的）并逐字记下
   - 输入契约: 一段可引用的言论；只有名字、没有言论时先请用户提供原文，不许凭印象评估

2. **标刺猬标记**
   - 完成标准: 逐条核对三个警告信号——① 一个理论能解释所有领域的问题且越用越顺手；② 预测失败后给出「这恰恰证明我是对的」式解释；③ 只收集支持自己学说的案例；并写出其「大主意」是什么

3. **对照十特征**
   - 完成标准: 对狐狸十特征逐条给出「符合 / 不符 / 无信息」三态判定，附一句证据出处；**不做加权、不合成总分**（原书未给权重与打分细则，使用者只能做定性对照）

4. **查领域关系**
   - 完成标准: 说明该言论是否跨出他的小领域，并提示转述自泰特洛克的反直觉结论——本专业领域的预测得分可能反而更差

5. **输出判定**
   - 完成标准: 给出①判定（可信 / 需降权 / 仅作参考）②命中的特征清单 ③命中的刺猬标记 ④下一步动作（另找狐狸式来源，或按 p04 补充其他领域的论点数据）
   - 输出契约: 一份可复述的三段式结论：判据（哪些特征/标记）→ 判定 → 行动

6. **自查（不可省）**
   - 完成标准: 用同样的十条特征对照**自己**在同一议题上的立场，写出自己最像刺猬的一条
   - 判停条件: 若用户其实只是要一个决策结论、不接受概率式检验，说明本卡只给可信度评估，决策仍需汇总多方论点（p04）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 手上没有对象的具体言论或预测文本时（本卡评的是言论与行为，不是人品、名声与人设）
- 用户要的是「替我做决定」时——评估完可信度仍需再收集别人的论点数据（p04），本卡不产出决策
- 纯价值排序与审美判断（没有可检验的预测，任何特征对照都无处落地）

### 作者在书中警告的失败模式

- 十特征**无权重、无打分细则**（原书未给）：只能做定性对照；若自行补造权重与分数线，即属超出原书
- 「大主意劫持」的检查对象首先是自己（p01）：只拿它指控别人、不查自己，等于换了一种刺猬式自信
- 以头衔 / 专业对口 / 从业年限给可信度打分（ce02 反例）：这三样与准确度都无关
- 单一学说扩散到不适用的领域：作者说这类知识分子「其实都是刺猬」（ce01）

### 作者的盲点 / 时代局限

- 「专家总成绩不如均分 33%」是**泰特洛克研究结论的转述**，引用须随带「转述自泰特洛克」；书中也写明专家总体仍比普通人略高一点（L291）——不可写成「专家一律不可信」
- 刺猬不是没用：作者明说刺猬可当「吹鼓手和工具」（L181）——不可写成「刺猬一律不可信」
- 十特征来自统计问卷得到的**群体差异**，用于单个专家时是启发式，不是个体判定公式；原书未给个体校准方法
- 研究基于 1984—2003 年间的政治预测，书中未讨论信息环境剧变（社交媒体、预测市场）之后专家可信度的评估方式

### 容易混淆的邻近方法论

- **性格测评式判断**：把「狐狸 / 刺猬」读成「狡猾 / 呆萌」或性格褒贬——本卡限定在做预测与判断的一方，且只用于预测准确度（L145）
- **阴谋论式怀疑**：对一切专家一律不信——作者保留的立场是有检验的怀疑，且承认专家群体平均仍略高于普通人
