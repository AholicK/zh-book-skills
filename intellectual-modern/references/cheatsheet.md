# 决策规则速查 — 《智识分子：做个复杂的现代人》

| 能力 | 一句话规则 |
|---|---|
| 狐狸与刺猬：专家可信度评估（自序） | 判断专家或说法是否可信，看思维方式不看头衔：狐狸式特征越多越可信，刺猬式断言先降权 |
| 智识分子与理工科思维：博雅教育总纲（自序） | 复杂问题不绑定单一理论：多流派套路轮换试招，算「度」与代价，一招不成再换一招 |
| 常识是我们的敌人：社会科学方法与概率史观 | 对「大家都这么觉得」的常识默认不信任：先找统计与重复实验，再决定信不信 |
| 模仿的雪崩效应：社会传染与维稳干预 | 面对模仿型事件（模仿自杀、骚乱、跟风），干预点是「事件初期的几步」，不是起因也不是结果 |
| 国家不是家庭：陌生人社会与政策视角 | 先判议题属于家庭逻辑还是陌生人社会逻辑，再把「是否道德」的问法改写为「怎样的制度有效率」 |
| 边际分析与成本思维 | 继续投入只看下一步：下一单位收益大于成本才继续，等于成本就该停止 |
| 激励设计：改变行为的最佳办法 | 改行为先改激励：挣得式奖励（先做后给、即时兑现、按件定价），并先做反向激励自检 |
| 价格信号与市场化条件 | 市场化前先三问：价格信号有无、能否反映质量与需求、链条能否贯通到供给端 |
| 复杂系统与勿扰动：Rossi 铁律与意外后果 | 先判 complex 再动手：别用凭空大招扰动复杂系统，先设净影响预期值≈0（Rossi 铁律） |
| 选民与民主失灵：理性的无知与小故事 | 公共沟通别上经济课：先还原对方脑中的「小故事」（勇敢故事／奋斗故事） |
| 高效能任性：公平世界假设与做好人的理由 | 别信「善有善报」：先修世界观（公平世界假设是错的），再问自己是奴隶还是主人 |
| 统计歧视：经济歧视的判别与个人应对 | 被区别对待先分类（敌意歧视 vs 经济歧视），再用信号自保：「我今天要拿三个报价」 |
| 道德直觉与六个模块 | 道德/政治分歧先做六模块定位：把分歧当「模块组合差异」，用换位回应代替讲道理 |
| 三围权力分析：名义选民/实际选民/胜利联盟 | 分析权力格局：列三层名单（名义选民/实际选民/胜利联盟），看联盟与名义选民之比，再拿五规则对号入座 |
| 教育分类机器：高考、军备竞赛与门槛 | 择校报班先过四问：分类谁、门槛是什么、是不是抬价型竞争、因果方向对吗 |
| 名校机制与素质教育真相 | 冲不冲名校：先做溢价剥离（同被录取对照），再复核低收入例外；读学校看 KPI 与资金流向 |
| 把穷人变成正常人：KIPP 与品格教育 | 给行为亏空的孩子补习惯：一切靠挣、即时反馈、固定结算——不作通用教育法 |
| 圣贤之道：品格之路与成熟 | 先自测是不是「想办大事的人」，再用亚当I/亚当II复盘与四要素修炼品格——目标成熟不是成功 |
| 流水线教育识读：标准学生、隐含教案与三层次 | 三把尺子识读教育：隐含教案（学校在教什么）、三层次（工具/工艺品/主人翁）、主人与奴隶对照 |
| 大数据预测与英雄判据 | 用「我被预测到了吗」自测：处处符合大数据＝可替代，有一条预测不了的线＝不可替代 |
| 英雄的套路与使命：内在动力 | 分清两类成功与两种动力：长期事业只由内在动力（使命感）驱动 |
| 创新=意外：企业家三境界与供给创造需求 | 用「意外量＝信息量」判定贡献，用三境界定位自己在需求链的哪一端 |
| 可预测性判定与数据军备竞赛 | 三问判简单/复杂：个体独立＋无正反馈＝可预测，含正反馈＝可能出黑天鹅 |
| 大尺度与硬条件 | 大尺度问题先定尺度、再抓长期不变因素——硬条件要列限制与机遇双栏 |
| 技术左右天下大势 | 评估新技术先看它的攻防属性与成本结构，而不是发明者的愿望 |
| 突击式学英语 | 可量化技能要短期突击练成：背词300～600/天、读完一本真书 |
| 信息极客三功夫 | 查数据是膝跳反应：先问原始出处，再拿数据说话 |
| 舌战群儒：辩论识人与防守 | 辩论应关于议题不关于人；识别三招话术、只做防守，网络场景可以不接战 |
| 贝叶斯信念更新 | 把信念写成概率：估先验与两个似然、算后验、随新证据迭代——观点随事实改变 |
| 进化心理学：解释法与限度 | 只有「说不清却普遍如此」的行为才用进化心理学解释，且必须并列替代解释、写明限度 |
| 知识可靠度与科学素养 | 先按领域给知识定信任权重（物理＞工程＞生物医学），再用两条准则行动：试试看、对「宇宙真理」式宣称不理 |
| 宇航时代与大科学 | 大项目能不能持续，看利益触发点：无实际利益与接续投入的就是郑和模式 |
| 数字时代：个人数据的攻防 | 不想被数字玩就学会玩数字：先知道你的数据位置，再主动做个价格敏感者 |
| AI 与就业：与机器竞赛 | 先用『三类输赢』定位自己，再按三条转型建议行动——但个人对策不解决就业总量问题 |
| 人机分工：人的三个任务 | 人机分工：机器是经验主义者，人守三个位置——打破常规、表达好恶、感情技能 |
| 海星与蜘蛛：去中心化组织诊断 | 海星用三策略、蜘蛛才擒王——先诊断形态，再核算去中心化的弱点 |
| 合弄制：以工作为本的组织操作系统 | 合弄制不是零管理：目的声明 → 管治会议拆功用 → 圈与链长 → CEO 签宪法 |
| 该死就死：市场精神与创新代价 | 对每个在办项目三问：该不该死？为何死不掉？谁在挡着？ |
| 富足时代与需求派经济学 | 先查隐含假设，再用供给/需求两副镜子读经济主张，结论连前提一起引用 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
