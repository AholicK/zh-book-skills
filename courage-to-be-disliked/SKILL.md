# 《被讨厌的勇气：“自我启发之父”阿德勒的哲学课》 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 临床心理治疗、精神科诊断与用药（本方法不替代医疗）
- 正在发生的家庭暴力、霸凌、人身安全危机与自伤／伤人风险（先确保安全并联系专业帮助）
- 法律、医疗、劳动等专业处置与纠纷追责
- 把「目的论／课题分离／被讨厌的勇气」用于否定受害者的遭遇或要求其忍耐

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 人不是被过去决定的——决定人的不是发生了什么，而是赋予经历的意义；被改写的是「赋予意义」这一步，不是事件与痛苦的真实性。
2. 一切烦恼皆源于人际关系；解开的入口是课题分离：问「某种选择带来的结果最终由谁承担」，不干涉别人的课题，也不让别人干涉自己的。
3. 课题分离不等于放任，也不等于疏远：它是「在了解的基础上守护、随时准备援助」，是人际关系的入口而非终点。
4. 自由就是不再寻求认可：被讨厌的勇气是行使自由的代价，不等于惹人厌或作恶；「人际关系之卡」始终握在自己手里。
5. 一切人际关系都应是横向关系（虽不同但平等）：不批评也不表扬，用感谢与喜悦的语言（谢谢／我很高兴／帮了大忙了）替代评价。
6. 幸福是「贡献感」：自我接纳 → 他者信赖 → 他者贡献的循环缺一不可——贡献感可以不被看见，但不可用「被认可」换取。
7. 人生是连续的刹那：不把现在当准备期；意义不存在普遍答案、由自己赋予，「引导之星」是他者贡献。
