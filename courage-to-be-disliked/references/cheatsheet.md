# 决策规则速查 — 《被讨厌的勇气：“自我启发之父”阿德勒的哲学课》

| 能力 | 一句话规则 |
|---|---|
| 目的论：改写「过去决定现在」 | 把「因为过去××所以现在××」翻转成「为了××而维持现状」，再回到此时此刻选一次。 |
| 情绪与症状的目的分析（怒气与症状管理） | 把「我控制不住脾气」改写成「我在用脾气达成什么」——再换一个交流工具。 |
| 权力斗争识别与退出 | 对方要的是争赢不是讨论：识别信号、不做反应、承认错误不等于失败。 |
| 自卑感 / 自卑情结 / 优越情结三分诊断 | 分清自卑感（人人都有）／自卑情结（当借口）／优越情结（虚假优越），再各自给出路。 |
| 竞争退出与伙伴重构 | 从「与别人比」切换到「与理想的自己比」，把他人从对手改置为伙伴。 |
| 人生三大课题与人生谎言 | 把「不敢面对的人际关系」按工作／交友／爱归位；「挑缺点」常是借口系统而不是事实清单。 |
| 课题分离判定与执行（核心程序） | 问一句「这个结果最终由谁承担？」——不干涉别人的课题，也不让别人干涉你的。 |
| 亲子/家庭课题分离与援助原则 | 把孩子/父母的课题还回去：不妄加干涉、随时准备援助——把马带到水边，但不强迫其喝水。 |
| 认可欲求诊断与「被讨厌的勇气」 | 不再为「不被讨厌」而活：写下自由的代价，把「人际关系之卡」收回自己手里。 |
| 横向关系与鼓励（替代表扬/批评） | 不批评也不表扬：用「谢谢／我很高兴／帮了大忙了」替代评价，把关系改成「虽不同但平等」。 |
| 存在标准（行为/存在双标准） | 评价起点从「做了什么」换成「存在于这里」：对存在本身表达喜悦与感谢。 |
| 自我接纳与自我意识 | 别对自己撒谎说「我能行」——承认 60 分，再问「如何才能接近100分」。 |
| 他者信赖（信用/信赖） | 分清「有条件才给」（信用）与「无条件相信」（信赖）——信赖是手段，且可以剪断。 |
| 他者贡献与「幸福即贡献感」 | 问题从「别人为我做了什么」换成「我能为他人做什么」——幸福即贡献感。 |
| 问题行为功能分析与「特别存在」 | 问题行为不是道德问题：读它在关系里换到了什么（关注／特别／报复），先停掉错误的反馈回路。 |
| 人生和谐、工作狂与甘于平凡 | 别用人生一个侧面判断整体；「普通并不等于无能」，甘于平凡不是懒惰。 |
| 此时此刻与刹那人生 | 人生是点的连续：不把现在当准备期，今天做一个「解一个算式」粒度的动作。 |
| 人生意义自赋与引导之星 | 不存在普遍的人生意义——它由你自己赋予；迷失时看方向指针（他者贡献）。 |
| 共同体感觉与「更大共同体」 | 从「我和你」开始：归属感不是被给予的，靠参与获得；杯子外还有更大的天地。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
