# 《被讨厌的勇气》整书导读

## 基本信息

- **标题**：《被讨厌的勇气：“自我启发之父”阿德勒的哲学课》
- **作者**：［日］岸见一郎、古贺史健 著；渠海霞 译
- **出版**：机械工业出版社 2015 年 4 月第 1 版第 1 次印刷（原著《嫌われる勇気》KIRAWARERUYUKI，2013；ISBN 978-7-111-49548-2）
- **内容类型**：对话体人生哲学（阿德勒心理学的通俗诠释；非教材、非治疗手册）
- **能力结构**：19 张能力卡（7 张晋级为独立 Skill + 12 张经来源路由入口可达）

## 一句话主旨

人不是被过去所决定（目的论），一切烦恼皆源于人际关系；通过课题分离划清界限、以横向关系相待、
培养共同体感觉（自我接纳—他者信赖—他者贡献），任何人都能随时获得幸福——所缺的只是「勇气」，
包括被讨厌的勇气。

## 骨架（五个一级论点 = 五夜递进）

1. **第一夜「我们的不幸是谁的错？」**：否定原因论、引入目的论（情绪与症状可能是为「目的」服务的手段）；「心理创伤并不存在」的真意是经历本身不决定什么；生活方式约 10 岁被无意识「选择」、可以重新选择；「不改变」是自己的决心。
2. **第二夜「一切烦恼都来自人际关系」**：烦恼皆源于人际关系；自卑感（主观臆造）vs 自卑情结（当借口用）vs 优越情结（虚假优越感、夸耀不幸）；人生不是与他人的比赛；权力斗争与复仇阶段；人生三大课题（工作/交友/爱）与「人生谎言」。
3. **第三夜「自由就是不再寻求认可？」**：课题分离（判定＝某种选择的结果最终由谁承担；不干涉别人的课题、也不让别人干涉自己的）；父母也得放下孩子的课题；自由就是被别人讨厌；「人际关系之卡」握在自己手里；共同体感觉的完整框架（范围「无限大」，实操以「更大共同体」为准）。
4. **第四夜「要有被讨厌的勇气」**：横向关系（「虽不同但平等」）；不批评也不表扬（表扬＝纵向关系＋操纵）；鼓励＝基于横向关系的援助（谢谢／我很高兴／帮了大忙了）；有价值就有勇气；存在标准（不按理想形象做减法）。
5. **第五夜（副标题 OCR 未转出）**：自我接纳（vs 自我肯定；「肯定性的达观」）；他者信赖（信用 vs 信赖）；他者贡献（「幸福即贡献感」，看不见的贡献也可）；甘于平凡的勇气（vs「廉价的优越性追求」）；人生是连续的刹那；人生意义由自己赋予、「引导之星」＝他者贡献。

**逻辑链**：目的论（否定原因论）→ 否定认可欲求 → 课题分离 → 自由＝被讨厌 → 横向关系 → 共同体感觉 → 自我接纳/他者信赖/他者贡献 → 幸福＝贡献感 → 活在此时此刻。

## 叙述与文本说明（引用纪律）

1. **对话体分层**：全书主体是「哲人」与「青年」的对话。「哲人」所说＝本书主张（岸见-阿德勒学）；「青年」是反方与典型读者，**不得把青年的反方观点当作本书主张**；书中以引号明确标记的阿德勒言论为转述（非逐字稿）；推荐序/译者序/后记是第三方文字，不进入能力卡主体。
2. **案例来源分层**：哲人亲历（身高 155cm、与父亲关系等）／青年经历（闭门不出的朋友、与哥哥比较等）／转述案例（母亲与女儿的电话等）／教学演示（18 度井水、马与水等）。
3. **OCR 缺陷登记（引用照抄、不改字）**：`自单`=自卑、`惯怒`=愤怒、`自已`=自己、`一一`=破折号、`震慢`=震慑类、`暮然`=蓦然、`伽锁`=枷锁、`蔽打/殿打`=殴打（L2273）、`蔬远`=疏远、`羁纤`=羁绊（即「三大羁纤」）；**第五夜副标题未在 OCR 稿中转出**。

## 关键概念速查

术语的完整作者定义与关键区分见 `glossary.md`（28 条）。最常用于判定的六个：

| 术语 | 一句话 |
|---|---|
| 目的论 | 不是过去的「原因」决定现在，而是现在的「目的」制造情绪、症状与行为（g01） |
| 课题分离 | 判定法＝「某种选择所带来的结果最终要由谁来承担」；不干涉、不被干涉；≠放任、≠疏远（g10） |
| 被讨厌的勇气 | 行使自由的代价＝在人际关系中被别人讨厌；**不是**去惹人厌或作恶（g13） |
| 横向关系 | 「虽不同但平等」；表扬与批评同属纵向关系，替代物是基于横向关系的鼓励（g16/g17） |
| 自我接纳 | 诚实接受「做不到的自己」再朝能做的方向努力；与「自我肯定」（对自己撒谎）相反（g18） |
| 他者贡献 | 对作为伙伴的他人给予影响、作出贡献；「幸福即贡献感」，但不可用「被认可」换取（g21） |
