# 人生三大课题与人生谎言：关系归位与借口识别

## R — 原文 (Reading)

> 阿德勒把这些过程中产生的人际关系分为“工作课题”“交友课题和“爱的课题”这三类，又统称为“人生课题”。
>
> — 第二夜 · 人生的三大课题：交友课题、工作课题以及爱的课题 L1593

> 阿德勒把这种企图设立种种借口来回避人生课题的情况叫作“人生谎言”。
>
> — 第二夜 · “人生谎言”教我们学会逃避 L1705

## I — 方法论骨架 (Interpretation)

这张卡做两件事：给关系归位，给借口识别。

① 归位：人际关系按距离和深度分三栏——工作课题、交友课题、爱的课题，统称人生课题，亦称「三大羁纤」（L1597）[原文如此]（羁绊）。它不是劳动、纳税一类的社会义务：青年当场把课题读成义务，被明确纠正。门槛排序：工作最低（有共同成果目标、下班或转行后可退回他人关系）；交友课题没有工作那样的强制力，更难开始和发展；爱之课题最难（恋爱可以分手，亲子原则上不可分割）。

② 识别：为回避人生课题而设立借口，叫人生谎言。检验方法是查时间顺序——先有要讨厌、要结束关系的目的，之后才搜集符合目的的缺点材料；关系末期连对方睡眠时的呼吸声都惹人生气，就是材料后找的实况。

两件事共用同一条口径：这是勇气的问题，不是善恶问题。用道德语言使用它（指责撒谎、懦弱），会立刻触发对抗，反而变成新的用怒气回避。

归位之后，问题从这些关系为什么烦，变成我在回避哪一个、以什么方式回避——这是把问题交给课题分离处理的入口。行为目标（自立、与社会和谐共处）与心理目标（我有能力、人人都是我的伙伴）都通过直面人生课题实现；归位相当于把这两组目标拆回具体关系上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 哲人高中时代不想交朋友
- **类型**: 哲人亲历（第二夜 L1631-1635）
- **问题**: 哲人自陈高中时代根本不想交朋友，每天都独自学习希腊语、德语、研读哲学书，母亲为此不安地去找班主任老师
- **方法论的使用**: 老师回答「不必担心。他是不需要朋友的人。」——交友课题的价值不在数量；这句话同时给了母亲和哲人底气，哲人后来用它论证：该考虑的是关系的距离和深度
- **结论**: 朋友或熟人的数量不构成衡量关系价值的指标
- **结果**: 有结果：高中时代只有一个朋友，几十年没见，仍「感觉我们现在再次见到，也能够像那个时候一样交往」

### 案例 2: 讨厌 A 这个人
- **类型**: 教学演示（第二夜 L1681-1701）
- **问题**: 假设「你讨厌A这个人，说是因为A身上有让人无法容忍的缺点」——听起来缺点在前、讨厌在后
- **方法论的使用**: 哲人倒转顺序：缺点清单是后找的，先有「要讨厌A」的目的；并用恋爱、夫妻关系末期的现象验证——「就连对方睡眠时的呼吸声都让你生气」，尽管几个月前还不是这样
- **结论**: 理由要按时间顺序检验；目的先行的理由清单，是人生谎言的典型操作
- **结果**: 未说明（青年当场反驳说顺序是反的，哲人用恋爱关系的类比继续推进）

### 案例 3: 浪漫的红线和坚固的锁链
- **类型**: 教学演示（第二夜 L1669-1673）
- **问题**: 恋爱、夫妻关系可以选择分手，亲子关系里“怎么做才好”
- **方法论的使用**: 哲人用「红色丝线」与「坚固的锁链」区分两类关系：恋爱、夫妻可解除，亲子原则上不可解除（「自己手里只有一把小小的剪刀」）；爱之课题因此最难——处理顺序只有一条硬要求：先面对（「无论多么困难的关系都不可以选择逃避，必须勇敢去面对。」），之后才谈继续或剪断
- **结论**: 困难关系的第一动作是面对；逃避与在现状中止步不前都被排除
- **结果**: 未说明（哲人给到「现阶段能说的就是不能够逃避。」为止）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 对室友、同事或伴侣越看越烦，纠结是我太挑剔，还是这段关系该结束
2. 分不清自己的烦恼是事务问题、社交问题还是亲密关系问题
3. 想分手或想远离某人，却发现自己在不停收集对方的罪证，心里发虚
4. 习惯用我性格不适合和人打交道解释所有关系难题，想验证这是不是借口
5. 想按书里的三分类给自己的人际关系做一次清点，找到一直在回避的那一栏

### 语言信号

- 「我看到他就烦，但他好像没做错什么」
- 「我是真的讨厌他，还是在找理由」
- 「这段关系到底要不要继续」
- 「我是不是在逃避什么」
- 英文: "I keep finding reasons to dislike them", "should I end this relationship", "am I avoiding something"

### 与相邻 skill 的区分

- 与 `separation-of-tasks` 的区别: 本卡先做归位（工作/交友/爱三栏）与人生谎言识别；那条接档“这是谁的课题”的判定与双向执行——顺序是先归位、再分离
- 与 `family-tasks` 的区别: 爱之课题里的亲子部分（坚固的锁链、小剪刀）在本卡只做定位与原则；具体处置序列与援助动作（把马带到水边，不强迫喝水）用那条
- 与 `life-meaning` 的区别: 那条回答人生意义由谁赋予、迷失时往哪看（方向指针是他者贡献）；本卡回答当前困惑落在哪类人际关系、是不是在用借口回避——归位工具与意义问题不要混用

## E — 可执行步骤 (Execution)

1. **列清单、归位三栏**
   - 完成标准: 把当前烦恼涉及的关系逐条填入三栏（工作课题 / 交友课题 / 爱的课题），每条标注距离与深度，并标出最难的一栏
   - 输入契约: 一段真实的烦恼描述；若其中没有出现任何具体的人，先补人再归位——本书处理的是人际关系
2. **挑一条做人生谎言检验**
   - 完成标准: 取一条因为××所以我讨厌他、想远离、做不到的理由，回答两个问题：这个理由最早是什么时候被注意到的？想疏远的念头出现在它之前还是之后？理由出现在决定之后的，标为人生谎言候选（借口系统）
   - 判停条件: 出现家暴、跟踪、威胁、控制信号时，停止检验，先确保安全并转介专业帮助（NR-05）
3. **把道德语言换成勇气语言**
   - 完成标准: 检查记录里是否有对自己的道德审判词（如骗子、懦夫、不孝之类），全部改写为勇气句式（我目前缺少的是面对××的勇气），事实内容保持不变；改写依据：原文口径「这不是一个应该从道德方面来遣责的问题，它只是“勇气”的问题。」（L1729）
4. **对每条关系选先面对动作**
   - 完成标准: 为每条关系写出一个先面对级别的动作（准备一次坦率对话 / 赴一次不回避的见面 / 起草一封把话讲清的信），并在每条动作旁注明：继续或剪断，由面对之后的判断决定
   - 判停条件: 不得把面对写成必须维持关系；原文口径是「无论多么困难的关系都不可以选择逃避，必须勇敢去面对。」（L1673）
5. **汇总并移交**
   - 完成标准: 输出五件套——①三栏归位 ②人生谎言候选与理由顺序 ③道德化改写记录 ④先面对动作清单 ⑤接力说明（需要归属判定或双向执行转 `separation-of-tasks`；亲子场景转 `family-tasks`）；且全文没有对任何一方的道德指控、没有关系一定会改善的承诺

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 安全场景（家暴、跟踪、威胁、控制、自伤）：停止用本卡做分析；先面对的动作不得被用来要求受害者继续接触危险关系——先确保安全并转介专业帮助（NR-05）
- 拿“人生谎言”去审判别人（尤其家人、伴侣）时：先自查口径——它是分析工具，不是道德指控；对他人使用的安全姿势是收回道德语言（见失败模式第 1 条）
- 把三分类当成社交任务清单去逐项完成（多交朋友、必须脱单、必须与家人和解）：分类是定位工具，不是待办事项——这正是青年把课题读成义务后被纠正的那一点

### 作者在书中警告的失败模式

- **把“人生谎言”用作道德指控**: 原文防线——青年质问后，哲人第一句是「请你不要用怒气来回避这个问题。这是非常关键的。阿德勒并不打算用善恶来区分人生课题或者人生谎言。」（L1725）；收口句是「这不是一个应该从道德方面来遣责的问题，它只是“勇气”的问题。」（L1729）——用它定罪会激起怒气与对抗，落回用发怒回避的循环
- **把缺点清单当事实清单**: 「但是，那并不是因为无法容忍A的缺点才讨厌他，而是你先有“要讨厌A”这个目的，之后才找出了符合这个目的的缺点。」（L1685）——关系末期的怪相（「就连对方睡眠时的呼吸声都让你生气」）就是材料后找的实况
- **把人生课题读成社会义务（劳动/纳税）**: 青年原话「这里的课题是指作为社会人的义务吗？也就是类似于劳动或纳税之类的事情。」（L1595）被当场纠正：「不，请你把它理解为单纯的人际关系。人际关系有距离和深度。为了强调这一点，阿德勒也曾使用“三大羁纤”这样的表达方式。」（L1597）；同节还有半步限定「在“不得不面对”这一意义上确实可以说是“义务”。」（L1601）——按义务读，本卡就会被做成任务管理，偏离人际关系这一本体
- **以数量代替深度**: 「朋友或熟人的数量没有任何价值。」（L1637）——用通讯录人数、饭局次数衡量关系质量，是交友课题上被点名的失败模式

### 作者的盲点 / 时代局限

- 朋友关系的处理流程书内未单独给出：先面对、再决定继续或剪断的原文语境是爱之课题（L1673）；把它迁移到朋友关系属书外推断，本卡标注为边界，不假装书里有现成流程
- 先面对、再决定继续或剪断的顺序不承诺结果——面对之后关系是否改善、选择继续还是剪断，书内不给保证；本卡不设关系改善类完成标准（NR-06 口径）
- 三分类的判据只有距离和深度一条（含排序：工作门槛最低、交友更难开始、爱之课题最难）；共同养育、失能者照护等复合情形未覆盖（NR-04，不脑补判据）
- 「三大羁纤」为 OCR 原字（羁绊），引用照抄不更正（NR-08）

### 容易混淆的邻近方法论

- `separation-of-tasks`: 本卡先归位、先识别借口；“这是谁的课题”的判定与双向执行在那条——顺序是先归位、再分离
- `family-tasks`: 亲子部分（坚固的锁链、小剪刀）在本卡只做定位；援助动作与处置序列（把马带到水边，不强迫喝水）在那条
- `life-meaning`: 那条回答人生意义由谁赋予、往哪看；本卡回答当前困惑落在哪类关系、是否在用借口回避——不要把归位工具当成意义观输出
