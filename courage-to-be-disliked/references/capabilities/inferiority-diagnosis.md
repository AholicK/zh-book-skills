# 自卑感 / 自卑情结 / 优越情结三分诊断

## R — 原文 (Reading)

> 阿德勒说“无论是追求优越性还是自卑感，都不是病态，而是一种能够促进健康、正常的努力和成长的刺激”。只要处理得当，自卑感也可以成为努力和成长的催化剂。
>
> — 第二夜 · 自单[自卑]情结只是一种借口 L1151

> 自卑情结是指把自己的自卑感当作某种借口使用的状态。……表现得好像自己很优秀，继而沉浸在一种虚假的优越感之中。
>
> — 第二夜 · 自单[自卑]情结只是一种借口 L1175 / 越自负的人越自单[自卑] L1233

## I — 方法论骨架 (Interpretation)

这套方法解决一个用词混乱：日常语言里的「自卑」，其实是三种不同的东西——感觉、借口、补偿。分不清就会把人人皆有的正常感受当成病症，或者把借口当成事实。

① 自卑感 = 关于自我价值判断的感觉。原文口径是价值更少的感觉（L1063）：它来自与他人的比较，是主观判断而非客观缺陷（L1097-1099）；人人皆有、不是病态，处理得当可以成为努力与成长的催化剂（L1135、L1151）。
② 自卑情结 = 把自卑感当作借口使用的状态（L1175）：判据句式是因为有A所以才做不到B；其语言标记是外部因果律（L1183），言外之意是只要没有A、我也会是有能力有价值的人（L1203）。它与自卑感不是程度之差，而是不同类别——原文明说日常混用完全是一种误用（L1165）。
③ 优越情结 = 没有勇气努力改变、又不甘于自卑情结时的简便补偿（L1229）：表现得好像自己很优秀，沉浸在虚假的优越感中（L1233）。变体包括权势张扬、自夸功绩、夸耀不幸（把不幸当武器取得特别地位）与弱势特权（L1267-1293）。读法：越自负越自卑（L1263）。
④ 诊断读的是语言的功能（在描述感觉？在当借口？在补偿？），不是程度，也不是人品。

缺口如实标注：真实结构性障碍与外部因果律的界线书内未给（f03 missing_conditions）；夸耀不幸的处置话术书内未给、只给方向（NR-04）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 看到同龄人活跃就自卑的青年
- **类型**: 青年经历（第二夜 L1057）
- **问题**: 青年逐项自陈：同龄人的活跃、朋友的幸福（引发嫉妒而不是祝福）、满是粉刺的脸、学历、职业与年收入——「总之就是哪里都很自卑」
- **方法论的使用**: 哲人把它读成关于自我价值判断的词语（自卑感），并在其后用自身身高案例把客观的劣等性与主观的自卑感切开（L1093-1099）
- **结论**: 自卑感来自与他人的比较，是主观的价值判断，不是客观测量
- **结果**: 未说明（哲人由此转入「自卑感来自主观的臆造」一节，L1059-1065）

### 案例 2: 哲人的身高 155 厘米
- **类型**: 哲人亲历（第二夜 L1071-1105）
- **问题**: 哲人自陈身高155厘米，曾长期苦恼，幻想「哪怕是再长高10厘米，一切就会不同，就会拥有更愉快的人生」；朋友回他「这种想法太无聊了！」
- **方法论的使用**: 价值转换：朋友一句「你可有让人感觉轻松的本事啊！」把同一事实翻到另一个关系视角；哲人由此区分劣等性（低于平均数的客观测量数字）与自卑感（在人际关系中产生的主观感觉）
- **结论**: 问题不在于有所欠缺，而在于如何看待它、赋予它什么价值
- **结果**: 哲人称「现在的我已经不会再为自已的身高而烦恼了」；收束句：我们无法改变客观事实，但可以任意改变主观解释（L1109）

### 案例 3: 外部因果律：假因果的典型句式
- **类型**: 转述案例（第二夜 L1183）
- **问题**: 哲人转述听来的说法——「自己之所以始终无法结婚，就是因为幼时父母离婚的缘故」
- **方法论的使用**: 阿德勒把这类论调命名为「外部因果律」：将原本没有任何因果关系的事情解释成似乎有重大因果关系一样；从目的论看，改写方向是「不是“不能成功”而是“不想成功”」（L1187）
- **结论**: 严整的因果句可能是由不想行动倒推出来的理由
- **结果**: 未说明（哲人只做命名与改写提示，未追踪该当事人后续）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 自己或他人反复用「我因为X所以做不到Y」解释不行动（学历、外貌、出身、年龄）
2. 想弄清「自卑感」和「自卑情结」的区别，或被人说自己「有自卑情结」需要澄清
3. 遇到爱炫耀功绩、爱讲不幸、拒绝安慰与帮助的人，想理解其机制而不被牵动
4. 自我怀疑时想确认：这是正常的欠缺感，还是已经变成借口——避免把感受病理化
5. 想为自卑找一个不靠比较、能行动的出口

### 语言信号

- 「我就是因为学历低才没有机会」
- 「要是没有这个缺点，我什么都能做成」
- 「我为自己的…感到自卑」（误用为「自卑情结」）
- 「你根本不懂我的痛苦」
- 「我不是想炫耀，但我当年…」
- 英文: "I have such an inferiority complex", "I can't because…", "I'm just not good enough"

### 与相邻 skill 的区分

- 与 `competition-exit` 的区别: 本卡做三格诊断（感觉/借口/虚假优越）；从与别人比切换为与理想的自己比、把人从对手改置为伙伴的动作在那条
- 与 `teleology-reframing` 的区别: 识别「外部因果律」式借口句式（因为 A 所以做不到 B）在本卡；把整句翻转为「为了…而维持现状」的完整改写程序在那条
- 与 `self-acceptance` 的区别: 自我肯定与自我接纳的区分、60 分练习与能改/不能改二分在那条；本卡只处理自卑一词的三态判定与术语校正

## E — 可执行步骤 (Execution)

1. **范围与安全筛查**
   - 动作: 检查输入是否含临床抑郁、自伤、创伤或被虐待信号
   - 判停条件: 出现上述信号 → 停止本流程，建议专业帮助（NR-05）；本卡不做任何病理诊断
   - 完成标准: 给出明确的「继续 / 停止并转介」结论

2. **取原句**
   - 动作: 收集一句具体的自我描述或他人描述，保留原话；标记关键句式（因为…所以做不到… / 只要没有…我也能… / 我当年… / 你不懂我的…）
   - 完成标准: 写出原句并圈出关键句式，一字不改

3. **三格判定**
   - 动作: 按序检查——①出现「因为有A所以才做不到B」→ 自卑情结（L1175）；②出现「只要没有A，我也会是有能力、有价值的人」式后门 → 自卑情结的另一侧面（L1203）；③出现权势张扬、自夸功绩、夸耀不幸、弱势特权 → 优越情结（L1225-1293）；④以上都没有、只是关于价值更少的感觉 → 自卑感（L1063）。判据是语言功能，不是严重程度；自卑情结与优越情结密切相关，优越情结的底层仍是自卑感（L1263-1267）
   - 完成标准: 写出判定（感觉 / 借口 / 补偿）+ 依据原句片段 + 一句说明为什么停在自卑感或不只是自卑感

4. **术语校正**
   - 动作: 对照三格校正用词——自卑感不叫自卑情结（混用完全是一种误用，L1165）；优越情结不等于优越感或自信（真正拥有自信就不会自大，L1263）；输出里不出现「有病」「心理有问题」等病理化用词
   - 完成标准: 输出校正后的一句话表述，且不含病理化用词

5. **分格给方向**
   - 动作: 自卑感 → 当作催化剂，改成与理想的自己比较（L1317，细化见 competition-exit）；自卑情结 → 把「不能成功」改读为「不想成功」（L1187），标注外部因果律（L1183），用提问追一句「保持这样说，能免除什么」，不对人下结论；优越情结 → 识别底层自卑感，停止补偿不减自卑则不成立；夸耀不幸 / 弱势特权 → 方向是不再以关注供给之（L1297 的代价警告），并注明处置话术原书未给（NR-04）
   - 完成标准: 每格写出一句方向句；全文不含道德语言（不给人品定性）

6. **边界声明**
   - 动作: 输出两行边界——a) 自卑感是人人皆有的中性刺激，本诊断不做病理化；b) 三分诊断只用于看语言功能，不用于指责
   - 判停条件: 若涉及真实结构性障碍（歧视、疾病、客观机会不平等），标注「书内未给外部因果律与真实障碍的界线判据」，作为书外判断处理，不作单方定性（f03 missing_conditions）
   - 完成标准: 输出含两行边界声明与（如适用）书外判断标注

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 临床抑郁、自伤、创伤、被虐待等信号——停止本流程，转介专业帮助；不得用目的论或「自卑情结」对当事人的痛苦做归因（NR-05）
- 拿三分诊断给别人贴标签或做道德指责——「你就是自卑情结」不是本卡的输出形态；诊断的是语言功能，不是人格
- 真实的歧视与结构性障碍（学历歧视、外貌羞辱、机会不平等）——书内未给「外部因果律」与真实障碍的界线判据（f03 missing_conditions），不得把真实障碍一律改写为「不想」

### 作者在书中警告的失败模式

- **把自卑感病理化**: 「自卑感本身并不是什么坏事」（p24 定性与 L1135）——它是人人皆有的中性刺激，处理得当才是催化剂
- **混用术语**: 「目前“自卑情结”这个词似乎在使用的时候与自卑感是一样的意思。……其实，这完全是一种误用」（ce12，L1165）
- **把借口当事实**: 把「因为有A 所以才做不到B」式的外部因果律当成因果陈述（ce13/f03，L1175/L1183）——改写方向是「不是“不能成功”而是“不想成功”」（p27，L1187）
- **用不幸当武器**: 「只要把自已的不幸当作保持“特别”的武器来用，那人就会永远需要不幸」（ce17，L1297）
- **把自大读成自信**: 「如果真正地拥有自信，就不会自大」（ce16，L1263）——正因为有强烈的自卑感才会骄傲自大

### 作者的盲点 / 时代局限

- 真实结构性障碍与「外部因果律」的界线书内未给（f03 missing_conditions）——本卡以标注书外判断、不作单方定性处理，不虚构判据
- 「夸耀不幸」「弱势特权」的处置话术书内未给（L1289-1297），只给方向——本卡不虚构话术（NR-04）
- 三分判定基于对语言句式的阅读，不是心理测量；书中例子（十根手指戴宝石戒指、婴儿支配大人等）是教学演示，不外推（L1247、L1293）
- 临床边界：自卑感与抑郁、焦虑的分界书内未讨论；功能受损或持续痛苦时必须转介（NR-05）

### 容易混淆的邻近方法论

- `competition-exit`: 诊断之后的动作（与「理想的自己」比较、退出竞争、把他人重设为伙伴）
- `teleology-reframing`: 「外部因果律」句子翻转为目的论表述的完整改写程序
- `self-acceptance`: 自我肯定与自我接纳的区分、能改/不能改二分；本卡只诊断自卑一词的三态
- `life-tasks`: 「人生谎言」的借口系统与三大课题归位在那条
