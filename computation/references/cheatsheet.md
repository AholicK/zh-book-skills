# 决策规则速查 — 《计算》

| 能力 | 一句话规则 |
|---|---|
| 计算概念的定位与混淆诊断 | 先把一场关于「计算」的讨论按三问定层、按五类视角归位，再判断它是同层可谈、跨层混淆，还是信念层不可判对错。 |
| 从计数到代数：计算抽象化的历史方法 | 给一个具体计算做法定出它在「具体-对应／序列-数制／符号-记号／公理化-演绎」四层中的位置，再用书内可复用的抽象化动作把它推上一层，并列出这次抽象新增的限制。 |
| 三级筛选：可计算性 → 代价 → NP 完全（立项前的快筛） | 动手前连问三句——能不能算（可计算性）、值不值得算（代价量级）、是不是 NP 完全（是否必须转近似）。 |
| 计算系统的先天约束清单（数学层 + 物理层） | 给一个计算系统逐条钉住先天约束——先分归属（模型 / 实现 / 物理），再列数学层三条、有穷化与精度、物理层三条与能力上限。 |
| 编码—符号变换三步设计法 | 把任何对象（现实过程或构想）变成可计算模型，按「先编码、再定义符号变换规则、最后给定义与初始状态」三步走，次序不可颠倒。 |
| 递归与迭代逼近 | 把求解换成一条能一直做下去的链——定一条有限步骤的变换规则、取初值、以本轮输出作下轮输入反复执行，并按精度或步数定停。 |
| 归谬法：不存在性证明 | 要证某物「不存在」，就按「反设→导出关系式→用可判定的结构性质推进→得矛盾」四步走到一句「所以不存在…」，并注明结论依赖哪些前提与哪套逻辑。 |
| 编码+对角线+归谬：自指系统界限诊断 | 要判一个能谈论自己的系统的界限，就按「编码 → 对角线构造 → 归谬收口」三步走到一句「既不可证是也不可证否」或「该列表必不完整」，再回答四问（编码方式／对角点／界限对象／系统保证不了什么）。 |
| 模型化归约：相对一致性证明 | 要为一个无法自证一致的系统找担保，就把它的初始概念逐条解释到一套更可信的系统里、验证每条公理都变成宿主定理，交出一句「若 B 一致则 A 一致」加一条标出终点的归约链——并声明这是相对一致性。 |
| 形式系统四性质体检 | 拿到任何公理／规范体系，按独立性、一致性、完备性、可判定性四行逐项给结论与后果，而不是给一句「靠不靠得住」。 |
| 有穷化改写 | 把「涉及任意无穷多对象」的论述改写成只需检验有穷多个对象、且界明确可说的版本，并同时报告丢掉了什么。 |
| 哥德尔式编码与自指良恶性判定 | 给出可逆的逐层编码（符号→码→公式码→序列码）与解码反查规则，并用「是否经编码作中介 + 否定次数奇偶 + 是否混淆命题层次」三条判据判定自指良恶性。 |
| 图灵机五元组与图灵完备判定 | 要判一门语言、指令集或规则系统是否图灵完备，先把它写成覆盖全部"状态×读入符号"的五元组表，再看它能否接收并模拟通用图灵机。 |
| 问题复杂度类定位（七步流程） | 拿到一个具体问题，按"可计算性→增长阶→求解/验证不对称→归约→NP 完全→中间问题→可近似性"七步定类，每一步留依据、每一步登记依赖的未证假设。 |
| 归约论证模板 | 要证「A 至少和 B 一样难」，就给出一个多项式时间的实例变换，并逐条核对「任意实例 / 答案一致 / 规模不爆炸」——不要停在「A 可以换成 B」。 |
| 近似算法评估与启发式设计 | 面对 NP 难问题，先核「这个实例具备可近似结构吗」，再选「近似模型＋精确求解」或「精确模型＋近似求解」，最后必须给出误差来源与边界（因子 p 或可比的下界），不许只交一个「差不多」的答案。 |
| 并行化可行性与加速比评估 | 要判断「加机器能不能快」，先查有没有固有串行性（P 完全），再按固定规模（Amdahl：串行比例是硬上限）或规模可放大（Gustafson-Barsis）分别估加速比，最后核对总工作量守恒与时空代价（算／存／通信／搬数据）——不要只看处理器数量。 |
| 量子计算可信度判定 | 拿到量子计算宣称先问三件事——加速来自哪种结构、量级是多项式还是平方根、口径是单问题里程碑还是通用加速；答不上来的产出一律记为「未证明」。 |
| 复杂系统诊断（涌现/耗散/必要多样性/逻辑深度） | 面对「怎么都预测不准」的系统，先判是不是复杂系统（可分解但不可还原），再逐条核涌现四要件、动力学类型、耗散结构三特征、逻辑深度与必要多样性——并声明这是研究纲领级判据，不出量化承诺。 |
| 组织与智能系统的计算化翻译与评估 | 把组织翻成「目标函数+计算规则+状态+反馈」四字段表、把「智能 XX」按「任务入—结果出—行动闭环—价值可量化」四问筛一遍，两件都做不了就说明输入不合格。 |
| 问题定义与排障流程（附录 B） | 排障前先做三件事——把现象与问题分开、判清边界、再决定是改写问题还是直接求解；根因候选未回到观察验证前只算猜想。 |
| 争议问题资产化与潜/实无穷判别 | 老问题看「还有没有人必须反驳它」来判资产还是负债；含「无穷」的表述按潜、实两种口径各读一遍，两读结论不同就是口径混用，工程上必须落到精度与截断。 |
| 计算主义世界观及其使用边界 | 遇到「一切皆可计算／宇宙是台计算机／机器能思考」这类论断，先用基石（论题非定理）、前件（条件句）、强度（信念/强推测）三判据做归位，再决定它能写到什么强度。 |
| 机器智能与 AI 架构范式 | 面对一个智能系统或 AI 路线，先按「知识放在哪里、改进时改什么」归到四档（规则显式／参数拟合／提示／知识外置+Agent），再做选型与风险核算。 |
| 科研范式与产业落地判据（附录 A/C） | 用作者的三条观察点给一个科研范式或工具价值主张定位——方法是否换代、是否在用上一代成功当准入条件、计算工具是止于暴力穷举还是能提出新公理，并在输出中如实标注这只是作者主张。 |
| 符号化与逻辑演算：把推理变成符号变换（从莱布尼茨到布尔） | 把推理变成符号变换——备好符号与演算两根支柱，把散落规则整成公理加演绎，把命题译成等式做代数演算，最后补一层取值解释才落地为机器可用。 |
| 数学基础的严格化与无穷 | 要把「数学基础稳不稳」说清楚，就按三条线走——严格化（找承重概念→改写成不依赖直观的可判定定义→逐层重定义）、无穷判别（潜无穷还是实无穷、为什么机器必须有精度）、公理定位（按 ZF/ZFC 十条找出本问题由哪条公理承担，并声明终点仍未证明）。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
