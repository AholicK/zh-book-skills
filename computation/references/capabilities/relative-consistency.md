# 模型化归约：相对一致性证明

## R — 原文 (Reading)

> 为了验证非欧几何的严密性，数学家们通过模型化方法，将非欧几何映射到欧氏几何，证明如果使用了千年的欧氏几何是一致的，那么非欧几何也是一致的。…但这种模型化的映射方法无非是将一个系统的问题转化为另一个系统的问题，总有退无可退的时候。
>
> — 导论·数学的不确定性（L469-471）

> 数学家们证明曲面几何一致性的办法，是将曲面几何映射到欧几里得几何，通过欧几里得几何的一致性来证明曲面几何的一致性。这种利用欧几里得几何一致性的方法来证明曲面几何一致性的方法，被称为“模型方法”。
>
> — 第6章·计算理论的奠基：希尔伯特进路·模型方法（L4079）

> 在ZFC系统中，通过无穷公理确立了自然数集合的合法性，再由幂集公理实现实数的合法化，然后用分离公理（模式）保证实数集中满足性质p的元素能构成自己的合法性。这样只要ZFC是无矛盾的，严格的微积分理论就能建立在ZFC 系统的基础之上。
>
> — 第5章·第三次数学危机（L3755）

## I — 方法论骨架 (Interpretation)

要回答的问题是：**一个系统的一致性（无矛盾）靠什么担保？** 这套方法不试图在系统内部证明它，而是把疑问整体搬到另一个系统去。

动作有四步：①选宿主系统 B——一个人们已长期接受、更可信的系统（欧氏几何、实数代数、ZFC）；②定义映射——把待验证系统 A 的**初始概念逐条解释成 B 中的对象**（椭圆几何的「平面」→欧氏球面、「点」→球面上的一对对顶点、「直线」→球面上的一个大圆，L4081）；③逐条验证——A 的每条公理在解释下变成 B 的一条定理（第五公设在椭圆几何中被解释为「通过球面上一个点，无法画出一个和已知大圆平行的大圆」，L4081）；④按固定形态表述结论——**条件句「若 B 一致则 A 一致」**，并向上追一条归约链，标出退无可退的终点（L469、L3755）。

判据只有一条但不能打折：**映射必须保住公理结构**。若 A 的公理在 B 中只是一些相互无关的类比，得到的不是相对一致性，而是一段比喻。

为什么有效、又为什么到此为止：一致性不是可以正面逐项验证的性质——「在有穷的情况下很容易理解和证明一致性……但是在大多数无穷的情况下则比较难以建立模型和演算，因为一个无穷的模型可能是隐含有矛盾的」（L4151）。归约只能把疑问转移，不能终结疑问。作者给的终止规则是：算术是否一致这个问题「需要从算术系统内部解答。如果再映射到另一个系统，问题会无穷无尽、永无答案」（L4095）——此时必须换方法（希尔伯特因此转向元数学/证明论，把「数学证明本身」当作研究对象，L4097）。

因此本卡的输出永远是**相对**一致性，不是「已证明一致」。这也是阶段 1.5 登记的最易被误引处：把「若 B 一致则 A 一致」说成「A 已证明一致」，就是把一张空头支票当成到账。

## A1 — 书中的应用 (Past Application)

### 案例 1: 椭圆几何 → 欧氏球面——模型方法的示范
- **类型**: 原书例题
- **问题**: 非欧几何（曲面几何）的公理是否一致（无矛盾）？没人知道会不会从这些公理中推出矛盾结论（L469）。
- **方法论的使用**:
  1. 选宿主 B：欧几里得几何（已被使用千年）；
  2. 定义映射：把椭圆几何的「平面」解释为欧几里得球面、「点」解释为球面上的一对对顶点（以球心为中点）、「直线」解释为球面上的一个大圆（L4081）；
  3. 逐条验证：每条椭圆几何公理都变成一条欧几里得定理；第五公设在此被解释为「通过球面上一个点，无法画出一个和已知大圆平行的大圆」（L4081）；
  4. 表述结论：这是「一种相对性证明，它依赖于欧氏几何的一致性」（L4083）。
- **结论**: 椭圆几何（非欧几何）的一致性由欧氏几何的一致性担保——**条件句**「若欧氏几何一致则非欧几何一致」。
- **结果**: 书中紧接着指出链条的空档：欧几里得公设「显而易见」、千百年没出差错，因此数学家「都忽略了这个问题，默认欧几里得的几何学一定是一致的」（L4083）——宿主自身的一致性是被默认而非证明的。

### 案例 2: 微积分 → 实数论 → 集合论 → ZFC——三级归约链
- **类型**: 原书案例（书内给出的奠基链条）
- **问题**: 为微积分/分析奠定严格基础，需要一层层说清上层对象「是合法的」。
- **方法论的使用**: ①把微积分的基础归约到实数论（柯西、戴德金）；②把实数论的相容性归约到集合论；③在 ZFC 内用无穷公理确立自然数集合的合法性，用幂集公理实现实数的合法化，用分离公理（模式）保证满足性质 p 的子集自身合法（L3755）；④声明整条链只在「ZFC 无矛盾」的前提下成立。
- **结论**: 一条自上而下的合法化链，产出条件性结论——「这样只要ZFC是无矛盾的，严格的微积分理论就能建立在ZFC 系统的基础之上」（L3755）。
- **结果**: 链条的两处空档被作者点名：其一，「无法在ZFC系统内部证明其自身的相容性，必须在某个更强的系统中证明，而这个更强的系统自身的相容性也存在问题」（L3757）；其二，「ZFC系统的相容性迄今为止也没有得到证明」，庞加莱因此讽刺「我们设置了栅栏，把羊群围住，以免遭受狼的侵袭，但谁也不知道是不是把狼也圈在栅栏里了」（L3759）。

### 案例 3: 平面几何 → 实数代数——作者对该方法的当场批判
- **类型**: 原书案例
- **问题**: 面对非欧几何带来的「欧氏几何真的可靠吗」，希尔伯特重新建立平面几何的公理体系，用解析几何把它映射到基于实数的代数学（L469）。
- **方法论的使用**: 同四步——选宿主（实数代数）、定义映射（解析几何方法）、逐条验证公理、得出条件句。
- **结论**: 「如果实数代数是一致的，那么平面几何也是一致的」（L469）。
- **结果**: 作者随即给出判词与边界：这种方法「无非是将一个系统的问题转化为另一个系统的问题，总有退无可退的时候」（L471）；「将平面几何的一致性问题转移到了实数代数上，这是一种转移问题的方法，并没有解决根本问题，因为实数代数的一致性也没有得到证明」（L495）。此处即 v09 最容易被误引的位置：**结论是相对的，不是已证明一致**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 有人说「这套规则/这个系统我们用了很多年都没出问题，所以它是可靠的」，需要把「一致/可靠」这个断言换成一条可核查的归约链。
2. 要为一个无法自证的基础（某套规范体系、某层抽象定义）找担保，考虑「把它映射到一套更可信的系统上」。
3. 拿到一条「A 的一致性已由 B 保证」的结论，需要核对它到底是相对一致性还是绝对一致性，以及链条终点在哪。
4. 在讨论某条自明公理「能不能删掉」或「要不要换成别的」，需要判断换掉之后是不是换了一套系统、其后果如何评估。

### 语言信号

- 「这套体系可靠吗？能不能证明它不会自相矛盾？」
- 「只要能证明它跟 X 是一致的就行了吧？」
- 「我们把它归约到一个更基础的东西上，这样是不是就算证完了？」
- 「这条链最后落在哪儿？尽头是谁？」
- 英文: "Can we reduce this to something we already trust?" / "Is this relative or absolute consistency?" / "If the host theory is consistent, then ours is too." / "Where does the reduction chain bottom out?"

### 与相邻 skill 的区分（阶段 3 定稿）

- 与 `formal-system-checkup` 的区别: v10 检查对象始终是同一套体系本身，填一致/完备/可判定/独立四格；本卡的核心动作是**换系统**——把 A 的疑问搬到 B，产出条件句与归约链。
- 与 `reductio-proof` 的区别: 一正一反——本卡造模型（存在性/构造性路线，结论是「若 B 一致则 A 一致」），v07 出矛盾（否定性路线，结论是「不存在 X」）。
- 与 `reduction-argument` 的区别: 两者都叫「归约」，但本卡归约的是**公理系统的疑问**，保的是相容性；v15 归约的是**问题的难度**（A 难 ⇒ B 难），保的是代价结论。
- 与 `foundations-infinity` 的区别: v27 给的是基础严格化的历史路径与无穷层级坐标（严格化怎么走、潜/实无穷怎么分层、公理清单长什么样）；本卡给的是一个可执行动作——把一处一致性问题做成一条归约链并标出终点。

## E — 可执行步骤 (Execution)

1. **判定是否真的需要一致性论证**
   - 完成标准: 写清待担保的断言（「A 是一致的/无矛盾的」）与它为什么无法在 A 内部直接证明（对象无穷、A 无自证手段或已被证明不能自证）。
   - 输入契约: A 的公理表（或规则条目清单）+ 该断言的使用场景（要用于何处）。公理表缺失先索要，不许按印象代拟。
   - 判停条件: 若用户其实想要的是 A 的四项性质判定 ⇒ 转 `formal-system-checkup`；若要紧的是「A 里某个命题无法证明」⇒ 转 `reductio-proof` 或 `self-reference-limits`。
2. **选宿主系统 B 并登记它的可信度来源**
   - 完成标准: 写明 B 是什么、B 的一致性来自何处（已被长期使用 / 已由另一系统担保 / 仍无证明），并明确标出后两种情形。
   - 输入契约: 候选宿主清单 + 每个候选的可信度依据（不得凭感觉选「看起来更基础」的系统）。
   - 判停条件: 若所有候选宿主的一致性都无证明 ⇒ 继续做，但第 6 步的终点声明必须显式写出「归宿主的未证明假设」。
3. **定义映射（逐条概念解释）**
   - 完成标准: A 的每个初始概念都在 B 里有对应物（如平面→球面、点→对顶点、直线→大圆），对应关系逐条可查。
   - 输入契约: A 的初始概念表 + B 的对象域。缺对应物时不得用「类似地」带过。
   - 判停条件: 若某个初始概念在 B 中找不到对应 ⇒ 停止归约，说明该映射不保结构；可改选宿主或判定本路线不适用。
4. **逐条公理验证**
   - 完成标准: A 的每一条公理在解释下都成为 B 的一条定理，一条不落；每条都写出「A 公理 X ⇒ B 定理 Y」的对照。
   - 判停条件: 若有公理只能靠**额外假设**才变成 B 的定理 ⇒ 把该假设列入第 6 步的依赖清单，并标注它使结论强度下降。
5. **固定结论的表述形态**
   - 完成标准: 结论写成条件句「若 B 一致，则 A 一致」，并显式写出「这是相对一致性，不是绝对一致性」的声明。
   - 判停条件: 若对方要求的是绝对一致性 ⇒ 明确回答本方法给不出，并转 `formal-system-checkup`（判 A 能否自证）或说明须改用元数学/绝对性证明路线（L4097）。
6. **交付归约链与终点风险声明**
   - 输出契约: 结构 = ①待担保断言 ②归约链（A → B → … 逐环列出，每环写映射要点）③每环的可信度来源 ④**退无可退处的显式声明**（哪一环仍无证明）⑤结论条件句 ⑥依赖的未证明假设清单（如「ZFC 无矛盾」）。完成标准：第三方能顺着链逐环复核，且不会把结论读成绝对一致性。
   - 判停条件: 若链条无终点（可无限上溯）⇒ 按 L4095 的终止规则停手并声明「再映射下去问题无穷无尽、永无答案」，改走系统内部的绝对性证明或直接标注为开放问题。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要的是「A 已证明一致」这种绝对结论：本方法在原理上给不出——归约只传递疑问，不终结疑问。
- A 没有可列出的公理表/初始概念表：映射无从定义，别用「大体上等价」硬套。
- 只是要判定单个体系的一致/完备/可判定/独立四项 ⇒ 转 `formal-system-checkup`。
- 实际要解决的是「某个命题证不出来」而不是「体系会不会矛盾」⇒ 转 `reductio-proof` / `self-reference-limits`。

### 作者在书中警告的失败模式

- **把相对一致性当已证明一致（ce06，L471、L495）**: 作者两处点名此法「无非是将一个系统的问题转化为另一个系统的问题，总有退无可退的时候」、希尔伯特早年用它处理平面几何「并没有解决根本问题，因为实数代数的一致性也没有得到证明」。警告信号：论证以「只要 B 没问题，A 就没问题」结束；归约链没有标出终点；把相对一致性表述为绝对一致性。
- **把「看起来像定理」当可推导（ce05，L463）**: 第五公设「看起来就像一个定理」，几千年来数学家一直想从其余四条推出来「但一直没有成功」——直觉与逻辑蕴涵被混同。警告信号：把「显然」「谁都知道」当证明；反复尝试从其余前提推出某条前提；推不动时增加技巧而不质疑其地位。
- **工具先行、根据缺席（ce08，L473）**: 柯西的极限理论「并没有定义无理数，缺少一个实数系作为极限理论的根据，因此以无理数为极限的无穷序列也就缺少真正的极限」——上层工具的正确性只能靠使用中的一致性担保，直到基础补上。警告信号：工具链某一环建立在未定义对象上；用「结果一直都对」替代定义闭合。
- **归约中途不断加公理（ce115，L3607）**: 《数学原理》为定义自然数引入无穷公理，为乘法交换律与类型论引入选择公理，为归纳法与简化类型论引入可化归性公理——「无穷公理、选择公理和可化归性公理的滥用，引起巨大争议」，庞加莱攻击可化归性公理「比数学归纳法更加靠不住」。警告信号：归约过程中不断「临时」加入公理；最后无法说明这些公理为何成立；批评者指出某条公理比待证对象更不可靠。
- **无穷模型可能隐含矛盾（f129，L4151）**: 「在目标对象、演算操作有穷的情况下很容易理解和证明一致性……但是在大多数无穷的情况下则比较难以建立模型和演算，因为一个无穷的模型可能是隐含有矛盾的」；作者并举康托尔连续统研究与罗素悸论为代价案例。警告信号：模型的一致性只靠「直观上的清晰和显然」，而作者明说「人们直观上的『清晰』和『显然』在很多时候并不可靠」。

### 作者的盲点 / 时代局限（含阶段 1.5 登记的待核查项）

- **NR-01① 史实外部不一致·待核查（L463、L4065）**: 书内两处称「19世纪意大利数学家贝尔特拉米证明第五公设是独立于前四条公设的」。外部主流把双曲几何的独立发现归于罗巴切夫斯基/鲍耶，贝尔特拉米（1868）的贡献是欧氏模型下的**相对一致性**。本条正是本卡主题的史实版：引用时必须标注为书内说法并标 `【待核查】`，不得作为书内事实转述；候选池 ce05/c04 亦已带 status 待核查。
- **ce103 待核查·外部不一致（L3271）**: 「希尔伯特也曾尝试证明这个假设，但后来人们在他的证明中找到一处错误一一他的证明基于所有自然数的子集都是递归集这一前提」（OCR 作「一一」＝破折号，[原文如此]）。该叙述为本书特有表述，本次范围内未见与之对应的主流来源，下游引用须标注为本书说法，不作定论。
- **依赖未证明假设（NR 依赖清单口径）**: 本卡的全部结论都挂在「宿主系统一致」这一未证明前提上——欧氏几何的一致性长期被默认（L4083），实数代数的一致性与 **ZFC 的相容性「迄今为止也没有得到证明」（L3759）**。另需注意选择公理本身有争议：「当F为无穷集族时，则出现了巨大的争议」（L3779），它等价于良序原则、基数三歧性、佐恩引理、勒文海姆-斯科伦定理、季洪诺夫定理等一批结论（L3789）——因此「若 ZFC 一致」这句话的强度要随所选的公理集逐条评估。
- **NR-04 / NR-06 OCR 口径**: 本单元涉及的公式与符号区在源文中有残缺与上标降级（如「勒文海姆一斯科伦」中的「一」为破折号 OCR 形，L3789 [原文如此]；指数与下标多处丢失）。引用一律照抄，涉及指数/数值处标 `待核查`，**不提供数值复算、不补写符号**。
- **术语口径（g10）**: 本书的「模型化方法/模型方法」是指**相对一致性证明**（把 A 映射到 B，得到「若 B 一致则 A 一致」），不是工程上的「建个模型跑一遍」。写报告时必须把这个口径写在最前面，否则下游会把条件句读成实测结论。
