# 机器智能与 AI 架构范式

## R — 原文 (Reading)

> 后来他们结合认知模型，在1976年提出了“物理符号系统”的假设，他们指出：“一个物理符号系统具有必要且充分地表示一般智能行动的手段。”这就开启了人工智能的符号主义进路。
>
> — 第12章·符号主义与连接主义（L7059）

> 这样就形成了深度学习中的“预训练+微调”（pre-trained，fine-tuning）工作范式，其好处是对于各种各样的任务，不必从头开始训练，而是直接使用预训练好的模型进行微调
>
> — 第12章·ChatGPT的原理（L7321）

## I — 方法论骨架 (Interpretation)

这张卡做的是机器智能的**范式定位**：面对一个智能系统或一条 AI 路线，先问「它把知识放在哪里、改进时改什么」，再用这个坐标解释它为什么成、为什么败。

四档坐标（书内可归位的全部档位）：

1. **知识写成显式规则**——符号主义。判据来自 1976 年的物理符号系统假设（L7059）：智能被当作符号处理。优点是知识与推理分离设计、便于扩展；代价是规则规模上去后无法维护、甚至自相矛盾（L7069）。
2. **知识拟合进参数**——连接主义。工作流是「定义损失函数 → 选择模型 → 用标注数据拟合参数」（L7123）。核心难题是贡献度分配：很难确定每个神经元对整体计算的相对重要性（权重），解法是链式法则逐层递推的反向传播（L7079）。工程上有一条硬约束：权重不能初始化为零，否则各权重会「不断校平」，必须随机初始化（L7081）。
3. **参数固定、知识走输入侧**——提示路线。判据是可数的刻度尺：只给提示 zero-shot、给一个范例 one-shot、给多个范例 few-shot、范例多到需要更新参数即变成微调（L7423）；路线分岔点是「是否更新模型参数」（L7391）。
4. **知识外置 + 控制回路**——世界模型／知识库 + AI Agent。Agent 被作者定义为「一个能够自适应环境的自主控制系统」（L7737）。

改进步长是这张卡的刻度：加规则（1）→ 加数据加参数（2）→ 改输入（3）→ 改架构与知识位置（4）。跳跃通常由一次失败诊断触发，而不是由规模触发。

## A1 — 书中的应用 (Past Application)

### 案例 1: 支付宝风控系统抛弃专家系统

- **类型**: 作者亲历
- **问题**: 一套知识密集型的专家系统，规则数量膨胀，维护成本失控 —— 「当时一线员工跟我抱怨说系统里有几千条规则，已经完全无法维护了，甚至有些规则还是自相矛盾的。」
- **方法论的使用**: ① 确认症状：规则膨胀／自相矛盾／无法维护，即第 1 档的失效形态；② 判断瓶颈位置：问题出在「人工知识维护」，不是算力不足；③ 换档：从显式规则转向数据驱动，用数据训练模型替代人工规则；④ 执行重构：「在往后的几年里，支付宝重构了风控系统，彻底抛弃了专家系统。」
- **结论**: 范式的更替是因为第 1 档的维护成本与一致性崩了，而不是因为符号主义「理论上错」。
- **结果**: 书内交代：风控系统被整体重构、彻底抛弃专家系统；同期背景是 20 世纪 80 年代美国涌现几百家专家系统公司、AI 产业从 1980 年几百万美元增至 1988 年数十亿美元后泡沫破灭，人工智能进入第二次寒冬（L7069）。书内未给替换的规则数门槛与迁移期风险控制。

### 案例 2: AlphaGo 的三技术组合

- **类型**: 原书案例
- **问题**: 围棋的搜索空间无法穷举 —— 国际象棋棋盘 64 格、含 1050 种可能性；围棋棋盘 361 个交叉点、每点 3 种状态，「棋局有3361～10171种可能性」（量级上标 OCR 残缺，只记结构、不做数值复算，L7135）。
- **方法论的使用**: ① 不试图穷举，改建「直觉 + 评估 + 有偏搜索」的组合：「AlphaGo主要用到了3种技术的组合：有监督学习、强化学习和蒙特卡洛树搜索」（L7155）；② 有监督学习：策略网络（13 层卷积网络）用互联网采集的 3000 多万步人类棋步作标注数据训练（L7165）；③ 强化学习：与自己下几百万盘（「左右手互搏」），无直接监督信息，由环境给胜负反馈、自己调整参数（L7167）；④ 蒙特卡洛树搜索四步循环：选择、扩展、模拟、回溯，走得越多的节点越优秀（L7189）；⑤ 两个网络分工：策略网络预测落子概率、价值网络评估当前盘面胜率（L7155）。
- **结论**: 用「策略网络 = 棋感、价值网络 = 盘面评估、MCTS = 有偏推演」把不可穷举的搜索问题变成可行的近似决策。
- **结果**: 强化学习后「AlphaGo在80%的对战中战胜了过去的自已」[原文如此]，预测对手落子位置的准确率可达 57%（L7167）；2016 年战胜李世石，2017 年 5 月柯洁三番棋全负（L7193）；此后 AlphaGoZero 不再学人类棋谱、完全从规则生成棋步，「取得了100：0的胜绩」（L7195）。**作者的限定**：「AlphaGo代表了一种确定性的终结」—— 围棋是规则固定的封闭系统，战胜人类不代表具备面对开放复杂环境的自适应能力（L7197）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 需要在一个 AI 方案上做选型或复盘：该用显式规则、训模型、改提示，还是做 Agent？上一代方案为什么走不下去？
2. 用户问技术路线的差别，例如「GPT 和 BERT 差在哪」「什么情况下该微调」「提示工程到底在做什么」。
3. 用户要评估「用大模型做这个业务」的门槛：要多少数据、要不要标注、成本与能耗是什么量级。
4. 用户把 AI 当会思考的心智来讨论（「它是不是真的懂了」），需要先把问题放回弱／强人工智能的分层。

### 语言信号

- 「我们这个系统该用规则还是用模型？」
- 「为什么专家系统做不下去？」
- 「GPT 和 BERT 有什么区别？」
- 「zero-shot、few-shot 有什么讲究？」
- 「大模型能不能直接用来做决策？」
- 英文: "symbolic vs connectionist", "should I fine-tune or just prompt?", "is this a system or just a capability?", "can I trust an LLM to decide this?"

### 与相邻 skill 的区分（阶段 3 定稿）

- 与 `organization-computationalization` 的区别: 后者把组织的行为翻译成计算过程并评估；本卡只给单个智能系统做架构范式定位，输出是范式档位 + 路线建议。
- 与 `research-paradigm-criteria` 的区别: 后者评科研范式与产业落地判据（附录 A/C）；本卡不评范式，只判架构。
- 与 `computationalism-boundary` 的区别: 后者判「机器能否思考」这类立场论断的引用强度；本卡判架构选型，只在需要弱／强分层时借用其判据。

## E — 可执行步骤 (Execution)

1. **固定评估对象与判据轴**
   - 完成标准: 用一句话写出「我在给哪个对象做范式定位」，并写出本次要做的决策类型（选型／排障／评估／写作）。
   - 输入契约: ① 对象（系统或方案的名称 + 现状，必需）；② 决策类型（四选一，必需）；③ 已知资源：数据是否可得、是否有标注能力、算力/成本约束（缺则先问，不许静默猜）。
   - 判停条件: 若对象不是智能系统而是组织/流程 → 转 `organization-computationalization`。

2. **范式定位（四档归位）**
   - 完成标准: 判定对象当前属于哪一档——① 规则显式（符号主义，L7059）；② 参数拟合（连接主义，L7123）；③ 参数固定 + 提示（L7391、L7423）；④ 知识外置 + Agent 控制回路（L7707、L7737）；并写明两项依据字段：知识存在哪里、改进时改什么。
   - 判停条件: 若定位为第 ① 档且已出现规则自相矛盾 → 进入第 3 步排障路径。

3. **排障：规则膨胀检查**
   - 完成标准: 输出三项事实——规则数量级、是否出现自相矛盾、维护成本趋势。
   - 判停条件: 三项都指向「人工知识维护是瓶颈」→ 输出「转向数据驱动」的路由建议，并显式提示：源文未给替换的判据门槛与迁移期风险控制（L7069），门槛须由用户自定，不得假装书里有。

4. **交互强度定位（提示四档刻度）**
   - 完成标准: 定位到 zero-shot / one-shot / few-shot / 微调 某一档，并写出判据的答案：「是否更新模型参数」——更新=微调路线，不更新=提示路线（L7391、L7423）。
   - 输入契约: 是否能获得标注数据（有／无）；任务是否长期稳定；预期更新频率。
   - 判停条件: 若既无标注数据又要求长期稳定且低延迟 → 标为「四档均不满足」，转第 5 步做风险核算，不得默认推荐微调。

5. **风险、成本与能耗核算**
   - 完成标准: 至少给出下列三项中的两项——① 决策边界（重要事情是否依赖模型）；② 成本／能耗量级；③ 数据来源可持续性。
   - 判停条件: 若方案要求把模型输出当作重要决策依据 → 直接引用使用纪律「任何重要的事情都不应该依赖ChatGPT做决策」（L7455）并标记为不可接受，除非另有外部校验环节。

6. **输出契约（本卡最终产物）**
   - 输出契约: 一张表 + 一段 ≤100 字结论语。表字段固定为：对象 / 范式档位（1–4）/ 判据事实 / 建议路线 / 出处（L####）/ 待核查项。结论语中不得出现把作者预言当结论的表述（如「未来互联网中超过90%的“网民”会是AIAgent」，L7747；「有智能，没系统」，L8559，均为作者判断/命名）。完成标准: 表至少 1 行；每行档位为 1–4；每行出处含 L####；待核查项列不留空（无则写「无」）。

7. **判停与转卡**
   - 完成标准: 明确写出本次未回答的问题及其去向。
   - 判停条件: 若用户问的是「机器是否真的在思考／有没有意识」→ 只回答弱／强人工智能的分层（「机器能够智能行动，看起来像是有智能的」vs「机器确实在思考，不只是模仿思考」，L7853）与中文屋之争（L6983），并转 `computationalism-boundary`；若问到复杂度分类 → 转 `complexity-class-locating`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用它替代组织、管理、流程问题的分析 —— 那是 `organization-computationalization` 的对象。
- 需要数学层面的结论（图灵完备、复杂度类归属、可计算性判定）时 —— 转 `turing-completeness`、`complexity-class-locating`。
- 想判定某条技术路线「必然成功／必然失败」时 —— 本卡只做定位与风险核算，不产出预测。

### 作者在书中警告的失败模式

- ce272「围棋一直被人们认为是机器智能所难以触达的领域」（L7135）：以组合空间更大断言「机器做不到」，把领域内共识当作技术边界；人类专家的判断只基于搜索复杂度，未考虑学习方法。
- ce284「我认为ChatGPT更像人们在照镜子，它反映的是人类自身的思想和意识」（L7457）：把大模型输出当作机器自身的意识或立场，向它索取情感与主观判断；书中明言「不必幻想机器产生了类人的意识与情感」。
- ce289「一味地追求大规模的数据标注再拟合模型参数这条路是有问题的」（L7491）：把训练语料规模当作可无限扩张的资源；作者提醒高质量文本语料将枯竭、下一步可能要靠 GAN 生成数据。
- ce287 人脑功耗仅 10～25 瓦（L7487）、ce290 ChatGPT 日耗电近 60 万度（L7495）：改进方案若一律是「加数据／加参数／加卡」，能耗与碳排会成为不可持续项。

### 作者的盲点 / 时代局限（含阶段 1.5 登记的待核查项）

- **阶段 1.5 note（本单元）**: 为「（无）」。以下为全局清单中与本单元相关、必须继承的条目。
- **信念 vs 事实**: 图灵信念（L601）与哥德尔信念（L605）是**信念选择而非事实判断**，作者自陈「当今大多数计算机科学家相信机器是可以达到大脑同等智能水平的，他们属于图灵信念阵营，我本人亦持这种观点」（L609）；引用该段时不得写成「科学界已证明机器能达到人脑智能」。
- **NR-01 史实不一致**: 书内称彭罗斯「与霍金一起获得诺贝尔奖」（L607），与外部主流不一致（彭罗斯获 2020 年诺贝尔物理学奖，霍金未曾获奖）；该段不作事实陈述。
- **假设而非结论**: 「物理符号系统」是西蒙与纽厄尔 1976 年提出的**假设**（L7059）；麦卡洛克-皮茨的工作被作者明言「在今天看来依然存在很多瑕疵…处理显得过于简单化了」（L6943），不得当已验证结论。
- **思想实验 ≠ 实验结果**: 中文屋（L6983）与图灵的模仿游戏／图灵测试（L6957）是判定标准与思想实验的设计，书内同时记录了标准反驳（把屋子与屋内的人视作一个整体，整体可被视为懂中文，L6983）；图灵测试本身亦属「衡量标准」而非实验结论。
- **价值观声明**: 附录D《机器智能宣言》（L8615-8619，2023 年 7 月 1 日签署，作者称由本人与 AI 共同起草、AI 贡献约 40%）属价值观声明，只能作为立场引用，不构成能力或结论。
- **NR-06 OCR 上标残缺**: 本单元涉及量级的引文（图灵预测算法长度「10°」、GPT-3 参数「10ll」、人脑神经元「1014」等，L7453；围棋「3361～10171」，L7135）上标丢失，一律标 待核查，不得当准确数字。
- **NR-05 数据口径须外部复算**: 成本与能耗类数字（GPT-3 训练一次约 140 万美元、Gopher/PaLM 预估 200 万–1200 万美元，L7493；每天近 60 万度电，L7495）原文只给离散点值与估算口径，不可外推到其他规模。
- **作者产业主张与预言**: 「有智能，没系统」（L8559）、「创造巨大社会价值的极有可能并不是大模型本身，而是通过大模型构建的AIAgent」、「未来互联网中超过90%的“网民”会是AIAgent」（L7747）均为作者的判断与预言，不得写成结论。
- **依赖未证明假设**: 神谕图灵机被作者称为「在我看来是一个作弊器，现实中当然不存在这样不讲道理的计算模型」（L8091），它只是用来类比「外挂知识库让难问题变简」的理论工具（L7475），不得当作实现路线。

### 容易混淆的邻近方法论

- `organization-computationalization`: 也谈「智能系统」，但对象是组织与流程的计算化翻译；本卡的对象是技术架构本身。
- `complex-system-diagnosis`: 也谈「把机器智能当大型复杂系统看」（L7453 的规模量级判断），但那套工具用于涌现/耗散/逻辑深度诊断；本卡只做架构归位。
- `computationalism-boundary`: 都涉及「机器能否思考」；分法是——立场强度问题走那张卡，架构选型问题走本卡。
