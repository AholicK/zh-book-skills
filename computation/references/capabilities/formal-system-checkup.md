# 形式系统四性质体检

## R — 原文 (Reading)

> 独立性。即系统的公理之间是没有完余的[原文如此]，每条公理都不应当被其他公理所隐含。……一致性。公理之间必须是相容的，不应推导出相互矛盾的结论。……完备性。通过已有公理能够推导出所有的定理。……可判定性。希尔伯特强调系统的可判定性，他定义的判定性问题，作为通用方法，可用来确定一个给定公式的可证明性。
>
> — 第6章·希尔伯特纲领（L4199 / L4207 / L4215 / L4219）

## I — 方法论骨架 (Interpretation)

本卡把「某个公理系统／规范体系是否可靠」拆成四条彼此独立、失败后果各不相同的判据，逐条给结论，而不是给一句整体的「靠不靠得住」。

- **四项各管一件事**：独立性问「某条公理能不能从其余公理推出来」（能推出 ⇒ 它只是定理，是多余的）；一致性问「会不会推出互相矛盾的结果」；完备性问「系统内任取一命题，是否总能证其为真或证其为假」；可判定性问「是否存在一个通用方法，能在有穷步内判定任一给定公式可证与否」——问的是「有没有通用方法」，不是「某个具体命题能不能判」。
- **顺序有意义**：先独立性（清理结构）、再一致性（基础不得自相矛盾）、再完备性、最后可判定性。一致性的地位最高，因为矛盾会波及整个体系。
- **后果各不相同**（第6章逐项补出）：独立性缺失 → 该条只是定理；一致性缺失 → 真命题与假命题同时成立，「引发逻辑灾难」；完备性缺失 → 存在真而不可证的命题；可判定性缺失 → 没有通用判定方法。
- **产物是一张表**：四行 × （性质 / 结论 / 依据 / 违反后果 / 待核查项），不是一段评价。导论 L497-505 以脚注给出四项定义，第6章 L4199-4221 逐项重述并补上失败后果。
- **作者的第五条立场**：「希尔伯特认为数学真理在于有穷性」（L505）——这是希尔伯特纲领的额外立场，不属于本表四项之内，不要混入体检结论。
- **为什么有效**：四项可独立检验、后果可分别指出，因此能定位到具体缺失项；反之，混用会得出「没发现问题 ⇒ 体检通过」这类假结论。

## A1 — 书中的应用 (Past Application)

### 案例 1: 选择公理的两向体检：一致性方向 + 独立性方向
- **类型**: 原书案例
- **问题**: 选择公理（C）加进 ZF 之后，它究竟是多余的、有害的，还是必需的？（L3793）
- **方法论的使用**: ① 先走一致性判据：哥德尔 1940 证明若 ZF 系统相容，则 ZFC 系统（加上选择公理）也相容，故加入 C 不会引出矛盾；② 再走独立性判据：科恩 1963 年通过力迫法证明选择公理相对于 ZF 系统是独立的；③ 书中并置欧氏第五公设的独立性与被最终确认为独立公理一事作为同类判据的对照（L4199-4205）。
- **结论**: 「选择公理对于ZFC系统来说是必要的，因为选择公理无法从其他公理中推出；同时它也是不必要的，因为它和其他公理没有直接关系。」——「必要」与「不必要」可同时成立，分别对应「不能推出」与「无直接关系」。
- **结果**: 书中未给出对该公理的最终裁决；接受它要一并接受的反直觉推论另见分球怪论（c194，L3791），替换方案另见决定性公理（L3795）。

### 案例 2: 用替代模型体检皮亚诺公理：偶数列也满足全部公理
- **类型**: 原书例题
- **问题**: 皮亚诺公理（3 个初始概念 + 5 条公理）是否精确刻画了自然数？（L3347-3361）
- **方法论的使用**: 体检动作为「找替代解释／非标准模型」——令「数」指通常说的偶数，令「后继」指每一数加 2，得到数列 0,2,4,6,8,*（末位「*」原文如此），再逐条核对全部公理；书中指出这样的解释可以有无穷多种（c175，L3361-3365）。
- **结论**: 「这足以说明皮亚诺公理是不够精确的。」公理只约束关系结构，不锁死个体对象是什么。
- **结果**: 书中未说明皮亚诺算术被如何修补；这个缺口被记为弗雷格用纯逻辑概念定义自然数的入口（L3361-3385）。

### 案例 3: 《数学原理》的补丁式公理与「无法自证一致」
- **类型**: 原书案例
- **问题**: 逻辑主义纲领下为定义自然数而建立的形式系统，四项性质各处于什么状态？（p203，第5章）
- **方法论的使用**: 按引入理由逐条列出三条非逻辑公理：无穷公理（为定义自然数）、选择公理（为证明乘法交换律、支持类型论）、可化归性公理（为使用数学归纳法、简化类型论）；再据此判读其一致性只能相对给出、可化归性公理遭庞加莱攻击「比数学归纳法更加靠不住」、无穷公理与选择公理「被斥为根本不是逻辑公理」。
- **结论**: 补丁使系统可用，但动摇了「数学建立在逻辑之上」这一目标本身；罗素 1919 年亦承认可化归性公理「不是逻辑的必然……是一个缺憾」。
- **结果**: 书中未给出该体系的修复；同页记「读完整部《数学原理》的可能只有6个人」，各公理的形式化陈述原文未给。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手上有一套规则体系（代码规范、类型系统、协议 RFC、公司制度、合同条款），要在落地前判断它「靠不靠得住」。
2. 用户提出「这套规范会不会互相冲突」「有没有哪条其实是多余的」「能不能写个程序自动判定某写法违规」这类具体问题。
3. 讨论公理系统／类型系统／法律体系时，有人把「我们一直没发现矛盾」当成「一致性已证」，或把「完备」当成「一致」。
4. 设计规范体系时被要求承诺「本规范能覆盖所有情况」，或被要求「让系统自己证明自己没有矛盾」。

### 语言信号

- 「这套规范自洽吗？」
- 「这条规则能不能从别的规则推出来？是不是多余的？」
- 「有没有通用办法判断某个写法是否违规？」
- 「他说『绝对严密已经实现了』，这话该信几分？」
- 英文: "is this axiom set consistent / independent / complete / decidable?"、"which of these rules is redundant?"、"can the system prove its own consistency?"

### 与相邻 skill 的区分（阶段 3 定稿）

- 与 `relative-consistency` 的区别: v09 是把 A 的一致性问题换到另一个系统 B 去证（相对一致性），检查对象在换；本卡的检查对象始终是同一套体系本身，不换系统。
- 与 `finitization-rewrite` 的区别: v11 只改一条论述的表述使其可逐步检验，不判定体系的四项性质；本卡给出判定与后果，不产出改写句。
- 与 `self-reference-limits` 的区别: v08 诊断的是「系统内部的自指结构会撞上什么界限」，需要构造命题；本卡是四行体检表，不构造自指命题。

## E — 可执行步骤 (Execution)

1. **固定体检对象与论域**
   - 完成标准: 写出被检体系的公理／规则清单（逐条独立可陈述），并写明每条适用的对象域与允许的操作；凡「默认大家都知道」的隐含规则须显式列出并标为待确认。
   - 输入契约: 一套公理／规则体系的条文原文 + 论域（对象是什么、允许什么操作）。若只有口头概括而无成文条款，先索要条文；缺条文时不得静默补齐，只能降级输出「凭描述的初步体检」。
   - 判停条件: 若清单为空、或覆盖不到论域 → 停在此步，输出「无法体检」并逐项列出缺什么。
2. **独立性逐条检查**
   - 完成标准: 对每条公理给出「可由其余公理推出 / 不可推出 / 暂时无法判断」三种判定之一，并附依据（依赖链或反例模型）；互为冗余的多条公理应合并列出。
   - 判停条件: 若某条独立性的判定依据是未证明的假设 → 该行记「待核查」，不得写入结论行。
3. **一致性检查**
   - 完成标准: 给出「已发现相互矛盾的可推导结论 / 未发现矛盾 / 一致性已由外部结果证明」的判定，并写明属于哪一种；未发现矛盾时须注明「这是观察结果，不是证明」。
   - 判停条件: 若已发现矛盾 → 直接跳到第 6 步出报告，在该行写明后果（矛盾波及整个体系，全部结论可信度同时受损），不再往下判完备性。
   - 补充条件: 若体系包含初等算术，「从系统内部证明自身一致」不成立；此时只能给「不能自证」或「由外部系统证明」两种结论。
4. **完备性检查**
   - 完成标准: 对论域内的命题给出「总能证真或证假 / 存在真而不可证的命题 / 未判定」之一，并写出依据。
   - 判停条件: 若体系弱于初等算术（如只含加法）→ 不得套用「任何公理系统都不完备」的说法；若使用方要求承诺完备 → 停下并要求缩小论域。
5. **可判定性检查**
   - 完成标准: 判定「是否存在通用方法在有穷步内判定任一给定公式可证与否」；结论必须写成「不存在**通用**判定方法」或「存在，方法是 X」，不得写成「判定问题不可解」。
   - 输出契约（本步局部）: 判定结论 + 方法描述或不可存在的理由。
6. **输出体检表**
   - 完成标准: 四行齐全，每行含 性质 / 结论 / 依据（行号、反例或外部结果）/ 违反后果 / 待核查项；结论行不得出现「一般没问题」这类无判据措辞。
   - 输出契约: 一张四行表 + 一段总述（缺失项及其后果）。若四项均无法判定，输出「体检未通过，原因：证据不足」，而不是给出乐观结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用来评判一套规范的「合理性／公平性／正当性」——四性质只回答结构性质，不含价值判断。
- 把「长期没发现矛盾」当作一致性已证：书中明确，若没有严格证明新系统的一致性，「总有人会担忧，未来是否会发现新的矛盾定理，从而导致公理系统崩溃」（L4075）。
- 对只是记录配置／枚举状态的有限清单套用完备性——有穷对象的一致性靠逐项检验即可，不需要本表。

### 作者在书中警告的失败模式

- ce109（L3455）：基础一旦含矛盾，「那么所有数学家证明的定理可能也都是隐含着矛盾的」——全部下游结论可信度同时受损，且修复方案短期缺位。
- ce113（L3603）：把每一步都展开为可机械检验的步骤，代价是长度爆炸——《数学原理》「直到第一卷的第363页才推出1的定义，直到第379页才证明了1+1=2」。
- ce111（L3543）：为排除悖论而引入的分支类型论「由于过于复杂和烦琐而没有得到推广」——正确性不是被采用的唯一变量。
- ce09（L475）：庞加莱 1900 年宣称「今天我们可以宣称绝对的严密已经实现了！」，「但庞加莱高兴得太早了」。

### 作者的盲点 / 时代局限（含阶段 1.5 登记的待核查项）

- **第二不完备性定理的边界（本单元重点）**：体检结论涉及「一致性」时必须区分「不能自证一致」与「一致性不可知」——哥德尔只证明系统无法从内部自证，而「哥德尔并未否定从PM系统外部以证明论的方式证明其一致性」（L4527）。把「ZFC 一致性未知」读成「数学不可靠」是错误引用。
- **不适用于全体公理系统**：「不是所有公理系统都是不完备的，相对较弱一些的公理系统可能是一致且完备的，比如Presburger算术」（L4533）——「任何公理系统都不完备」不得作为体检的默认前提。
- **依赖未证明假设**：若体检的一致性／独立性结论被用作其他命题的依据（例如据此断言某类问题可解），须写明该结论依赖未证明假设（全局清单：P≠NP、P=NP、BPP≠BQP、单向函数存在、宇宙是图灵机）。
- NR-02 术语口径：本单元术语按原文；OCR 错形（「完余」等）照抄并标 [原文如此]，不得更正。
- NR-06：本单元所在行区含上标降级处，引用含指数处一律标 待核查，不得当准确数字。
- 候选 spillover：本单元 95 条含跨单元交叉条目（c194／ce123／ce131→v27、c233／p485→v13、c427→v18、f280→v23、g39→v11、p484→v17、p67→v22、ce143／ce157→v20），这些不是本单元主张，写卡只取主属候选。

### 容易混淆的邻近方法论

- `relative-consistency`（v09）：把一个系统的一致性问题映射到另一个系统（模型化归约），产出「若 B 一致则 A 一致」；本卡不换系统，只判性质。
- `self-reference-limits`（v08）：需要构造自指命题来指出界限；本卡只填表。
- 「公理是否允许多种解释」（f96／c175）与本表不是同一件事：找非标准模型检查的是「公理能否锁死目标对象」，四条性质里没有这一项——两者混写会让体检表失真。

## 相关 skills（阶段 3 定稿）

- contrasts-with（易混、按情境选一）：
  - `relative-consistency` — 本卡始终检查同一套体系；要换系统找担保走它
  - `self-reference-limits` — 本卡只填四性质表、不构造对象；要指出一处界限须走它
- composes-with（常配合使用）：
  - `finitization-rewrite` — 本卡先给四性质结论，可判定性缺失的条款交它落成逐步检验形式
  - `godel-encoding` — 本卡先确认被编码体系的符号表与性质，是它做编码的前置
  - `symbolic-logic-calculus` — 本卡体检已成形的体系，符号体系与公理由它构造交来
