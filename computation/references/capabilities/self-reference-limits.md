# 编码+对角线+归谬：自指系统界限诊断

## R — 原文 (Reading)

> 哥德尔先用编码的思想将形式系统编码成哥德尔数，然后使用康托尔的对角线方法构造出了一个“既不可证是，又不可证否”的命题，用归谬法完成了证明。
>
> — 导论·重建数学基础（L507）

> 现在我们问，β 是不是α的元素？如果是，那么根据定义，α只包含M中不是其对应者的元素，即β不是α的元素；如果不是，那么根据定义，不包含在α中的M的任一元素一定是其对应者的元素，即β是α的元素。由此导致矛盾，可证明UM与M不是一一对应的。
>
> — 第4章·数学的基础·连续统假设（L3247）

> 一个公式的哥德尔数可以这样计算：将所有素数从小到大排列，对应公式里每个符号的位置，然后取每个符号对应的哥德尔数作为该位置素数的指数，最终相乘得到。
>
> — 第7章·计算不能做什么：终结者哥德尔（L4453）

## I — 方法论骨架 (Interpretation)

这套方法回答的是同一个问题的三种问法：**一个能谈论自己的系统，能不能把自己的界限也判出来？** 骨架是三步串行、缺一不可。

1. **编码**：给系统的每个符号、公式、公式序列各配一个可机械计算的自然数（编号唯一可逆），于是「证明过程」变成一条算术关系，「系统谈论自己」变成可检验的编码运算。完整流程须合读两处：导论只有纲领式三步（L507），**第7章 L4453-4473** 才给出素数指数编码法与公式序列的再编码（第4章 L3247 则是同一构造在对角线方法上的原型演示）——不注明这两处行号，读到的只是一句口号而不是构造。
2. **对角线构造**：把一个无穷列表（对应者列表、公式序列表、规则清单）排成阵列，在对角位取「与自己那一位不同」的动作，造出一个**按列表定义本该在列表内、实际上不在**的对象。书中三处同形：实数不可数（L477）、幂集基数更大（L3247 的 α/β 双向穷举）、哥德尔命题 G（L507）。作者把这一动作抽象成通用形式——任何集合与至少在其上定义的关系，都不存在「与且仅与那些与自身无该关系的元素有关系」的元素（L3515 区段），理发师、格雷林、理查德、罗素都落在这一族里。
3. **归谬**：假定新对象在系统内可证（或属于列表），沿定义推出与假定相反的一项，矛盾成立 ⇒ 得到一句「系统内既不可证是、也不可证否」或「该列表必不完整」的**界限结论**。

判据与顺序上的约束有三条：①编码必须覆盖到「证明/判定过程」这一层，只编码对象不编码证明，构造不出自指；②对角线造出的对象必须**仍在该系统内可表达**，否则只是一个跑题的反例；③归谬的两条分支（是/否、可证/不可证）都要闭合，只堵住一边等于没证明。收口交付的是界限（系统保证不了什么），不是「系统很糟」这类评价——界限本身是定理。

诊断的具体问法即本书的四问式：①编码方式是什么 ②对角线构造点在哪里 ③由此产生的「既不可证是也不可证否」的对象是什么 ④这限制了该系统能保证什么。

## A1 — 书中的应用 (Past Application)

### 案例 1: 康托尔定理——幂集基数严格大于原集合
- **类型**: 原书例题
- **问题**: 证明一个集合 M 的幂集 UM 的基数大于 M 的基数（书中称康托尔定理，并注明这是唯一一个以他名字命名的定理，L3247）。
- **方法论的使用**:
  1. 编码/反设：先假定 M 与 UM 一一对应，把 M 的每个元素与它的对应者配成对；
  2. 对角线构造：取「由 M 中不是其对应者的元素组成」的集合，它必是 UM 的一个元素，设为 α；
  3. 归谬：据假设 α 必与 M 的一个元素 β 相对应，追问「β 是不是 α 的元素」——如果是，按定义 α 只含不是其对应者的元素，故 β 不是 α 的元素；如果不是，按定义不包含在 α 中的 M 的任一元素必是其对应者的元素，故 β 是 α 的元素（L3247）。两向都得相反结论。
- **结论**: UM 与 M 不是一一对应的，即 |P(M)|>|M|；推广到无穷集合得 2^α>α，可反复用幂集造更大的集合，于是**没有最大的集合与基数**。
- **结果**: 书中点明这个证明「与后来罗素从集合论中构造罗素悸论使用的方法高度相似」（L3247，OCR 作「悸论」＝悖论 [原文如此]）——同一构造既能出定理，也能出自指悖论。

### 案例 2: 哥德尔不完备定理——三件套的完整形态
- **类型**: 原书案例
- **问题**: 希尔伯特宣布「我们必须知道，我们必将知道」之后，需要判定一个包含初等算术的形式系统（PM）能否既完备又自证一致（L507）。
- **方法论的使用**:
  1. 编码：把 PM 的符号、变量、公式、公式序列逐层编号——符号先给固定码，公式用「按位置取素数、把码放在指数位」的算法编码（L4453），公式序列再套一层，于是「证明」成为可机械检验的算术关系，系统与正整数的某个子集建立起一一对应（L4471）；
  2. 对角线构造：造出一个含义为「本命题不可证」的命题；
  3. 归谬：假定它可证则系统证出了假命题，假定其否定可证系统同样塌陷，两向收口。
- **结论**: 得到一个「既不可证是，又不可证否」的命题——含初等算术的形式系统既不完备，也无法从系统内部证明自身的一致性。
- **结果**: 希尔伯特重塑数学基础的计划破产；但形式系统的性质「被研究透彻，形成了完善的理论」，并启发丘奇与图灵证明判定性问题的答案也为否（L507）。

### 案例 3: 罗素悖论——同一构造收口失败时的样子
- **类型**: 原书案例（自指构造的负面结果，作反例读）
- **问题**: 假设 N 是由所有不属于自身的集合组成的集合，再问 N 属于自身吗（L3431）。
- **方法论的使用**: 编码面几乎不需要（这是它比哥德尔简易的原因）；对角线构造直接落在定义上——N 的成员资格由「不属于自身」这一条件给出；归谬：N 属于 N ⇒ 按定义 N 不应当把自身作为元素；N 不属于 N ⇒ 按定义 N 应当包含 N（L3431）。
- **结论**: 得到的是**悖论而不是界限结论**——系统在此处既答不了「是」也答不了「否」，非真即假的两值判断失效。
- **结果**: 直接引发第三次数学危机（导论 L481：「直接动摇了作为数学基础的集合论，数学陷入空前的危机」）；作者另给出它为什么比哥德尔式构造弱：悖论的形成「往往涉及自我指涉、否定性概念，以及『对潜无穷对象做了实无穷处理』」（L3487），而哥德尔把自指搬进编码、加上了分层与技术性限制。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手上有一套「规则适用于规则自身」的制度/评级/权限/合规体系（供应商评分、SLA 评级、代码审查规则、自评问卷），怀疑它在自身处无解。
2. 讨论一个形式系统/程序/协议「能不能判定自己」，或听到「这个系统证明了自身一致」「这个模型能完全自审」这类断言。
3. 要在报告里引用哥德尔不完备、罗素悖论、实数不可数、图灵停机问题之一，需要一个能被逐行复核的构造，而不是一句结论。
4. 文档里出现「所有」「一切」「任何」的总体性表述，需要检查它会不会导致自指塌陷。

### 语言信号

- ① 编码面：「这套规则能不能谈论自己？」「把判定规则本身也纳入判定流程行不行？」
- ② 对角线面：「有没有一条记录，怎么判都和规则自己冲突？」「能不能造出一个漏网的例子来？」
- ③ 不可证是也不可证否：「这个系统里有没有既证不出来也否不掉的东西？」「这是还没找到，还是根本找不到？」
- ④ 界限结论：「这套规则最多能保证什么？保证不了什么？」「把界限写下来。」
- 英文: "Can this rule system decide about itself?" / "Is there a statement this system can neither prove nor refute?" / "Show me the diagonal construction." / "Where is the boundary of what this system can guarantee?"

### 与相邻 skill 的区分（阶段 3 定稿）

- 与 `godel-encoding` 的区别: v12 只做构造面（符号→码→公式码→序列码的编码规则、解码校验、自指良恶性判定），不构造对角线、不下界限结论；本卡是整体诊断，取 v12 的产出接着走第 3、4 步。
- 与 `reductio-proof` 的区别: v07 是本卡第三步（归谬收口）的独立形态，输入是一个不存在性命题；本卡前两步（编码、对角线）不成立就只剩一句矛盾。
- 与 `formal-system-checkup` 的区别: v10 是对同一套体系填四性质体检表，不构造自指命题、不换系统；本卡必须构造出一个具体对象才能指出一处界限。
- 与 `recursion-iteration` 的区别: v06 负责让「输出即下次输入」的逼近过程跑起来并交代终止条件；本卡判的是「这个自指是良性的，还是会死循环/不可判定」。

## E — 可执行步骤 (Execution)

1. **固定诊断对象与其自指资格**
   - 完成标准: 写出被诊断系统的最小对象清单（符号/规则条目/字段）以及它与自身发生关系的具体方式（哪条规则用到了「本规则」「全部规则」）。
   - 输入契约: 系统对象清单 + 目标问句（用户要的是「界限结论」还是「四性质判定」）+ 允许使用的推理口径（经典/构造性）。目标问句缺失时先问，不许静默按体检跑。
   - 判停条件: 若对象里根本不存在指向自身的规则或引用 ⇒ 本卡不适用：要证不存在性转 `reductio-proof`，要四性质表转 `formal-system-checkup`。
2. **编码：把系统映射为可机械检验的编号**
   - 完成标准: 给出编码规则，并当场对一个真实表达式编出码、再解码回原式（双向可验证）；且编码覆盖到「证明/判定过程」这一层，而不只是对象本身。
   - 输入契约: 符号表（含符号数）+ 编码方法（可照 L4453 的「按位置取素数、码作指数」结构）。**不得复算具体数值**——源文公式区 OCR 残缺（NR-04），只记结构。
   - 判停条件: 编码写不出或不可逆 ⇒ 转 `problem-definition-troubleshooting` 先定义问题；只需编码与良恶性判定 ⇒ 转 `godel-encoding`。
3. **对角线构造**
   - 完成标准: 交出一个对象 X，逐项说明它与列表/对应者的每一项都不同（差异来源可核对），且 X 仍在系统内可表达。
   - 输入契约: 一个可枚举的列表（对应者列表、公式序列表、规则清单）或其一一对应假设。
   - 判停条件: 造出的 X 落在系统外（不可表达）⇒ 退回第 2 步补编码；X 只能靠额外假设成立 ⇒ 记录该假设并在第 6 步标注依赖。
4. **归谬收口**
   - 完成标准: X 可证与 X 不可证（或属于/不属于）两条分支各自导出明确矛盾，两支都写全。
   - 判停条件: 只有一支闭合 ⇒ 回第 3 步换对角位或换列表定义。
5. **把结论翻译回原系统的语言，回答四问**
   - 完成标准: 四问四答可逐条指向第 2–4 步的具体构造：①编码方式 ②对角线构造点 ③「既不可证是也不可证否」对象 ④界限结论（该系统保证不了什么）。
   - 判停条件: 第 ④ 问答不出（只能说「很糟」「不可靠」）⇒ 说明第 3 步的 X 不是界限对象，退回第 3 步。
6. **交付诊断报告**
   - 输出契约: 结构 = ①诊断对象与自指方式 ②编码规则 + 一次编/解码验证 ③对角线构造点与所造对象 ④两分支矛盾（可逐行复核）⑤四问四答 ⑥界限结论 ⑦依赖的前提与未证明假设清单（含 OCR 残缺标记）。完成标准：第三方按此报告能逐行复核到矛盾点，并看出结论依赖哪些前提。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只需判定一套体系的一致/完备/可判定/独立四项性质——那是 `formal-system-checkup` 的四行体检表；本卡要构造对象，成本更高。
- 只需从矛盾得出一句不存在性结论，且不需要编码与对角线——转 `reductio-proof`。
- 对象无法被符号化/编码（纯质性叙述、无明确规则条目）时不得硬套：三件套的第一步就落不了地。
- 想拿它当「证明某系统不好/不能用」的工具：本卡产出的是**界限**（保证不了什么），不是价值判断。

### 作者在书中警告的失败模式

- **定义里出现「所有不属于自身的 X」⇒ 自指塌陷（ce107，L3431）**: 罗素悖论两向自相矛盾，后果不是「有漏洞」而是「直接动摇了作为数学基础的集合论，数学陷入空前的危机」（ce11，L481）。警告信号：定义里出现「所有不满足本规则的…」；制度/评级/权限规则可以作用于规则自身而无人检查。
- **规则适用于规则执行者时无解（ce108，L3433）**: 理发师宣称只帮不给自己刮胡子的人刮胡子——给自己刮与不刮都违规则。这是把抽象悖论改写成日常情境的标准入口例，也是治理/权限条款最常见的自指形态（该条主属 v20，此处只作边界引用）。
- **自指句含否定时无真值（ce110，L3463）**: 「这句话是假的」与罗素悖论一样「引入了矛盾」；作者给的配套操作判据是**数否定次数**——奇数次否定构成恶性循环（悖论），偶数次为良性（p194「这种自我指涉，如果是奇数次否定，则构成恶性循环，会导致悖论出现；如果是偶数次否定，则是良性循环，不构成悸论」，L3471 [原文如此]）。警告信号：把「本句为假」「本规则不适用」当普通命题使用；自指链末端的否定次数没数清。
- **把「禁止自指」当通则（ce112，L3545）**: 拉姆塞指出恶性循环原则「只能应用于我们构造的实体，不能应用于独立于我们的构造而存在的对象」；作者另一处强调罗素「限制的是自我指涉中的病态部分，而非否定全部的自我指涉」，且「如果语言或逻辑的表达力强到一定程度，则很难避免悸论的产生」（L3519 [原文如此]）。警告信号：为排除病态自指而全面禁用自指；限制条款无法说明自己的适用域；表达力代价未被计入。

### 作者的盲点 / 时代局限（含阶段 1.5 登记的待核查项）

- **完整构造横跨 ch4 与 ch7（阶段 1.5 note）**: 导论 L507 只有纲领式三步，完整流程散在 **第4章 L3247**（对角线上的双向穷举原型）与 **第7章 L4453-4473**（哥德尔数的编码流程），**必须两处合读并同时标注行号**；只引导论会得到一句口号，做不出构造。
- **NR-04 OCR 公式残缺**：哥德尔数的素数指数式（L4455 区段，源文作「28×34×513×79×118×1313×…」）与描述数类公式残缺，**只记结构、不提供数值复算**，引用时不得补写正确的指数式。
- **NR-02 / NR-06 术语与符号口径**：作者用「哥德尔数/编码」，全书 0 次「哥德尔编码」；OCR 错形「悸论」「湟论」「论」（＝悖论）与上标丢失（指数降级）照抄，可加 `[原文如此]`，**不得更正**。
- **作者的引申不等于标准结论（f106，L3539）**: 用信息论读自指——「可以用非常简洁的算法描述『这句话是假的』的嵌套，这说明这种递归的方式是线性的，得到的增量信息非常少……信息余量非常大，信息量非常小」，这是作者自己的读法，本卡范围内未见对应的标准结果，引用须标为作者主张。

- `formal-system-checkup`（v10）: 都是给系统做体检；v10 是四性质填表、不换系统、不构造命题，本卡必须构造一个具体对象才能给出一处界限。
