# 归谬法：不存在性证明

## R — 原文 (Reading)

> 先假定等腰直角三角形的直角边为1，如果其弦是可通约的，那么就可以…表示为两个整数之比，假设为mln。…必有一个是奇数。现在m²=2n²，所以m²是偶数，m也是偶数；因此n是奇数。
>
> — 第1章·无理数的发现（L1167-1179）

## I — 方法论骨架 (Interpretation)

归谬法不是「随便举个反例」，而是一条可以逐步照抄的构造链，四个环节缺一不可：

1. **反设**：把待证「不存在」的东西当作存在，并为它写出一份可操作的表示（例如「弦可通约」就写成「可表示为两个整数之比 m/n」）。反设必须落到具体的符号上，否则后面无处使劲。
2. **导出关系式**：由已知前提（此处是毕达哥拉斯定理与可通约的定义）推出至少一条等式关系。
3. **用可判定的结构性质推进**：书内样板用的是奇偶性——把 m/n 约到最简后推出 m、n 必有一个是奇数，再由 m²=2n² 推出 m 为偶数，于是 n 为奇数；再令 m=2p 得 n 也是偶数。推进步骤必须落在一个可机械判定的性质上（奇偶、同余、有界性），否则「导出矛盾」就退回直觉。
4. **得矛盾并收口**：明确指出互相冲突的两项，断言原假设不成立，得出一句「所以不存在…」的不可能性结论。

它与反证法的分工是这条链的关键：反证法用矛盾去证「命题为真」，而归谬律用矛盾去证「某物不存在」。构造主义立场下这个区分不是口味问题——排中律只允许用在有穷集合上、反证法不被承认，但归谬律因为「可以能行地证明某物不存在」被接受（L3643-3645）。也就是说，**不存在性结论比存在性结论在更严的标准下仍然站得住**，这正是这套方法的价值所在。

最后一条可靠性口径：证明的效力等于它最弱前提的效力。逐条核对前提是归谬法的内建步骤，而不是事后审计。

## A1 — 书中的应用 (Past Application)

### 案例 1: √2 与 1 不可通约——四步归谬的样板
- **类型**: 原书案例
- **问题**: 证「不存在能同时约尽 √2 与 1 的整数比」。可用前提：可通约的定义（两条线段存在共同的度量单位，等价于两量之比为有理数，L1157）、毕达哥拉斯定理、奇偶判据。
- **方法论的使用**:
  1. 反设：假定等腰直角三角形的直角边为 1 时其弦可通约，即 m/n；
  2. 导出关系式：由毕达哥拉斯定理得 m²/n²=2，即 m²=2n²（L1171-1173）；
  3. 结构性质推进：若 m、n 有公约数则约掉，于是最终的 m 和 n 必有一个是奇数；由 m²=2n² 知 m² 为偶数，故 m 也是偶数，因此 n 是奇数（L1175-1177）；
  4. 得矛盾：设 m=2p，则 4p²=2n²，即 n²=2p²，所以 n 是偶数——与「n是奇数」矛盾，「所以不存在m/n可以约尽的弦」（L1179）。
- **结论**: √2 与 1 不可通约——一句「不存在m/n可以约尽的弦」的不可能性结论。
- **结果**: 书中称这是「极其简洁漂亮的归谬法证明」（L1167），并指出该证明收录于《几何原本》第十卷的附录 27；同一形态的归谬其后在芝诺、罗素、哥德尔处反复出现，是全书反复使用的推理骨架。

### 案例 2: 希尔伯特的连续统假设证明——栽在未被检验的前提上
- **类型**: 原书案例
- **问题**: 康托尔 1878 年提出连续统假设并为之耗尽精力；希尔伯特把它列为 1900 年 23 个问题之首，自己也尝试证明它（L3271）。
- **方法论的使用**: 复核者对该证明做的前提逐条检查 → 发现它基于「所有自然数的子集都是递归集」这一前提 → 用反例否证该前提：自然数的子集并非都是递归的，存在着非递归的子集。
- **结论**: 该证明被认定有误——不是推导出错，而是前提不成立。
- **结果**: 书中接着给出该问题的最终状态：1938 年哥德尔证明连续统假设与集合论公理一致（不可被证否），1963 年科恩证明其独立（推不出来），因此「连续统假设在集合论公理的体系内是不可判定的」（L3271）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要证某事物「不存在 / 做不到 / 不可能」（例如不存在这种约分、不能用尺规作某个图、不可能在给定预算内完成）。
2. 要反驳一个论证，想从对方自己的前提出发引出矛盾，而不是另起一套论证。
3. 拿到了别人给出的一个「不存在性」结论，需要核对它的前提是否站得住。
4. 讨论某条经典逻辑规则（排中律、反证法）能否用在无穷对象上，需要判断这条证明到底在哪个逻辑系统里有效。

### 语言信号

- 「怎么证明做不到？」
- 「这个证明能不能只用反证？结论可靠吗？」
- 「排中律在这儿能不能用？」
- 「他说的矛盾在哪儿，能指出来吗？」
- 英文: "Prove that this is impossible." / "Show that no such object exists." / "Is this argument self-contradictory?"

### 与相邻 skill 的区分（阶段 3 定稿）

- 与 `self-reference-limits` 的区别: v08 是「编码 + 对角线 + 归谬」三件套，用于诊断自指系统的界限；本卡是其中**收口的那一步**（从矛盾得出不存在性结论），单独使用时不含编码与对角线构造。
- 与 `relative-consistency` 的区别: v09 用模型化归约构造一个模型来证相对一致性（存在性路线）；本卡走的是「引出矛盾」的否定性路线，两者方向相反。
- 与 `formal-system-checkup` 的区别: v10 给形式系统做四性质体检（一致/完备/可判定/独立）；本卡只产出一个不存在性结论及其前提依赖，不做系统级体检。
- 与 `paradox-assetization` 的区别: v22 处理争议问题如何资产化、潜无穷与实无穷如何判别，含选题与价值判断；本卡不做价值判断，只完成一次证明。
- 与 `reduction-argument` 的区别: v15 的归约论证是「A 难 ⇒ B 难」的代价/难度转移模板；本卡是从矛盾出结论的证明模板，输出形态是结论句而非归约链。

## E — 可执行步骤 (Execution)

1. **写清待证的不存在性命题**
   - 完成标准: 命题写成「不存在 X 使得 Y」的形式，且 X 可按书内规则被描述（如「能被约尽的整数比」「能用尺规作出的线段」）。
   - 输入契约: 待证不存在的对象 + 已知前提/公理清单 + 本步允许使用的推理规则集（是否允许排中律、是否要求构造性）。三项缺任一项先向用户追问，不许静默按经典逻辑开跑。
   - 判停条件: 若目标其实是「证某命题为真」→ 说明本卡只管不存在性；在构造性口径下，存在性证明不属于本卡。
2. **反设：假定对象存在并写出表示**
   - 完成标准: 给出该对象的一个具体表示（如 m/n、一个多项式方程的根），并声明这一步依赖的前提（如可通约的定义）。
   - 判停条件: 若表示写不出来（对象无法被符号化）→ 转 `problem-definition-troubleshooting`。
3. **导出关系式**
   - 完成标准: 由已知前提推出至少一条等式或不等式关系，且每条推导都点名所用前提。
   - 判停条件: 若推导依赖一条未被检验的隐含前提（如「自然数的子集都是递归集」）→ 先停下核对该前提，未核实不得继续（书中希尔伯特证明翻车的正是这一步）。
4. **用可判定的结构性质推进**
   - 完成标准: 选定一个可机械判定的性质（奇偶、同余、有界/无界）并据此推出一个新结论。
   - 判停条件: 若找不出可判定性质，推不动矛盾 → 转 `reduction-argument`，改走归约路线。
5. **得矛盾并收口**
   - 完成标准: 明确指出矛盾的两项（如「n是奇数」与「所以n是偶数」），并据此断言原假设不成立。
   - 判停条件: 若矛盾只来自额外引入的假设而非反设本身 → 回到第 2 步重设反设。
6. **交付证明与前提依赖**
   - 输出契约: 结构化交付 = ①待证的不存在性命题 ②反设与其符号表示 ③逐步推导（每步标注所用前提）④矛盾点 ⑤结论句「所以不存在…」⑥前提依赖表与本节所用逻辑系统（是否用到排中律、是否满足构造性要求）。含完成标准：第三方按此交付能逐行复核每一步，并看出该结论依赖哪些未证前提。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 要证明的是「某命题为真」且要求构造性（能行地造出对象）时——归谬法给不出构造（L3645）。
- 要判定自指系统的可证性/停机界限时——转 `self-reference-limits`。
- 要比较两个问题的难度、做代价转移时——转 `reduction-argument`。

### 作者在书中警告的失败模式

- **宣布结论 ≠ 证明通过复核（ce134，L3769）**: 1904 年国际数学家大会上，匈牙利数学家寇尼声称证明了实数集不能被良序化、连续统假设是错误的；策梅洛听后「认为证明有瑕疵」，遂开始研究良序问题。警告信号：结果靠大会发言传播而非可复核文本、同行当场判有瑕疵却无统一裁定、争论立刻升级为对整个理论（康托尔集合论）的攻击。
- **证明的可靠性等于最弱前提的可靠性（c171，L3271）**: 希尔伯特挑战连续统假设的证明栽在一个未检验的前提上——看似无懈可击的证明可以只错在一个前提。
- **把几何直观当论证前提（ce98，L3099，待核查）**: 魏尔斯特拉斯构造出「处处连续，但处处不可微」的函数，推翻了「连续曲线必有切线」这类来自作图与运动的直观。警告信号：论证依赖「显然」「画图可知」，结论只在图示范围内成立。

### 作者的盲点 / 时代局限（含阶段 1.5 登记的待核查项）

- **f111 适用边界（L3643-3645）**: 本卡第 5 步能收口，靠的是构造主义者对归谬律的那一点让步——「但直觉主义者不排斥归诊律，因为归谬律可以能行地证明某物不存在，是可以接受的」（OCR 将「归谬律」识作「归诊律」，照抄）。但同一学派**禁止把排中律用在无穷集合上**（「每个自然数要么是奇数要么是偶数」因此不被承认），也**不承认用反证法引出矛盾来证明命题为真**。因此对无穷对象做归谬前，必须先声明所用的逻辑系统，不得默认经典逻辑到处可用。
- **这是学派之争，不是已定结论**: 书中紧接着记录了希尔伯特对该禁令的强烈抨击（L3647，称其将「意味着肢解和破坏我们的科学」）。**引用这条边界时必须两边都摆出来**，不得把直觉主义的要求写成学界共识。
- **存在性与不存在性的不对称（p207，L3645）**: 本卡只对「不存在性」有效；不要用同一套流程去声称「证明了某物存在」。
- **p130（L2073，待核查）**: 作者称「迄今为止对代数基本定理的所有证明，都或多或少用到了连续性的概念」——这是随文献变化而变的表述（候选池亦标 status: 待核查），引用须标待核查，不得当稳定事实。
- **NR-02 术语与 OCR 口径照抄**: 除「归诊律」外，源文另有「归律」（L1347，应为「归谬律」）、「芝诺论」（L1347，应为「芝诺悖论」）、「m/n」作「mln」、「√2」作「/2」「V2」（L1167-1179）、「错误——」被识成「错误一一」（L3271）。引用一律照抄并可加 `[原文如此]`，**不得更正**。
- **NR-01 史实外部不一致（不作为书内事实引用）**: 本单元涉及外部史实处按 needs-review 登记口径标注（贝尔特拉米与第五公设、彭罗斯获奖、戴德金年代）；其数学结论不受影响，但不得把作者的年代表述当史实转述。
- **依赖未证明假设 / 体系依赖**: 「连续统假设不可判定」本身是已证结论（哥德尔 1938 一致 + 科恩 1963 独立），但选择公理、良序定理的取舍在书内属于学派争论；此外 f111 的规则取舍（哪条推理规则可用）依赖事先选定的逻辑系统，不是可脱离体系判定的客观事实。
- **候选 spillover**: 本单元含 ce98（魏尔斯特拉斯病态函数）、p130（代数基本定理与连续性）、p59（欧多克索斯比例定义）等偏「分析严格化/比例理论」的条目，`task_ids` 标注宽泛。本卡按主属候选（f27/f28/f52/f111/p58/p207/g17/g36）立论，不把 spillover 条目当本单元主张。

### 容易混淆的邻近方法论

- `self-reference-limits`: 两者都用归谬，但 v08 的归谬前面还有编码与对角线两步；没有那两步，就只剩本卡。
- `relative-consistency`: 一正一反——v09 造模型（证一致性），本卡出矛盾（证不存在）。
- `paradox-assetization`: v22 把「证不出来的问题」当资产去做选题与价值判断，本卡只做判断本身。
