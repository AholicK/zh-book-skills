# 从计数到代数：计算抽象化的历史方法

## R — 原文 (Reading)

> 在需要对新的集合计数时，只需要将其和标准集合进行一一对应，直到刚好匹配上，那么新的集合的数就等同于标准集合的数。这样通过对应法则得到的数，就是“基数”。…“对应”和“序列”是数的根本法则，也贯穿了人类对数学和科学的一切研究。
>
> — 第1章·从数觉到计数（L699-701）

## I — 方法论骨架 (Interpretation)

本单元不是一条流程，而是一套「抽象阶梯」的爬升手法清单：给定一个具体的计算做法，判定它站在哪一层，再用书里可复用的动作把它往上一层推，同时检查这次抽象带来的新增代价。可执行面只有「抽象化手法」这一族。

四个可复用动作（按历史出现次序）：

1. 归约——把新运算化到已有运算上。工具最简单时，乘法被拆成加倍与相加的有限步骤序列；除法则把加倍过程倒过来用。
2. 对应与序列化——先靠一一对应得到基数（不需要计数即可比较多少），再把标准集合排成有前后次序的序列得到序数；序数「可以由一个数数到它的后继数」正是算术能运算的根本。只有对应没有序列，就出不了算术。
3. 具体物→符号——把量分成未知量与已知量并各配一套字母，抽象关系摆脱实物与自然语言的纠缠，由此才能机械化地「变形为等价形式」。
4. 特例→一般公式→公理化演绎——从摆出的特例观察出规律、写成能算任意项的公式，再进一步改为从更根本的原理演绎出结论。

判据与约束：

- 抽象的「进步」按方法判，不按结论判：相同的结论（如毕达哥拉斯定理式的关系）在经验数学里也出现过，区别在于是否换成了公理化与演绎推理的方法。
- 每次抽象都会新增限制：新记号会带来新的同维度/齐次性要求，新层会排除上一层的某些对象。有效抽象应扩大可表达、可计算的对象集；只增限制不增范围的是「包袱型抽象」。
- 越过这一层就不再是历史方法：公理系统的体检、编码三步设计、递归逼近求值分别属于别的 skill。

## A1 — 书中的应用 (Past Application)

### 案例 1: 古埃及逐次加倍乘法（把乘法归约到加倍与相加）
- **类型**: 原书案例
- **问题**: 在只有加法作为基本运算的工具条件下，怎么得到乘法的结果（书中取例 5×80）。
- **方法论的使用**: ① 从被乘数出发逐次加倍，得到 1×80、2×80、4×80 的序列；② 在序列中凑出乘数 5 的分解（5＝1+4）；③ 把对应的项相加得积；④ 除法把同一加倍过程倒过来使用（同一段，L883）。
- **结论**: 乘法被表示成「加倍＋相加」的有限步骤序列——把新运算归约到已有运算，这是抽象化手法最早的实例之一。
- **结果**: 书中只给出程序，未列出数值结果（未说明）；该段的乘法记号 OCR 作「5X×80」[原文如此]，引用时不得更正。

### 案例 2: 韦达的字母符号体系及其「齐次性原则」代价
- **类型**: 原书案例
- **问题**: 16 世纪的代数记号仍把量与几何长度绑在一起，代数的表达与运算都受制于几何直观。
- **方法论的使用**: ① 分层表征：把量分为未知量与已知量，未知量用大写元音字母 A、E、I、O、U 等表示，已知量用大写辅音字母 B、C、D 等表示（L1707）——这是「具体物→符号」这一步；② 代价显形：韦达认为代数必须严格建立在几何之上，其代数遵循「齐次性原则」，即方程中每一项必须具有相同的维度，于是符号 d 被降为二维「Dplano」、z 为三维「Zsolido」（L1713）；③ 破局：笛卡儿把几何对象看作数的一种便利表示——两条线段的乘积不必是矩形面积，也可以是另一条线段（单位线段思想），代数不再受几何约束（L1723）；④ 记法定型：用字母表最后几个小写字母 x、y、z 表示未知量自笛卡儿始（L1717）。
- **结论**: 抽象化是双面的——同一动作既让关系脱离实物（元音/辅音字母体系），也可能把上一层（几何）的直觉固化成新限制；判别标志是该规则是否还在扩大可表达的对象集。
- **结果**: 代数摆脱几何意义的约束，解析几何随之建立（L1723）。书中同时指出韦达「不承认负数」（L1713），其符号体系因此并不完整。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 有人问「这个东西在数学史/计算史上处在哪一步」，需要给一个对象（某记号、某算法、某教材写法）定位到抽象阶梯的哪一层。
2. 要给一套业务规则或表达方式「换一层」——例如把一堆特例写成一般规则、把实物台账换成符号化编码，需要可复用的迁移动作与代价清单。
3. 判断某个被沿用的写法（同维度约束、统一单位、必须保留的旧记号）是有效约束还是历史包袱。
4. 阅读本书第1、2章（数觉、计数、古埃及/巴比伦/中国算学、花拉子米与符号代数）时需要一个方法骨架，而不只是年代与人物。

### 语言信号

- 「这个算法历史上是怎么来的？」
- 「为什么古人要这样算？」
- 「这套符号/写法能不能改？」
- 「把特例写成通用规则，该按什么顺序做？」
- 英文: "where does this notation come from", "how is this abstraction ladder supposed to work", "is this constraint essential or historical baggage"

### 与相邻 skill 的区分（阶段 3 定稿）

- 与 `symbolic-logic-calculus` 的区别: 后者处理「符号优先、推理即计算」的方法原则（ch3），本卡处理从计数到代数的抽象层谱与迁移动作。
- 与 `encoding-rule-initial-state` 的区别: 后者的输出是「编码—规则—初始状态」的三步设计契约，本卡的输出是「现行层→目标层」的迁移表（含新增限制）。
- 与 `recursion-iteration` 的区别: 后者的对象是求值的迭代/递推逼近；本卡的「归约」是把新运算化到旧运算，不涉及逼近收敛。

## E — 可执行步骤 (Execution)

1. **登记对象与它当前的抽象层**
   - 完成标准: 对象写成一句「做法/记号 + 现在用什么表征」，并给出层标签（具体-对应层／序列-数制层／符号-记号层／公理化-演绎层）。
   - 输入契约: 必须提供具体做法或记号规则的原文/复述，含其适用条件与单位；只给出「抽象」「形式化」这类形容词时先问，不许替用户编例子。
   - 判停条件: 若对象没有可指认的表征（纯口头概念），停止本卡，转 `problem-definition-troubleshooting`。
2. **识别用到的抽象化动作**
   - 完成标准: 从四个动作中至少命中一个并写明书中行号依据——归约（L883）／对应与序列化（L699、L701）／具体物→符号（L1707、L1717、天元术 L1815）／特例→公式→公理（L1011、L941、L1333-1335）。
   - 判停条件: 四个动作都不命中 → 该对象不属于抽象化主题，停止，或转 `symbolic-logic-calculus`。
3. **做代价检查（包袱筛查）**
   - 完成标准: 写出这次抽象新增的限制，并注明书中依据（齐次性/同维度约束 L1713；欧洲长期回避负数 L1609；以「不足言之也」接受无理数而不追究 L1611；宁可要门派记号而不换效率记号 L3067）。
   - 判停条件: 若该动作只增加限制、不扩大可表达或可计算的对象集，判为「包袱型抽象」，跳到第 5 步并在输出中标明。
4. **给出迁移动作**
   - 完成标准: 写明「把什么换成什么」以及换掉之后原来不成立的结论如何处理；每个动作注明书中先例行号，无先例则标「书内无先例，属外推」。
   - 判停条件: 若目标层要求引入书中未讨论的结构，停止并标「超出本卡证据范围」，不得临场补理论。
5. **输出抽象层谱**
   - 输出契约: 一张表（列：现行做法／抽象层／目标层／迁移动作／书中依据行号／新增限制）＋ 一行结论（这次抽象是升级还是包袱）。引文与依据一律带 `L####`。
   - 完成标准: 表内每行都有行号依据或「书内无先例」标注；不出现书外公式、书目与数据（不新增外部知识）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 要直接求解某个值或给出逼近步骤——那是 `recursion-iteration`／`encoding-rule-initial-state` 的活儿。
- 要评估记号/接口设计的实际效率（推导成本、可复用性）——本卡只提供历史依据，不下工程结论。
- 要引用历史事实、年代与人物事迹作为定论——本书史实有 3 处与外部主流不一致（NR-01），且「英国数学落后近两世纪」类表述为通俗史说法（ce97，L3067，待核查）。
- 要给「抽象化」找一条统一流程——本单元是 202 条候选的历史方法集群，不是单一可执行流程。

### 作者在书中警告的失败模式

- 因「不自然/无意义」回避中间对象（ce59，L1609）：欧洲一直到 16 世纪仍在回避负数，回避它就等于限制算法能力（算筹/直除程序会在中途遇到减数大于被减数）；古代中国因程序需要而毫不犹豫地接受了负数。
- 「不足言之也」式自我豁免（ce60，L1611）：古代中国数学家豁达地接受了无理数，但一句「不足言之也」，也让他们失去了从无理数中发展出演绎推理的机会——接纳与追究是两件事。
- 用门派立场而不是符号效率选记号（ce97，L3067）：点主义／d 主义之争使推导成本整体上升，产出长期落后（作者表述为「将近两个世纪」，待核查）。
- 把上一层成功表达固化下来（p103，L1713）：齐次性原则使代数处处被几何意义限制，直到笛卡儿才被打破。

### 作者的盲点 / 时代局限（含阶段 1.5 登记的待核查项）

- **阶段 1.5 note（必继承）**：本单元是「历史方法集群」（202 条），非单一可执行流程；阶段 1.6 预计承担来源路由而非独立入口。写卡因此只取「抽象化手法」这一可执行面，其余条目作历史底座。
- **NR-04 OCR 公式残缺（第2章 L1657-1665 等）**：花拉子米六类方程判别式、群阶算例等公式区在底本中残缺，本卡只记结构、不提供数值复算。
- **NR-01 ①**：书内称「贝尔特拉米证明第五公设是独立于前四条公设的」（L463、L4065）——外部主流把双曲几何的独立发现归于罗巴切夫斯基与鲍耶，贝尔特拉米的贡献是欧氏模型下的相对一致性证明。引用此处须标「书内表述，与外部主流叙述不一致，待核查」。
- **NR-02 术语口径**：全书用「哥德尔数／编码」；OCR 错形（入演算＝λ演算、悸论/湟论＝悖论、炳/摘＝熵）照抄。
- **NR-06 全局 OCR 限制**：折行与上标丢失（`10ll`、`4×1075` 等）不得当准确数字；本卡引文以 `…` 连接处即为折行拼接。
- **候选 spillover**：部分候选因 `task_ids` 宽泛而挂入本单元（如 f284 附录A 科研范式史，主属 v25；f109 逻辑主义重建，主属 v10），引用时须按主属单元处理。
- **「最早/最原始」类判断须标书内叙述**：书中用考古与人类学材料（如约 3 万年前的刻痕计数遗迹、原始部落的数觉上限）支撑这类判断，属叙事性概括；本卡不把任何单点年代当作可引用定论。

### 容易混淆的邻近方法论

- `symbolic-logic-calculus`: 也在讲记号与形式化，但对象是 ch3 的「符号优先、推理即计算」原则，不是从计数到代数的层谱。
- `encoding-rule-initial-state`: 也谈「把东西编码」，但它输出的是可执行设计契约（编码／规则／初始状态），本卡输出的是历史层谱与迁移动作。
- `foundations-infinity`: 也涉及实数与数系扩张，但它处理的是严格化与无穷（戴德金分割、潜/实无穷），本卡处理记号与运算的抽象层。
