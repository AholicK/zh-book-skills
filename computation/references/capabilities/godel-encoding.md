# 哥德尔式编码与自指良恶性判定

## R — 原文 (Reading)

> 然后，哥德尔按照一定的规则，将PM里的所有符号、变量、公式和公式序列都转换成一个唯一的数字，称为“哥德尔数”。……一个公式的哥德尔数可以这样计算：将所有素数从小到大排列，对应公式里每个符号的位置，然后取每个符号对应的哥德尔数作为该位置素数的指数，最终相乘得到。
>
> — 第7章 计算不能做什么：终结者哥德尔（L4367 / L4453）

## I — 方法论骨架 (Interpretation)

本卡是 v08「自指系统界限诊断」的构造面：v08 回答界限在哪里，本卡回答编码怎么造、以及一条自指表达式是良性的还是恶性的。

- **编码的目的是让形式系统谈论自己**：给符号、变量、公式、公式序列逐层分配唯一数字，于是公式之间的排列关系被翻译成数字之间的算术关系，PM 的证明论完全算术化（L4505）。
- **分层规则（只记结构，不复述残缺符号）**：固定符号占一段连续小整数；数字变量、命题变量、谓词变量分别用大于某阈值的素数的 1／2／3 次幂区分；公式的码＝按符号位置取素数序列、以各符号码作指数连乘；公式序列（即「证明」）的码＝以各公式的码作第 i 个素数的指数连乘。
- **可逆是硬要求**：并非所有正整数都是码，但每个码唯一对应一个表达式；给定正整数能在有限步判定它是否为有效编码并还原（小整数段→固定符号；素数／平方／立方→变量类型；合数→按算术基本定理唯一分解）。
- **良恶性的分界线是「能否被直接定义」**：说谎者式的「这句话是假的」直接指向自己、无法被直接定义，属恶性循环；哥德尔的构造只断言「某个表达句有一个唯一的哥德尔数」，「这里没有任何的循环，只是恰好这个哥德尔数也可以作为这个表达句的变元」（L4511）。
- **第二条判据是数否定次数**：奇数次的否定构成恶性循环、会导致悖论出现；偶数次否定是良性循环，不构成悖论（L3471，原文「悸论」[原文如此]）。
- **第三条判据是层次纪律**：证明论命题（关于系统的命题）与系统内命题必须严格区分，把前者等同于后者「正是理查德悸论中的谬误」（L4509，另见 L4357；「悸论」[原文如此]）。
- **为什么有效**：编码之后，自指不再是语义循环，而是可机械检验的算术关系——这正是哥德尔能绕过理查德式谬误的原因（L4509）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 反查 243000000，还原出公式「0=0」
- **类型**: 原书例题
- **问题**: 给定一个大正整数，它是不是某个公式的哥德尔数？如果是，对应哪条公式？（L4473 起）
- **方法论的使用**: ① 判据先行——「并非所有正整数都是哥德尔数」，但给定正整数可以反过来确定它是否代表某个精确表达式；② 按三类分支处理：小整数段对应固定符号，大于该段则先验证它是否为素数、素数的平方、素数的立方，以判断是否为各类变量；③ 对合数则「根据算术基本定理，一个正整数如果是合数，则可以被唯一地分解为带有相应指数的素因子的乘积，而这正是哥德尔数对公式的描述」（L4473）；④ 书中给出的逐步分解为 243000000 → 64×243×15625 → 26×35×56 →「对应公式 0=0」（原文上标被 OCR 压在基线上，此处照抄 [原文如此]）。
- **结论**: 解码在有限步内完成且结果唯一——「在PM中，表达“0等于0”的公式的哥德尔数是243000000」（L4487），编码因此可逆、可机械检验；本卡只记结构与书中已给的十进制值，不做数值复算。
- **结果**: 书中未说明其他算例；该分解过程说明任何正整数都可检验其是否为有效哥德尔数。
- **待核查**: NR-04——幂次写法在 OCR 中残缺（原文作 26×35×56），照抄不更正。

### 案例 2: 莱布尼茨特征数：复合概念算成素因子之积
- **类型**: 原书例题
- **问题**: 能不能把「概念分解」变成整数运算，使推理可以计算？（第3章，L2613-2615）
- **方法论的使用**: 给每个词项指定一个特征数，复合概念的特征数由组成它的词项特征数相乘产生。书中照抄的演算是：动物＝a＝2，理性＝r＝3（因为人＝理性的动物）⇒ 人的特征数 h 就将是 2 乘以 3，或 6（原文行末「3,」为半角逗号，照抄）。
- **结论**: 概念之间的关系被翻译成整数之间的乘法关系——书中称 200 多年后哥德尔数所用的编码形式与此如出一辙。
- **结果**: 莱布尼茨本人未完成该演算系统（书中未给出该演算的后续）。

### 案例 3: 自指良恶性对照：说谎者（恶性）与互相否定的一对句子（良性）
- **类型**: 原书例题
- **问题**: 两句话互相指向时，什么情况构成悖论、什么情况不构成？（第5章，L3463-3481）
- **方法论的使用**: ① 先把互相指向的句子链拆开，数其中的否定次数——「这种自我指涉，如果是奇数次否定，则构成恶性循环，会导致悖论出现；如果是偶数次否定，则是良性循环，不构成悸论」（L3471，悸论[原文如此]）；② 恶性样板：说谎者「这句话是假的」，它直接指向自己、无法被直接定义（L3463，另见 L4511）；③ 书中在规则句之后紧接给出扩展例子，即一对互相断言对方为假的句子（S：S′是假的；S′：S 是假的，L3473-3475），按奇偶规则属偶数次否定。
- **结论**: 判定自指良恶性不必讨论语义真假——先数否定次数的奇偶，再看它是否经由唯一编码作中介，两条判据会给出明确的一边。
- **结果**: 书中未对这对扩展句子单独给出裁决文字；作者在同一节补上由编码提供的中介判据（f136，L4509-4511）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要为一套符号／规则体系设计编码，并希望编码可逆、可机械校验。
2. 用户手上有一条自指表达式（「本规则不适用于自身」「此条款不约束本协议」「本句为假」），想知道它会不会造成恶性循环。
3. 需要让系统「谈论自己」——把关于系统的事实映射成系统内部可陈述的对象。
4. 讨论哥德尔证明时，需要把「编码 + 自指」的构造步骤讲清楚，并避免把证明论命题与系统内命题混同。

### 语言信号

- 「帮我给这套符号设计一套编码规则。」
- 「这条规则说『本规则不适用于自身』，会不会出问题？」
- 「怎么判断一个自指表达式是良性的还是恶性的？」
- 「怎么让这个系统谈论它自己？」
- 英文: "design a numbering for this formal system"、"is this self-reference benign or vicious?"、"let the system talk about itself"、"reversible encoding"

### 与相邻 skill 的区分（阶段 3 定稿）

- 与 `self-reference-limits` 的区别: v08 是整体诊断——「编码 + 对角线 + 归谬」一起用，结论指向系统界限（存在真而不可证的命题）；本卡只做构造面——给编码规则、解码校验与自指良恶性判定，不下「界限在哪」的结论。
- 与 `encoding-rule-initial-state` 的区别: v05 是为一套计算／符号变换系统设计编码、规则与初始状态（面向可运行的变换过程）；本卡面向已有的形式系统，目标是可逆编号 + 自指判定。
- 与 `formal-system-checkup` 的区别: v10 判体系四项性质并给后果；本卡在体检判出问题之后提供「让系统谈论自己」的构造手段。

## E — 可执行步骤 (Execution)

1. **确认编码对象与符号表**
   - 完成标准: 符号表封闭且可枚举（每个符号只出现一次、彼此可区分），并区分「固定符号」与「变量」两类；变量再按种类分组。
   - 输入契约: 待编码系统的符号清单 + 各符号的类别 + 允许使用的码值空间。符号表不封闭、存在同形符号或缺类别标注时先问，不得自行合并或拆分符号。
   - 判停条件: 若符号表无法枚举（如动态生成的无界符号集）→ 停在此步输出「编码不可行」，并转 `formal-system-checkup` 检查该体系的定义是否完备。
2. **分层赋码**
   - 完成标准: 固定符号取一段连续小整数；各类变量用素数的不同幂次区分（幂次与变量种类一一对应）；码表内无冲突（任两类的码值集合不重叠）。
   - 判停条件: 若码值空间不足以分层 → 调整分段或改用更大的素数区间，回到本步重做。
3. **构造公式码**
   - 完成标准: 写出结构式「按符号位置取素数序列、以各符号码作指数连乘」，并说明该式给出唯一正整数。
   - 输出契约（本步局部）: 结构式 + 符号串到码的对应关系说明；本步不提供具体数值（源文公式区 OCR 残缺）。
4. **构造公式序列码（证明的码）**
   - 完成标准: 写出结构式「序列第 i 个公式的码作第 i 个素数的指数连乘」，并说明它把整个「证明」变成单个正整数。
   - 判停条件: 若只需判定单条公式的自指性 → 跳到第 6 步。
5. **解码反查**
   - 完成标准: 给出三类分支并能在有限步内出结论：落在小整数段 → 固定符号；素数／素数平方／素数立方 → 对应类别的变量；合数 → 按算术基本定理唯一分解后读回指数序列；以上皆非 → 判「不是有效编码」。
   - 判停条件: 若分解得不到合法指数序列 → 直接输出「该正整数不是哥德尔数」，不得强行解释。
6. **判定自指良恶性**
   - 完成标准: 三条判据逐条给出结论——① 是否经由唯一编码作中介（经编码 → 良性；直接指向自身 → 恶性）；② 否定次数奇偶（奇数 → 恶性；偶数 → 良性）；③ 是否把「关于系统的命题」当作「系统内的命题」使用（是 → 谬误）。
   - 判停条件: 若第 ③ 条命中（证明论命题与系统内命题未分层）→ 判为恶性／谬误，并转 `self-reference-limits` 做整体诊断。
7. **交付编码记录**
   - 完成标准: 记录含符号表与分层码表（结构）、公式码与序列码的结构式、解码分支与一个可复算示例（仅限书中已给出原值者）、良恶性判定结论与依据三条。
   - 输出契约: 一份编码记录；末尾须列「OCR 残缺、不得数值复算」项清单与待核查标记。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要数值精度的场合：本单元的编码表与公式区在 OCR 中残缺，只记结构、不提供数值复算（NR-04）。
- 把编码当成「证明系统不会出错」的手段：编码只让系统能谈论自己，不产生一致性，也不提升可靠性。
- 对不含初等算术的弱系统套用「必有不可判定命题」的结论：「不是所有公理系统都是不完备的」，只含加法的 Presburger 算术可以既一致又完备（L4533）。
- 把编码结果当作语义内容：编码是映射，不是等同（L4507、L4509）。

### 作者在书中警告的失败模式

- ce159（L4355）：理查德悖论——「命题“n是理查德数”既真又假：一个数n为理查德数当且仅当它不是理查德数」。失败点在于把「关于算术系统的证明论命题」在毫无预警的情况下当成系统内的算术命题使用（L4357）。
- ce160（L4509）：「将“关于PM的命题”等同于“PM之内的命题”，即将证明论命题包含在其描述的形式系统之内，正是理查德悸论中的谬误」（悸论[原文如此]）。
- c220（L4507）：奶茶店号码牌的类比给出正确做法——顾客取餐的先后顺序被转化成号码数字的大小关系，是「映射」而非「等同」；哥德尔数之间的算术关系恰好映射证明论命题之间的关系，但他并没有将哥德尔数直接对应到证明论命题上（L4509）。
- f98（L3385）：良定义的通用判据——定义里不得预先用到被定义的对象（「弗雷格采用的一一对应的方法，并没有涉及1这个数，因此不存在恶性循环」）。

### 作者的盲点 / 时代局限（含阶段 1.5 登记的待核查项）

- **术语口径（阶段 1.5 note，NR-02，本单元重点）**：全书未把「哥德尔」与「编码」连成一个固定术语（0 命中），本卡一律按原文写「哥德尔数」（「编码」只作动词使用）；OCR 错形照抄并标 [原文如此]，不得更正——如「悸论」（悖论）、「自已的」（自己的）、L4353 中被识成「一」／「一一」的破折号。
- **OCR 残缺（NR-04）**：12 个固定符号与小整数段的对应表未解析（L4369 只说「用数字1~12分别表示形式系统PM里的12个符号」，紧随的表在 L4373-4391 只剩碎片）；公式码行（L4455）与序列码行（L4469，原文作 k=2″×3"）的上标被 OCR 压成引号；算例幂次（L4479 作 26×35×56）同样残缺——本卡只记结构，不提供数值复算。
- **完整构造本书未展开**：作者自陈「完整的哥德尔证明非常复杂，在开始主要证明之前需要先掌握46个预备定义和引理，在此只简单介绍一下大致思路」（L4363）——本卡是思路层面的流程，不是可逐条执行的完整证明。
- **NR-06 上标降级**：含指数处一律标 待核查，不得当准确数字。
- **结论有适用范围**：自指并不必然致命——两项打击都要求系统「强」到能把足够的算术关系（加法和乘法）形式化（L4529-4533）；弱系统可以既一致又完备。不得把「自指 → 悖论」当无条件规律。
- **候选 spillover**：本单元 21 条候选无跨单元交叉（brief 记「跨单元交叉：（无）」）；但 f136／f100 同时属 v08（task-07）的候选，本卡只取本单元主属（task-11 的编码与判定）为依据。

### 容易混淆的邻近方法论

- `self-reference-limits`（v08）：整体诊断（编码 + 对角线 + 归谬 → 界限）；本卡是它的构造面，不做对角线构造与归谬。
- `encoding-rule-initial-state`（v05）：为可运行的符号变换系统设计编码／规则／初始状态；本卡为已有形式系统做可逆编号与自指判定。
- `formal-system-checkup`（v10）：判体系四项性质；本卡在体检之后提供构造手段——顺序上常被颠倒，且两卡都必须避免把「证明论命题」与「系统内命题」混为一谈。
