# 有穷化改写

## R — 原文 (Reading)

> “如果p是一个素数，那么总存在一个素数大于p”。这个论述是非有穷性的，因为它是一个关于所有大于p的整数的论述。而论述“如果p是一个素数，那么在p和p!+1之间总存在一个素数。”是有穷性的
>
> — 第6章·希尔伯特纲领（L4149）

## I — 方法论骨架 (Interpretation)

本卡处理「一条论述无法验证」这一类抱怨，动作是把关于无穷多对象的话，改写成只需要检验有穷多个对象的话。

- **判据只有一句**：这条论述是否只在有穷多个对象上做断言。像「总存在一个素数大于 p」要遍历所有大于 p 的整数，因此无法逐项检验；改写成「在 p 与 p!+1 之间存在一个素数」后，范围被一个明确的界框住，检查者只需在有限区间内逐项找。
- **改写不是弱化**：区间上界 p!+1 由 p 自己算出（书中用阶乘造界），要保住的结论（存在更大的素数）没有变，变的是可检查性。
- **固定动作序列**：定位量化词 → 判断是否落在有穷对象上 → 找一个带明确有穷界的等价表述 → 验证新表述仍能推出原结论 → 用「是否可具体检查」做终审。
- **书中引用的工作口径**：有穷性指论述／定义「限制在完全可构造的事物、完全可行的过程范围内，并在可具体检查的领域内执行的情形」（L4149，作者引用的原文措辞）。
- **代价必须同时报告**：有穷化会丢掉一部分内容。作者明确承认数学中大部分理论需要无穷模型，「如果舍弃它，对数学的限制将非常大」（L4151）——所以这是局部手术，不是全局替代方案。
- **为什么有效**：可验证性来自「界的明确与有限」，而不来自结论有多强。图灵 1936 年定义「可计算数」时沿用同一手法——把无穷量转化为一个有穷的计算过程（L4179）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 希尔伯特素数例：把「总存在更大素数」收进有限区间
- **类型**: 原书例题
- **问题**: 希尔伯特要给「证明论必须有穷」一个可操作的例子——一句话怎样才算有穷性的？（L4149）
- **方法论的使用**: ① 原句「如果p是一个素数，那么总存在一个素数大于p」被判定为非有穷，理由是它关于所有大于 p 的整数做断言；② 交出改写句「如果p是一个素数，那么在p和p!+1之间总存在一个素数」；③ 判定依据写在改写句之后：对任何一个素数 p，所要检验的只是「在 p 和 p!+1 之间有限个整数中是否存在一个素数」；④ 随附作者引用的口径定义，把有穷性落到「完全可构造、完全可行、可具体检查」三件事上。
- **结论**: 同一件事有了两种说法，前一种是无穷论述、后一种是有穷论述；判定标准就是要检验的对象是不是有限个。
- **结果**: 书中未说明该例子被用于哪条定理；它以证明论「有穷性」要求的操作化示例出现（区间上界 p!+1 系原文写法）。

### 案例 2: ε-δ：把「无限趋于」改写成不等式区间
- **类型**: 原书案例
- **问题**: 柯西的极限表述「一个变量无限趋于一个极限」在日常语言里含糊，无法逐步检验（L3097）
- **方法论的使用**: ① 先指出旧表述里的直观成分——魏尔斯特拉斯认为它「依旧存在运动上的直观」；② 再引入可任取的小量与可找到的邻域参数，把极限与连续性写成「任取…总存在…使得…」的不等式区间形式；③ 目的是让极限和连续性「彻底摆脱了对几何和运动的依赖」，「只建立在数的基础上」（L3097、L3099）。
- **结论**: 「无限接近」这种过程描述被换成一组对给定量的不等式条件——检查者按需取一个量、再去找到对应的界即可。
- **结果**: 书中未给出该改写的完整符号形式；后续魏尔斯特拉斯又以病态函数说明「通过运动建立的曲线，不一定有切线」（L3099）。
- **待核查**: NR-04——L3097 的不等式在 OCR 中残缺（原文作「总存在某一正数8……0<x-2<8时，都有x2-4<8」），符号与数值均不可复述。

### 案例 3: 把「所有用户都不会绕过审计」改写为可验收条件
- **类型**: 合成演练（原书未提供案例）
- **问题**: 一条典型的验收条款「所有用户都不会绕过审计」，无法在有限时间内检查，结项时也无法判定真假。
- **方法论的使用**: ① 定位量化词「所有用户」「不会」，作用域＝全体用户 × 全部时间；② 判定为非有穷——要遍历无穷多的「用户—时间」组合；③ 构造有穷界：把范围收窄为「在 X 天窗口内、对 Y 条抽样操作，绕过审计的成功次数为 0」，界由原文自带参数（时间窗、样本量）给出，与素数例用 p!+1 造界同型；④ 验证蕴含：抽样为 0 不能推出全体为 0，故必须同时写出丢失的强度——改写句是原断言的必要条件而非等价式；⑤ 终审：任何人拿到 X、Y 与样本即可在有限步内判定真假。
- **结论**: 得到一条可逐步检验的验收条件 + 一句明确的范围与强度损失说明。本演练按书内规则（受限区间 + 可具体检查）执行，但时间窗与样本量为演练自行设定，书中无此例。
- **结果**: 未说明（合成演练；真实场景的界须由业务方给出，不得由执行者静默假定）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手里有一条无法验证的全称断言或验收条款（「所有请求都不会超时」「任何人不得绕过流程」），要在落地前变成可检查的东西。
2. 有人用「理论上一定存在」「必然存在」收尾一段论证，但没给出可检验的形式。
3. 需要为规范／合同／测试用例写「可验收的表述」，被要求「给出能在有穷步骤内判定的条件」。
4. 讨论「无穷」时想区分：这句话是要遍历无穷多对象，还是只需检查一段有限区间。

### 语言信号

- 「这句话涉及『所有』，我没法验证。」
- 「怎么把这条全称断言变成可执行的验收条件？」
- 「他又是『理论上一定存在』就结束了。」
- 「这条规范不可操作，测不了。」
- 英文: "make this claim finitely checkable"、"rewrite the universal statement into a testable condition"、"this claim is untestable as stated"

### 与相邻 skill 的区分（阶段 3 定稿）

- 与 `formal-system-checkup` 的区别: v10 判体系的四项性质并给后果，本卡只改一条论述的表述，不改体系、不下四性质结论。
- 与 `paradox-assetization` 的区别: v22 先判这里的「无穷」是潜无穷还是实无穷、能否当资产用；本卡默认对象是有限可构造的论述，只做改写。
- 与 `inherent-constraints` 的区别: v04 列的是计算系统先天做不到的事（精度截断一类），本卡把「做不到逐项检验」的表述改写成做得到的表述。

## E — 可执行步骤 (Execution)

1. **定位量化与作用域**
   - 完成标准: 列出待改写论述中所有「任意／所有／总存在／永远／必然」的出现处，并写出各自的作用域（对哪些对象、在什么时间范围内）。
   - 输入契约: 待改写的原论述全文 + 它要服务的结论 + 允许使用的参数（如时间窗、样本量、上界）。只给半句或转述时先索要原句，不得凭印象补全。
   - 判停条件: 若论述中不含任何无穷量化词 → 停在此步，记为「已有穷」，不做改写。
2. **判定有穷 / 非有穷**
   - 完成标准: 对每处量化给出「可逐项检验 / 不可逐项检验」二值判定，并说明要遍历的对象数是否有界。
   - 判停条件: 若判定为不可逐项检验、且对象本质上是无穷过程的整体运算（例如追问无穷序列的终点结果那一类超任务）→ 转 `paradox-assetization`，不要强行改写。
3. **构造带界表述**
   - 完成标准: 给出改写句，并写明界的来源（由原论述中的参数算出，或由使用方给定）；界必须使待检对象成为有穷个。
   - 判停条件: 若找不到任何有穷界可框住结论 → 停下并报告「该断言不可有穷化」及原因，不得用含糊措辞代替。
4. **验证蕴含关系**
   - 完成标准: 明确写出改写句与原句的关系是「等价 / 必要条件 / 不再蕴含」三者之一；若为必要条件，逐条列出丢失的强度。
   - 判停条件: 若改写后不再蕴含原结论 → 回到第 3 步换界；连续两次失败则转 `formal-system-checkup`，检查该体系本身是否缺少可判定的条款。
5. **有穷可检查性终审**
   - 完成标准: 给出具体检查步骤（谁、拿到什么、按什么规则、在多少步内出结论），并确认检查过程不需要预设无穷多个对象。
   - 输出契约（本步局部）: 检查步骤清单 + 所需输入参数清单。
6. **交付改写记录**
   - 完成标准: 表格四列齐全——原句 / 改写句 / 界与来源 / 保留与丢失；表末附「尚未有穷化的残留量化词」清单。
   - 输出契约: 一份改写记录（上述表格 + 一行「可用于验收／仅可用于筛查」的结论）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把它当成通用的「把复杂问题简化」手段：本卡只处理量化范围问题，不处理复杂度、精度或工程取舍。
- 对本质上依赖无穷模型的结论强行有穷化：作者自己承认数学中大部分理论需要无穷模型，「如果舍弃它，对数学的限制将非常大」（L4151）——那类对象应转 `paradox-assetization` 或 `relative-consistency`。
- 用它把「不可证」包装成「已检验」：改写只降低检查成本，不提升断言强度，也不改变命题的真假。

### 作者在书中警告的失败模式

- ce137（L3855）：希尔伯特解到一半解不出来便「大手一挥不解了」，说「在形式系统里成立自然能推导出来」（原文「还铮有词」[原文如此]）——用形式系统的存在性信念替代具体推导。改写时若只写到「必然存在」而不给可检查形式，就是同一类失败。
- ce14（L507）：把「数学真理在于有穷性」的方法推及全部数学，结果是「一个包含初等算术的希尔伯特形式系统既不完备，也无法从系统内部证明自身的一致性……被希尔伯特寄予厚望的重塑数学基础的计划就这样彻底破产」。
- ce44（L1289）：汤姆逊灯——想从无穷过程的终点读出结果，「不管我们采用哪种无穷观点，我们都得不到最终结果的数」，且「现实中根本构造不出这样的实验」。不要把无穷多步操作当成可执行的操作计划。

### 作者的盲点 / 时代局限（含阶段 1.5 登记的待核查项）

- **证据偏薄（阶段 1.5 note，本单元重点）**：本单元仅 18 条候选，是全书 27 个单元中最小之列，原书未提供练习或独立例题，A1 的第三个案例是明确标记的合成演练——不要把「有穷化改写」当成书中已给出完整算法的通用工具。
- **书中未给一般化算法**：作者只给了素数例与「有穷性」的口径定义，没有说明「哪类论述可改写、改写后是否等价」——等价性必须逐案验证，不得凭形式相似直接套用。
- **NR-04 OCR 公式残缺**：ε-δ 的具体不等式（L3097 一带）与康托尔「高」的定义式（L3145，原文作「h= n+a+a|+a2|+..+an--+|an」）均残缺，只记结构、不提供数值复算；f88／p180 的分层枚举式同理。
- **NR-06 上标降级**：含指数处（如案例 1 的区间上界写法）一律照原文，涉及指数的数值一律标 待核查，不得当准确数字。
- **作者预测性主张不得当方法依据**：p451「人类的知识是有穷的，终有一天机器能够建立起这个知识库」（L7705）属作者预测；c428 的「10000人中70%以上」共识阈值（L7831）是作者设想，书中无任何实测统计——两者只能作为作者主张出现。
- **依赖未证明假设**：若要由「改写后有穷」进一步断言「必能在有穷步内判定」，须注意含初等算术的系统存在真而不可证的命题；而「不是所有公理系统都是不完备的」，弱系统（如只含加法的 Presburger 算术）可以既一致又完备——两头都不能当默认前提。

### 容易混淆的邻近方法论

- `formal-system-checkup`（v10）：体检的是体系的性质；本卡改的是一条论述的表述。通常顺序是先体检、判出可判定性缺失后才轮到本卡，实践中常被颠倒。
- `paradox-assetization`（v22）：判别「无穷」是潜无穷还是实无穷、能否当资产用；本卡不判别无穷观，只做局部改写。
- `complexity-class-locating`（v14）：「高效算法」在书中被界定为「可以在有穷步骤内实现……步骤数随着输入长度增加而缓慢增加」（L5483），判据是「有穷步骤 + 缓慢增长的封闭性」两条，不要与「有穷性」混为一谈。
