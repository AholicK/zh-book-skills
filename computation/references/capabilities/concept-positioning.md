# 计算概念的定位与混淆诊断

## R — 原文 (Reading)

> 这些问题可以简单地归结到三个根本问题上：…计算的原理是什么？…计算的技术如何实现？…计算将对世界产生什么影响？
>
> — 导论·计算的三个问题（L383-387）

## I — 方法论骨架 (Interpretation)

先把「一场关于计算的讨论」这种没有形状的对象，装进两个正交的坐标，再判断讨论卡在哪一格。

1) 层次坐标（决定问题属于哪一类）：任何计算话题先归入三问之一——计算的原理是什么 / 计算的技术如何实现 / 计算将对世界产生什么影响。三问由三部书分别回答，本书只答第一问；跨层的争论不会收敛（用价值判断回答边界问题，或用实现经验回答可计算性问题，都属此类）。
2) 视角坐标（决定同一句话指向什么对象）：同一句「计算」在五类说话人处指向五个不同对象——老百姓＝加减乘除；程序员＝芯片执行指令的过程；信息产业从业者＝提供算力的机器和操作系统；计算机科学家＝图灵机所描述的严格数学定义；哲学家＝生物的进化、群体的演化乃至宇宙本源的奥秘。
3) 判据：不判各方对错，只判「是否混淆了层次」。同一场讨论中若两个发言者的结论分处不同坐标，则此场的结论不可合并。
4) 「原理」层内部还能再拆三问：计算的目的是什么 / 计算能算什么、不能算什么 / 我们需要什么样的计算。拆完再去找答案，而不是先答。
5) 口径约束：本书的「计算」对应 computing（一种可由机器执行的泛在计算），不是算术义的 calculation。引用本书的任何边界结论前，先确认讨论没有退回到算术口径。

执行次序：定层 → 定视角 → 判争点类型（同层可继续／跨层混淆／信念层不可判对错）→ 最后才决定这场讨论要不要继续。若争点落在四个无答案的问题（数学是发明还是发现、无穷的本质、机器能思考吗、宇宙是不是台计算机）上，到此为止，不再判对错。

## A1 — 书中的应用 (Past Application)

### 案例 1: 五类视角的混淆诊断（导论开篇）
- **类型**: 作者亲历
- **问题**: 作者长期在云计算领域工作，发现同一个词「计算」在不同人口中指向不同对象，讨论无法在同一水平面上进行；他自陈写作出发点就是让更多人对计算的概念有相同的认知基础，「能在同一水平面上进行对话」（L379）。
- **方法论的使用**: ① 把关于计算的一切问题收敛为三个根本问题（L383／L385／L387，并在 L389 交代三问分包给三本书）；② 逐个记录五类说话人的「计算」指什么（老百姓 L393-397／程序员 L401-403／信息产业从业者 L405-409／计算机科学家 L411-415／哲学家 L417-419）；③ 给出诊断——「不能说这些理解是错的，但在我看来其中一定混淆了概念」（L421）；④ 把第一问内部再拆成目的／能算与不能算／需要什么样的计算三小问（L427）。
- **结论**: 得到「三问 × 五类视角」的定位表，并据此划定本书的作答范围——只回答「计算的原理是什么」（L429）。
- **结果**: 全书以此框架开篇；该诊断在读者端的效果未说明。

### 案例 2: 在四个无答案的问题上争论对错（原书反例）
- **类型**: 原书案例
- **问题**: 「数学是发明还是发现」「无穷的本质」「机器能思考吗」「宇宙是台计算机吗」这四个问题被当作已有答案的事实问题来争论，并据此站队、下判断。
- **方法论的使用**: 作者先声明这四个问题他自己也没有答案，「世界上所有的数学家和科学家也都没有答案，只有猜想」（L539），理由是问题涉及世界本源、目前没有有效手段验证；随后给出处置规则：「因为没有答案，所以不存在对错。面对这些未解的终极难题，我们只能依靠心中的信仰做出自已[原文如此]的选择」（L561）。
- **结论**: 这四个问题只能做信念选择，不能做对错判定；把信念问题当事实问题争论属于层次错置。
- **结果**: 作者据此把「计算主义」一类立场整体归入信念层，另立第13章处理。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 会议或群里为「AI 算不算计算」「算力够不够」「算法和计算是不是一回事」争起来，各方越说越远，需要判定争点在哪一层。
2. 评估一项技术承诺（例如「算力再涨十倍就能解决」）时，需要先确认这句话是原理层的边界断言、实现层的工程判断，还是影响层的价值主张。
3. 写文章、做分享或给团队做概念对齐，需要一个把「计算」讲清楚的入口框架。
4. 有人把某一方立场（如计算主义、宇宙是台计算机）当作已被证明的结论引用，需要判断这句话能不能这么用。

### 语言信号

- 「我们说的是同一个『计算』吗？」
- 「这不就是算力问题吗？」
- 「这个争论到底在争什么？」
- 「AI 是不是计算？」
- 英文: "are we even talking about the same thing", "is this a compute problem or a computability problem", "which layer is this argument on"

### 与相邻 skill 的区分（阶段 3 定稿）

- 与 `abstraction-history` 的区别: 后者检查「抽象层次在历史上如何演进」（对象＝方法史），本卡检查「当前这场讨论里各方站在哪一层」（对象＝一次争论）。
- 与 `complexity-class-locating` 的区别: 后者对一个问题做复杂度定位、输出复杂度类；本卡对一场讨论做层次定位、输出层次-视角表，不产出复杂度结论。
- 与 `computationalism-boundary` 的区别: 后者处理世界观主张的可引用边界；本卡只做概念层次归位，不评判世界观本身。

## E — 可执行步骤 (Execution)

1. **收齐讨论样本**
   - 完成标准: 每条样本都带「说话人身份 + 原话 + 其主张的适用范围」，至少 2 条。
   - 输入契约: 需提供（a）待诊断的讨论记录/转述，或（b）2 条以上主张的原话与说话人；缺说话人身份时先问，不许按语气替对方归类，不许静默猜值。
   - 判停条件: 若只拿到 1 条主张、没有对立面，跳到第 4 步做单条口径澄清，不输出「混淆」判定。
2. **按三问定层**
   - 完成标准: 每条主张被标为 Q1（原理/边界）、Q2（技术实现）、Q3（对世界的影响）之一，并写明标注依据（该主张的结论是「能不能算」／「怎么算得快」／「该不该做」）。
   - 判停条件: 若一条主张同时跨两层（如「算力决定一切」），拆成两条分别标注，不合并。
3. **按五类视角归位**
   - 完成标准: 每条主张带视角标签（老百姓／程序员／信息产业从业者／计算机科学家／哲学家），并写出该视角把「算法／软件／硬件」各归到哪一边。
   - 判停条件: 说话人身份无法归入五类时标为「其他视角」，不硬套。
4. **判定争点类型**
   - 完成标准: 给出三者之一的结论——① 同层可继续讨论；② 跨层混淆（写明被混为一谈的两个层次）；③ 信念层（争点落在四个无答案问题上），不可判对错。
   - 判停条件: 若为 ③，停止判定并输出「信念层，不存在对错，只能作立场引用」，不进入第 5 步。
5. **输出定位表与口径确认**
   - 输出契约: 一张表（列：原话摘要／说话人／三问层 Q1-Q3／五类视角／混淆标注）＋ 一段结论（≤3 行，指出可继续讨论的部分与已判定为信念层的部分）＋ 一行口径确认（引自本书结论时，须确认沿用 computing＝机器可执行的泛在计算这一口径）。
   - 完成标准: 表中每条主张的「层」与「视角」两列都有取值；结论段不含任何对信念层的对错判断。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 要判断「某类问题能不能被算出来」「代价有多大」——那是可计算性与复杂度的活儿（`three-tier-screening`、`complexity-class-locating`），本卡只做概念归位。
- 要评估具体 AI 架构或智能系统方案（`machine-intelligence-paradigms`、`organization-computationalization`）。
- 需要工程可测的性能结论（吞吐、加速比、误差率）——本卡的输出是概念定位表，不对任何数值负责。

### 作者在书中警告的失败模式

- 五类人各说各话（ce01，L421）：同一句「计算」指向五个对象，讨论无法收敛，也无法判断谁的结论对谁错。
- 在无答案的问题上争论对错（ce19，L539／L561）：四个哲学问题被当作已有答案的事实问题，据此下判断、站队、定论。
- 以数学结构的完美充当物理存在的证据（ce20，L555）：书中举超弦理论「有完美的数学结构，却找不到任何的实验证据，已经偏离了科学的本意」。
- 把算法比作菜谱（ce241，L6659）：「我认为这种比喻很形象，但停留在了表面」——类比替代定义会丢掉「良定义（可停机）」这一维。
- 因领域风向回避准确术语（ce269，L7087）：因人工智能寒冬把「卷积神经网络」写成「卷积网络」，概念传承与检索受损。

### 作者的盲点 / 时代局限（含阶段 1.5 登记的待核查项）

- **NR-01 ②**：书内称彭罗斯是「与霍金一起获得诺贝尔奖的物理学家」（L607）——外部事实为彭罗斯获 2020 年诺贝尔物理学奖、霍金未曾获奖。该处位于「哥德尔信念」阵营的举证位置，引用须标「书内表述，与外部主流叙述不一致，待核查」，不得整段照抄。
- **NR-03 作者强推测（本单元归属条目，只能作作者主张引用，不得当结论）**：「由于世界可能存在单向函数……这可能是这个世界会存在犯罪的主要原因」（L659）；「推理越多，对算力的需求越大，因此算力在某种程度上可用于衡量价值」（L4927）；「我个人估计计算机革命有500年以上的保鲜期」（L2459）。
- **依赖未证明假设**：计算主义世界观（「大脑乃至宇宙是一台计算机」）依赖丘奇-图灵论题及其心灵版本、物理版本，均为信念选择而非已证结论；本卡只把它当立场处理。
- **候选 spillover**：本单元 76 条候选中有经 `task_ids` 误挂入的条目（如 f208「BPP 误差边界」、g30「戴德金分割」），引用与写卡须以 f01／f02／p01／p02（三问与五类视角）为主属依据，不得把 spillover 条目当成本单元主张。
- **NR-02 术语口径**：全书用「哥德尔数／编码」，无「哥德尔编码」；OCR 错形（入演算＝λ演算、悸论/湟论＝悖论）照抄不改。
- **NR-06 全局 OCR 限制**：折行与上标丢失（如 `10ll`、`4×1075`）。本卡引文中以 `…` 连接处即为折行拼接，未补字；引用含指数处一律标「待核查」。

### 容易混淆的邻近方法论

- `abstraction-history`: 也谈「计算概念的层次」，但它的判据是历史上的抽象递进（计数→记号→代数→公理），本卡的判据是当前讨论中的层次错置。
- `computationalism-boundary`: 同样处理「计算主义」这类主张，但它回答「这种世界观能用到哪一步」，本卡只回答「这句话属于哪一层、能不能与其它层的结论合并」。
