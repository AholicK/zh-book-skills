# 心理游戏：两层结构与识别方法

## R — 原文 (Reading)

> 我说的是一种长期重复的行为，这种行为可能持续一辈子，这类行为就被称为游戏。……玩这类游戏的必然后果是，玩家最终会产生糟糕的、不快乐的情绪。
>
> — 第十三章 人生坐标与心理游戏

> 游戏体现在两个层面：在社交层面上，似乎一切都是公开诚实的。而游戏玩家的真正动机却隐藏在心理层面，同时也隐藏着欺骗。至于游戏的必然后果呢，全都是让人产生负面情绪。
>
> — 第十三章 人生坐标与心理游戏

> 名字叫'猜猜我在想什么'。很多年来，老师一直对学生玩这个游戏，老师当然是赢家了。学生肯定觉得自己很蠢，就像你之前一样，而老师赢了无知的学生，就能获得优越感。
>
> — 第十三章 人生坐标与心理游戏

## I — 方法论骨架 (Interpretation)

"心理游戏"指**长期重复、以负面情绪收场**的行为模式——判定标准有三条：重复（不止一次、可能持续一辈子）、结局（玩家最终产生糟糕的、不快乐的情绪）、结构（两层）。两层结构是识别的核心工具：社交层"似乎一切都是公开诚实的"——说辞句句在理；心理层"隐藏着真实动机……同时也隐藏着欺骗"——真正要的是赢（优越感、确认预期）。发起动机"基本上都不是出于真诚"——不为好玩，而是为了那个戏剧化的结果。

对使用者来说，最重要的是把怀疑转换成格式：不要问"他是不是在玩我"（这是指控），而要拆——**表面在谈什么 / 底下真正要什么 / 结局是什么情绪**。同时记住两条方法纪律：①识别只能靠模式（长期、重复、结局雷同），不能靠单次对话——两层结构使游戏极难被当面揭穿，质疑动机时对方只需掏出社交层的合理解释；②工具使用守则——"这些理念不是用来给人贴标签，攻击羞辱别人的。它们只是用来理解行为的方法，尤其是理解我们自己的行为"。

具名游戏的完整清单与共谋机制在 `games-and-collusion`；坐标与游戏的系统对表在 `life-positions`。

## A1 — 书中的应用 (Past Application)

### 案例 1: "猜猜我在想什么"——当场演示的游戏
- **类型**: 叙事案例（第十三章）
- **问题**: 蛤蟆在面谈中支支吾吾，苍鹭突然不耐烦催促："我可没有一整天的时间等你"
- **方法论的使用**: 蛤蟆"仿佛重返学校被老师提问"；苍鹭随即揭示这正是游戏——"名字叫'猜猜我在想什么'……老师当然是赢家了……老师赢了无知的学生，就能获得优越感"
- **结论**: 概念以示范方式落地：信息不对称（答案只在提问者脑中）就是游戏设定，它把传授关系偷换成胜负关系
- **结果**: 蛤蟆一脸愠怒："希望你明白我一点儿都不喜欢这个游戏"——苍鹭承认并说明这类游戏的危害

### 案例 2: 两层结构与"恶意的游戏"
- **类型**: 叙事案例（第十三章）
- **问题**: 游戏到底"玩"在哪里
- **方法论的使用**: 苍鹭给出通用结构——不是出于真诚、结果戏剧化；社交层公开诚实，心理层隐藏动机与欺骗；必然后果是负面情绪
- **结论**: 由蛤蟆自己点出'不是"快乐的游戏"，而是"恶意的游戏"'
- **结果**: 面谈到此结束——判据（重复、两层、负面结局）成为后续所有具名游戏的共同尺子

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 「我觉得我们部门开会总有人挖坑让人出丑」——想弄清反复出现的负面互动
2. 「为什么我总被针对/总在同样的争执里收场」
3. 感到被套路但说不清"他到底想干嘛"
4. 想理解"这剧情我见过"式的重复模式

### 语言信号

- 「总有人让我难堪」「怎么回事，又是类似的事」
- 「表面上看挺有道理，可我就是觉得不舒服」
- 「他到底想干嘛」「是不是我想多了」
- 英文: "mind games", "why does this keep happening", "something feels off about this interaction"

### 与相邻 skill 的区分

- 与 `games-and-collusion` 的区别: 本条给"拆解任一游戏"的通用方法（两层结构）；具名游戏清单与共谋机制在那张卡
- 与 `life-positions` 的区别: 坐标解释"为什么总朝同一个方向"；游戏是坐标的具体表现——坐标定位后逐个对表
- 与 `critical-parent` 的区别: 挑剔型父母描述"一方的状态"；游戏描述"双方互动的结构"——同一场景可两种视角看

## E — 可执行步骤 (Execution)

1. **确认是"模式"而非单次事件**
   - 完成标准: 拿到至少两次以上、结局雷同的互动记录；单次冲突不适用本卡
   - 判停条件: 只有单次事件时，如实说明"现在无法判定为游戏"，先记录模式再回来看

2. **两层拆解**
   - 完成标准: 分两行写出——社交层：表面在谈什么（说了什么、句句在理的部分）；心理层：底下真正想要什么（赢什么、证明什么、让对方感觉如何）
   - 输入契约: 互动记录（谁发起、说了什么、怎么收场）；无需其他字段

3. **动机与结局核对**
   - 完成标准: ①发起是否出于真诚（还是为了戏剧化结果）②结局是否负面情绪（谁不舒服、为什么）；两条都命中才判"符合游戏结构"
   - 输出契约: ①模式描述（≥2 次）②两层拆解 ③动机/结局核对结论

4. **套使用守则收尾**
   - 完成标准: 输出包含守则声明（"这些理念不是用来给人贴标签、攻击羞辱别人的……尤其是理解我们自己的行为"）；证据不足时输出"疑似"而非"定罪"
   - 判停条件: 用户想用它做当面指控时停下，说明游戏极难被当面揭穿（对方只需掏出社交层说辞），指控只会升级冲突

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 指控他人（"你在玩我"）或当侦探工具监视别人
- 分析单次冲突（判定前提是长期重复）
- 替代对真实权力伤害的处置——被针对可能真的是伤害，识别游戏不等于"一个巴掌拍不响"

### 作者在书中警告的失败模式

- 把游戏当正常沟通（ce30）: 社交层说辞句句在理，质疑动机只会吃一颗软钉子——识别只能靠模式，不能靠单次对话
- "猜猜我在想什么"式的教育/顾问场景（ce29）: 提问者不给足信息却要求猜中答案——信息不对称即游戏设定，学习通道随之关闭
- 把工具当标签与武器（ce39）: "我猜你认为我是'不好'的，我完全就是个废物"式自我宣判，或反向误读成"那我就该像獾那样发火"

### 作者的盲点 / 时代局限

- 书中不讨论"为什么人会玩"的深层成因与修通方式；"如何停止"的完整步骤未给
- 游戏清单源自《人间游戏》（1964 年，100 种游戏）的时代语境，当代生活场景（微信、职场群聊、算法信息流）未覆盖
- 不区分"无意识游戏"与真实恶意——这是下游使用时最容易被误用的灰区

### 容易混淆的邻近方法论

- `games-and-collusion`: 具名清单（我真不幸、NIGYYSOB 等）与共谋机制——识别出结构后去那里查名字与止玩方向
- `life-positions`: 坐标↔游戏的关联分析法在那张卡
