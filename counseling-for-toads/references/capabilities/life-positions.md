# 人生坐标四象限与自证预言

## R — 原文 (Reading)

> 比如在你童年时，大约四到五岁左右，你会试图回答两个问题。……第一个问题是：'我是怎么看自己的？我好吗？'第二个问题是：'我是怎么看别人的？他们好吗？'
>
> — 第十三章 人生坐标与心理游戏

> 一切的关键就在于那是'人生坐标'。一旦我们在童年决定用哪种态度和观点，我们就会在随后的人生里始终坚持自己的选择。这些态度和观点，变成我们存在的底层架构。从那以后，我们便建构出一个世界，不断确认和支持这些信念和预期。换一个词来说，我们把自己的人生变成了一个'自证预言'。
>
> — 第十三章 人生坐标与心理游戏

> '我好；你也好'的人生坐标并非静止的状态，而是动态的过程。你不能说'好了，我终于到了'，好像登顶珠穆朗玛峰一样。你觉得自己是好的，也相信别人是好的，那就得靠行为和态度持续地对自己和别人展示出来。
>
> — 第十五章 最后一次面谈

## I — 方法论骨架 (Interpretation)

人生坐标是对两个基本问题的回答组合：**我好吗？他们好吗？**——各取"好/不好"，得到四种坐标：我好；你也好 / 我好；你不好 / 我不好；你好 / 我不好；你也不好。书中把坐标的形成定在四五岁，并把它的作用称为"存在的底层架构"：此后人"用同一个视角看待一切事物"，并以**自证预言**的方式维持它——"我们会控制事件的发生，从而确保预言会成真"。

自证预言的运作可以精确拆解（喝醉→宿醉的示例）：信念（生活不善待我）→ 行为（今天喝醉）→ 必然后果（宿醉难受）→ 印证的预期（果然悲惨）。所以"总遇到同类的事"不是玄学，而是一套可观察的行为循环。同一情境在不同坐标下的反应截然不同：预订的出租车没来，"我好；你不好"者大发雷霆，"我不好；你好"者悲伤、自责、把自己归为"最不重要的乘客"。

有两件事必须一起说：①坐标不是宿命——"除非你决心要改变"；②终点坐标「我好；你也好」是**勇敢的选择、终生的承诺、动态的过程**，且"不能给你庇护，免于残暴命运如投石飞箭般的摧残"。它还要一个使用守则："这些理念不是用来给人贴标签，攻击羞辱别人的"——尤其不是用来理解别人，而是"理解我们自己的行为"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 同一情境、两种坐标（出租车没来的假设举例）
- **类型**: 假设性举例（第十四章，**书中为演示而设、非实际发生的事件**）
- **问题**: 怎么看出两个人坐标不同？苍鹭设想：预订的出租车没来
- **方法论的使用**: "我好；你不好"的人会发火、怪罪司机（引出 NIGYYSOB 游戏）；"我不好；你好"的蛤蟆则"觉得悲伤……我或许会想，他接到的其他订单更紧急，而我是最不重要的乘客。我甚至会自责，认为兴许是我没把事情安排妥当"
- **结论**: 同一事件因坐标不同产生完全不同的解释与情绪链
- **结果**: 蛤蟆看清差别后情绪激动，反问"难道要我像獾一样发火"，并怀疑"我猜你认为我是'不好'的"

### 案例 2: "理念不是用来给人贴标签的"
- **类型**: 叙事案例（第十四章）
- **问题**: 坐标分析让蛤蟆感到被评判——"我完全就是个废物，是不是"
- **方法论的使用**: 苍鹭当即划出工具边界——"这些理念不是用来给人贴标签，攻击羞辱别人的。它们只是用来理解行为的方法，尤其是理解我们自己的行为"
- **结论**: 坐标是自我理解的工具，不是评判他人（或自我宣判）的仪器
- **结果**: 蛤蟆随后承认"此时此刻，我对你很生气，而且已经有一阵了"，当场把火发了出来

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 「我总觉得自己是团队里最差的那个，虽然别人说我不错」
2. 「为什么我总遇到同样的事/同样的人」——重复模式，想找底层原因
3. 自卑与自我价值感长期偏低，或反过来对谁都不屑
4. 想理解"我没有恶意，为什么总把关系搞成一样"

### 语言信号

- 「我不够好」「我配不上」「反正最后都会证明我不行」
- 「他肯定觉得我很差」
- 「为什么总是我」「为什么总是同一类人」
- 英文: "I'm not good enough", "why does this keep happening to me", "life position / self-fulfilling prophecy"

### 与相邻 skill 的区分

- 与 `ego-states` 的区别: 状态解释"这一次怎么反应"；坐标解释"为什么总朝同一个方向反应"——两套模型交叉印证
- 与 `self-criticism` 的区别: 坐标是背景设定（属于哪个象限）；法官是具体机制（谁来审判）；常先后使用
- 与 `games-and-collusion` 的区别: 游戏是坐标的表现与维持手段（逐个象限对表游戏）——坐标定位后转那张卡查具体游戏

## E — 可执行步骤 (Execution)

1. **两问作答**
   - 完成标准: 分别回答"我好吗？""他们好吗？"，得到四种组合之一；回答含糊时请对方先凭直觉给一个，再用行为示例校准
   - 输入契约: 用户自述；无需其他字段

2. **行为证据核对**
   - 完成标准: 用近期具体事件校准坐标（如被失约/被批评时的第一反应：生气指责还是悲伤自责），至少 1 条证据
   - 输出契约: ①坐标组合 ②≥1 条行为证据

3. **识别自证预言循环**
   - 完成标准: 找出一个"你做了什么让自己预期的事成真"的实例（按"信念→行为→必然后果→印证预期"四步拆解）
   - 判停条件: 若用户把坐标当"命中注定的判词"而绝望，先给出口声明（步骤 4）再继续

4. **边界与出口声明**
   - 完成标准: 输出必须包含——"坐标不是宿命（除非你决心要改变）"；"「我好；你也好」是动态过程 + 终生承诺 + 不提供免疫"；"不用于给人贴标签"
   - 输出契约: ①坐标组合 ②行为证据 ③自证预言实例 ④边界声明；**禁止**输出"你就是X坐标的人"式结论

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 给人贴标签或当心理测评使用（"你是'我不好；你好'型人格"）
- 把坐标迁移包装成"几步重塑信念"的技术——书中没有步骤，只有方向与终点
- 用坐标解释一切处境（贫困、歧视、疾病等外部现实对"我不好"感受的贡献，不在本书框架内）

### 作者在书中警告的失败模式

- 把康复当终点站（ce35）: "'好了，我终于到了'，好像登顶珠穆朗玛峰一样"——坐标靠行为与态度持续兑现，不是一次性通关；当成终点会在复发时加倍挫败
- 把理念当武器（c70）: 贴标签、攻击羞辱别人——书中明确禁止；蛤蟆当场感到"被评判"的反应就是警报

### 作者的盲点 / 时代局限

- **早期决定论**："四五岁定下、随后一直坚持"是强表述；未讨论后期经历、神经可塑性与其他治疗路径（BOOK_OVERVIEW §3）
- **坐标迁移无操作步骤**：书中只有"决心"这一入口与终点描述（V2 已登记）
- 坐标是解释性模型而非心理测量工具；"好/不好"的判据在书中是可指任意具体内容的，边界模糊

### 容易混淆的邻近方法论

- `ego-states`: 另一套模型（父母/成人/儿童）；两套模型不要混用同一套话术
- `self-criticism`: "我不好；你好"的极端形态会与自我审判叠加；严重时转 `depression-warning-signs`
