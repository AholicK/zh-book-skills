# 自然型儿童与四种基本情感

## R — 原文 (Reading)

> 我们的某些基本情感是与生俱来的，就好像红黄蓝三原色，对所有婴儿来说都是类似的。然而当我们作为个体开始发展的时候，我们的情绪和反应都变得越来越个人化，就好像几种原色混合在一起就变出各式各样微妙的色调和色差来。
>
> — 第五章 成长的寓言

> 儿童的基本情感 快乐和深情 愤怒 悲伤 恐惧
>
> — 第五章 成长的寓言（挂纸板清单）

> 如果我看到有人非常深情，或者发怒、悲伤和害怕，我就能说这人正处在'自然型儿童'的状态里。
>
> — 第五章 成长的寓言

## I — 方法论骨架 (Interpretation)

儿童自我状态这枚"硬币"有上下两半：上半部是**自然型儿童**——与生俱来的情感底子，由四项基本情感构成：快乐和深情、愤怒、悲伤、恐惧（书里比作红黄蓝三原色）；下半部是**适应型儿童**——为适应父母而调整出来的部分（转 `adapted-child-patterns`）。自然型这一半是"出厂配置"，不是品格问题，也不分好坏。

识别口径是直接的：看到某人非常深情、发怒、悲伤或害怕——即四项基本情感的直接流露——就可以说对方处在自然型儿童状态里。用途有二：①给情绪一个最小可用的命名表，把"我很糟糕"翻译成"我在悲伤/害怕/生气"；②自查"哪一项我最不熟悉、最不敢有"——那一项往往就是被调暗（适应）最重的部分（转 `adapted-child-patterns` 与 `anger-release`）。

注意两个限定：四项情感是作者的教学举例而非实证分类；其中"愤怒"更复杂，书中有专门一章展开（转 `anger-release`）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 用侄子侄女辨认基本情感
- **类型**: 叙事案例（第五章）
- **问题**: 苍鹭要蛤蟆用自己熟悉的孩子作实例，一件件辨认婴儿与生俱来的情感——蛤蟆讲起侄子侄女打架、闹脾气、依恋的表现
- **方法论的使用**: 从具体孩子的行为里逐项提取情感（"孩子有时候真是小恶魔"，但闹脾气的背后是愤怒；依恋与亲近是快乐和深情），最后在挂纸板上写出四项
- **结论**: "儿童的基本情感：快乐和深情、愤怒、悲伤、恐惧"——并命名为"自然型儿童"
- **结果**: 蛤蟆追问能否据此判断他人状态，苍鹭答"正是如此"，并提示"愤怒更复杂"（留给下一章的展开）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 「我只知道我很难受，但说不出是什么感觉」——情绪词汇贫乏
2. 觉察自己长期不敢有某一类情绪（不敢生气、不敢哭、不会表达深情）
3. 想帮孩子/伴侣辨认和说出情绪
4. 读到"情绪没有好坏"，想知道如何落到具体的感受上

### 语言信号

- 「说不清，就是难受」「心里堵得慌」
- 「我不该生气/我不该哭」
- 「他闹起来就说是闹脾气，其实……」
- 英文: "I can't name what I feel", "am I allowed to feel angry"

### 与相邻 skill 的区分

- 与 `connecting-with-emotions` 的区别: 本条解决"这叫什么"（命名）；后者解决"要不要和它联结、压抑的代价是什么"（态度与动作）
- 与 `adapted-child-patterns` 的区别: 本条是"出厂配置"；后者是"被调暗之后"的适应行为——同找一枚硬币的两半
- 与 `anger-release` 的区别: 愤怒在四项中单列展开，识别释放方式请转该卡

## E — 可执行步骤 (Execution)

1. **取一个情绪时刻**
   - 完成标准: 拿到一段具体情境（何时、何地、发生了什么、身体与心情如何）
   - 判停条件: 用户无法描述情境时，可从"最近一次哭/发火/害怕"切入

2. **四项对照**
   - 完成标准: 在"快乐和深情 / 愤怒 / 悲伤 / 恐惧"中定位最接近的基调，并给出行为证据（如"想哭、想缩起来"→悲伤/恐惧）
   - 输入契约: 一段自然语言描述；无需其他字段

3. **辨认"直接流露还是调暗后的变形"**
   - 完成标准: 区分"正在自然流露"与"被压住后以别的形式出现"（如长期不生气可能是愤怒被调暗）；后者转 `anger-release` / `adapted-child-patterns`
   - 输出契约: ①情感命名 ②证据 ③一句"我现在感觉……"的准确表述

4. **效果化提问收尾**
   - 完成标准: 以"这份感受反映了什么"替代"有用没用/该不该"；禁止给情绪贴好坏标签

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把四项清单当作"只有四种情绪"的字面真理——它是原色基底，不是情绪全表
- 用于评判他人情绪是否"合理"（"你这不叫悲伤，就是矫情"）
- 临床情绪评估或量表计分——本书无此工具

### 作者在书中警告的失败模式

- 把基本情感误读为"天生没脾气/天生乐观"：被压制的愤怒与悲伤不是消失了，而是调暗后变形（详见 `adapted-child-patterns`）
- 用命名替代理解："说出'我在生气'不等于处理了生气"——命名只是入口

### 作者的盲点 / 时代局限

- **四项情感是作者的教学举例，非实证心理学公认的情感分类**（BOOK_OVERVIEW §3）
- "基本情感与生俱来"的先验性未加论证；发展心理学对情绪分化有更细的争议，本书未涉及
- 对述情障碍（说不出情绪）者的适用性未讨论——而这类人恰恰最需要工具

### 容易混淆的邻近方法论

- `connecting-with-emotions`: "截肢"比喻与情感联结属于态度层，与本条的词汇层分开使用
- `emotion-thermometer`: 温度计给"程度"，本条给"名称"，两者组合使用
