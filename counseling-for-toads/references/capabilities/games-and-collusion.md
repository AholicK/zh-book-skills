# 心理游戏清单与共谋（PLOM 一族）

## R — 原文 (Reading)

> 意思是达成一种秘密协议。我用'共谋'是想说，你偷偷地或无意识地配合对方，来给自己制造不快，这就是在玩心理游戏，而且在游戏里输的人才算是赢家。
>
> — 第九章 秘密协议

> 为什么你总是遇到类似的事情？这些事情最后都让你显得很蠢，让对方占了上风，让你感觉又变回小时候那个可怜弱小的自己，到底是纯属倒霉，还是因为你用某种方式和对方共谋了这件倒霉事儿？
>
> — 第九章 秘密协议

> 这是人们经常在工作场合玩的游戏。首先，有个人犯了错，可以想象，这种情况很常见。然后上司发现了，把犯错的下属叫进来好一顿训斥，小题大做，对下属大声咆哮。所以你看，这种游戏能让愤怒的人找到看似正当的理由来发火，借此证实'我好；你不好'的人生坐标。
>
> — 第十四章 赢了游戏，输了自己

## I — 方法论骨架 (Interpretation)

这张卡是心理游戏的"名册 + 参与机制"。参与机制叫**共谋**：当事人"偷偷地或无意识地配合对方，来给自己制造不快"——没有共谋，游戏玩不起来；而"在游戏里输的人才算是赢家"（赢了道理、输了关系与心情）。因此对"我总遇到同类破事"的标准化问句是二选一的：**纯属倒霉，还是你用某种方式和对方共谋了这件倒霉事儿？**——这个问题不指控别人，只把外部归因转成可介入的自身模式。

具名游戏按坐标分组。落在"我不好；你好"（受害者坐标）上的有：**我真不幸**（随时报出一长串不幸、"选择记住那些悲伤和不快乐的事件，而忘记或忽略美好的时光"）、**PLOM**（可怜弱小的我呀）、**不论我做什么都要爱我**（有意无意惹上麻烦，测试别人的宽容底线，被排斥后自证"证明我是真的很差劲很愚蠢"）。落在"我好；你不好"（权力坐标）上的有：**NIGYYSOB**（我抓到你了，你个坏蛋——小题大做、大声咆哮，把愤怒装进"应得的惩罚"）、**你为什么总让我失望**、**你怎么敢**。另有"猜猜我在想什么"（见 `game-identification`）与"酗酒"（书中只有定义、无玩法拆解）。

使用纪律贯穿全卡：①这套工具"不是用来给人贴标签，攻击羞辱别人的"——尤其不是用来揭发别人；②被点破游戏时对方往往暴怒否认（那不是停玩，那是游戏的一步），此时先处理阻抗（转 `learning-resistance`）；③看见才是出口——"帮助你看到你在玩什么样的游戏，这样你才可以就此打住"。

## A1 — 书中的应用 (Past Application)

### 案例 1: PLOM 的点破与阻抗
- **类型**: 叙事案例（第九章）
- **问题**: 蛤蟆控诉獾逼他辞职时的委屈，苍鹭却说"我得祝贺你。你的游戏玩得很棒"，点出 PLOM（可怜弱小的我）
- **方法论的使用**: 蛤蟆恼怒否认——"我没有玩游戏。我诚实地告诉你这么件糟心事，你倒说我在跟你玩游戏"；苍鹭道歉、把话题放一放，并解释"越是能帮助你深入自我的概念，也越容易引发激烈的阻抗"
- **结论**: 否认本身就是游戏的一步（ce24）；停玩的前提是先看见自己在玩
- **结果**: 蛤蟆承认"我的胸口直发烫"；苍鹭说"这扇门也可能通向深刻的领悟"，两人继续

### 案例 2: 父亲的游戏
- **类型**: 叙事案例（第十四章）
- **问题**: 苍鹭拆解 NIGYYSOB——"把犯错的下属叫进来好一顿训斥，小题大做"
- **方法论的使用**: 蛤蟆逐条认出："我同情这游戏里被训斥惩罚的每一个人，让我想起我小时候还有长大后……还是我父亲，他总说这句话……他经常对我玩这一套，而且总能起效，最后都让我自卑或自责"
- **结论**: 附带"你为什么总让我失望"与"你怎么敢"，靠施压"加强他的道德优越感"
- **结果**: 蛤蟆认同"在这个坐标的人总需要攻击或者谴责别人"

### 案例 3: "不论我做什么都要爱我"
- **类型**: 叙事案例（第十四章）
- **问题**: 同一坐标上的另一游戏——"有些人生活一团糟，或者有意无意惹上麻烦，就是想看看别人能宽容他们到什么程度，什么时候会排斥他们"
- **方法论的使用**: 收束台词是"我早说过你会这样对我，证明我是真的很差劲很愚蠢"；苍鹭警告"它们会严重伤害你的健康"
- **结论**: 测试的设计使失败成为必然——容忍总有上限，被放弃却被当成自我概念的确认
- **结果**: 蛤蟆自陈"我确实觉得每个人都在找我的茬儿"，并判断"这些游戏很危险"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 「我每次谈恋爱都遇到控制欲强的人，朋友说我总在重复同样的剧本」
2. 「我总在同样的争执里收场」「同一个坑我掉好几次」
3. 想核对"我是不是在玩某个游戏"（自察而非揭发）
4. 职场中反复的"被针对/被训斥"体验，想弄清结构

### 语言信号

- 「为什么总是我」「我身边全是这种人」
- 「这集我看过」「怎么又是这个结局」
- 「我早就知道会这样」（自证台词）
- 英文: "why does this keep happening to me", "same script different person"

### 与相邻 skill 的区分

- 与 `game-identification` 的区别: 那条给通用拆解方法（两层结构）；本条给具名清单（PLOM、NIGYYSOB 等）与共谋机制——先拆结构、再查名字
- 与 `life-positions` 的区别: 坐标指出"哪个象限"，本条指出"这个象限里玩的是哪个游戏"——逐个对表
- 与 `self-criticism` 的区别: "与自己共谋"的自我谴责版本在那张卡；本条聚焦人际间共谋

## E — 可执行步骤 (Execution)

1. **确认重复模式**
   - 完成标准: 列出至少两次、结局雷同的事件（写清：发生了什么、谁占上风、最后什么情绪）
   - 判停条件: 只有单次事件时如实说明"无法判定"，先记录模式

2. **运行共谋自查（对自己，不指控）**
   - 完成标准: 用标准化问句——"到底是纯属倒霉，还是你用某种方式和对方共谋了这件倒霉事儿？"——得到至少一条具体回答（如"我反复选择同类人""我没有离开""我不表达真实感受"）
   - 输出契约: 共谋自查结果；语气必须是好奇而非定罪；**不得**用于向对方逼供

3. **对照具名清单**
   - 完成标准: 按坐标分组对照命名（我真不幸 / PLOM / 不论我做什么都要爱我 / NIGYYSOB / 你为什么总让我失望 / 你怎么敢 / 猜猜我在想什么），命中 1 个候选游戏并核对其玩法步骤（如"制造麻烦 → 测试宽容 → 被排斥 → 自证"）
   - 输出契约: ①模式清单 ②共谋自查 ③游戏候选 + 玩法核对

4. **止玩方向与边界**
   - 完成标准: 目标写成"看见——帮助你看到你在玩什么样的游戏，这样你才可以就此打住"；如实说明书中未给完整的停止步骤；若对方（或自己）刚被点破，先转 `learning-resistance` 处理阻抗
   - 判停条件: 出现抑郁加重或极端念头时转 `depression-warning-signs`

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用来揭发、指控他人（"你在玩 NIGYYSOB"）——工具守则明确"不是用来给人贴标签，攻击羞辱别人的"
- 对被点破者逼供——书中示范的处理是道歉 + 放一放
- 把"共谋"读成"你活该"——共谋是无意识的，不是道德责任

### 作者在书中警告的失败模式

- 被点破时的暴怒与否认（ce24）: 把结局归因于倒霉、否认参与，游戏因此继续
- 酗酒式长期重复（ce25）: 用行为制造负面情绪、再用负面情绪证明"生活本来就不善待我"
- 选择性记住不幸（ce26）: "确实会抑郁……觉得自己不够好"
- 测试宽容（ce27）: 每次被容忍都被解读为还需继续测试——越玩越孤绝
- 用权威制造惩罚机会（ce28）: 抓住别人的错误小题大做、公开训斥，反复确认"我好；你不好"

### 作者的盲点 / 时代局限

- **"如何停止游戏"的完整步骤书中未给**——只有"看见才能打住"的方向（不得补造步骤）
- **"酗酒"游戏只有定义、无玩法拆解**（L4388-4398）——不得替它编造细节
- 游戏清单出自《人间游戏》1964 年的语境；两个坐标的极端行为梯度（自杀 / 谋杀）在书中仅作叙述，未与游戏停止条件关联

### 容易混淆的邻近方法论

- `game-identification`: 两层结构的通用拆解方法；本条负责名字与机制
- `critical-parent`: NIGYYSOB 一族与挑剔型父母互为表里（一个是互动结构、一个是状态）
