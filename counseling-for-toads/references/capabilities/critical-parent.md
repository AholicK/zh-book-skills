# 父母自我状态与挑剔型父母（含「从不抑郁」机制）

## R — 原文 (Reading)

> 处于'父母自我状态'时，我们表现得正如自己的父母。……'父母状态'包含了自出生起，我们从父母那里学到的所有价值观和道德观，还包含了对生活的评判标准，让我们借此判断是非对错。
>
> — 第九章 秘密协议

> 他在挂纸板上写了标题'父母自我状态'，在下方画了一个圈，用竖线把它一分为二，在右半边写了'挑剔型父母'。……蛤蟆拿起蜡笔写下了'爱批评人''愤怒'，还有'严厉'这几个词。
>
> — 第九章 秘密协议

> 因为愤怒能够非常有效地抵抗抑郁。愤怒的人从不觉得内疚，因为他们总在怪罪别人。他们自卫的方式，是把自己内在的恐惧对外投射到别人身上，这样就能把对自己的怒火转向别人。
>
> — 第十四章 赢了游戏，输了自己

## I — 方法论骨架 (Interpretation)

父母自我状态是"内化的父母声音"：言行如父母，内容是从父母那里学来的价值观、道德观与评判标准。它不只在你当父母时出现——任何时候你开始"挑剔、教育、证明自己对"，它就在运行。这张卡处理它的**对外一极**：挑剔型父母（爱批评人、愤怒、严厉），常见形态是"动不动就指责，焦虑得随时会发脾气，还想用不可能达到的标准来评判别人"；偶尔摆出的"养育型父母"姿态（"我比你更心痛""我是为你好"）多为虚情假意。

它的反面是同一枚硬币的另一半：转向内部的法官（转 `self-criticism`）。理解"从不抑郁"机制有助于看清两者的关系——愤怒向外投射（怪罪别人、把对自己的怒火转向别人）的人从不抑郁，代价是人际关系全面受损；而抑郁者常是愤怒向内。识别挑剔型父母的用途不是"定对方的罪"（那会变成另一种法官行为），而是：①把"他让我难受"翻译成"他被父母状态接管了，我被拉进了旧剧本"；②引导自保与运作提问——用"它是怎么运作的"替代"他为什么这样对我"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 判断獾的状态
- **类型**: 叙事案例（第九章）
- **问题**: 蛤蟆描述獾的来访——"他总让我想起我父亲"
- **方法论的使用**: 苍鹭让蛤蟆自己判断獾当时的状态；结论是"父母自我状态"（言行如父母、携带价值观与评判标准），同时给出边界——"我们绝不是父母的翻版……是独立的个体"
- **结论**: 识别父母状态后可预测其行为（蛤蟆说这下能预测獾下次会怎么说、怎么做）
- **结果**: 苍鹭评语"很明显你的情商提高了"

### 案例 2: 三个特征词的由来
- **类型**: 叙事案例（第九章）
- **问题**: 蛤蟆举出日常实例：球场管理员"你过来前我干得好好的"、干洗店女士"你需要的不是干洗，是围兜"
- **方法论的使用**: 从这些尖刻但"正当"的点评里，蛤蟆自己提炼出"爱批评人、愤怒、严厉"三个词，写在挂纸板"挑剔型父母"一侧
- **结论**: 挑剔型父母的特征是被日常语言携带的——识别焦点是句式（指责、评判、不可能达到的标准），不是态度好坏
- **结果**: 挂纸板上形成"挑剔型父母 / 养育型父母"两分的结构图

### 案例 3: 獾逼辞校董
- **类型**: 叙事案例（第八章）
- **问题**: 獾不请自来，先挑剔蛤蟆的园艺与精神状态，再宣布已与校区牧师说好顶替他的校董职位，当场要他写辞职信
- **方法论的使用**（事后回看）: 这是"挑剔型父母 + 代做决定"的完整现场——蛤蟆的愤怒"很快化为悲惨的心情"，只能弱弱要求"一两天时间考虑"
- **结论**: 被挑剔型父母接管者的典型反应链：愤怒无法出口 → 自我怀疑 → "也许獾是对的"
- **结果**: 蛤蟆拖到"明天晚上打电话给你"，并意识到"他需要苍鹭的帮助"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 「我妈每次打电话都挑我毛病，挂掉后我要难受一整天」
2. 被上司/长辈反复否定，开始怀疑"是不是我真的不行"
3. 想判断某人"为什么一开口就让人觉得自己很差"
4. 被"我是为你好"一类话困住，分不清关心与打击

### 语言信号

- 「他总是挑我的毛病」「动不动就批评我」
- 「我说什么都被否定」「一开口就让我觉得自己很糟糕」
- 「她说这是为我好，可我听完特别难受」
- 英文: "my mother keeps criticising me", "nothing I do is good enough", "they say it's for my own good"

### 与相邻 skill 的区分

- 与 `self-criticism` 的区别: 同一枚硬币的两半——本条是对外（挑剔他人），后者是对内（审判自己）；被"法官"接管的人常两半共用
- 与 `ego-states` 的区别: 本条专查父母状态这一极的识别与自保；整体状态判定转 `ego-states`
- 与 `helping-others` 的区别: 帮助者的"训诫路线"（劝告、施压、代做决定）就是挑剔型父母状态的变形——那条卡给帮助者用的对照表

## E — 可执行步骤 (Execution)

1. **取一段"某人让我难受"的具体事件**
   - 完成标准: 拿到对方的言行原话（"你需要的不是干洗，是围兜"式的句子最好）
   - 判停条件: 只给情绪描述时先还原原话；涉及正在发生的精神虐待或控制时先转安全讨论

2. **特征核对**
   - 完成标准: 逐项核对——①动不动就指责 ②焦虑得随时会发脾气 ③用不可能达到的标准评判别人；再检查有无"养育型"包装（"我比你更心痛/我是为你好"）
   - 输出契约: 命中项清单 + 原话证据

3. **过边界声明**
   - 完成标准: 输出中必须包含两句——"影响极大≠翻版（我们绝不是父母的翻版）"；"识别用于理解与自保，不用于给对方定人格结论"
   - 判停条件: 用户想要"给我妈定性"时，停下并说明这会变成新的法官行为

4. **转向自保与运作提问**
   - 完成标准: 给出至少一个动作——问"此刻谁在说话、我是否已进入儿童状态"（转 `ego-states`）；把"他为什么这样"重构为"它是怎么运作的"（模式、触发条件、后续反应链）
   - 输出契约: ①事件 ②命中项 ③边界声明 ④自保/运作提问 ≥1 条

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 给人贴"你是挑剔型父母"的标签——这本身就是法官行为的复刻
- 子女用它"起诉"父母、伴侣用它互相指控
- 把"从不抑郁"当优点或缺点评判（它是机制描述，不是人格评价）
- 替代对精神控制/长期打压的专业处理

### 作者在书中警告的失败模式

- 法官式帮助（ce04）: 獾式的"为你好、替你做决定、再定罪给你看"——来访者的愤怒无法出口，转为自我怀疑与"我确实不行"，抑郁被加固
- 养育型伪装（ce23）: 用"我比你更心痛"包装的挑剔型攻击，听者几乎都能识破其虚情假意
- 预判定性（c03）: "他骨子里是软弱、不安分的"——先声明"没必要批评朋友"随即给出断语，父母状态的言谈形态在此完整演示

### 作者的盲点 / 时代局限

- "父母状态"与"成人状态"在日常交叠处没有判据；被批评时如何判断对方是"挑剔"还是"就事论事"，书中未给工具
- "从不抑郁"是机制解释而非临床标准，不得用于自诊或他诊
- 长期共处的应对（如何与挑剔型父母/上司相处）书中未给方案——只到识别与自保为止

### 容易混淆的邻近方法论

- `self-criticism`: 内部审判；"无期徒刑"口径在那张卡
- `helping-others`: 帮助者的训诫路线=挑剔型父母变形；想要"该怎么做"时转过去
