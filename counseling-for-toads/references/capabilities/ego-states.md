# 自我状态三位一体与状态识别（父母·成人·儿童）

## R — 原文 (Reading)

> 而当我们问'他处于什么状态'时，我们其实是在问'他存在的模式是什么'。
>
> — 第四章 抑郁的原因

> 所以当我说一个人处在'儿童自我状态'时，我是指他的行为和感受都像一个孩子。这不同于'幼稚'，而是'像孩子一样'。
>
> — 第四章 抑郁的原因

> 我们称它为'成人状态'。加上它，就形成了自我状态的三位一体，分别是父母、成人、儿童状态。这个三位一体也代表了人格的结构。
>
> — 第十一章 蛤蟆先生的选择

> 没有好坏，……只是用来描述一个人实际的状态。也许更好的一个问题是：'处于儿童状态会有什么样的效果？'
>
> — 第五章 成长的寓言

## I — 方法论骨架 (Interpretation)

同一个人的反应可能来自三个不同的"说话人"：内化的父母、当下的成人、童年的儿童。三者合起来构成人格结构（人际沟通分析的教学模型），没有哪个是坏的——但它们的运作方式不同：儿童状态复演童年的感受与行为；父母状态重复从父母那里学来的观念与标准；只有成人状态面对此时此地的事实。

识别不靠玄想，靠两个可观察量：**感受**与**行为**。问"当时你处在什么状态下（你的感受和行为像什么）"，比问"你是什么样的人"有效得多——前者是状态问题，后者是性格问题。判定标准是可检验的：感受与行为是否"和小时候的自己如出一辙"（与真实年龄无关）；成人状态则表现为能计划、考虑、决定、行动，不被父母过去的声音驱使、不被童年的情绪围困。

两条纪律贯穿全部下游用法：①状态没有好坏，只问"处于儿童状态会有什么样的效果"——把自评从道德题改写成效用题；②状态是可切换的模式，不是身份标签，不能用来给人定性。

## A1 — 书中的应用 (Past Application)

### 案例 1: 苍鹭命名「儿童自我状态」
- **类型**: 叙事案例（第四章，虚构咨询示范）
- **问题**: 蛤蟆因朋友们"为他好"的轮番施压而彻底沮丧，苍鹭不评判事件，一次次问"在这些事件发生的时候，你处在什么状态下？"
- **方法论的使用**: 用提问链把模糊的情绪逼成可回答的问题，直到蛤蟆自己说出"你可以说我当时的感受就和小时候一样。我感觉自己像个孩子"
- **结论**: 这种"感受与行为重演童年"的模式被命名为"儿童自我状态"——全书概念体系的入口动作
- **结果**: 蛤蟆追问"处在儿童状态是件坏事吗"，苍鹭答"没有好坏"，并改问"处于儿童状态会有什么样的效果"

### 案例 2: 蛤蟆自己发现「成人状态」
- **类型**: 叙事案例（第十一章）
- **问题**: 蛤蟆主动报告："近来我一直在想，应该还存在另一种自我状态，让你既不会表现得像父母，也不会感觉像孩子。在这个自我状态里，你更像个大人，更像当下的自己"
- **方法论的使用**: 苍鹭确认这就是"成人状态"，并补全"父母—成人—儿童"三位一体
- **结论**: 三位一体（代表人格结构）由来访者自己完成发现，而非被告知
- **结果**: 蛤蟆自己动手画三位一体图（"让我来好吗？我知道怎么画"）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 刚经历一次情绪失控或行为反常（发火、哭泣、僵住）,想搞清"我这是怎么了"
2. 反复被同一类情境惹毛，开始怀疑"是不是我自己的问题"
3. 想理解身边一个人的反应（家人/伴侣/同事），想知道对方"为什么这样说话"
4. 读到了"三种自我状态"的概念，想知道怎么用在具体事件上

### 语言信号

- 「我为什么会这样反应」「我都这么大了怎么还像个小孩」
- 「一遇到他/一到那个场合我就控制不住」
- 「冷静下来想想，我当时说的话根本不像我」
- 「她一张口就像我妈/像领导在训人」
- 英文: "why do I react like a child", "ego state", "I wasn't myself"

### 与相邻 skill 的区分

- 与 `adapted-child-patterns` 的区别: 本条解决"此刻在哪个状态"；后者深入"儿童状态内部被改造成了什么样"（适应型行为与顺从四件套）
- 与 `life-positions` 的区别: 本条解释"这一次怎么反应"；坐标解释"为什么总朝同一个方向反应"——两个模型锚点不同
- 与 `self-criticism` / `critical-parent` 的区别: 本条只做整体状态判定；那两张是父母状态两个方向（对外挑剔 / 对内审判）的细查

## E — 可执行步骤 (Execution)

1. **圈定一个具体事件**
   - 完成标准: 拿到"什么时间、什么场合、发生了什么、你说了什么做了什么"的可复述素材
   - 判停条件: 用户只给情绪标签（"我很烦"）时先追问场景；确实无具体事件则按"最近一次类似情况"处理并标注

2. **运行提问链（感受与行为）**
   - 完成标准: 得到①当时的感受词 ②当时的行为描述 ③"这像不像小时候的你"的回答
   - 输入契约: 一个具体场景 + 用户自我报告；无需其他字段

3. **对照三种状态特征表**
   - 完成标准: 给出候选状态判断，依据必须落在感受与行为证据上（"想哭+想道歉"→儿童状态信号；"反复讲道理+证明自己对"→父母状态信号；"能就事论事地计划下一步"→成人状态信号）
   - 输出契约: ①场景复述 ②候选状态 ③证据逐条对应 ④附带"处于这个状态会有什么样的效果"

4. **效果化改写与边界声明**
   - 完成标准: 输出中不含对人对己的道德评价（"幼稚""不像话"均不合格）；证据不足时给"需要更多信息"并列出要补问的点
   - 判停条件: 若用户要求"给他（别人）判个状态"，转为说明这是自我反思工具，不用于给人定性

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 给人贴标签或"诊断"他人（"你就是儿童状态的人"）——状态是模式，不是身份
- 用状态判断做道德评价（"你这样很幼稚"）——原文明确"没有好坏"
- 需要专业诊断的场合（心理疾病、人格障碍）——本模型是教学隐喻，不承担诊断功能

### 作者在书中警告的失败模式

- 把状态当宿命（ce10）: "一个人显然没办法控制自己进入哪种状态……这显然取决于你是什么样的人，而这是你没法控制的"——把"状态会自动切换"误读为"我只能被状态支配"，恰好免除了觉察的责任
- 新术语替代旧评判: 把"我性格不好"换成"我总在儿童状态"，若只换来一个新自我标签，就是换汤不换药

### 作者的盲点 / 时代局限

- 三分人格模型属人际沟通分析（TA）的临床与教学隐喻，非当代实证心理学公认的人格结构（BOOK_OVERVIEW §3）
- 书中没有临床诊断标准；识别只有"感受与行为"的自我报告一条路，报告能力因人而异
- "父母状态"与"成人状态"在正常生活里的交叠边界，书中未给判据

### 容易混淆的邻近方法论

- `basic-feelings` / `adapted-child-patterns`: 同属"儿童状态"内部的展开（自然型/适应型两半），不要与"状态判定"混用
- `life-positions`: 另一套模型（我好不好×你好不好），解释方向不同——坐标是"底层架构"，状态是"此刻模式"
