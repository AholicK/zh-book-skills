# 责怪→负责：从儿童状态到成人状态的分水岭动作

## R — 原文 (Reading)

> 选择就是：你还要为自己的不快乐责怪别人多久？……相比责怪，负起责任听着如何？……如果你为自己负责，就会认识到你对自己是有自主权的。因此你就知道自己有力量来改变处境，更重要的是，有力量改变你自己。
>
> — 第十一章 蛤蟆先生的选择

> 责怪是人处在'儿童自我状态'里做的事情，好像你最喜欢待在那个状态里。但一个处在'成人自我状态'的人，可能会有怎样恰当的做法呢？
>
> — 第十一章 蛤蟆先生的选择

> 也许'选择'这个词不太恰当，我们选择怎么感受，和选择再吃块巧克力是两码事儿。但我们做这些选择时都是无意识的，更像是一种条件反射。
>
> — 第十一章 蛤蟆先生的选择

## I — 方法论骨架 (Interpretation)

这本书最重的一次转向发生在第十一章：把"是谁让我这么不快乐"换成"我还要责怪多久"。责怪是儿童状态的动作——它能给人道德上的清白感（我是受害者），却不给行动力；负责是成人状态的动作——对象包括自己的行为**和情绪**，收益是自主权，以及"有力量改变处境、更有力量改变自己"。

与这条转换捆在一起的是"选择自己的感受"命题及其自我修正。作者先说"没有人能'让'我们产生什么感受……是我们'选择'了自己的感受"，随即自我修正：这里的"选择"是无意识的、像条件反射一样的反应模式。这两句必须连读——**"你学会的自动反应可以改变"**是它的本义；把它读成"痛苦是你自找的"是全书最大的误读。

因此执行时必须同时携带两扇闸门：①负责≠自责（作者明确否定了"又要我自责"的读法）；②选择≠自找（绝不向受害者说"这是你自己的选择"）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 十字路口——责怪还是负责
- **类型**: 叙事案例（第十一章）
- **问题**: 苍鹭直问"你这段时间的不快乐，该去怪谁？"蛤蟆把责任外推——先怪獾、河鼠、鼹鼠，再怪父母，哭着说"这不公平"
- **方法论的使用**: 苍鹭不做归因裁判，只把选择题摆上桌面："你还要为自己的不快乐责怪别人多久？"并点明"相比责怪，负起责任听着如何"
- **结论**: 责怪与负责被确立为儿童状态与成人状态的分水岭动作；负责的范围经追问确认为"还包括你自己的情绪"
- **结果**: 蛤蟆平静下来问"你是说，我该为自己的行为负责？"——转向开始于他不再追问"怪谁"

### 案例 2: "选择"论的出场与修正
- **类型**: 叙事案例（第十一章）
- **问题**: 苍鹭提出"是我们'选择'了自己的感受"，蛤蟆激烈反对："没有一个正常人会'选择'去感受悲伤或痛苦。这完全说不通。"
- **方法论的使用**: 苍鹭自我修正——"选择"一词不恰当，这些选择是无意识的，"更像是一种条件反射"（以巴甫洛夫的狗与膝跳反射作比）
- **结论**: "感受来源在己"的准确含义是"反应模式由自己携带"，而非理性决策
- **结果**: 蛤蟆立刻抓住修正反问"如果我们无法避免这么做，那就不是我们的错"——对话由此自然转向"怪谁"的追问（接了案例 1）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 「我的一切都是原生家庭造成的」——反复讲述伤痛故事但走不出来
2. 抱怨轮循环：把所有不快乐逐一归因给不同的人，却没有下一步
3. 出现"凭什么要我改变/负责"的僵局
4. 有人劝你"放下/原谅"，你更愤怒或更内疚

### 语言信号

- 「都怪我爸/我妈，要不是他们……」「我这辈子毁在他手里」
- 「凭什么要我负责」「我又不是错的那个」
- 「我知道我不该这么想，但我就是想不通」
- 英文: "it's all my parents' fault", "blame", "why should I be the one to change"

### 与相邻 skill 的区分

- 与 `parental-forgiveness` 的区别: 本条处理通用的"责怪→负责"转换；后者专处理"父母已过世"这一特殊情境及其原谅边界
- 与 `self-criticism` 的区别: 本条防"负责滑向自责"；后者处理已经发生的自我审判（法官与囚徒）
- 与 `adapted-child-patterns` 的区别: 本条处理"把责任放哪"；后者的顺从四件套解释"为什么我总在讨好/依赖"

## E — 可执行步骤 (Execution)

1. **列出责怪清单**
   - 完成标准: 把"怪谁、怪什么"逐条写下来，确认为追责历史（过去时）而非行动清单
   - 判停条件: 若叙事中出现虐待/暴力等严重伤害，先声明边界（见 B 段），不进入"负责"练习

2. **摆出十字路口之问**
   - 完成标准: 引入"你还要为自己的不快乐责怪别人多久？"——让用户自己看到"怪谁"不能带来出路；不否定伤害的真实性
   - 输出契约: 一句转折问句 + 对伤害的如实承认

3. **过防误读闸门**
   - 完成标准: 明确两句话——"负责不是自责、不是把错全揽到自己身上"；"感受的'选择'是无意识的反应模式，不是'你活该'"
   - 判停条件: 用户听到"负责"即反弹时，先停在闸门这一步，不推进

4. **生成负责清单**
   - 完成标准: 围绕三个范围产出可执行条目——(a) 我的情绪反应里哪些是学会的自动模式；(b) 眼下我能做的下一件事；(c) 对过去的伤害：保留什么、行动什么；至少 1 条可执行动作
   - 输出契约: ①责怪清单 ②负责清单 ③两扇闸门声明；不得出现"痛苦是你自找的"类表述

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用于让受害者闭嘴（"别怪别人了，管好你自己"）——这正是本书被误用的最大风险
- 在虐待、霸凌、权力压迫情境中要求对方"为自己的情绪负责"——可能构成二次伤害（BOOK_OVERVIEW §3）
- 替代专业心理帮助（严重创伤的处理不在本书范围）

### 作者在书中警告的失败模式

- 责怪链与"负责=自责"误读（ce16）: 蛤蟆列完"怪谁"名单后被问"还要怪多久"，立刻反弹"你想让我责怪自己。我不要"——两个选项都被拒绝，出路被堵死
- "选择感受"被读成"痛苦是自找的"（ce17）: 一旦按字面传播，会滑向受害者有罪论，也会被当事人用来进一步自责
- 决策外包（ce11）: 冲动拍板或问别人"我该怎么办"，把选择权与后果一起外推——责怪的另一面是依赖

### 作者的盲点 / 时代局限

- **"负责≠自责"的判据书中未给**（NR-04）: 作者只用"这完全不是我要说的选项"一句否定，下游必须把这条边界原样携带
- 责任框架默认"当事人有行动资源"（蛤蟆有庄园、有闲、有支持系统）；对资源匮乏者本书无讨论
- "选择感受"命题的自我修正展开很少，脱离上下文引用会与常识相抵触（BOOK_OVERVIEW §3）

### 容易混淆的邻近方法论

- `self-criticism`: 同章相邻——法官隐喻处理"内部审判"，本条处理"外部归责"；两者常见于同一个人身上，先后使用
- `parental-forgiveness`: 仅适用于父母已过世的情境；且"原谅"不是义务（转该卡边界声明）
