# 自我批判：法官与囚徒（含「无期徒刑」口径）

## R — 原文 (Reading)

> 没有一种批判比自我批判更强烈，也没有一个法官比我们自己更严苛。
>
> — 第九章 秘密协议

> 会严厉地惩罚，包括折磨自己，在极端案例里，甚至会施以极刑。但问题是，即便对自己轻判，这种谴责和惩罚也可能伴随一生，变成无期徒刑。
>
> — 第九章 秘密协议

> 能帮你的人是你自己，也只有你自己。有许多问题需要你向自己发问。比如你能停止自我批判吗？你能对自己好一些吗？也许最重要的问题是，你能开始爱自己吗？
>
> — 第九章 秘密协议

## I — 方法论骨架 (Interpretation)

当挑剔型父母转向内部，就形成"法官审判囚徒"的结构：同一个人既在控诉、定罪，又在服刑。自查的方式是一个简单却难答的问题——"你在审判谁？"多数人先答"我不审判谁"，被耐心追问后才会说出"我在审判我自己"。这时要如实告知量刑口径：这种谴责与惩罚即便"轻判"，也可能伴随一生——书中用"无期徒刑"一词，这是全书对自我批判最重的判词。

机制上有两点必须携带：①内化的父母声音不需要外部触发即可运行，惩罚带来的"道德清算感"能短暂缓解焦虑，于是审判被不断重复；②更深一层，自我批判是童年与父母关系的重演——"正如小时候父母对他做的一样，这甚至是在满足他的需求"。理解这两点，"减少自我攻击"就不再是简单的意志问题。

收束动作是三个自问：能停止自我批判吗？能对自己好一些吗？能开始爱自己吗？必须同时诚实说明边界：**书中没有给出"如何停止自我批判"的操作步骤**——可用的起步只有觉察与"允许自己做主"；若伴随持续抑郁或自伤念头，转 `depression-warning-signs` 走专业帮助路径。

## A1 — 书中的应用 (Past Application)

### 案例 1: 法官与囚徒
- **类型**: 叙事案例（第九章）
- **问题**: 蛤蟆坚称自己"不审判谁"，但在生活的诸多方面都在定自己的罪
- **方法论的使用**: 苍鹭反复追问"所以你在审判谁"，良久沉默后蛤蟆低声说"我想我明白你的意思。你是说，我在审判我自己？"
- **结论**: 自我批判被确认为抑郁维持机制的核心——最严厉的审判来自内部
- **结果**: 蛤蟆呆坐，自述"我的脑子嗡嗡直叫"；苍鹭送别时加了一句"蛤蟆，要照顾好自己"

### 案例 2: 与自己共谋
- **类型**: 叙事案例（第十章）
- **问题**: 消化"共谋"概念时，蛤蟆想到——"一个人能同自己共谋来谴责自己吗？而且不自知，连潜意识也没能察觉到？"
- **方法论的使用**: 他明白自己真的会批判和惩罚自己，正如小时候父母对他做的一样，"这甚至是在满足他的需求"
- **结论**: 自我谴责不只是"太严苛"，而是无意识地在满足某种需求（维持熟悉的秩序、换取父母式认可）
- **结果**: 蛤蟆很难应对这些想法——"和苍鹭面谈到现在，这是蛤蟆第一次产生困惑"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 「我一旦犯错就会在心里骂自己很久，甚至想惩罚自己」
2. 长期低自我评价——"我就是觉得自己不配/没用"
3. 完美主义、内耗，做完任何事都先找自己的错
4. 想停止自我攻击但"停不下来"，不知道这算不算严重

### 语言信号

- 「我怎么这么没用」「我不配」「我恨我自己」
- 「心里总有个声音在骂我」「我对自己特别狠」
- 「别人都劝我别想太多」
- 英文: "I'm so hard on myself", "inner critic", "I can't forgive myself"

### 与相邻 skill 的区分

- 与 `critical-parent` 的区别: 同一枚硬币两半——那条对外（挑剔他人），本条对内（审判自己）；两卡常连用
- 与 `blame-to-responsibility` 的区别: 那条处理"责怪→负责"且防止负责滑向自责；本条处理已经发生的自我审判本身
- 与 `depression-warning-signs` 的区别: 本条做识别与安放；涉及自伤念头、持续抑郁信号时转那条走安全路径

## E — 可执行步骤 (Execution)

1. **收集内心评语**
   - 完成标准: 把自我攻击的原话写下来（如"你连这个都做不好，你真丢人"），而不是概括为"我有点自卑"
   - 判停条件: 若出现自伤/自杀念头，跳过以下步骤，直接转 `depression-warning-signs` 的安全路径

2. **识别审判结构**
   - 完成标准: 用"你在审判谁？"自查，命名出"我在审判我自己"；标出法官在指控什么、判决是什么
   - 输出契约: ①原话 ②"法官—囚徒"结构标注（谁指控、指控什么、判决是什么）

3. **严重度核对与如实告知**
   - 完成标准: 说明量刑口径——即便轻判也可能伴随一生（"无期徒刑"）；确认是否需要转专业帮助
   - 判停条件: 出现"折磨自己/极刑式"念头时停止分析，转安全路径

4. **安放与起步**
   - 完成标准: 给出自问三连（能停止自我批判吗？能对自己好一些吗？能开始爱自己吗？），并**如实说明**书中未给"如何停止"的步骤——起步动作只有觉察与允许自己做主
   - 输出契约: ①原话 ②结构 ③严重度提示 ④三连 + 边界声明；不得输出"别想太多就好了"式安慰

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把"你太自我批判了"当成新的批评（这又是法官在开庭）
- 要求对方"立刻爱自己"——原文只是提问式邀请，不是可被要求的任务
- 替代专业治疗：严重抑郁、自伤风险的处理不在本书范围

### 作者在书中警告的失败模式

- 无期徒刑（ce21）: 自己既是法官又是囚犯，自定其罪、自我惩罚；自我评价长期低于事实
- 与自己共谋（ce22）: 自我谴责在无意识地满足某种需求——惩罚带来的短暂"清算感"让人不断重复审判，而不自知

### 作者的盲点 / 时代局限

- **"如何停止自我批判"书中未给方法**（V2 已登记此缺口）——卡片只能到"觉察 + 允许自己做主"为止，不得补造步骤
- "满足需求"的机制未展开如何松动，也未讨论它与抑郁生理机制的关系
- 对"过度自责"与"真诚反省"的区分标准未给——反省与自我攻击的边界需要下游谨慎处理

### 容易混淆的邻近方法论

- `blame-to-responsibility`: 防止"负责"被读成"自责"的那扇闸门在那张卡
- `games-and-collusion`: "与自己共谋"是共谋概念落回自身的用法，机制背景在那张卡
