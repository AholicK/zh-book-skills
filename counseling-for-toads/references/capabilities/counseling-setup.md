# 咨询过程与设置（自愿·合作·责任）

## R — 原文 (Reading)

> 心理咨询向来是一个自发的过程，咨询师和来访者双方都得出于自愿。所以这就意味着，只有当你是为自己而不是为取悦朋友们才想咨询的时候，我们才能真正合作。……为咨询负责的只能是你，而不是其他任何人。
>
> — 第三章 初见咨询师

> 如果我不相信每个人都有能力变得更好，我就不会做这份工作了。我无法保证事情一定会变好，但我可以承诺的是，我会对你倾注我全身心的关注，我也希望你对咨询是全心投入的。……但归根结底，这一切都取决于你。
>
> — 第三章 初见咨询师

> 每周我们面谈一小时，整个咨询周期多长视情况而定。……最后一次面谈将回顾我们在之前的咨询中做了哪些事，你学到了什么，你也可以考虑制订将来的计划。
>
> — 第三章 初见咨询师

## I — 方法论骨架 (Interpretation)

本书用第一场面谈完整示范了一段咨询的"开机设置"，可以拆成四件事：①**自愿**——"只有当你是为自己而不是为取悦朋友们才想咨询的时候，我们才能真正合作"；咨询师甚至会用"谁是我的来访者？是你，还是他们？"来做归属判定（为朋友而来时，真来访者是朋友，咨询不成立）；②**合作与责任**——拟合同、寄收据、"为咨询负责的只能是你"；"合作"的含义是来访者全程是主动参与者；③**设置**——每周一小时、固定时段、周期"视情况而定"不预设、最后一次面谈专门用于回顾所学与制定计划；议题"一直都是由你来设定的"，来访者能自己提出问题本身就是进步；④**承诺边界**——咨询师能承诺的是"全身心的关注"，不能承诺"事情一定会变好"，"归根结底，这一切都取决于你"。

两个操作细节值得带走：角色可以显式切换（讲概念时"切换到老师的角色"用讲解模式，处理体验时回到倾听模式）；用词可以适配触发点（发现"作业"会触发恐惧，就换成"做一些事情"）。

使用边界必须交代：本书的设置来自 1998 年英国单一（虚构）案例，**费用与周期数字对现实无参考性**；咨询师资质核验、流派选择、无效退出与转介——书中完全没有（NR-05），下游不得代补。

## A1 — 书中的应用 (Past Application)

### 案例 1: 初见的沉默——"你不打算告诉我该做什么吗"
- **类型**: 叙事案例（第三章）
- **问题**: 蛤蟆"早已习惯人们同他说话，正等着苍鹭开启一场冗长的训诫，可什么动静也没有"
- **方法论的使用**: 沉默持续到蛤蟆崩溃发问——"你不打算告诉我该做什么吗"；随后谈及朋友时他哭出来，苍鹭递上面巾纸
- **结论**: 咨询不是训诫——"不训诫、先倾听"的姿态在第一场就立了起来
- **结果**: 面谈继续，蛤蟆第一次体验"没有人替他做决定"的房间

### 案例 2: "谁是我的来访者"
- **类型**: 叙事案例（第三章）
- **问题**: 蛤蟆坦白"他们让我来的""不管怎么做，只要你觉得是最好的，我都会照办"
- **方法论的使用**: 苍鹭指出"你的那些朋友们才是我真正的来访者"，并说明咨询必须出于自愿、费用自负、责任自负；甚至建议"就当是一次体验"后结束
- **结论**: 动机归属是咨询能否开始的开关
- **结果**: 蛤蟆承认"刚才我的表现就像个混蛋一样"，表示愿意合作——咨询真正开始

### 案例 3: 苍鹭的承诺与界限
- **类型**: 叙事案例（第三章）
- **问题**: 蛤蟆追问"你认为我会好起来吗"
- **方法论的使用**: 苍鹭给出完整样本——"如果我不相信每个人都有能力变得更好，我就不会做这份工作了。我无法保证事情一定会变好，但我可以承诺的是，我会对你倾注我全身心的关注……"
- **结论**: 可承诺的是过程（关注与投入），不可承诺的是结果；"这一切都取决于你"
- **结果**: 蛤蟆走出咨询室，"竭力揣摩着这些话的意义"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 「我在考虑去看心理咨询，应该了解什么？」
2. 「是朋友/家人让我去的，我该不该去」
3. 「咨询了几个月感觉没进展，是继续还是停」
4. 想弄清咨询与"找人聊天/被教育"的区别

### 语言信号

- 「看心理咨询要准备什么」「进去要说什么」
- 「我怎么知道有没有用」「我会好起来吗」
- 「他们说我不去不行」
- 英文: "should I see a therapist", "how does therapy work", "how do I know it's working"

### 与相邻 skill 的区分

- 与 `growth-path-and-eq` 的区别: 那条讲咨询关系里的情感动力（依赖/移情/独立）；本条讲制度面（自愿、设置、责任、结束）
- 与 `depression-warning-signs` 的区别: 出现抑郁信号/自杀念头时的求助更紧急，转那条走安全路径；本条是常规了解与准备
- 与 `helping-others` 的区别: 那条给"怎么帮别人"；本条给"自己怎么开始一段被帮助的关系"

## E — 可执行步骤 (Execution)

1. **归属判定**
   - 完成标准: 问清"你为谁而来"——自己/取悦他人/被要求；动机在外时说明"真正的来访者其实是旁人"，先处理动机
   - 判停条件: 涉及被胁迫或控制关系时先处理安全，不推进设置讨论

2. **设置清单核对**
   - 完成标准: 逐项过——自愿与合作的含义、频率与时长、费用与收据、周期不预设、议题归属（由来访者设定）、结束方式（末次回顾 + 将来计划）；产出"该问咨询师的问题清单"（资质、取向、如何评估进展、如何结束）
   - 输出契约: ①归属结论 ②设置清单 ③提问清单

3. **承诺边界说明**
   - 完成标准: 说明可承诺与不可承诺——"全身心的关注" vs "无法保证事情一定会变好"；点明"归根结底，这一切都取决于你"
   - 输出契约: ④承诺边界陈述

4. **现实适配标注**
   - 完成标准: 明确标注——本书设置来自 1998 年英国单一（虚构）案例，费用/周期数字不具现实参考性；资质核验、流派选择、无效退出书中未讨论（NR-05），需另行询问专业渠道
   - 输出契约: ⑤现实适配与缺口声明

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 替代真实的咨询师筛选建议（资质、流派、转介、投诉渠道——书中全无）
- 用"你应该自愿"去责备求助者（动机本来是逐步建立的；书中做法是说明与邀请，不是审判）
- 把书中数字（40 英镑/次等）代入现实做费用推算（NR-03/NR-05）

### 作者在书中警告的失败模式

- 为取悦朋友而来（ce12）: "我来这儿，是他们让我来的"——动机外部化后，任何进展都只需向外部交代，咨询变成又一场取悦表演；真正的来访者不在椅子上

### 作者的盲点 / 时代局限

- **咨询师侧完全缺失**：资质核验、流派选择、无效退出、转介——书中零讨论（NR-05）
- **疗程次数口径两可**（NR-03）："不算糟糕的初次见面，我们一共面谈了十次"含/不含初见均可自洽；不得用次数做费用推算
- 案例为 1998 年英国单一虚构个案；对当代不同文化、保险与平台化咨询场景无覆盖

### 容易混淆的邻近方法论

- `growth-path-and-eq`: 咨询关系的"情感动力学"（依赖→对抗依赖→独立）；与本条的制度面互补
- `helping-others`: 帮助者视角；本条是被帮助者视角
