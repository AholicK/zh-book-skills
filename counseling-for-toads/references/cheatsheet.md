# 决策规则速查 — 《蛤蟆先生去看心理医生》

| 能力 | 一句话规则 |
|---|---|
| 自我状态三位一体与状态识别（父母·成人·儿童） | 先问「当时你的感受与行为」，再对表三种状态——判断此刻是谁在说话。 |
| 三种状态与学习条件（为什么劝不动、学不进） | 劝不动不是方法问题——非成人状态里学不进新东西，先换通道再谈改变。 |
| 责怪→负责：从儿童状态到成人状态的分水岭动作 | 把「还要怪多久」摆上桌——负责（含情绪）才有改变的力量，负责不是自责。 |
| 自然型儿童与四种基本情感 | 用四项基本情感（快乐和深情/愤怒/悲伤/恐惧）给情绪命名。 |
| 童年模式：适应型儿童·顺从行为·触发点 | 讨好/道歉/不敢拒绝是生存策略而非性格缺陷——用四件套清单找出仍在重演的部分。 |
| 愤怒：机制·释放方式·「不带攻击性地发火」 | 愤怒不会消失只会变形——找出你的释放方式（冷战/憋着/爆发），换「不带攻击性地发火」。 |
| 父母自我状态与挑剔型父母（含「从不抑郁」机制） | 把「他让我觉得自己很差」翻译成「挑剔型父母状态在运行」——识别特征，守住边界。 |
| 自我批判：法官与囚徒（含「无期徒刑」口径） | 「没有一种批判比自我批判更强烈」——识别内心的法官，用自问三连起步。 |
| 阻抗·困惑与学习阶段（深入自我的代价） | 抵触与困惑是学习进程的信号——重标定、可搁置，验收看能否实践。 |
| 人生坐标四象限与自证预言 | 用「我好吗？他们好吗？」定位人生坐标——自证预言在维持它，而它不宿命。 |
| 心理游戏：两层结构与识别方法 | 反复的负面互动用「表面在谈什么/底下真正要什么」两层结构来拆。 |
| 心理游戏清单与共谋（PLOM 一族） | 共谋是游戏的参与机制——「纯属倒霉，还是你也在配合？」，再看名册。 |
| 情绪温度计：测量与跟踪 | 用 1-10 刻度纵向跟踪情绪——低分（≤2）立刻直问自杀念头。 |
| 情绪联结与情感层面的学习 | 否认情绪等于截肢——先允许、再命名、再理解，改变发生在情感层面。 |
| 情商·共情与成长路径（依赖→对抗依赖→独立→共生） | 成长四档（依赖→对抗依赖→独立→共生）+ 情商自查。 |
| 帮助他人：倾听路线与训诫路线的对照 | 帮助不是训诫——别做（劝/评/代做）与可以做（听/问/共情/不给答案）。 |
| 咨询过程与设置（自愿·合作·责任） | 咨询四件事：自愿、合作与责任、设置、承诺边界。 |
| 人生故事·脚本溯源与改写 | 「你说我听」——把人生讲成故事，从事件链里找出脚本并练习即兴。 |
| 与已故父母的和解（「原谅他们」） | 对已故父母的愤怒-内疚循环——书里只有「原谅」一词，且它不是义务。 |
| 抑郁警示信号与安全边界 | 信号识别→直问自杀念头→转介专业帮助；本书不构成医疗建议。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
