# 函数定义与调用（def / 默认值参数 / return / lambda）

## I — 方法论骨架 (Interpretation)

复用一段代码的办法是把它变成「有名字的代码块」，再在需要处按名字叫它一次：定义写 `def functionname(parameterlist):` 接函数体，调用写 `functionname(parametersvalue)`。

书中把定义拆成四要素：函数名（供调用时引用）、参数列表（形参，多个用逗号分隔，不指定即无参）、函数注释（书中只给角色说明、未要求必写）、函数体。

参数可带默认值：`def functionname(...,[parameter1=defaultvalue1]):`，不传该参数就用默认值——价值是**减少调用处的重复实参**。`return [value]` 给出返回值：`value` 可省（返回空），可返回一个值，也可返回多个值。

短小功能用匿名函数 `result = lambda [arg1[,arg2,...,argn]]:expression`：参数列表可选，`expression` 是**必选参数**，参数就在这个表达式里被使用。

判据：一段逻辑被写下第二遍就该有名字；定义与调用要对得上「参数 ↔ 实参」「返回值 ↔ 接收方」。位置参数/关键字参数、可变参数、作用域、递归不在本书范围（见 B 段）。

## A1 — 应用示例 (Application Example)

### 示例 1: 求矩形面积 area(w, h=1)（合成演练）
- **类型**: 合成演练（按原书规则构造，非作者案例）
- **问题**: 写一个求矩形面积的函数 `area(w, h=1)`，并检查 `area(3)` 与 `area(3, 4)`

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这张卡?
1. 同一段计算或处理在代码里写了两三遍，想收成一个函数
2. 想让某个参数「不传也能跑」，或不确定要不要写 `return`
3. 需要一个临时小函数（如排序时按某个字段取键），不想为它单独写 `def`

### 语言信号
- 「这段代码重复了，怎么封装成函数？」「默认参数怎么写？」
- 「函数怎么返回多个值？」「lambda 是什么？」
- 英文: "how to define a function", "default argument", "lambda in python"

### 与相邻能力的区分（阶段 3 定稿）
- 与 `sort-vs-sorted` 的区别: 本卡负责「函数怎么写」；lambda 交给 `key`、决定顺序属 `sort-vs-sorted`。
- 与 `exception-handling` 的区别: 本卡只做定义与调用；函数内部要 `raise` 或 `assert` 时用 `exception-handling`。
- 与 `class-and-objects` 的区别: 实例方法就是定义在类里的函数，`self` 只是它的第一个参数；代码里出现 `class` / `self` / `@property` 时转过去。
- 与 `process-and-thread` 的区别: 那边启动并发任务要传一个函数作 target；本卡负责让函数存在且可调用。

## E — 可执行步骤 (Execution)

1. **确认复用什么**
   - 完成标准: 指出至少两处会重复使用的代码，并写出一句功能描述
   - 判停条件: 只出现一次且不会再用的逻辑不必封装，本卡不适用

2. **定函数名与参数**
   - 完成标准: 写出 `def 函数名(参数列表):`——函数名表意、形参多个用逗号分隔（无参则不写）；常用取值写成 `参数名=默认值`
   - 输入契约: 要接收几个参数、各参数含义、哪些有默认值；缺项先问用户，不替用户增删参数

3. **写函数体与返回**
   - 完成标准: 函数体完成第 1 步的功能；要把结果交回调用方时以 `return` 结束（多值在 `return` 后并列）；没有返回值时写明「不返回结果」

4. **写调用**
   - 完成标准: 写 `函数名(实参)`——实参个数与形参对应（有默认值的可省略），逐个核对「调用处传了什么、函数里当什么用」

5. **短函数改走 lambda（按需）**
   - 完成标准: 功能能用单个表达式说清且只此一处时改写为 `变量 = lambda 参数: 表达式`
   - 判停条件: 需要多行逻辑、提前返回或函数名要出现在错误信息里时不转 lambda

- **输入契约**: 要复用的逻辑 + 参数清单（含义与默认值）+ 调用处实例。若要求关键字参数、可变参数、作用域或递归，先说明「本书未覆盖」，只用书中可核验的部分作答。
- **输出契约**: 交付 ① 函数定义（`def` 或 `lambda`）② 每个参数的含义与默认值 ③ 调用示例 ④ 返回值说明。完成标准 = 定义、调用、返回三段核对无误（实参对形参、返回对接收方）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这张卡
- 需要区分位置参数与关键字参数、可变参数、作用域、递归时——**本书未覆盖**
- 需要捕获或抛出异常时（用 `exception-handling`）；要定义类与方法时（用 `class-and-objects`）

### 作者在书中警告的失败模式
- 形参与实参的个数关系是作者给出的唯一约束（见 R 段引文）；多传少传会怎样书中未讲
- `return` 的口径只有「可以返回一个值，也可返回多个值」，加上 `value` 可省

### 作者盲点与底本缺口
- unit_note：**位置参数 / 关键字参数、可变参数、作用域、递归本书均未覆盖**，不得当作本书规则使用。
- 未显式 `return` 时「返回空」之外的行为、参数不匹配时的处理书中都未给（NR-07 ~ NR-14 同类的调用层缺口）。
- OCR 现象（NR-15）：p25 引文中 `parameterl=defaultvaluel` 是方括号与下划线被误识（实为 `parameter1=defaultvalue1`），f15 中 `result - lambda` 的 `-` 是赋值号被误识；照抄原文未更正。
- **示例缺口**：本单元 3 条候选全是规则说明，书中本节**没有原书示例代码**，故 A1 两例均为合成演练。

### 容易混淆的邻近方法论
- `class-and-objects`: 实例方法与普通函数写法相同（`def 名(self, 参数):`），差别在第一条参数与调用方式受类的规则约束。
