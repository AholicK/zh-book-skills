# 修己以安人：帮忙的次序与分寸（先修己 → 安人 → 安大众）

## R — 原文 (Reading)

> 所以，要先修己以安人。修你自己，像修一棵树——剪掉树上的残枝败叶，加水，加肥料，不断成长进步，这是修己：修正自己做错的事情，把做对的经验留下来。……只有把“修己”这一步完成了，接下来才有能力去“安人”。
>
> — 第 08 篇 L343

> 从楼上走来一个不方便的人，在他下楼梯的时候伸一把手，援助他一下，跟他讲“小心前面脚步”——真的，这就是第一步，为人家着想。……我们能够安周围的人，安伸手能碰到的人，安对面说话的人，这就是安人了。……不能做烂好人，不能帮倒忙，帮忙要帮得恰到好处，安慰人要安慰得恰到好处。
>
> — 第 08 篇 L343-347

## I — 方法论骨架 (Interpretation)

这套方法回答的是「想帮人，但从哪帮起、帮到什么程度」：它给帮忙排了一个不可颠倒的次序，并配一把分寸尺。

次序：**先修己，再安人**。修己不是自我优化的终点，而是安人的前置件——修己的动作很具体：剪残枝（修正自己做错的事情）、加水加肥（把做对的经验留下来），像修一棵树那样持续。只有修己这一步完成了，才有能力去安人；自己安不下来，就无从安人。安人的范围按能力递进：伸手能碰到的人、对面说话的人 → 同社会圈、同文化圈的人 → 安大众（安民、安百姓）。作者自己的表述是「先修己，再安人。先安你附近的人，再安远一点的众人，再安百姓」（第 26 篇 L699）。作者还把「安人」（安顿个别的人）与「安民」（安百姓）分开，并把安民、安百姓划给有大能力的人去做——普通人的合格线就是安伸手能碰到的人。

分寸：**审量能力，能做多少是多少；不做烂好人，不帮倒忙**。帮忙与安慰都要恰到好处。作者只给了原则和例子（老先生明明坐得好好的，硬要给他挪位就是添麻烦），没有给度的量化判据——本卡因此以「先问对方需求再动作＋用对方反馈复核」作为替代判据，不虚构数值。

容易读丢的两点：其一，修己被读成孤立的自我提升就会偏离原书（它是安人的前置件）；其二，安人不是让别人情绪变好、也不是施舍与拯救世界，而是分层的伦理责任，第一步只是给下楼梯不便的人搭一把手。

## A1 — 书中的应用 (Past Application)

### 案例 1: 楼梯口伸一把手——安人的第一步
- **类型**: 作者举的日常示例（第 08 篇 L343）
- **问题**: 普通人没有能力做大事，安人到底从哪一步开始
- **方法论的使用**: 作者把安人缩到最小动作——「从楼上走来一个不方便的人，在他下楼梯的时候伸一把手，援助他一下，跟他讲“小心前面脚步”」，并在当场给出判定：「真的，这就是第一步，为人家着想」
- **结果**: 作者结论：日常生活里能做到这一点，就能让周围人的心安，「这就叫“安人”了」

### 案例 2: 老先生挪位的反例——帮忙可能变成添麻烦
- **类型**: 作者举的反例（第 08 篇 L347）
- **问题**: 帮忙的分寸在哪里，什么时候算帮倒忙
- **方法论的使用**: 作者以一位老先生为例——「明明坐在那儿挺好的，你说我给你挪个位置，这是给他添麻烦」，以及「你说我扶你起来，他说我不要起来」；说明帮忙要恰到好处，过度帮忙就是添麻烦
- **结果**: 作者没有给统一判据，结论是「这种事靠你自己审量行事」

### 案例 3: 大花园里照顾三五棵小树——大期许的降维
- **类型**: 作者打的比方（第 08 篇 L335）
- **问题**: 面对「为天地立心」式的大期许，一个人做不到全部怎么办
- **方法论的使用**: 作者说这四句话是对读书人的期许——「不需要一下子全部做到，我们也可以分担一个大任务里面的一个角色，就等于给你一个大花园，真正让你做的是照顾三五棵小树」
- **结果**: 大期许被降维为可执行的小范围：照顾自己园子里的几棵树，就是分担了整个任务

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想改善一个群体的氛围或环境，逢人便提意见，处处碰壁，开始心灰意冷
2. 热心帮人却越帮越忙、对方不领情，不确定自己的分寸
3. 被「先修身再做事」的说法卡住：不知道修到什么程度才算完成、什么时候可以出手
4. 面对宏大目标（改变行业、帮助很多人）感到无从下手
5. 常替所有人操心，累到撑不住，想划定自己该管与不该管的范围

### 语言信号

- 「我想改变团队／家里的氛围，但根本没人听」
- 「我帮了他那么多，他反而不领情」
- 「我自己都一团糟，哪有资格帮别人？」
- 「这些大道理，我一个人能做什么？」
- 英文: "I want to fix things but no one listens", "how much should I help", "where do I even start"

### 与相邻 skill 的区分

- 与 `empathy-check` 的区别: 那条是单个决定或回应前的两问复核（尽心＋将心比心）；本卡管帮多少、从谁帮起的次序与范围，不逐条复核具体说法
- 与 `doing-your-best` 的区别: 那条把「尽力而为之」用作自我期许的定标；本卡把同一句尽力展开成对外的行动次序——能做多少是多少，先从伸手能碰到的人做起
- 与 `letting-go-of-unreachable` 的区别: 那条处理够不到的东西如何放下；本卡处理能够到的人该怎么安——先缩范围再动手，不主张放弃

## E — 可执行步骤 (Execution)

1. **先修己：列出本轮的修正点**
   - 完成标准: 写下 1-2 条做错待修正的事（剪残枝）和 1 条做对了要留下的事（加水加肥），每条是一周内可做的具体动作
   - 输入契约: 用户此刻想让某人／某个环境变好——先不急着对那个对象动手
2. **审量能力、划定范围**
   - 完成标准: 把想照顾的对象分三档（伸手能碰到／对面说话／更远），明确本轮只做第一档；写不出第一档对象时，把范围缩到同一屋檐或同一办公室里的一个人
   - 判停条件: 想直接跳到更远一档的，把目标改写为其中一角的角色（照顾三五棵小树），而不是整片花园
3. **选一个最小动作**
   - 完成标准: 给出一个具体微动作——写明对象、动作、时机，强度是伸手能碰到级别（如替对方解决一个具体的小麻烦），不是宏大方案
4. **分寸检查（先问需求＋对方反馈复核）**
   - 完成标准: ①动作前先问对方需求或先确认其真实处境；②动作后以对方反馈复核是帮忙还是添麻烦；③对照三条负面清单自查：不做烂好人、不帮倒忙、恰到好处
   - 判停条件: 对方表示不需要或自己无法判断时，停手或改为询问，不换花样再加码
   - 约定: 帮忙的度原书未给量化判据（NR-06）——本卡只用事前问问、事后看反馈作替代判据，不设数值标准
5. **迭代与扩展**
   - 完成标准: 只有当前一档被对方稳定接受后，才考虑上一档；扩展前回到第 2 步重新审量
   - 输出契约: 四行记录——修正点 / 可安名单（第一档）/ 微动作 / 事前确认＋事后反馈

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 紧急或专业助人场景（救援、医疗、心理危机）: 先转介专业力量；本卡不提供救助或治疗方法
- 对方明确拒绝、或已有更强支持系统的场景: 再帮就是添麻烦（对照不能帮倒忙）
- 被要求无限度付出、需要停下来的处境: 本卡的分寸条款（不做烂好人）支持停手，不要用安人逼自己继续帮

### 作者在书中警告的失败模式

- 做烂好人、帮倒忙（第 08 篇 L347）: 「不能做烂好人，不能帮倒忙，帮忙要帮得恰到好处，安慰人要安慰得恰到好处。」老先生挪位的例子说明过度帮忙就是添麻烦
- 次序颠倒、越级安人（第 08 篇 L343）: 「你自己安不下来的话，就无从“安人”」——修己未完成就大举安人，是本卡要防的次序错误
- 把安人读成让别人情绪变好或拯救世界（第 13 篇 L427）: 作者区分「安人是安顿个别的人，安民则是“安百姓”」——安人是分层的责任，不是把所有人一次安顿好

### 作者的盲点 / 时代局限

- 安人的分寸无量化判据（NR-06）: 帮忙要恰到好处只有原则与一个例子，何时算帮过头、何时算没帮够，原书未给判据
- 本单元证据体量最小之一（9 条候选，全为框架／原则／术语条目，无叙事案例）: 安民、安百姓的操作路径缺失——作者自认普通人做不了安百姓之事，本卡因此把范围上限止于伸手能碰到的人
- 修己完成无完成标准: 作者说修己完成了才有能力安人，但未给修到什么程度算完成的判据；本卡以本轮修正点已处理近似，并提示修己是持续动作（内心要不断磨炼）

### 容易混淆的邻近方法论

- 「先管好自己再管别人」的时间管理／精力管理说法: 方向相似，但本卡的修己有具体动作（修正做错、留下做对），且明确是安人的前置件，不以自我优化为终点
- 救助型助人流程（评估需求→干预）: 结构相近，但本卡的特有约束是范围上限与分寸（不做烂好人），且不提供专业干预方法
- 把先修己当无限期推迟帮助的借口: 原书的安人第一步（给下楼梯不便的人搭把手）是随时可做的微动作，不需要等修己完成才开始
