# 尽力而为之、尽其在我：自我期许的定标（含「脚注」目标）

## R — 原文 (Reading)

> 我们不一定要想天将降大任于我，而是我降我的责任于我，让我做一个尽力而为之的人。……该做的做，该说的说，别人怎么想、怎么批评，我都不在乎，我尽力而为之，求良心之所安。
>
> — 第 19 篇 L521-525

> 所以，不一定要做领头羊，要甘心做“脚注”。你能够做到一辈子有一篇文章被人家引用作为脚注，我认为就是很大的成就了。……这就是我所谓“尽心而为之”的意思，不要求高，但要求“尽其在我”。
>
> — 第 08 篇 L353-355

## I — 方法论骨架 (Interpretation)

这套方法处理的是「我该拿什么尺子要求自己」——把自我期许从外部评价手里拿回来，定在自己的尽心上面。四个动作：

1. **责任自降**：不等待天将降大任于我，改成我降我的责任于我——责任由自己下达给自己，合格线是尽力而为之；不做对上天、对社会的欠账式想象，只对自己负责，求良心之所安。
2. **换判据**：评估一件事，不问成没成、别人认不认，问该做的做了吗、该说的说了吗、有没有尽心。别人怎么想、怎么批评，不在方程里。
3. **换成就观**：不一定要做领头羊——甘心做脚注：一辈子有一篇文章被引作脚注、成为别人立论的台阶，就是很大的成就。标准是不要求高，但要求尽其在我。
4. **刹住加码的欲望曲线**：不为人生制订宏大计划（每年赚十万元→一百万元→一千万元这类数字目标，欲望永远没有满足的时候）；不说自己明天怎么样、后天怎么样，把眼前的事情做好。理想就是尽我的能力，做我可以做的事情。

容易读丢的地方：不要求高不等于降低要求——它的后半句是但要求尽其在我，是低标准＋高执行；脚注不是自嘲，而是一种成就观——做别人站立的那一级台阶，也是尽心。作者还给出一条反面提醒：有大志、有大愿，因为没机会就心怀怨恨——不必的，碰到机会就去做。

## A1 — 书中的应用 (Past Application)

### 案例 1: 刘崇竑先生的「脚注」愿望
- **类型**: 作者转述的师门材料（第 08 篇 L353-355）
- **问题**: 做一辈子研究，成不了「有大贡献的人」，这份工作算什么
- **方法论的使用**: 作者的老师刘崇竑先生把标准降到可执行处——「至少我的一篇文章，被某个大科目的文章或书引用，我就尽了我的一片心」；作者把它提炼为甘心做脚注：不一定要做领头羊，能成为别人立论的台阶，就是很大的成就
- **结果**: 作者给出累积图景——每个人的研究一步一步累积，最后碰到大家；那位大家走了一千步，「有一个台阶是你的，这就尽了你的心」

### 案例 2: 手术之后——「派人过来或送年轻人来，我拼着老命教他」
- **类型**: 据李静特稿转述（L1323）
- **问题**: 2013 年脊柱手术后，作者不能再长途跋涉回国，与南大共事这件事怎么继续
- **方法论的使用**: 把尽力锚定在自己还能做的事上——不能亲自回去，就把教这条路留着：只要有人来，他就教，「派人过来或送年轻人来，我拼着老命教他」
- **结果**: 原书未说明结果（未交代后续是否有学生赴美）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 长期努力没得到外部回报（没升职、没获奖），被周围人说「没出息」，开始怀疑值不值
2. 给自己定了连环加码的目标（收入、名次、粉丝数），达成后立刻空虚，想刹车
3. 自觉有大志向却没有机会，心里积着怨气
4. 面对去留抉择（跳槽、换赛道），发现自己用的全是「别人会怎么看」的标尺
5. 觉得自己能力普通、当不了领头羊，不知道还值不值得把手上的事做下去

### 语言信号

- 「我这么拼到底值不值？」
- 「都五年了还没升上去，是不是我太差？」
- 「等我做到 X，我就……」
- 「如果当年给我机会，我早就……」
- 英文: "am I doing enough", "what if I never achieve anything big", "I keep moving the goalposts"

### 与相邻 skill 的区分

- 与 `letting-go-of-unreachable` 的区别: 本卡处理「期许定标」——把尺子定在尽心／尽其在我上，管事前与过程中；那条处理「欲望落空后的处置」——够不到的东西如何放下与掌握自己。两者互为近邻：定标没做好，落空时才需要放下；但先后别混——已经落空的部分先走那条卡处置，再回本卡重新定标；也可以在定标阶段就把目标改成脚注式，直接避开落空
- 与 `empathy-check` 的区别: 那条把「尽心」落到具体人际事项的两问复核；本卡是「尽心」作为人生尺子的全局定标
- 与 `order-of-helping` 的区别: 那条管帮人的次序与范围（先修己→安人→量力）；本卡管自我期许的高度与判据

## E — 可执行步骤 (Execution)

1. **清点外部标尺**
   - 完成标准: 列出至少 3 条正在使用的别人给的尺子（职位、收入、称号、家人期望），每条标注来源（谁／什么场合）
   - 输入契约: 一个正在纠结的决定，或一段持续的低落感
2. **责任自降**
   - 完成标准: 写出天将降大任式的默认假设（或原句），改写为我降我的责任于我式的一句——责任主体必须是「我」；同时给出该做的做、该说的说在本案里的具体所指
   - 判停条件: 改写句写不出来，说明还在等外部授权——回到第 1 步补标每条尺子背后的人
3. **用尽心两问替代结果评估**
   - 完成标准: 对当前的事回答两问——①该做的做了吗、该说的说了吗？②这件事我有没有尽心？回答只允许是／否＋具体行为，不允许用数字、名次、称号作答
4. **设脚注式目标**
   - 完成标准: 把当前目标改写成一条脚注式目标——说清我做的事能支援谁、成为谁的台阶；同时检查目标里有没有「等我做到…就…」的加码句式，有则删改为把眼前的事情做好
5. **排除别人的期望后做决定**
   - 完成标准: 对纠结的决定，先划掉别人会怎么看一类的理由，给出 1 条不依赖外部评价的决定性理由；若只剩外部理由，回到第 2 步重做
   - 输出契约: 五行记录——外部尺子清单 / 自降责任句 / 尽心两问 / 脚注目标 / 决定＋理由

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 正在遭受不公对待、需要争取合法权益（欠薪、侵权、歧视）: 本卡不用于接受现状或放弃应得权益
- 临床抑郁、自我价值全面崩塌等心理危机: 先求助专业支持，本卡不能替代
- 需要客观外部标准的场景（考试、资质、安全合规）: 这些场合的外部标尺不可省，本卡只处理把外部评价当成唯一尺子的情形

### 作者在书中警告的失败模式

- 为人生制订宏大计划（ce19，第 06 篇 L311）: 「但不要为人生制订宏大计划，比如我一定要每年赚十万元，赚到了十万元以后就会想着赚一百万元、一千万元……欲望永远没有满足的时候。」
- 有大志而无机会就心怀怨恨（ce25，第 08 篇 L351）: 「不必说我有大志、有大愿，但因为没机会，就心怀怨恨。不必的，碰到机会就去做，这样就够了。」
- 追求顶天立地、追求被封为精英（ce41，第 19 篇 L525）: 「你能在职位上做到尽力为之就够了，无须追求顶天立地，更无须追求被人家封为精英。」

### 作者的盲点 / 时代局限

- 尽心是内部判据，缺外部校准: 如何区分「我真的尽心了」与「用尽心当托词」，原书以问句形式提出（能力有没有完全发挥？有没有好好想怎么做？），无操作细则——本卡不虚构细则
- 结构性因素被轻放: 对机会稀缺与竞争环境，作者给的是碰到机会就去做的姿态，未给现实路径；引用时注意这是处世姿态，不是职业规划方法
- 「脚注」成就观出自学术语境（一篇文章被引用作脚注），迁移到其他行业需要自行翻译其含义
- c80（手术后教人）为李静特稿转述，证据强度按二手传记材料处理

### 容易混淆的邻近方法论

- 知足常乐／低欲望类说法: 方向相近，但本卡是不要求高、但要求尽其在我——低标准＋高执行，不是把标准一降了之
- 目标管理（OKR／SMART）类: 本卡不反对具体目标，反对的是层层加码、没有止盈线的欲望曲线（ce19）；有明确交付的场景，外部标尺仍可用，但最终判据要换回有没有尽心
- 与 `letting-go-of-unreachable` 的混用: 定标（本卡）与放下（那条）互为近邻但不要合成一步——一事未落空之前不必先练习放下，落空之后也不要只靠重定标来回避处置
