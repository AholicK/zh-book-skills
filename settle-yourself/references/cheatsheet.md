# 决策规则速查 — 《往里走，安顿自己》

| 能力 | 一句话规则 |
|---|---|
| 「往里走」：把外界刺激内化为观念与行为（含文本解读范例） | 把冲击你的那件事走完一条链：看见变化 → 感受影响 → 找出影响最深的部分 → 反思 → 照见行为。 |
| 「你是什么样的人」：自我责任与修养（面貌是自己的责任） | 把遭遇里属于你的那部分责任收回来——二十岁以后你的「样子」由你负责，但只到十之七八。 |
| 安定与内在力量：存在、尊严与清贫之乐（自我排遣） | 先把「能改变／不能改变」切开，再给不可改变的那一半配一套补养与排遣。 |
| 忠恕之道：将心比心的日常复核（含「仁」的字源） | 做决定或开口前问两句：我尽心了吗？我把心放到对方心里试过没有？ |
| 修己以安人：帮忙的次序与分寸（先修己 → 安人 → 安大众） | 想帮人先修自己，再从伸手能碰到的人帮起；不做烂好人，不帮倒忙。 |
| 尽力而为之、尽其在我：自我期许的定标（含「脚注」目标） | 把「天降大任」换成「我降我的责任于我」：以尽心定标，以「脚注」为成就。 |
| 读世界这部大书：知识、判断力与为学（含跨学科与为常民写作） | 把周围环境当成书来读：观察→分类→讨论→应对，再练「判断力两步」。 |
| 不糟蹋自己：欲望与自怜两条禁令（做「完整的人」） | 停不下来时自查两栏：被欲望糟蹋了什么，被自怜糟蹋了什么。 |
| 抓不到的云：欲望落空的处置与「掌握自己」 | 抓不到的云让它飘走——再把「一半由我掌握」的部分列出来。 |
| 感恩不抱怨：以所得恩惠重估困苦（含心理安全边界） | 把吃过的苦放回所得里称一称——只给自己用，且不适用于创伤与受害场景。 |
| 顿悟与机缘：思想不定型（每日质疑旧思考） | 把「必须想通」改成「保持准备」：每天学一点新东西，并对一条旧判断提一个质疑。 |
| 迷茫时代：经营小圈子 + 面对现实（与不确定性共存） | 关系侧经营小圈子，认知侧理解世界在怎么变——两张处方一起用。 |
| 文化的消化：借来的东西必须咀嚼—检验—吸收—修正 | 借来的东西先咀嚼、再检验合不合，然后小范围吸收、边吸收边修正。 |
| 世界尺度：天下国家、宽容与谦卑（不以「国家」为最大） | 把对外判断放大到全球社会与历史尺度，再用两条禁令与「谦卑」收束。 |
| 变化与文明活力：以变化观看世界（盛极必衰／唯一不变的是变化） | 把「这次完了」放回长周期看：盛极必衰、否极泰来，活力靠自我修正与采纳众流。 |
| 科技时代：智力与智慧之分、信息过载与精神危机 | 用「智力是运算能力、智慧是预见后果的能力」做能力分栏：什么交给机器，什么自己守住。 |
| 灾难与变局：重估价值、重建生活（含制度反思与时评材料） | 大变故之后允许世界观改变：先重排价值，再做一件互助重建的事。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
