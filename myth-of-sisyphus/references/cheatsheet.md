# 决策规则速查 — 《西西弗神话》

| 能力 | 一句话规则 |
|---|---|
| 荒诞的界定与荒诞感识别（五主题 + 三要素） | 把「说不清哪里不对劲」译成结构：五主题对号 + 三要素归位 + 越界自查。 |
| 跳跃检测与哲学的自杀（四模式） | 从「理性破产」处跳到信仰/永恒/希望的那一步，就叫跳跃——找出它、归类它、查平衡。 |
| 自杀问题分析（荒诞不导向自杀） | 「看透了所以不想活」在逻辑上不成立：自杀取消的是荒诞本身，而不是跟着荒诞走。 |
| 三重后果推演与反抗判定 | 从荒诞推不出「什么都可以」：三个后果是反抗、自由、激情——且每一步都要回查是否越界。 |
| 荒诞自由（自在自由 → 行动自由） | 「等我……就自由了」是伪自由：没有未来反而带来行动自由；给生活设目的就是给自己造藩篱。 |
| 数量伦理（生活得充实） | 重要的不是生活得最和睦，而是生活得最充实——按被意识到的经验数量计，前提是清醒意识。 |
| 荒诞人画像分析（唐璜／演员／征服者） | 唐璜、演员、征服者是寓意图像，不是行为范本——「一个范例不一定是必须遵循的范例」。 |
| 荒诞作品判定 | 作品是否保持荒诞，看三条：荒诞戒律是否被尊重、有没有表现分离与反抗、有没有推崇幻想或激发希望。 |
| 荒诞创作纪律与表达技法（生产侧） | 明知没有结果还继续：不为什么而创作，把创作当苦行——天天努力、自我控制、准确估量真实的界限。 |
| 创作家的背叛点定位（陀思妥耶夫斯基／卡夫卡） | 背叛点就是跳出去的瞬间：提供答案、预告未来生活、把希望递回给读者。 |
| 逻辑自杀推演（基里洛夫） | 「假如上帝不存在，我就必须自杀」——这种链子的可拆之处在中间那个「必须」。 |
| 西西弗模型（意识·蔑视·幸福） | 明知无望还要继续的人靠三件事站住：意识（看见处境）、蔑视（比石头更坚强）、以及「应当想像」的幸福。 |
| 希望／隐遁检测 | 把生活抵押给「下辈子」或某个伟大理念的，是隐遁——检测对象是生活策略，不是情绪。 |
| 反抗越界诊断（机制与判据） | 反抗的越界只有两条路：全盘说不（绝对否定）与全盘说是（绝对肯定）——两条都通向杀害与封闭。 |
| 反抗谱系个案（萨德 → 超现实主义的越界史） | 把一种极端主张放回萨德→尼采→超现实主义的坐标系里：它走到哪一步、会滑向什么，都有先例。 |
| 自反性检查与诚实性纪律 | 「拒绝一切跳跃」本身要不要过一次自反检查？——要，而且这份风险应当外显保留，不是掩藏。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
