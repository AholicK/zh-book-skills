# 反抗越界诊断（机制与判据）

## R — 原文 (Reading)

> 每次反抗挑战全盘拒绝现存秩序，挑战绝对的“不”，反抗就格杀勿论，每次反抗盲目接受现存秩序，并高喊绝对的“是”，反抗也格杀勿论。……但在这两种情况下，反抗导致杀害，并失去被称为反抗的权利。
>
> — 附编·虚无主义与历史（L1069-1081）

## I — 方法论骨架 (Interpretation)

这是一台**诊断仪**：拿一种反抗立场、学说或运动进来，判断它是否越界——即是否已经「导致杀害」并且「失去被称为反抗的权利」。它不评价反抗的价值，只定位它在哪条路径上越了界。

两条路径（都格杀勿论）：

1. **绝对否定的路径**：全盘拒绝现存秩序，高喊绝对的「不」——书中谱系的第一站是萨德，从反抗唯一得出绝对的「不」；
2. **绝对肯定的路径**：盲目接受现存秩序，高喊绝对的「是」——终点是「向一切说“是”意味着向杀人说“是”」（L997）。

关键机制：

- **共同根源 = 单一性诉求**。形而上反抗的原动力是「无休止的单一性诉求：拒绝死亡，渴望延续和透明」（L1073）；诉求本身不是罪，一旦被绝对化（要求彻底透明、延续、一统）就滑向越界。
- **绝对肯定的双重结构**：向一切说「是」须做角色检验——奴隶说是＝接受自身痛苦，奴隶主说是＝颂扬杀人；「归根结底使两者之中的强者即奴隶主神圣化」（L997）。
- **置换规则**：尼采把「假如什么都不是真的，那么一切都允许了」置换成「假如什么都不是真的，那么什么都不允许了」（L979）；自由的前提是可能与不可能同时被确定——「没有法则就没有自由」，自由因此是「最大的依附」、是「拉得最满的弓」的苦行，而不是无约束。
- **后果形态 = 自我封闭**：反抗把上帝驱逐之后「把自己封闭起来，其最大的自由仅仅在于建造自身罪行的监狱」，从萨德的城堡直到集中营；绝对自由终究成为「一座绝对义务的监狱」（L1081）。

术语校准（三个易错点）：虚无主义不是「什么都不信」，而是「不相信现有一切的人」（g21）；形而上反抗是「奋起反对生存状况及其造物主」却「肯定造物的孤独和一切道德的虚无」的抗议（g18，L1071），不是荒诞人那种守界限的反抗；绝对否定与绝对肯定不是「坏选项与好选项」，而是两条同归的路（g19、g20）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 反抗者自我封闭——从萨德的城堡到集中营
- **类型**: 书中转述（附编·虚无主义与历史 L1069-1081）
- **问题**: 反抗否定现存秩序、把上帝驱逐出去之后，会把自己安顿成什么形态？
- **方法论的使用**: 用双路径诊断先定位落点（绝对否定一端：舍神宠、自立规则），再按机制推演：自食其力 → 必须建立自己的规则并扩张壁垒 → 对自由的诉求普及到全体大众 → 集体苦行与历史终结；书中同时记下「扼杀上帝和建立教会，正是反抗持久而矛盾的运动」
- **结论**: 书中判定：「世人反抗到了头便把自己封闭起来，其最大的自由仅仅在于建造自身罪行的监狱」；绝对自由终究成为「一座绝对义务的监狱」，并势必要建立「唯一的王国」
- **结果**: 书中判定（谱系走向）：「从萨德悲剧性的城堡到集中营，一概如此」——封闭、戒严与规训是该路径的常规终局

### 案例 2: 绝对「不」与绝对「是」殊途同归（总判据）
- **类型**: 书中转述（附编·虚无主义与历史 L1069-1081；本卡与 `three-consequences` 的交叉候选，主属 v04）
- **问题**: 两种相反的反抗姿态（全盘拒绝／盲目接受）会不会有不同的结局？
- **方法论的使用**: 并置两条路径做同一检查，并追踪情感的转化：「对创造者的恨很可能转为对创造的恨，抑或转为对现存秩序的爱，而且是排他性和挑衅性的爱」
- **结论**: 「但在这两种情况下，反抗导致杀害，并失去被称为反抗的权利」；「人们可以用两种方式成为虚无主义者，但不论哪种方式都是绝对无节制的」
- **结果**: 未说明（该条是总判据与警示信号登记，不是单一事件）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读到或听到一种极端主张（「现存的一切本质上都是压迫，必须彻底摧毁」／「接受一切、肯定一切」），想判断它是否越界
2. 一份宣言或学说把自由定义成「取消一切约束」，需要检查这个定义
3. 一个运动从「要求」变成「消灭对方」，需要复盘它走了哪条路
4. 想解释「为什么恰恰是最激进的反抗，最后建起了新的监狱」
5. 评估一个学说的历史后果（如「超人」被诠解成暴力的教导），要落到机制上而不是道德上

### 语言信号

- 「彻底摧毁」「不破不立」「全盘否定」
- 「一切都是最好的安排」「接受一切、肯定一切」
- 「没有对错，规则都是压迫」
- 「不惜一切代价」「不管什么革命，先闹一场」
- 英文: "tear it all down", "everything is permitted", "say yes to everything", "by any means necessary"

### 与相邻 skill 的区分

- 与 `three-consequences` 的区别: 那条给反抗的**正面判定**（荒诞的反抗是什么、界限在哪）；本卡只做越界侧的诊断（路径 → 杀害与封闭）。ce31 与 p35 是两卡的**双向交叉候选**，两侧共用同一批判据，引用时不得写成单侧归属
- 与 `revolt-genealogy` 的区别: 那条是附编 150 年的个案史（萨德 → 超现实主义），负责个案定位与判词；本卡只引机制层判据（双路径、单一性诉求、封闭机制），个案按需从那条取
- 与 `logical-suicide` 的区别: 那条拆解个人赴死的推演（基里洛夫）；本卡处理「反抗如何制度化地走向杀害与奴役」，不处理个人赴死

## E — 可执行步骤 (Execution)

1. **取主张**
   - 完成标准: 逐字拿到该立场的核心表述（宣言句、纲领句或论证链的结论句）
   - 输入契约: 一段可判定的立场文本；只有情绪表达（「我受够了」）时先请其补出主张

2. **路径定位**
   - 完成标准: 判定它落在哪一端（绝对否定／绝对肯定／两端兼有），依据是它对现存秩序的态度（全盘拒绝 vs 盲目接受）与对「杀害／毁灭」的态度
   - 判停条件: 若它并没有把任一项推到极限（仍保留对峙、仍要求界限）→ 不在本卡的诊断范围内，转 `three-consequences`

3. **动力追溯**
   - 完成标准: 指出它诉求的单一性是什么（拒绝死亡／渴望延续／渴望透明／渴望一统），以及这一诉求是否被绝对化
   - 输出契约: ①路径判定 ②动力（单一性诉求）说明 ③立场句中的对应词

4. **机制预测**
   - 完成标准: 给出两项预测——封闭形态（是否要建立自己的规则、扩张壁垒、走向戒严与「唯一的王国」）与杀害的正当化（是否出现「向杀人说『是』」式的论证）；遇到「肯定一切」的表述时按角色检验（对谁说「是」、接受谁的痛苦）
   - 判停条件: 只做「是否越界」的机制判定，**不对现实政治运动下价值判决**；「越界临界点」的量化判据原书未给，需使用者自定并写明

5. **越界结论与交叉校验**
   - 完成标准: 给出结论（是否已「导致杀害」并「失去被称为反抗的权利」）；并检查该反抗是否还保有共同体维度（p35：「我反抗，故我们存在」——失去这一维度的「反抗」只剩权力意志与杀害）
   - 输出契约: 路径判定 + 动力解释 + 越界结论 + 交叉校验一句

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把本卡当政治判决工具：它是诊断仪，只做「是否越界」的机制判定，不对具体运动与个人下价值判决
- 处理个人自伤／自杀风险：那超出本卡范围，应停止流程并寻求专业帮助
- 回答「什么才是真反抗」的正面问题：转 `three-consequences`

### 作者在书中警告的失败模式

- 两条路径都「格杀勿论」：「每次反抗……反抗就格杀勿论」；「人们可以用两种方式成为虚无主义者，但不论哪种方式都是绝对无节制的」
- 绝对肯定的杀机：「向一切说“是”意味着向杀人说“是”」；「归根结底使两者之中的强者即奴隶主神圣化」
- 术语混用即误判（g18–g22）：虚无主义≠「什么都不信」；形而上反抗≠荒诞人的反抗；绝对否定／绝对肯定不是「坏与好」的两端；「苦行」是纪律词（「自由是伟人的苦行主义，“是拉得最满的弓”」L983），读成「吃苦受罪」会丢掉「维持紧张」的方法论含义
- **NR-03 疑点登记**：L985 的拉丁文括注「（拉丁文：死去的爱）」疑为源稿／OCR 异常（该句与下文 odium fati 对举，括注释义存疑）——**本卡只引正文句、不引括注**；修正前不得引用该括注（见 needs-review.md NR-03）

### 作者的盲点 / 时代局限

- **ce31/p35 与 `three-consequences`（v04）双向交叉**：两条候选主属 v04，本卡共享同一批判据；引用时双侧都要标注，不得写成单侧引用
- 附编为《反抗者》节译（本项目计入正文口径），写于 1940-1942 年；**不涉及战后问题**：核武器、极权制度的完整形态、殖民解放运动（BOOK_OVERVIEW 批判节）
- 附编本身就是「反抗凭什么能长期停在界限之内」这一问题的最大疑问——本卡的判据不承诺给出可长期稳定的界限
- 「越界临界点」原书未给，需使用者自定
- 底本限制：引文取自 **OCR 整理稿**（加缪《西西弗神话》，沈志明译，上海译文 2013 版），照抄原稿、含 OCR 形近字噪声；逐字转引前应先复核底本

### 容易混淆的邻近方法论

- `three-consequences`: 正面判定与本卡的反证互补；同一主张常需两卡先后使用（先判真伪，再判越界）
- `revolt-genealogy`: 本卡给机制、那条给个案；需要具体坐标时以那条的判词为准
