# 西西弗模型（意识·蔑视·幸福）

## R — 原文 (Reading)

> 这则神话之所以悲壮，正因为神话的主人公是有意识的。假如他每走一步都有成功的希望支持着，那他的苦难又从何谈起呢？……心存蔑视没有征服不了的命运。
> ……
>
> — 西西弗神话（L713-737）

> 攀登山顶的拼搏本身足以充实一颗人心。应当想像西西弗是幸福的。
>
> — 西西弗神话（L713-737）

## I — 方法论骨架 (Interpretation)

这是全书的终点模型，用于分析「明知无望而为之」的动机结构。三要素：

1. **意识**：悲壮的前提是主人公「有意识」。作者选中的图像不是推石头的苦役，而是「回程时稍事休息」的西西弗——那个时辰「就像一次呼吸」，既是他的不幸肯定再来，也是「觉醒的时刻」。判据：此人在「下山时」是否仍清楚看见自己的处境，不自我欺骗、不追加虚妄的希望支持（「假如他每走一步都有成功的希望支持着，那他的苦难又从何谈起呢」）。
2. **蔑视**：姿态指向命运本身，而非某个外部对手——「心存蔑视没有征服不了的命运」，「他比所推的石头更坚强」。判据：离开山顶的每个瞬息，他是否「超越了自己的命运」（c29）。
3. **幸福**：作者把幸福放在攀登的过程而非结局——「攀登山顶的拼搏本身足以充实一颗人心」；幸福与荒诞是「共一方土地的两个儿子」，不互为因果。
4. **落点判据**：他确信「一切人事皆有人的根源」；「命运是属于他的、岩石是他的东西」——不再向诸神或永恒索赔。

同构校准：俄狄浦斯在失明与绝望之后吼出「一切皆善」，作者判其与基里洛夫「一语道出了荒诞胜利的格言」。

**声明**：本卡的「幸福」是**结论而非推论**——作者用的词是「应当想像」，它是一种认领与呼吁，不是可检验的定理；去掉「幸福」一项，全书会缩水为虚无主义版本（g12）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 西西弗的判罚——无用又无望的劳动
- **类型**: 书中转述（西西弗神话）
- **问题**: 被诸神判罚的「无用又无望的劳动」是什么样
- **方法论的使用**: 诸神判罚西西弗把岩石推上山顶，石头因自身重量一次又一次滚落——「没有比无用又无望的劳动更为可怕的惩罚了」；作者随后交代各种传说（荷马眼中最明智谨慎的人、泄露诸神秘密、用铁链锁住死神、考验妻子的爱情），再把他定为荒诞英雄「既出于他的激情，也出于他的困苦」。
- **结论**: 石头因自身重量滚落，是结构性的失败；作者判定「这是热恋此岸乡土必须付出的代价」。
- **结果**: 西西弗「竭尽全身解数却落个一事无成」。

### 案例 2: 下山时的觉醒——意识在场的时刻
- **类型**: 书中转述（西西弗神话）
- **问题**: 荒诞英雄的「意识」在场于哪个时刻
- **方法论的使用**: 作者说他的兴趣恰在「回程时稍事休息的西西弗」：贴着石头的苦脸、沉重而均匀的步伐——这个时辰「就像一次呼吸」，恰如他的不幸肯定会再来，「此时此刻便是觉醒的时刻」。
- **结论**: 神话之所以悲壮，正因主人公是有意识的；他思考的正是自己的生存状况。
- **结果**: 书中判定：「他离开山顶的每个瞬息，他渐渐潜入诸神洞穴的每分每秒，都超越了自己的命运」；「他比所推的石头更坚强」。

### 案例 3: 俄狄浦斯的「一切皆善」——同构样本
- **类型**: 书中转述（西西弗神话）
- **问题**: 荒诞胜利的格言在另一则神话中如何出现
- **方法论的使用**: 俄狄浦斯起先不知不觉顺应了命运，「一旦知觉，他的悲剧就开始了」；就在同一时刻，他失明、绝望，认定自己与这个世界唯一的联系只是一位姑娘娇嫩的手，于是吼出一句过分的话：「尽管磨难多多，凭我的高龄和高尚的灵魂，可以判定一切皆善。」
- **结论**: 他与基里洛夫「一语道出了荒诞胜利的格言」——「古代的智慧与现代的壮烈不谋而合了」。
- **结果**: 书中判定如上。

### 案例 4: 全书落点——「应当想像西西弗是幸福的」
- **类型**: 书中转述（西西弗神话）
- **问题**: 荒诞英雄的结论以何种句式给出
- **方法论的使用**: 作者让西西弗留在山下，「以否认诸神和推举岩石这一至高无上的忠诚来诲人警世」；他判定一切皆善，觉得这个从此没有救世主的世界「既非不毛之地，抑非渺不足道」——岩石的每个细粒、大山每道矿物的光芒，都成了他一人世界的组成部分。
- **结论**: 「攀登山顶的拼搏本身足以充实一颗人心。应当想像西西弗是幸福的。」
- **结果**: 作者明言这是「应当想像」——一种呼吁与认领，而非证明。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一个项目或事业被证明「此路不通」，但决定继续推进其中「毫无结果」的部分
2. 长期坚持一件注定失败的事，需要给这种坚持一个不靠自我安慰的说法
3. 想检查自己的坚持是「清醒的」，还是靠希望支撑（希望一撤就停下来的那种）
4. 在「结局永远失败」的前提下，想弄明白动机结构到底是什么（意识？蔑视？还是别的）
5. 需要区分「认命式的受难忍耐」与「西西弗式坚持」

### 语言信号

- 「明知没用，我为什么还在做」
- 「赢不了，但我还想继续」
- 「我不想再骗自己说会成功」
- 「石头还会滚下来，这我知道」
- 英文: "it will never work and I'm doing it anyway", "I've stopped pretending it will succeed", "the rock rolls back — I know"

### 与相邻 skill 的区分

- 与 `hope-detection` 的区别: 那条检测「抵押未来」的生活策略（希望／隐遁）；本卡处理抵押被撤掉之后的当下——意识在场的此刻如何构成动机。一句「等我……就好了」触发前者，一句「明知没用我还在做」触发本卡
- 与 `creation-discipline` 的区别: 那条是无望而为之的创作侧（纪律与技法）；本卡是生活侧的姿态模型（意识·蔑视·幸福）——同一精神，两个场域

## E — 可执行步骤 (Execution)

1. **确认处境是「无用又无望」的**
   - 完成标准: 说清为什么它不会成功（对照 c28：石头「因自身重量」必然滚落那一类结构性失败），而不是暂时受挫
   - 判停条件: 若失败只是阶段性、成功仍可努力，本卡不适用（那是普通项目复盘）
2. **意识检查**
   - 完成标准: 指出此人在「下山时刻」（失败之后、重新开始之前）是否仍清楚看见处境：有没有追加虚妄的希望支持？有没有自我欺骗式的重新包装？
   - 判据: 对照「假如他每走一步都有成功的希望支持着，那他的苦难又从何谈起呢」
3. **蔑视检查**
   - 完成标准: 判断姿态指向的是命运本身还是某个外部对手；对照「心存蔑视没有征服不了的命运」「他比所推的石头更坚强」
4. **落点检查（幸福的位置）**
   - 完成标准: 把「值不值得」的问法改成「攀登的拼搏本身是否充实」；检查结论是否落在过程而非结局
   - 输出契约: ①处境判定 ②三要素逐项结论 ③「可继续／不可继续」的判据（若继续，靠的是意识与蔑视；若不可，说明缺哪一项）
   - 判停条件: **不得把「幸福」当成推得出来的结论**——若用户要求证明「坚持必然幸福」，如实告知：作者用的词是「应当想像」，本卡只能给出结构与呼吁，不给证明
5. **同构校准（可选）**
   - 完成标准: 用俄狄浦斯的「一切皆善」（c30）做一次同构比对：知觉、绝望之后仍下判断——校准「觉醒之后仍继续」的形态

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 要求「证明坚持必然通向幸福」的场合——本卡给不出证明（「幸福」是结论而非推论，见下）
- 阶段性挫折、需要项目复盘与止损决策的场合——本卡针对的是「结构性无望」的处境
- 把西西弗当纯悲情受难者来同情或美化——英雄性不在结局，而在意识与蔑视（g12）

### 作者在书中警告的失败模式

- 去掉「幸福」一项，全书会退化为虚无主义版本（g12）
- 把幸福当证明：作者用的词是「应当想像」——幸福不能靠证明获得，包装成可证明定理即失真（p30）
- 追加希望支持：一旦「每走一步都有成功的希望支持着」，苦难的性质就变了——那不是本模型中的坚持（f24 的反问句）
- 忽略「下山时刻」：只在推石头的苦役里看西西弗，就丢掉了意识与蔑视的唯一在场时刻（c29）

### 作者的盲点 / 时代局限

- **「幸福」是结论而非推论**：作者用词是「应当想像西西弗是幸福的」（L737），本卡不得把它包装为可证明定理——这一抒情性质必须保留（verified note）；BOOK_OVERVIEW 批判节亦指出：从「命运属于他、岩石是他的东西」到「幸福」之间，作者未给出可检验的推论
- 神话为转述材料：判罚、传说、觉醒诸节均是加缪对神话的解读（「作者对神话的解读，非史实」），不得当作史实断言
- 可行性存疑：批判节指出，荒诞英雄都需要极强的意志与清醒度；对多数人而言，「消灭希望」的要求可能导向冷漠或自我消耗，作者对此未给出更细的支持路径
- **底本限制**：本卡所依底本为 OCR 整理稿，R 段引文照抄原稿（含噪声）；书籍为加缪 1942 年作品、沈志明译上海译文 2013 版；作者批判节的时代局限按需引用
- 原书未给「何种处境算『无用又无望』」的判定线，需使用者自定

### 容易混淆的邻近方法论

- `hope-detection`: 反面关系——那条检测「抵押未来」（希望／隐遁），本卡处理抵押被撤掉之后的当下（意识在场的此刻）
- `creation-discipline`: 同一精神的两个场域——创作侧是纪律与技法，生活侧是本卡的三要素模型
