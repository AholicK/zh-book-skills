# 三重后果推演与反抗判定

## R — 原文 (Reading)

> 综上所述，我从荒诞取得三个结果，即我的反抗、我的自由和我的激情。我仅仅通过意识的游戏，就把对死亡的邀请变为生活的准则——而且我拒绝自杀。
>
> ……
>
> 这样，唯一前后一致的哲学立场，就是反抗。所谓反抗，是指人与其自身的阴暗面进行永久的对抗。苛求不可能有透明，每时每刻都要叩问世界。……反抗就是人自身始终如一的存在，不是憧憬，也不是希望。
>
> — 荒诞自由（L347）／荒诞自由（L315）

## I — 方法论骨架 (Interpretation)

从已认定成立的荒诞出发（前提：荒诞已完成界定，且未查出跳跃），推出三个结果——反抗、自由、激情；每一步都回查荒诞三项（人／世界／对峙）是否完好。

- **反抗**（判定标准）：人与其自身的阴暗面进行永久的对抗——对抗对象是自己，不是外部敌人；每时每刻叩问世界；不是憧憬，也不是希望。唯一前后一致的哲学立场就是反抗。
- **自由**：没有未来 → 行动自由（本卡只做定位，展开见 `absurd-freedom`）。
- **激情**：以数量代替质量的经验方式（生活侧展开）。
- **推理纪律**：严以律己，仅凭所知生活——眼见为实、随遇而安、不让任何不可靠的东西掺和；对「没有任何东西可靠」的回应是「至少此话是可靠的」；把方法坚持到底。
- **总收束**：通过意识的游戏，把「对死亡的邀请」变为「生活的准则」，并且拒绝自杀。
- **误读拦截**：「一切皆许可」不是放纵的许可证——荒诞是束缚不是解套；它只不过把行为的等值回归成行为的结果。
- **越界警戒**：反抗若走向全盘拒绝（绝对的「不」）或盲目接受（绝对的「是」），都会导致杀害并失去反抗之名——转 `revolt-overreach`。

## A1 — 书中的应用 (Past Application)

### 案例 1: 伊凡·卡拉玛佐夫的「一切皆许可」
- **类型**: 书中转述（荒诞人）
- **问题**: 「一切皆许可」能不能当放纵的许可证用
- **方法论的使用**: 加缪特意限定：这句惊呼的重点「不是解脱和快乐的呐喊，而是出自苦楚的确认」；它「以不可庸俗理解为条件」——荒诞并不打开犯罪的自由，它只是把行为的等值回归成行为的结果，把人重新摆到必须为后果负责的位置
- **结论**: 荒诞不是解套的，而是束缚的；它并不劝人犯罪，但把悔恨的无用性恢复了
- **结果**: 书中判定：「并不意味着任何东西都不维护了」

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 听到或想说「既然没有意义，那什么都可以干／规矩不用守」
2. 想检查某个自称「从荒诞出发」的立场：三后果是否齐备、哪一步偷偷取消了一项
3. 想判定一个行为或学说是不是真反抗（对抗自身阴暗面，还是对外部秩序的愤怒）
4. 有人引用「一切皆许可」为放纵甚至犯罪背书，需要纠偏
5. 自查生活纪律：凭何生活、有没有把不可靠的东西掺和进来

### 语言信号

- 「看透一切，就什么都随便了」
- 「反正没有意义，我干嘛守规矩」
- 「什么都没有约束了」
- 「我反抗」被当成对外部世界的拒绝宣言
- 英文: "if nothing matters, anything goes", "why follow any rules then", "I'm done playing by their rules"

### 与相邻 skill 的区分

- 与 `absurd-freedom` 的区别: 自由是三重后果之一——本卡是总清单与判定程序，那张专门展开「自在自由 → 行动自由」那一支
- 与 `revolt-overreach` 的区别: 本卡做反抗的正面判定（真伪之分）；那张对越界后的机制做诊断；ce31／p35 的交叉判据两卡双向互见
- 与 `logical-suicide` 的区别: 那张专门拆解「因无意义而作恶／赴死」的推演（基里洛夫式）；本卡处理日常误读（「一切皆许可」）

## E — 可执行步骤 (Execution)

1. **前提核查**
   - 完成标准: 确认对象是已认定成立的荒诞——已完成界定，且未检测到跳跃；两项缺一时先补前置工序

2. **拒绝自杀**
   - 完成标准: 明确不取消「人」这一项——推演以「而且我拒绝自杀」为总收束

3. **逐项推演三后果**
   - 完成标准: ①反抗——对抗对象是否为自身阴暗面，是否混入憧憬／希望；②自由——是否承认没有未来的行动自由；③激情——是否落在穷尽经验的意识数量上；每一步回查荒诞三项是否完好
   - 判停条件: 某一步取消了三项中的任一项 → 停止推演，标注越界位置

4. **推理纪律检查**
   - 完成标准: 按「仅仅凭借他所知道的东西生活，眼见为实，随遇而安，不让任何不可靠的东西掺和」核对——是否让不可靠的东西掺和进来（f07 类推理纪律在本卡中是被检对象）
   - 输入契约: 一段立场自述或行为方案

5. **误读纠偏**
   - 完成标准: 对「一切皆许可」类句子，按「出自苦楚的确认」处理，写明荒诞并不劝人犯罪；去掉放纵解法（ce13 的误读点：「没有赦免」被听成「没有约束」）

6. **越界警戒**
   - 完成标准: 检查反抗是否滑向绝对「不」或绝对「是」；出现「一心想死，有的却一心想让人死」的信号 → 转 `revolt-overreach`
   - 输出契约: 三后果清单 + 判定（真／伪反抗）+ 越界警示

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把推演结果当作鼓励冒险／犯罪的依据——荒诞是束缚不是解套；「一切皆许可」以不可庸俗理解为条件
- 对现实政治运动下价值判决：本卡的越界判定是机制性检查，现实应用须回到 `revolt-overreach` 的机制判据，并保持谨慎
- 只想要立场口号、不做逐步回查的场合：三后果要求每一步都可核验，否则只是修辞

### 作者在书中警告的失败模式

- ce13 的误读点：「没有赦免」被听成「没有约束」——以荒诞为由解除自我约束；警告信号：引用「一切皆许可」时语气轻松或亢奋、把「没有善恶报应」等同于「没有后果」
- ce31：绝对「不」与绝对「是」殊途同归——「每次反抗挑战全盘拒绝现存秩序，挑战绝对的“不”，反抗就格杀勿论」，两条路都「失去被称为反抗的权利」；警告信号：目标从维持对峙变成消灭对方
- 三后果不齐备或某一项走偏，都会回到「哲学的自杀」（p20 代价栏）
- 反抗若失去共同体维度，只剩权力意志与杀害（p35 判定口径）

### 作者的盲点 / 时代局限

- **覆盖登记**（单元 note）：f07（推理纪律）无独立任务，为 task-18 提供被检对象；p25（只要知情和毫不掩饰就行了）同时服务 task-11——两处引用时不得升格为独立方法论
- **判词保持原文**：p15 的两条判词（L317）在 R／A1 中被引用时必须保持原文、不得改写——「自杀并不象征反抗的逻辑结局，而完完全全是反抗的反面」；「意识到死亡又拒绝死亡，那就逃脱自杀了」
- **史例性质**：ce31／p35 引自附编（L1069-1081），判词针对其所分析的历史机制；本卡不做现实政治外推
- **底本限制**：引文照抄 OCR 整理稿《西西弗神话》（加缪 1942 年作品，沈志明译，上海译文出版社 2013 年版），形近字与标点噪声一仍其旧；作者批判节的时代局限按需引用，不作外推

### 容易混淆的邻近方法论

- `absurd-freedom`: 本卡是三重后果总清单，那张展开自由一支——同一句「自由」表述可能双触发，判定时写明所查的是哪一步
- `revolt-overreach`: ce31／p35 为双向交叉条目（本卡 ↔ 那张，归并账口径主属本卡）——引用时写明两卡口径，不得写成单侧引用
- `logical-suicide`: 「因无意义而作恶／赴死」的推演拆解在那张；本卡处理的是日常误读（「一切皆许可」）
