# 希望／隐遁检测

## R — 原文 (Reading)

> 致命的“隐遁”，即为希望，是本散论的第三个主题。所谓希望，就是对下辈子生活的希望，应当“对得起”才行，抑或是自欺欺人：不是为生活本身而生活，而是为某个伟大的理念而生活，让理念超越生活，使生活变得崇高，给生活注入意义，任理念背叛生活。
>
> — 荒诞与自杀（L185）

## I — 方法论骨架 (Interpretation)

这本书把「希望」从日常语义里拆出来，重新定义成一种**可判定的生活策略**：把生活的依据放到生活之外——下辈子、后世、某个伟大的理念、「对得起」。作者给它一个名字：「隐遁」，并声明这是本散论的第三个主题；它与帕斯卡尔所说的「转移」同类，但「既少点儿什么又多点儿什么」。

判定只有一条主线：**是否「为生活本身而生活」**。命中隐遁的说法通常有三个标记：

1. 重心落在「以后」「下辈子」「某个伟大的理念」上——不是被计划的一件具体事，而是把整个生活的依据挪走；
2. 那个理念被允许「超越生活、使生活变得崇高、给生活注入意义」，即用具体生活为它服务，直到「任理念背叛生活」；
3. 它与「想望死亡」有直接关联，所以作者用了「致命」二字（L179）。

机制：隐遁把人对峙的核心从「此刻的世界」移走。注意力转向彼岸或理念之后，人就不必直面「不可理喻的世界 + 非弄清楚不可的愿望」这一冲突（ce02）。

两类典型样本，用于校准判定：**后世型**——把意义寄给「后世」，指望后代记得并评判（罗兰夫人即此型，书里判为「轻率咎由自取」）；**屏幕型**——用固定的万能解说遮挡荒诞（跳跃、神性、永恒、常人或理念的幻想），其对立形象是「无屏幕的公务员」。同源变体还有帕斯卡尔式的「消遣」与补编中卡夫卡的「助理们」（L787）。

判定之后做什么？识别出「抵押」之后，改写方向在自由一支：转入 `absurd-freedom`（「剥夺希望和未来意味着增加人的不可约束性」L325）。本卡只管识别，不负责改写。

## A1 — 书中的应用 (Past Application)

### 案例 1: 罗兰夫人——寄希望于后世
- **类型**: 书中转述（荒诞人 L451-467）
- **问题**: 一位历史人物把意义寄托在「后世」——指望后代引用、记得并评判自己的选择
- **方法论的使用**: 按本卡判据检验这一策略的重心位置：生活的依据被放到自己无法支配的未来目光上，当下经验被未来评价替换；作者把「后世」直接归入「被人称之为后世的那种可笑永恒」
- **结论**: 后世型希望不兑现担保——「这种轻率咎由自取」「后世倒乐意引用这个词，但忘了加以评判。后世对罗兰夫人漠然视之」
- **结果**: 书中判定：无法验证的彼岸（后世）承接不了生活的依据（该条是作者对史例的判词，非完整生平叙述）

### 案例 2: 「屏幕」清单——用跳跃遮挡荒诞
- **类型**: 书中演练（征服 L519-547）
- **问题**: 人如何在不直视荒诞的情况下维持平静？书中给出一份可逐项对照的遮蔽物清单
- **方法论的使用**: 逐项对照：各种形式的跳跃、匆忙跳入神性或永恒、沉溺于常人或理念的幻想——凡命中者即属「屏幕」，其功能是遮挡而非解决
- **结论**: 「所有这些屏幕都在遮挡荒诞」；只要屏幕在，荒诞就不被看见，人得以安心地待在原地；对立形象是「无屏幕的公务员」（不靠遮蔽而能正常生活的荒诞人）
- **结果**: 未说明（该段是判据清单与对照形象，不是事件）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 说出或听到「等我……就……」式的安排（等财务自由、等孩子长大、等退休），想知道它是支撑还是抵押
2. 打算为「更重要的东西」牺牲当下的具体生活，却把这说成负责
3. 行动的理由里出现「后人会记得／会评判」「对得起谁」这类无法验证的担保
4. 生活中有一个固定的万能解说（信仰、永恒、大众、理念），一遇到问题就回到它
5. 想检查某个「让生活更有意义」的安排，是否把生活本身抵押给了别处

### 语言信号

- 「等我……就……」
- 「现在忍一忍，以后就好了」「这辈子先这样」
- 「人总要信点什么」
- 「对得起自己／对得起这份期待」
- 英文: "once I…, then I'll really start living", "it'll all be worth it later", "I'm doing this for something bigger"

### 与相邻 skill 的区分

- 与 `absurd-structure` 的区别: 那条是总入口——先界定荒诞（分离、对峙、三要素）；本卡在结构清楚之后，判定**一种生活策略**是把依据放在生活本身还是抵押给别处
- 与 `absurd-freedom` 的区别: 两卡会在「等我……就……」上双触发。本卡只判「是不是隐遁型抵押」；那条处理「没有未来 → 行动自由」的转换与「自在自由」的无效。**同一句双触发属正常**：先判后改
- 与 `sisyphus-model` 的区别: 那条是抵押未来的反面形态（意识在场的当下、蔑视与幸福）；本卡给「命中／未命中」的判定，那条给正面模型

## E — 可执行步骤 (Execution)

1. **取原句**
   - 完成标准: 拿到那个说法或安排本身（用户自己说的，或听到的），逐字写下，先不改写
   - 判停条件: 若只有情绪描述而无具体策略，先请其还原原话；仍然只有情绪 → 本卡不适用（检测对象是生活策略，不是情绪）

2. **判据一：依据放在哪里**
   - 完成标准: 回答「它是为生活本身而生活，还是为生活之外的某个理念而生活？」——后者即登记为隐遁候选
   - 输入契约: 一句策略或信念的自然语言表述

3. **判据二：理念是否背叛生活**
   - 完成标准: 检验该理念是否被允许「超越生活、使生活变得崇高、给生活注入意义」，即用具体生活为它服务；是 → 判定成立
   - 输出契约: ①判定（隐遁／支撑性安排）②命中的判据 ③一句话理由

4. **机制定位与样本校准**
   - 完成标准: 指出它属于哪一类（后世型／屏幕型／转移式消遣），并标出命中的词（重心在「以后」「下辈子」「某个伟大的理念」，或存在固定万能解说）
   - 判停条件: 若它只是「安排未来的具体事务」——有期限、可核验、不要求生活为它服务 → 判为支撑性安排，不按隐遁处理
   - 备注: 「支撑」与「抵押」之间的量化判定线，**原书未给，需使用者自定**，并在输出中写明理由

5. **对置输出（改写方向）**
   - 完成标准: 对命中的策略给出一条改写方向（把依据放回当下可支配的时间），具体程序转 `absurd-freedom`
   - 输出契约: 判定 + 机制说明 + 改写方向

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把「有希望」当成道德问题来指责——检测对象是**生活策略**，不是情绪，也不是「这个人不够清醒」
- 情绪困扰或临床场景（持续低落、自伤念头等）——本卡不处理情绪，也不替代专业帮助
- 需要评估「生活得够不够充实」的时候：那属于 v06 数量伦理的判据，不是本卡的问题

### 作者在书中警告的失败模式

- 术语硬区分（g15）：书中的「希望」是**荒诞的对立面**（「假如我们承认荒诞是希望的对立面」L271），专指对下辈子生活的希望与宗教性希望。按常识义「希望是美德」来用，会把判定整个写反
- 术语硬区分（g16）：「隐遁／转移」不是「娱乐消遣」的字面义，也不仅指宗教——凡「不是为生活本身而生活」的寄托都算；补编中卡夫卡的「消遣」与「助理们」亦属同类（L787）。误读为「娱乐」会让判定完全失焦
- 隐遁带「致命」二字：书中把希望与「想望死亡」直接关联（L179），并把理念「背叛生活」写进定义
- 无法验证的担保不构成依据（罗兰夫人例）：后世、来世这类不受自己支配的彼岸，不能承接生活的重心

### 作者的盲点 / 时代局限

- **与 v06 数量伦理相邻但针对性不同**：本卡检测「生活抵押给别处」，v06 评估「经验数量」；同一条句子可能同时触发两者，属正常——两卡的判定口径需保持一致
- 「支撑性安排」与「逃避性抵押」的量化判定线，原书未给，需使用者自定并写明
- 书中的样本偏重宗教性希望与「后世」希望（1942 年语境）；世俗版本（财务自由、成就叙事、自救式忙碌）落在同一条判据上，但原书没有逐一讨论
- 底本限制：引文取自 **OCR 整理稿**（加缪《西西弗神话》，沈志明译，上海译文 2013 版），照抄原稿、含 OCR 形近字噪声；逐字转引前应先复核底本

### 容易混淆的邻近方法论

- `absurd-freedom`: 「等我……就自由了」句式的另一种判定。双触发时先由本卡判「是否隐遁」，再由那条给改写
- `absurd-structure`: 若使用者还说不清「荒诞」指什么，先过那条，再回来判生活策略
