# 自反性检查与诚实性纪律

## R — 原文 (Reading)

> 对观者来说，假如精神是有意识的，这种跳跃仍不失为荒诞的。精神要是以为清除了这种反常现象，倒将其全然恢复了。
>
> — 荒诞自由（L349）

## I — 方法论骨架 (Interpretation)

这是一条**元规则**：任何「到此为止、不再超越」的立场，都要过一次自反性检查——包括本书自己的荒诞推理。

检查的是什么：

1. **立场自身**。不是检查别人有没有跳跃（那是别的卡的事），而是问：我手里这个「不跳跃」的姿态，是不是已经变成新的地基、新的信条？
2. **机制**：意识在场时，连「拒绝跳跃」都可能被读作一次新的跳跃——把「不跳跃」绝对化，等于对「界限」的信仰。
3. **反噬律**：「精神要是以为清除了这种反常现象，倒将其全然恢复了」——把批判做绝，反而把被否定的东西请回来。
4. **校准**：诚实性 ＝ 「善于在令人眩晕的山脊上站稳」（L305），即守住「提问—尚未回答」的悬置状态，而不是急于用结论换取安宁。危险不在跳跃之后，而在跳跃前的微妙时刻。
5. **处置**：把这一风险作为**外显的边界声明**保留（写进结论或产物的 B 段），而不是掩藏；声明自反性本身就是本卡要求的动作。

定位说明：本卡是元规则，给其他卡片提供边界声明的写法，**不是一套独立方法论**（阶段 1.6 判定为 router，理由见下）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 自己的立场是「我什么都不信／我只相信能验证的东西」，想检查这句话本身要不要过检查
2. 交付一份分析或结论时，担心把「不跳到结论」变成了新的结论
3. 写作或评审需要一条可复算的自反检查步骤（给结论的边界声明找依据）
4. 与一位「只讲证据」的对话者争论，双方都声称自己没有立场
5. 复盘旧判断：当时以为停在界限内，事后发现其实是换了个地基

### 语言信号

- 「到这儿为止，不再往下想」
- 「我不做任何跳跃」「我不需要意义」
- 「我只相信我能验证的东西」
- 「这个问题问不出来／没有答案，就该停」
- 英文: "I just stop there", "no leaps, no faith", "I don't need meaning", "that's as far as I go"

### 与相邻 skill 的区分

- 与 `leap-detection` 的区别: 那条查**别人的跳跃**（四模式归类与哲学的自杀）；本卡只查**自己这个「不跳跃」立场**的风险——拒绝跳跃是否已被绝对化。顺序上：先用那条得出「某处发生了跳跃」，再用本卡复查自己的结论有没有同类风险
- 与 `absurd-structure` 的区别: 那条界定荒诞结构与荒诞感（对象层）；本卡不界定任何对象，只做一次立场自检（元层）

## E — 可执行步骤 (Execution)

1. **取立场**
   - 完成标准: 逐字写下那句「到此为止」的声明（自己交付的结论、或自己的立场句）
   - 输入契约: 一句可复述的立场表述；说不出则先请用户写出「我不再往下问」的那句话

2. **自反检查**
   - 完成标准: 回答「这个『不跳跃』是否已经被当成地基或信条？」；命中即登记为自反性风险
   - 判停条件: 若检查对象是**别人的**论证（对方跳跃了）→ 转 `leap-detection`

3. **反噬检验**
   - 完成标准: 追问「把批判做绝，是否反而把被否定的东西请回来了？」；给出会/不会的判定与理由

4. **诚实性校准**
   - 完成标准: 判定该立场是停在「提问—尚未回答」的悬置（山脊）上，还是已经用结论换取安宁；给出依据句
   - 备注: 「自反风险的量化判据」（多大程度算绝对化）**原书未给，需使用者自定**，并在输出中写明

5. **处置（外显化）**
   - 完成标准: 把风险写进产物——作为边界声明显式保留，而不是掩藏；同时写明该声明不构成新地基
   - 输出契约: ①立场句 ②自反检查结论 ③反噬检验结论 ④诚实性校准 ⑤外显化后的边界声明文本

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 拿来做别人的立场审判：它检查的是使用者自己（或所交付产物）的立场自反性
- 当作独立方法论使用：本卡是元规则（给其他卡用的边界声明），单独调用价值有限
- 情绪或临床场景（持续低落、自伤念头等）——本卡不处理情绪，也不替代专业帮助

### 作者在书中警告的失败模式

- 把「拒绝跳跃」绝对化，等于对界限的信仰——作者自己在 L349 承认了这一风险
- 反噬律：「精神要是以为清除了这种反常现象，倒将其全然恢复了」——把批判做绝，被否定之物反而被请回来
- 掩藏自反风险（不写进边界声明）会让产物以「已清除」的姿态出现，这恰是最不诚实的形态；危险在「跳跃前的微妙时刻」，不在跳跃之后

### 作者的盲点 / 时代局限

- **⚠ 证据量最小（NR-04，必须显著标注）**：本单元仅 **2 条候选**（f29、p12），是**全库最小的单元**、证据密度最低（task-18，coverage-audit 登记重要性：中）。**本卡边界结论的强度低于其他单元**，不得当作与其他卡同等可靠的方法论使用
- 书中对该主题只有两处原文（L305、L349），无法再补（needs-review.md NR-04）；阶段 1.6 判定为 router（判据 C1 未过：用户不会单独提出这个任务），建议作 `leap-detection` 的边界补充卡
- 「把风险外显保留」是作者的操作建议（f29 的判读），书中没有对应案例，其效果未被书中材料检验
- 底本限制：引文取自 **OCR 整理稿**（加缪《西西弗神话》，沈志明译，上海译文 2013 版），照抄原稿、含 OCR 形近字噪声；逐字转引前应先复核底本

### 容易混淆的邻近方法论

- `leap-detection`: 检测他人跳跃是本卡的前置步骤；先有那条的结论，再用本卡复查自身立场
- `absurd-structure`: 对象界定（荒诞结构）与立场自检（元规则）分工不同，不要用本卡替代结构分析
