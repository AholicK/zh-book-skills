# 决策规则速查 — 《悉达多》

| 能力 | 一句话规则 |
|---|---|
| 三艺（思考 · 等待 · 斋戒）——匮乏中的行动自由 | 先算清能撑多久，再用标准而不是焦虑来做决定。 |
| 石子沉水——目标已定后的不费力达成 | 目标定了就停止挣扎，把干扰逐项挡住，让节奏带你去。 |
| 倾听——不褒贬、不挑剔的接纳（听人 · 听世界 · 万声合一） | 对方在情绪里时，先把他没说完的话接住，而不是给建议。 |
| 向河学习——就地求教、重复深挖的处所式学习 | 选一处可以反复求教的「河」，留久一点，深挖胜过换新。 |
| 觉醒与离开——判定法义无法救我，走自己的路 | 检验体系里有没有人活成你想要的样子；区分「它不好」与「它不救我」。 |
| 认识「我」——不扼杀、不喂养的自我功课 | 警惕「我」藏在修行、自律与优越感里盘踞生长。 |
| 亲口品尝——从知识到体验的学习策略 | 分清「知道」与「经历」，选一件本周能做的最小的事去做。 |
| 轮回的识别与了断——走出消耗性重复 | 识别这场重复是不是「未受尽」，用行动了断，而不是靠意志硬扛。 |
| 唵的锚点——至暗时刻的紧急转向（含安全边界） | 先做安全分级：有风险就转介；轻度时刻用锚点中断、休息、重新评估。 |
| 伤口的转化——从溃烂到风化发光 | 伤口不是要被治愈，是要风化发光：停止舔舐，去讲给一个会听的人。 |
| 对亲人的放手——不以爱束缚，尊重他人的路 | 先问「我是否在用爱束缚他」和「我能否替他免于他的轮回」，然后放他走。 |
| 时间并不存在——当下圆满的视角转换 | 把「我已经晚了」放进河流视角里改写，再用「第一步动作有没有变化」检验它。 |
| 对世界说「是」——从比照评判转向接受与爱 | 停止把世界和理想的版本比照；爱它此刻的样子——从一块石头练起。 |
| 言辞的限度——何时停止说教（智慧不可言传的操作面） | 只能被体验的事，停止论证；把言辞换成陪伴与行动。 |
| 告别的结构——承认、离开、不回望 | 承认、承受、离开、不回望——告别的最低限度结构。 |
| 星与落叶——内心律法与轨道的定力自检 | 检查自己是在被风吹，还是内心有轨道；没有就先记录风从哪来。 |
| 游戏与投入——旁观式生活的自检 | 当「这无非是游戏」成为口头禅，给出一份押上署名的投入。 |
| 探求与发现——目标执着与自由敞开的姿态区分 | 「探求未止」不等于在前进；做一次没有目的地的发现实验。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
