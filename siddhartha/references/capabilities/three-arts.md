# 三艺（思考 · 等待 · 斋戒）——匮乏中的行动自由

## R — 原文 (Reading)

> “我会思考。我会等待。我会斋戒。”……“斋戒极好，先生。对于没有食物的人，斋戒最为明智。假如悉达多没学过斋戒，他今天就必须寻找活计。不论在你这里，还是别处。饥饿迫使他行动。而事实上，悉达多能安静地等待。他从不焦急，从不陷于窘迫。
>
> — 第二部·迦摩罗 L415；第二部·尘世间 L521（另见 L681“三种高贵又制胜的艺术”的回指）

## I — 方法论骨架 (Interpretation)

三艺不是三条戒律，而是一套把「匮乏」转成「行动自由」的组合技艺：

- **斋戒**＝不被匮乏驱使行动的能力。先算清「我实际能撑多久」，把「必须立刻赚钱／立刻出手」的压力从决策里拿掉——行为由标准驱动，不再由饥饿感驱动。
- **等待**＝目标已定后的不焦急、不窘迫。不是消极，是让时机成熟，同时不被沿途的催促改变节奏。
- **思考**＝把认知放在冲动之上：用筛选标准复核选项，而不是用情绪。
- **组合用法**：有目标时三艺并用（与 `stone-in-water` 同源）；没有目标时，三艺先保住行动的自由。

两个必须切割的误读：斋戒 ≠ 苦修式断食（沙门期的斋戒已被判定为「麻醉与逃避」）；等待 ≠ 拖延（它的前提是目标与标准已经写好）。

## A1 — 书中的应用 (Past Application)

> 本书为哲理小说；以下案例均为叙事虚构（`narrative_case`），不是作者亲历。

### 案例 1: 三艺亮相——「我会思考。我会等待。我会斋戒。」
- **类型**: 叙事虚构（第二部·迦摩罗 L391-419）
- **问题**: 悉达多请求迦摩罗做他的老师学习爱之艺，被问「你会什么？拿什么赚钱」
- **方法论的使用**: 他不报技能、不报学历，只答三艺；并以一首诗赢得对方的吻
- **结果**: 迦摩罗赐吻，并把他引荐给城中最富庶的商人——三艺开始在尘世中兑现

### 案例 2: 应聘考验——斋戒的用处（含「书写虽好，思考更佳」）
- **类型**: 叙事虚构（第二部·尘世间 L489-535）
- **问题**: 悉达多到商人迦摩施瓦弥处谋职，被问「斋戒有何益处」
- **方法论的使用**: 给出「斋戒极好」的完整辩护——不被饥饿驱使行动、能安静等待、从不焦急窘迫；随后通过读契约与写字考验，写下「书写虽好，思考更佳；聪敏虽好，忍耐更佳」
- **结果**: 商人夸他「写得精彩」，留他做事；悉达多得到衣裳、鞋子与住所

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 裸辞、断粮边缘，焦虑催促「随便先接一个 offer」
2. 求职/转型期内，被身边人反复催促「别挑了、先上车」
3. 项目延期、资源短缺时，想仓促做一个不可逆的决定
4. 想坚持自己的标准，但周围都在催、自己也开始动摇

### 语言信号
- 「等不了了，先接受再说」「再等下去就来不及了」「随便先选一个吧」
- 「我急着要钱/要结果」「先活下来再说，别的以后想」
- 英文: "I can't afford to wait", "just take the first offer", "I need money now"

### 与相邻 skill 的区分
- 与 `stone-in-water` 的区别: 本卡处理「匮乏中的自由」（还没有确定的目标时怎么不被压力推着走）；`stone-in-water` 处理「目标已定后怎么不费力地推进」
- 与 `breaking-the-cycle` 的区别: 本卡不识别沉沦模式，只处理资源压力下的决策姿态
- 与 `time-perspective` 的区别: 后者处理「我已经晚了」的时间焦虑（视角层），本卡处理「我撑不住了」的资源焦虑（行动层）

## E — 可执行步骤 (Execution)

1. **清点底线（斋戒的前提）**
   - 输入契约: 当前匮乏项（钱/时间/机会）+ 可量化数据（存款月数、可等待窗口、最坏情形）
   - 完成标准: 写出「我至少还能撑 N 个月／天」的具体数字
   - 判停条件: 若无法量化（收入为 0 且无处可去），先协助把生存底线列出来再继续；生存无解时本卡不适用，先处理现实支持

2. **斋戒：冻结被匮乏胁迫的动作**
   - 完成标准: 列出「如果不被匮乏驱使，我本不会做」的动作清单，并逐条标为「暂停」（如：不接受不符合标准的选项）

3. **等待：写下筛选标准与观察窗口**
   - 完成标准: 3 条筛选标准 + 一个最短观察期（阈值由使用者自定，原书未给「度」）

4. **思考：用标准复核，而非情绪**
   - 完成标准: 用标准复核已有候选，输出「保留 1-2 个选项 + 放弃项及原因」

5. **定期复核**
   - 完成标准: 每个观察期结束时问一次「压力有没有回来、标准有没有被改」；标准被改需写出理由
   - 输出契约: 一张「三艺自检表」= 底线数据 / 暂停清单 / 筛选标准 / 复核结果

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 真正需要即时行动的场合：人身安全、医疗、紧急事务——先处理，后自检
- 把「等待」当成拖延或不作为的借口（检查点：标准与时间表是否已写下）
- 无任何资源支撑、生存未解的人——先解决生存，再谈行动自由

### 作者在书中警告的失败模式
- 压制反弹（ce04）: 把斋戒做成与欲望的苦斗，越压制越反弹——书内原文「他压制渴望，又收获新的渴望」
- 遗弃三艺（ce26）: 有饭就不斋戒、有捷径就不等待、有现成答案就不思考——「先停用，后失效」，他的「宝、力、不变的支撑」是这样丢的
- 苦修＝麻醉（ce03）: 把三艺做成逃避痛苦的修行——与酒鬼同构，方向已错

### 作者的盲点 / 时代局限
- 斋戒与等待的「度」与训练法，书中全部未界定（NR-02）——阈值只能由使用者自定，不要伪造原书标准
- 主角总能全身而退（批判节：代价被叙事豁免）——不要用「悉达多也这样走过来了」为风险背书

### 容易混淆的邻近方法论
- `stone-in-water`: 「会什么」与「怎么走」互为表里——目标已定时用后者，目标未定时先守住前者
- `time-perspective`: 一个处理资源焦虑，一个处理时间焦虑，可先后配合
