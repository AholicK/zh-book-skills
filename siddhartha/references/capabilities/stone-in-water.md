# 石子沉水——目标已定后的不费力达成

## R — 原文 (Reading)

> 如果你将一粒石子投入水中，石子会沿着最短的路径沉入水底。……悉达多什么都不做，他等待、思考、斋戒。他穿行于尘世万物间正如石子飞入水底——不必费力，无需挣扎；他自会被指引，他任凭自己沉落。目标会指引他，因为他禁止任何干扰目标的事情进入他的灵魂。
>
> — 第二部·迦摩罗 L477

## I — 方法论骨架 (Interpretation)

这是一条关于「执行姿态」的机制，不是关于「如何努力」的技巧：

- 前提：目标已经确定，且决心已经下过（机制不处理「要不要做」，只处理「已经决定之后怎么走」）。
- 动作一：**停止挣扎性动作**——不用蛮力推进，不做报复性冲刺、不演给自己看。
- 动作二：**屏蔽干扰**——「禁止任何干扰目标的事情进入他的灵魂」：把干扰逐项列出，再为每一项设计一道屏障（关闭推送、固定拒绝话术、清理触发环境）。
- 动作三：**维持常规节奏**——等待、思考、斋戒照常运行，让方向由目标接管。
- 效果：行动像石子下沉一样沿最短路径前进——抗拒消耗下降，判断不被扰动。

注意：它描述的是「笃定之后的轻盈」，不是「不行动」。而且「禁止干扰进入」与执念在形式上同构——所以前提（目标本身是否值得）必须先被验证。

## A1 — 书中的应用 (Past Application)

> 本书为哲理小说；以下案例为叙事虚构（`worked_example` 为叙事内呈示的教学情境）。

### 案例 1: 石子沉水的演示（全书的唯一完整演示）
- **类型**: 叙事内教学情境（`worked_example`，第二部·迦摩罗 L469-477）
- **问题**: 迦摩罗问悉达多「如果没有我你会怎样」，实际上是追问他的行事方式
- **方法论的使用**: 他用「石子沉水」说明：有了目标并下定决心之后，什么都不必做——只是等待、思考、斋戒，禁止任何干扰目标的事物进入灵魂，目标自会指引他
- **结果**: 迦摩罗被说服（「或许是的」）。后文亦有两处印证与反证：他确实顺利成为商人；而离开河边入世后不再练习三艺，机制的效力随之消失（L681 回望）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 备考（如 CPA）、求职、写作等长期目标，已被推送、聚餐、邀约反复打断
2. 方向定了，却每天在「要不要换一个」的动摇里消耗自己
3. 执行计划总被打乱，归因于「意志力不够」而不是「干扰没被屏蔽」
4. 冲刺型作息（报复性熬夜、自我感动式加班）带来反噬

### 语言信号
- 「目标是定了，但总被打断」「每天都在动摇，要不要换方向」
- 「我是不是该换一个目标」「计划执行不下去，我太没毅力了」
- 英文: "I keep getting distracted from my goal", "should I switch goals again"

### 与相邻 skill 的区分
- 与 `three-arts` 的区别: 那条是「匮乏中保住行动自由」（还没有目标时）；本卡是「目标已定后不费力地推进」
- 与 `breaking-the-cycle` 的区别: 如果这个目标本身已被证明是消耗循环（每次同样收场），应先读轮回识别，而不是继续「沉水」
- 与 `time-perspective` 的区别: 本卡不辩论目标对错，也不处理时间焦虑；只处理执行姿态

## E — 可执行步骤 (Execution)

1. **验证前提（判停点）**
   - 输入契约: 一句话目标 + 「为何是它」的一句依据
   - 完成标准: 写出目标与依据；依据不是「因为焦虑」或「因为别人都有」
   - 判停条件: 若目标是焦虑驱动或未经检验 → 不适用本机制，转 `three-arts` 或 `leaving-the-teacher`

2. **写下唯一目标**
   - 完成标准: 一句话，不含"或者/也许"的并列项

3. **列干扰源，逐项设计屏蔽动作**
   - 完成标准: 每个干扰源（3-6 个）配一个**具身动作**（关闭推送、固定拒绝话术、调整物理环境），不能只写「我要自律」

4. **停止挣扎性动作**
   - 完成标准: 列出并在执行中停用（报复性熬夜／冲刺式自我感动／反复比较进度）

5. **维持节奏 + 每周复核**
   - 完成标准: 写出每日/每周固定节奏；每周一次检查「干扰有没有重新进入、屏蔽是否失效」
   - 输出契约: 目标一句话 + 「干扰 → 屏蔽」对照表 + 节奏表

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **目标本身未经验证时**（写死的边界）：赌徒与偏执者同样能「禁止干扰进入灵魂」——机制与执念同构；目标是否值得，先用 `leaving-the-teacher` 的检验或外部反馈核实
- 目标已被事实证明是消耗循环时：转 `breaking-the-cycle`
- 涉及安全、伦理或法律风险的目标：直接停止

### 作者在书中警告的失败模式
- 把一切非目标之物判为「障碍」（ce29）: 千万人把河视作障碍，只有「为数不多的四五人」凝神听水——目标化过度的代价是错过沿途
- 低估环境（ce15）: 「尘世生活其实简单」的无防备进入，正是被俘获的开始
- 半吊子（ce24）: 玩不进去也回不去，两边都不产生真实结果
- 探求者错过眼前（ce37）: 目标导向会窄化感知——求道本身可能成为遮挡道的墙

### 作者的盲点 / 时代局限
- 目标错误时的处置，书中未讨论（NR-03）——本卡以「前置验证」补注，并声明这是流水线补注而非原书内容
- 「屏蔽干扰」的具体做法未展开——由使用者落地，保持可检查即可

### 容易混淆的邻近方法论
- `three-arts`: 共享同一机制（思考/等待/斋戒）——目标未定时先读三艺
- `leaving-the-teacher`: 用于检验「要不要继续走这条路」——与本卡构成「验证 → 执行」的前后关系
