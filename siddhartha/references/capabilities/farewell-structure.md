# 告别的结构——承认、离开、不回望

## R — 原文 (Reading)

> 他已完全觉醒。他已走上自我之路。……“我已不再是过去的我。不再是苦行僧、沙门，不再是婆罗门。”……他重新迈开步子，疾步前行。他再也不回家，再也不回父亲那里，再不回去。
>
> — 第一部·觉醒 L327-331（完整实例见第一部·婆罗门之子 L89-141 的告别过程）

## I — 方法论骨架 (Interpretation)

告别是悉达多一生的「运动方式」：告别双亲及家园、朋友及老师、佛陀、挚爱、旧我。书里从未把它方法化，本卡给出的是**从叙事重建的最低限度结构**（如实标注：非原书程序性方法）：

1. **承认**——「我已不再是过去的我」：旧身份已不属于前路。写具体变化（事实），不写情绪。
2. **承受**——预告分离期的孤独与颤栗（书中意象：「苏醒的最后颤栗，分娩的最后痉挛」）；列出可预期的感受与应对，而不是当场压制它们。
3. **离开**——完成具体动作：告知、交割、离场（书中实例：伫立等待得到放行；「他重新迈开步子，疾步前行」）。告别可以是单方面的，但现实责任必须交割清楚。
4. **不回望**——「他再也不回家，再也不回父亲那里，再不回去」：写下禁止动作清单（回头谈判、找补、求证），并配置替代支持（新空间、新的关系）。

配套语境：c02（告别父亲）给出「伫立彻夜、等待放行」的具体过程——承认—坚持—放行；而译后记的「这些残酷的告别或许是人生真相」为**译者观点**，已转 reference，不作为方法证据（引用时必须标注「译者观点」）。

## A1 — 书中的应用 (Past Application)

> 本书为哲理小说；以下案例均为叙事虚构（`narrative_case`），不是作者亲历。

### 案例 1: 告别父亲——伫立彻夜，等待放行
- **类型**: 叙事虚构（第一部·婆罗门之子 L89-141）
- **问题**: 悉达多请求父亲允许他离家加入沙门；父亲拒绝并气愤离席
- **方法论的使用**: 他不争辩、不离开，双臂交叉在父亲房中伫立整夜——以「我会站着等待」回应父亲的每一句劝退；破晓时父亲见他双膝颤抖而面容不动，意识到「悉达多已不在他身边」，终于放行
- **结果**: 父亲抚摩他的肩膀放行，并留下话：若寻得幸福就回来教我；若只收获幻灭，那也回来。此后他再未回到父亲身边（书中多以「再未回去」回指）

### 案例 2: 了断与放鸟——告别执行后的不回望
- **类型**: 叙事虚构（第二部·轮回 L597-607）
- **问题**: 在芒果树下完成「了断」之后，如何执行告别
- **方法论的使用**: 他「起身告别芒果树和花园」，深夜离城，「一去不返」；迦摩罗同步放走金笼中的知更鸟、关闭宅邸、不见客——「放鸟」成为断念的象征
- **结果**: 两人各自完成了告别（一个离城，一个放鸟），此后再未回到旧生活

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 决定不再续约的长期合作（8 年），需要「怎么体面收尾」
2. 离开工作多年的公司；结束一段关系；搬离生活已久的城市
3. 完成一次「断念」式的转身：不想撕破脸，也不想反复回头
4. 想告别旧身份（一段职业、一种生活方式），但总在回望里动摇

### 语言信号
- 「该结束了，但不知道怎么开口」「我怕回头又动摇」
- 「最后一次……」「再试一次看看」
- 英文: "how do I end this properly", "I keep going back and forth"

### 与相邻 skill 的区分
- 与 `leaving-the-teacher` 的区别: 后者是「要不要离开」的判定；本卡是「如何完成告别」的执行结构——先判定，再告别
- 与 `breaking-the-cycle` 的区别: 后者识别「该离开的循环」并设计了断动作；本卡把了断扩展为完整的告别（含承受与不回望）
- 与 `transforming-the-wound` 的区别: 本卡处理「离开」，后者处理「离开后的痛」

## E — 可执行步骤 (Execution)

1. **承认（写下变化）**
   - 完成标准: 「我已不再是过去的我」的具体变化 3 条——事实性（作息/价值观/关系状态已变），不写情绪句

2. **承受（预告与应对）**
   - 完成标准: 列出 2-3 种可预期感受（孤独、颤栗、反复）与各自应对；**预先把「回头」的冲动写进清单**，并指定一个替代动作

3. **离开（动作清单）**
   - 完成标准: 告知 / 交割 / 离场三类具体动作 + 时间点；现实责任（债务、承诺、共同事务）必须逐项列清
   - 判停条件: 涉及法律程序（共同财产、监护、竞业）时，先咨询专业人士，本卡不替代

4. **不回望（禁区与支持）**
   - 完成标准: 禁止动作清单（回头谈判/找补/求证）+ 一个替代支持（新空间/新关系/新日常）
   - 输出契约: 告别计划（承认—承受—离开—不回望四段）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 把「不回望」读成「不告而别/抛弃责任」的借口——现实义务（债务、承诺、监护、共同事务）必须了结，书内对代价的豁免（批判节）不可照搬
- 情绪性告别（为赌气而断）——先用 `leaving-the-teacher` 的核查冷静一遍
- 涉及法律程序时：先专业咨询

### 作者在书中警告的失败模式
- 无专属反例（叙事中告别均顺完成）——已登记 NR-06：task-14 尚缺条件，本卡只给最低限度动作
- 认知无法行动（ce32 相邻）: 知道自己该走却走不了——把「承受」写实、把动作缩小，才可能启动

### 作者的盲点 / 时代局限
- **证据最薄的单元**（3 条主属）：结构自叙事重建、无程序性交代；「如何承受孤独」只有叙事句支撑
- 书中告别多为单方面、不回头，且代价被叙事豁免（伦理张力见批判节）——现实版本必须携带责任交割

### 容易混淆的邻近方法论
- `leaving-the-teacher`: 判定在前，执行在后——顺序不要颠倒
- `breaking-the-cycle`: 了断是告别的浓缩版；本卡是它的完整结构
