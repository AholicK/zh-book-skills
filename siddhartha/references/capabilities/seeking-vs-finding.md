# 探求与发现——目标执着与自由敞开的姿态区分

## R — 原文 (Reading)

> 一个探求之人，往往只关注探求的事物。他一无所获，一无所纳。因为他一心想着探求，被目的左右。探求意味着拥有目标。而发现则意味自由、敞开、全无目的。可敬的人，你或许确实是位探索者。但你却因努力追求目标，而错过了些眼前事物。
>
> — 第二部·乔文达 L967

## I — 方法论骨架 (Interpretation)

全书对「找」这件事本身的一次反思：**探求与发现不是程度差别，是两种姿态**。

- **探求**：有目标、被目的左右——「往往只关注探求的事物。他一无所获，一无所纳」。它是勤勉的，但因为只认目标，过滤掉了不合框架的一切，甚至包括已经出现在眼前的东西。
- **发现**：自由、敞开、全无目的——不是「努力找到」，是「允许被给到」。
- 配套的判据句：「一位真正的求道者……不会接受任何法义。但得道之人却认可任何法义、道路和目标」（L785）——姿态对了，什么都能用；姿态错了，什么都抓不住。
- 用法（三步＋一次实验）：识别自己的探求者倾向（在找什么、换了几个）→ 反向检查代价（最近因「只关注目标」错过的人/事/景）→ 做一次「发现」实验（不设目标、不做 checklist，只观察和记录）→ 接受「探求未止 ≠ 在前进」。
- **如实标注**：书内没有给出「如何从探求切换到发现」的步骤——本卡提供的是姿态对照与一次实验，不承诺转换。

## A1 — 书中的应用 (Past Application)

> 本书为哲理小说；以下案例均为叙事虚构（`narrative_case`），不是作者亲历。

### 案例 1: 乔文达——「你探求过多」
- **类型**: 叙事虚构（第二部·乔文达 L955-967）
- **问题**: 一生遵循僧规、受人敬重的乔文达说「我尚未停止探求，永远不会停止探求」；他自认仍是求道者
- **方法论的使用**: 悉达多却说「你探求过多」——探求者因执着目标而「一无所获，一无所纳」，错过眼前；「探求意味着拥有目标。而发现则意味自由、敞开、全无目的」
- **结果**: 乔文达「尚未完全明白」，留宿一夜后继续赶路——他两度与最亲密的朋友同处（被守候整夜、同宿一夜）而不相识，示例了这种过滤的代价

### 案例 2: 终身探求者的画像（失败侧）
- **类型**: 叙事虚构（第二部·乔文达 L961、L1019）
- **问题**: 追随过沙门、佛陀、乃至最后的悉达多的乔文达，为何到老仍不安？
- **方法论的使用**: 叙述者给出他的结局：眼中「写满永恒的探求和永恒的失落」——把「永远探求」当作使命的人，得到了探求者的勤勉与不满足
- **结果**: 未说明（书末他仍在向悉达多讨要「能领悟的话」）。含义：探求可以是止息的替身，且因其勤勉谦逊而无人（包括他自己）觉得有问题

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 每年换一种「自我提升体系」，越学越不安
2. 找老师、找方法停不下来；总觉得答案在下一个资源里
3. 与人、事相遇先问「这对我有什么用」，错过了眼前
4. 反复宣告「我还在找真正适合我的路」，但一直没上路

### 语言信号
- 「我还在找那个真正适合我的方法」「等我找到对的老师/课程就……」
- 「这个不是我要的，下一个会更好」「我不确定这是不是我的路（而从不检验）」
- 英文: "still looking for the right method", "maybe the next one is it"

### 与相邻 skill 的区分
- 与 `leaving-the-teacher` 的区别: 后者决定「离不离开、走哪条路」（决策）；本卡管「以什么姿态继续」（姿态）——离开之后若仍是探求姿态，会重演
- 与 `listening` 的区别: 「发现」姿态是倾听的底子（全无目的、敞开）；两卡共享同一气质
- 与 `firsthand-tasting` 的区别: 本卡处理「找」的心理与代价；后者处理「做」（把知识换成经历）

## E — 可执行步骤 (Execution)

1. **探求识别**
   - 完成标准: 列出最近的「探求清单」——在找什么、换过几个、每次多久

2. **代价检查**
   - 完成标准: 举出 1-2 个「最近因只关注目标而错过的人/事/景」的具体例子（带时间与细节）

3. **一次「发现」实验**
   - 完成标准: 一次没有 checklist、没有目标的观察记录（一段散步、一次会面、一小时的专注），只记录「看见了什么」

4. **语言改写**
   - 完成标准: 把「我又报名了 X」改写为「我从 X 里看见了什么」；并写下「探求未止不等于在前进」的自检句
   - 输出契约: 探求清单 + 代价例 + 发现实验记录 + 改写练习

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 需要明确目标的执行场景：本卡不反对目标，反对的是「被目的占据」——`stone-in-water` 与 `three-arts` 的目标执行不受本卡影响
- 用作放弃努力、拒绝方向的借口——「发现是自由敞开」不是「什么都不做」
- 与「设定目标（石子沉水）」的表面张力书内未完全消解：差别在被目的「占据」还是被目标「指引」——引用时两个词都要带上

### 作者在书中警告的失败模式
- 探求者错过眼前（ce37）: 「求道本身成了遮挡道的墙」——符合探求框架的信息优先，其余被过滤
- 终身探求不得安（ce38）: 「把‘永远探求’当作使命的人，得到了探求者的勤勉与不满足」

### 作者的盲点 / 时代局限
- 「如何从探求切换到发现」书内未给步骤（本卡不承诺转换，只给实验）；无专属关键任务（支撑型单元）
- 全书以乔文达为对照把「探求」设成失败者形象——这是叙事安排，不是对一切探索的判决；批判节提醒不要把叙事结论当作普遍规律

### 容易混淆的邻近方法论
- `leaving-the-teacher`: 一个管「走哪条」，一个管「怎么走」——姿态不对，换了路也白换
- `firsthand-tasting`: 从「找」里退出来的人，需要的是「去做」
