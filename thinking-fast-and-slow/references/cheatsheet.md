# 决策规则速查 — 《思考，快与慢》

| 能力 | 一句话规则 |
|---|---|
| 双系统总论与慢思考唤起 | 重要决定前先判定「此刻是谁在作答」：答案来得毫不费力，就放缓并自行构建答案 |
| 认知努力与自我控制（最省力法则与自我损耗） | 重要判断前先看精力与负荷：分不清「我不想做」和「我做不了」，就别靠意志硬撑 |
| 联想、启动与具身效应 | 先排查环境线索，再谈决定：让你做出某种选择的原因，可能根本没被你意识到 |
| 认知放松与可信度判断（流畅感不等于真相） | 流畅不等于真相：把「读起来顺」与内容证据分开记账，先问它为什么顺 |
| 替代机制与情感启发（我实际在回答哪个问题） | 先问「我实际在回答哪个问题」：写出目标问题与被偷换的问题，不等价就回到原题作答 |
| 连贯性、WYSIATI 与光环效应（去光环程序） | 去光环：把整体印象拆回分项证据，按维度跨对象评估、隐藏已打分并接受不一致 |
| 大数法则与小数定律（样本量检查与随机波动识别） | 极端结论先查样本量：小样本的极端结果多为随机波动，别当因果 |
| 锚定效应（识别、估值隔离与程序化防御） | 任何被考虑过的数字都会拉估值：先独立估计，再接触锚并程序化防御 |
| 可得性启发法（频率判断自查与印象来源排查） | 频率判断先自查：你答的是「想起的容易程度」，不是真实频率 |
| 风险感知与效用层叠（风险沟通与恐慌机制自查） | 风险判断先分开问、先查口径：分子分母齐备再谈要不要恐慌 |
| 典型性、基础比率与贝叶斯修正（概率判断的基率核查） | 概率判断先算基线：先问这一类有多少，再给证据打折扣 |
| 合取谬误与少即是多（概率嵌套与估值自查） | 细节越多概率越低：A 且 B 永远不可能比 A 更可能 |
| 因果基础比率改写：让统计事实进入判断 | 统计基率改写成因果句才会进入判断；改变观念靠令人惊讶的个体案例。 |
| 回归平均值：极端之后必然向均值靠拢 | 看到「极端表现→反向变化」先当回归处理：拆出运气成分、预测向均值收缩，宣布干预有效前先要对照组 |
| 直觉性预测的修正程序（基准线—直觉—折中） | 任何数值或概率预测都先给基准线，再按证据与目标的关联度从基准线向直觉值折中，并检查预测分布是否等于基率分布 |
| 后见之明、叙事谬误与结果偏见（按过程而非结果评估决策） | 复盘与追责一律评过程不评结果：先复原决策时点的信息集，清查「我早就知道」，用「事前能否预测」筛掉事后故事 |
| 有效性错觉与专家直觉：什么时候可以相信直觉 | 判直觉先看两条件与环境出处：规律环境＋长期带反馈练习＋预测记录，三者缺一即按有效性错觉处理，不采信自信度 |
| 公式优于直觉：让最终结果由公式给出（含结构化评分程序） | 低效度环境里让最终结果由公式给出：挑 6 个左右独立条件、1~5 分固定顺序打分、等权相加，只在「断腿」式罕见明确事实时例外 |
| 外部意见与规划谬误（参考类别预测三步法） | 任何工期/预算/收益预估先做参考类别预测：识别参考类别→取类别统计作出基准预测→只在有特别原因时才用本案信息调整基准 |
| 事前验尸（premortem）：以「已惨败」为前提穷举失败原因 | 决策将定、尚未下达决议时，以「设想已经惨败」为前提，让知情者各自独立书面写出失败缘由，再汇总回填风险清单 |
| 前景理论与损失厌恶：先定参照点，再把亏按更重的一侧计价 | 任何得失/风险判断先写参照点，再把「亏」按更重的一侧计价（损失厌恶系数书内口径 1.5~2.5，原文如此） |
| 禀赋效应：买卖价差诊断与商人式提问 | 同一物品分别问「最低愿卖价」与「最高愿买价」——差距显著即禀赋效应，用商人式提问改写后再估价 |
| 公平性、参照点与社会规范（定价与变革的公平性判读） | 涨价/降薪/改革先读参照点与损失归属：为自保转移损失可接受，为赢利强加损失不公平 |
| 概率权衡与四重模式（风险决策的定位矩阵） | 先按得失方向×概率高低把决策放进四格（左上规避/左下买彩票/右上孤注一掷/右下买保险），再做权重校正与期望值对照 |
| 罕见事件与风险表述（高估与过高权衡的自检） | 罕见事件分两量查：概率是否被高估（焦点归一化到100%）＋下注权重是否被过高权衡（生动性剥离后再估） |
| 宽框架与风险政策（把多个同类风险决策合并评估） | 把多个同类小风险决策合并成一个综合选择（宽框架）来评估，并逐条核对独立／不危及全部资产／赢面不太小三条适用条件，再写成风险政策 |
| 心理账户、沉没成本与后悔（钱不是同质的：定位账户再决策） | 钱不是同质的：先定位这笔钱被记在哪个心理账户，再拆掉沉没成本与后悔不对称，改按未来结果决策（并保留预算等建设性用法） |
| 框架效应与联合评估（同一事实换个说法，选择就变） | 同一事实换个说法选择就变：先做框架双查（存活率↔死亡率、收益↔损失），再用联合评估把单个判断放进同类背景，改写时不得改动任何事实数据 |
| 峰终定律与体验设计（记忆自己记分：峰值＋结尾，时长不计） | 回顾性评级≈峰值与结尾的平均、时长不计：先分清要减少痛苦记忆还是减少实际痛苦，再用「你是喜欢90秒还是只前60秒」校验偏好 |
| 幸福测量与两个自我（经验自我 vs 记忆自我） | 任何「幸福」判断先声明测的是哪个自我——经历（U指数/ESM/DRM）还是评估（生活满意度）——两套数据并列同报，不互相替代 |
| 机构决策与助推（把偏见防御制度化） | 机构把偏见防御制度化：决策四阶段质控＋检查表/参考类别预测/事前验尸工具箱＋独立意见、批评词汇与选择架构 |
| 校准程序：把信念变成可检验的区间（X90/X10 法） | 把信念变成可检验的区间：用 X90/X10 百分位法搭主观概率分布，以「98% 覆盖」验收线事后统计命中率，并固定引出程序 |
| 不变性检验：用多框架重述测试偏好稳定性 | 用多种框架重述同一决策并比对选择：偏好翻转即不变性被违背，该偏好不可用作决策依据，须回到单阶段等价问题重做 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
