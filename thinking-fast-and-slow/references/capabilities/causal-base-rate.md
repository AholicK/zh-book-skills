# 因果基础比率改写：让统计事实进入判断

## R — 原文 (Reading)

> 同一问题的两种表述从数学角度来看并没有区别，但从心理学角度来看则有很大不同。看了第一种表述的人并不知道怎样运用基础比率，通常会忽略它。相反，看到第二种表述的人会对基础比率给予一定重视……
>
> 当他们向学生展示令人惊讶的统计学事实时，学生什么也学不到；但当学生惊讶于个体案例时，例如知道两个友好的人对求救的人袖手旁观时，他们会立刻归纳并推断出帮助他人似乎比自己想象的要困难。
>
> — 第16章 因果关系比统计学信息更具说服力（L1940-2044）

## I — 方法论骨架 (Interpretation)

同一组数字有两种说法，效果完全不同：

- **统计学基础比率**：关于类别的事实总量，与单独事件无关（「这座城市85%的出租车是绿色的」）。
- **因果关系基础比率**：能改变你对单独事件看法的基率（「事故中85%是绿色出租车造成的」）。

判据：两种表述数学上等价、心理学上不等价。系统1 只处理有因果关联的信息——统计事实不改变对个案的看法，因果事实会。想让基率进入他人（或自己）的判断，就把「总体中有多少」改写成「某人或某原因造成了某结果」的因果句。

代价要一起算：因果化会顺带激活思维定式（把对团体的看法延伸到团体中每个成员）。社会规范反对这样做，但判断代价是真实的——可以主张「为更好的社会值得付这个代价」，不能一面要道德正确、一面否认代价。

改变观念（培训、说服、自我教育）的规则：**惊讶必须来自个体案例**。令人惊讶的统计学事实不产生学习；个案让人吃惊（两个友善的人没有施救）才会被立刻归纳出普遍结论。最有效的是让人从自己的行为中发现惊人事实。检验标准：学习是否发生，看对方对所处环境的理解是否改变，而不是能否复述事实。

判停点：对方只是复述了统计事实、判断与行为没变 → 学习未发生，回补个体案例或换场景。

## A1 — 书中的应用 (Past Application)

### 案例 1: 哈佛学生的鼓腮与皱眉实验
- **类型**: 作者亲历（第14章）
- **问题**: 增强系统2 的激活状态，能否提高「汤姆问题」（典型性 vs 基础比率）的回答准确率？
- **方法论的使用**: 作者与哈佛学生做实验，把问题与认知顺畅性结合——一半学生鼓起腮帮（与感情无关的表情），一半皱眉头（增强系统2 警觉、降低对直觉的依赖）。
- **结论**: 鼓腮组与原实验一样：只依赖典型性、忽略基础比率；皱眉组对基础比率明显更敏感。作者的解读：忽视基础比率有两个原因——忽视与懒惰，「懒惰」至少对哈佛学生是合理解释。
- **结果**: 皱眉组对基础比率敏感；鼓腮组仍只依赖典型性、忽略基础比率。

### 案例 2: 出租车问题的因果表述变体
- **类型**: 书中演练（第16章）
- **问题**: 同一数学问题换成不同表述，人们的判断会怎样变化？
- **方法论的使用**: 表述一给统计事实（两家公司拥有数量相同的出租车）；表述二改成因果形式——「在出租车造成的事故中，绿色出租车占85%」，读者立刻把基率读成「开绿色出租车的司机是一群莽撞的疯子」。
- **结论**: 统计学基础比率被轻视、甚至被忽略；因果关系基础比率被视为个别事件的信息，与具体细节结合起来使用。
- **结果**: 看到因果表述的人平均判断与运用贝叶斯定理得出的答案相差不多（41%，原文如此）；看到统计表述的人忽略基础比率。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要把统计结论讲给团队/客户/家人，对方听完没有任何反应或行动
2. 写汇报、做科普、做说服，发现对方只对故事有反应、对数据无感
3. 自己明明知道某个基率（行业成功率、发病率），却总在具体判断中用不上它
4. 在「使用群体统计」与「不要贴标签」之间被道德压力卡住，需要先把代价说清楚

### 语言信号

- 「数据都摆在这里了，他为什么就是不当回事」
- 「讲了一堆统计，大家还是照着个案感觉走」
- 「这个数字我知道，但一到具体的人就用不上」
- 「这么说会不会是在贴标签？」
- 「要讲个故事大家才听得进去」
- 英文: "the numbers don't land", "base-rate neglect", "make it about a person"

### 与相邻 skill 的区分

- 与 `bayes-base-rate` 的区别: 那条管**判断侧**——自己如何识别典型性、用基率做贝叶斯式修正；本卡管**沟通侧**——把基率改写成因果表述，让它进入他人（或自己）的判断，是前者的下游动作。
- 与 `outside-view` 的区别: 那条用参考类别三步法做预测修正（流程与制度）；本卡只解决单个基率的呈现形式（统计句 vs 因果句）。参考类别本质上正是把统计基率变成可用输入，本卡是它的最小可用单元。

## E — 可执行步骤 (Execution)

1. **取基率与目标**
   - 完成标准: 写出①原始统计句（「总体中有多少」）②它要影响的判断/决策
   - 输入契约: 一个统计事实 + 一个具体目标；缺任一先向用户补齐

2. **改写成因果句**
   - 完成标准: 新句写成「某人/某原因造成了某结果」形式，数字不变，读者能把它对号入座到个案
   - 输出契约: 原句 → 改写句对照（数字保留原书口径，必要时标注「原文如此」）

3. **算定式代价**
   - 完成标准: 写明改写激活了哪条思维定式、在哪些社会情境（招聘、评价、风控）不宜使用或需声明使用
   - 判停条件: 场景的社会规范敏感度高时，先与使用者确认是否接受代价，再决定是否改写

4. **配个体案例**
   - 完成标准: 每个关键统计结论配一个令人惊讶的个体案例；条件允许时，安排「让学习者从自己的行为中发现惊人事实」的体验（提问、小实验）
   - 判停条件: 对方只复述事实、判断未变 → 学习未发生，回到案例设计

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对方已经愿意接受、主动使用统计信息（因果化改写多余，还会引入不必要的思维定式）
- 不得把它做成「故事营销」技巧：本方案的立场是把**既有**统计事实改写成可用的形式，不是为没有根据的结论编造因果故事

### 作者在书中警告的失败模式

- 向他人展示令人惊讶的统计学事实→学生「什么也学不到」：把人只当统计数字，世界观不会被改变
- 把统计事实放在「类别」层面讲述、不落到个体案例——接受者会「默默地把自己排除在外」
- 忽视与懒惰：即使给出基率，人们也可能不用它（c114 中只有皱起眉头的一组才对基率敏感）
- 偏见无法从生活经验中自然学会：相关例子不会被恰当编码，激励与奖赏也不能消除判断错误（ce247）

### 作者的盲点 / 时代局限

- 学习迁移的方向不对称（普遍→特殊难，与特殊→普遍易如出一辙）——作者把这一点作为**限制**指出，而不是给了解法
- 改写手法依赖具体案例的生动性，存在被拿去操纵注意力的风险面；书内没有给出「生动性的正当边界」
- 思维定式的讨论未区分「有根据的定式」与「滥用的定式」在制度层面如何监管，只给了个体层面的权衡

### 容易混淆的邻近方法论

- `bayes-base-rate`: 与「统计素养」是一对——那条训练自己用基率，本卡负责让基率可以被别人用
- `outside-view`: 参考类别预测是把统计基率制度化变成可用输入；与单纯的句法改写相邻、但层级不同
