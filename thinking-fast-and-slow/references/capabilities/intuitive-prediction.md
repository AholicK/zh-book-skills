# 直觉性预测的修正程序（基准线—直觉—折中）

## R — 原文 (Reading)

> 按照以下4个简单步骤来做，我们就可以进行无偏见预测：…1.先估测出平均绩点的平均值。…2.根据你对证据的印象算出与之相匹配的平均绩点。
>
> ……
>
> 这个过程很接近一个恰当的统计分析可能会出现的结果。如果成功的话，这个过程就会使你作出的预测偏见越来越少，作出的可能性评估越来越合理，对各种数值作出的预测也越来越适度。前述两个过程意在解决同一种偏见，即直觉性预测总是过于自信或过于极端。
>
> — 第18章 如何让直觉性预测更恰当有效？（L2168-2325）

## I — 方法论骨架 (Interpretation)

诊断先行（作者自述与阿莫斯的实验）：被要求「预测」时，人们**总会将预测替换为对所描述问题的估测**，而且没有意识到自己回答的并不是被问到的问题。机制叫**强度匹配**——把证据给人的印象按强度换算成同一尺度上的预测值，于是「预测结果与支持这个预测的证据一样极端」（例：朱莉4岁能流畅阅读 → 猜她的平均绩点 3.7 或 3.8（原文如此））。预测里没有未来、没有不确定性，也就没有回归。

修正程序（四步，第18章）：

1. **估基准线**：估测目标变量的平均值（数值预测）或基础比率（概率预测）；
2. **算直觉值**：根据对证据的印象算出与之相匹配的值（保留直觉，它含信息，不要直接丢掉）；
3. **估关联度**：估计证据与预测目标之间的关联（共有因素占多大比重）；
4. **折中**：按关联度从基准线向直觉值移动——关联度是 0.3，就从平均值中抽出 30% 放到匹配值里（作者对「阅读年龄→平均绩点」的估计是「最多30%」）。

统一结构：一切修正都是「**基准线 ↔ 直觉反应之间的媒介**」。没有有价值的信息时坚守基准线；证据经严格验证时才可以坚守直觉；大多数情况下承认两者关联并不完美，给出中间的答案。**证据与目标联系越紧密，需要调整的余地越小。**

两条配套检查：

- **分布检查**：对一批对象做完预测后看等级分布——预测分布与真实基率分布相同（或更极端），就是完全没回归的信号（以色列军官学校实验：预测出的 A、B 频率几乎与结业成绩的 A、B 频率等同）；
- **小样本警觉**：印象越深刻、样本越小，极端表现越可能由运气造成，预测越要向基准收缩（金的面试惊艳但无实质成果，简的成果扎实但面试平淡——按学术能力作者会选简，尽管直觉偏爱金）。

适用条件与代价（作者自述）：修正是系统2 的费力任务，只有在「风险很高而你又特别渴望避免犯错误」时才值得做；代价是放弃极端值，也就放弃「我早就知道会这样」的愉快体验。

## A1 — 书中的应用 (Past Application)

### 案例 1: 以色列军官学校的评分预测实验
- **类型**: 作者亲历（第18章）
- **问题**: 以军选拔部队的工作人员平时就给候选人打分，作者请他们在常规评级之外，再预测每个学员将来在军官学校中可能得到的分数
- **方法论的使用**: 所有作预测的军官都知道学校采用字母评分以及 A、B、C 各等级的近似比例，因此可以检查预测分布有没有向真实分布收缩；共搜集了几百份预测
- **结论**: 实验结果令人惊讶——预测出来的 A 和 B 的频率几乎与学校结业成绩中的 A、B 等级频率等同：军官们用强度匹配把平时的评级直接换算成学校评分，对预测中（相当大的）不确定性完全没有作回归
- **结果**: 预测的 A/B 频率与实际结业成绩中的 A/B 频率几乎等同（作者据此指出这是「预测分布＝基率分布」的典型失败）

### 案例 2: 朱莉的平均绩点——直觉预测与四步修正
- **类型**: 书中演练（第18章）
- **问题**: 朱莉是州立大学4年级学生，4岁就能流畅阅读；她的平均绩点（GPA）是多少？
- **方法论的使用**: 先记录直觉答案（熟悉美国教育体制的人很快给出 3.7 或 3.8，与「4岁能阅读」这项证据一样极端，完全没有回归）；再按四步程序走：①估测平均绩点的平均值作基准线；②按证据印象算出与之匹配的平均绩点；③估计证据与平均绩点的关联度；④按关联度（作者估测最多 30%）从平均值向匹配值移动
- **结论**: 修正后的预测仍受直觉影响，但影响已被削弱、向平均值回归；步骤1提供基准线、步骤3使人离开基准线靠向自己的直觉
- **结果**: 作者估测共同因素最多占 30%（原文如此），修正后的预测介于基准线与直觉之间（具体数值原书未给）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要为一个具体对象预测下一个数值结果（GPA、业绩、投资回报、销售额、通过率），手头只有印象式的材料
2. 已经给出一批预测/评级（候选人、门店、项目），想检查整体是否偏极端、有没有回归
3. 一次面试或一份材料留下了强烈印象，正准备据此下判断或录用
4. 需要给出概率（谁更可能成功、这笔贷款会不会违约），手上只有基础比率和一点个案信息
5. 别人给出一个与证据一样极端的预测（「他这么优秀，结果一定好」），需要复核

### 语言信号

- 「他这么优秀，结果一定差不了」
- 「这个项目我很有信心，至少翻三倍」
- 「凭印象给个分吧，差不多就行」
- 「干这行靠的就是经验和眼光，还要算什么」
- 「面试太惊艳了，人就要她」
- 英文: "my gut says he'll do great", "I'm confident this is a three-bagger", "based on my impression of the evidence"

### 与相邻 skill 的区分

- 与 `regression-to-mean` 的区别: `regression-to-mean` 是理解侧（为什么极端之后必然回落、什么是数学事实），本卡是应用侧——把回归做成一套可执行的四步预测程序
- 与 `calibration` 的区别: 本卡处理单次预测的修正（基准线—直觉—折中）；`calibration` 处理一批预测的事后校准训练（给区间、统计命中率）——两者常配套：先用本卡出预测，再用校准统计命中率

## E — 可执行步骤 (Execution)

1. **判定是否值得修正**
   - 完成标准: 写下预测对象、目标变量、错误代价与是否「风险很高且渴望避免错误」；若非高代价场景，允许直接用直觉并在记录中标注「未修正」
   - 输入契约: 待预测的目标变量＋现有证据；缺目标变量口径时先问「你要预测的到底是哪个数、什么时间点」

2. **估基准线（步骤1）**
   - 完成标准: 给出目标变量的平均值或基础比率，并写明数据来源（历史均值、总体分布、已登记记录）；概率类预测用基础比率充当基准线
   - 判停条件: 找不到任何基准线数据 → 先补数据或明确写「基准线缺失，本次预测不可修正」

3. **算直觉值（步骤2）**
   - 完成标准: 按对证据的印象给出一个匹配值，并明确标注这是「对证据的估测」而非「对未来的预测」；自检——我的预测是不是与证据一样极端？换一个人带来同等强度的证据，我会不会给出同样的分数？

4. **估关联度并折中（步骤3、4）**
   - 完成标准: 给出证据与目标之间的关联度估计（书内示例为最多 30%（原文如此），通用参数原书未给，需使用者自定），并按该关联度从基准线向直觉值移动，输出折中值
   - 输出契约: ①基准线 ②直觉值 ③关联度及其理由 ④折中值；关联强则少收缩、关联弱则靠近基准线

5. **分布检查与小样本警觉**
   - 完成标准: 一批预测做完后，把预测的等级/区间分布与真实基率分布对照；若两者相同或预测更极端，整批向平均值收缩后再交付。对「一次见面、一次表现、几条信息」形成的强烈印象，注明样本量并按小样本打折
   - 判停条件: 环境毫无规律可言（预测目标不可学习）时停止使用本程序，直接放弃预测

6. **错误代价不对称检查**
   - 完成标准: 书面回答「哪一类错误更糟糕」；若错过极端赢家的代价远大于押错的代价（如只为寻找「下一件大事」的风险投资），允许保留极端预测，但必须写明这是主动选择的非无偏预测
   - 输出契约: 修正后预测＋「这是无偏预测还是有意保留极端值」的标注；同时说明代价——无偏见预测不会太离谱，也不会有「我早就知道会这样」的体验

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 错误代价不对称的场合直接套「回归折中」：作者明确给出例外——若一位风险投资家只为寻找「下一件大事」，他错过下一个谷歌或脸谱网的风险就会远远大于对刚刚创立的公司（最终破产）进行适度投资带来的风险；保守银行家则相反。此时允许极端预测，但要对自我诚实（这是主动选择，不是无偏预测）
- 毫无规律可言的环境：预测目标本身不可学习时，修正程序没有可用的关联度，也谈不上基准线
- 当作日常低风险预测的例行公事：作者明说修正是系统2 的费力任务，只在风险很高且渴望避免错误时才值得做

### 作者在书中警告的失败模式

- 预测被替换为对描述的评估且不自知：两组受试者（一组估描述印象、一组预测未来绩点）给出完全相同的答案，这是「替换存在」的最佳证据（ce95）
- 预测分布＝基率分布（完全没回归）：军官学校的 A/B 频率与结业成绩几乎等同（ce94）
- 只凭直觉印象给极端预测：印象越深刻越容易给出与证据一样极端的数值，而信息样本越小越应回归

### 作者的盲点 / 时代局限

- 折中的具体权重（相关系数）在现实中难以估准：作者自己给「阅读年龄→平均绩点」的估计也只是「最多30%」，并说明证据与预测联系越紧密需要调整的余地越小；书给的是程序而不是保证，通用参数原书未给，需使用者自定
- 程序假定「基准线可得、证据效度可估」，这两项在数据稀薄或环境快速变化时都难以成立（书中未展开此情形）
- 追求无偏预测的代价被作者如实保留：无偏见预测永远不会太离谱、不会有极端值，因此也不会有「我早就知道会这样」的愉快体验——使用者需自行承担这一取舍

### 容易混淆的邻近方法论

- `regression-to-mean`：先懂回归（极端值之后为什么必然回落），本卡才谈得上把回归做进预测；两者是理解与应用的衔接
- `calibration`：都靠「给区间、事后统计命中率」的思路训练，但 `calibration` 管一批预测的事后校准，本卡管单次预测的事前修正
