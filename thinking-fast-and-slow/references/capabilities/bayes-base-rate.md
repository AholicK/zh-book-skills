# 典型性、基础比率与贝叶斯修正（概率判断的基率核查）

## R — 原文 (Reading)

> 典型性的第一宗罪就是，它过于喜爱预测不可能发生的（低基础比率的）事件。…典型性的第二宗罪是它对证据质量不够敏感。
>
> ……
>
> 如果你相信某个候选人当选总统的概率是30%，并且相信他在首次竞选成功后再次当选的概率是80%，你就必须相信他连任的概率是24%。…第一，基础比率十分重要，即便是在手头的案例已有证据的情况下依然如此；第二，通过分析证据得到的直观印象通常都会被夸大。
>
> — 第14章 猜一下，汤姆的专业是什么？（L1621-1763）

## I — 方法论骨架 (Interpretation)

核心判据：**被问「概率有多大」，你答的往往是「它像不像那一类人的典型形象」。**概率问题难、相似性问题易，系统1自动把问题置换了（f63、p92、g13）。替换不分专业与业余——114 名上过几门统计学课程的心理学研究生，对 9 个专业「概率」的排序与「和典型形象相似程度」的排序并无太大差别（c113）；连深知基础比率作用的统计学家道斯，看到汤姆的性格描述后第一反应也是「计算机科学」（c112）。

**典型性的两宗罪**（f64）：①偏爱不可能发生的（低基础比率的）事件——地铁里读《纽约时报》的人更可能是「没有大学文凭」而不是「有博士学位」（c116、p93）；②对证据质量不够敏感——原则上知道「不值得信任的信息就相当于没有信息」，但眼见即为事实，除非当即否定它，系统1会把它自动视为真实（p94、ce80）。

可执行程序（本卡的可执行核心）：

1. **先算基线**：没有任何个案信息时，概率＝该类别的规模占比（汤姆读某专业的概率＝该专业招生比例）（f62、p91）。
2. **再用证据修正，并给证据打折扣**：后验 ∝ 基础比率 × 似然比——书中口径：基率 3%、似然比 4 → 11%；同样的似然比在基率 80% 时给出 94.1%（原文如此）（f65、p99）。
3. **两源合成**：统计学基础比率与具体证词都要计入。出租车问题：蓝色车基率 15%＋目击者辨认正确率 80% → 贝叶斯答案是 41%（原文如此）；只抓证词的普遍答案是 80%（f72、p110）。
4. **概率自洽检查**：P(A)+P(¬A)=100%；P(A∧B)=P(A)×P(B|A)——当选 30%×再次当选 80% 必须等于连任 24%；明天某个时候下雨 40%，早晨下雨就不可能 50%（p98）。
5. **强行唤起系统2**：提示「像统计学家那样思考」就能促使人们使用基础比率信息，「像临床医生」则相反；皱眉（认知紧张）的学生对基率明显更敏感（f67、p96）。需要统计判断时用明确角色提示、放慢节奏、要求书面核对，而不是指望「给了数据就够了」。
6. **区分失误的两类原因**：系统1引起错误直觉、系统2采纳它；原因一是忽视（有个人信息时认为基率与问题无关），原因二是懒惰（没把注意力集中在任务上）——处方要分别针对知识与投入（p97、ce81、ce82）。

两条必须记住（书内总结，f65、p100）：**①基础比率十分重要，即便是在手头的案例已有证据的情况下依然如此；②通过分析证据得到的直观印象通常都会被夸大**——所以要质疑自己对证据的分析。作者自述：意识到自己从未学过怎样运用这两条理念时非常震惊，即使现在实践时仍感到不自然（p100）。因此本卡不是「知道就会用」，而是一条必须走的流程。

（先验概率本身从哪来：**原书未给，需使用者自定**，并把来源与不确定度写在结论里。）

## A1 — 书中的应用 (Past Application)

### 案例 1: 罗宾·道斯的「计算机科学吗？」
- **类型**: 作者亲历（第14章）
- **问题**: 作者清晨打完汤姆问题的描述后，第一位到办公室的是同事罗宾·道斯——经验丰富的统计学家、直觉判断有效性的怀疑者；如果谁能想到基础比率，就该是他
- **方法论的使用**: 直接把刚打出的问题拿给他，请他猜汤姆的专业（描述是按计算机科学学生的典型形象刻意设计的）
- **结论**: 道斯看着问题，第一反应仍是「计算机科学吗？」——个性化描述触发典型性印象并主导判断；**「知道」基础比率重要，不等于当下会用**，连专家也要被提醒才更正
- **结果**: 道斯最初凭直觉答「计算机科学」，一提到「基础比率」即很快更正；作者称那是「令人开心不已的时刻」（c112、ce78）

### 案例 2: 出租车问题——贝叶斯 41% vs 普遍答案 80%
- **类型**: 书中演练（第16章）
- **问题**: 一辆出租车在夜晚肇事后逃逸；城中 85% 的出租车是绿色、15% 是蓝色；目击者辨认肇事车是蓝色，其辨认可靠度 80%（错误率 20%）——该车是蓝色的概率多大？
- **方法论的使用**: 把两个信息源——统计学基础比率（颜色比例）与目击证词——用贝叶斯定理结合起来，而不是让最有画面感的证据独占判断
- **结论**: 正确答案是 41%（原文如此）：证词强烈指向蓝色，基础比率又把它拉回一些；人们面对这个问题会忽略基础比率、只考虑目击者的因素
- **结果**: 贝叶斯答案 41%；最普遍的答案是 80%（c123、f72、ce87）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要判断「他属于哪一类」「这事会不会发生」，手里却只有一个生动描述或一次面谈
2. 招聘、诊断、投资、信贷、业绩预测场景里凭「像不像」下结论，需要补上基率
3. 自己或他人给出的多步概率互相矛盾（说 40% 下雨又说明早 50%；30%×80% 却写成 50%）
4. 面对「统计事实＋具体证词／个案信息」冲突，需要合成而不是二选一
5. 想给评审流程加一道强制基率复核，或需要一套话术说服对方先看基率

### 语言信号

- 「他一看就像个……」
- 「描述这么具体，肯定就是它了」
- 「统计数据跟这个案子没关系」
- 「我的第一反应是……」
- 「目击者／当事人自己都这么说了，还有别的可能吗」
- 英文: "he looks exactly like a ...", "that stat doesn't apply to this case", "my gut says 80%"

### 与相邻 skill 的区分

- 与 `question-substitution` 的区别: 相似性替代概率是替代机制的经典实例——本卡做概率判断的基率与自洽核查；替代机制的完整清单与「难问题被换成了什么」归 `question-substitution`
- 与 `law-of-small-numbers` 的区别: 同属统计素养两张卡——本卡管「起点概率（基率）与证据的合成」；小样本结果被过度解读、对样本量不敏感归 `law-of-small-numbers`
- 与 `conjunction-fallacy` 的区别: 同族但问法不同——本卡问「这一类到底有多少（有多少 vs 像不像）」；`conjunction-fallacy` 处理概率嵌套（A∧B ≤ A）与估值中的「少即是多」
- 与 `causal-base-rate` 的区别: 本卡是判断侧（自己怎么算）；`causal-base-rate` 是沟通侧——把统计基率改写成对方会用的因果表述

## E — 可执行步骤 (Execution)

1. **定格概率问题**
   - 完成标准: 写下①要判断的问题（他/它属于哪一类；某事件会不会发生）②当前的直觉答案 ③你说得出的理由
   - 输入契约: 一个待判的概率问题＋已有的个案信息（描述、证词、观察）；不足时先问「你要判断的是哪一类归属、手上有什么证据」

2. **算基线**
   - 完成标准: 给出相应类别的规模占比（招生比例、患病率、故障率、复现率等）及其来源；无数据则标注「无基率数据」并说明该判断只能作定性参考（**获取基率的方法原书未给，需使用者自定**）
   - 判停条件: 类别本身定义不了（问题模糊）→ 回第 1 步重述问题，不得直接跳到个案判断

3. **给证据打分并合成**
   - 完成标准: ①标注每条证据的可信度；不可信的信息按「相当于没有信息」处理，且必须写出明确否定它的理由（不否定就会被系统1当成真的）②按「后验 ∝ 基础比率 × 似然比」算一次（书内口径：基率 3%、似然比 4 → 11%；基率 80% → 94.1%，原文如此）③证据与基率指向相反时，两者都写进结论
   - 判停条件: 证据不可信且无法否证 → 判断停在基线附近（f74）

4. **自洽检查**
   - 完成标准: 逐项验算 P(A)+P(¬A)=100% 与 P(A∧B)=P(A)×P(B|A)（30%×80%=24%）；发现矛盾就回改，不允许两条并存
   - 输出契约: 一份「基线 → 证据 → 后验 → 自洽验算」四行记录

5. **唤起系统2并记录责任类型**
   - 完成标准: 用角色提示（「像统计学家那样思考」）＋放慢节奏＋书面核对强制复核；把本次失误归类为「忽视（以为基率与问题无关）」或「懒惰（没把注意力放在任务上）」，并写明下次的加固动作（清单、提示语、他人复核）
   - 输出契约: ①原始直觉答案 ②基线（含来源或「无数据」）③证据可信度与合成后的概率 ④自洽检查结果 ⑤失误类型与加固动作

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 信息极少但必须快速反应的场合（安全、急救、抢答式决策）：贝叶斯式核查需要时间与数据，先按现有证据行动，事后补核查
- 不要把它做成「凡直觉必错」的教条：作者给出的是**两级责任**——系统1引起错误的直觉，系统2采纳了这个直觉（p97）；直觉在日常判断中仍是省力且多半有效的起点，本卡只要求「以直觉为起点、让基础比率在预测时起主导作用」（p95）

### 作者在书中警告的失败模式

- **只凭「像不像」下概率判断**（史蒂夫问题）：美国农民与图书管理员的比例超过 20∶1（原文如此），受试者仍忽略统计数据、只依赖相似度选图书管理员（c03、ce04）
- **忽略基础比率，或在有具体信息时完全抛弃它**：汤姆问题中 114 名上过统计学课程的研究生把概率排序排成了相似度排序（c113、ce77）；附录 A 的工程师/律师实验里，连「迪克」这种与职业无关的描述也把先验概率从 0.7／0.3 抹平成 0.5——**无用的证据比没有证据更糟糕**（c306、ce240）
- **对证据质量不敏感**（f64、p94、ce80）：明知描述来自不一定有效的测试，判断仍按描述内容自动运转
- **概率不自洽**（p98）：30%×80% 写成 50%、某个时候下雨 40% 又说早晨下雨 50%
- **「知道≠会用」**（ce82）：放松状态下基率知识处于「知道」状态却不被应用，只有付出特别努力时才用得上（皱眉带来不同结果，说明懒惰是忽视基率的合理解释）——所以流程与检查点比提醒重要

### 作者的盲点 / 时代局限

- 贝叶斯修正的数值前提（先验概率／基率）本身常无据可依：原书未给获取与校验基率的方法，需使用者自定；把估计出来的基率当成客观数据同样是风险
- 责任链是两级（p97）：系统1引起、系统2采纳——不能只怪直觉，也不能只做「提醒」，要同时改「知识」（基率相关）与「投入」（强制努力）两条路径
- 案例多为实验室例题与旧数据（美国农民/图书管理员 20∶1、出租车 85%/15%、附录 A 的 70/30 样本，原文如此）；书中还标注了「统计学家也高估小样本结果的可复现性」，说明本卡的受众包括专业人员，但其数值不得当普适常数

### 容易混淆的邻近方法论

- `question-substitution`：相似性替代是替代机制的经典实例——机制清单归它，概率核查归本卡
- `law-of-small-numbers`：同属统计素养两张卡——本卡管基率与证据合成，它管样本量与「小数定律」
- `conjunction-fallacy`：同族（像不像 vs 有多少）——概率嵌套与估值里的「少即是多」归它
- `causal-base-rate`：v13 是沟通侧——本卡算给自己，它负责把统计基率改写成别人会用的因果表述
