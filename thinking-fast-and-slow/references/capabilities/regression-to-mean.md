# 回归平均值：极端之后必然向均值靠拢

## R — 原文 (Reading)

> 弗朗西斯·高尔顿用了好几年的时间才确定相关性和回归性并非两个概念—它们只是从不同视角对同一个概念作出的阐释。这个概念的原则很简单，但是影响却很深远：只要两个数值之间的相关度不高，就会出现回归平均值的情况。
>
> ……
>
> 或许学员某一次非同寻常的糟糕表现招来了教练的怒吼，因此接下来的进步也和教练没什么关系。这个教练把不可避免的随机波动与因果解释联系起来了。
>
> — 第17章 所有表现都会回归平均值（L2045-2167）

## I — 方法论骨架 (Interpretation)

核心判据（转述自高尔顿，第17章）：**相关性不完美 → 回归必然出现**。两个数值的共有因素不足 100%，极端值在另一侧就会向平均值靠拢；这不是因果，而是数学事实（作者自述：运动员第一跳与第二跳之间不存在因果关系，运气在其中起了很大作用）。

给一次表现建模：**表现 = 稳定成分（天赋/水平）＋ 波动成分（运气）**（作者自述：成功=天赋+运气；巨大的成功=更多的天赋+更多的运气）。预测下一次时保留稳定成分、把运气成分按平均值处理——好成绩向下修正、坏成绩向上修正，且「原始数据越极端，我们所期待的回归就越明显」（L2045-2167）。两次测量的共有因素越多，可保留的偏差越大；共有因素接近零，预测就直接贴回平均值。

先问三句，再谈因果：

1. **这是不是同一主体的重复测量？** 是 → 第一假设就是回归，不是「他变了」；
2. **两个量的共有因素占多大比重（相关系数）？** 越低，回归越强；
3. **观察到的那个「因果动作」（怒吼、表扬、治疗、培训）是否恰好发生在极端表现之后？** 是 → 它很可能是冒名者。

用途分两支：**解释侧**——绩效反馈、教育、体育、门店与政策解读，先把随机波动摘出去；**预测侧**——把上一期的极端值当成含运气的观测，下一期预测向均值收缩（与 `intuitive-prediction` 的四步修正衔接）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 以色列空军飞行教练的课堂反驳
- **类型**: 作者亲历（第17章）
- **问题**: 作者讲完「对良好表现的嘉奖比对错误的惩罚更有效」，经验最丰富的一位教练举手反驳：他对完美的特技飞行动作表示赞许，飞行员下次尝试同样动作时通常表现差一些；对没执行好的学员大声怒吼，他们基本上下一次表现得更好——「事实恰恰相反」
- **方法论的使用**: 判定这位教练的观察可否由奖惩解释——受表扬者是因为表现远超平均值才受奖，回落是回归；挨骂者是因为极端糟糕的表现被吼，进步也是回归；把两次表现都拆成「稳定成分＋当天的运气」
- **结论**: 教练的观察精明到位，推断却彻底错误：奖励与惩罚之间毫无关系，他把不可避免的随机波动与因果解释联系了起来，陷入「惩罚有效」的偶然性困局
- **结果**: 作者称这次经历带来了他职业生涯中最引以为豪的发现；教练们对代数方法没兴趣，他后来改用现场演示说服他们

### 案例 2: 粉笔靶子与背身投硬币的现场演示
- **类型**: 作者亲历（第17章）
- **问题**: 教练们对概率预测的代数方法毫无兴趣，怎么让他们亲眼看到回归
- **方法论的使用**: 用粉笔在地上画一个靶子，请房间里每一位教练转过身去、背对靶子向里面接连扔两枚硬币，测量两枚硬币到靶心的距离并按第一次投掷的距离远近排序
- **结论**: 第一次扔得好的人第二次大都变差、第一次没扔好的人大都有了进步——与飞行员的表现模式一致，说明「糟糕的表现常常会有提高，而好的表现则会变得糟糕」与表扬、惩罚都没有关系
- **结果**: 黑板上的硬币数据重现了回归模式，与飞行学员的表现模式一致

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 某人/某团队表现忽好忽坏，要解释「是不是上次那顿批评起了作用」
2. 培训、教练、治疗方案或管理动作宣布「有效」，却只有前后对比、没有对照组
3. 要为一批对象（门店、选手、候选人、基金）做下一期预测，已知的只有上一期的极端成绩
4. 看到「某类人总是如何如何」（聪明的女人嫁给不如她们聪明的男人、上封面的运动员下赛季下滑）就想找一个因果故事
5. 别人拿回归当挡箭牌，说「反正会回归，做什么干预都没用」

### 语言信号

- 「骂一顿就见效，夸两句就飘了」
- 「这次考砸了，下次肯定能上去」
- 「我们做了培训／上了新疗法，业绩明显好转」
- 「他就这水平，上次是超常发挥」
- 「这就是报应／因果循环」
- 英文: "punishment works better than praise", "they improved after the training", "he regressed to the mean"

### 与相邻 skill 的区分

- 与 `law-of-small-numbers` 的区别: `law-of-small-numbers` 解释「为什么小样本更容易出现极端值」；本卡解释「极端值之后为什么必然回落」——两卡互为对方的解释工具，小样本＋回归常同场使用
- 与 `intuitive-prediction` 的区别: 本卡是诊断侧（看懂并说出「这里只是回归」），`intuitive-prediction` 是应用侧（用四步程序把回归做进预测里）——先懂回归，再做修正

## E — 可执行步骤 (Execution)

1. **定格观察到的序列**
   - 完成标准: 写出主体、两次测量的时点与数值、以及被指控的「原因动作」（表扬/怒吼/治疗/培训）及其发生位置；确认这是同一主体（或同一极端筛选群体）的重复测量
   - 输入契约: 一个「极端表现→反向变化」的观察；缺时点或数值时先问「什么时候测的、上次多少、这次多少、中间发生了什么」

2. **拆成稳定成分与波动成分**
   - 完成标准: 把第一次成绩分解为「平均水平＋可保留的偏差＋当天的运气」；给出下一次的预测时应保留偏差、抛弃运气——好成绩仍高于平均但回落，坏成绩仍低于平均但回升，并注明「原始数据越极端，回归越明显」
   - 输出契约: 一个比原始数据更接近平均值的点预测或区间，附一句「这不是对该主体的重新评价，只是把运气成分按平均值处理」

3. **回归 vs 因果的分流判定**
   - 完成标准: 回答三问——①两次测量的共有因素占多大比重（相关系数；书中示例口径为父母与子女身高≈0.5、SAT 与 GPA≈0.6、收入与教育程度≈0.4（原文如此），日常估算工具原书未给，需使用者自定）；②那个「原因动作」是否恰好落在极端表现之后；③换一个运气结果，这个因果解释是否还成立。任一为「是」→ 先按回归解释
   - 判停条件: 已排除回归（有对照组、效应量超出回归可解释范围）时转因果分析，本卡停止推进

4. **干预效果评估（必须设对照）**
   - 完成标准: 对任何治疗、培训或管理措施，确认是否设有不干预组（或安慰剂组），并预期对照组仅通过回归就会改善；只有实验组比对照组恢复得更快，才能说干预有效
   - 判停条件: 无对照组 → 结论只能写「无法区分疗效与回归」，不得写「有效」
   - 输出契约: 干预结论＋「是否有对照」的明确标注

5. **交付与话术准备**
   - 完成标准: 交付含 ①观察到的模式 ②回归解释 ③校正后的预测或评估结论 ④是否需要对照验证；向他人解释前先读下面 B 段的沟通代价
   - 输出契约: 一页结论；对方索要因果故事而证据只支持回归时，明确写出「本结论没有因果解释，只有统计解释」

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把回归当宿命论（「反正会回归」）而放弃一切改进动作——本卡校正的是「把随机波动读成因果」，不是「努力无用」
- 用它否定所有干预：对照组设计的作用正是区分回归与疗效；有对照组且效应超出回归可解释范围时，干预结论依然成立

### 作者在书中警告的失败模式

- 把回归读成因果：教练怒吼后进步＝惩罚有效、表扬后退步＝表扬有害（第17章以色列空军教练案例，ce91；附录 A 亦记录同一误读）
- 对极端成绩直接外推：把上一期的极端表现当成真实水平做统一乘数式预测——原文口径是「将每家店的销售额增加10%显然是不对的」，应让预测具有回归性（原文如此）
- 疗效评估不设对照：极端群体（抑郁儿童）无论喝功能饮料、抱猫还是每天倒立，一段时间后病情都会好转——回归会「自愈」，用治疗前后对比证明效果等于把回归当疗效（ce93）

### 作者的盲点 / 时代局限

- **向他人解释回归极难，沟通代价要如实保留**：书中引述统计学家戴维·弗里德曼——把回归概念用在民事或刑事审判中，试图向陪审团解释「回归」的一方一定会输掉官司；连杰出研究者也犯过把相关性和因果性混淆在一起的错误（ce92）
- 书中未给「回归量级」的日常估算工具：该收缩多少、折中到哪一点没有现成参数，需使用者自定或按书中示例的相关系数口径自行估计（作者只给原则，不给通用系数）
- 回归解释天生缺乏情节，作者也承认：能为回归效应编出巧妙因果解释的人往往大受欢迎，而这类解释通常是错的——这是解读者的现实处境，不是可消除的技术缺陷

### 容易混淆的邻近方法论

- `law-of-small-numbers`：小样本更容易产生极端值，而极端值本身就会回归——两卡互为对方的解释工具
- `intuitive-prediction`：本卡是理解侧（先懂回归），它才是应用侧（把回归做进预测的四步修正程序）
