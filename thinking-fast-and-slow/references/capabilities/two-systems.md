# 双系统总论与慢思考唤起

## R — 原文 (Reading)

> 系统1的运行是无意识且快速的，不怎么费脑力，没有感觉，完全处于自主控制状态。……系统2将注意力转移到需要费脑力的大脑活动上来，例如复杂的运算。系统2的运行通常与行为、选择和专注等主观体验相关联。……避免系统1出错的方法从原则上讲是很简单的：认识到你正处于的认知领域，放缓并要求系统2来加以强化。
>
> — 第1章 一张愤怒的脸和一道乘法题（L245-385）；结语（L4509-4574）

## I — 方法论骨架 (Interpretation)

两套加工的分工（作者自述的「虚构角色」，不是脑区）：**系统1**快速、自动、不费力、由联想与情绪驱动、无法关闭；**系统2**缓慢、费力、需要注意力，兼任自我控制与监督，但它懒惰——平时只有部分能力参与、多数照单全收，只在系统1遇到麻烦时出面。

判定的意义：任何防御动作都从「**判定此刻是谁在作答**」开始——

1. **系统1的答复特征**：答案来得毫不费力、说不出推理过程、找不到验证痕迹（命中多数即当作系统1的直觉答案）；
2. **系统2的激活条件**：系统1给不出答案（17×24）、遇到令人吃惊的事、事物违反系统1设定的世界模式、即将犯错/冲动将脱口而出时；
3. **系统2的运行条件**：所有运作都需要集中注意力，注意力分散即中途中止——所以唤起必须配降载（一次只做一件难事、把中间结果写下来）。

慢思考程序（本书母程序）：**识别你正处在的认知领域 → 放缓 → 要求系统2强化**；并通过明确后果、留出时间、写明「必须使用哪条规则」来制造条件（书内实验：学生都「知道」规则却不使用；条件具备时多数人本可避开错误）。

重要的边界认识：认知错觉与视错觉同构——**知道有错，不消除直观感受**（缪勒-莱耶线）。系统1不可关闭、对逻辑和统计学几乎一无所知；所以要采取**妥协策略**：不追求时刻警觉（不可行也不实际），只把警觉集中到「常出重大错误＋风险高」的情境清单上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 坐诊艺术课——老师教我们识别「病态假象」
- **类型**: 作者亲历（第1章）
- **问题**: 心理治疗中，对「屡治不愈、盛赞你与众不同」的病人不由自主的同情心，可能是把人带向失败的危险信号
- **方法论的使用**: 老师像教识别缪勒-莱耶错觉一样教学生识别这种认知错觉：告诫「过多关注这类病人是危险信号」，切莫相信这种感觉、更不要依照感觉行事（系统2的识别＋抑制）
- **结论**: 同情心自动源自系统1，感受真实而强烈，却与事实不符；只能靠事先学会的错觉模式清单绕开感觉，不能靠意志消灭感受
- **结果**: 多年以后，精神病研究领域的权威证实了老师所给的建议是合理的

### 案例 2: 17×24 的按部就班
- **类型**: 书中演练（第1章）
- **问题**: 面对 17×24，系统1只能识别题型、给出大致范围（能排除 12609 和 123，但排除不了 568），无法给出答案
- **方法论的使用**: 系统2被激活，按部就班地提取乘法知识、分步运算、记住算到哪一步；过程刻意、努力、有序，身体也参与（肌肉紧张、血压上升、心跳加速、瞳孔扩大）
- **结论**: 慢思考是费力、有序的过程，需要注意力预算——这正是重要判断要「先降载、再唤起」的原因
- **结果**: 正确答案是 408（书内注明）；算出答案或放弃后瞳孔恢复正常大小

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面临重要决定（投资、签约、录用、重大发言），怀疑自己正在凭直觉拍板
2. 已经「想清楚了」却说不出推理过程，答案来得又快又顺
3. 想在疲惫、被打断或时间压力下复核关键判断
4. 想给自己建一份「容易出错情境」清单，知道什么时候该慢下来
5. 观察他人的决策时，想给出「此刻为什么要唤起系统2」的具体建议

### 语言信号

- 「我就是感觉这事不对劲」
- 「答案不是明摆着吗，有什么好想的」
- 「没时间细想，先这么定吧」
- 「我很清醒，不会被什么偏见带偏」
- 「让我想想」——但其实没有真的想
- 英文: "I just know it", "no time to think this through"
- 英文: "I'm aware of biases, so I'm fine"

### 与相邻 skill 的区分

- 与 `cognitive-load` 的区别: 本卡负责「判定谁在作答＋决定是否唤起慢思考」；`cognitive-load` 处理唤起之后的现实约束——高负荷/损耗状态下系统1影响为何增大、何时必须降载或改期
- 与 `cognitive-ease` 的区别: 本卡管唤起动作（放缓、自行构建答案）；`cognitive-ease` 管判定线索——放松/紧张是「系统1是否在主导」的直接读数
- 与 `priming-effects` 的区别: 本卡是总判定与总程序；`priming-effects` 描述系统1自动造义的机制底座（联想激活、环境线索如何悄悄改变行为），是诊断线索之一而非唤起程序

## E — 可执行步骤 (Execution)

1. **定格当前判断**
   - 完成标准: 用一句话写下「我现在要回答/决定的问题是什么」＋此刻脑中已经出现的直觉答案；记录时点与状态（是否疲惫、是否被催促）
   - 输入契约: 一个具体待决问题；信息不足时先问「你正要决定什么、在什么状态下决定」

2. **判定谁在作答**
   - 完成标准: 对照系统1特征清单（答案毫不费力、无验证痕迹、说不清推理过程）与系统2激活条件（答不出/惊讶/违反模式/冲动将脱口而出）逐条勾选；命中多数即判为系统1作答
   - 判停条件: 纯习惯动作或低风险琐事 → 按妥协策略接受直觉，本卡不再推进

3. **唤起并复核（高错误＋高风险情境）**
   - 完成标准: ①放缓——留出时间、一次只做一件难事、把中间结果写下来；②自行构建答案——不采信第一个直觉答案，从依据起步重算；③写下「必须使用哪条规则」「还需要哪些信息」，并明确后果
   - 判停条件: 注意力被分散或被迫切换任务时暂停复核、改约时间（系统2运作中断即中止）

4. **错觉防御与归档**
   - 完成标准: 检查情境是否属于已知易错模式（作者自用句式：「这个数字会成为一种锚定……」「如果问题被重新架构，决策会改变……」）；命中则标注「知道≠感觉会变」，以测量/程序替代感觉，并收录进个人易错情境清单
   - 输出契约: ①直觉答案 ②复核后答案 ③差异说明（或「维持直觉」及理由）④该情境是否列入易错清单（清单的收录阈值原书未给，需使用者自定）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 日常习惯性动作与无需核查的琐事：处处慢思考不现实；作者明说采用「妥协策略」——只聚焦「常出重大错误＋风险高」的情境
- 纯信息查询：只是找一条已知信息，不需要「谁在作答」的判定

### 作者在书中警告的失败模式

- 把系统1/系统2 当成两个脑区或「快慢开关」：作者明确「两个系统并不是真实存在的，它们只是我杜撰出来的角色」
- 以为「知道有偏见」就能免疫：自视错觉——审视自己时更容易采用系统2，认为自己头脑清醒；实际上大多数判断由系统1引导，系统2只做事后追认（ce11）
- 以为系统2时刻待命：它懒惰（ce17）；甚至可能对系统1产生的错误毫无所知（ce16）
- 指望「要犯错时有铃声提醒自己」：不可能；重大压力下质疑直觉令人不愉快，于是系统1的建议继续获得支持（ce238）

### 作者的盲点 / 时代局限

- 双系统是描述性隐喻，原书没有给出一套可操作的「谁在作答」判别程序（批判节）——本卡的清单是对书内主动句清单的操作化改写，不是原书原有程序
- 拟人化语言（「系统1做了某事」）容易被实体化；作者对情绪、文化、权力结构着墨少

### 容易混淆的邻近方法论

- `cognitive-load`：高负荷下系统1影响增大——本卡「状态判定」的深化；两者常在同一场决策里先后使用
- `cognitive-ease`：放松/紧张是判定「系统1是否在主导」的直接线索，可作本卡的判定输入
- `priming-effects`：联想激活是系统1的机制底座——解释「为什么系统1自动造义」，不承担唤起功能
