# 概率权衡与四重模式（风险决策的定位矩阵）

## R — 原文 (Reading)

> 阿莫斯和我在研究前景理论时，很快就得出了两个结论：相对于现有财富来说，人们更看重得失，而且关于结果的可能性和决策权重方面，表现大不相同。这并不是全新的观点，但它们一旦结合起来，就可以对一种偏好的特殊模式作出解释，我们将这一特殊模式称为四重模式。……大家都知道：从零提升到5%和从95%提升到100%要比从5%提升到10%或从60%提升到65%更具诱惑力。
>
> — 第29章 对结果可能性的权衡（L3404-3563）

## I — 方法论骨架 (Interpretation)

风险态度不是性格，而是**得失方向 × 概率高低**四格的产物（f142、g32）。先定位象限，再谈策略：

| 概率 | 收益 | 损失 |
| --- | --- | --- |
| 高 | 左上：风险规避（选确定所得，愿接受低于期望值的确定赌注） | 右上：**风险追求**——孤注一掷，唯一出乎意料的新发现 |
| 低 | 左下：风险追求（买彩票，可能性效应） | 右下：风险规避（买保险，付高于期望值的价格） |

**两机制的方向**（f142、p219）：上排两因素同向——敏感性降低＋决策权重共同作用出「收益规避、损失冒险」；下排两因素背道而驰——敏感性降低仍主张保守，但「对较小可能性的过分看重」压倒它，于是「为收益愿冒风险、对损失保持谨慎」。两端各有一个效应（f139、p210、p211）：**可能性效应**（从零到 5% 是从无到有的实质转变，小概率被高估、被过高定价）与**确定性效应**（95%→100% 是另一种实质转变，几乎确定的结果被赋予低于其应得的权重）。

**数值口径（决策权重函数，实验拟合值，原文如此）**（f141、p214、c235）：1%→5.5、2%→8.1、5%→13.2、10%→18.6、50%→42.1、90%→71.2、95%→79.3、98%→87.1、99%→91.2、100%→100。三条读数：0 与 100 两端一致；靠近 0 处过度加权（2% 的权重放大 4 倍多）；靠近 100 处欠加权（2% 的不确定把权重从 100 压到 87.1）；中段整体欠加权，约为理性期望的 2/3（f141、c235）。低于 1% 或高于 99% 是特例：要么被彻底忽视（权重为零），要么被过分重视（p215）。

**判据与代价**（f143、p220、p222）：同一分析适用于四栏中的任何一栏——「从长远来看，期望值的系统偏差的代价还是很高的」，对风险规避与冒险之举同样成立；一贯看重不大可能出现的结果最终会导致不好的结果。诉讼谈判是最常用的落地场景：原告胜算大（左上）不愿冒险，愿接受 90% 赔偿金的和解；被告败诉概率大（右上）宁可赌一把，因而握有更强谈判地位。

## A1 — 书中的应用 (Past Application)

### 案例 1: 阿莱斯悖论——巴黎大会上的自相矛盾
- **类型**: 书中转述（第29章）
- **问题**: 1952 年巴黎风险经济学大会上，阿莱斯出题：问题 A（61% 概率赢 52 万美元 vs 63% 概率赢 50 万美元）、问题 B（98% 概率赢 52 万美元 vs 100% 概率赢 50 万美元）
- **方法论的使用**: 多数人在 A 中偏前者、在 B 中偏后者——但 B 中左罐的改进明显更大，两题的选择互相矛盾；诊断结论是确定性效应：98% 与 100% 之间两个百分点的影响远大于 61% 与 63% 之间的同样两点；改写成「100 颗弹珠、红球赢白球输」的罐子后，荒谬更易被发现
- **结论**: 连萨缪尔森、阿罗、弗里德曼、萨维奇等顶尖学者也犯同样的逻辑错误且毫不察觉，直到大会快结束才发现
- **结果**: 阿莱斯想借此制造爆炸性新闻却大为失望：不研究决策理论的经济学家照旧使用期望效用理论，决策理论专家则高度重视——阿莫斯与作者的研究初衷正是给阿莱斯悖论一个满意的心理学解释

### 案例 2: 遗产官司与「结构性和解」——为确定支付溢价
- **类型**: 书中演练（第29章）
- **问题**: 你继承了 100 万美元，同母异父的妹妹在法庭上对遗嘱提出质疑；判决明天公布，律师保证你有 95% 的胜算（期望值 95 万美元），一家风险调整公司愿立刻支付 91 万美元与你交易
- **方法论的使用**: 用四重模式定位：这落在左上格（高概率收益）→风险规避，几乎确定的结果受到的重视小于其理应受到的重视，于是 91 万 vs 95 万的差价被当作「买保障」而认真考虑
- **结论**: 「结构性和解」这个产业正是以不菲的价格提供「保障」，充分利用了确定性效应——它为消除最后几个百分点的不确定收费
- **结果**: 书内未给出受试者的实际选择数据；结论是结构性和解产业靠确定性效应存在

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面临有明确概率与得失结构的决策（投资、保险、彩票、赌注），想弄清自己此刻为什么保守/冒进
2. 谈判、诉讼和解、项目对抗中要预测对方的风险态度（谁会冒险、谁会让步）
3. 看到「要不要花钱买个安心」「要不要赌一把翻盘」这类选项，想按账算而不是按感觉选
4. 发现自己面对大额损失时越赌越大、面对高胜算时过度保守，想解释并纠正
5. 要评估一份风险方案（保险、担保、和解报价）是否定价过高

### 语言信号

- 「万一中了呢」
- 「花钱买安心」
- 「差一点点就稳了，还争什么」
- 「反正是要亏，不如赌一把」
- 「我这个人就是比较保守/比较爱冒险」
- 英文: "cheap insurance", "may as well take the gamble"
- 英文: "certainty effect", "possibility effect"

### 与相邻 skill 的区分

- 与 `loss-aversion` 的区别: 两者同属前景理论族；`loss-aversion` 管价值函数一侧（损失比同等收益更重、得失记账），本卡管价值函数与决策权重**联合**后的四格分类与定位
- 与 `rare-events` 的区别: 本卡是**查阅矩阵**（先定位落在哪一格）；`rare-events` 专攻权重机制在罕见/生动事件上的表现与风险表述（为什么小概率被放大成高权重）
- 与 `invariance-test` 的区别: 本卡是正文的可执行分类与预测工具；`invariance-test` 是附录 B 的学术判据（用多框架重述检验偏好是否稳定），以正文版本为主、附录为佐证

## E — 可执行步骤 (Execution)

1. **写清决策结构**
   - 完成标准: 为每个选项写出「结果（收益/损失）＋发生概率＋相对参照点是得还是失」，参照点写明确（现状、目标、既有条款）
   - 输入契约: 一个具体的两选项以上决策；信息不足时先问「赢面有多大、输了会怎样、现在处在什么位置」
2. **定位象限**
   - 完成标准: 按得失方向×概率高低把决策放进四格之一，写出该格对应的预期态度（左上规避 / 左下买彩票 / 右上孤注一掷 / 右下买保险）——两维都要有依据，禁止凭「我是什么性格」作答
3. **权重校正（把概率换成心理权重）**
   - 完成标准: 用权重函数量级把「说出的概率」与「实际决策权重」分开：靠近 0 的按被放大处理、靠近 1 的按被压低处理、中段按约 2/3 处理（数值为实验拟合值，原文如此）；低于 1% 或高于 99% 时注明「特例：要么忽视、要么过分重视」
   - 判停条件: 涉及的是日常低风险小额选择（不必逐一校正）→ 直接用期望值比较并停止
4. **期望值对照与长期核算**
   - 完成标准: 算出期望值，与直觉选择并排放置；写明差异方向，并回答一个长期问题——「这种偏差反复出现时代价多大」（系统偏差的长期代价很高，对规避与冒险同样成立）
   - 输出契约: ①决策结构 ②象限定位与依据 ③权重校正后的量级 ④期望值对照与最终选择（或「维持直觉」及理由）
5. **谈判与对抗场景加做一步**
   - 完成标准: 分别判定双方所处的象限（胜算大/必败、索赔或筹码大小），据此前置「对方更可能冒险还是规避」的判断，再决定对抗还是和解

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 当算命工具用：它是**描述性模式**，解释的是人群与情境层面的偏好规律，不预测具体个体的具体选择
- 单次、不可重复、结构极不清楚的选择：算不出概率与得失结构时，四格定位没有输入，只能承认无法定位

### 作者在书中警告的失败模式

- 把「小概率被高估、大概率被低估」当**套利手册**去利用他人（ce172、ce173）：彩票式定价、以不菲价格出售保障的生意长期系统性占便宜——书中把同一机制同时写成风险与机会，本卡只作识别与自评
- 忽略四重模式与期望值的系统偏差（ce179、p222）：面对糟糕抉择时孤注一掷，「这种做法常会使可控制的失误变成灾难」（不认赔、延长斗争、把清算一拖再拖）
- 为消除小概率坏结果支付高溢价（ce173）：接受明显低于期望值的确定报价（91 万 vs 95 万），长期系统性亏损
- 对中间概率不敏感、对极端概率两极摇摆（ce176、ce177）：不同概率的风险被同等对待；风险档案随注意力而非数据变动
- 只做单题不作一致性检查（ce175）：成对选择给出互相矛盾的偏好，还事后用理论为自己辩护

### 作者的盲点 / 时代局限

- 权重函数数值（2%→8.1、90%→71.2 等）为实验拟合值（原文如此），不同估计方法给出不同数值，不得当普适常数
- 阿莱斯悖论是**一致性检验工具**，它不能告诉人「该选哪个」——它只指出偏好自相矛盾
- 书中承认实际选择还受情绪与直觉影响；四重模式给出的是概率与得失结构下的倾向，不覆盖其他动机
- 案例与实验（诉讼、保险、彩票）多为美国语境，书成于 2011 年，未讨论数字化投注产品等新形态

### 容易混淆的邻近方法论

- `loss-aversion`: 同一理论族、价值函数一侧——本卡上排两格直接由它推出
- `rare-events`: 权重机制的两端（接近 0 处被放大）——本卡左下/右下两格的解释器
- `invariance-test`: 附录 B 学术版佐证，用于检验偏好是否稳定，不是预测工具
- 与「期望值最大化」区分：期望值是本卡的对照基线，不是本卡主张的行为准则（作者指出系统偏差从长看代价很高，但没有主张人应按期望值行事）
