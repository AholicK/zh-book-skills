# 机构决策与助推（把偏见防御制度化）

## R — 原文 (Reading)

> 决策产生的相关阶段包括解决框架问题、收集引导决策的相关信息、反馈以及检查。想要提高其决策质量的机构应该经常在每一个阶段里搜寻可提高效率的环节。……
> 机构可以制定和有效使用检查表，还可以深入开展，比如参考类别的预测以及“事前验尸”练习。机构能够鼓励其成员形成一种在靠近雷区时互相留意和提醒的文化，而这种文化的形成一部分是通过为其成员提供一些独特的词汇。
>
> — 结语（L4509-4574）

## I — 方法论骨架 (Interpretation)

机构人多、思考慢、有规则，比个人更容易执行系统化程序——所以偏见防御在机构层可以被制度化。骨架三块：

**① 决策四阶段质控（f195）**：把机构决策当作工厂产品，设计、装配、最后检查每个环节都应有质量保障方法。四阶段＝解决框架问题 → 收集引导决策的相关信息 → 反馈 → 检查；提高决策质量的机构应在每个阶段反复搜寻可改进的环节（持续质控通常以「危机后对过程的全面回顾」形式出现）。

**② 反偏见工具箱（f196）**：检查表、参考类别的预测（外部意见）、「事前验尸」练习——机构可以制定并有效使用。

**③ 文化与环境配套**：
- 独立判断（f30）：汇总多人判断的前提是来源相互独立、错误不相关——讨论前先让每位成员各自写下简短意见（警察办案：证人录口供前不得讨论）；
- 批评渠道（f01/f198）：闲谈越多，所做的决策就可能更好；决策者听到外部批评常比自己的内心疑虑更容易接受；
- 词汇（f197）：提供「锚定效应」「窄框架」「过度一致性」这类精确词汇，批评才可命名、可讨论（辨别判断性错误像诊断病人，需要精确词汇）；
- 评价标准（f198）：希望决策按制定的方式而不是结果来评判时，人们会做出更好的决策。

**助推侧（选择架构）**：把有利选项设为默认、把损失改写为未得收益（「为明天储蓄更多」）、要求清晰、简单、显著及有意义的披露；三要件＝默认选项＋保留退出＋无误导。

## A1 — 书中的应用 (Past Application)

### 案例 1: 玻璃罐里的硬币——群体的智慧与独立判断
- **类型**: 书中转述（第7章）
- **问题**: 如何汇总多人判断才能接近真相
- **方法论的使用**: 让大量观察者独立估计罐中硬币数量再取平均；平行实践是警察办案时证人录口供前不得讨论、高管会议在讨论前先让每人写下自己的意见
- **结论**: 只有当各观察相互独立、错误互不相关时，群体平均才趋近准确值；若持有相同偏见或相互影响（减少样本量），汇总也难以降低错误率
- **结果**: 独立判断的平均值趋近准确值；允许观察者相互影响会减少样本量、降低小组估值的准确率

### 案例 2: 「为明天储蓄更多」——把损失转成未得收益
- **类型**: 书中转述（结语）
- **问题**: 如何在不强迫、不误导的前提下让员工为养老金多储蓄
- **方法论的使用**: 设计上避开直接损失——储蓄率的提高绑定在加薪时自动上升（默认＋自动性），把损失转变成未得收益（foregone gains）；员工注意到存得太多可主动退出
- **结论**: 书中称其不强迫任何人做任何他们不想做的事，也不含误导或欺诈；自动性把系统2的懒惰与工人的长远利益结合在一起
- **结果**: 这个革新使储蓄率有了一定的提高，也使成千上万工人的前景更加光明

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队/组织反复在同一环节犯错（评估、招聘、投资、立项），想把防御写进流程
2. 会议讨论后意见高度一致，想确认群体判断是否真正独立
3. 想引入检查表、事前验尸、参考类别预测等工具，但不知道如何组合与分工
4. 组织里没人敢质疑决策，想建立可命名的批评语言与批评渠道
5. 在设计健康、储蓄、保险类的默认选项（助推），需要自查边界与伦理要件

### 语言信号

- 「我们每次评估都偏乐观」
- 「会上大家都同意，但我心里没底」
- 「员工不敢提反对意见」
- 「怎么把偏见防御写进流程」
- 英文: "institutionalize debiasing", "independent opinions before discussion", "checklist culture", "nudge design"

### 与相邻 skill 的区分

- 与 `premortem` 的区别: 事前验尸是本卡工具箱里的一个组件（机构可制定的练习之一）；本卡管机构层的四阶段质控、工具组合与批评文化。只做单次决策的失败预演时转 `premortem`
- 与 `broad-framing` 的区别: 宽框架管风险与投资侧的制度化决策框架（机构层的风险政策）；本卡管决策流程与选择架构——怎么把偏见防御做进流程、词汇与选项设计

## E — 可执行步骤 (Execution)

1. **定位阶段**
   - 完成标准: 把当前决策归入四阶段（解决框架问题 / 收集引导决策的相关信息 / 反馈 / 检查），指出问题出在哪一阶段
   - 输入契约: 一段具体的机构决策流程描述（谁在什么环节做什么决定）；信息不足时先请用户补充环节清单
   - 判停条件: 分不清阶段时，先按「框架 → 信息 → 反馈 → 检查」四问逐项过一遍

2. **独立采集信息**
   - 完成标准: 讨论开始前收集到每位成员的独立书面意见（会后不得倒推补写）
   - 输出契约: 每人一段简短意见的清单 + 汇总方式说明

3. **部署工具箱**
   - 完成标准: 三件工具各指定负责人与产出物——检查表（清单条目）、参考类别预测（外部基准区间）、事前验尸（失败情景清单）
   - 判停条件: 需要完整的失败预演流程时，转 `premortem` 完成后回到第 5 步

4. **建立词汇与批评渠道**
   - 完成标准: 组织内可用的偏见词汇表（锚定效应、窄框架、过度一致性等）就位；保留闲谈式批评渠道；复盘时先分「过程质量」与「结果好坏」再谈改进
   - 输出契约: 一份词汇表 + 一条复盘规则

5. **助推设计自查（若涉及选项设计）**
   - 完成标准: 逐条核对三要件——默认选项、保留退出自由、无误导与欺诈（披露清晰、简单、显著及有意义）
   - 判停条件: 缺任一要件即降级为「告知」而非助推，不得按助推推行

6. **危机后回顾**
   - 完成标准: 每次危机后产出对过程的全面回顾与流程改进项（持续质控的落地形式）
   - 输出契约: 改进项清单 + 责任人

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把它做成「为员工好」的家长式管控：助推定义上保留退出选项、不含误导或欺诈，「没有强迫任何人做任何他们不想做的事」——缺此要件就不是助推
- 对个人事务套机构流程：四阶段质控与工具箱是机构级安排；个人决策场景转用对应的个人层能力卡

### 作者在书中警告的失败模式

- 批评文化缺失：员工不敢质疑决策（书内指出，当决策者相信批评者经验丰富且公平正直时会做得更好；外部批评常比自己的内心疑虑更易被接受）
- 群体信息不独立收集：开放性讨论总是偏重发言早而强势者，其他人一味附和（f30：讨论前先独立写；ce48）
- 语言粗糙，无法讨论「判断性错误」：需要「锚定效应」「窄框架」「过度一致性」这类精确词汇，批评才可命名、可讨论（f197）
- 复盘的错误归因：用结果而不是制定方式评判决策（f198：希望决策按制定的方式而不是结果被评判时，决策会更好）

### 作者的盲点 / 时代局限

- g51「经济人/人类」的政策讨论属作者立场（作者站在行为经济学一侧），引用其政策论断时须注明立场性，不得当作中立结论
- 助推案例（「为明天储蓄更多」、器官捐献）为特定政策情境（美国养老金与器官捐献制度），迁移到其他组织需自行判断
- 对「自由家长制」的伦理争议书内未展开：辩论双方都认同自由是价值，分歧在于「帮助」是否侵蚀自由——本卡只给要件，不给伦理裁决

### 容易混淆的邻近方法论

- `premortem`: 事前验尸是单次决策的失败预演工具，本卡把它当作机构工具箱的组件之一；先有机构流程，再用它
- `broad-framing`: 它处理机构层的风险政策与投资框架；本卡处理决策流程、词汇文化与选择架构——常成套部署但分工不同
