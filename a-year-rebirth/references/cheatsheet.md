# 决策规则速查 — 《用一年时间重生：如何从0到1开启个人事业》

| 能力 | 一句话规则 |
|---|---|
| 人生关键词（自由书写 + 偶像人物分析） | 用「一个问题回答 100 遍」的自由书写加上三位偶像的共同经历，提炼出三个能管三年的人生关键词。 |
| 重生年计划与系统化思维（五件套・量化・减量） | 用「关键词 → 描述 → 优势路径 → 量化目标 → 四维度日程」五件套做一份能执行、有减量的年度计划。 |
| 人生寻宝图与优势识别（热情线索・高峰事件・长板策略） | 把人生高峰/低谷画成折线图，用四问找热情线索、三问提炼优势能力，再按长板策略发力。 |
| 四维度日程管理法（输出/输入/开源/固本） | 把每天的事排进输出、输入、开源、固本四个格子，睡前十分钟规划、次日结束复盘。 |
| 情绪管理与低谷期穿越（自问自答・情绪记录・恐惧应对） | 用自问自答把「恐惧」问到事实层面，再建情绪记录与情绪糖果，穿越低谷期。 |
| 快速学会一项新技能（二八定律・黄金圈・拆解模仿） | 用黄金圈找到技能背后的「为什么」，把 20 小时投入到关键 20%，再用拆解模仿向高手学。 |
| 技能交换与个人事业定价（低风险内测・定价公式） | 用技能交换跑完整服务流程攒案例，用「时薪×耗时×3」给第一次定价。 |
| 大脑效能五方法（自动驾驶・双脑运转・狩猎・一休・五分钟线程） | 把琐事交给反射脑、把思考脑留给大事、用切换脑区替代硬扛——五方法各管一段。 |
| 主题式学习与社会人学习法（提问・立体式思维・学徒制） | 把当下最卡的问题定为一年主题，用提问—模型—验证循环长成知识树，向师傅与场景学习。 |
| 钻石人生图（现状诊断与切入点） | 给热情、知识、优势、资源四维各打 0-10 分，对号入座三类病灶、找准切入点。 |
| 个人品牌三步曲与打卡（记住/信任/选择） | 用场景标签让人记住、用践行让人信任、用差异化经历让人选择——打卡按五要素立体呈现。 |
| 加速期诊断与好运体质（制约理论・黄金五角星・人脉三锦囊） | 定位之后用五角星找最弱的那一角——通常在人和资源；再用人脉三锦囊破局。 |
| 幸福苹果树（主线整合） | 用一条主线做树干，把工作生活所有事项挂上去——有连接就加强，没连接就减掉。 |
| 自我认识总纲与卡点突破（成长三阶段・三板块自检・方向—路径・卡点觉知） | 用三问自查目标/优势/卡点，再看清「卡点不在外界，在自己」——总纲与分流器。 |
| 价值创造、给予者思维与输出观 | 先问「对他人有没有价值」再问「要不要继续」——市场是成长的试金石。 |
| 无纸化整理与模板思维 | 每经手一件事就问「能不能做成模板」——固定位置＋每日 5 分钟整理，一个人像一家公司。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
