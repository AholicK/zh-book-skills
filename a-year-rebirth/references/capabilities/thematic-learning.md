# 主题式学习与社会人学习法（提问・立体式思维・学徒制）

## R — 原文 (Reading)

> 真正的问题就像冰山一样，我们看到的、感知到的只是水面上极小的一部分，更本质更核心的问题其实深藏在水面之下。探究方法很简单，就是继续追问问题…第三步就可以小范围地验证自已的思路。在验证的过程，确定的部分就保留，有疑惑的地方就继续提出问题，然后用思维模型去分析，得出结论进行验证。
>
> — 第七章 · 主题式学习，互联网时代学习的正确姿势（L2825-2899）

## I — 方法论骨架 (Interpretation)

学生与社会人是两种学习：学生的任务是熟练掌握知识（理解、记忆、举一反三，给出正确答案）；社会人的任务是熟练解决问题（分析、拆解、各个击破，提出正确的问题）。所以社会人的学习是一个**提出问题、验证答案**的过程，三步走：

**提问**——真问题像冰山，露出来的只是现象。方法就是继续追问：为什么想出国、为什么想考研、顾虑是什么……直到能把「选项问题」改写为「需求问题」（「出国还是考研」→「你不知道自己要什么」→ 要解决的是「了解你要什么」）。

**用思维模型分析**——作者的常用模型是立体式思维：从书本、网络、人物、实践四个维度去找同一个问题的答案，刻意让自己看到不同面向。

**小范围验证**——确定的部分保留；有疑惑处继续「提问 → 分析 → 结论 → 验证」，像俄罗斯套娃一样层层深入，「自然地你就成了这个话题的达人，甚至是专家」。

倒过来看，这就是围绕一个主题逐个搞清楚分支、长成自己的知识树——**主题式学习**：每年 11-12 月定下一个「当下特别卡住我」的问题作全年主题，以一年为周期持续投入。学习场景配套「学徒制回归」：为经验付费、向有经验的人学；城市游学在真实场景中学；加入社群做志愿者近身跟前辈学习。没有核心的单点技能学习就像没有根的树枝。

## A1 — 书中的应用 (Past Application)

### 案例 1: 以一年为周期——2016 天赋潜能 / 2017 自由人移动办公 / 2018 内在力量
- **类型**: 作者亲历（第七章）
- **问题**: 2015 年刚离职，不知道应该从事什么工作、优势和方向在哪里
- **方法论的使用**: 每年 11-12 月思考下一年「当下特别卡住我的地方」并定为全年主题——2016 天赋潜能（花重金体验各种探索自我的课程、流派，一年后逐渐清楚自己在咨询方面的天赋）；2017 自由人移动办公（添置移动办公软件工具、提升写作和演讲能力）；2018 内在力量（上课、找老师咨询、拿自己做实验、看相关图书）
- **结论**: 主题随卡点推进：不知道做什么 → 想做自由办公 → 自我疆界不够
- **结果**: 书中交代：内在力量提升后「咨询的时候更能敏锐感知来访者的深层问题」；不到一年就感觉到了变化

### 案例 2: 立体式思维示范——用四个维度回答「我要什么」
- **类型**: 书中演练（第七章）
- **问题**: 「我要什么」是典型的真问题，如何立体地找答案
- **方法论的使用**: 书本——通读发现自我的经典图书；网络 / 人物——看《女人明白要趁早》后对王潇产生兴趣，上网检索信息、关注微博、看讲座视频与访谈；实践——学自我认知课程、拿自己做实验；人物——观察身边已经知道自己要什么的人、交流请教；最后小范围验证，确定的部分保留
- **结论**: 至此对「我要什么」有了立体全面的了解；像俄罗斯套娃一样层层深入，「自然地你就成了这个话题的达人，甚至是专家」
- **结果**: 书中交代：形成解决问题的思路，进入下一步验证环节

### 案例 3: 吴雨芯的主题年「与金钱的关系」——月收入从 1 万提升到 5 万
- **类型**: 学员自述（原书附录）
- **问题**: 想专题攻破与金钱的关系，突破自己不敢要价的限制
- **方法论的使用**: 定下「与金钱的关系」主题年——读关于金钱关系的书，也在工作中以及与人的合作中践行与体会
- **结论**: 「站在帮助别人的角度来让自己得到发展，开始种下尊重和共赢的种子」
- **结果**: 学员自述口径：月收入从 1 万元提升到 5 万元；「践行重生年计划的一年，我也发生了不小的蜕变，而且是可以量化的」

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想系统学一个领域，却被零散教程带着走，学完不会用
2. 手里是「该不该 A 还是 B」的选择题，反复比较、做不了决定
3. 想定下一年的学习 / 成长重点，但不知道以什么为准
4. 新领域想快速入门，却不知道该找谁学、去哪学
5. 「学了很多却过不好」——想给自己的学习找到一个核心

### 语言信号

- 「我该学什么好」
- 「报了一堆课，还是不会用」
- 「出国还是考研」「要不要转行」
- 「没人教我，我自己慢慢摸索吧」
- 英文: "I don't know what to focus on", "I keep taking courses but nothing sticks", "should I do X or Y"

### 与相邻 skill 的区分

- 与 `rapid-skill-learning`（v13）的区别: 时间尺度不同——本卡是**长周期主题**（一年一个主题、以解决卡点为纲、长成知识树）；v13 是**快周期技能**（二八定律拆解模仿、按「入门」口径快速学会一项技能）。主题式学习提供「学什么」的根，快速学习解决「怎么快」

## E — 可执行步骤 (Execution)

1. **判别问题类型（前置）**
   - 完成标准: 确认要解决的是「一个卡住的问题」而非「一套要掌握的知识」；若目标是考试 / 证书，按原书口径说明考试是入场券不是评优标准，再把目标翻译回待解决的问题
   - 输入契约: 使用者当前最想解决的问题原句（如「该不该出国」）；缺失时先问，不许静默猜值

2. **提问：把现象问题追问成真问题**
   - 完成标准: 对问题连续追问为什么、顾虑是什么，直到能把「选项问题」改写为「需求问题」（如「出国还是考研」→「你不知道自己要什么」→ 要解决的是「了解你要什么」）
   - 输出契约: 追问链记录 + 改写后的真问题陈述
   - 注意: 「追问到哪算找到真问题」原书未给停止规则——以「能改写问题陈述」为验收点，仍不成立则继续追问

3. **用立体式思维找答案（四维度）**
   - 完成标准: 对真问题分别从书本、网络、人物、实践四个维度列出取材清单，四维都要过一遍
   - 输出契约: 四维清单（每维至少一项具体动作，如「读某一类图书」「约谈一位已经做到的人」）

4. **小范围验证**
   - 完成标准: 确定的部分保留；有疑惑处继续「提问 → 用思维模型分析 → 结论 → 验证」循环；以在小范围实践中收到真实反馈为完成标准
   - 判停条件: 若验证中发现问题本质是方向性困惑（「不知道自己要什么」），先做方向澄清，再回到本卡设定主题（承接卡见「相关 skills」段）

5. **定为年度主题（一年为期）**
   - 完成标准: 主题来自「当下特别卡住我的地方」；按每年 11-12 月定下一年主题的节奏，以一整年为周期持续投入
   - 输入契约: 使用者当前最大的卡点；多个卡点并存时原书未给选择方法——与使用者确认一个，不得静默替其选择
   - 判停条件: 若使用者只想快速学会一项具体技能而非长周期主题，转 `rapid-skill-learning`（v13）

6. **找师傅 / 学徒场景（可选补充）**
   - 完成标准: 按三条路径之一行动——为经验付费、向有经验的人学；城市游学（到真实场景中学，如宜家 / 沃尔玛 / 星巴克，为 2019 年当时的举例）；加入社群做志愿者近身学习
   - 提问规范: 梳理语言、表达清楚意思、列举已经尝试过的方法；无论有没有得到回复都真诚感谢对方
   - 说明: 社群推荐清单与游学场景均为 2019 年语境，使用时以当下可用资源为准

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 目标是一套必须掌握的确定性知识 / 证书：先分清「入场券 vs 评优标准」，本卡不处理纯应试场景
- 只想快速入门一项技能：转 `rapid-skill-learning`（v13，快周期技能），不要用主题年替代短期需求

### 作者在书中警告的失败模式

- ce301 把现象当问题：「该出国还是考研」只是现象——真问题像冰山藏在水面之下；不继续追问就永远在选项之间打转
- ce214 只会考试不会学习：沿用学校「有考纲才学习」的评价标准，离开考纲就不知道如何学习
- ce302 追逐快速学习、多内容学习：单点技能散落一地、没有核心根系——「没有核心的单点技能学习就像没有根的树枝，是没有意义的」
- ce19 把求助当示弱：宁可自己硬扛也不请教，担心问题太初级被笑话
- ce20 伸手党式提问：不经思考就提问——既得不到有效帮助，也消耗前辈的耐心与善意

### 作者的盲点 / 时代局限

- **2019 年语境**：社群推荐清单（拆书帮、头马俱乐部、笔记侠、WorkFace 成都等）与城市游学示例（宜家 / 沃尔玛 / 星巴克）是当时的举例，不是现存资源清单；使用时以当下可用的社群与场景为准
- **学员自述标注**：附录一的吴雨芯（c329）为学员自述（原书附录），不得标注为作者亲历；其收入变化为学员自述口径
- 「追问到哪算找到真问题」原书未给停止规则；「多个卡点并存时选哪个」原文也未给判断方法
- 城市游学对观察分析能力要求高、吸收的经验零散，如何训练该能力原文未展开
- 「为经验付费 / 学徒制回归」是作者 2019 年的趋势观察；中世纪学徒制（7 年）为书中转述的历史背景，现代同辈学徒制无固定时长口径

### 容易混淆的邻近方法论

- `rapid-skill-learning`（v13）：长周期主题 vs 快周期技能——先有主题的「根」，再让快速学习放大单点技能；反过来先囤技能再找主题，正是 ce302 的失败模式
