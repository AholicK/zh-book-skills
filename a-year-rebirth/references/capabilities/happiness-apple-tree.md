# 幸福苹果树（主线整合）

## R — 原文 (Reading)

> 这将是你未来三到五年的主线，通过它筛选、整合你工作生活的所有面向，你就能抵御干扰你的诱惑，同时形成自己的主心骨。……
>
> 罗列出以上所有的内容之后，逐一将其跟你的树干关键词连接，看是否能重新定义你在做的事情或者将要做的事情…有连接的部分就优化加强其中的意图和方法，没有连接的部分就减少这件事在我生活中的比重，甚至是舍弃。……
>
> 当你罗列出所有苹果和树干的连接方式后，你就会知道哪些领域是你学习的重点。……
>
> 你需要的仅仅是在生活中给自已厘清一条主线，串联起你的家庭、事业和个人世界，那么过日子本身就是坚持。
>
> — 第五章 · 幸福苹果树（L1301-1375）

## I — 方法论骨架 (Interpretation)

「家庭和事业如何平衡」本身就是一道错题：把两者切成互相对立的两块去配时间，任何突发事件都会打破配比——挫败感不是来自「不坚持」，而是来自「分」的框架。换「合」的解法：找一条主线（Sally 的主线是「做一个外表柔如水、内心稳如山的女人」，核心是情绪修炼），把家庭、副业、职场都变成同一条主线的练习场——安抚孩子是情绪沟通、接临时任务是情绪调节、被爱人放鸽子是情绪释放；于是「过日子本身就是坚持」。

主线从哪来：从人生关键词里挑出代表「你价值所在」的那一个（作者选「真理」；倩倩「语言和旅行」→行者代言人；阿冰「创造」→创造代言人），它将是未来三到五年的主线，用来筛选、整合工作生活的所有面向——抵御诱惑、形成主心骨。

把它画成一棵幸福苹果树：

- **树干**＝代表价值的关键词（未来三到五年主线）；
- **苹果**＝工作生活的所有板块，要拆细——工作按对上/对下/对左/对右/中间自提升分解，生活按父母/孩子/伴侣/朋友/个人成长分解；
- **树枝**＝每个苹果与树干的连接方式。

操作是三轮：**罗列 → 连接 → 取舍**。逐个苹果问「能否从主干的视角重新定义它」——有连接，就优化加强其中的意图和方法（「接临时任务」可重定义为「情绪调节练习」）；没有连接，就减少比重、舍弃或授权他人。保留的苹果画上树，工作生活各挑三个重点画大；最后把所有树枝上的连接方式摊开看——反复出现的内容，就是学习重点（主要去向是主题学习年）。

## A1 — 书中的应用 (Past Application)

### 案例 1: Sally 的三个法宝——家庭、副业、职场都是练习场
- **类型**: 书中转述（第五章）
- **问题**: 体制内工作、坚持写作锻炼、运营两个社群（每月两场线下活动与多场线上分享），同时是两个孩子的妈妈——多线并行，如何不撕裂
- **方法论的使用**: 她不把几块拆开硬配时间，而是找到主线「做一个外表柔如水、内心稳如山的女人」，核心是情绪修炼：安抚孩子是情绪沟通、接临时任务是情绪调节、被爱人放鸽子是情绪释放、帮团队解决问题是情绪引导
- **结论**: 主线让一切整合在一起，「也就无所谓兼顾家庭和工作」
- **结果**: 书中交代：转身写作分享时，这些学习全都派上用场

### 案例 2: 示范 Sally 苹果树的「树枝」怎么写
- **类型**: 书中演练（第五章）
- **问题**: 苹果与树干的连接方式具体长什么样、怎么落地
- **方法论的使用**: 以「陪伴孩子」这个苹果为例，树枝上写：孩子生病或惹我生气时，用情绪修炼的视角去看待；用情绪修炼的方法引导孩子表达情绪；学习儿童心理学以掌握情绪引导知识
- **结论**: 把全部连接方式写完之后就能看出学习重点（Sally 面对的是沟通技术），不至于陷入学习的焦虑
- **结果**: 书中交代——「你就会知道哪些领域是你学习的重点」

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 家庭、副业、职场多线并行，总觉得顾此失彼、时间不够分
2. 反复在「工作与家庭的平衡」上自责，越计算配比越挫败
3. 人生关键词已经定了，但不知道它怎么落到自己的工作生活里
4. 想学的东西太多，怕又陷入「样样想学、样样没学好」
5. 面临一个不错但偏离主线的新机会，拿不准要不要接

### 语言信号

- 「家庭和事业根本没法兼顾」
- 「时间怎么分都不对，我是不是太贪心了」
- 「关键词听起来很好，但我不知道该做什么」
- 「这个邀请看起来不错，但跟我想要的方向好像不太一样」
- 英文: "I can't balance work and family", "I don't know how to apply my keywords", "is this opportunity worth taking"

### 与相邻 skill 的区分

- 与 `four-dimension-schedule` 的区别: 「整合 vs 平衡」的分工——本卡决定「什么是主线、哪些事项留下＋怎么连接」；v07 决定「留下的事项怎么排进每一天」
- 与 `life-keywords` 的区别: v02 负责「造词」（三个关键词：自己/外界/价值三层）；本卡负责「用词」——从中选出树干并把工作生活挂上去
- 与 `rebirth-year-plan` 的区别: 本卡是主线整合图（定义什么是练习场）；v06 是把主线兑现为年度五件套的计划系统

## E — 可执行步骤 (Execution)

1. **确认树干关键词**（输入契约）
   - 完成标准: 拿到使用者的人生关键词（由 `life-keywords` 产出，本卡不重做关键词探索），指出其中代表「价值所在」的那一个作为树干，并写成「××代言人」式的一句话
   - 判停条件: 关键词未定、或无法区分哪个词代表价值所在时，判停转 `life-keywords`——树干是本卡一切连接动作的锚点，不许代替使用者硬选

2. **列出全部苹果**
   - 完成标准: 工作按对上/对下/对左/对右/中间自提升分解、生活按父母/孩子/伴侣/朋友/个人成长分解，每一项写到具体模块（不写笼统的「工作」「生活」）

3. **逐一连接与重新定义**
   - 完成标准: 每个苹果都能回答「能否从树干视角重新定义」——有连接 → 写出优化、加强的意图与方法；无连接 → 给出减少比重、舍弃或授权他人的处置
   - 输出契约: 每项苹果的「连接方式 / 处置结论」两栏

4. **成图与取舍**
   - 完成标准: 树干居中写关键词；保留的苹果画上树，工作与生活各挑 3 个重点苹果画大、其余画小；每个保留苹果画一根树枝连回树干，并在树枝上写出连接方式

5. **归纳学习重点**
   - 完成标准: 把所有树枝文字摊开，提取反复出现的学习内容，形成学习重点清单（对接下一年主题学习重点）
   - 输出契约: ①苹果树图 ②保留苹果与连接方式清单 ③学习重点清单
   - 判停条件: 要落进每天的执行 → `four-dimension-schedule`；要把学习重点设为主题学习年 → `thematic-learning`

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 人生关键词尚未澄清时——树干依赖 `life-keywords` 的产出（顺序依赖：树干＝选定的一个关键词、未来三到五年主线），没有关键词就先别画树
- 想靠一次性外部调整解决失衡时——换城市、换一份不加班的工作、来一场说走就走的旅行只是短期感觉良好，很快会被生活惯性拉回失衡怪圈（ce111）
- 只想画一张好看的图、不打算逐个写连接方式时——跳过「逐一连接＋重写树枝」的关键动作，产出只剩装饰（g15）

### 作者在书中警告的失败模式

- 「分」的思维（ce105）: 把家庭与事业割裂成彼此对立的两块，精打细算配时间，仍被突发事件打乱，招来「无法掌控生活」的挫败感；「试图在各种不确定性中坚持所谓的『1：1家庭事业平衡』几乎是不可能的」
- 1:1 平衡把两者预设成独立的量——生活本质是变化快于计划，问题不在坚持，在框架；正解是厘清一条主线，让「过日子本身就是坚持」
- 把「没连接的事」直接一刀切掉，而不先尝试重新定义——原书的动作顺序是先连接（重定义）、后取舍

### 作者的盲点 / 时代局限

- 树干与关键词的数量关系（三个词里选一个）未详细说明；三个词语义冲突、判断不出哪个代表价值所在时怎么办，原书未给
- 「连接方式写不出来」时没有处理方法（f111）——需使用者自定；本卡按「减少比重 / 舍弃」处理，不硬编理由
- 工具手册版四步未给「与树干无关事项如何处置」——正文补齐为「减少比重甚至舍弃」，两版合读才完整
- 学习重点的产出规则来自「树枝连接方式中反复出现的内容」（p131，本卡主要输出之一）——若连接方式写得太少或彼此无关，「反复出现」就识别不出来，输出会是噪音

### 容易混淆的邻近方法论

- `four-dimension-schedule`: 本卡管「筛选与整合」，v07 管「每日排布」；两卡共用四维度视角但分工不同
- `life-keywords`: v02 产出三个关键词（自己 / 外界 / 价值三层结构），本卡只取「价值所在」那一个画成树干
