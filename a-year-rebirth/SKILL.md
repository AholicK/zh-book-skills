# 《用一年时间重生：如何从0到1开启个人事业》 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 临床心理治疗、精神疾病诊断与用药（本能力包的情绪工具不是治疗手段）
- 正在发生的人身安全威胁与暴力场景（先确保安全并联系专业机构）
- 法律、财务、医疗等专业决策的代理（定价公式为经验口径，不构成财务建议）
- 学术、公益、照护等不以市场变现为目标的成长路径评估（「市场价值」标尺对此不适用）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 成长有顺序：深刻的自我认识 → 知行合一 → 有市场价值的成长；顺序颠倒就会出现「学了很多却过不好」。
2. 方向先于路径：先回答「要什么」（人生关键词），再谈「怎么走」——反复纠结选项的人往往缺的是目的地。
3. 不加系统不成长：用「重生年计划」把方向落成系统（关键词 → 优势路径 → 量化目标 → 四维度日程），让一件事带动多条线。
4. 市场是价值标尺：不以市场价值为目标的成长都是自嗨；输出必须对他人有价值——判断成长效度的是市场，不是努力本身。
5. 优势 = 天赋 × 投入：天赋只是「新手的运气」；精进长板、协作补短板（「上帝给我们劣势，是希望我们有朋友」）。
6. 用整合替代平衡：用一条主线（关键词）串联家庭、事业与个人世界——过日子本身就是坚持。
7. 情绪与卡点是信号：卡点的源头最终都是自己；自问自答、情绪记录与低谷穿越让人恢复行动能力，而不是替人做决定。

## 边界与判停

- 出现持续情绪低落、自伤或伤人念头等临床指征时：停止自助流程，建议尽快寻求专业心理/医疗帮助。
- 用户描述正在发生的人身安全威胁（暴力、跟踪、威胁）时：停止成长工具流程，优先确保安全并求助专业机构。
- 用户处于债务、照护等重大现实危机中时：先处置现实约束，不套用「一年期」时间表，避免把结构性困难误读为「不够努力」。
- 用户要求用虚假宣传、施压客户等损害他人的手段做营销或成交时：停止，本包的输出观以「对他人有价值」为前提。
