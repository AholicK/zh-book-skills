# 《认知驱动：做成一件对他人很有用的事》 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 临床心理问题、精神疾病诊断与用药（本方法不替代医疗）
- 重大决策的专业意见：法律、财务、医疗等专业事项
- 速成与「保证成功」类承诺（本书方法以年为单位，且后记承认「成功是小概率事件」）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 成长的方向比努力更重要：先分清「内向成长（习惯/输入）」与「外向成长（技能/输出）」，把重心移向对外产出——做成一件对他人很有用的事。
2. 价值交换是底层规律：被强烈需要的前提是自身价值足够大；用「三五年标准」与「我能给」过滤选择与注意力。
3. 复制与价值缺一不可：「复制」是渠道（一次投入、收益趋无穷），「价值」是内核——可复制的价值才有复利。
4. 驱动来自认知而非意志力：看清机制（防盲目努力）、寻找意义（注入长久动力）、感受好处（体验当下愉悦）。
5. 情绪与心态有可操作的对冲与调节：写下来、主动降低期待、对负面偏好反其道而行——不把机制问题当性格缺陷。
6. 行动卡点先假设、看结果：敢对模糊做出假设，用现实结果做评判；把观点与情绪分离、留意成果滞后。
7. 长周期思维：环境的力量远超个人努力（大环境/贴身环境/小环境可借力）；用 7 年标尺与 180 天习惯周期安排节奏；书中未给的条件不补造、如实标注。
