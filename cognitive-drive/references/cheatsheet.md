# 决策规则速查 — 《认知驱动：做成一件对他人很有用的事》

| 能力 | 一句话规则 |
|---|---|
| 内向/外向成长诊断与转向（重技能辅习惯） | 先分清你手上的事是「习惯」还是「技能」——把技能做成对外的产出，努力才看得见希望。 |
| 复制 vs 转换（可复制的价值） | 判断一件事是「做多少是多少」还是「一次投入可反复受益」——尽早把时间挪向后者。 |
| 价值交换规律与三五年标准（「我能给」替代「我想要」） | 每次选择都问两句：「三五年后还有价值吗」「我能给什么」——两问下去，浮躁自消。 |
| 顶级信息输入与输入输出结构（「知识写作」升级） | 输出之前先升级输入：用顶级信息与约 100:1 的输入输出比喂养你的作品。 |
| 利他四步（本质→结果→途径→接纳） | 利他不是付出，是成为有价值的人——本质是爱、结果是利己、途径是创造价值、从接纳利己开始。 |
| 镜子原理（影响/吸引/成为） | 想让别人改变，先把自己变成那面镜子——用影响/吸引/成为替代劝说/付出/要求（该劝说时仍要劝说）。 |
| 被动社交（用作品说话） | 不擅即时表达就用作品说话：先把价值做够，再让作品替你连接世界。 |
| 逻辑层次六层标尺（自定位工具） | 卡住时先定位层次——环境/努力/方法/选择/身份/意义，哪一层的问题就在哪一层解。 |
| 身份建设（心理建设：从「我要成为什么样的人」出发） | 改变总失败，是因为你在结果层使劲——先回答「我要成为什么样的人」，再谈行动。 |
| 态度—行为—结果（十大积极结果练习） | 态度—行为—结果：先审视态度、找到积极视角（如写 10 个好处），事情才会往好的方向转。 |
| 语言改造（语言—态度—行为—结果） | 把「我做不到」改成「我暂时还做不到」——语言是链条的源头，说积极、和善、开放的话。 |
| 理性双刃剑与三阶段姿态（乐观构想/悲观计划/乐观实行） | 理性要在对的时候用：构想期大胆乐观、计划期悲观推演、实行期专注乐观。 |
| 负面偏好对冲（成功日记 / 想象三式） | 不是你不快乐，是大脑天生偏好坏事——用成功日记与想象三式主动对冲。 |
| 二元对立→多元互存 | 从「非黑即白」走向「多元互存」：先自查三特征，避开两个误区，从观念接受开始。 |
| 舒适区边缘与「适度难受」（15.87%/二八口径） | 好的生活是始终游走在舒适区边缘——无压就加压，超压就减压，加码控制在一两成吃力。 |
| 认知驱动三步（看清机制/寻找意义/感受好处） | 坚持不下去时别加意志力——补三件事：看清机制、寻找意义、感受好处。 |
| 「写下来」五用（情绪/专注/行动/目标/思考） | 情绪、分心、拖延、目标模糊、想不透——五个问题的第一动作都是「写下来」。 |
| 假设与现实结果（破模糊的一对能力） | 想不清就先假设：写下脑力范围内最大程度的假设，用小行动换取现实结果的评判。 |
| 主动降低期待（数量/难度两侧） | 把期待主动降到「最差结果」，多出来的都是惊喜——但别忘了你仍是希望变好的人。 |
| 深度练习（有一是一 / 速度也是能力） | 学习即练习、有一是一——标准是「快速做出且不出错」，卡壳就回头补熟练度。 |
| 跨界 B 计划（独自潜行 / 秘密前行） | 在主业之外跨得越远越好地养一个秘密 B 计划——独自潜行、秘密前行，用维度复利对冲无聊。 |
| 环境借力（大环境/贴身环境/小环境） | 努力没效果，先看环境——大环境借势、贴身环境治理、小环境借力，让环境替你说话。 |
| 多维学习（含仍要读书的理由与时机） | 学了没用，多半是维度不够——同时调动多感官参与，读书只是其中一维。 |
| 目标觉醒（含刚需 / 两种驱动力 / 试错） | 目标觉醒：写下来、只选一个、变成刚需、从痛苦驱动切换到喜悦驱动、用苍蝇模式试错。 |
| 成事之旅（7 年周期 / 180 天 / 5 层次进度条） | 把心理标尺拉长到 7 年，习惯按 180 天执行，用价值交换 5 层次当进度条。 |
| 创造层的生活（消费/生产/创造 + 创造三步） | 顶级的生活不是奢华，是创造——输出、有价值、再拿反馈迭代，每次突破一点点就算创造。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
