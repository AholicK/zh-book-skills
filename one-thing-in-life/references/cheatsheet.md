# 决策规则速查 — 《人生只有一件事》

| 能力 | 一句话规则 |
|---|---|
| 活好总纲（关系两问；觉知＋接受＋臣服） | 用关系两问检验自己活成什么样子：别人真心想不想和你在一起、想不想和你一样。 |
| 三件事（自己的事／别人的事／老天的事；当真 vs 认真） | 遇事先分三件事——能做主的才认真，其余练习不当真。 |
| 接受自己（认真＝认＋真；面对—接受—处理—放下） | 认真＝如实地承认自己真的是这样；然后面对→接受→处理→放下。 |
| 修“愿意”（愿力修炼：从小事／揪“不愿意”） | 把“不愿意”揪出来，从小事起修，直到愿意。 |
| “叫停”机制（知止） | 状态不好先踩刹车：叫停→不想不说→调息→调整好再回来。 |
| 管好念头与转念（含“不得不”、决定要快乐、执念、真心） | 找出脑子里那句话，检视它，再换一个说法——“不得不”是可以转的。 |
| 逆境三颗心（对不起、我爱你、谢谢你） | 对过不去的人和事，老老实实念：对不起，我爱你，谢谢你。 |
| 认错与惭愧（含傲慢诊断、自我感觉良好） | 认错不是认输，是让执念消融的解脱机制——“都是我的错”。 |
| 放下与减法（豁出去／放下 vs 放弃／日损／归零） | 做最坏的打算，尽最大的努力；挫折要归零，成功经验更要归零。 |
| 自我突破（搞定自己／改个性／跟随／成全别人） | 与其搞定事、搞定人，不如先搞定自己；放下自己，先做到跟别人一样。 |
| 倾听与说话（学“听话”／学“说话”；好为人师边界） | “你听我的，我就听你的”——让人愿意听你的唯一理由是你先听他的。 |
| 感同身受与面对脾气 | “己所不欲”未必是“人所不欲”；觉察到无法感同身受，立即提问。 |
| 关系修复日常（说对不起／赞美／不计较／记名字） | 道歉有四种境界、赞美有四种境界；把账本烧掉、把人记进心里。 |
| 感恩、信任与助人 | 每天对“过不去”的人说四句感谢词；用三盲区检查感恩的广度。 |
| 家庭修炼（关心 vs 担心／教育／童蒙／家族业力／尽孝） | 家事国事天下事，事事关心而不担心；父母要活得比子女“小”。 |
| 职场修炼（离苦得乐／以假修真／甘愿受，欢喜做／洞察／五随） | 从事里抽离→回到内在→从念头抽离；甘愿受，欢喜做。 |
| 领导修炼（对人不累／事上练心／反求诸己／空间／愿意换愿意） | 对“人”不累的秘诀是重心在人不在事；用空间换时间、用愿意换愿意。 |
| 企业修炼（文化／赚到做／真／简单／极致价值／境随心转／传承） | 文化是企业的中央银行；在每件事上衡量“赚到做”。 |
| 高效能人生（解忧／超级努力／认真求人／被动／百万分） | 过不过得去、放不放得下——把日常当作毕业考的模拟考。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
