# 领导修炼——对「人」不累、给人空间、用愿意换愿意

## R — 原文 (Reading)

> 第一，真正的累，是心累，不是身体累；第二，累的源头，不在别人，而在自己；第三，把重心放在事上一定累，把重心放在人上就不累了。……最容易不自觉“占空间”的人，通常是反应快、口才好、意见多、性子急、标准高、个性强、居上位者。大家不妨对号入座，如果这七项特性，你拥有两项以上，应该就算“占空间症候群”的带原者。……要让你的团队成为一个“愿意”的团队，只有一个方法：你要带头说“我愿意”，除此之外，别无他法。我发现组织的秘密就是：境随心转，心想事成！
>
> — 第9章 领导的修炼 ·「对“人”就不累」（L5511-5571）｜「给人空间」（L6053-6117）｜「带出“愿意”的团队」（L6185-6237）

## I — 方法论骨架 (Interpretation)

领导修炼的问题起点是「累」：累到睡眠、运动、休闲、麻醉都无法缓解，累到「无所逃于天地之间」（c88）。书里的诊断链分三层：

1. **给「累」归因**（f45/p95）：真正的累是心累、不是身体累；源头不在别人、在自己；把重心放在「事」上一定累，放在「人」上就不累。机制：只看见「事」没看见「人」＝用脑不用心 → 你越来越能干 → 陷入「能者多劳」：身边人越来越不能干、更多事由你承担 → 心一定累；把心放在「人」上＝帮身边的人变得更好 → 人都好了就把事情都承担了。（「脑只会『反射』，心却会『共振』」为作者机制表述、无出处。）
2. **时间不够用的底账是「空间」不足**（f50/p103）：时间不够用不是因、只是果——通常是效能不够高，效能不够高往往是空间不足；空间＝个人内在、人际关系、组织环境的成长余地，而它常被「自以为是」占满（对什么事都有与众不同的看法、不吐不快、非我不可）。自查工具＝「占空间」七项特性（f51/p104）；改法两条：起心动念转为「成全别人」「成就团队」（「我想得对没用，因为做的人不是我，必须是他想出来的」）；看和听时尽可能不想、一想就叫停。
3. **带团队＝带出「愿意」**（f52/p105/p106）：愿意不能用头脑、只能用「心」；组织里居上位者只有一件事——不断修炼自己的愿力，用愿意换所有同事的愿意；唯一方法是带头说「我愿意」，验收看七条「愿意」清单。人才流失、理念推不动时，先走「反求诸己」：不强留、总是祝福、惭愧反省、发愿让自己和组织更强（f49/p101/五级推导链 p102）。

组织外推的边界：「境随心转，心想事成」只取「居上位者先改自己的心念与行为」这一最小可执行动作，不对团队业绩、留人效果作承诺（见 B 段）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 累到无所逃于天地之间
- **类型**: 作者亲历（第9章）
- **问题**: 作者自述曾累到身心俱疲——睡眠、运动、休闲、麻醉都无法缓解，「累到无所逃于天地之间，累到不知人生所为何来」
- **方法论的使用**: 抽离工作场所、花一段时间沉淀整理自己、向内探索学习人生，再回到工作岗位
- **结论**: 回岗后不再累；作者归纳三点体会——真正的累是心累；源头在自己不在别人；重心在事上一定累、在人上就不累
- **结果**: 作者自述「自从不累了以后，事业也一帆风顺了」（作者自述，非独立验证）

### 案例 2: 「一看就明白」的代价
- **类型**: 作者亲历（第9章）
- **问题**: 作者曾自豪于「一看就明白」「一听就清楚」「一说就命中」的本事，觉得自己反应快、很厉害，为此得意扬扬
- **方法论的使用**: 对照处境复盘——恰恰是那段日子整天忙得团团转、周围人像无头苍蝇、困局无解；如今看清是空间被「自以为是」占满
- **结论**: 空间是效能的前置条件：「空间一出来，时间就不再是问题」
- **结果**: 作者自述此后每次觉得时间不够用，就检查自己是否太自以为是、太占空间（「屡试不爽」为作者自述口径）

### 案例 3: 女同事的去而复返
- **类型**: 作者亲历（第9章）
- **问题**: 一位优秀女同事在作者准备委以重任之际请辞，理由是想历练不同媒体
- **方法论的使用**: 作者只感到遗憾和惭愧（没能提供更大舞台），不强留、总是祝福，并发愿让《商业周刊》更强更好
- **结论**: 「过程曲折，结果圆满……只能尽其在我，只能反求诸己」——缘分之不可测
- **结果**: 几年后这位同事重回《商业周刊》，成了担当大任的主管（作者自述案例）

### 案例 4: 一场两小时的独角会议
- **类型**: 书中转述（第9章）
- **问题**: 一位创业者向作者抱怨找不到人才、留不住人才、员工不能独当一面
- **方法论的使用**: 作者到他公司看会——他亲自主持，同事面色凝重不太说话；他一个个询问近况、一一指出不足、然后下达指令
- **结论**: 作者了然于胸：「他把『空间』占满了，难怪他的员工难以成才，难当大任」
- **结果**: 未说明（现场观察，作者据此给出诊断）

### 案例 5: 刘备的三句话
- **类型**: 书中演练（第9章）
- **问题**: 领导之「将」——知人善任靠什么
- **方法论的使用**: 刘备运筹不如孔明、打仗不如关云长张飞赵子龙，但能让这些人跟随，只靠三句话
- **结论**: 「你说的真有道理！这件事很重要！我怎么没想到？」——能让人「为知己者死」，但要真心说出须有格局、有肚量
- **结果**: 未说明（作者评：这不仅是「修」出来的，而且是「让」出来的）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 带团队的人长期喊累：睡眠、运动、休闲都缓解不了，「事情永远忙不完」
2. 时间永远不够用，复盘后发现真正的瓶颈是身边没人成长、事都堆在自己身上
3. 开会基本一个人说话；下属爱依赖、很被动、不动脑，抱怨「找不到人、留不住人、不能独当一面」
4. 团队只靠 KPI 与奖惩驱动：做事要推、要盯，遇到问题先撇清
5. 优秀干部请辞，或反复宣讲的价值观「员工总是听不懂、没感受、做不到」，自己既挫败又不服

### 语言信号

- 「事情永远忙不完」「一天忙到晚，也不知道忙出了什么」
- 「开会基本就是我在说」「他们怎么就不能独当一面」
- 「我这么栽培他，他还是要走」
- 「时间永远不够用」
- 英文: "there's never enough time", "I can't find or keep good people", "my team just won't take initiative"

### 与相邻 skill 的区分

- 与 `cultivating-willingness` 的区别: 同一机制的两种尺度——那条是个人在每件小事上修「愿意」；本卡把它用到组织：居上位者带头说「我愿意」，用愿意换愿意
- 与 `admitting-fault` 的区别: 那条处理「认错」的功课（含「都是我的错」）；本卡中「反求诸己」是领导者在人才流失、影响力受挫时的向内归因流程，带头认错只是其中动作之一
- 与 `workplace-cultivation` 的区别: 那条是任何职场人的工作观修炼；本卡的组织动作（带头、给空间、留人）以「在职带团队」为前提
- 与 `enterprise-cultivation` 的区别: 尺度再上一层——本卡止于带团队层，领导→企业的传导链归 `enterprise-cultivation`

## E — 可执行步骤 (Execution)

1. **给「累」做归因**
   - 完成标准: 对照三句话写下归因句——累的是心还是身？源头指向别人还是自己？重心在事还是在人？
   - 判停条件: 确认重心在事、源头在自己后进入第 2 步；身心症状严重时先求专业帮助，本卡不替代

2. **占空间自查**
   - 完成标准: 七项特性逐条对号入座（反应快 / 口才好 / 意见多 / 性子急 / 标准高 / 个性强 / 居上位者），记录命中项数 + 最近一周的具体证据（哪场会、哪次谈话自己说了大部分话）
   - 判停条件: 命中两项以上（或周围人多半爱依赖、很被动、不动脑、手脚慢、不负责），按「带原者」处理，进入第 3 步；不足两项也如实记录

3. **腾空间：两个最小动作**
   - 完成标准: ①挑一件自己「想得对」的事交出去，让对方自己想出做法（检验句：做的人不是我，必须是他想出来的，才有可能由他做出来）；②在一次看和听中尽量不想，一想就叫停，事后记录发生了什么
   - 输出契约: 交出去的事 + 叫停练习的记录

4. **校准团队「愿意度」并带头**
   - 完成标准: 用七条「愿意」清单（不懂的愿意问 / 不会的愿意学 / 做不好愿意认 / 认了后愿意改 / 分内的事愿意做 / 同事有难愿意帮 / 分外的事愿意担）逐条举出实例；写下自己要带头说的一句「我愿意——」
   - 输出契约: 七条清单的现状记录 + 带头句

5. **受挫时走「反求诸己」与五级推导链**
   - 完成标准: 人才流失按流程走——确认无误会 → 不强留、总是祝福 → 惭愧反省（舞台/能量/磁场）→ 发愿让自己和组织变强；理念推不动时自查五级链（没说清楚→体悟不深→没做到→深度不够→对别人的关心不够）
   - 判停条件: 确认自己已「事实行深」仍不能影响别人，只能接受、只能等待（p102），不得升级为强推、施压
   - 输出契约: 一份反求诸己修正计划（含要修正的具体一项）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 组织尺度动作须「在职带团队」才成立：带头说「我愿意」、带出「愿意」的团队、留人/劝留动作都以有团队、有下属为前提；不满足时只使用个人层动作（累的归因、占空间自查）
- 「境随心转，心想事成」的组织外推只取「居上位者先改自己的心念与行为」这一最小可执行动作——不承诺业绩、留人或「愿意」的转化效果
- 不得把「占空间」七特性用作对他人的人格评判或考核标签——它是自查清单；诊断别人是否「占空间」，看的仍是自己的行为证据
- 不得用本卡去要求下属「愿意」：书中的唯一方法是居上位者带头，不是对下提要求、更不是考核（愿意要用愿意来换）
- 沉溺于「反求诸己」式自责、或拿它当拖延解决问题的借口，都不在用法内——它的出口是修正自己和接受随缘
- 「对『人』就不累」不是「不再管『事』」：对人与对事不是二选一——重心放在人上不等于放弃对结果的要求；书里的说法是人都好了、事情自然被承担，把它用作当甩手掌柜的依据也是误用

### 作者在书中警告的失败模式

- 能者多劳的漩涡（ce73）：只看见「事」没看见「人」＝用脑不用心 → 越来越能干、身边人越来越不能干 → 更多事由你承担；喊累者画像——自负、责任心重、追求完美，觉得非自己盯着不可
- 空间杀手（ce79/p103）：自豪于「一看就明白、一说就命中」，对任何事都有与众不同的看法、不吐不快、非我不可 → 整天忙得团团转、周围人像无头苍蝇、困局无解
- 独角会议（ce80）：亲自主持会议，逐个询问、指出不足、下达指令，两小时基本他一个人在说话——员工难以成才、难当大任
- 把人才流失归因于对方（ce77）：抱怨「我这么栽培他还是要走」，夹杂灰心、不平和不解；作者说善解因缘、随缘对待者「凤毛麟角」
- 把理念推不动归给员工（ce78）：抱怨员工「听不懂、没感受、做不到、不彻底」——链条的另一端在自己：心不真则事不实、愿不广则行不深
- 「忙」就是「心亡」（ce74）：日程爆满、说不清在忙什么，忙出的结果「也不怎么样」——忙的反面不是闲，而是活在当下
- 不愿意的团队（ce81）：做事要推要盯、遇事先撇清、只剩 KPI 与奖惩驱动——「天王老子也管不动」

### 作者的盲点 / 时代局限

- 「境随心转，心想事成」「愿力/业力」「离苦得乐的一扇门」是作者的信仰性表述（不可证伪）——不作事实断言，不对效果作任何承诺
- 机制解释无出处：脑「反射」、心「共振」、愿力共振磁场、善缘大磁场等均为作者自述/书中转述口径，无文献支持
- 人才流失场景缺判别标准：作者未给「哪些是自己的问题、哪些确实是无常因缘」的判据（f49 missing_conditions）；「反求诸己」有被误用为万能归因的风险
- 五级推导链在作者自己的表述里也不可证伪；其出口是「只能接受、只能等待」，对需要及时纠偏的组织场景操作性有限
- 案例样本集中于作者本人与身边企业（《商业周刊》、创业者），对权力不对等、裁员、经营困难等硬约束场景未作讨论

### 容易混淆的邻近方法论

- 时间管理 / 效率技巧：书中「以空间换时间」明确不是时间管理技巧——时间不够用是果、空间不足是因；把它做成日程表、番茄钟一类会失效（p103 边界）
- 权力与掌控式领导：向外掌控只会把焦虑和恐惧埋得更深（ce75）——「向外，掌控；向内，觉察」；本卡走的是向内觉察、开发力量一路
- 话术与激励术：刘备三句话要「有格局、有肚量」才说得真，作者强调不是话术表演（p97 边界）；用话术或奖惩逼出「愿意」也违背「愿意只能用愿意来换」（p105/ce81）
