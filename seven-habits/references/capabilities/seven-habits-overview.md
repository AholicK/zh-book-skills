# 七个习惯总纲：成熟模式图与效能（P/PC）定义

## R — 原文 (Reading)

> 而真正的效能应该包含两个要素：一是"产出"，即金蛋；二是"产能"——生产的资产或能力，即下金蛋的鹅。……所以，效能在于产出与产能的平衡。
>
> ……
>
> "成熟模式图"（Maturity Continuum）即人类成长的三个阶段，分别为依赖期、独立期、互赖期。
>
> — 第二章 七个习惯概论 · 「效能」的定义（L3213-3479）；成熟模式图（L3063-3185）

## I — 方法论骨架 (Interpretation)

本卡给两件东西：一把度量衡（P/PC）和一张地图（成熟模式图）。

度量衡：效能 = 产出（金蛋，想要的产出）与产能（下金蛋的鹅，产出赖以为生的资产或能力）的平衡。两种失衡各有名字：重蛋轻鹅，最终保不住资产；重鹅轻蛋，自己会被饿死。作者称这是七个习惯的基础。

三类资产各查一遍：物质资产（只用不保养→马力报废）、金融资本（本金＝产能、利息＝产出；动用本金＝杀鹅取蛋；最宝贵的金融资本是赚钱的能力）、人力资本（婚姻与亲子——权威式与纵容式管教都只盯金蛋；「你希望员工怎样对待顾客，就要怎样对待员工」）。团体版：机器昼夜运转不维修，前任拿金蛋晋升、继任者接手「生病的鹅」，而账簿不记资产损耗。

地图：成熟模式图把成长分为依赖期（以「你」为核心）→ 独立期（以「我」为核心）→ 互赖期（以「我们」为核心）。两条硬规则：独立是重大成就但不是最高成就；只有独立的人才能选择互赖。次序「如同耕种与收获的次序无法颠倒」，但不必等完全掌握前三个习惯才开始后三个。

诊断入口：知道却做不到时，用习惯三要素定位缺口——知识（做什么/为何做）、技巧（如何做）、意愿（想要做），三者缺一不可。

判停点：一次性短任务的单笔取舍不适用（P/PC 度量长期平衡）；「产能」不等于「少产出」——平衡不是牺牲产出。

## A1 — 书中的应用 (Past Application)

### 案例 1: 鹅与金蛋——效能的定义来源
- **类型**: 书中演练（第二章）
- **问题**: 农夫每天从鹅圈拿到一个金蛋，不久成富翁；财富让他贪婪又急躁，无法满足于每天一个金蛋
- **方法论的使用**: 他异想天开地把鹅宰杀，想将鹅肚子里的金蛋全部取出；柯维由此提出效能的两要素——产出（金蛋）与产能（下金蛋的鹅，即生产的资产或能力）
- **结论**: 重蛋轻鹅保不住资产，重鹅轻蛋会被饿死；效能在于产出与产能的平衡（P/PC Balance）
- **结果**: 鹅死，再也无法得到金蛋

### 案例 2: 电动割草机——只使用不保养的代价
- **类型**: 作者亲历（第二章）
- **问题**: 柯维购得一台电动割草机，只知使用、从不保养
- **方法论的使用**: 头两个季度正常，第三个季度出故障；想修时发现引擎马力已损失一大半，等同废铁
- **结论**: 若早花功夫在产能（保养）上，就能继续享受产出（修整过的草坪）
- **结果**: 割草机报废，不得不花费更多时间和金钱更换新机器——不符合效能原则

### 案例 3: 机器日夜运转的人得晋升，继任者接手「生病的鹅」
- **类型**: 书中转述（第二章）
- **问题**: 公司扩张期，某人管理一部机器，急于讨好领导
- **方法论的使用**: 让机器日夜不停地极速运转、从不维修保养，产量增、成本降、利润涨（金蛋漂亮）；会计账簿只列产量、成本与利润，不记资产的损耗
- **结论**: 制度性的记账盲区奖励了破坏产能的行为——损失算到接替者头上，而不是破坏资产的前任
- **结果**: 前任获得晋升；继任者面对成本飞涨、利润锐减

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对任何「短期 vs 长期」取舍：业绩与保养、成绩与亲子关系、省钱与信誉、加班与健康——想知道该保哪一头
2. 「我知道该做，就是做不到」——需要定位缺的是知识、技巧还是意愿
3. 想给自己或团队定位：现在处于依赖/独立/互赖哪一段，先练哪个习惯
4. 组织现象：前任数据漂亮、后任接手即下滑；考核只看产出、不看资产与团队状态
5. 想做一次系统的自我评估，找一份量化自测的底座

### 语言信号

- 「先把业绩做上去，保养/关系以后再说」
- 「我知道该做，就是坚持不下去」
- 「我们到底该从哪个习惯开始练？」
- 「这个季度目标漂亮，但明年的本钱呢？」
- 英文: "we need results now", "short-term vs long-term tradeoff", "where do I start with the seven habits"

### 与相邻 skill 的区分

- 与 `inside-out` 的区别: 本卡依赖其范式概念——先懂「地图不是地域」，成熟模式图的次序主张才读得懂；本卡不重复范式检查动作
- 与 `put-first-things-first` 的区别: 本卡是度量（这件取舍在消耗还是在养护产能），习惯三是操作（把时间投向哪里）
- 与 `sharpen-the-saw` 的区别: 习惯七是产能的自觉维护（四层面更新），本卡是判断「需不需要维护、维护哪一侧」的度量
- 与 `reading-and-index` 的区别: 总纲按成熟度给自己定位，索引按症状给章节定位——两套定位工具

## E — 可执行步骤 (Execution)

1. **指认对象与「鹅」**
   - 完成标准: 写出本次诊断的对象（个人 / 一段关系 / 一类资产 / 一个团队），以及这次要保护的产能（鹅）是什么
   - 输入契约: 一个正在做的取舍或一个反复失衡的场景

2. **分离 P 与 PC**
   - 完成标准: 分别列出想要的产出（金蛋：业绩、成绩、整洁的房间、听话……）与产出赖以为生的资产或能力（鹅：健康、信任、关系、设备、赚钱的能力），各至少 1 条

3. **按三类资产做失衡扫描**
   - 完成标准: 对物质资产 / 金融资本 / 人力资本各问一遍——是否只使用不保养？是否在动本金或从不投资赚钱能力？是否只盯金蛋（权威式/纵容式）？标出命中的失衡模式（重蛋轻鹅 / 重鹅轻蛋）
   - 判停条件: 一次性短任务的单笔取舍，退出（本卡不回答一锤子买卖）

4. **为产能侧安排一笔投入**
   - 完成标准: 给被透支的一方安排一笔具体投入（保养、投资、关系时间、培训），写明它保住的是哪一个产出；同时防止把「产能」当成不产出的借口
   - 输出契约: ①对象 ②金蛋清单 ③鹅清单 ④命中的失衡模式 ⑤投入安排

5. **设复查点与定位（可选）**
   - 完成标准: 约定下个周期的复查点（原书未给周期，需使用者自定）；如需系统自评，按书中「付诸行动」的 27 题流程定位——注意自评图刻度区 OCR 严重错乱，使用前须回源核对

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性短任务：P/PC 度量针对长期平衡，不适用于一锤子买卖的取舍
- 把「产能」误读为「少产出」——平衡不是牺牲产出，而是两者一起看

### 作者在书中警告的失败模式

- ce16 / ce17 伪独立与「生产标兵」：以独立之名抛妻弃子、逃避责任；只知独立不懂互赖者与「优秀领导」「最佳合作者」无缘
- ce18 物质与金融资产失衡：割草机不保养、本息不分——动用本金改善生活＝杀鹅取蛋，不投资赚钱的能力则经济上受制于人
- ce19 婚姻里操控对方、互列证据：只顾满足自己的需要、维护地位，爱情这只鹅日益虚弱
- ce20 权威式与纵容式管教都只盯金蛋：忽略子女的责任感、自律能力和自信心，青春期便无法施加积极影响
- ce21 唠叨、威胁、吼叫换整洁房间：只要产出，牺牲的是孩子的健康与幸福
- ce12 「我现在就想得到」：透支式速成、为现在牺牲一切，把健康、家庭、品德放在工作之后

### 作者的盲点 / 时代局限

- 自评表与对照表 OCR 损毁（只引正文叙述句；题号-分值对应与刻度不可靠）
- 成熟模式图的阶段论跨文化适用性未讨论
- 把「独立→互赖」设为普遍次序属价值主张，无实证对照

### 容易混淆的邻近方法论

- `put-first-things-first`: 本卡是度量（金蛋还是鹅），`put-first-things-first` 是操作（先做哪件事）；先度量再排程
- `inside-out`: 本卡依赖 `inside-out` 的范式概念（地图不是地域），不能反过来把总纲当作前提使用
