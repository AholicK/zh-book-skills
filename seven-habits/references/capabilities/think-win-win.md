# 双赢思维：六种模式与五个要领

## R — 原文 (Reading)

> 双赢既非损人利己（赢输），亦非损己利人（输赢）。我们的工作伙伴及家庭成员要从互赖式的角度来思考（'我们'，而非'我'）。
>
> ……
>
> 双赢的原则是所有人际交往的基础，包括五个独立的方面："双赢品德"是基础，接着建立起"双赢关系"，由此衍生出"双赢协议"，需要"双赢体系（结构）"作为培育环境，通过双赢的"双赢过程"来完成，因为我们不能用赢/输或输/赢的手段达到双赢的目的。

## I — 方法论骨架 (Interpretation)

双赢不是一种态度，而是一组条件同时成立时的结果。判与做的顺序：

1. **先认清模式**——人际交往有六个模式：利人利己（双赢）、损人利己（赢/输）、舍己为人（输/赢）、两败俱伤（输/输）、独善其身（赢）、好聚好散（无交易）。判定依据是**结果如何分配**，不是自我描述（伪双赢：自认双赢、实为输/赢）。六种模式各有适用边界，「最好的选择依情况而定」；但在相互依赖的环境中，「长远来看，不是双赢，就一定是两败俱伤」。
2. **按固定次序修条件（五个要领）**——品德（诚信、成熟、知足；成熟＝敢作敢为与善解人意的平衡，其定义转述自赫兰德·萨克森年教授的研究结论）→ 关系（信用即情感账户；没有信用，最多只能妥协）→ 协议（五要素：预期结果 / 指导方针 / 可用资源 / 任务考核 / 奖惩制度）→ 体系（奖励结构决定行为：提倡双赢却奖励赢/输，结果注定失败）→ 过程（四步骤找方案）。链条不可倒置、不能跳步，「不能用赢/输或输/赢的手段达到双赢的目的」。
3. **做双赢过程**——四步骤：从对方的角度看问题 → 认清主要问题和顾虑（而非立场）→ 确定大家都能接受的结果 → 找到实现这种结果的各种可能路径（后两步展开在习惯五、六）。
4. **兜底**——实在无法达成共识就「好聚好散」（放弃交易）；对配偶、子女等持续性关系，妥协是双赢的较低形式。

完成标准：给出①当前模式判定及结果分配证据 ②五要领中的第一个断裂点 ③与断裂点对应的修复物（存款设计 / 协议草案 / 奖励结构调整）④谈不动时的兜底决定。协议中的具体时限与奖惩额度原书未给统一数值，需使用者自定。

## A1 — 书中的应用 (Past Application)

### 案例 1: 大型连锁商店总裁：「双赢太理想化」的辩论
- **类型**: 作者亲历（第七章）
- **问题**: 柯维的客户是一家大型连锁商店的总裁，他认为「双赢的观念的确不错，可惜太理想化。商场现实无情，不与人争，只有被淘汰」。
- **方法论的使用**: 柯维逐句追问——「难道让你盈利，让顾客吃亏就现实了吗」（会失去顾客）、做赔本生意也不现实；对方承认与顾客的关系的确如此，但认为和供应商不一样，柯维提醒「对供应商来说，你不就是顾客吗」。他又说起最近同商场经营者与业主谈新租约时以双赢为目的，对方却当作软弱、让他们无利可图——柯维指出这正是输/赢模式：你们输了。
- **结论**: 分析长期效应后断定：平静关系下面涌动着压抑的情感、被践踏的价值和隐藏的怨恨，最终将导致两败俱伤；所谓「双赢」实质是输/赢（伪双赢）。
- **结果**: 总裁意识到自己所谓的双赢实质是输/赢模式（L8896-8900）；柯维建议以双赢态度多与业主交流、听取意见并勇于表达，寻找「第三条道路」（L8902-8906）。

### 案例 2: 小型电脑公司退约：放弃 48000 美元，三个月后得 24 万美元
- **类型**: 书中转述（第七章）
- **问题**: 一家小型电脑公司受聘为银行设计全套新软件，合约一签 5 年；一个月后银行总裁换人，新总裁对产品有意见、员工也难适应，要求更改合约。当时该公司财务状况并不好，坚持依约行事「损人却不一定利己」。
- **方法论的使用**: 负责人身体力行「不能双赢就好聚好散」——同意取消合约、退回定金，并说日后欢迎再光顾；「就这样我放弃了一笔48000美元的生意……可是我相信，坚持原则一定会有回报」。
- **结论**: 非双赢的方案即使能强行履约也会伤害长远关系；主动放弃交易保住了信用与善意。
- **结果**: 3 个月后，那位新总裁再次打来电话，带来另一笔总价 24 万美元的生意（L8940）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一段合作、谈判或家庭决策里反复出现「谁赢谁输」的争法，或一方总在退让
2. 组织口头提倡合作，实际按竞争规则发奖励（评优、排名、唯一名额）
3. 自己一直在「当好人」：让利、忍耐，事后积怨
4. 手里有一个自称双赢的方案，需要验证是真双赢还是伪双赢
5. 合伙、开店、签长约之前，需要约定谈不拢时的退出机制

### 语言信号

- 「商场如战场」「不与人争，只有被淘汰」
- 「这次我先让一步」「我都行，听你的」
- 「凭什么总是我吃亏」
- 「我们提倡合作，可是奖励只有一个名额」
- 英文: "win-win is too idealistic", "someone has to lose", "business is war"

### 与相邻 skill 的区分

- 与 `emotional-bank-account` 的区别: 那条度量关系的信任存量（账户余额）；本卡把它当作五要领中「关系」一环的条件，再继续检查协议、体系、过程
- 与 `seek-first-to-understand` 的区别: 那条做「先倾听」这一步工序；本卡负责模式判定与条件链诊断，双赢过程的第一步会调用它
- 与 `synergize` 的区别: 双赢是目标与条件框架（含「好聚好散」的退出）；在具体分歧上创造第三方案是 `synergize` 的职责
- 与 `responsible-delegation` 的区别: 两卡共用协议五要素结构，但口径有差异——授权版「责任归属」对绩效版「任务考核」，引用时须注明来源

## E — 可执行步骤 (Execution)

1. **识别模式**
   - 完成标准: 把当前关系/谈判判定为六种模式之一（含「伪双赢」），判定依据是结果如何分配，不是双方的口头说法；写出支持判定的事实清单
   - 输入契约: 一段具体的合作关系或谈判 + 近期可核实的往来；缺事实时先请用户举例，不许代替用户臆断

2. **五要领逐层诊断**
   - 完成标准: 按 品德 → 关系 → 协议 → 体系 → 过程 逐层检查，明确指出第一个断裂点；体系层固定检查「奖励什么」与「提倡什么」是否一致
   - 判停条件: 若断裂点在品德/关系（信任存量不足），先转 `emotional-bank-account` 做存款设计，本卡只保留诊断结论

3. **修复断裂点**
   - 完成标准: 产出与断裂点对应的修复物——协议缺口 → 按五要素（预期结果 / 指导方针 / 可用资源 / 任务考核 / 奖惩制度）起草，含「方法不计」与自我评估机制；体系缺口 → 列出奖励规则修改建议并附「你鼓励什么就会得到什么」的自洽检查；过程缺口 → 进入第 4 步
   - 输出契约: 修复物草案（一份协议 / 一份奖励结构对照表 / 一份路径清单）；具体参数原书未给，需使用者自定

4. **走双赢过程四步**
   - 完成标准: ①能复述对方的想法、需要与顾虑（先转 `seek-first-to-understand` 完成倾听）②把议题从立场还原为问题与顾虑 ③确定双方都能接受的结果 ④列出多条实现路径
   - 判停条件: 对方坚持赢/输且拒绝条件修复时，进入第 5 步，不硬谈

5. **兜底决策**
   - 完成标准: 给出「好聚好散（放弃交易）」或「妥协（双赢的较低形式）」的明确决定与理由；对配偶、子女等持续性关系写明为何妥协（原书：那里妥协更好）
   - 输出契约: ①模式判定 ②第一个断裂点 ③修复物/过程结果 ④兜底决定

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对方毫无诚意、或交易本身不成立的场合——改用「好聚好散（无交易）」直接退出，不勉强维持
- 把双赢当话术去劝对方让步：品德/关系/协议/体系不动，只讲「我们要双赢」，就是作者判定的「无效的表面功夫」
- 体系不配套时不要启动双赢谈判：**不能用赢/输或输/赢的手段达到双赢的目的**——口头提倡双赢却奖励赢/输，结果注定失败（ce84）
- 并非所有决定都要以双赢为目的：时间紧迫、情感账户充足时可以直接支持对方（原书：「希望自己是错的，而你是对的」）

### 作者在书中警告的失败模式

- ce13: 把「赢」当作唯一——把同学、同事、家人都当竞争对手，「你周围的人得到的越多，留给你的就越少」
- ce75: 赛马图——口头高唱互助合作，实际以「百慕大之旅」奖励唯一胜出的经理；「治标不治本」，关键要建立突出合作价值的奖励机制
- ce76: 赢/输模式的文化温床——家庭比较、学校正态分布曲线、运动比赛；「赢/输模式是这种合作的最大障碍」
- ce77: 输/赢（舍己为人）——没有标准与期望地取悦他人；「被压抑的情感并不会消失」，累积后以更丑恶的方式爆发
- ce78: 在赢/输与输/赢之间摇摆——无法忍受混乱就转强硬，内疚日增又回纵容，愤怒与挫败感循环累积
- ce79: 输/输（两败俱伤）——为报复不惜牺牲自身利益（一万美元汽车以五十美元出售）；「谋杀等于自杀」
- ce80: 独善其身（赢）——「别人输不输都无所谓」；在互赖关系里等于放弃合作与信任投资
- ce81: 伪双赢——自认双赢、实为输/赢；「平静的关系下面涌动着的是压抑的情感、被践踏的价值和隐藏的怨恨，最终将导致两败俱伤」
- ce83: 传统权威型监督——情感账户透支的结果：「没有信任，就想对下属时时操控」
- ce86: 合伙生意不设退出条款——事业的繁荣导致关系破裂；家族式/友谊型生意启动前先约定「不能双赢就好聚好散」

### 作者的盲点 / 时代局限

- 双赢核对表区域（L9672-9684）转档 OCR 错乱严重：引用须回源核对或回避，本卡只取可辨识的正文叙述
- 双赢在**权力严重不对等**场景（裁员谈判、巨头与小微供应商）中的适用前提未讨论；「以礼相待、尊重对方」的操作建议默认双方都有议价空间
- 体系论（「问题都源于体系，而不是人」）与个人责任框架存在张力：先查体系不等于免除当事人的选择责任，两者边界原书未交代

### 容易混淆的邻近方法论

- `emotional-bank-account`: 账户余额是本卡五要领中「关系」一环的度量；余额不足时先做存款，而不是直接谈协议
- `responsible-delegation`: 两卡共用协议五要素结构，授权版口径是「预期成果 / 指导方针 / 可用资源 / 责任归属 / 明确奖惩」，本卡的绩效版是「预期结果 / 指导方针 / 可用资源 / 任务考核 / 奖惩制度」——引用须注明来源
- `seek-first-to-understand` / `synergize`: 先倾听是双赢过程的第一步工序；分歧场景下创造第三方案转 `synergize`；妥协只是本卡的低阶出口，不是目标
