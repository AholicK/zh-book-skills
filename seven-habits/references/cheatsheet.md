# 决策规则速查 — 《高效能人士的七个习惯：30周年纪念版》

| 能力 | 一句话规则 |
|---|---|
| 由内而外：品德成功论与思维方式转换 | 先检查心里那张地图，再换做法——技巧治标，品格与思维方式的转换才治本 |
| 七个习惯总纲：成熟模式图与效能（P/PC）定义 | 先问金蛋还是鹅：效能＝产出与产能的平衡——重蛋轻鹅与重鹅轻蛋都是失衡 |
| 积极主动：选择的自由与影响圈 | 把「他/环境让我……」改写成「我选择……」，再问这件事落在影响圈还是关注圈 |
| 以终为始：两次创造与使命宣言 | 先写下「盖棺定论时希望被怎样评价」（使命与角色），再比较眼前的选项。 |
| 生活中心诊断与以原则为中心 | 问「我此刻以什么为中心」——九种中心里认出你正在被哪种扭曲，再换到以原则为中心。 |
| 领导与管理的区分 | 先问「这是不是正确的事」（领导），再问「怎样把它做对」（管理）——别在错误的墙上爬梯子。 |
| 要事第一：四象限诊断与第四代时间管理 | 先把下周的资源挪向第二象限（重要不紧急），再谈效率——要事不能放在第二。 |
| 责任型授权 | 把「我不敢放手」写成一份五要素协议：预期成果 / 指导方针 / 可用资源 / 责任归属 / 明确奖惩。 |
| 情感账户：人际关系的信任储蓄 | 关系先看余额：列出存款与提款，再设计一次小小的存款——长期关系没有速效术。 |
| 双赢思维：六种模式与五个要领 | 先认清这是六种模式里的哪一种，再修条件：品德→关系→协议→体系→过程；不行就好聚好散。 |
| 知彼解己：移情聆听与表达 | 先诊断后开方：先复述对方的感受与需要，等对方觉得被理解，再表达自己。 |
| 统合综效与第三条道路 | 不争我的方式、不取你的方式——把分歧当资源，一起找第三种方案。 |
| 不断更新：四个层面的自我更新 | 先看四个层面哪一层在亏空，再安排每天至少一小时的更新——锯树之前先磨锯。 |
| 由内而外深水区：代际传承与转型者 | 这条延续了几代的模式可以在你这里画句号：在刺激与回应之间用上「距离」，再选回应。 |
| 阅读方法与全局索引工具 | 以老师角色读：48 小时内讲给别人听；找不到该读哪里就查「挑战/机遇索引」。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
