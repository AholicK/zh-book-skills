# 《高效能人士的七个习惯：30周年纪念版》 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 临床心理治疗、精神疾病诊断与用药；出现自伤或伤人风险、持续两周以上低情绪等指征时应建议就医。
- 正在发生的暴力、人身安全危机与灾难现场（先确保安全并联系专业机构）。
- 法律争议、劳动争议、财务与投资的正式专业处置。
- 把本书当作评判他人或要求他人改变的工具（它是自我修炼的方法，不是改造别人的杠杆）。

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 由内而外：改变从思维方式与品德开始，技巧只居次要——先检查地图，再换做法。
2. 效能是产出（金蛋）与产能（鹅）的平衡——任何取舍先问：这件事在消耗还是在养护长期能力？
3. 习惯 = 知识 + 技巧 + 意愿（做什么 / 如何做 / 想要做），三者缺一不可。
4. 次序不可颠倒：个人领域（习惯一至三）先于公众领域（习惯四至六）；依赖 → 独立 → 互赖，只有独立的人才能选择互赖。
5. 刺激与回应之间存在距离：把资源投向影响圈与第二象限，而不是关注圈与紧急之事。
6. 公众领域的两条硬规则：先理解对方再求被理解；不能双赢就好聚好散。
7. 改变是螺旋不是一次顿悟：四层面（身体/精神/智力/社会情感）的持续更新是其余一切习惯的产能保障。

## 边界与判停

- 用户要求用「积极主动/影响圈」要求某人（或自己）为结构性不公、受害经历承担全部责任时，停止，并说明该框架的边界（受害者有罪论风险）。
- 用户把「双赢/统合综效」用作劝对方让步的话术，或为已发生的操控、报复、惩罚行为寻找正当性时，停止，回到「先修条件（品德/关系/体系）再谈方案」的纪律。
- 涉及具体健康数据（心率、训练处方、饮食）时只保留原书表述，不得扩展为医学建议；用户寻求医疗建议时转专业渠道。
- 用户处于急性情绪危机（惊恐发作、自杀意念等）时，停止方法论练习，先建议寻求紧急支持（如心理热线或就近就医）。
