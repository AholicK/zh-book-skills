# 决策规则速查 — 《Python编程从入门到实践》

| 能力 | 一句话规则 |
|---|---|
| 环境搭建与运行排障（第1章 起步） | 装不上、跑不起来：先确认版本与命令名（python / python3 / 完整路径），再按「检查→安装→配置→运行→七步排障」走，不盲装。 |
| 变量、字符串与数字基础（第2章） | 报错先分型：NameError 查赋值与拼写，SyntaxError 查引号与括号，TypeError 查是否漏了 str()/int() 转换。 |
| 列表操作与 IndexError 排障（第3章） | 列表操作先选型：按位置删除用 del/pop、按值用 remove、保留原序用 sorted；报 IndexError 先做「索引减 1」核对。 |
| 遍历、切片与代码格式（第4章） | 遍历用 for，复制列表用 [:]（直接赋值只是同一个列表的别名）；range 边界「加 1」核对，缩进错误先查冒号与空格。 |
| 条件测试与 if 结构选型（第5章） | 互斥分支用 if-elif-else，可能同时成立的条件用独立 if；空列表先判空、比较前先归一大小写。 |
| 字典与嵌套建模（第6章） | 字典建模：增改用赋值、删除用 del、遍历选 items/keys/values；不依赖顺序，要顺序就 sorted。 |
| 用户输入与 while 循环（第7章） | 交互程序=先给状态初值+可终止条件+体内推进；input() 一律是字符串，数值比较前先 int()。 |
| 函数与模块化（第8章） | 优先关键字实参、收集形参放最后；返回值别拿去 print；导入优先「import + 句点」，不用星号。 |
| 类与继承（第9章） | 类名驼峰、属性全部在 __init__ 赋初值；继承先 super().__init__()、重写必须同名；组合优于深继承。 |
| 文件读写、异常与重构（第10章） | 文件用 with 管关闭、写入前想清楚 'w' 会清空；异常三段分工 try 装载、except 兜底、else 才统计。 |
| 单元测试 unittest（第11章） | 测试=import unittest+TestCase 子类+test_ 方法+unittest.main()；测试红了修代码，不改测试。 |
| Pygame 游戏项目起步（第12章上半） | 做游戏先搭最小骨架（事件循环+刷新），参数集中进 Settings，加新功能前先重构。 |
| 飞船操控与子弹编组（第12章下半） | 持续移动用标志位、同时按键用两个独立 if；删除编组元素必须遍历副本。 |
| 外星人群与碰撞检测（第13章） | 敌人先网格后移动：int() 向下取整、触边整群下移换向、碰撞 groupcollide 双 True。 |
| 记分、升级与游戏状态管理（第14章） | 状态先分归属（每局重置 vs 跨局保留），重开照重置清单逐项核，计分遍历碰撞字典。 |
| 数据可视化：matplotlib 与 Pygal（第15章） | 画图先跑通最简版再逐项定制：折线传 x/y 两个列表，散点去轮廓，保存用 savefig。 |
| CSV/JSON 解析与清洗（第16章） | 外部数据先打印核对再可视化：表头定位列号、缺测打印跳过、字符串数值先 int(float()）。 |
| Web API 取数：GitHub 与 Hacker News（第17章） | 调 API 三步：拼 URL→核验 status_code→打印结构再取字段；数字是实时快照，别当固定值。 |
| Django 项目入门：模型、迁移、视图与模板（第18章） | Django 三阶段循环 URL→视图→模板；改模型必走 makemigrations+migrate 三步。 |
| 用户账户与数据归属（第19章） | 表单 GET/POST 双分支；数据归属三道闸：@login_required、filter(owner=)、不匹配 Http404。 |
| 样式与部署：Bootstrap、Heroku 与安全加固（第20章） | 部署前把漂移检查做完：/app 条件块、Procfile、.gitignore、DEBUG=False 一个不落。 |
| 安装与编辑器参考（附录A–B） | 装 Python 三步：先查版本→按平台安装→新终端复验；Path 只追加不覆盖。 |
| 调试与求助方法论（附录C） | 卡住先三问（做什么/试过什么/结果如何），再橡皮鸭子复述、重做→休息→整条错误搜索，最后才发问。 |
| Git 版本控制（附录D） | 提交=可行状态快照：add→commit→status 看到 clean；回退分级使用，reset --hard 仅限单人项目。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
