# 直觉判断偏差的诊断与纠偏

## R — 原文 (Reading)

> 如果人们积累了足够多的专业知识，他们就可能凭直觉获得问题的答案。

— 第3章 · 社会信念和判断

> 在63%的情况下，访谈者猜对了答案，超过概率水平13%，但是平均来看，他们对自已的猜测有75%的确信度。

— 第3章 · 社会信念和判断

> 要在没有相关的地方看到相关很容易。当我们期待发现某种重要的联系时，我们很容易会将各随机事件联系起来，从而知觉到一种错觉相关（illusorycorrelation）。

— 第3章 · 社会信念和判断

## I — 方法论骨架 (Interpretation)

这张卡管一件事：一次「凭感觉」的判断，能不能信、错了以后怎么纠。它不先回答「直觉好不好」，而是先设一道门槛：**直觉只在有足够专业积累的领域可用**——技能由有意遵守的规则逐步自动化，专家能一眼读出一盘棋的意义，新手意识不到。跨过门槛之前的「跟着感觉走」，产出多半是对自己莫名行为的即时虚构解释。

门槛之内，判断偏差仍有稳定的「签名」。作者在第 3 章给出的清单，每条都带可核对的口径：

- **过度自信**：实际命中率减自评确信度，差额就是偏差的估计——63% 命中配 75% 确信、98% 自信区间外有约 30% 的正确答案、专家 80% 确信而实际正确率不足 40%；且最自信的人恰恰最容易过度自信（pB2-04）。
- **信念固着**：为结论写过理由之后，即使证据被彻底否定，解释仍独立存活——只有 25% 的人接受新结论（pB2-02）。
- **验证性偏差**：人更愿意证实而非证伪——29 人里 23 人用「只检验支持例证」的方式找到错误规律（pB2-06）。
- **错觉相关与控制错觉**：期待联系就会在随机数据里看到联系；把随机结果当成自己能影响的对象（pB2-12、pB2-13）。
- **趋均数回归**：极端分数下一次必然向均值回落，「最差时介入然后好转」不构成疗效证据（pB2-14）。

纠偏工具箱与偏差一一对应：对信念固着，**解释相反的观点**——自问「假设我是一个持相反观点的人，我是否会得出同样的结论」，而「尽可能客观无偏见」的口号被实验证明无效（fB2-01）；对验证性偏差，把检验程序改成「先问什么会证明我错了，再去找那个结果」（fB2-03）；对过度自信，三件事——即时反馈、分解任务分别估计、强制写出判断可能出错的原因（fB2-04）；对错觉相关，去清点「没有同时出现」的那一栏（pB2-12）；对趋均数回归，只认与同类基线或对照组的比较（pB2-14）。

整条流水线是：**先判直觉门槛 → 对号识别签名偏差 → 用对应纠偏动作 → 落成一个可证伪的对照观察**。它产出的是修正后的判断和检验点，不是「从此不再犯」的保证。

## A1 — 书中的应用 (Past Application)

### 案例 1: 克鲁格与邓宁——能力不足反而过度自信
- **类型**: 实验室实验（第3章）
- **问题**: 为什么缺乏能力的人常常意识不到自己缺乏能力
- **方法论的使用**: 克鲁格与邓宁（Kruger & Dunning, 1999）检验「对能力的认识也是需要能力的」：在语法、幽默与逻辑测验中比较被试的实际得分与自我估计的差距；卡普托与邓宁（2005）进一步用实验观察人们如何忽视自身缺陷
- **结论**: 得分最低的学生最可能高估自己的才能——不知道何谓好的语法逻辑的人，也不知道自己缺什么
- **结果**: 书中未说明该发现的后续应用；作者提醒这一结果常被误传为「越无知越自信」，原文限定在特定测验任务上

### 案例 2: 沃德与詹金斯造云实验——在随机数据里看到相关
- **类型**: 实验室实验（第3章）
- **问题**: 预期会不会让人在纯随机数据里读出规律
- **方法论的使用**: 向被试报告一个假想的 50 天造云试验——哪几天造了云、哪几天下了雨，数据只是随机混合，然后测被试知觉到的「造云—下雨」相关
- **结论**: 人们仍确信看到了相关，且相关方向与其原有信念一致；机制是注意与记忆的偏向——相信有联系就更可能注意并回忆支持性证据
- **结果**: 这成为「错觉相关」的经典演示：任何「我注意到一个规律」的结论都需要统计核对

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 复盘一次重大误判，想知道「我为什么做了这么蠢的判断」
2. 想凭直觉快速定案，不确定这份「感觉」能不能信
3. 预估工期、概率、结果时总是偏乐观，越自信越错
4. 被第一印象锚定之后，即使新证据不利也改不掉看法
5. 「我亲眼看到规律了」——想把一个经验规律核验成真规律

### 语言信号

- 「我总觉得这事儿能成，说不上来为什么」
- 「我是干这行的，一看就知道」
- 「我确定不会错 / 这规律我亲眼验证过」
- 「自从我做了那个调整，一切就好起来了」
- 英文: "I just have a gut feeling", "I'm 100% sure about this", "I've seen this pattern before"

### 与相邻 skill 的区分

- 与 `self-bias-audit`（v02）的区别: v02 管对自己的认知偏差；本卡管对事对人的判断过程
- 与 `attribution-and-expectancy`（v05）的区别: v05 专管对他人行为的归因与期望循环；本卡是一般判断偏差
- 与 `evidence-vs-causation`（v01）的区别: v01 管研究证据判读；本卡管自己头脑里的判断过程

## E — 可执行步骤 (Execution)

1. **把判断写成命题**
   - 完成标准: 当前结论被改写成一句含数量/可观察对象的话（「调整工位让业绩变好」→「调整后第 N 个月比此前均值高 X%」）
   - 输入契约: 一次判断 + 支撑它的依据；说不出依据时追问「你是从哪几个例子得出它的」，不替用户补例子

2. **过直觉门槛**
   - 完成标准: 明确回答两问——该领域是否积累了足够专长？是否存在清晰即时的反馈（如气象预报员式的每日对账）？
   - 判停点: 高风险决定 + 无专长 + 无反馈时，本卡禁止用直觉定案，先转入收集信息

3. **对号识别签名偏差**
   - 完成标准: 从清单（过度自信 / 信念固着 / 验证性偏差 / 错觉相关 / 控制错觉 / 趋均数回归 / 概率性忽视）中至少指出 2 条与当前判断同形的候选偏差，并说明对应证据（确信度-命中率差额、有没有写过理由、有没有清点反例栏、介入是否发生在最低谷）

4. **执行对应纠偏动作**
   - 完成标准: 至少完成一项——写下「什么会证明我错了」并去找该结果；写出反对当前结论的最强理由；把「我很确定」换算成数字区间；找出同期未干预的对照基线
   - 输出契约: 给出①原判断 ②命中的偏差 ③纠偏后修正的判断 ④仍不确定之处

5. **落一个可证伪的观察点**
   - 完成标准: 写出未来可核对的一次观察（时间点 + 指标 + 对照口径），能明确回答「看到什么结果就算我错了」

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要当机立断的高压现场——作者明说纠偏不应摧毁果断性，「基于现实的自信是有适应意义的」（fB2-04 边界）
- 已有充分即时反馈且成绩优异的领域（预报员、赔率设定者式环境）——此时自查收益很低，直觉本身就是校准过的
- 评估他人动机或做道德评判时——本卡只处理判断过程，不给人定性

### 作者在书中警告的失败模式

- **信念固着**: 为错误信念编出解释后，即使被告知最初证据是捏造的，仍只有 25% 的人接受新结论（ceB12-16）
- **「要客观」的口号无效**: 死刑支持者与反对者阅读同一份混合证据，加上「尽可能客观无偏见」的指导语与不加一样偏（ceB12-17）
- **过度自信**: 约 30% 的正确答案落在被试 98% 的自信区间之外；能力不足反而促进过度自信；公认专家 80% 确信的长期预测实际正确率不足 40%，出错后仍认为「我基本上是正确的」（ceB12-19、ceB12-20、ceB12-21）
- **验证性偏差**: 2-4-6 任务中 29 人里 23 人检验的全是支持性例证，发现错误规律却个个确信不疑（ceB12-22）
- **错觉相关**: 50 天造云数据纯属随机，人们仍确信看到相关（ceB12-25）
- **控制错觉**: 选号彩票、掷骰子力度、自己选股都会制造「我能影响随机结果」的感觉，并带来交易成本之外的损失（ceB12-26）
- **趋均数回归**: 随机数据里哈罗德被批评后第二天通常「改善」，学生因此确信批评有效——批评其实毫无作用（ceB12-27）

### 作者的盲点 / 时代局限

- **硬边界（pB2-16）**: 「努力尝试还是不能消除思维上的偏见即使用报酬来奖励正确的作答，从而激励被试以最理想化的方式思考，某些偏见和扭曲仍然存在。」——**知道偏差不等于消除偏差**。偏差与智力关系可忽略，本卡只能降低而非清除偏差，一切交付物以此为期望上限。
- 纠偏技巧多来自单一实验效应，书中未给出需要几轮、能否迁移到深度意识形态信念的剂量信息（fB2-01 边界）
- 书中同一章承认训练能改变归因习惯（学过心理学的学生解释行为更「不单纯」），但未据此宣称一般性偏差可被训练消除——训练与消除之间的证据缺口是作者自己留下的
- 部分核心素材（如启动实验）此后处于可重复性争议中，书中正文未回溯修订；引用具体效应量时应保留怀疑

### 容易混淆的邻近方法论

- `attribution-and-expectancy`: 对「某个人为什么这样做」的解释，走那卡的归因判定表；本卡的清单管非人际的判断与估计
- `evidence-vs-causation`: 评估外部研究证据时用那卡；评估自己脑内结论时用本卡
