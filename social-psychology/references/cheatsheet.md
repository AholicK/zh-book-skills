# 决策规则速查 — 《社会心理学》（第 11 版）

| 能力 | 一句话规则 |
|---|---|
| 证据判读与常识陷阱（研究怎么读、结论能走多远） | 先问研究设计（相关还是实验、样本怎么来的），再决定这条结论能信多远。 |
| 自我认知偏差自查（焦点效应、自我服务偏差与防御性乐观） | 把「都怪别人/我肯定没问题」翻译成可检查的自我服务偏差清单，再用过往实际数据校准。 |
| 可控性、自我效能与自我控制 | 把「放弃」从态度问题改判为可控性分解问题：先测控制点与归因，再改环境与反馈。 |
| 直觉判断偏差的诊断与纠偏 | 用偏差清单（过度自信、启发式、错觉相关、趋均数回归）把「我感觉」翻译成可检验的对照设计。 |
| 归因与期望效应（三信息归因、基本归因错误、自我实现预言） | 解释他人行为先过三信息归因（一致性/区别性/共同反应），再检查自己的期望是否正在自我实现。 |
| 先改行为：态度改变与自我改变的因果链 | 改变自己先改行为再等态度：小量启动、固定触发、减少外部理由。 |
| 性别与文化差异的归因判读 | 对「天生如此」类主张用两条检验回应：个体差异大于组间差异、社会角色理论的可检验预测；演化解释不可事后无限追溯。 |
| 从众与服从的情境诊断 | 把「我是不是太懦弱」改判为四个可改变的情境变量：群体规模、公开性、事前承诺、有无同伴榜样。 |
| 抵御社会压力（逆反、独特性与同伴榜样） | 抵御群体压力不靠勇气靠设计：先争取一名同类意见者，用保留自由感的措辞代替命令。 |
| 说服设计（路径选择与四要素配置） | 先判断对象走中心还是外周路径，再把可信信源、内容、渠道、受众四要素配齐。 |
| 抵制说服与态度免疫 | 识别被逐步说服的结构信号（渐进承诺、公开表态、社会内爆），用态度免疫提前建抵抗力。 |
| 他人在场效应（社会助长与社会懈怠） | 「人多人少」先分任务类型（简单优势反应/复杂任务），再查可识别性；匿名性方向由情境线索决定。 |
| 群体决策风险与群体思维预防 | 「开会没人反对」是风险信号不是共识：按八条症状诊断，用程序性对冲（领导后发言、魔鬼代言人、分组独立讨论）。 |
| 少数派影响与少数派策略 | 少数派影响多数靠一致性而非音量：坚持一致、就观点类议题表现自信、争取一名「背叛者」。 |
| 偏见与刻板印象的根源诊断 | 偏见不是坏人的问题：按社会（地位）/动机（内群体）/认知（类别化）三重根源结构诊断，干预归另一张卡。 |
| 减少偏见的条件改造与合作介入 | 减少偏见先核对三前提（平等地位、共同目标、制度支持），单次联谊大概率白做。 |
| 攻击行为的成因诊断与减少 | 攻击先分敌意性/工具性，再按挫折—攻击与社会学习定位成因；「发泄一下」没有证据支持，确定性优先于严厉性。 |
| 吸引与亲密关系诊断 | 「感情变淡」先分激情衰减（常态）与相伴之爱的缺失（问题），再查依恋、公平、表露三变量。 |
| 帮助行为与旁观者干预 | 旁观者不行动不是冷漠而是「人数多+模糊性高+无明确指示」：求助要指向具体的人并明确请求。 |
| 冲突的结构诊断 | 先分离「真实分歧 vs 误解」，再判定是否社会困境（各自的优势策略导致集体受损），对结构下刀而不是对人性下刀。 |
| 和解路径与冲突解决机制 | 和解有次序：接触→合作→沟通→和解，机制按谈判→调解→仲裁升级；GRIT 可单方主动，但完全合作会被倾轧。 |
| 临床判断偏差的校正 | 专家自信 ≠ 准确：统计预测普遍优于临床直觉；自我核对用记录与量表，不用回忆式确认。 |
| 抑郁、孤独与社会焦虑的认知机制与干预 | 「我完了」式判词按稳定/普遍/内在三维定位，选行为激活或归因重构一个点下手。 |
| 健康、应激与社会关系 | 压力伤身有三条可核对路径（社会孤立、应激反应、就医与依从），个人层面先做表达性写作与恢复固定社交联系。 |
| 目击者证词与陪审团判断 | 自信不等于准确：按观察条件与辨认程序评估证词强度，而不是目击者的确信程度。 |
| 可持续行为（气候、消费与政策） | 环保倡导是信息设计问题：把年度数字换成长期总额、给出社会比较反馈、区分提效与减量两条路径。 |
| 财富、物质主义与主观幸福感 | 「再赚一倍就幸福」不可信：阈值以上收入与幸福相关很弱，落差来自社会比较与享乐适应。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
