# 决策规则速查 — 《非暴力沟通》

| 能力 | 一句话规则 |
|---|---|
| 观察与评论的区分（含面对批评时的澄清序列） | 把「你总是……」改成对方无法反驳的具体观察，再开口。 |
| 感受反推需要（含听到不中听的话时的四种选择） | 从「我很难受」再往下问一层，找出真正没被满足的那个需要。 |
| 请求的构造与请求/命令的划界 | 把「你能不能上点心」改成对方能执行、也能拒绝的具体请求。 |
| 四要素倾听（含妨碍倾听十项自查与助人者五问） | 对方情绪激动时，先把他没说完的话替他说出来，而不是给建议。 |
| 充分表达愤怒（四步 + 先倾听后表达） | 生气时先找出是哪句话在脑子里点火，再把那句话换成需要。 |
| 自我同理与自我宽恕 | 自责的时候先听见自己的感受和需要，再决定要不要惩罚自己。 |
| 防卫性强制力与惩罚性强制力的判别 | 判断这一次动手是为了阻止伤害，还是为了让他长记性。 |
| 四要素表达（观察 → 感受 → 需要 → 请求） | 把一句抱怨拆成观察、感受、需要、请求四段，再开口。 |
| 感受与想法的区分（含感受词汇表的两分使用） | 把「我觉得被忽视」这类伪感受，换成真正的感受词。 |
| 用「选择做」代替「不得不」 | 把「不得不做的事」逐条改写成「我选择做，因为我要……」。 |
| 表达感激与接受感激 | 表达感谢时说清「你做了什么 + 我的感受 + 我的需要」，而不是「你真好」。 |
| 内心冲突与情绪压力（双声对话 + 需要转向） | 用双声对话把内心两个打架的声音分开，各自找出需要。 |
| 异化沟通方式的自查与替换 | 按四类异化沟通给自己的话做体检：道德评判、比较、回避责任、强人所难。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
