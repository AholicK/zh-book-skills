# 感受与想法的区分（含感受词汇表的两分使用）

## R — 原文 (Reading)

> 当我们说「我觉得」，我们常常并不是在表达感受，而是在表达想法。例如，有时我们会说：「我觉得这不公平。」在这句话中，「我觉得」换成「我认为」也许更恰当。
>
> — 第四章 · 区分感受和想法

## I — 方法论骨架 (Interpretation)

「我觉得」是中文与英文里最常用的开场白，也是最大的陷阱：它后面接的经常不是感受，而是判断、评价或推测。「我觉得这不公平」「我觉得他很过分」——这些句子说出的是**我对事情的裁定**，不是**我正在经历的情绪**。

一个可靠的机械检验：把「我觉得」替换成「我认为」。如果句意通顺，那原本就是个想法。

第二类陷阱是**伪感受词**：被抛弃、被羞辱、被虐待、被打扰、被拒绝、不受重视、被束缚、被欺负、无人理睬、得不到支持、无人赏识、被利用、被贬低。这些词看似描述情绪，实际都在描述「别人对我做了什么」或「别人是怎样的人」——它们把情绪的钥匙交到了对方手里。检验法：这个词是否在讲别人的行为？是 → 它是想法。

真感受词来自两栏对照：需要得到满足时（喜悦、感激、欣慰、期待……）与需要未满足时（害怕、忧虑、失落、沮丧、孤独……）。找到真感受只是中间站——它的真正价值是作为**通往需要的入口**：情绪是需要的信使。

## A1 — 书中的应用 (Past Application)

### 案例 1: 9 岁男孩说出「我很害怕」，被老师训斥
- **类型**: 作者亲历（第四章）
- **问题**: 作者 9 岁时放学后被几个男孩堵截，他躲在教室不敢回家
- **方法论的使用**: 老师发现后叫他离开学校，他说「我很害怕」，老师教训他「男孩子不要胆小怕事」
- **结论**: 感受被权威否定；后来他做运动员时，教练只看重「全力以赴」，他手腕骨折没接受治疗，忍痛打了一个月棒球
- **结果**: 作者以此说明「被压抑的心灵」——感受的表达能力是被环境训练掉的，不是天生没有

### 案例 2: 大学生室友音响太吵：「我没什么感受！」
- **类型**: 作者亲历（第四章，研讨班现场）
- **问题**: 一位大学生被问及室友深夜放音响时的感受
- **方法论的使用**: 他答「我觉得在晚上不该这么大声」（看法）；作者提醒「觉得」后接的不是感受，他再答「声音太大了就会打扰到别人」（仍是看法）
- **结论**: 两次尝试后他斩钉截铁地说「我没什么感受！」
- **结果**: 作者评论：他有强烈的感受，只是体会不到，更不用说表达它们了

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 自认为在表达感受，对方却听成了指责或评判
2. 分不清自己是在说感受还是在讲道理、下定论
3. 被问「你什么感受」时说不出来，只能用「好 / 不好 / 还行」应付
4. 想开口谈一件事，但一开口就是「我觉得他不尊重我」这类定性

### 语言信号

- 「我觉得他很过分 / 这不公平 / 你根本不在乎我」
- 「我说了我的感受，他反过来说我在骂他」
- 「我不知道自己到底什么感受」
- 只能用生理词（累、烦、头疼）代替情绪词
- 英文: "I feel like you…", "I feel that…"（后接从句多为想法而非感受）, "I don't know what I feel"

### 与相邻 skill 的区分

- 与 `observation-vs-evaluation` 的区别: 那条检查**行为层**（句子里是行为还是评价）；本 skill 检查**感受层**（句子里是感受还是判断）。「我觉得被忽视了」两句都踩，可先用本卡把感受找出来
- 与 `feelings-to-needs` 的区别: 本 skill 负责**找到**真感受，那条负责从感受**追到需要**并给出行动；找不到感受时用本卡，找到后接头给那条

## E — 可执行步骤 (Execution)

1. **取原句并做「我认为」替换检验**
   - 完成标准: 写出原句，把「我觉得」换成「我认为」；通顺 → 判定为想法，进入步骤 2；不通顺 → 进入步骤 2 用清单复核
   - 输入契约: 一句自称表达感受的话；用户说不出原句时，先请其复述最近一次「说了感受却被误会」的对话

2. **伪感受词清单比对**
   - 完成标准: 逐词对照伪感受清单（被抛弃 / 被羞辱 / 被拒绝 / 不受重视 / 被贬低……），标出句中被命中的词，并确认它描述的是「别人对我做了什么」
   - 判停条件: 若句子里找不到任何伪感受词也找不到真感受词（如「就那样吧」），跳到步骤 3 的词汇表辅助

3. **替换为真感受词**
   - 完成标准: 从「需要满足 / 需要未满足」两栏中各取参照，给出一个具体情绪词（不允许用「好 / 不好 / 还行」；允许先用身体感定位再映射）
   - 输出契约: 给出①原句 ②判定（想法 / 伪感受 / 真感受）③替换后的感受句

4. **衔接需要**
   - 完成标准: 为该感受指出一个与之相关的需要（如「失落 → 需要被看见」），把结果交给 `feelings-to-needs` 做完整推导
   - 判停条件: 若用户的目标不是自我表达而是提出请求，转 `requests-vs-demands`

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 本来就要下判断的场合（评估、定责、写结论）——此时应明说「这是判断」，而不是把它伪装成感受
- 对方只想要事实确认、不需要情感语言时，强行改写成感受反而降低效率

### 作者在书中警告的失败模式

- 伪感受把情绪责任外包：说「我被忽视了」，等于说「我的情绪由你负责」——这是内疚控制的语法基础（ce40 区域）
- 感受能力缺失是训练结果而非个人缺陷：学校二十年没人问过感受，「人们认为感受是无关紧要的」；律师、工程师、警察、经理等职业尤其困难——表达感受与职业形象相冲突（ce41）
- 「我觉得」后面接从句时，十有八九是想法——作者在无数场合都要先纠正这一点

### 作者的盲点 / 时代局限

- 感受词汇表带有英语词汇分类的假设，中文语境下的对应关系（如「憋屈」「窝火」等词的地位）书中未讨论
- 中文口语里「我觉得」常只作语气垫词，机械替换会失真——需要按句意而非字面操作
- 伪感受清单是开放清单，清单之外的灰色词（如「被期待」「被打扰但无所谓」）没有裁定规则

### 容易混淆的邻近方法论

- `observation-vs-evaluation`: 「我觉得被忽视了」同时是伪感受与隐式评论；两卡配合的顺序是先剥离行为层、再修正感受层
