# 四要素表达（观察 → 感受 → 需要 → 请求）

## R — 原文 (Reading)

> 首先，留意发生的事情。我们此刻观察到什么？不管是否喜欢，只是说出人们所做的事情。要点是，清楚地表达观察结果，而不判断或评估。接着，表达感受，例如受伤、害怕、喜悦、开心、气愤等等。然后，说出哪些需要导致那样的感受。
>
> — 第一章 · 非暴力沟通的要素

## I — 方法论骨架 (Interpretation)

这是全书的母流程，也是前面四张卡（观察 / 感受 / 需要 / 请求）的合成体：

**观察**（只说发生了什么，不评判）→ **感受**（说出真实情绪，不说想法）→ **需要**（是什么需要导致了这个感受）→ **请求**（希望对方做的具体行为）。

配套句式（附录：「非暴力沟通模式」）：
「当我（看、听、想到我看到的 / 听到的）……我感到……因为我需要 / 看重……你是否愿意……？」

三条使用规则：

1. **这是觉察顺序，不是台词**。作者明确说：「非暴力沟通不是固定的公式……精髓在于对其四个要素的觉察，而不在于使用什么字眼进行交流。」有时一个微笑就够了。
2. **同一套要素有两个方向**：正向用于诚实地表达自己，反向用于关切地倾听他人。完整的循环包含双方各四个要素——「我此刻的观察、感受和需要是什么……你此刻的观察、感受和需要是什么……」，交替运行直到情意相通。
3. **形式不能替代意图**。书里那位母亲用完整的四要素句式对孩子说话，孩子没动，她立刻说「像他这样懒惰和不负责任的人是不会有什么前途的」——形式上的四要素没有改变她「让对方照做」的底层目标，所以一失效就退回异化沟通。

本卡是**合成体而非独立能力**：任一要素卡壳时，分流到对应的兄弟卡处理，再回到本卡组装。

## A1 — 书中的应用 (Past Application)

### 案例 1: 费利克斯的两只脏袜子
- **类型**: 作者教学示例（第一章，原文明确以「举例来说」引出，非真实事件）
- **问题**: 一位母亲对处于青春期的儿子说话
- **方法论的使用**: 观察（「看到咖啡桌下的两只脏袜子和电视机旁的三只」）→ 感受（「我不太高兴」）→ 需要（「因为我看重整洁」）→ 请求（「你是否愿意将袜子拿到房间或放进洗衣机？」）
- **结论**: 四要素完整句式的标准示范
- **结果**: 未说明（教学示例，非事件）

### 案例 2: 圣地亚哥研讨班参与者——「非暴力沟通挽救了我们的婚姻」
- **类型**: 作者转述（第一章）
- **问题**: 结婚 28 年的丈夫在研讨班前的那个周末提出了离婚
- **方法论的使用**: 她改用非暴力沟通与丈夫交流——「我不再觉得受伤，也没有退缩，而能倾听和领会他的情感」，并发现「这个与我结婚 28 年的男人，内心原来那样痛苦」
- **结论**: 四要素（表达 + 倾听）可用于亲密关系，且双方都不必为讨好对方而改变
- **结果**: 「幸亏非暴力沟通挽救了我们的婚姻」（当事人陈述）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一开口就吵起来，想换一种表达方式但不知道从何说起
2. 想系统学习非暴力沟通的完整框架（含四要素的完整链条）
3. 面对一件积累了情绪的事，想一次性把它完整说出来
4. 想重组一次重要对话（伴侣、亲子、职场）

### 语言信号

- 「我不知道该怎么跟他说这件事」
- 「我一说就吵，有没有别的办法」
- 「我想把话好好说清楚」
- 「怎么用非暴力沟通的方式表达」
- 英文: "how do I bring this up without a fight", "how do I say this properly", "I want to learn NVC"

### 与相邻 skill 的区分

- 本卡是**合成体**：四个要素各自出问题时，分流到 `observation-vs-evaluation`（剥离评价）、`feelings-vs-thoughts`（找真感受）、`feelings-to-needs`（追需要）、`requests-vs-demands`（构造请求）四张兄弟卡
- 与 `empathic-listening` 的区别: 本卡负责**说**（表达侧）；那条负责**听**（接收侧）。完整循环需要两者交替

## E — 可执行步骤 (Execution)

1. **过四问**
   - 完成标准: 依次回答四问——①我的观察是什么（具体行为）②我的感受如何（情绪词）③哪些需要导致了这个感受 ④我的请求是什么（具体、可执行）
   - 判停条件: 任一问答不出来 → 分流到对应兄弟卡（观察不清 → `observation-vs-evaluation`；感受是伪感受 → `feelings-vs-thoughts`；说不出需要 → `feelings-to-needs`；请求模糊 → `requests-vs-demands`），处理完回到本卡
   - 输入契约: 一次想表达的对话 + 事件经过；信息不足时先请用户补充关键句

2. **组装表达**
   - 完成标准: 用四要素造出一段完整表达（套用句式，顺序可按语感调整）；读一遍确认不含指责、定性、翻旧账
   - 输出契约: 一段可直接说出口的话（书面版 + 口语压缩版各一）

3. **意图检查**
   - 完成标准: 回答「如果对方不照做，我会怎样」——若第一反应是批评、冷脸或让对方内疚，说明意图仍是「改变对方」，回到 `requests-vs-demands` 的可拒绝性自检

4. **转入双向循环**
   - 完成标准: 表达结束后主动转向倾听对方的四要素（观察 / 感受 / 需要 / 请求）；注意到对方仍在情绪中时，先听再说
   - 判停条件: 对方情绪激动无法接收时，转 `empathic-listening`

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 琐碎场景（作者本人指出：有时一个微笑、一声「谢谢」就够了，不必四要素齐备）
- 紧急处置与安全场景（先行动，后表达）

### 作者在书中警告的失败模式

- **形式主义陷阱**：用了四要素句式，但判据仍是「对方有没有照做」；请求落空后立刻回到道德评判（那位母亲的案例，ce10）
- 道德定性开场会当场毁掉对话，即使诉求正当（「地球杀手」案例，ce44）
- 把四要素当话术卡使用——句式完整而觉察缺席

### 作者的盲点 / 时代局限

- 四要素句式在中文口语中显得冗长、书面化，使用者需要压缩变形；作者未讨论书面（邮件/消息）与口语的适配差异
- 「如实表达」在权力不对等场景中的风险（职场中说出真实感受可能招致报复）未讨论
- 作者承认语言有时多余（一个微笑足够），但未给出判断「何时用语言、何时不用」的标准

### 容易混淆的邻近方法论

- `observation-vs-evaluation` / `feelings-vs-thoughts` / `feelings-to-needs` / `requests-vs-demands`: 本卡是四者的合成与组装；单独使用时优先调用那四张
