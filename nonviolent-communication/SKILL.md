# 《非暴力沟通》 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 临床心理治疗、精神疾病诊断与用药（本方法不替代医疗）
- 正在发生的家庭暴力、人身安全危机（先确保安全并联系专业机构）
- 法律争议、劳动争议、合同与赔偿的专业处置

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 四要素是全书的共同语法：观察 → 感受 → 需要 → 请求。表达与倾听用的是同一套要素，方向相反。
2. 对方反驳的通常不是事实，而是裹在事实外面的那层评论——所以第一步是把评价从观察里剥出来。
3. 情绪的根在需要：某种情绪反复出现，是因为某个需要在反复未被满足；找到需要才有出口。
4. 请求必须正向、具体、可拒绝；一旦对方感到「不答应就有代价」，它就已经变成了命令。
5. 倾听是把对方没说完的话替他说出来，而不是给建议、安慰或分析——十项妨碍行为里最常被误用的恰恰是「询问」。
6. 生气时先停下来：找到脑子里那句点火的话，再把那句话翻译成需要。
7. 强制力只可用于防卫（阻止正在发生的伤害），不可用于惩罚（让人长记性）——两者的分界线是意图，不是力度。

## 边界与判停

- 用户描述正在发生的暴力或人身安全威胁时，停止本流程，先建议确保安全并求助专业机构。
- 出现自伤或伤人风险、或持续两周以上的低情绪等临床抑郁指征时，停止并建议就医。
- 用户要求为已经发生的体罚、羞辱或报复行为寻找正当理由时，停止，并明确区分防卫性强制力与惩罚性强制力。
