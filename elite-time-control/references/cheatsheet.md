# 决策规则速查 — 《为什么精英都是时间控》

| 能力 | 一句话规则 |
|---|---|
| 总纲与时间分配（时间价值不均等・二维时间观・专注性/非专注性二分与拼图） | 把「时间不够用」改写成「分配错误」：先给任务二分（专注性/非专注性），再把大图块放上高专注时段。 |
| 重启专注力：睡眠与休息的基础（睡眠是特效药・睡眠损益换算） | 睡眠不是可压缩的成本，是专注力的特效药：少睡 1 小时，次日要多干 1.6 小时来还。 |
| 15·45·90 法则与专注力冲浪（节律・休息单位・假说边界） | 别和节律硬拼：以 15 分钟为基本单位、45 分钟为一大节，按自己的波峰波谷「冲浪」。 |
| 杂念排除法（外物・思考・人・通信）与专注空间 | 专注不是靠意志力顶住，而是把四类杂念（外物・思考・人・通信）逐类清掉。 |
| 时间限制工作术（秒表・初始/最终努力・严守・后有约定） | 给工作一个时限，用秒表而不是闹钟，并且任何情况下都不推迟它。 |
| 早晨：大脑黄金时间与起身术（早起五术・延长黄金时间・提前起床工作术） | 把最费脑的工作放进起床后 2～3 小时的黄金时间，用五术把早晨从「昏沉」改成「临战」。 |
| 上班后最初的 30 分钟与 TO DO 清单 | 到岗后的第一件事不是查邮件：先规划时间、列清单、把专注度标上再排顺序。 |
| 午休重启与午睡（外出午餐三要件・场所神经元/乙酰胆碱・20~30 分钟小睡） | 中午走出去吃（日晒＋步行＋咀嚼），回来小睡 20～30 分钟——下午的状态是「挣」出来的。 |
| 下午重启术（运动/换场所/穿插/小憩/闭目养神/正念/5 分钟小睡） | 下午 2～4 点效率塌方不是靠咖啡，是靠「换状态」：动一动、换个地方、闭目养神。 |
| 下午工作法：确定离开时间与战略性「后有约定」 | 先定死「几点离开公司」，再给晚上安排不可更改的约定——把准时下班变成效率工具。 |
| 运动重启与「第二个黄金时间」（剂量・时机・坚持机制） | 下班后 60～90 分钟有氧，把一天变成两天——但要在睡前 3 小时结束。 |
| 不让压力和疲惫过夜（以天为单位的收支平衡・交流治愈・切断工作） | 恢复的单位是「一天」而不是「一周」：当天结算压力，离开公司就不想工作。 |
| 睡前 2 小时与睡前 15 分钟（睡眠卫生・记忆黄金时间・心理暗示） | 睡前 2 小时给交感神经降温，睡前 15 分钟留给记忆与正面暗示——不刷屏、不反刍。 |
| 周末过法（不补觉・生长激素恢复术・互补休息法・规律生活） | 周末不是补觉日：晚起不超过 2 小时，用运动和「互补休息」把疲劳清掉。 |
| 「For You」工作术（ASAP・提前30分钟・严格守时） | 珍惜别人的时间会返还成你的时间：提前 30 分钟到，严格守时，先做「别人正在等」的事。 |
| 「趁现在」工作术（2分钟判断・30秒决断・未决留后・点式时间・立刻就预约） | 2 分钟能做完的立刻做；能决断的 30 秒内定；定不了的就写死一个「决断时点」。 |
| 并行工作术（移动读书・耳学・思考・3点输出法） | 把通勤这类「机械时段」变成学习时间——但只允许「简单机械动作＋脑力任务」的真并行。 |
| 自我投资（自由时间不还回工作・主要专长・上升螺旋） | 省出来的时间不许还回工作：先练「主要专长」，再谈长期投资。 |
| 主动性娱乐与放松（娱乐分类・电视减量・幸福论・玩乐清单・放松系娱乐） | 给娱乐分两类：能自评的「主动娱乐」用来成长，专注力归零的「放松系」用来恢复。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
