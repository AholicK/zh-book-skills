# 语言基础：表达式、变量与程序结构（条件、循环、模块导入）

## R — 原文 (Reading)

> 你可以给变量取任何名字，只要它遵守以下3 条规则：
> 1．只能是一个词。
> 2．只能包含字母、数字和下划线。
> 3．不能以数字开头。
>
> — 第1章 · 1.4.2 变量名 L1686-1728

> 错误信息Can't convert 'int' object to str implicitly 表示Python 认为，你试图将一个整数连接到字符串'Alice'。代码必须显式地将整数转换为字符串，因为Python 不能自动完成转换。
>
> — 第1章 · 1.6 程序剖析 L1632-1650、L1848-1860

## I — 方法论骨架 (Interpretation)

这张卡把「第一个能跑的 Python 脚本」拆成五个构件：表达式、变量、条件、循环、模块调用——后续全部单元的语言底座。

两条硬约束：命名是语法级（一个词、字母数字下划线、不以数字开头）；大小写敏感——`spam` 与 `SPAM` 是两个变量。

表达式不要求含操作符：单个值与函数调用都算，判据是「能否求值为单个值」。

控制流三口径：条件每次迭代开始时重新求值，循环体必须自己更新条件状态，否则死循环；if/elif/else 至多执行一个子句、取第一个为真，区间条件从窄到宽排；break/continue 只在循环内部。

真值判定：0、0.0、空字符串为假，其余为真。input() 拿到的都是字符串——参与算术前先 int()/float()、拼进字符串前先 str()，Python 不做隐式转换。

模块调用：非内建函数先 import、调用带模块名前缀；提前结束用 sys.exit()（先 import sys）。

## A1 — 书中的应用 (Past Application)

### 案例 1: hello.py——在文件编辑器中写、保存并运行第一个程序
- **类型**: 书中示例（第1章）
- **问题**: 代码在哪写、怎么保存、怎么运行
- **方法论的使用**: 按 f01 流程——File→New Window 打开文件编辑器（无 >>>，区别于交互式环境）→ 输入源码 → Save As 存为 hello.py → 编辑器窗口按 F5 运行，输出在交互式窗口
- **结论**: 书中实测输出：输入 Al 得 The length of your name is: 2；输入年龄 4 得 You will be 5 in a year.
- **结果**: 程序成功运行

### 案例 2: yourName.py——用 while 等到指定输入才退出
- **类型**: 书中示例（第2章）
- **问题**: 追问用户直到输入满足条件才继续——循环出口怎么写
- **方法论的使用**: 按 f02/c05——name 初值为空字符串使条件为真、进入循环；循环体最后一行 input() 取新值赋给该变量；子句结束回到 while 开头重新求值
- **结论**: 输入 your name 时条件求值为 False，跳过子句、继续执行后面的部分（打印 Thank you!）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这张卡?

1. 第一次写 Python 小脚本，把「输入→判断→输出」变成可运行代码
2. 报 TypeError（字符串与数字拼接）或数字相加不对
3. 循环停不下来，或不知道出口怎么写
4. elif 链结果与预期不符

### 语言信号

- 「帮我写个小脚本」「第一段 Python 代码怎么写」
- 「为什么循环停不下来」「input 拿到的数字不能相加」
- 英文: "write a small script", "infinite loop", "cannot concatenate str and int"

### 与相邻能力的区分（阶段 3 定稿）

- 与 `functions-and-exceptions` 的区别: 本卡只给单层脚本的语法底座；多函数结构、参数返回值与错误处理在那条卡。
- 与 `lists-and-references` 的区别: 单值与基本类型在本卡；容器的下标、切片与引用语义在那条卡，列表遍历依赖的 for 口径回引本卡。

## E — 可执行步骤 (Execution)

1. **确认脚本骨架**
   - 完成标准: 一句话写出「输入什么、怎么判断、输出什么」
2. **命名变量**
   - 完成标准: 每个名字通过三条规则（一个词、字母数字下划线、不以数字开头）；全文大小写一致
   - 判停条件: 名字含空格/中划线/$ 或数字开头——先改名
3. **写条件与循环**
   - 完成标准: elif 区间条件从窄到宽（防 ce04 截胡）；循环有可终止路径——条件变量在体内更新，或 while True + break / sys.exit()
   - 判停条件: 循环体内找不到更新语句时先停下补出口
4. **处理类型转换**
   - 完成标准: input() 结果参与算术前先 int()/float()；数字拼进字符串前先 str()（防 ce02）
   - 判停条件: 输入可能非法时只按「合法输入」交付，越界转 `functions-and-exceptions`
5. **模块与退出**
   - 完成标准: 非内建函数先 import、调用带模块名前缀；提前退出用 import sys + sys.exit()

**输入契约**: 必需 = ①任务做什么（输入/判断/输出）；②输入从哪来。缺「判断条件」先问。多函数结构与文件/表格/网页操作不在本卡。

**输出契约**: 可运行单文件脚本 + 每个判断点的出处（命名 p05/p06、类真类假 p08、类型转换 ce02、循环出口 f02/f03）。完成标准: 对合法输入跑通。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这张卡

- 需要多函数结构、参数/返回值或错误处理——走 `functions-and-exceptions`
- 需要文件/表格/网页数据读写——属于对应任务卡；本卡只给语法骨架
- 需要「注释掉危险代码再运行」的完整流程——p07 只是初步形态，强化版在 v08

### 作者在书中警告的失败模式

- ce02: 字符串与整数用 + 相加不做隐式转换（报错 Can't convert 'int' object to str implicitly）；程序在该行崩溃
- ce03: 循环条件由用户输入决定且永不改变——「如果永不输入your name，那么循环的条件就永远为False，程序将永远问下去」；逃生只有 Ctrl-C；对策是给循环明确出口
- ce04: 找到 True 条件后剩余子句自动跳过；范围条件顺序错了宽条件先命中（age=3000 输出 'You are not Alice, grannie.'），窄分支成为死代码

### 作者盲点与底本缺口

- 单元 note: c02/c49 是「读代码」教学例；p07 的强化版在 v08
- 类真/类假只列 0、0.0、'' 三类；空列表/None 书中未写，不得以常识补齐
- range() 单参数从 0 开始是间接给出；step=0、sys.exit() 退出码与清理书中未讲
- 输入验证（int() 收非数字抛 ValueError）第3章才讲，本卡按合法输入限定
- nr_warnings: 本单元为空

### 容易混淆的邻近方法论

- `functions-and-exceptions`: 同样回答「程序怎么写」，对象是多函数与错误处理；本卡是其语言底座
- `lists-and-references`: 对象是容器的下标/切片/引用；单值运算与转换仍回本卡
