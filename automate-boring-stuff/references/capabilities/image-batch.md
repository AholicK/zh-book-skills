## I — 方法论骨架 (Interpretation)

这张卡把「修图」从 GUI 手工变成脚本：批量打开 → 变换 → 另存，让统一尺寸、加水印这类机械劳动可重复执行。

流程骨架：`Image.open(文件名)` 拿 Image 对象 → 变换（crop(矩形) 裁剪、copy() 复制出可改的新图、resize((w,h)) 缩放、paste() 粘贴、rotate() 旋转）→ `save(新文件名)` 落盘；原图不会被改动，除非你对同一对象连续操作。

坐标口径先立住：原点 (0,0) 在左上角，x 从左至右增，y 从上至下增（与数学课的 y 相反）。RGBA 分量是 0–255 的整数，alpha=0 完全透明；`ImageColor.getcolor('darkgray', 'RGBA')` 把颜色名换成 RGBA 值。

两个关键判据：① 粘贴透明徽标必须给 paste() 传第三个参数（徽标 Image 对象本身），否则透明像素会被贴成不透明白块；② 缩放要自己按比例算新宽高（用 im.size 读原尺寸），批处理时跳过输出文件本身。

逐像素用 `getpixel((x, y))` / `putpixel((x, y), RGBA值)`；空白画布 `Image.new('RGBA', (宽, 高), 颜色)`；绘制走 ImageDraw，绘制文本的字体必须给真实字体文件（字体名不是文件名，见 ce34）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 添加徽标（resizeAndAddLogo.py）
- **类型**: 书中项目（第17章）
- **问题**: 要给数千张图片统一缩放并在角上加水印；GUI 逐个做太慢，专业软件要几百美元
- **方法论的使用**: 打开 catlogo.png；常量前置 SQUARE_FIT_SIZE=300、LOGO_FILENAME → 遍历目录 .png/.jpg（跳过徽标自身）→ 宽或高超 300 时按比例算新尺寸并 resize() → paste(logoIm, (width - logoWidth, height - logoHeight), logoIm) → save() 到 withLogo 文件夹
- **结论/结果**: 实测输出 Resizing zophie.png... / Adding logo to zophie.png...；zophie.png 变为 225×300 并加上徽标

### 案例 2: 逐像素涂色（17.2.6 交互式演示）
- **类型**: 书中示例（第17章）
- **问题**: 演示单个像素怎么读、怎么写
- **方法论的使用**: Image.new('RGBA', (100, 100)) 建空白图 → getpixel((0, 0)) 初始为 (0, 0, 0, 0) → 两层 for 逐个 putpixel 涂色
- **结论/结果**: 涂色前 (0, 0, 0, 0)，涂色后 (210, 210, 210, 255)

## E — 可执行步骤 (Execution)

1. **确认变换目标与坐标系**
   - 完成标准: 明确每张图要做哪些操作（缩放/裁剪/粘贴/旋转/绘制）；坐标计算换成「左上原点、y 向下」的像素坐标
2. **打开与遍历**
   - 完成标准: Image.open() 读图；批处理遍历目录并按扩展名筛选，跳过徽标/输出文件本身；用 im.size 取原尺寸
3. **按比例缩放**
   - 完成标准: 最长边超阈值时按原比例算新宽高后 resize((w,h))（int() 取整）；可参照书中项目 SQUARE_FIT_SIZE=300 的算法
   - 判停条件: 不要求统一尺寸、只加水印 → 跳过本步
4. **粘贴徽标/水印**
   - 完成标准: 位置按图像与徽标尺寸计算（右下角 = 宽/高相减）；paste(logoIm, (x, y), logoIm) 必须带第三个参数
5. **另存与自检**
   - 完成标准: save() 到独立输出目录（不改原图）；检查输出数量；抽查尺寸与角落水印；绘制文本前确认字体文件真实存在（ce34）

**输入契约**: 必需 = ①图片目录或文件列表；②变换目标（统一多大/水印图与位置/绘制内容）；③输出目录与是否保留原图。缺 ② 先问；水印需图片文件本身，缺则要求先提供。

**输出契约**: 可运行脚本 + 输出目录中的处理后图片；完成标准：每张图执行同一变换且跳过输出文件本身；open/resize/paste/save 可回指 f57/f58/p70 口径。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这张卡

- 需要处理动图/多帧（GIF 帧、视频）——书中未覆盖
- 需要调色板模式转换、色彩管理、压缩参数调优——书中未覆盖
- 需要「字体名直接映射」（不提供字体文件）——ce34 的坑
- 复杂图像管线（证据最薄入口）：6 条候选（全场最小），超出部分查 Pillow 官方文档

### 作者在书中警告的失败模式

- 漏传 paste() 第三参数（f58/c38）：「如果没有传入logoIm 作为第三个参数，paste()方法不会粘贴透明的像素」——透明像素变白块
- 字体找不到（ce34）：ImageFont.truetype() 要的是真实字体文件（或可被自动搜索到的文件名），不是「字体名」；跨平台/换机器时路径失效直接报错，批量脚本中途停住

### 作者盲点与底本缺口

- **NR-03**：strftime 指令表在源稿中不存在；Box 元组四整数顺序在源稿中被截断（p70）——不得自行补齐，需要时指向 Python 官方文档 / Pillow 官方文档（外部资料）；unit_note 记为 needs-review，不得回填
- **版本风险**：本书示例为 2016 年版；现代版本的同名库可能已改名或调整语义，执行前按当前官方文档核对；阶段 4 不得把版本变化导致的失败计为能力缺陷
- **unit_note**：本单元候选数全场最少（6 条）、证据密度中等；书中未处理 GIF/非 RGB 模式图片（f58 缺失条件）
