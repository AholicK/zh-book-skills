# 决策规则速查 — 《再见智人：人类主义的黄昏》

| 能力 | 一句话规则 |
|---|---|
| 人类主义批判与两条路径 | 读话语先问：谁被放在中心、谁被排除为「亚人」——框架不破，余数永存 |
| 技术-政治总纲与文明两把钥匙 | 分析任何文明/组织/平台先做技术-政治双侧体检：智能在加速，智慧是否在虚化？ |
| 器官学分析：赛博格与去功能化→再功能化 | 问一项技术改写了哪些器官功能：什么被去功能化了，又有没有长出新的用途？ |
| 去智化诊断：神人、无用阶级与算法权力 | 把「AI 让人变蠢」做成两栏体检：能力退场清单（生物器官）＋算法权力（政治器官）。 |
| 智能/智慧判定与知识分享双模式 | 先判一项能力宣称挂在「人-物」还是「人-人」关系上，再看缺口在智能侧还是智慧侧。 |
| 信任问题：技术政治学分析 | 信任是对信息的透支与无凭跃步：技术认证能降低风险，但不能替代信任的创制。 |
| 大语言模型的智能与意识辨析 | AI 意识宣称要过「慢、理由化、符号性」三关：图灵测试不算数，涌现不排除、也不轻信。 |
| 对齐与可解释性工程审计 | 审计「让 AI 可信」方案：先问谁的价值、谁承担代价，再做黑箱对称性检验。 |
| 竞速学分析：速度、决断让渡与紧急状态 | 用竞速学三问定位加速现象：谁在竞速、谁的后勤跟不上、决断权在谁手中。 |
| 系统性愚蠢与纳什均衡 | 诊断「谁都停不下来」的僵局：纳什均衡侦测＋「诉诸更高的力量」破局条件。 |
| 行动元与后民主政治 | 先列行动元清单与触动链，再用「形式保留／实质掏空／算法替补」三判据核对后民主。 |
| 全面赋闲与「不被需要」 | 先判层级（个体策略 vs 共同体政治），再排三大框架的失效点；「不被需要」≠ 失业。 |
| 爱的算法化与算法黑箱（大他者） | 把「算法懂爱」当工程读：先查问题怎么被改写，再查三基石、过滤器与失效点 |
| 教育：焦虑诊断与后人类教育（斆学半） | 先拆教育焦虑的两级肇因与两前景，再做表征主义体检，用「斆学半」重设师生互动。 |
| 人类学机器与赛博格机器 | 用「人类学机器」做正当性审计：先查对象是否被话语降维，再查残忍是否以卫生／工程之名获得正当性。 |
| 技术哲学：负熵、熵账本与地居者 | 评估技术先记熵账本：局部熵减必伴更大熵增，再判药性与熵人／负熵人分岔 |
| 后人类知识实践（跨学科、纯化与杂交） | 跨学科不是口号：用「纯化／杂交／怪物」诊断学科建制，以「非现代杂交」（不再做纯化）组织知识实践。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
