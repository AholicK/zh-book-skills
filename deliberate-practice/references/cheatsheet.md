# 决策规则速查 — 《刻意练习：如何从新手到大师》

| 能力 | 一句话规则 |
|---|---|
| 有目的的练习：四特点诊断与改造 | 用「目标/专注/反馈/走出舒适区」四点给一段练习做体检，缺哪补哪。 |
| 挑战校准：走出舒适区、体内平衡与甜蜜点 | 难度停在「甜蜜点」：成功就加码、反复失败就减码并复盘，既别停在舒适区也别一次推太猛。 |
| 瓶颈突破与停滞跨越 | 卡住时先换一种练法（不同的方式，而不是更难的方式），再找出停滞点单练。 |
| 无导师自训：三步路线图与三个F | 没有导师就复刻杰出者的成果：辨别→推测差别→自设练习，用三个F（专注、反馈、修正）循环。 |
| 心理表征：概念、功能与创建（含复写对比法） | 高手的壁垒是心理表征：用「能预测/能解释/能组织/能计划」四问诊断表征质量，用复写-对比-纠正创建。 |
| 工作中训练化：边干边学与会议改造 | 把日常会议/演示改造成练习：选一项技能、观众按点记录并反馈、下轮改进、固化成制度。 |
| 组织训练系统设计：王牌训练式仿真与即时反馈 | 给组织造训练场：绩效可测＋可仿真＋即时反馈＋答错回环，而不是讲课。 |
| 导师的使用：选择、评估与更换 | 选导师看「能否帮你创建心理表征」而非名气与有趣，教完当前可教内容就该换。 |
| 动机系统：弱化停下理由与增强前行理由 | 把「坚持」改造成系统：弱化停下理由（固定时间、睡眠、时长上限）＋增强前行理由（信念、团体、榜样）。 |
| 目标分解与进步监测 | 把长期目标切成能记录的小规格：一次只盯一个、每次可计数、固定复盘看趋势。 |
| 破除意志力神话与三种错误思想 | 「意志力」不是可耗尽的通用特质：把它拆回「继续理由 vs 停下理由」再谈方法。 |
| 天赋偏见纠偏：自我实现预言与标签 | 「没天赋」多是标签自证：识别标签→替换能力归因→用教法与时间替代。 |
| 教学与课程改造 | 把「讲知识」的课改成「练技能」：先列学完能做什么，再逆向设计练习、问题与反馈。 |
| 成年与大龄学习判断 | 成年后心理能力照样可塑：几乎无绝对限制（身体窗口型除外），真正的限制常是练习条件。 |
| 练习史解释框架：训练时间 vs 天赋 | 解释「谁更强」时先看练习史与训练质量，天赋归因留到最后，并说明证据局限。 |
| 1万小时法则的错与对 | 「1万小时」拆成错四对二：不是阈值、是平均数、表演≠练习；但多年艰苦努力确实必要。 |
| 天才祛魅：两问框架与传说破解 | 遇到「神童/天才」传说用两问拆：这种能力的特点是什么？什么样的训练使它成为可能？ |
| 杰出人物路线图与「练习人」心法 | 长期发展按四阶段推进：兴趣（玩）→认真（技艺）→全力（比赛）→开拓（创新），家长/教练各阶段角色不同。 |
| 刻意练习的界定与条件审查 | 先审两条件（领域是否已发展、有无导师设计监管），不满足就降级为「有目的的练习」实施。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
